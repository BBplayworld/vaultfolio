# S-4.23 세금 신고 안내 (세금 캘린더)

> 상태: 승인 | 브랜치: `issue-4.20` (기존 작업 브랜치 유지) | 작성 2026-07-27

## 1. 왜
앱은 순자산·수익률은 보여주지만 **자산을 보유했기 때문에 생기는 납세 의무**는 전혀 안내하지 않는다. 상가(사업자)는 1·7월 부가세와 5월 종소세, 부동산은 6/1 과세기준일과 7·9월 재산세, 해외주식은 이듬해 5월 양도세가 각각 다른 기한으로 돌아오고 놓치면 가산세로 이어진다. 사용자가 이미 앱에 입력해 둔 자산 구성만으로 "이번 달 내가 해야 할 신고"를 특정할 수 있는데도 그 정보가 놀고 있다.

## 2. 무엇 (범위)
- 포함:
  - **월별 세금 일정 정적 데이터**(`config/tax-calendar.ts`) — 부가세·종소세·재산세·종부세·양도세·연말정산·건강보험료 정산 등 20여 건.
  - **보유 자산 기반 개인화** — 자산 구성 → 세금 태그 매칭. 해외주식은 당해 **실현차익 250만원(기본공제) 초과 여부**까지 계산해 이듬해 5월 신고 대상임을 알린다.
  - **홈 배너**(`TaxNoticeBox`) — 이번 달·다음 달 중 **내 자산에서 파생된** 일정만 최대 3건 + 매칭 근거 문구. 닫기 시 **해당 월 동안** 미노출.
  - **세금 캘린더 뷰**(`#tax`) — 12개월 전체 일정. `내 세금 / 전체` 필터.
  - 더보기 "지원" 섹션 + 홈 배너 "상세" 두 경로에서 진입.
- **제외**:
  - 세액 계산·시뮬레이션(과세표준·누진공제·필요경비) — 정확도를 보장할 수 없어 하지 않는다. 일정 안내와 "신고 대상 여부"까지만.
  - 국세청 API 연동·홈택스 딥링크 — 외부 API 추가 없음.
  - 알림(푸시·이메일) 발송 — 앱 진입 시 배너로만.
  - 법인세 상세·근로소득 연말정산 항목별 공제 안내 — 개인 자산 관리 범위 밖.
  - 가상자산 과세는 시행 예정 상태로 **참고 표기만**(과세 판정 안 함).
  - 하단탭(1차 메뉴) 추가 — 저빈도 정보라 `settings`와 동일한 더보기 하위 페이지로 둔다.

## 3. 수용 기준
- [ ] AC1. WHEN 상가·사무실(`realEstate.type === "commercial"`)을 보유하면, 시스템은 1·7월 부가가치세 확정신고와 5월 종합소득세를 **내 세금**으로 판정한다.
- [ ] AC2. WHEN 이번 달·다음 달에 **자산에서 파생된**(`common` 태그 전용이 아닌) 일정이 하나도 없으면, 시스템은 홈 배너를 **렌더하지 않는다**. 연말정산·건강보험료처럼 전 국민 공통 항목만 있는 달에도 배너는 뜨지 않는다.
- [ ] AC3. 홈 배너의 각 항목에는 **매칭 근거**가 함께 표시된다(예: "상가·사무실 1건 보유", "해외주식 3종목 보유").
- [ ] AC4. WHEN 홈 배너를 닫으면, 시스템은 닫은 달(KST `YYYY-MM`)을 기록하고 **그 달 동안 재노출하지 않는다**. 달이 바뀌면 다시 노출한다.
- [ ] AC5. WHEN 백업 JSON을 복원하거나 클라우드 동기화 pull이 일어나도, 시스템은 닫기 상태를 **유지**한다(기기 로컬 메타데이터).
- [ ] AC6. WHEN 당해 연도 해외주식 매도 거래의 실현차익 합계가 **250만원을 초과**하면, 시스템은 5월 양도소득세 항목에 "이듬해 5월 신고 대상 · 예상 차익"을 표시한다. 매수 로그가 없거나 체결 환율이 없으면 현재 평단·환율로 폴백하고 **추정치임을 표기**한다.
- [ ] AC7. WHEN `transactions`가 비어 있으면, 시스템은 실현차익을 계산하지 않고(`null`) 양도세 항목을 일반 안내로만 표시한다.
- [ ] AC8. 캘린더 뷰는 12개월 전체를 세로 리스트로 보여주고, 현재 월을 강조하며 마운트 시 해당 위치로 스크롤한다. `내 세금` 필터는 교집합 항목만, `전체`는 모두 표시하되 비해당은 흐리게 처리한다.
- [ ] AC9. `#tax`로 직접 진입해도 뷰가 복원되고, 뒤로가기는 `history.back()`으로 **진입 경로**(홈 또는 더보기)로 돌아간다.
- [ ] AC10. 캘린더 뷰 하단에 "일반 참고용이며 실제 신고·납부는 국세청·세무 전문가 확인" 면책 문구가 항상 노출된다.

| 통화·환율 | 해외주식 실현차익은 KRW 환산. 체결 환율(`tx.exchangeRate`) 우선, 없으면 `purchaseExchangeRate` → 현재 `exchangeRates` 순 폴백 + `estimated: true` |
