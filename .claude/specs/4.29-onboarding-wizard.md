# S-4.29 스크린샷 일괄 온보딩 마법사

> 상태: 완료 | 브랜치: `issue-4.29-onboarding-wizard` | 작성 2026-08-12

## 1. 왜

신규 유저의 첫 성공 경험을 "몇 분 안에 내 자산 전체를 한눈에 보기"로 만드는 것이 목표. 신규 인식 엔진 개발이 아니라 기존 스크린샷 인식 엔진을 순차적 온보딩 플로우로 재조립하는 UX 작업으로 한정한다.

## 2. 무엇 (범위)

- 포함:
  - 자산 0건 신규 유저에게 카테고리 순차 업로드 마법사 노출(주식→코인→현금→대출, 4단계)
  - 각 단계: 가이드 이미지 → 이미지 1장 업로드 → 기존 `parse-screenshot` 인식 → 수정 가능한 미리보기 → "다음"/"이 카테고리는 없어요(건너뛰기)"
  - 완료 화면: 파싱된 자산 기반 홈 대시보드 프리뷰 + "확인 완료" → 실제 홈 진입
  - 완료 화면에서 S-4.28 목표 설정으로 선택적 연결(건너뛰기 가능)
  - 온보딩 중단 후 재실행 시 마지막 완료 단계부터 재개
  - 더보기 메뉴에 재진입 경로 제공

- **제외** (이번에 하지 않는 것 — 원 스펙 대비 축소, 사용자 확정):
  - **부동산 스크린샷 인식** — `parse-screenshot` API(`ParseAssetType`)에 `realEstate` 타입 자체가 없고 FAB에서도 `hasScreenshot:false`로 명시적 배제된 상태. 신규 인식 엔진(프롬프트·스키마) 개발은 "기존 엔진 재조립"이라는 이번 라운드 취지를 벗어나므로, **v1은 부동산을 마법사 순서에서 제외**하고 카테고리 선택 화면에서 "부동산은 직접 입력할게요" 진입점만 제공해 기존 수동 입력 폼으로 바로 보낸다. **v1 카테고리는 주식→코인→현금→대출 4종.**
  - **카테고리당 다중 이미지 업로드** — 기존 4개 스크린샷 컴포넌트(`*-screenshot-import.tsx`) 전부 단일 `File`만 처리하는 구조(input에 `multiple` 없음, `dataTransfer.files[0]`만 사용). 다중 지원은 4개 컴포넌트를 전부 뜯어고치는 작업이라 **v1은 카테고리당 1장**으로 제한한다. 여러 계좌/보유분이 있으면 완료 화면 이전에 각 카테고리를 반복 재방문(다시 이 단계로)해 추가 업로드하는 것도 v1 범위 밖 — 완료 화면 도달 후 "더보기 → 자산 추가"로 마저 등록
  - **Gemini 사용량 한도 완화 설계** — 카테고리당 1장 제한(위 항목)으로 마법사 1회당 최대 4회 호출에 그쳐 일일 15회 한도 대비 여유가 커짐. 별도 한도 상향·마법사 전용 쿼터는 이번에 만들지 않는다
  - 인식 실패 시 해당 카테고리 자동 수동 입력 전환의 세부 UX는 기존 각 스크린샷 컴포넌트의 실패 처리(에러 토스트 등)를 그대로 따르고, 신규 "실패 감지 후 자동 폼 전환" 로직은 만들지 않는다(사용자가 직접 "건너뛰기 → 수동 입력" 선택)

## 3. 수용 기준

- [ ] AC1. WHEN 자산 0건 상태로 앱에 처음 진입하면, 시스템은 마법사 진입 화면을 노출한다(기존 `isWelcomeGuide` 트리거 조건 재사용).
- [ ] AC2. WHEN 온보딩을 한 번이라도 건너뛰면, 시스템은 이후 자동 재노출하지 않는다. 더보기 메뉴의 진입점으로만 재진입 가능하다.
- [ ] AC3. 각 카테고리 단계(주식·코인·현금·대출)는 독립적으로 건너뛸 수 있다.
- [ ] AC4. 부동산은 마법사 순서에 포함되지 않고, 카테고리 선택 화면에서 기존 수동 입력 폼으로 바로 연결된다.
- [ ] AC5. 인식 결과는 최종 반영 전 수정 가능한 미리보기 화면을 거친다.
- [ ] AC6. WHEN 온보딩 도중 앱을 종료했다가 재실행하면, 시스템은 마지막으로 완료한 카테고리 단계부터 재개한다(처음부터 다시 시작하지 않는다).
- [ ] AC7. 완료 화면은 실제 홈 대시보드와 동일한 데이터(도넛차트·요약)로 프리뷰를 렌더한다.
- [ ] AC8. 완료 화면에서 목표 설정(S-4.28) 연결은 선택적이며 건너뛰기 가능하다.
- [ ] AC9. WHEN 자산이 1건 이상 있는 상태에서 더보기로 마법사를 재진입하면, 시스템은 기존 자산을 덮어쓰지 않고 인식된 항목을 추가 등록으로 처리한다(기존 스크린샷 인식 컴포넌트의 "병합/신규 추가" 동작을 그대로 따름 — 신규 병합 UI를 별도로 만들지 않는다).
- [ ] AC10. 5개(v1은 4개) 카테고리를 전부 건너뛴 경우, 완료 화면 대신 기존 `WelcomeGuide` 화면으로 안내한다.
