# S-4.28 GA4 사용 기능 추적 (4.41 #68에서 page_title 하나로 단순화)

> 상태: 4.28 완료 → **4.41 단순화(현행)** | 작성 2026-10-18, 개정 2026-11-06
> (번호 주의: 과거 롤백된 "목표 설정"도 S-4.28을 썼으나 명세 파일 없이 철회됨 — 본 명세와 무관)

## 1. 왜

대표가 보고 싶은 것은 **사용자가 어떤 기능·페이지를 주로 쓰는가** 하나다. 4.28의 맞춤 매개변수 8개·사용자 속성 5개·한국어 라벨 체계는 분해 판독용이었으나 쓰지 않았고, `track()`이 `page_title`을 보내지 않아 액션 이벤트가 문서 기본 title 행("시크릿에셋 — …")에 몰렸다. 4.41은 페이지와 액션을 **한 목록(page_title)** 으로 통일하고 나머지를 정리한다.

## 2. 현행 구조 (4.41)

- 모든 앱 이벤트·화면 page_view는 `page_title`(= 사용 기능 이름) + `page_location`(가상 경로 `origin/v/<화면키>`)만 보낸다. 맞춤 매개변수·사용자 속성은 보내지 않는다.
- 호출부의 의미 인자(`asset_type`·`method`·`category` 등, `PARAM_VALUES`)는 `featureTitleOf(eventName, params, currentScreenKey)`가 title을 정하는 데에만 쓰고 GA로 나가지 않는다.
- 화면 page_view는 GA4 표준 필드 `page_title`·`page_location`·`page_path`만 전송하며, 맞춤 매개변수·사용자 속성은 없다(`page_path`는 맞춤 정의가 아닌 표준 필드, 기존 동작 유지).
- 대표가 보는 것은 GA 기본 보고서 **"페이지 및 화면"(페이지 제목 및 화면 클래스) 한 장**(PC).
- 이벤트 이름과 키 이벤트 지정(`first_asset_saved`·`tutorial_complete`·`share`)은 유지.
- 안전 원칙 유지: 금액·수량·종목·티커·닉네임·assetId·공유키·URL 해시·쿼리(허용 UTM 3키 제외)·에러 문구 전송 금지. gtag 부재·예외·옵트아웃은 no-op, 체험 모드 전송 0, `window.gtag` 직접 호출 금지(`ga.ts` 단일 진입점), `?ga-debug=1`은 `debug_mode:true`.

## 3. 사용 기능 목록 (page_title 값)

- 화면(`SCREEN_TITLES`): 홈 / 상세 / 상세·주식 / 상세·주식 X-Ray / 상세·주식 거래내역 / 상세·부동산 / 상세·암호화폐(·거래내역) / 상세·현금(·거래내역) / 상세·대출(·거래내역) / 성과 / 성과·자산 변화 / 성과·자산 변화·구성(#72, 연 탭 구성 카드 50% 노출 시 1회) / 성과·배당 / 성과·자산 성적표 / 세금 관리 / 더보기 / 설정 / 비중 미리보기(/ratio)
- 액션(`featureTitleOf`):

| 이벤트 | page_title |
| --- | --- |
| `welcome_view`·`onboarding_action` | 웰컴 |
| `tutorial_*`·`wizard_step` | 온보딩 |
| `asset_add_start` | 자산 추가 시작(·자산종류) |
| `asset_save`·`first_asset_saved` | 자산 저장(·자산종류) |
| `screenshot_parse` | 스크린샷 등록(·자산종류) |
| `transaction_save` | 거래 입력(·자산종류) |
| `share` (method=save) | 인증카드 저장 |
| `share` (그 외)·`share_restore` | 공유 |
| `sync_action` | 기기 동기화 |
| `data_action` (export·import) / 그 외 | 백업 / 데이터 관리 |
| `pwa_install` | 앱 설치 |
| `settlement_view` | 월 결산 |
| `theme_mode` (#4.42, 파라미터 `theme`: dark/light — page_title 결정용, 전송 안 함) | 다크 모드 사용 / 라이트 모드 사용 — 앱 시작 후 세션당 1회, 설정에서 전환 시 새 모드로 1회 재전송, 체험 모드 0 |
| `feature_use` category: xray / tax_sim / home_tip·notice / feedback / theme / ai_prompt / demo / share_card / app_guide | X-Ray / 절세 시뮬레이션 / 홈 팁 / 의견 보내기 / 테마 변경 / AI 프롬프트 복사 / 체험 모드 / 인증카드 열기 / 앱 가이드 열기 |
| 그 밖(`asset_delete`·`transaction_delete`·`app_lock`·`feature_use` ratio_preview 등) | 현재 화면 title (없으면 title 생략) |

자산종류 접미: 주식·암호화폐·현금·대출·부동산·연도별 순자산.

## 4. 수용 기준

- [x] AC1. gtag 부재·예외 시 `track`/`trackScreen` 무시, 예외 비전파.
- [x] AC2. `track`/`trackThenNavigate` payload는 `page_title`·`page_location`(+`event_callback`·`event_timeout`·디버그 시 `debug_mode`)만. 의미 인자·잡값은 전송되지 않는다.
- [x] AC3. `page_location`에 URL 해시·쿼리 없음(허용 UTM만 `/ratio`).
- [x] AC4. `featureTitleOf` 전수 매핑·화면 title 불변·매핑 없으면 화면 title/생략.
- [x] AC5. 사용자 속성(`gtag('set','user_properties')`)·`nav_source` 전송 0.
- [x] AC6. 체험 모드 전송 0.
- [x] AC7. 화면 전환 page_view 1회(같은 화면 연속 호출 무시).
- [x] AC8. `first_asset_saved` 기기당 1회(`gaFlags`), 공유 복원·가져오기·pull 제외.
- [x] AC9. `sync_action`은 수동 동작·충돌에서만(자동 폴링 제외).
- [x] AC10. 인증카드 열기·앱 가이드 열기 `feature_use` 1회씩.

## 5. 데이터 계약
저장·스키마·동기화·공유 토큰 무변경. 신규 키 없음(`gaFlags`는 4.28 유지). 서버로 나가는 값이 늘지 않고 오히려 줄어든다(분석 전송만, 사용자 자산 값 없음).

## 6. 폐기된 4.28 설계 (참고)
다음은 4.41에서 **폐기**했다: GA 맞춤 정의(이벤트 범위 8 `asset_type`·`category`·`content_type`·`method`·`result`·`source`·`step`·`nav_source` / 사용자 범위 `app_mode`·`asset_count_bucket`·`sync_enabled`·`onboarding_state`·`theme`), 한국어 값 라벨(`PARAM_LABELS`·`USER_PROP_LABELS`), `sanitizeParams`, `setUserProps`, 활성화 퍼널·스크린샷 퍼널 등 맞춤 정의 기반 탐색 분석 템플릿. 대표 GA 작업: 배포 후 맞춤 정의 보관처리, 24~48시간 뒤 "페이지 및 화면" CSV 공유.
