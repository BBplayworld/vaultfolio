# S-4.19 예적금 만기일·금리

> 상태: 초안 | 브랜치: `issue-4.19-deposit-maturity` | 작성 2026-07-20

## 1. 왜

예금·적금은 **만기라는 행동 시점**이 있는 유일한 자산인데, 현재 `Cash`에는 만기일도 금리도 없다. 그래서 사용자는 앱에서 "언제 만기인지", "이자를 얼마나 받는지"를 알 수 없고 별도로 기억해야 한다. 대출은 이미 만기 D-day와 이자 부담을 보여주는데(`loan-tab`), 반대편인 예적금만 비어 있어 비대칭이다.

## 2. 무엇 (범위)

- **포함**
  - `Cash`에 만기일·연이율 optional 필드 추가 (예금·적금에만 노출)
  - 현금 탭 카드에 만기 D-day + 연 이자 수입 예상 표시
  - 만기 임박(90일 이내) 강조 — 대출 탭과 동일한 시각 규칙
- **제외** (이번에 하지 않는 것)
  - 만기 시 자동 알림·푸시 (알림 인프라 자체가 없음)
  - 만기 후 자동 재예치·잔액 갱신 (사용자가 직접 수정)
  - 세후 이자 계산 (이자소득세 15.4% 반영은 별도 판단 필요)
  - 적금의 월 납입액 기반 정확한 만기 수령액 계산 — 단리 근사만
  - 홈·성과 탭 노출 (현금 탭 안에서만)

## 3. 수용 기준

- [ ] AC1. WHEN `type`이 `deposit` 또는 `savings`일 때, 입력 폼은 만기일·연이율 필드를 노출한다
- [ ] AC2. WHEN `type`이 그 외(`bank`/`cma`/`cash`)일 때, 시스템은 두 필드를 노출하지 않는다
- [ ] AC3. WHEN 만기일이 입력돼 있을 때, 카드 상세에 `D-{일수}`와 남은 기간을 표시한다
- [ ] AC4. WHEN 만기일이 이미 지났을 때, 시스템은 "만기 지남"으로 구분해 표시한다
- [ ] AC5. WHEN 연이율이 0보다 클 때, 연 이자 수입 예상(잔액 × 이율)을 표시한다
- [ ] AC6. WHEN 만기가 90일 이내일 때, 시스템은 강조색으로 표시한다
- [ ] AC7. 두 필드가 비어 있는 기존 데이터는 아무 변화 없이 그대로 동작한다

## 4. 데이터 계약

| 항목 | 확인 |
| --- | --- |
| `assetDataSchema` 변경 | **있음** — `cashSchema`에 `maturityDate?: string`, `interestRate?: number` 추가. **둘 다 `.optional()` 필수** |
| 구버전 백업 JSON 복구 | optional이므로 `applyImportedPayload`의 `assetDataSchema.parse` 통과 ✅ (필수 필드로 만들면 구버전 백업 복구 불능 — 금지) |
| 신규 `STORAGE_KEYS` | 없음 (기존 `assetData` 안에 저장) |
| 공유 토큰 직렬화 | **검토 필요** — `packV7`의 cash 섹션에 필드를 추가하면 구버전 파싱이 깨질 수 있음(R3). **미추가 권장**: 공유는 1회 핸드오프라 만기 정보가 없어도 치명적이지 않음. 추가한다면 끝자리에 append하고 구버전 unpack 경로 보존 확인 |
| cloud-sync 비교 대상 | 없음 — 사용자 입력값이라 접속마다 갱신되지 않음. `getComparablePayloadString` 제외 불필요(R14 무관) |
| 마이그레이션 | **불필요** — optional 필드라 기존 데이터는 `undefined`로 자연 동작 |
| 통화·환율 | 무관하지 않음 — 외화 예금(USD/JPY)의 이자 표시 통화를 원화 환산으로 할지 원통화로 할지 결정 필요 (§7) |
| 비활성 종목 | 무관 (주식 전용 개념) |

## 5. 영향 표면

- 화면: `views/detail/tabs/cash-tab.tsx`(카드 상세), `forms/asset-update/input/cash-input.tsx`(입력 폼)
- 타입: `src/types/asset.ts` `cashSchema`
- 유틸: **신규 없음** — `daysUntil`(`lib/number-utils.ts`)·`formatPriceByMode` 재사용. 이자 계산은 대출 탭과 동일한 `잔액 × 금리/100` 수식
- API·캐시 키: 영향 없음
- **건드리지 않는 것**: 순자산 계산(`computeNetAsset`)·성적표·홈 대시보드·동기화 로직. 만기일은 표시 전용이며 자산 평가액에 영향을 주지 않는다
