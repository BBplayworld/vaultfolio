# S-4.31 연말 절세 시뮬레이션 (해외주식 양도소득세)

> 상태: 완료 | 브랜치: `issue-4.31-tax-sell-simulation` | 작성 2026-08-26 | 개편 2026-08-27

## 0. 개정 이력
1차 구현(개별 종목 "예상 세금" `Sheet` + 세금 캘린더 내 작은 인사이트 박스)을 사용자가 확인한 뒤 세 가지 문제로 전면 개편했다:
1. 인사이트 섹션이 `computeForeignRealizedGain`이 `null`(=당해 매도 거래 0건)이면 통째로 숨어 대부분의 사용자에게 안 보였다(근본 원인 버그).
2. 기능이 개별 종목 버튼과 캘린더 섹션 두 곳에 흩어져 하나의 도구로 인지되지 않았다.
3. 여러 종목을 동시에 비교하는 손익통산·재매수 절세 팁이 없었다.

아래 §2·§3은 개편 후(v2) 기준으로 다시 쓴 것이며, 1차 구현의 AC(단일 종목 `Sheet`, 인사이트 null 게이팅)는 폐기되었다.

## 1. 왜
S-4.23 세금 캘린더는 "언제 신고해야 하는지"만 알려주고 세액 계산은 하지 않는다. 사용자가 실제로 매도를 고민하는 순간 궁금한 "지금 팔면 세금이 얼마인가", "손실 종목과 같이 팔면 얼마나 줄어드는가", "이익 종목을 한도 내에서 팔고 재매수하면 절세가 되는가"에 답하는 **하나의 통합 시뮬레이션 화면**을 "세금 관리"(구 "세금 일정") 메뉴 안에 별도 탭으로 제공한다. 세무사 수준 정확도가 아니라 참고용 추정치임을 명확히 표기하는 조건으로 진행한다.

## 2. 무엇 (범위)
- 포함:
  - **메뉴 개편**: 더보기 > 지원의 메뉴명 "세금 일정" → **"세금 관리"**. 페이지(`#tax`) 최상단에 `InlineSelector`(size="lg")로 **"세금 일정관리"**(기존 12개월 캘린더)와 **"절세 시뮬레이션"**(신규) 두 화면 전환.
  - **연말 절세 시뮬레이션 탭**: 보유 해외주식을 체크박스로 선택 → 프리셋 칩("전량"/이익 종목이면 "한도까지")과 `±1` 스테퍼(버튼만, 텍스트 입력 없음)로 수량 조정 → 선택 종목 합산 손익·예상 세액·미선택 대비 절감액을 즉시 계산.
  - **당해 실현손익 baseline은 항상 표시**: 매도 거래가 하나도 없어도(=0원) 잔여 공제 한도·후보 목록을 항상 보여준다(보유 해외주식이 1건도 없을 때만 빈 상태).
  - **재매수 절세 팁**: 이익 종목 중 잔여 공제 한도 내에서 비과세로 팔 수 있는 수량(`rebuyQuantity`)을 안내 — "N주까지는 지금 팔아도 비과세, 매도 후 재매수하면 원가가 올라가 향후 세금이 줄어든다".
- **제외**:
  - **국내 상장·비상장주식·암호화폐**: 1차와 동일한 이유(대주주 판정 불가·세율 복잡도·과세 미시행)로 계산 대상에서 제외, 후보 목록에 노출하지 않는다.
  - **개별 종목 카드의 진입 버튼**: 1차에 있던 주식 상세 화면의 "예상 세금" 버튼은 완전히 제거 — 시뮬레이션은 "절세 시뮬레이션" 탭 하나로만 진입한다.
  - **수동 텍스트 입력**: 수량·가격을 직접 타이핑하는 폼은 두지 않는다. 항상 "전량 보유·현재가" 기준이며 조정은 버튼(프리셋·스테퍼)만 허용.
  - **여러 종목에 걸친 공제 한도 배분 최적화**: `rebuyQuantity`는 종목별로 독립 계산한다(한 종목에 한도를 다 쓴다고 가정) — 여러 이익 종목을 동시에 선택했을 때 한도를 자동으로 나눠 배분하지 않는다. UI에 이 전제를 명시.
  - 필요경비·배당소득세·종합소득세 합산신고 영향은 계산하지 않는다.
  - 실제 매도 실행(거래내역 등록)과의 연동, Plus 유료 게이팅, 세율 자동 갱신(국세청 API) — 1차와 동일하게 제외.
