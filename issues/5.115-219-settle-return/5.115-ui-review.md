한계: preview는 체험 모드로만 열려 설치 앱 상태(알림 팁·설치 안내 실카드·설정 알림 구역)는 재현하지 못했다. 해당 항목은 같은 클래스의 복제 DOM 실측 + 코드 판정이며 아래에 명시했다.

## 판정: UI 수정 요청 (R-1 차단, R-2 권고)

### R-1 (차단) 설정 알림 구역 스크롤이 실제로는 동작하지 않는다 — AC-6
- 파일: `src/app/(main)/_components/header-menu/settings-page.tsx`
- 원인: `if (!mounted) return null`(193행)이라 첫 커밋에서 DOM이 비어 있다. `focus` effect(68~75행)는 첫 커밋에서 `getElementById("settings-section-notify")`가 null인데도 `focusedRef.current = true`를 먼저 세팅하고 deps가 `[focus]`뿐이라 `mounted` 이후 다시 돌지 않는다. 결과: 팁을 눌러도 스크롤 0, 1회 소진만 된다(테스트로 안 잡힘).
- 기대: effect deps에 `mounted`를 추가하고 `if (focus !== "notify" || !mounted || focusedRef.current) return;`로 바꾼다. `focusedRef`는 요소를 찾아 `scrollIntoView`를 호출한 뒤에만 true. 구역이 없으면(unsupported·체험) 호출 없이 true 처리해도 무방.
- 재검증 방법(qa): 홈 팁 누름 → `settings-section-notify` 상단이 헤더 아래 뷰포트에 보임(390x844), 뒤로 후 재진입 시 재스크롤 0.

### R-2 (권고, planner 확인 필요) 배당 표 640~767 행 높이가 2.2~2.6배로 커진다 — C103·C109
- 실측(다크, 동일 데이터): 640·767에서 행 높이 운영 61/74/69px → preview 135/194/135px. 768·1024는 운영과 완전 동일(64/74/73, 열 5개), 768 경계에서 양끝 모두 정상 전환.
- 목표(C103)인 종목명 말줄임은 해결됨(640에서 삼성전자·SK하이닉스 `clip` true → false, 티커·주기 배지는 보조 줄 1개만 노출, 이중 노출 0). 그러나 휴대폰 열 폭(월 칩 열 3.25rem)이 614~741px 카드에 그대로 적용돼 이름 열이 400px 넘게 비고 월 칩이 세로로 4~5개 쌓인다(`dividend-640-dark.png`). 태블릿 폭에서 정보 밀도가 눈에 띄게 낮아져 "촌스럽다"로 읽힐 위험이 있다.
- 수정안(`monthly-dividend-stocks.tsx`): 열 정의·간격(`sm:grid-cols-[…11.5rem…]`, `sm:gap-x-2`, `sm:px-3`)은 원래 `sm:`로 되돌리고, 이름 줄만 `md` 전환점으로 유지한다. 즉 티커·배지는 640~767에서 이름 아래 보조 줄(`md:hidden`/`hidden md:inline` 쌍 유지)로 내려 이름 열 폭을 확보. 월 칩 재배치는 하지 않으므로 O1 범위 안이다. 행 높이는 운영 수준(60~75px)을 기대값으로 한다. 승인 조건: planner가 "휴대폰 배치 통일"을 이 혼합형으로 수용하거나, 현행 유지를 선택해 R-2를 면제.
