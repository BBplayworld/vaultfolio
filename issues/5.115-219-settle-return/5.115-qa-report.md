## 7. 재현 불가 항목(근거)
1. 실기기 iOS Safari·Chrome의 `navigator.storage.persist()` 실제 반환값·ITP 효과: 팀 환경에 실기기 없음. 모킹으로 호출 횟수·GA·분기만 검증. 판독은 허용/거부 기기 수로만(spec 한계와 같음)
2. 실제 설치 PWA(display-mode CSS)·OS 알림 권한 창: Chromium은 display-mode 미디어 에뮬 미지원. JS matchMedia 오버라이드(앱 로직 전체 standalone 판정)와 `.pwa-only-action` CSS 강제 표시로 대체했고, 실제 설치 앱 렌더·권한 창은 확인하지 못함
3. GA 실제 전송: preview는 gtag.js를 로드하지 않아 dataLayer·gtag 호출 payload로 검증(GA 콘솔 접근 없음)
4. 결산 창 날짜의 브라우저 재현: vitest(날짜 주입)로만 확인
5. 라이트 모드·잠금 상태 브라우저 재현은 일부(라이트는 390 1장, 잠금은 코드·정적 판정)
