## 0. 원칙 — 면 = 내가 적은 것, 글자 = 앱이 계산한 것
계산값(`지급`·`예상`)은 지금처럼 글자만, 사용자가 적은 배당은 **중립 회색 면**(`bg-secondary`)으로 그린다. 결론 줄 칩과 거래 행 배지가 같은 규칙이다. 색은 중립 토큰만 쓴다(주황·손익 빨강/파랑·에메랄드·amber·brand 0). 신규 토큰·신규 공용 컴포넌트 0.

## 1. 컴포넌트 트리
**① 입금 폼 `cash-tx-input.tsx`(수정)** — 금액과 날짜 사이, `txType === "deposit"`일 때만
```
div[role=group][aria-label="입금 종류"] .space-y-2        ← 신규 래퍼(폼 space-y-4 안에서 두 상자를 8px로 묶음)
 ├ 정기 상자(기존 클래스 유지)  Checkbox + label(제목 + 도움말)
 └ 배당 상자(신규, 같은 클래스 rounded-lg bg-muted/40 dark:bg-muted/20 p-3)
    ├ 줄: Checkbox + label(`배당으로 받은 돈` + 도움말)
    └ 종목 칸(항상 마운트, grid-rows 펼침) pl-6 pt-3 · `종목 (선택)` + Select(w-full)
```
- 재사용: `Checkbox`(자동 brand, §5), `Select`(같은 폼 계좌 칸과 같은 프리미티브), `groupStocksByTicker`. 상자를 따로 두되 8px로 묶는 이유: 서로 배타인 두 선택지임을 간격으로 보인다(§3.1).
- label은 제목+도움말 전체를 감싼다(`flex flex-col justify-center min-h-10`) — 두 상자 모두. 지금 정기 상자는 제목 글자(14px)만 눌려 §7 히트 40px에 못 미친다.

**② 거래 행 `cash-tx-view.tsx`(수정)** — 제목 줄 정기 배지 자리에 `Badge variant="secondary"` 1개, 날짜 줄 아래 종목 줄 1개(고른 경우만).
**③④ 결론 줄 `dividend-chart.tsx`(수정)** — 셋째 조각 자리 1개 + 월 선택 겹침 칸. `DOT_WRAP_ROW`·`DotLead`·제목 아래 `dividend-sub-slot`의 `grid [&>*]:[grid-area:1/1]` 재사용.

## 2. 사양
### ① 입금 폼
| 상태 | 정기 상자 | 배당 상자 |
|---|---|---|
| 둘 다 꺼짐(기본) | 현행 | 체크 해제, 종목 칸 접힘 |
| 정기 켜짐 | 현행 | 누를 수 있음. 켜면 정기가 해제되고 비활성 |
| 배당 켜짐 | **비활성·해제**: `Checkbox disabled`(기본 `opacity-50`), 제목 `text-muted-foreground`, 도움말 → `배당을 끄면 선택할 수 있어요` | 체크, 종목 칸 펼침 |
| 출금 | 둘 다 없음(현행 조건), 배당 값 false로 되돌림 | |
| 보유 주식 0 | — | 체크만, 종목 칸 없음 |
- **숨기지 않고 비활성으로 둔다(spec 4-2 '숨김'과 다름 → 5장 수정 요청).** 상자가 사라지면 아래 칸이 한 번 올라갔다 종목 칸만큼 다시 내려가고, 정기로 되돌아갈 길이 안 보인다. 비활성 사유는 도움말 한 줄로 읽힌다(색·투명도에만 기대지 않음).
- 종목 칸: 라벨 `종목 (선택)`(`메모 (선택)`과 같은 표기), 트리거 `w-full` 기본 크기(h-9) + 히트 40px(`relative after:absolute after:inset-x-0 after:-inset-y-0.5`), 기본값 `선택 안 함`(목록 첫 항목), 이어서 보유 종목을 티커 단위로 `groupStocksByTicker` 순서 그대로(정렬 신설 금지). 트리거 값은 한 줄 말줄임, 목록 항목은 전체 이름.
- 펼침: §6 높이 펼침 규약 그대로(항상 마운트, `grid-rows-[0fr]→[1fr]` + `inert`, `motion-safe:duration-200`, 재탭 시 현재 값에서 역전). 정기 비활성 전환은 색·투명도만 바뀌고 높이 불변. 유형을 바꿀 때의 재마운트는 현행 그대로.
- 배당 화면에서 열렸을 때(④): `입금` 선택 + 배당 체크 + 종목 칸 펼친 상태로 시작(펼침 애니메이션 없음). 현금 계좌가 1개면 그 계좌로 고정(현행 `cashId` 진입과 같은 모습), 2개 이상이면 계좌 칸 노출.
- 중복 확인 화면: 요약 줄 첫 조각을 `배당 입금`으로(저장될 내용 그대로, tech-review 4장). 세 조각을 `whitespace-nowrap`으로 묶고 가운뎃점은 뒤 조각 머리에 붙인다 — 시안에서 `2026-11-20 ·`처럼 점이 줄 끝에 남았다(C152).
- 제출 버튼 `입금 기록`·다이얼로그 제목 `입출금 기록`은 그대로.

### ② 거래 행
- 배지: `Badge variant="secondary"` + `text-2xs px-1.5 py-0 leading-tight font-semibold`(§2 상태 배지). 글자는 항상 `배당`. 정기(amber 선)·기록만(회색 선)과 **면/선**으로 구분된다. 순서 `입금` · `배당` · `기록만`.
- 종목명은 배지에 넣지 않고 날짜 아래 한 줄: `text-sm max-[359px]:text-xs text-muted-foreground truncate`(메모 줄 위). 배지에 넣으면 375 다크에서 제목 줄에 약 52px만 남는다(시안 폭으로 계산).
- 행 높이: 종목을 고른 행만 +20px(375, 메모 줄과 같은 방식). 나머지 행 불변.

### ③④ 결론 줄 — 셋째 자리 한 조각
순서는 **`지급 N · 예상 N · [셋째 자리]`**. 앞 두 조각은 현행 그대로(더해서 Hero가 되는 쌍, #317).
| 조건(위에서부터) | 셋째 자리 |
|---|---|
| 올해 받은 기록 합계 > 0 | 칩 `받은 기록 398,200원` |
| 0이고 현금 계좌 ≥ 1 | 칩 `받은 배당 적기` |
| 0이고 현금 계좌 0 | 현행 `다음 지급 M월 K종목`(spec 8장 '조각 없음' 상태 — 줄어드는 정보 0) |
- 칩 = `<button>`: `inline-flex items-center gap-1 h-[1lh] px-2 rounded-full bg-secondary text-muted-foreground whitespace-nowrap` + `PenLine size-3.5` + 라벨, 금액만 `font-semibold text-foreground tabular-nums`. 높이가 줄 높이와 같아 결론 줄 높이가 늘지 않는다(시안에서 고정 20px는 1280의 23px 줄과 어긋났다). 히트 `relative after:absolute after:inset-x-0 after:-inset-y-2.5`(40px). `hover:bg-accent`, `motion-safe:transition-[background-color,scale] duration-150 motion-safe:active:scale-[0.96]`, 포커스 링은 월 배지와 같다(`focus-visible:ring-[3px] focus-visible:ring-brand/40`).
- 누르면 입금 폼이 배당 켠 상태로 열린다. **기록이 생긴 뒤에도 같은 칩이 진입이다**(자리·모양 고정, 새 버튼·메뉴 0). 닫으면 포커스가 칩으로 돌아오고 금액은 저장 즉시 바뀐다.
- 월 선택: 결론 줄을 `grid [&>*]:[grid-area:1/1] items-start` 칸에 넣고, 연간 줄은 지금처럼 `opacity-0` + **`inert`**(안의 칩이 포커스를 받지 않게), 그 달 기록 > 0이면 같은 칩 `11월 받은 기록 N`을 겹쳐 그린다(`motion-safe:animate-in fade-in duration-150`, key 없이 유지 — 달을 바꿔도 다시 깜빡이지 않음). 기록 없는 달은 지금처럼 빈 자리. 높이는 연간 줄이 정한다.
- 계산 합계 0 · 기록만 있음: Hero 블록이 없으므로 카드 본문 맨 위에 칩 혼자 `올해 받은 기록 N`(기간을 알려 줄 Hero 라벨이 없어 `올해`를 붙인다). 이 상태에서 기록도 0이면 아무것도 넣지 않는다.
- 로딩·조회 실패: 칩은 저장값이라 그대로 보인다. `data-screenshot-hide` 대상 없음으로 본다(지금 두 파일에 이 속성을 쓰는 곳이 없다 — 캡처 경로 포함 여부는 tech 확인).

## 5. spec 수정 요청(planner-designer)
1. 4-2·완료 기준 1: 정기 체크 `숨김` → **비활성(자리 유지)**.
2. 4-5: 조각 순서 → **`지급 · 예상 · 받은 기록`**.
3. 4-4: 배지는 `배당` 고정, 종목명은 날짜 아래 줄.
4. 4-6: 기록이 생긴 뒤에도 같은 칩이 입금 폼을 연다. 현금 계좌 0이면 `다음 지급` 유지.

축소 시(challenge ⑤): 월 조각을 빼면 겹침 칸만 걷어 낸다(현행 `opacity-0` 그대로). 종목 칸을 빼면 배당 상자는 체크 한 줄, 거래 행 종목 줄 없음. 배지를 빼도 칩·폼은 그대로다.

## 6. 품질 체크리스트(qa·ui-review 판정)
1. 320·375·390·1280 × 라이트·다크에서 결론 줄의 각 조각이 조각 안에서 꺾이지 않고, 줄 머리·줄 끝에 `·`가 홀로 남지 않는다(C152).
2. 같은 데이터에서 결론 줄 높이가 main과 같고(조각 교체 전후 px 동일), 월 선택 전후로 차트 위쪽 y좌표가 변하지 않는다.
3. 셋째 자리는 언제나 1개다: 합계 칩·`받은 배당 적기`·`다음 지급` 중 둘이 동시에 보이지 않는다(3상태 각각 화면으로 1회, C120).
4. 칩·배지·폼 추가분의 computed color에 주황·rose·blue·emerald·amber·brand 계열이 없다(체크된 Checkbox의 brand만 예외).
5. 칩 히트영역이 `elementFromPoint` 기준 세로 40px 이상이고, 월 선택 중 숨은 연간 줄의 칩은 Tab·클릭으로 닿지 않는다.
6. 성과 › 배당에서 칩을 실제로 눌러 폼이 `입금`·배당 체크·종목 칸 펼친 상태로 열리고, 닫으면 포커스가 칩으로 돌아온다(C153). 저장 직후 칩 금액이 새로고침 없이 바뀐다.
7. 배당을 켜면 정기 체크가 해제·비활성되고 도움말이 바뀌며, 상자 위치·높이가 변하지 않는다. 배당을 끄면 정기를 다시 켤 수 있다. 저장 레코드 `recurring`은 false.
8. 종목 칸을 빠르게 켰다 껐다 해도(연타 5회) 중간에서 방향이 바뀌고 끝 상태가 체크 값과 같다. `prefers-reduced-motion`에서는 즉시 바뀐다.
9. 320에서 폼의 새 문구 전부(제목·도움말 2종·`종목 (선택)`·`선택 안 함`)가 어절 중간에서 꺾이지 않는다 — 글자 위치 측정 또는 캡처(C25·C114). InfoHint는 실제로 열어 320에서 캡처한다(C113).
10. 최장 종목명 픽스처에서 Select 트리거와 거래 행 종목 줄이 한 줄 말줄임이고 가로 스크롤이 없다. 목록 항목에서는 이름 전체가 보인다.
11. 중복 확인에서 `새로 추가`로 저장한 기록에 `배당` 배지가 붙고, 요약 줄이 `배당 입금`으로 시작한다.
12. 거래 행: `배당` 배지는 면, `정기`·`기록만`은 선으로 보이고(라이트·다크 캡처), 종목을 고르지 않은 배당 행의 높이는 일반 입금 행과 같다.
13. 12개 달의 `M월 받은 기록` 표시 문자열 합 = 연 합계 칩 문자열(C150, 같은 포맷터).
14. 화면에 새로 생긴 숫자·라벨을 전수로 적어 처음 보는 사람이 뜻을 아는지 한 줄씩 판정한다(C139). `지급`과 `받은 기록` 금액이 다른 픽스처로 캡처하고 차액·달성률 표기가 없음을 확인한다.
15. 새 메뉴·새 라우트·기록 목록 0(11-10 반려 형태), 컨트롤 줄 수는 폼 +1(배당 체크)·배당 화면 +0(C2).
16. 라이트·다크 캡처는 `theme_mode` 쿠키를 실제로 설정해 찍는다(C81). 767↔768·1279↔1280에서 칩 높이 = 줄 높이.
