## 6. 접근성 — 표 의미 유지
- 현재는 role이 없는 div 그리드다. 이번에 ARIA 표 역할을 부여한다: 머리글+행을 감싸는 래퍼 div 1개 추가 `role="table" aria-label="{국내주식 등} 배당 종목"`(그룹 제목 div는 표 밖), 머리글 행·데이터 행 `role="row"`, 머리글 5칸 `role="columnheader"`, 데이터 5칸 `role="cell"`.
- 열 수·DOM 순서는 전 폭 동일(종목명 → 배당월 → 주당 → 지급 → 합계). 359 이하의 시각 순서(이름 → 칩 → 주당 → 지급 → 합계)가 DOM 순서와 같아 읽기 순서가 어긋나지 않는다.
- `배당월` 머리글은 `sr-only`(display:none 금지 — 열 머리 이름 유지). 자리 채움 `&nbsp;`는 `aria-hidden`.
- 글자 11px 미만 0(신규 크기 없음), 색만으로 구분하는 신규 정보 0.

## 9. 범위 밖(기록만)
- 360~639의 최장값 지급·합계 겹침(375에서 −16.5px, main 기존 동작)은 이번 범위가 아니다. 같은 2단 구성의 경계를 넓히는 것이 해법 후보이나 360 이상 화면 변경이라 별도 판단.
- `N월 예정` 칩의 11px·자간 축소(`max-sm`)는 현행 유지. 2단에서는 칸이 넓어 풀 필요가 있는지 후속에서 검토.
- design-system 흡수: 신규 토큰 0. "좁은 폭 표는 열 재배분 대신 행 2단(식별 1단 전폭 + 숫자 2단 3열, DOM 한 벌·`max-[359px]:` 배치)" 한 줄을 구현 릴리스의 KB 일괄 갱신 때 §5.1에 등록.
