# 5.160 상세·주식 증권사별 합계 — spec (#319, risk:low)

근거: tech-review(같은 폴더), CEO 판정 `_discovery/2026-11-26-core-value/ceo.md` ②·③, business.md ④-2. 코드 기준 main `fb66d3c`.
**'마지막 맞춘 날'은 v1에서 뺀다.** 기존 필드로 증권사 단위 날짜를 정확히 낼 수 없다(tech-review 2장). 새 필드나 새 키를 쓰면 risk를 다시 판정한다.

## 1. 문제
증권사 2곳 이상과 ISA·연금 계좌를 함께 쓰는 사용자는 상세·주식에서 전체 합계와 종목별 금액만 본다. "키움에 얼마, 미래에셋에 얼마"를 보려면 종목 카드를 하나씩 펼쳐 증권사별 줄을 더해야 한다. 어느 증권사 숫자를 다시 맞출지 고를 근거도 화면에 없다.

## 2. 목표 행동
- 상세·주식에서 '증권사별'을 열어, 증권사마다 평가금·손익·종목 수·비중을 한 번에 확인한다.
- 그 행에서 바로 '맞추기'를 눌러, 해당 증권사가 미리 골라진 상태로 보유 현황 맞추기를 시작한다.
- 측정: 새 GA title 1개 `상세·주식·증권사별 열기`(`stock_broker_open`, 페이지 수명당 1회, 증권사명·금액 미전송). 맞추기 진입은 기존 `resync_start`로 본다.

## 3. 범위
- 포함: (1) 순수 함수 1개 `src/lib/asset/broker-totals.ts` (2) 접기형 블록 1개(상세·주식) (3) 행마다 '맞추기' 버튼, `HoldingsResyncDialog`에 `initialBroker?` prop 1개.
- 줄일 수 있는 것: 행 '맞추기' 버튼. qa FAIL이 2회 나면 이 버튼을 다음 릴리스로 분리하고, 블록은 읽기 전용으로만 낸다.
- 하지 않을 것
  - 마지막 맞춘 날
  - 증권사 탭이나 필터(행을 눌러도 목록은 거르지 않는다)
  - 열림 상태 저장(새 저장 키 0)
  - 인증카드 포함, 코인 탭, 데모 데이터 변경
  - 비중 조정 문구, 증권사 이름 정리·편집 기능

## 4. 블록 위치·표시
- 위치: 카테고리 selector(`stock-category-row`) 바로 아래, `StockCategorySection`(비중바·목록) 위. 요약 헤더·도구 타일·selector·목록은 바꾸지 않는다.
- 렌더 조건: 지금 탭의 묶음(미지정 포함)이 **2개 이상**일 때만 그린다. 1개면 헤더 합계와 같아서 DOM을 만들지 않는다. `screenshotMode`일 때도 그리지 않는다.
- 기본값: 접힘. 접힌 줄은 `증권사별 · N곳`과 펼침 아이콘만 둔다. 열림 상태는 컴포넌트 `useState`에만 두고, 탭을 바꿔도 유지하며, 화면을 다시 들어오면 접힘으로 돌아간다.
- 행(펼침)
  - 왼쪽: 증권사명, `N종목`
  - 오른쪽: 평가금, 손익(부호·빨강/파랑)과 수익률, 비중 %
  - 끝: `맞추기` 버튼(히트영역 40×40 이상)
  - 시각 규약은 ui.md(ui-designer)가 정한다.
- 정렬: 평가금 내림차순으로 두고, '증권사 미지정'은 항상 맨 아래에 둔다.
- 묶음 규칙
  - 행 단위 `filteredStocks`를 기준으로 묶는다(병합 `groupedStocks`에서 거꾸로 나누지 않는다).
  - 같은 증권사 판정은 `sameBroker`를 쓴다(공백 차이, 목록명 일치). 표시 이름은 목록 증권사와 맞으면 목록 이름을 쓰고, 아니면 사용자가 쓴 글자를 그대로 쓴다(예: 데모의 `연금저축`, `ISA`).
  - `isUnassignedBroker`가 참인 행(빈 값, `항목 N`)은 `증권사 미지정` 한 묶음으로 둔다. 비상장은 대개 여기로 들어간다.
- 같은 종목이 여러 증권사에 있으면 각 증권사에 1종목씩 센다. 그래서 행들의 종목 수 합은 전체 종목 수보다 클 수 있다. 종목 수는 합계로 표시하지 않는다.
- 상장폐지(`inactiveStatus="delisted"`)와 수량 0 행은 블록에서 뺀다(헤더 합계와 같은 정책). 이것만 가진 묶음은 행을 만들지 않는다.
- 통화: `computeStockTotals(rows, rates, displayCurrency)`를 묶음마다 그대로 호출한다.
  - '전체'·국내 등 탭: 원화로 표시한다. 해외 원가는 매입환율을 쓴다.
  - 해외 탭 달러 보기: `$` 표시, 환차손익을 뺀다. 헤더와 같은 정의다.
- 수익률: 원가가 0이면 `—`.

## 5. 합계 일치(C150, 화면 문자열 기준)
- 정본은 요약 헤더 `총 주식 평가금액`·`평가손익`이다. 블록에는 합계 줄을 두지 않는다.
- 금액은 `PRICE_DISPLAY_MODE="full-only"`라 원 단위 전체 표기다. 묶음 평가금·손익을 원(달러 보기는 센트) 단위로 반올림한 뒤, 표시 문자열의 합이 헤더 문자열과 **정확히 같게** 맞춘다. 반올림 차이는 최대 잔여 방식으로 흡수한다.
- 비중은 `largestRemainderTenths`(ratio-list.ts)를 재사용한다. 0.1% 단위로 표시하고 합은 100.0%다.

## 6. 맞추기 진입(initialBroker)
1. 행 `맞추기`를 누르면 기존 `trigger-add-stock` 이벤트에 `{ mode: "screenshot", broker }`를 보낸다. `StockInput`이 이를 받아 `HoldingsResyncDialog initialBroker`로 넘긴다. stock-tab에 대화상자를 새로 두지 않는다(이중 마운트 금지).
2. `증권사 미지정` 행은 broker 없이 연다(현행과 같다).
3. 대화상자 동작
   - `initialBroker`는 **증권사를 자동으로 확정하지 못한 장**(`r.broker === undefined`)의 선택 칸 기본값으로만 채운다. 기존 `brokerOverrides` 경로라서 사용자가 직접 고른 것과 같고, 바꿀 수 있다.
   - 자동으로 확정된 장은 그대로 둔다. 다른 증권사 화면을 올렸을 때 엉뚱한 증권사 종목이 삭제 후보가 되지 않게 하기 위해서다.
   - 안내 문구 1줄만 `{증권사} 보유 종목 화면을 골라 주세요`로 바꾼다.
4. 닫으면 `initialBroker`는 사라진다. 상태는 UI 안에만 있고 저장 변경은 0이다.

## 7. 사용자 흐름
1. 상세 › 주식 진입. 묶음이 2개 이상이면 selector 아래에 `증권사별 · N곳`이 접힌 채 보인다.
2. 탭하면 펼쳐진다. 첫 펼침에 GA 1회.
3. 카테고리를 바꾸면 블록이 그 탭 기준으로 다시 계산된다. 묶음이 1개로 줄면 블록이 사라진다.
4. 행 `맞추기`를 누르면 보유 현황 맞추기가 열린다. 확정되지 않은 장에는 그 증권사가 기본으로 골라져 있다.
5. 적용하거나 닫으면 상세·주식으로 돌아온다. 블록은 새 값으로 갱신되고, 열림 상태는 유지된다.

## 8. 엣지 케이스
- 빈 데이터·첫 사용자: 주식이 0건이면 블록 DOM이 0이다. 맞추기 분기(`useResync`)도 보유가 1건 이상일 때만이라 충돌하지 않는다.
- 증권사가 전부 비어 있으면 묶음이 1개라 블록이 없다.
- 일부 갱신: 시세가 일부 종목만 받아진 상태에서도 헤더와 같은 `currentPrice`를 쓴다. 따라서 값 불일치는 0이다.
- 오래된 데이터: 시세 시각은 5.155 '언제 시세' 줄이 정본이다. 블록은 시각을 표시하지 않는다.
- 긴 증권사명·자유 텍스트: 320 폭에서 2줄까지 줄바꿈하고, 금액은 줄바꿈하지 않는다(tabular-nums).
- 인증카드·금액 숨김: 블록은 `screenshotMode`에서 렌더하지 않는다. 그래서 SHOT DOM과 `decision-unset-baseline` 스냅샷이 바뀌지 않는다. 앱 화면에는 금액 숨김 모드가 없다(maskFn은 인증카드 전용). 따라서 마스킹은 해당하지 않는다.

3. 묶음이 1개이거나, 주식이 0건이거나, 인증카드(저장 PNG 포함)인 경우 블록 DOM이 0이다. 기존 스냅샷, `stock-entry-tools.test.tsx`, `price-asof-309.test.tsx`가 통과한다.
4. 처음 들어오면 접혀 있다. 펼친 뒤 다시 들어오면 접혀 있다. localStorage 키 증가는 0이다.

6. 행 `맞추기`를 누르면 기존 대화상자가 1개만 열린다. 확정되지 않은 장의 선택 칸이 그 증권사로 채워진다. 자동으로 확정된 장은 바뀌지 않는다. 미지정 행에서 열면 기존 화면과 같다. `resync.test.ts`를 확장한 테스트가 통과한다.

8. 저장 스키마·키·동기화·서버 전송 변경 0(C151 N/A). 코인 탭은 바뀌지 않는다.
