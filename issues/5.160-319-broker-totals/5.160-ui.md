## 1. 컴포넌트 트리(상세·주식, 위→아래)
```
StockSummaryHeader (불변)
StockToolTiles (불변)
stock-category-row (불변)
BrokerTotalsBlock  ← 신규 1개 (!screenshotMode만 렌더, SHOT DOM 0 변경)
  ├ 토글 행(버튼)  broker-totals-toggle
  └ 패널(항상 마운트, grid-rows 0fr↔1fr)  broker-totals-panel
       ├ 증권사 행 × N (broker-row)
       └ 미지정 행 (broker-row[data-unassigned])
StockCategorySection (불변)
```
- 위치 근거: §11 "컨트롤은 접힘 밖"이라 카테고리 줄은 그대로 두고, 그 **아래·목록 위**에 둔다. 카테고리 필터와 연동하지 않는다(항상 전체 주식 기준 → 헤더 총평가와 합이 같다. 라벨에 `전체 기준` 명시). 이유: 필터 연동은 헤더 합과 어긋나 보이는 오해를 만든다.
- 재사용: 외피 = `ASSET_THEME.subCard`(라이트 bg-card, 다크 bg-popover, rounded-lg)가 아니라 목록과 같은 면을 쓰기 위해 `ASSET_THEME.listBox`(다크 rounded-xl bg-card shadow-sm) + 라이트 `rounded-lg bg-card shadow-sm`(테두리 금지, 그림자 우선 §3.3). 행 내부는 `StockRowHeader`의 좌/우 2열 뼈대(`cardInfoLeft`/`cardInfoRight`, `cardAmountMain`, `cardAmountProfitRow`, 손익색 `getProfitLossColor` 계열 tone)를 그대로 쓴다. 신규 색·토큰 0, design-system 신규 항목 0(컴포넌트만 components.md 등록 대상).
- 비중 막대: **넣지 않는다**(증권사 소계 비중은 정보 과밀·막대 색 의미 충돌, 목록 비중바와 혼동). 대신 비중 `NN%` 텍스트 1개만 이름 옆 보조색.

## 2. 토글 행(접힘 트리거)
- 전체 폭 `<button>` `min-h-10`(히트 40px 자체 상자), `px-4 py-2.5`(listBox 안 좌우 16px = 목록 카드와 같은 시작선), `aria-expanded`·`aria-controls=panel id`.
- 좌: `증권사별` `text-sm font-semibold` + 보조색 `· 3곳`(미지정 포함 묶음 수). 우: `ChevronDown size-4 text-muted-foreground`, 열림 시 `rotate-180` `motion-safe:transition-[rotate] duration-200`(Tailwind 4 `rotate` 속성 → 전환 목록에 `rotate`).
- 기본 **접힘**, 열림 상태 `useState`만(저장·세션 모듈 변수 없음 → 탭 재진입 시 접힘). 접힌 상태에서도 한 줄 요약은 없다(숫자 노출은 펼침 때만, 홈 정보 과밀 방지).
- 누름 `active:scale-[0.99]`(카드류 §6), 포커스 링 기본.
- 패널: §6 "높이 펼침" 정본 그대로. 항상 마운트, 닫힘 `grid-rows-[0fr] opacity-0 invisible inert`, 안쪽 `min-h-0 overflow-hidden`, `motion-safe:duration-300 ease-out`. 연타 시 CSS가 현재 값에서 역전, reduced-motion 즉시. 조건부 렌더(`{open&&…}`) 금지. 열림 시 포커스 이동 없음(토글 유지)이므로 `visibility` 전환 사용 가능.

## 3. 행 구성 (375 기준)
2열 · 최대 3줄(좌 2줄 / 우 2줄), 행 높이 최소 56px, 행 사이 헤어라인 `divide-y divide-border dark:divide-border/30`.
```
키움증권 ·· 38%                    12,345,000원
5종목                           +1,234,000원 (+11.1%)
```
- 좌 1줄: 증권사명 `text-sm font-semibold` `break-keep line-clamp-2 [overflow-wrap:anywhere]`(`cardInfoName`) + 비중 `text-sm text-muted-foreground tabular-nums`(이름이 2줄이면 비중은 2줄째 끝 아닌 3줄째로 내리지 않고 `whitespace-nowrap` 후 줄바꿈 허용 → 이름만 clamp).
- 좌 2줄: `N종목` `text-sm text-muted-foreground`. 상장폐지·평가 제외 종목은 종목 수에서 뺀다(spec 정본 따름).
- 우 1줄: 평가금 `cardAmountMain`(text-sm bold tabular-nums). 우 2줄: 손익 금액+(수익률) `cardAmountProfitRow` + 손익색(빨강 +/파랑 −, 0은 muted, 기존 `profit-text` tone 함수 재사용). `whitespace-nowrap`, 우열 `max-w-[60%]`(360 미만 `max-[359px]:max-w-[45%]`, `stock-row-right`와 동일 규칙), 우열이 넘치면 `max-sm:flex-wrap justify-end`(기존 행과 같은 방식)로 손익 금액 / 수익률 2줄.
- 줄 수 기준: 390 = 좌 2줄·우 2줄. 320 = 좌 2줄(이름 clamp 2줄이면 3줄)·우 3줄(평가금 / 손익 / 수익률)까지 허용, 가로 스크롤 0. 1280(`sm:`) = 같은 구조, 컨테이너 `max-w`는 목록과 동일(별도 폭 지정 없음), `sm:` 폰트·패딩은 목록 카드 토큰 따름.
- 정렬 순서: 평가금 내림차순, **미지정은 항상 맨 아래**(평가금과 무관).
- 증권사 평가금이 0(전부 상장폐지·시세 없음)이면 우열 `—`(보조색), 손익 줄 생략. 통화: `displayCurrency`·환율 설정을 따른다(KRW 환산 합).

## 4. 미지정 묶음
- 이름 `증권사 미지정`(`text-muted-foreground`가 아닌 본문색 semibold — 정보 손실 아님을 강조하되 아이콘·경고색 없음). 2줄째 `N종목 · 비상장·직접 입력 포함`은 **쓰지 않는다**(긴 문구) → 2줄째는 `N종목`만. 설명은 토글 행 우측이 아닌 패널 맨 아래 1줄 보조 `text-sm text-muted-foreground`: `증권사를 적지 않은 종목이에요.`(미지정 묶음이 있을 때만). 이 줄은 CTA·경고 아님.
- 미지정만 존재(증권사 입력 0건)하면 블록 자체를 **렌더하지 않는다**(의미 없는 1행 합계 방지; 헤더와 동일 값). 증권사 1곳 + 미지정 0이면 렌더하지 않는다(소계 = 총합). 2묶음 이상일 때만 노출.

## 5. '맞추기' 진입 버튼
- 위치: 패널 하단 푸터 1개(행마다 버튼 금지 — v1은 프리셋이 없어 행마다 두면 같은 동작 N개 중복). 증권사 행 자체는 비인터랙티브(읽기 전용).
- 형태: `Button variant="secondary" size` 높이 `h-10`(히트 40px), 전체폭 아님 `w-full sm:w-auto`, 아이콘 없음 또는 `RefreshCw size-4`(광학 정렬 `mr-1.5`). **의미색 없음**(brand·destructive 금지; 확인·제출이 아니므로 brand 미적용, 규칙상 보조 = secondary 플랫).
- 문구: `보유 현황 맞추기`(기존 FAB·다이얼로그 제목과 같은 말. spec 정본 우선). 증권사 지정 맞추기로 오해되지 않게 `OO 맞추기` 문구 금지(프리셋 없음). 푸터 옆 보조문은 없음.
- 동작: 기존 맞추기를 그대로 연다. 새 `HoldingsResyncDialog` 이중 마운트 금지(tech-review §3). 열기 이벤트가 없으면 developer가 기존 `StockInput` 경로 재사용(구현 선택은 developer, 외형 변화 없음).
- 접힘 상태에서는 버튼도 `inert`(패널 안).

## 7. 금액 숨김 마스킹
- `maskFn`을 그대로 사용(`hideAmounts = maskFn(123456).includes("•")`). 평가금·손익 금액은 `•••`, **손익 부호(+/−)는 가림**(`!hideAmounts && tone.sign` 기존 규칙). 수익률(%)·비중(%)·종목 수는 기존 행과 동일하게 노출 정책을 따른다: 기존 `StockRowHeader`가 %를 숨기지 않으므로 동일. 단 증권사별 평가금 역산이 가능한 조합(비중% × 총평가)은 총평가가 숨김 상태면 불가라 허용.
- 마스킹 중에도 행 높이·줄 수 불변(`•••` 폭 ≤ 숫자 폭), 레이아웃 시프트 0.

## 8. 모션·접근성
- 토글: 위 §2. 행은 진입 stagger 없음(펼침이 곧 진입). `will-change` 금지, `transition: all` 금지.
- `role` 불필요(버튼+영역). 패널 `role="region" aria-label="증권사별 합계"`. 행은 `<div>`이며 스크린리더용으로 한 줄 문장 `aria-label` 없이 텍스트 순서만 보장(이름→종목 수→평가→손익).
- 다크: 외피 `dark:bg-card dark:shadow-sm`, 행 구분 `dark:divide-border/30`, 보조 글자 `text-muted-foreground`(4.5:1 유지), 손익 `dark:text-rose-400/blue-400`(기존 tone 함수가 처리). 토글 chevron `text-muted-foreground`.
- 구분선·그림자: 테두리 박스 금지, 라이트는 shadow-sm.

## 9. 문구(임시안, spec 정본 우선·투자 조언 금지)
- 토글: `증권사별` + `· N곳`
- 푸터 버튼: `보유 현황 맞추기`
- 미지정 안내: `증권사를 적지 않은 종목이에요.`
- 합계는 평가 사실만. `비중을 맞추세요`·`정리하세요` 류 금지. 맞춘 날·낡음 표시 없음(v1 제외).
- `data-screenshot-hide`: 블록 루트에 부여(이중 안전; 실제로는 `!screenshotMode`에서 미렌더).

## 11. 품질 체크리스트 (qa 판정용)
1. 375·390·1280 × 라이트·다크 8컷 모두 가로 스크롤·텍스트 겹침 0.
2. 블록은 카테고리 줄 아래·목록 위에 있고, 증권사 2묶음 이상일 때만 DOM에 존재(1곳·미지정만이면 `broker-totals` 없음).
3. 토글 행 `getBoundingClientRect().height ≥ 40`, 맞추기 버튼 높이 ≥ 40, `elementFromPoint`로 확인.
4. 기본 접힘, 토글 후 `aria-expanded=true`, 패널은 열림·닫힘 모두 DOM에 존재(재마운트 0), 닫힘 시 패널 내 버튼 포커스 불가(`inert`).
5. 펼침 연타 4회 후 최종 상태가 홀짝과 일치, 중간 깜빡임·점프 0.
6. `prefers-reduced-motion`에서 즉시 전환.
7. 증권사 행 평가금 합계(미지정 포함) = `StockSummaryHeader` 총평가(원화 환산), 손익 합 = 헤더 손익(상장폐지 제외 동일).
8. 정렬: 평가금 내림차순, `증권사 미지정`은 항상 마지막.
9. 평가·손익·수익률·비중 숫자 `tabular-nums`, 손익색 빨강(+)/파랑(−)/0은 muted, 다른 의미색(brand·주황·경고) 0.
10. 320px에서 긴 증권사명(예: 20자 이상)이 2줄 clamp, 우열 금액 줄바꿈이 최대 3줄, 이름·금액 겹침 0. 390px은 좌우 각 2줄.
11. 금액 숨김 on 시 평가금·손익 금액이 `•••`, 손익 부호 가림, 행 높이 변화 0.
12. 원/달러 토글 변경 시 합계 통화가 따라간다.
13. 인증카드(SHOT) 열기·캡처 시 `broker-totals` DOM 0, 기존 스냅샷 불변.
14. 맞추기 버튼은 `secondary` 플랫(brand·의미색 아님), 탭하면 기존 보유 현황 맞추기 흐름이 열리고 `HoldingsResyncDialog` 마운트는 1개.
15. 카테고리 필터(국내·해외 등) 변경해도 블록 값 불변(전체 기준).
16. 블록 내 문구에 투자 권유·비중 조정 표현·구체 금액 문구 0, 존댓말(해요체) 일치.
17. CHECKLIST.md UI 항목(히트 40px·동심 radius·그림자 우선·다크 대비·긴 문구) 해당 전부 확인.
