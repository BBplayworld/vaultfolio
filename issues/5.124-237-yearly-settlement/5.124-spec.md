# 5.124 #237 올해 결산 — spec

기준: origin/main 5d2e301. 방향·3묶음 매핑·결론 문장 규칙·지표 대조표는 [`5.124-direction.md`](./5.124-direction.md) 경험 절이 정본이다. cto 판정(선정 문서 9절) 반영.

**문제**: 한 해를 기록한 사용자가 "올해 얼마 늘었고 그중 넣은 돈과 불어난 돈이 얼마인지" 보려면 6행을 직접 더해야 하고, 실사용자는 1~10월분이 통째로 '기록 안 된 변화(예측)'에 섞여 답이 흐려진다.
**목표 행동**: 연 탭에서 3줄로 읽는다. 나눌 수 없는 기간은 기간 이름이 붙은 별도 1행으로 구분해 본다.

**사용자 흐름**
1. 성과 › 자산 변화 › 전체 › 연 → Hero 아래 `올해 결산` 블록.
2. 결론 1줄(규칙 충족 시) → 넣은 돈 / 불어난 돈 / 빠져나간 돈 → 기록 안 된 변화 → `1~N월 · 원인을 나눌 기록이 없던 기간`(N=1이면 `1월`, 도움말 `M/D 기록까지`).
3. 불어난 돈에 0원 아닌 하위 행이 2개 이상이면 누를 수 있고, 누르면 시세 변동·평가 갱신·환율 효과가 펼쳐진다. 1개면 화살표 없이 도움말만 있다.
4. 기록 안 된 변화가 큰 경우(현행 `showUnrecordedHint` 조건, 나눌 수 있는 구간 기준)이고 현금 계좌가 1개 이상이면 링크 1개 → 상세 › 현금. 문구는 계좌를 고르는 화면임이 드러나게 ui.md에서 확정한다(C33). 현금 계좌 0개면 링크 없음.

**완료 기준**
- AC-1 연 탭 Hero 아래 첫 블록 제목이 `올해 결산`이고, 묶음 이름이 `넣은 돈`·`불어난 돈`·`빠져나간 돈`이다. 평면 6행 목록은 연 탭에 없다.
- AC-2 묶음 금액 = direction 매핑 표의 하위 행 합(원 단위). 불어난 돈 펼침 안 행 합 = 묶음 금액. 펼침 화살표는 0원 아닌 하위 행이 2개 이상일 때만 있다.
- AC-3 보이는 행(묶음 + 기록 안 된 변화 + 기간 행)의 합 = Hero 증감(원 단위). 1월 초는 머리 줄 증감과 같다(2026년 끝값 출처는 tech-review가 년도별 2026 항목·12월 기록 중 하나로 정한 값).
- AC-4 픽스처에서 기록 안 된 변화 행이 예측 구간 몫(12,000,000)을 포함하지 않고, 기간 행이 `1~10월`과 함께 따로 보인다. 첫 enrich 기록이 1월이면 라벨은 `1월`이다(`1~1월` 없음). 도움말에 그 기록의 실제 날짜가 있다.
- AC-5 결론 줄은 규칙 1~3대로만 나오고 기간 표현이 들어 있다. 반올림한 비율이 0 또는 100이면 금액 문장이다. 규칙 3 상태·전부 예측 상태에서는 결론 줄 DOM이 없다. 빠져나간 돈은 문장에 없다.
- AC-6 블록 전체 문자열에 평가어·권유·전망 낱말이 없다(금지 목록 grep 테스트).
- AC-7 상태별 배치 표 10행이 각각 표대로 그려진다(행마다 캡처 1장 이상, 일요일 포함).
- AC-8 첫 해: Hero 제목과 블록 제목의 시작일이 같고, 합계 항등식(AC-3)이 성립한다.
- AC-9 2027-01-01~01-10: 블록은 2026년 값이고 제목 `2026년 결산`, 머리 줄 `2025년 말 → 2026년 말 ±N`이다. Hero가 문구 상태여도 블록이 뜬다. 12/31 화면과 행 구성이 같고 금액은 12월 기록 확정분만큼만 다르다. 01-11부터 현행 동작.
- AC-10 12/28~1/10을 포함해 언제나 월 결산 화면에 새 진입 0개(main 대비 링크·버튼 수 동일). 선택기 `연` 칸의 표시는 ui.md가 정하면 그대로, 없으면 diff 0.
- AC-11 `올해 입출금을 기록하면 더 정확해져요` 문구가 연 탭에 없다. 같은 조건에서 현금 계좌가 1개 이상이면 링크가 상세 › 현금에 도착하고, 0개면 링크 DOM이 없다. 월 탭 문구는 무변경.
- AC-12 월·주·일 탭 원인 블록, 성적표, 시장과 비교, 결산 알림·홈 결산 팁 도착지 렌더 diff 0. `mapSettlementCauses`·`asset-report.ts` diff 0.
- AC-13 저장 키·스키마·동기화·서버 전송 diff 0, 사용자 기록 생성 0.
- AC-14 GA: 블록이 값과 함께 그려지면(묶음 또는 기간 행 1개 이상) 진입당 1회 `feature_use` 신규 category 1개 → page_title `성과·자산 변화·올해 결산`(`ga.ts` 810행 category 목록 + title 매핑 1줄). 금액·비율·상태 값 미전송. 진입 줄 누름은 새 title 없음. 체험 중은 `track` no-op(326행). **vitest로 신규 category의 page_title 문자열이 정확히 `성과·자산 변화·올해 결산`임을 고정한다** — category 허용 목록(810행)이나 `CATEGORY_TITLES`(178행~) 중 하나라도 빠지면 폴백으로 `성과·자산 변화`에 섞이기 때문이다.
- AC-15 새 소식 1줄(`src/config/whats-new.ts`, id를 PR 본문에 기재 — C121). 금액·평가어 없음.
