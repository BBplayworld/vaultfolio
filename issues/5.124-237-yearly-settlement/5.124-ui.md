## 2. Hero와의 위계 (#232 교훈)
- 글자 단계: Hero 증감 `text-2xl` > 1월 초 머리 줄 `text-xl` > 묶음 금액 `text-base` > 하위·기록 안 된 변화·기간 행 `text-sm`. 한 화면에 같은 크기의 합계가 둘이 되지 않는다.
- 블록 안에서 Hero 증감·%·시작→끝 금액을 다시 쓰지 않는다. 1월 초 머리 줄만 예외(Hero는 2027년 기준, 머리 줄은 2026년 — 기준 문구를 금액 위에 함께 둔다).
- **판정 요청 ① (spec 3행·tech ②·AC-14)**: 전부 예측 상태의 `올해 전체 1행(금액 = Hero 증감)`은 Hero 숫자가 24px 아래에 한 번 더 나온다. ui 결정 = **행을 그리지 않고 안내 1줄만**(GA도 이 상태는 미전송 — AC-14 '묶음 또는 기간 행 1개 이상'과 그대로 맞음). planner가 spec 표 3행을 맞춘다.
- **판정 요청 ② (AC-5 규칙 2·10절 b)**: 금액 문장(`넣은 돈은 +A, 불어난 돈은 −B`)은 바로 아래 묶음 행과 같은 금액을 반복한다. ui 권고 = 금액 문장 대신 기간 캡션(4절 `period-note`)만. 판정 전까지 기본 구현은 spec대로(금액 문장, 목업 `mock-long9-*`·`mock-one-side-skip-*`).
- 선택기 `연` 칸 표시(cto ⑤ 재량): **두지 않는다**(월 결산 화면 diff 0, AC-10).

## 4. 상호작용·모션·접근성·testId
- 펼침: 항상 마운트, `grid-rows-[0fr]↔[1fr]` + `inert` 200ms ease-out `motion-safe`, 화살표 `rotate-180` 200ms, hover 배경 150ms. 기본 접힘. 연타·중간 방향 전환은 CSS가 현재 값에서 되돌린다. **열림 상태는 블록 컴포넌트 state** — 시세 갱신(`summary`·`snapshotVersion` 변경)으로 다시 그려져도 닫히지 않아야 한다(블록 `key`에 금액·시각을 넣지 않는다, 현행 `key="year"` 유지). 기간 탭을 바꿨다 돌아오면 접힘(허용).
