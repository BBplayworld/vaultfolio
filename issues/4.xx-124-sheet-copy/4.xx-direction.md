## 사업

### 1. 왜 지금
- **기여: 첫 발견(주), 리텐션(보조).**
  - 첫 발견: 진짜 경쟁자는 엑셀·노션 습관이다(PRINCIPLES 1장). 몇 년 치 시트를 가진 사람에게 "옮기면 시트가 끊긴다"는 이유가 남아 있다. 앱이 시트를 대체하지 않아도 **시트에 넣을 숫자를 대신 모아 주는 곳**이 되면 써 볼 이유가 생긴다. 채널 문구도 처음으로 "엑셀 그만 쓰라"가 아니라 "엑셀에 붙일 표를 1분 만에"로 쓸 수 있다. 병목인 월 신규 약 17명의 메시지 쪽 해법이다.
  - 리텐션: 시트에 옮기는 시점이 월말이다. 월 결산과 같은 날 앱을 열 이유가 하나 더 생긴다. 리마인더·알림은 없다(LEARNINGS 경과일 알림 교훈과 무관).
- **시즌**: 12월 말~1월 초는 엑셀 사용자가 '올해 말 순자산' 줄을 채우는 시기다. 12월 결산 창(11/27~12/10)이 첫 사용 기회다. 그래서 **11/26 전 머지**를 목표로 한다(대표 승인 포함).

### 2. 누구를 위해
- 엑셀·구글시트에 월말 순자산 표를 몇 년째 쌓아 온 3040 주식 투자자. 이 중 **앱을 쓰기 시작했지만 시트를 놓지 못하는 병행층**이다.
- 시트를 못 놓는 이유: 과거 이력이 시트에 있다, 앱에 없는 칸(연금·보험·가계부)을 같이 본다, 배우자와 시트를 공유한다.
- 지금 이 사람은 앱 숫자를 시트로 손으로 옮긴다. 종목 10개면 10줄을 다시 친다. 여기서 귀찮아지면 둘 중 하나를 버리고, 대개 새로 시작한 앱을 버린다.

### 3. 성공의 모습 (익명 기기, GA '페이지 및 화면' CSV로 판독)
- 계측: 기존 `feature_use` + `CATEGORY_TITLES`에 값 1개 추가(예: `sheet_copy: "표로 복사"`), 화면 키 1개(`SCREEN_TITLES` "표로 복사"). 신규 맞춤 정의 0(11-06 GA 단순화 결정 준수, linked_trade 선례).
- **주 지표**: '표로 복사' 28일 활성 사용자 수. 12월 창(11/27~12/10) + 연말(12/24~1/10)에 **대표 기기 제외 3명 이상**이면 성공. 0~1명이면 실패로 보고 정리(제거) 후보로 올린다.
- **보조**: '표로 복사' 조회수/사용자 1.5 이상(다시 쓰는가). 채널 게시일을 병기하고 '웰컴'·'자산 저장·*' 사용자 수 변화는 참고로만 본다(표본 작아 인과 판정 안 함).
- 판독 경계 = 머지 시각. 같은 날 다른 머지와 묶이면 판독 메모에 적는다.

### 4. 하지 않으면 무엇을 잃나
- **근거 강도: 중간~약함.** 직접 요청 데이터(의견 보내기)는 확인하지 못했다. 엑셀 병행층의 규모도 로컬 데이터라 GA로 볼 수 없다.
- 잃는 것: 엑셀 사용자를 향한 채널 문구가 계속 "갈아타라"뿐이다. 병행층은 손으로 옮기다 앱을 놓는다. 대표가 요청한 '새 확장'이 이번 주기에 0건이 된다.
- 반대로, 해도 잃는 것이 적다. 읽기 전용이라 데이터 위험이 없고, 실패하면 화면 1개를 지우면 된다.

## 범위 제안 (planner-designer가 경험 절에서 확정)
- v1 표 2개: ① 보유 현황(자산군·이름·수량·평가금액(원)·비중 %) ② 월말 순자산(월·순자산·전월 대비·**기록일**, 월 스냅샷 13개월 + 그 이전은 연도별 순자산). 기록일은 `MonthlyAssetSnapshot.date`, 없으면 빈칸(월말로 꾸미지 않는다).
- 복사 형식: 엑셀·시트·노션에서 표로 붙도록. 숫자 열은 단위 없는 숫자. 전달 방식은 브라우저별로 설계 단계에서 정한다(LEARNINGS .ics 교훈, C19). iOS 웨일·인앱 브라우저에서 복사가 막히면 선택 가능한 표 텍스트로 대체.
- 파일 다운로드(CSV·xlsx)는 v1에서 하지 않는다(iOS blob 다운로드 실패 이력, #45 반려 영역 회피).
- 화면 문구: 평가어·권유어 0, "기기 안에서 만든 표예요" 수준의 사실만. 보안 문구는 security-copy 재사용, 새 단정 금지.

## 반려 이력 대조
- 엑셀·CSV **가져오기** 반려(10-31) → 이건 반대 방향(내보내기)이고 파일이 아니다. 다만 이후 발굴 문서에 'CSV'가 포괄 표기된 적이 있어 cto challenge에서 판정한다(아래 판단 포인트).
- 세금 3건(신고 요약) 보류 → 세금 목적 요약 문서가 아니다. 세액·공제 숫자를 넣지 않는다.
- 자산 공유·스트릭 카드 반려 → 외부 공유 전제가 아니다. 본인 시트로 옮기는 용도다.
- 연간 회고 반려 → 회고 화면이 아니다. 새 계산 없이 기존 값을 표로만 낸다.
- 경과일 알림·결산 홈 팁 → 알림·팁 변경 0.

## 경험 (planner-designer, 2026-11-09 · origin/main eb204e4 기준)

코드 근거 재확인: 더보기 › 도구 절은 지금 '세금 관리' 1행뿐(`header-menu/tool-menu.tsx` 252~261). 클립보드는 공유 URL·동기화 링크·AI 프롬프트(`prompt-preview-dialog.tsx` copyPrompt)·설치 코드만, **표 복사 없음**. 월 스냅샷은 **최근 13개월 롤링**, `date` = 그달 마지막 기록일(`asset-data-context.tsx` 797~812). 값 계산 정본은 `computeNetAsset`(같은 파일 223, 외화 = 현재 환율 × 수량, JPY는 100엔당). **앱 전역 '금액 숨김' 모드는 없다**(숨김은 인증카드 공유 다이얼로그의 로컬 토글 `share-menu.tsx` 74뿐). iOS 클립보드는 `use-external-move.ts` copyUrlForIOS 패턴(ClipboardItem → writeText 폴백)이 이미 있다.

### 1. 사용자가 하게 될 행동 (관찰 가능)
- 월말에 더보기 › 도구 › '표로 복사'를 열어 **표 1개를 한 번 눌러 복사**하고, 자기 시트에 붙여넣는다(앱 안에서 관찰: 복사 성공 1회 = GA '표로 복사').
- 다음 달 같은 시기에 다시 와서 복사한다(보조 지표 조회수/사용자).

### 2. 범위
- **포함**: ① 보유 현황표 ② 순자산 기록표, 표마다 '복사' 버튼 1개. 복사 실패 시 선택 가능한 표 텍스트로 대체.
- **줄인 것(사업 제안 대비)**: 새 화면(라우트·해시·스와이프 순서) 대신 **더보기 안 다이얼로그 1개**(자산 공유 · 동기화 선택 다이얼로그와 같은 패턴). 화면 키(`SCREEN_TITLES`)·navigation 타입 변경 0 → 계측은 `feature_use` 2값만. 화면 안에 표 전체를 다시 그리지 않고 **미리보기 3행 + "외 N행"**만(항목 중복 표시 최소화).
- **하지 않을 것**: 파일 다운로드(CSV·xlsx), 표 3개 이상·열 고르기·정렬 옵션, 거래내역·배당 표, '금액 빼고 복사' 토글, 합계 행, 붙여넣기 서식(색·굵기), 가져오기(역방향), 외부 공유 버튼, 리마인더·홈 팁.

### 3. 표 형식 (엑셀·구글시트·노션 공통)
- 클립보드에 **text/html `<table>` + text/plain TSV를 함께** 쓴다(시트·노션은 HTML 표, 메모장·구형 앱은 TSV). ClipboardItem이 없으면 TSV `writeText`만.
- 1행 = 머리글, 그 아래 데이터. 표 위·아래 설명 줄 없음(붙인 뒤 SUM이 바로 되게).
- 숫자: **콤마·단위·% 기호 없는 숫자**(원 단위 반올림 정수, 음수는 `-`). 비중은 소수 1자리 숫자, 열 이름에 단위 `평가금액(원)`·`비중(%)`. 수량은 저장값 그대로(뒤 0 제거, 최대 8자리).
- 날짜 `YYYY-MM-DD`, 월 `YYYY-MM`(시트가 날짜로 바꿔 보일 수 있음 — 값은 같음, 알려진 한계).
- **표 ① 보유 현황**: `자산군 | 이름 | 기관 | 수량 | 평가금액(원) | 비중(%)`. 1 저장 항목 = 1행(같은 종목 다른 증권사는 '기관'으로 구분). 주식·코인·현금·부동산·실물 = 양수, **대출·임차보증금 = 음수 행**(비중 빈칸) → 평가금액 열 합계 = 앱 순자산. 상장폐지 종목 제외(computeNetAsset과 동일). 외화 자산은 **현재 환율로 원화 환산**, 다이얼로그 캡션에 "1달러 X원·100엔 Y원 기준" 표시(복사 내용엔 넣지 않음). 비중 분모 = 홈 도넛과 같은 값.
- **표 ② 순자산 기록**: `기간 | 순자산(원) | 직전 대비(원) | 기록일`. 오래된 순→최근 순(시트에 아래로 쌓는 습관). 월 스냅샷(최대 13개월) 행은 `2026-10`, 기록일 = `date`(없으면 빈칸, 월말로 꾸미지 않음). 첫 월 스냅샷 연도보다 이전 연도는 연도별 순자산 행 `2024년 말`(기록일 빈칸). 직전 대비는 바로 앞 달(연도 행은 앞 연도) 값이 있을 때만, 없으면 빈칸. 이번 달 행도 넣는다(기록일이 진행 중임을 말해 줌).

### 4. 흐름
더보기 › 도구 › '표로 복사' → 다이얼로그(카드 2개: 제목·행 수·미리보기 3행·[복사]) → 복사 → 토스트 "표를 복사했어요. 시트에 붙여넣으세요" + 버튼 '복사됨' 2초 → 닫기.
- 실패(권한 거부·인앱 브라우저·write 예외): 토스트 오류 + 그 카드 아래에 **읽기 전용 텍스트 영역(TSV)** 펼침, 안내 "길게 눌러 전체 선택한 뒤 복사해 주세요". iOS·안드로이드·PC 모두 같은 대체. 권한 팝업을 띄우는 API(read)는 쓰지 않는다. 표 문자열은 **누르기 전에 미리 만들어 두고** 탭 핸들러에서 await 없이 바로 write(iOS 제스처 만료 방지, C19·LEARNINGS .ics).
- 문구: 사실만. 캡션 "복사한 표에는 금액이 그대로 들어 있어요." 새 보안 단정 문구 없음(security-copy 변경 0).

### 5. 빈·예외 데이터
- 자산 0건: 행 비활성(백업 행과 같은 `!hasAssets` 규칙).
- 표 ② 기록 0행(첫 사용자 첫날 전): 카드에 "아직 기록이 없어요. 자산을 저장한 날부터 달마다 쌓여요." 복사 버튼 비활성.
