# 4.xx #124 표로 복사 — ui (ui-designer)

기준: origin/main dc4133d. 신규 색·토큰·컴포넌트·모션 0 (`MENU_*`, `PromptPreviewDialog`, `MAIN_PALETTE[0]` 재사용). 코드 수정 없음.

## 1. 더보기 › 도구 행 (`tool-menu.tsx` more-section-tools)
- 순서: 세금 관리 → 인증카드(#125) → **표로 복사**. 행은 `MENU_ROW` + `MENU_ICON` + `MENU_LABEL`, 목록 `gap-2`.
- 아이콘: **`Table2`**(lucide 기존 패키지, import만 추가. 현 파일 미사용이라 신규 아이콘 import 1개). `Copy`는 이미 다이얼로그 버튼에 쓰여 의미 중복이라 제외. 우측 chevron 없음(다이얼로그형, 인증카드·공유 행 규칙 동일).
- 문구: "표로 복사" 한 줄, 설명 줄 없음.
- 자산 0건: `disabled={!hasAssets}`(`MENU_ROW`의 `disabled:opacity-50 cursor-not-allowed` 그대로, 별도 안내문 없음). 공유·백업 행들과 동일 규칙. 참고: #125 인증카드는 0건 시 "숨김"이라 같은 절에서 숨김/비활성이 섞임 — 수용(인증카드는 기존 하단 아이콘 이동 규칙, 표로 복사는 spec 비활성). 통일 원하면 cto 판단, 본 사양은 spec대로 비활성.
- testId `more-row-sheet-copy`.

## 2. 다이얼로그 (`PromptPreviewDialog` 재사용, 변경 = 버튼 라벨 prop 1개)
- 탭: **1개(선택기 숨김)**. `tabs=[{id:"sheet",label:"표",getPrompt}]`.
- 제목 "표로 복사"(기존 `DialogTitle`, 아이콘 없음). 설명 1줄 "엑셀·구글 시트에 붙여 넣을 수 있어요. 복사가 안 되면 아래 내용을 길게 눌러 전체 선택해 복사해 주세요." (`DialogDescription` 기본 스타일, 320에서 3줄 내 줄바꿈 허용 — 단어 끊김 방지 `break-keep` 기존 적용 여부 확인 불가 시 developer가 설명 노드에만 `text-pretty break-keep`).
- 버튼: prop 신규 `copyLabel?: string`(기본 "프롬프트 복사"), 전달값 **"표 복사"**. 복사 후 2초 "복사됨"(기존). 닫기 secondary(기존). 버튼 `MAIN_PALETTE[0]` 기존 그대로.
- 텍스트 상자: 기존 `min-h-[380px] font-mono text-sm resize-none` **그대로**(변경 0). 고정폭 유지(열 정렬이 탭 구분 확인에 유리). 
- 가로 스크롤: **허용**. 표는 한 줄이 길어지므로 `Textarea`는 줄바꿈 없이(`wrap="off"`/`whitespace-pre`, `overflow-x-auto`)가 이상적이나, 기존 코드 변경 최소 원칙으로 **기본 줄바꿈 상태 유지도 허용** — 단 어느 쪽이든 다이얼로그 자체(폭 100vw−2rem)에 페이지 가로 넘침이 없어야 한다. 줄바꿈 모드에서 긴 행이 접혀 보여도 복사 값은 TSV 원문이라 무관. 결정: 기존 동작 유지(수정 0).
- 상태: 자산 있음만 열림(0건 비활성). 로딩 없음(동기 생성). 긴 이름은 접힘/스크롤. 오류는 §3.

## 3. 복사 결과
- 성공: `copySuccessMessage="표를 복사했어요."`(토스트 기존 `toast.success`), 버튼 2초 '복사됨'.
- 실패: 기존 `toast.error("복사에 실패했습니다.")` 재사용 + 설명 문구가 이미 대체 경로(상자 길게 눌러 전체 선택)를 안내. 추가 UI 0. Textarea가 `readOnly`라 선택·복사 가능 유지.

## 4. 접근성·모션
- 행 히트영역 ≥ 48px(`py-3.5`+아이콘), 키보드 Tab/Enter, 다이얼로그 Radix 포커스 트랩·Esc 기존. 신규 모션 0. 다크 대비는 기존 토큰이라 불변. 행 `aria-label` 불필요(가시 텍스트).
- `data-screenshot-hide` 대상 없음(스크린샷 캡처 대상 화면 아님).

## 5. 문구 최종
행 "표로 복사" · 제목 "표로 복사" · 버튼 "표 복사" · 토스트 "표를 복사했어요." · 설명 위 1줄. '노션'·'CSV'·'파일'·보안 주장·금액·조언 0. 320px 줄바꿈: 행·버튼 한 줄, 설명만 다줄.

## 6. testId
`more-row-sheet-copy`(행), 다이얼로그는 `role="dialog"` + 제목 "표로 복사" 텍스트로 조회, 복사 버튼은 버튼명 "표 복사".

## 7. 품질 체크리스트 (qa, 320·375·1280 × 라이트·다크)
1. 도구 절 행 순서 세금 관리 → 인증카드 → 표로 복사, 아이콘 Table2·size-5.
2. 행 높이 ≥ 44px, 라벨 1줄(320), 좌측 아이콘 정렬이 세금 관리 행과 x 동일 ±1px.
3. 자산 0건: 행 disabled·opacity 50, 탭해도 다이얼로그 안 열림.
4. 다이얼로그: 탭 선택기 없음, 제목·설명·텍스트 상자·버튼 2개, 상자 높이 ≥ 380px, 고정폭.
5. 버튼 라벨 "표 복사"(brand 색), 성적표·결산·X-Ray는 "프롬프트 복사" 그대로(회귀).
6. 복사 성공: 토스트 "표를 복사했어요.", 버튼 2초간 "복사됨" 후 복귀.
7. 클립보드 값이 TSV 원문(`기준일\t…` 1행, 마지막 `순자산` 행)이고 상자 표시와 동일.
8. 복사 거부(권한 거부 모킹): "복사에 실패했습니다." 토스트, 상자 텍스트 선택 가능.
9. 320px: 다이얼로그·페이지 `scrollWidth ≤ clientWidth`(상자 내부 가로 스크롤은 허용), 닫기·복사 버튼 가려짐 없음, 설명 문구 잘림 없음.
10. 다이얼로그 `max-h-[90vh]`, 작은 높이 화면에서 버튼이 화면 밖으로 밀리지 않음.
11. Esc/닫기로 닫힘, 포커스가 행으로 복귀.
12. 신규 색·hex·컴포넌트 0(diff: Table2 import, copyLabel prop, 행 1개, 헬퍼).
13. '노션'·'CSV'·'파일'·조언 문구 없음. 다크·라이트 대비 판독 가능.
