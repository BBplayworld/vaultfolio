# 4.xx 표로 복사 — spec

작성: planner-designer 2026-11-09 · 기준 origin/main · 방향 `4.xx-direction.md`(합의함) · 축소 근거 `4.xx-challenge.md`(cto)
위험: low 제안(읽기 전용). **신규 기능 → 머지는 대표 승인**(위임·COO 자체 승인 금지). 네비 개편과 같은 릴리스로 묶지 않는다.

## 1. 문제
엑셀·구글 시트에 자산을 정리해 온 병행 사용자는 앱 숫자를 손으로 다시 친다. 앱에는 표 복사가 없다. 옮기기가 귀찮으면 새로 시작한 앱을 버린다.

## 2. 목표 행동
월말에 더보기에서 [표 복사]를 1번 누르고 자기 시트에 붙여넣는다. 다음 달에도 온다.

## 3. 범위
- 포함: 더보기 › 도구 절 '표로 복사' 행 1개(순서 `세금 관리 → 표로 복사 → 인증카드`), 기존 `PromptPreviewDialog`로 표 1개 표시·복사.
- 하지 않을 것: 새 화면·라우트·`SCREEN_TITLES` 키·새 컴포넌트, 월말 순자산 표, 비중·전월 대비·손익·수익률·세액 열, HTML 표 형식, '노션'·'CSV'·'파일' 표기, "기기 안에서 만든 표예요" 등 새 보안 주장, 파일 다운로드, 가져오기(후속으로도 금지), 외부 공유 호출, 홈 팁·알림, 금액 숨김 옵션(앱에 전역 숨김 모드 없음).

## 4. 사용자 흐름
1. 더보기 › 도구 › '표로 복사'(자산 0건이면 비활성, 기존 `hasAssets` 패턴).
2. 다이얼로그: 제목 "표로 복사", 설명 "엑셀·구글 시트에 붙여 넣을 수 있어요. 복사가 안 되면 아래 내용을 길게 눌러 전체 선택해 복사해 주세요.", 탭 1개(선택기 숨김), 읽기 전용 Textarea에 표 텍스트.
3. [표 복사] → `navigator.clipboard.writeText`(문자열은 열 때 미리 생성, 핸들러에서 쓰기 전 await 없음).
4. 성공: 토스트 "표를 복사했어요.", 버튼 2초 '복사됨', `onCopy`로 `feature_use` category `sheet_copy` 1회.
5. 실패: 기존 오류 토스트, 계측 없음. Textarea가 대체 경로(iOS 인앱·웨일·권한 거부 공통).
6. 닫기.

## 5. 데이터 계약 (읽기 전용, 서버 전송 0)
- 입력: `assetData`, `exchangeRates`(컨텍스트 현재값). 저장·fetch·localStorage 쓰기 0. GA에는 금액·이름 0(category 값만).
- 신규 순수 함수(예: `src/lib/export/sheet-table.ts`): `buildSheetTable(data, rates, today) → string`(TSV).
- 값 정본: `computeNetAsset`(`asset-data-context.tsx` 223)과 같은 식을 행 단위로 — 새 공식 금지. 상장폐지 제외, 거래정지 포함, USD×환율, JPY×환율/100.
- 형식(줄 = `\n`, 열 = `\t`):
  1. `기준일\tYYYY-MM-DD`(KST 오늘)
  2. `구분\t이름\t수량\t평가금액(원)`
  3. 행 순서: 주식 → 암호화폐 → 현금 → 부동산 → 실물 → 대출 → 임차보증금. 1 저장 항목 = 1행. 수량은 주식·암호화폐만(소수 허용, 저장값), 나머지 빈칸. 대출 = −잔액, 임차보증금 = −보증금(이름 = 해당 부동산 이름).
  4. 마지막 `순자산\t\t\t<Math.round(netAsset)>`
- 숫자: 쉼표·단위·`+` 없는 정수(원 반올림), 음수 `-`.
- 이름: 탭·줄바꿈(`\r`,`\n`,`\t`) → 공백. `=`,`+`,`-`,`@`로 시작하면 앞에 `'`.
- 다이얼로그 재사용 변경: 복사 버튼 라벨 선택 prop 1개(기본 "프롬프트 복사" 유지 → 기존 3곳 diff 0). 다른 변경 없음.
- `ga.ts`: `PARAM_VALUES.category`에 `sheet_copy`, `CATEGORY_TITLES` `sheet_copy: "표로 복사"`. 신규 맞춤 정의 0.
- 스키마·저장 키·마이그레이션·동기화·공유 토큰·보안 문구(`security-copy.ts`) 변경 0.

## 6. 정보 구조 — 지표 단위 전수 대조표
| 지표 | 정본 위치(불변) | 표로 복사 처리 |
|---|---|---|
| 순자산 | 홈 헤더 | 합계 행 = 같은 값(정본 함수 재사용) |
| 항목별 평가금액·수량 | 상세 각 탭 | 같은 값 텍스트로만 출력, 새 시각화 없음 |
| 자산군 합계·비중 | 홈 도넛·범례 | **넣지 않음**(시트가 계산) |
| 손익·수익률·평단 | 상세·성과 | 넣지 않음 |
| 월별·연도별 순자산, 전월 대비 | 성과·자산 변화, 결산 | 넣지 않음(v1 제외) |
| 환율 | 상세 외화 표시 | 넣지 않음(원화 환산값만) |

## 7. 엣지 케이스
- 빈 데이터: 자산 0건 → 행 비활성. 대출만 있는 경우도 `hasAssets` 규칙 그대로.
- 일부 갱신: 시세 일부만 갱신돼도 저장된 현재가 그대로(화면과 같은 값).
- 오래된 데이터: 환율 기본값 상태면 그 값으로 환산(화면과 동일).
- 첫 사용자: 항목 1개여도 기준일·머리·1행·합계 행.
- 같은 종목 여러 증권사: 행이 여러 개(합산하지 않음).
- 이름 특수문자: 5절 규칙. 순자산 음수면 합계 행 음수.
- 체험 모드·preview: 데모 데이터로 동작, 계측 no-op.

## 9. 완료 기준 (qa 검사 문장)
1. 더보기 › 도구 절 행 순서가 `세금 관리 → 표로 복사`(인증카드가 있으면 그 다음)이고, 자산 0건이면 '표로 복사'가 비활성이다.
2. 행을 누르면 탭 선택기 없는 다이얼로그에 표 텍스트가 읽기 전용으로 보이고 버튼 라벨이 '표 복사'다. 다른 PromptPreviewDialog 사용처(성적표·결산·X-Ray) 버튼 라벨은 '프롬프트 복사' 그대로다.
3. vitest(실데이터 형태 픽스처 5종: 주식만 / 대출 있음 / 외화 현금 / 실물 / 임차보증금): 마지막 행 값 = `Math.round(computeNetAsset(data, rates).netAsset)`, 차이 0.
4. vitest: 1줄 = `기준일\t<오늘>`, 2줄 = 머리 행, 행 순서가 5절과 같고 대출·임차보증금 값이 음수, 상장폐지 종목 행이 없다.
5. vitest: USD 항목 = 수량×현재가×USD, JPY = ×JPY/100(반올림 정수).
6. vitest: 숫자 셀에 쉼표·`원`·`%`가 없다. 이름의 탭·줄바꿈이 공백이 되고, `=`·`+`·`-`·`@` 시작 이름 앞에 `'`가 붙는다.
7. vitest(copyPrompt 경유): 쓰기 성공 시에만 `feature_use` `sheet_copy`가 1회, 실패 시 0회.
8. 코드 확인: 복사 핸들러에서 쓰기 전 await 없음, 새 fetch·localStorage 쓰기·저장 키 diff 0, `security-copy.ts` diff 0.
9. 화면·표에 '노션'·'CSV'·'파일'·투자 평가·권유 문구가 없다.
10. Vercel preview(데모 데이터): 데스크톱 Chrome 복사 성공 토스트, 320px 뷰포트에서 다이얼로그 가로 넘침 없음.
11. 홈·상세·성과·결산·세금 화면 diff 0.
