# 4.xx 표로 복사 — spec

작성: planner-designer 2026-11-09 · 기준 코드 origin/main eb204e4(v4.64) · 방향 문서 `4.xx-direction.md`(합의함)
위험: low 제안(읽기 전용). **신규 기능이라 머지는 대표 승인**(위임 머지 아님).

## 1. 문제
엑셀·구글시트·노션에 월말 순자산을 쌓아 온 병행 사용자는 앱 숫자를 손으로 다시 친다. 앱에는 표 복사·내보내기가 없다(클립보드 사용처는 공유 URL·동기화 링크·AI 프롬프트·설치 코드뿐). 옮기기가 귀찮아지면 새로 시작한 앱을 버린다.

## 2. 목표 행동
월말에 더보기에서 표를 한 번 눌러 복사하고, 자기 시트에 붙여넣는다. 다음 달에도 다시 온다.

## 3. 범위
- 포함: 더보기 › 도구 절 '표로 복사' 행 1개 → 다이얼로그 1개(카드 2개: 보유 현황, 순자산 기록). 카드마다 제목·행 수·미리보기 3행+"외 N행"·[복사]. 복사 실패 시 읽기 전용 텍스트 영역 대체.
- 하지 않을 것: 파일 다운로드(CSV·xlsx), 새 라우트·해시·SCREEN_TITLES 키, 열 선택·정렬·기간 선택, 거래내역·배당·세금 표, 금액 빼고 복사, 합계 행, 표 위·아래 설명 줄, 가져오기, 외부 공유 호출, 홈 팁·알림, 새 보안 단정 문구, 새 계산(평가·등급·수익률).

## 4. 사용자 흐름
1. 더보기 › 도구 › '표로 복사'(아이콘+라벨, 세금 관리 아래). 자산 0건이면 비활성.
2. 다이얼로그 열림 → `feature_use` category `sheet_copy_open`.
3. 카드 ① 보유 현황: 미리보기 3행, 캡션 "외화는 1달러 X원·100엔 Y원으로 환산했어요"(외화 자산 있을 때만), "복사한 표에는 금액이 그대로 들어 있어요."
4. 카드 ② 순자산 기록: 미리보기 최근 3행.
5. [복사] 탭 → 미리 만들어 둔 문자열을 await 없이 클립보드에 씀(HTML 표 + TSV, 불가 시 TSV만).
6. 성공: 토스트 "표를 복사했어요. 시트에 붙여넣으세요", 버튼 2초 '복사됨', `feature_use` category `sheet_copy`.
7. 실패: 토스트 "복사하지 못했어요", 해당 카드 아래 TSV 텍스트 영역 펼침 + "길게 눌러 전체 선택한 뒤 복사해 주세요". 계측 없음.
8. 닫기.

## 5. 데이터 계약 (읽기 전용, 서버 전송 0)
- 입력: `assetData`, `exchangeRates`(컨텍스트 현재값), `readMonthlySnapshots()`(`snapshot-storage.ts`), `assetData.yearlyNetAssets`. 저장·네트워크 호출 0, localStorage 쓰기 0.
- 순수 함수(신규, 예: `src/lib/export/sheet-table.ts`): `buildHoldingsTable(data, rates)`, `buildNetAssetHistory(monthly, yearly)` → `{ header: string[], rows: (string|number|null)[][] }`; `toTsv(table)`, `toHtmlTable(table)`.
- 값 정본: 평가금액은 `computeNetAsset`(asset-data-context.tsx 223)과 같은 식(상장폐지 제외, USD×환율, JPY×환율/100). 새 공식 금지 — 항목별 값의 합 = `computeNetAsset(...).netAsset`(반올림 오차 ±행 수 원 이내).
- 표 ① 열: `자산군 | 이름 | 기관 | 수량 | 평가금액(원) | 비중(%)`. 순서 주식→코인→현금→부동산→실물→대출→임차보증금. 대출·임차보증금은 음수, 수량·비중 빈칸. 비중 분모 = 홈 도넛과 같은 값(developer가 dashboard.tsx로 확인 후 dev-notes에 기록). 기관 = broker / exchange / institution, 없으면 빈칸.
- 표 ② 열: `기간 | 순자산(원) | 직전 대비(원) | 기록일`. 오래된 순. 연도 행(`YYYY년 말`)은 첫 월 스냅샷 연도 미만 연도만, 월 행(`YYYY-MM`)은 월 스냅샷 전부(최대 13). 기록일 = `MonthlyAssetSnapshot.date`, 없으면 빈칸. 직전 대비는 바로 앞 달(연도 행은 앞 연도)이 있을 때만.
- 서식: 숫자는 콤마·단위 없는 숫자(금액 정수 반올림, 비중 소수 1자리, 수량 저장값·최대 8자리·뒤 0 제거). 셀 안 탭·줄바꿈은 공백으로 치환, HTML은 이스케이프.
- 클립보드: 기존 `copyUrlForIOS` 패턴(ClipboardItem → writeText 폴백)을 일반화해 재사용(`text/html`+`text/plain`). 문자열은 다이얼로그 열 때 생성.
- 저장 스키마·저장 키·마이그레이션·동기화·공유 토큰·서버 전송 변경 0.

## 6. 정보 구조 — 지표 단위 전수 대조표
| 지표 | 정본 위치(그대로) | 표로 복사에서의 처리 |
|---|---|---|
| 순자산(현재) | 홈 헤더 | 표 ① 평가금액 합계로만 성립, 화면에 별도 표시 안 함 |
| 자산군별 금액·비중 | 홈 도넛·범례 | 행 단위로만 출력, 자산군 합계 행 없음 |
| 종목별 평가금액·수량 | 상세 각 탭 카드 | 같은 값 출력, 화면엔 미리보기 3행만 |
| 종목 비중 % | 상세 주식(PC) | 표 ① 비중은 총자산 대비(홈 도넛 분모) — 상세 주식 내 비중과 다름을 열 이름이 아닌 캡션 없이 두지 않도록 ui에서 확인 |
| 손익·수익률·평단 | 상세·성과 | **넣지 않음** |
| 월별 순자산 | 성과·자산 변화(월)·결산 | 표 ②로 출력, 원인분해·결산 문구 넣지 않음 |
| 전월 대비 | 결산·자산 변화 | 단순 차이만, 원인 없음 |
| 연도별 순자산 | 성과·자산 변화(연) | 월 기록 이전 연도만 출력 |
| 환율 | 상세 외화 표시 | 다이얼로그 캡션 1줄, 복사 내용엔 없음 |

## 7. 엣지 케이스
- 빈 데이터: 자산 0건 → 메뉴 행 비활성. 표 ② 0행 → "아직 기록이 없어요. 자산을 저장한 날부터 달마다 쌓여요.", 복사 비활성.
- 일부 갱신: 시세가 일부만 갱신돼도 저장된 현재가 그대로(화면과 동일 값).
- 오래된 데이터: 월 스냅샷에 `date` 없는 레거시 → 기록일 빈칸. 13개월 이전은 연도별 값만.
- 첫 사용자: 표 ② = 이번 달 1행(+수동 연도 행). 직전 대비 빈칸.
- 외화: 환율 기본값(1430/930) 상태여도 그 값으로 환산, 캡션에 그대로 표기.
- 이름에 탭·줄바꿈·`<`·`&`: 공백 치환·이스케이프.
- 체험 모드·preview: 데모 데이터로 동작, 계측 no-op.
- 인앱·권한 거부·ClipboardItem 미지원: 흐름 7 대체.

## 8. 지표 계측
- `ga.ts` `PARAM_VALUES.category`에 `sheet_copy_open`, `sheet_copy` 추가, `CATEGORY_TITLES`에 "표로 복사 열기", "표로 복사". 신규 맞춤 정의·화면 키 0.
- 주 지표: '표로 복사' 28일 활성 사용자, 12월 창(11/27~12/10)+연말(12/24~1/10) 대표 기기 제외 3명 이상. 0~1명이면 제거 후보. 보조: '표로 복사' 이벤트/사용자 1.5 이상. 판독 경계 = 머지 시각.

## 9. 완료 기준 (qa 검사 문장)
1. 더보기 › 도구 절에 '세금 관리' 아래 '표로 복사' 행이 있고, 자산 0건이면 비활성이다.
2. 행을 누르면 다이얼로그가 열리고 카드 2개(보유 현황·순자산 기록)에 각각 행 수, 미리보기 최대 3행, [복사]가 보인다.
3. 단위 테스트: 표 ① 평가금액 열 합 = `computeNetAsset().netAsset`(행 수 원 이내 오차), 대출·임차보증금 행은 음수, 상장폐지 종목 행 없음.
4. 단위 테스트: USD 주식은 수량×현재가×USD 환율, JPY는 ×JPY/100로 원화 환산된다.
5. 단위 테스트: TSV 1행 = 머리글, 숫자 셀에 콤마·`원`·`%`가 없고, 셀 안 탭·줄바꿈이 없다. HTML은 `<table>` 1개이며 이름의 `<`·`&`가 이스케이프된다.
6. 단위 테스트: 표 ② 오래된 순, `date` 없는 월은 기록일 빈칸, 앞 달이 없으면 직전 대비 빈칸, 연도 행은 첫 월 스냅샷 연도 미만만.
7. 클립보드 mock 테스트: 성공 시 `text/html`·`text/plain` 두 형식이 쓰이고 `feature_use` `sheet_copy`가 1회 호출된다. write 실패 시 writeText로 재시도, 그것도 실패하면 텍스트 영역이 펼쳐지고 계측은 호출되지 않는다.
8. 복사 탭 핸들러에서 클립보드 write 이전에 await가 없다(코드 확인).
9. 저장 키·스키마·동기화·공유 토큰·`fetch` 호출 diff 0, localStorage 쓰기 0(코드 grep).
10. 화면·복사 내용에 투자 평가·권유 문구, 'CSV'·'파일' 표기, 새 보안 단정 문구가 없다. `security-copy.ts` diff 0.
11. Vercel preview(데모 데이터)에서 데스크톱 Chrome 복사 성공 토스트, 모바일 뷰포트 320px에서 카드·미리보기가 가로 넘침 없이 보인다.
12. 홈·상세·성과·결산·세금 화면 diff 0.
