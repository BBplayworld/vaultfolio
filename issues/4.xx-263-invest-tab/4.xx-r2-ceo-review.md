## 3. 축 값 가독성 (390·320)
- **지수 y(로그)**: `100·200·500·1,000·2,000·5,000·10,000`(나스닥 1-3 눈금) 겹침 0, 실제 값이라 '1987년엔 200대, 지금 6,000대'를 말할 수 있다 — **대표 요구 충족**. 간격이 고르지 않은 이유는 ⓘ 1개로 충분.
- **x축**: 금리 패널 아래 1줄뿐이라 지수 선 위 한 점의 연도를 읽으려면 세 패널을 내려가 짚어야 한다 → 10년 눈금 **세로 hairline을 세 패널 관통**(겹침 영향 없음). 읽기 줄에 **그해 말 지수 값** 추가(`2008년 말 903 · −38.5% · 금리 내려감`) — y값 판단의 직접 수단.
- **낙폭 축**: `0%·−20%·−40%·−60%` 46px에 4개, 390 읽힘·320 빠듯(허용).
- **금리 축**: `0·5·10%`(코스피 `0·2·4·6%`) PASS.
- **'크게 빠진 때 −20% −40% −60%' 줄이 금리 x축 바로 아래 붙어 금리 차트의 두 번째 축처럼 보인다**(390·320·ndx 전부). 목록 머리로 내려 구분(카드 안 섹션 경계 + 위 여백 ≥16px, 라벨은 막대 눈금 hairline과 정렬)한다.
- 확대 차트 y `500·1,000·2,000`·금리 `0~6%`·x 연도·고점/바닥 축 표식 PASS.

## 4. 새로 생긴 문제
1. **정의 3중화**(1절 #1·#2): 헤드라인 = 고점→바닥 순변화, 기준선 = 국면 알고리즘, 읽기 줄 = 연말 목표 변화. 같은 화면 세 숫자가 다른 자.
2. **빈 상자 하나에 뜻 3개**: 금리 패널 멈춤(빈 상자), 6px 미만 국면(1px 테두리 상자), 행 표식 `거의 그대로`(빈 둥근 상자). 범례엔 올림·내림뿐.
3. **진행 중 하락이 그림에서 구분 안 됨**(코스피 2026년).
4. **출처 줄 오류**: 나스닥 화면 하단에 `S&P 500은 S&P DJI의 상표` 그대로, `지수는 공개 통계의 월말 요약값`은 라이선스 미확정 상태에서 출처를 단정(DECISIONS 11-22 데이터 결정과 충돌 소지). 지수별 문구 + 출처는 '확정 전' 자리표시로.
5. **가데이터 모양 이음매**: S&P 2016 이전은 앵커 직선 보간(1280·확대 차트에서 금융위기 하락이 직선 2개, 2011~12 평평한 고원), 이후는 들쭉날쭉. 10초 판독·qa 시각 판정을 왜곡 → 세 지수·전 기간 같은 방식의 가데이터로.
6. 320 라벨 단 순서 뒤집힘, 코스피 라벨 3단(3절·1절 #3), 연도 읽기 시 행 강조 누락(#7).

## 5. ui 남은 쟁점(8절 7건) — CEO 권고
1. **국면 정의 → 세는 자를 하나로.** 헤드라인(하락별: 고점 달→바닥 달), 기준선(해마다: 전년 12월 말→그해 12월 말), 읽기 줄(같은 연 단위) 모두 **'기준금리 상단 순변화, 절댓값 0.25%p 미만 = 거의 그대로'** 한 규칙. 기준선은 합이 맞게 `41년 중 금리가 내려간 해 N년, 올라간 해 M년, 거의 그대로 K년`(숫자 +1, 첫 화면 10개 이내). 12개월 연결·0.5%p 국면 알고리즘은 **금리 패널 그리기 전용**(세지 않음). 문구는 순변화와 일치하게 `내리던 중` → **`그 사이 금리가 내려갔어요`**: 머리 `그 사이 미국 금리는 3번 내려갔고, 1번 올라갔고, 1번은 거의 그대로였어요`, 행 표식 `내려감·올라감·거의 그대로`. qa는 연준 원자료로 연 단위 N·M·K를 독립 재계산.
2. **월말 유지**(D5 '연·월 요약값만'과 라이선스). 경계 규칙 = 원값 기준 **낙폭 ≥ 20.00%**(표시 반올림 전 값으로 판정, 손으로 넣고 빼지 않음). 코로나 고점 `2019.12`처럼 일별 상식과 다른 달은 펼침 ⓘ에 `월말 종가로 셌어요` 1줄, 출처 줄에 `월말 종가 기준`. 실데이터 교체 시 건수가 바뀌면 문장이 따라 바뀌는 구조로(하드코딩 금지).
3. S&P 1987·2000·2007 미검증 값: R3 진행은 막지 않되 **development 진입 게이트**(확정 출처로 재계산·qa 대조).
4. 코스피 접지: **기준선 1줄로 축약**(`금리 자료가 있는 27년 중 내려간 해 6·올라간 해 7·그대로 N`) + 이름표 **최대 2단**(넘치면 가장 얕은 하락 이름표만 생략 — 전수는 행이 보장, R7 위반 아님). 진행 중은 그림에 `진행 중` 점선 표식으로 구분. 외환위기 펼침에 `자료 시작(1994.12) 이후로 셌어요`.
5. **0.25%p는 '미만 = 그대로' 유지.** 0.25%p는 한 번의 실제 인상·인하 — 경계 건(코스피 2002 = 올라감)을 위해 규칙을 바꾸지 않는다.
6. 지수 y 실제 값의 공유 캡처 노출: 가데이터 칩 유지, 출시 게이트 = 라이선스 확정(대표 경로 결정). 지금 할 일은 4절 #4 출처 문구 정리.
7. 터치 스크럽: development 실기기 검증 유지, 정식 입력은 행(현행 맞음).

## 6. R2.5 수정 목록 (ui-designer, 목업·캡처만, R3 전)
1. **정의 통일**(5절 1): 헤드라인·기준선(3분류, 합 = 전체 해)·읽기 줄 한 규칙, 문구 `내려갔어요/올라갔어요`, 행 표식 교체. 집계 재계산 후 숫자 예산 재확인(≤10).
2. **금리 패널 표기 정리**: 멈춤 = 계단 선만(세로 변·상자 없음), 6px 미만 국면은 이웃 국면에 흡수하거나 상자 없이 비움. 행 `거의 그대로` 표식은 상자 아닌 모양(짧은 가로줄 `—` 등)으로 바꿔 금리 패널 표기와 겹치지 않게.
3. **'크게 빠진 때' 눈금 줄을 목록 머리로 분리**(섹션 경계·여백), 10년 세로 hairline 3패널 관통, 읽기 줄에 그해 말 지수 값.
4. **진행 중 하락 구분**(점선 이름표·`진행 중`) + 이름표 최대 2단·시간 순서 유지(320 `코로나19`가 `2022년` 앞), 코스피 기준선 1줄·접지 안 행 이름 3개.
5. **출처 줄 지수별 정정**(나스닥 화면 S&P 상표 문구 제거, `공개 통계` 단정 삭제, `월말 종가 기준` 추가), ③ 각주 `수익` → `앞으로도 같다는 뜻은 아니에요`.
6. **가데이터 생성 방식 통일**(세 지수·전 기간 같은 월별 방식, 직선 보간 이음매 제거) + 연도 읽기 시 행 강조 구현 + **10초 기대 문장 정정**(금융위기: '금리는 고점 무렵부터 내려 바닥 전에 0.25%', 닷컴·코로나에만 '하락이 먼저').

R2.5 캡처로 CEO가 1~4번만 재확인(30분 이내 범위) 후 R3(모션·상태·접근성·1280 디테일)로 넘긴다. 같은 정의 결함이 다시 나오면 data/ 집계 스크립트(build-data.js)부터 고친다.
