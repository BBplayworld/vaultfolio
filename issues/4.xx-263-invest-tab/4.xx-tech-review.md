## 1. 데이터 파일(확인 항목 1)
- 정본 CSV는 저장소 `data/market-history/*.csv`(현 `data/` 11종에서 verify_status·시안 메모 열 제거본). 생성 스크립트 `scripts/market-history/build.mjs`(Node, 의존 0)가 CSV → `src/lib/invest/data/market-history.generated.json`(+`.d.ts`용 타입은 `types.ts`)과 공개 CSV를 만든다. **생성물 커밋 + 드리프트 테스트**(CSV로 재생성한 결과 = 커밋본, 수동 편집 즉시 FAIL). 파생 계산(하락 지그재그·금리 방향·침체 겹침·③ 계산)은 `src/lib/invest/*.ts` 순수 함수 + 단위 테스트(목업 build-data.js 정의 한 벌을 그대로 이식).
- 용량(목업 data.js 실측, sim·sens 시험 데이터 제외 시 ≈65KB·gzip ≈13KB): 지수 3종 연 값+파생 7.1KB gz, 월 금리(미·한) 2.4KB gz, 10년물 월 4.6KB gz, 사건·침체·표 나머지. **단일 청크로 충분**(겹쳐 보기 분리 시 4.6KB gz 절감뿐, 폭포 지연이 더 나쁨). 투자 탭 청크 전체 목표 ≤ gzip 40KB(데이터 13 + 뷰·계산).
- **생성 스크립트 테스트(vitest)**: 시안 단언 그대로 — 사건 31건·분류 7종(금리·통화 정책 10/전쟁·지정학 7/금융위기 7/에너지 2/시장 급락 2/팬데믹 2/기술 거품 1), 하락 건수 S&P 4·나스닥 3·코스피 6(−15% 연말 기준), 금리 집계(S&P `n43 up16 down18 flat9`·나스닥 `41/15/17/9`·코스피 `26/12/14/0`), 침체 월 수 = NBER 구간 재계산 불일치 0, 10년물 12월 월말 = 연말 불일치 0, 한국 기준금리 연말 = 월 계단 12월 불일치 0. (위 숫자는 scratchpad에서 build-data.js를 돌려 확인함, 모두 통과.)
- **추가 결함 의심(qa 확인)**: 월 10년물 월말값은 R1(FRED 경로) 값이고 연 표만 H.15다(12월만 대조). 생성 스크립트가 H.15 XML 일별(`RIFLGFCY10_N.B`)에서 월말 값을 직접 만들고 R1과 **전 월 대조**하도록 바꾼다(출처 문구 `연준(H.15)`과 일치). 한국 월 기준금리·국고채 10년 월평균(~600값)은 36행 재대조 범위 밖이므로 5절 엑셀에 포함.

## 3. 갱신 절차(항목 3, `docs/ops/market-history-refresh.md`로 문서화·매년 1월 1회)
1. **Damodaran**: `histretSP.xls` 1월 갱신본 → 연말 S&P 수준값 +1행(공개 CSV에는 제외 열).

4. **ECOS**: 사람이 웹 통계표를 엑셀로 내려받아 정적 인용(Open API·내부 요청 자동 호출 금지).

- **H.15 DDP 종료 대체 경로(확인 완료)**: 연준 안내 원문 "Historical data will remain available for download as XML files on Board statistical release pages" · 실제 파일 `https://www.federalreserve.gov/releases/h15/data/FRB_h15_xml.zip`(HTTP 200, 4.29MB, 최종수정 2026-11-20). 내려받아 열어 보니 `H15_data.xml`의 Prepared 시각 2026-11-20T16:40:02·계열 ID `RIFLGFCY10_N.B`가 현 DDP 패키지와 **같다**(R3 데이터 문서 기준). 따라서 2027-03-31 이후도 같은 파싱 코드로 지속 가능. FRED는 R1 배제 경로이므로 쓰지 않는다(API 키·약관).
- 위험: 갱신 1월 누락 시 `2025년 말까지` 표기가 낡는다(결함 아님, 문구가 기준일을 말함). 캘린더 1월 알림은 오케스트레이터 예약에 등록 권고.

## 5. 한은 36행 비API 재대조(항목 5) — **막힘, 대표 수동 1건**
