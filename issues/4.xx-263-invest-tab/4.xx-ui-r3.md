## 3. 모션·인터랙션·접근성
- 겹쳐 보기: 선 그룹은 **항상 DOM에 두고 opacity 0↔1만 전환**(.2s, `motion-safe`) — 재마운트 없음, 연타·중간 방향 전환에도 현재 불투명도에서 이어짐. 목록은 opacity+translateY(-4px)+scale(.98) 140ms(subtle exit), 바깥 탭·Esc로 닫고 포커스는 버튼으로 복귀. 알약 press scale .96
- 표 펼침: `grid-template-rows 0fr→1fr` 240ms(높이 점프 없음), 닫힌 동안 `visibility:hidden`(포커스 제외). 쉐브론 180° 회전
- 연도 읽기: 터치 스크럽 실기기 검증은 development(R2.5 이월). 행 전환 160ms 유지
- a11y: 차트 `role=img`(대체 문장에 `연도별 표` 안내), 알약 `aria-haspopup=listbox`·`aria-expanded`, 목록 `role=listbox/option`·`aria-selected`, 표 `region`+`caption`+`th scope`, 표 버튼 `aria-expanded/controls`, 읽기 줄 `aria-live=polite`. 히트 40px: 알약 40, 표 버튼 48, 목록 항목 44. 다크 대비: 선택·축 글자 `--brandtx`(라이트 indigo-600 / 다크 indigo-300, design-system 링크 규약 재사용, 신규 토큰 0 — 단 CSS 변수명은 구현 때 기존 클래스(`text-brand dark:text-indigo-300`)로 대체)
- design-system 흡수 후보(신규 규약 2): ① 차트 캡션 줄 오른쪽 알약+목록 컨트롤 ② 접힘 표(grid-rows 전환·고정 열). development 뒤 §5·§13에 등록

## 9. 남은 쟁점
1. **사건 사실 1줄 위치**: 점·펼침은 이름·날짜·분류만 보인다(이름만으로 뜻을 모르는 사건 예: 볼커 긴축, 테이퍼 탠트럼). 사건 CSV 문장은 `~했다` 문체·일부(E13 등)가 사건 자체와 어긋나 그대로 못 쓴다. spec에서 해요체 사실 1줄 31개를 쓰고 1차 출처로 qa가 대조할지 결정 필요. 시안 범위 밖
2. **코스피 10년물**: CEO 지시는 `10년물 1개`. 코스피는 국고채 10년 월평균(ECOS)으로 대응했고 표에는 국고채 3·10년. 금리차·침체 열은 미국 전용이라 코스피 표에서 뺐다 — 확인 요청
3. **사건 표시명·날짜 규칙**: E31 `러시아-우크라이나 전쟁`(원문 `…·급격한 금리 인상`에서 앞부분만), E13은 사건일이 아닌 구간 `2000~2002년` 표기, 점 위치는 월 단위 근사. `DISP`·`SHORT` 규칙이 CEO 판정과 맞는지 qa 대조
4. **320 코스피 이름표 3단**: 2단 초과라 CEO ③ 조건상 옛 기준 환원 대상이나, 3단으로 6개 모두 노출하고 제목이 740에서 접지 안에 들어 예외로 둠 — 승인 요청
5. **미국 하락 창 침체 문구**: 하락 구간(고점 다음 해 1월~바닥 해 12월)과 겹치는 침체만 적는다. 정의가 CEO 문구와 같은지 확인
6. 한은 값 36행 비API 재대조(출시 차단), H.15 갱신 경로(2027-03), 물가·실업률 govinfo 탐색(tech-review) — 코드·CEO 판정 그대로
7. 침체 띠 면(fg 7%)과 ⓑ 회복 띠(ink3 32%)가 비슷한 회색이라 ⓑ 층에서는 위 막대 유무로만 구분 — 실기기 대비 확인 후 필요하면 띠 톤 조정(spec)
