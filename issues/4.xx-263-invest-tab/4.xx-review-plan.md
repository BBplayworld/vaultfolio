# #263 투자 탭 — 반복 검토 계획 (대표 지시 11/22: "몇 차례 지속적인 검토를 통한 고수준 결과물")

구현 전 '채울 내용'과 '한눈에 보는 UI'를 최소 3라운드 검토로 끌어올린 뒤에만 개발에 들어간다.

| 라운드 | 산출물 | 검토자(서로 다른 관점) | 통과 기준 |
|---|---|---|---|
| R0 초안 | direction·business(사업), data/(역사 데이터), ia(정보 구조) | — | 3종 완성 |
| R1 | 데이터 검증 + 시안 3종(서로 다른 시각 언어) 390·1280 목업 | qa: 데이터 표본 대조(출처 재확인) · cto: 원칙·라이선스 반대 검토 · 사업: 가치 | 데이터 오류 0, 원칙 위반 0, 시안 1안 선정 |
| R2 | 선정안 고도화(상호작용·사건 상세·거치/적립 계산 화면) | ui-designer↔planner 교차 · CEO 대리 사용자 점검(처음 보는 사람이 10초 안에 '금리·사건·지수' 관계를 말할 수 있나) | 지적 0 또는 반영 |
| R3 | 최종 시안 + spec + tech-review | 전원 최종 · 대표에게 목업·요약 보고 | 대표 방향 확인 후 개발 |

원칙: 지적이 나오면 다음 라운드에 반영하고, 같은 지적이 두 번 나오면 원인을 고친다. 라운드마다 목업 재촬영.
