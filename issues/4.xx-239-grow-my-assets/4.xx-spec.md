# 4.xx #239 내 자산 불리기 — spec

기준: main c9fd234(읽기만). 방향·추천 아님 경계·금지 단어는 [`4.xx-direction.md`](./4.xx-direction.md), 저장·지표 조건은 [`4.xx-challenge.md`](./4.xx-challenge.md)가 정본이다. 화면 문구·배치 정본은 `4.xx-ui.md`. risk:high, 대표 승인 머지.

**문제**: 성적표는 점수만 주고 "무엇을 그대로 두고 무엇을 다시 볼지"는 엑셀에서 한다. Plus 배지 4곳은 뜻이 없고, 성적표 '다음 행동' 줄 일부가 권유형이다.
**목표 행동**: ① 보유 주식 종목에 '오래 둘 자산'·'점검할 자산' 이름표를 직접 붙인다 ② 점검할 자산을 보고 '오늘 점검했어요'를 누른다 ③ 다음 방문에 "마지막 점검 N개월 전"을 보고 반복한다.

**범위**
- 넣는 것: 이름표·점검 블록, 점검 주기(3·6·12개월, 기본값 없음), 허브 셋째 카드 교체, Plus 배지 4 → 2, 성적표 권유형 문장 정리, GA title 2개, 새 소식 1줄, 기능 목록 이름(`app-features.ts:131~132`), PRINCIPLES 5장 메뉴 이름 1줄(별도 커밋).
- 뺀 것: 주식 외 자산 이름표, 매수일 기준 보유 기간, 배당, 비중 상한 기준, 점검 알림·푸시·홈 팁, 상세·주식 진입, 앱이 먼저 나누는 분류, 점검 메모, 해외주식 세금 행, 성적표 새 접힘 층, 이름표의 AI 프롬프트 반영.
- **direction과 달라진 것 1건(cto 수용, challenge '11/17 spec 쟁점' 1)**: **X-Ray 행을 새로 만들지 않는다.** 성적표 분산 축의 링크가 이미 X-Ray로 간다(`asset-report-view.tsx:379·383`). 행을 더하면 같은 도착 진입이 한 화면에 2개다(C124). 기존 축 링크 1개를 유일한 진입으로 두고, 문장을 사실형으로 고쳐도 링크는 남긴다.

## 추천 아님 조건 5개 (challenge 1절 그대로, AC-8~12)
1. 이름표 0개 상태의 허브 카드·화면에 앱이 센 숫자·분류를 두지 않는다. `오래 둘 6 · 점검할 3`은 사용자가 붙인 개수일 때만 나온다.

3. 성적표 축 문장·점수가 개별 종목이나 이름표를 가리키지 않는다. 축 문장에서 이름표 블록으로 가는 링크 없음.
4. 이름표는 AI 프롬프트 본문에 넣지 않는다(v1, 본문 diff 0).
5. "주기가 지났어요"는 화면 안 사실 문구만. 푸시·홈 팁 없음.
