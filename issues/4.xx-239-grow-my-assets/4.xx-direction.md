# 4.xx #239 내 자산 불리기 — Plus 기능 종합 정리

대표 지시(2026-11-17): "Plus 기능 종합 정리. '내 자산 불리기' — 좋은 자산은 오래 장기 유지하도록. 검토 필요 자산은 사용자에게 체크하도록. 절대 종목과 투자 추천은 아니어야 해."
코드 기준: main c9fd234(사업 절은 로컬 작업 트리로 읽음, origin/main 미대조).

## 문제
1. **Plus가 약속이 아니다.** `Plus` 글자는 배지 4곳뿐이다(`performance-hub.tsx:196`, `asset-report-view.tsx:393`, `cloud-sync-menu-entry.tsx:144`, `tool-menu.tsx:330`). 분석 1개와 기기 연결 1개에 같은 배지가 붙어 있고 뜻을 말하는 문장이 없다.
2. **고급 기능이 흩어져 있고 거의 안 쓰인다.** X-Ray, 절세 시뮬레이션, 시장 비교, 배당, AI 프롬프트 2곳, 가계 통계 비교. 성적표 진입은 주 1기기다(`_discovery/2026-11-15-d-business.md` 9행).
3. **성적표는 점수만 주고 다음 행동이 없다.** "무엇을 그대로 두고 무엇을 다시 볼지"는 엑셀로 돌아가서 한다.
4. **성적표 '다음 행동' 문장 일부가 권유에 가깝다**(`asset-grade.ts` 179·208·370행 등).

## 대상
엑셀·노션에 종목마다 '산 이유·점검일' 칸을 만들다 만 3040 주식 투자자. 종목 5~20개를 오래 들고 있고 월 1회 이상 여는 기존 사용자다(11/07~13 홈 16기기). 신규·미등록 기기는 대상이 아니다.
- Plus의 약속: **"기록한 자산을 내 기준으로 오래 지키고, 정기적으로 내가 점검한다."** 앱이 골라 주지 않고 사용자의 결정을 기록한다.

## 사업 절 (business-pm)
1. **왜 지금 — 리텐션. 첫 발견 기여 없음.** 월 결산 뒤 "그래서 무엇을 볼까"가 이어지면 월 1회 방문에 할 일이 생긴다. 근거는 대표 지시가 중심이고 GA 근거는 약하다. 이것만으로 월 100명에 닿지 않는다.
2. **규모.** 진입을 더하는 과제가 아니라 성적표 자리를 다시 짜고 배지·권유 문장을 줄이는 과제다(LEARNINGS 11-16).
3. **성공의 모습 (익명 기기 수, page_title만 — C122)**
   - 주 지표: 신규 title **`내 자산 불리기·체크`**('오늘 점검했어요'를 누른 기기). 머지 후 4주(월 결산 창 1회 포함) **3기기 이상 성공 · 2기기 보류 · 1기기 이하 축소**. 진입이 성과 허브(28일 6명) 하나라 3은 낙관적인 가정이다.
   - 보조: 신규 title **`내 자산 불리기·이름표`**(이름표 0개에서 첫 이름표를 저장한 때 1회). 기준 없이 깔때기로 읽는다: 화면 진입 → 이름표 → 체크.
   - 화면 title은 **`성과·자산 성적표` 유지**(`ga.ts` 163행 무변경). 기준선 주 1기기와 이어 읽는다.
   - 전송 경로: `track("feature_use", { category })` → `CATEGORY_TITLES`(178~221행) → `page_title`(315~317행). **두 값 모두 지금은 전송되지 않는다.** 허용 목록(89행)과 `CATEGORY_TITLES`에 각 2줄을 넣고 title 문자열을 vitest로 고정한다. 빠지면 312행 폴백으로 '성과·자산 성적표'에 섞인다.
   - 보내지 않는 것: 종목코드·종목 수·이름표 종류·개수·금액·비중·주기. 체험 중은 전송 없음(327행). 대표 기기를 뺄 수 없어 수치는 상한이다.
4. **하지 않으면 잃는 것 — 약~중.** Plus 배지가 뜻 없이 남고 성적표는 주 1기기에 머문다.

- **가드레일**: '성과·자산 성적표'·'성과·자산 변화'(159행) 기기 수 유지.
- **판독 창 오염**: 홈·웰컴·연 탭·알림 변경 0이라 #234·#232·4.90·5.115는 오염 없음. 성과 허브 카드가 바뀌므로 머지 시각을 #237(12/27~1/10) 메모에 기록한다. `year_settlement` 전송 조건 diff 0.
- **알릴 채널**: 새 소식 1줄, 출시 주 Threads 2~3건·블로그 1건. 금액 0, "불려 준다" 표현 금지. 초안만.
