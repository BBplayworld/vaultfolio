## 2. 웰컴 ③ 라벨 행 — "직접 둘러보기"
컴포넌트: `PreviewLabel`에 선택 prop `action?: ReactNode` 추가(③만 전달, ⑤ 무변경). 신규 컴포넌트 아님.
```
div.flex.items-start.gap-2                       ← 행(기존 items-center → items-start)
  div.flex.min-w-0.flex-1.flex-wrap.items-center.gap-x-2.gap-y-1   ← 제목+배지 묶음(320에서 배지만 둘째 줄)
    p "포트폴리오 미리보기" / Badge "예시 데이터"(기존 그대로)
  {action}                                         ← shrink-0, 첫 줄에 고정
```
- 버튼(`<button type="button">`, Button 컴포넌트가 아니라 칩이므로 직접 마크업, 누름 규약은 동일 적용):
  `data-testid="welcome-trial-link"` `className="relative -my-1.5 inline-flex h-8 shrink-0 items-center gap-1 rounded-full bg-brand/15 px-3 text-sm font-semibold text-foreground break-keep whitespace-nowrap hover:bg-brand/25 dark:bg-brand/20 dark:hover:bg-brand/30 motion-safe:transition-[background-color,scale] motion-safe:duration-150 motion-safe:active:not-disabled:scale-[0.96] outline-none focus-visible:ring-[3px] focus-visible:ring-ring/50 disabled:opacity-60 after:absolute after:-inset-1 after:content-['']"`
  - 내용: "직접 둘러보기" + `ArrowRight size-3.5 text-brand aria-hidden`(아이콘은 비텍스트 3:1 충족)
  - 히트영역: 칩 32px + `after:-inset-1` = 40px. `-my-1.5`로 행 높이(20px)를 늘리지 않는다 → CTA 슬롯 위치·`min-h-[152px]` 불변(#48 구조 보존)
- 폭 계산: 칩 약 128px. 375(351px): 제목 약 130 + 배지 약 69 + 칩 128 + 간격 = 약 343 → 한 줄. 320(296px): 배지가 제목 아래로 내려가고 칩은 첫 줄 오른쪽 유지(행 높이 약 44px). 가로 넘침 0. 1280: 한 줄, 칩은 오른쪽 끝
- 상태: 기본 / hover(`bg-brand/25`) / focus-visible(링 3px) / 누름 0.96 / **이동 중**: 탭 즉시 `disabled` + `aria-busy="true"`, 화살표 → `Loader2 size-3.5 motion-safe:animate-spin`(연타로 beacon 2회 방지). 라벨 문구 유지
- 노출: 웰컴이 렌더되고 `isSharePending=false`이고 해시(`#share`/`#sync`) 없음. 인앱(#60 `inapp` 상태)에서도 노출

## 3. 체험 로딩(TrialGate, `?trial=1`일 때만)
- 게이트 처리 중 children 미렌더 구간: `fixed inset-0 bg-background` 위 중앙 `Loader2 size-5 text-muted-foreground motion-safe:animate-spin`, 300ms 지연 페이드인(`motion-safe:animate-in fade-in` + `style={{animationDelay:"300ms",animationFillMode:"backwards"}}`). 문구 없음. `data-testid="trial-gate-loading"` `aria-busy="true"` `role="status"` + `sr-only` "불러오는 중"
- 실패(fail-closed): 메시지 없이 일반 화면(spec 6장 문구 표 "격리 검증 실패: 문구 없음")
- `?trial=1` 없으면 DOM 추가 0(spec 10-5)

- 4-2 인앱(#60 `useExternalMove`): 라벨 동일. Android는 스킴 이동(이동 중 상태 동일). iOS는 버튼 아래에 **항상 마운트된** 높이 펼침 영역(§6 grid-rows 0fr↔1fr, `inert`, `motion-safe:duration-300`) 안에 #60 4.38-ui.md 3장과 같은 캡션 + `InAppExternalGuide notice={…}`. 펼침 시 배너는 `flex-col`로 전환(`sm:flex-row`는 펼침 전만). 재탭 시 재복사, 영역은 열린 채
- 퇴장 모션 없음(페이지 이동)

## 9. 품질 체크리스트(qa·ui-review 판정용)
1. 375·1280 × 라이트·다크: 웰컴 ③ 행에 "직접 둘러보기" 칩이 제목과 같은 첫 줄 오른쪽에 있고, `welcome-cta-slot`의 top 좌표가 main 대비 ±1px 이내(행 높이 불변).
2. 320: ③ 행에서 배지만 둘째 줄로 내려가고 칩·제목은 첫 줄, `document.documentElement.scrollWidth === 320`.
3. 칩 히트영역(`::after` 포함) ≥ 40×40, 칩 텍스트 대비 라이트·다크 ≥ 4.5:1(전경색 on `bg-brand/15`·`/20`).
4. 칩 탭 후 즉시 `disabled`·`aria-busy=true`, 연타해도 `feature_use{demo}` 1건.
5. `#share`·`#sync` 해시 URL과 자산 1건 이상 기기에서 `welcome-trial-link` 부재.
6. 체험 홈: `trial-banner`가 1개, `AssetPageTabs` 위에 있고 fixed/sticky 아님(computed `position: static`), 상세·성과·결산 화면에는 배너·"예시" 배지 0.
7. 배너 375·320: 텍스트 2줄 + 버튼 전체 폭(버튼 높이 40px), 1280: 한 줄·버튼 오른쪽. 라이트에서 배너가 캔버스와 구분(카드 면+그림자), 다크에서 테두리 0.
8. 배너 버튼이 `variant="brand"`(배경 #5b6fbf), 화면의 다른 brand 버튼 0.
9. 배너 버튼 탭 후 즉시 `disabled`, `/`로 이동, 웰컴 슬롯 `data-state="asset"`이고 `welcome-cta-wizard`가 `document.activeElement`.
10. 체험 중 FAB·더보기·설정 진입 DOM 부재, 상단 우측 아이콘 행에 빈 자리 없음.
11. 새 문구 전부(칩·배너 2문장·버튼)가 320·375에서 어절 중간 줄바꿈 0, 해당 요소 computed `word-break: keep-all` 또는 `white-space: nowrap`(C25).
12. reduced-motion에서 배너 진입·로딩 스피너·버튼 스피너 애니메이션 없음, 일반 모션에서 `transition-property`에 `all` 없음.
13. `?trial=1` 로딩 중 문구 0, 300ms 이전 스피너 opacity 0.
14. C2: 체험 홈의 컨트롤 줄 수가 일반 홈보다 늘지 않는다(배너 1블록만 추가, 상단 탭 그대로).
