# #59 체험 모드 — direction (경험 절)

상태: planning ① / 사업 절·합의 절: 아래(business-pm, 2026-10-31) / cto 반대 검토: 축소·risk:high(4.38-challenge.md 반영) / 근거 코드: issue-4.37 기준 현재 `src/`
대표 결정(DECISIONS 2026-10-31): ①착수 ③새 URL 금지 해제 → 체험 진입은 `/?trial=1`(방식 B). 새 라우트(`/trial` 등)는 만들지 않는다.

## 경험
### 1. 사용자가 하게 될 행동 (관찰 가능)
- 웰컴 화면(자산 0건)에서 "직접 둘러보기"를 눌러 홈·상세·성과·월 결산을 실제 화면 그대로 탐색한다.
- 체험 중 상단 고정 배너의 "내 자산으로 시작"을 눌러 일반 웰컴의 CTA(스크린샷 등록)로 돌아온다.
- 새로고침·탭 닫기로 체험을 끝내도 내 기기 저장소·서버에 흔적이 남지 않는다(쿼리 없는 새로고침 = 일반 화면).

### 2. 범위
- 포함: 예시 금고(기존 `demo-data.json` + `materializeDemo` 재사용, 메모리 전용), 운영용 `TrialGate`(provider 바깥, `?trial=1`일 때만 동작), 체험 배너 1개, **외부 전송 진입점만** 숨김(FAB=스크린샷 AI 인식, 더보기=공유·피드백·동기화, 설정), 체험 페이지 GA 전면 끔, 웰컴 진입 링크 1개.
- **줄일 수 있는 것**: 읽기 전용 완전성 조사(상세 행 편집은 메모리 안에서만 일어나고 새로고침하면 사라지므로 허용) / 체험 전용 안내 투어 / 체험 상태 복원 / 체험 중 실시간 시세(네트워크 0) / GA 허용 목록(전면 끔으로 단순화) / `welcome_view` 재전송 억제.
- **하지 않을 것**: 체험 데이터를 localStorage·IndexedDB 원본에 저장, **종료 시 원본 복구 코드**(S2: 종료는 `location.assign("/")` 이동뿐), 실행 중 `window.localStorage` 교체(대안 A), 별도 라우트·provider 트리(대안 C), 저장소 어댑터 리팩터링(대안 D), 체험→내 금고 데이터 승계, 홍보 글 직결 링크(v1 밖), 투자 조언성 문구.
- 위험 등급 **high**(cto 확정): S1 실패 시 실제 기기 데이터 삭제 가능. 스키마·저장 키는 무변경(마이그레이션 없음).

### 3. 기존 화면 변화
- 바뀌는 곳: 웰컴 ③ "포트폴리오 미리보기" 라벨 행에 "직접 둘러보기" 링크 1개(CTA 슬롯 min-h 152px 유지, #48 구조 보존). 체험 페이지 홈 상단 배너 신설. 체험 중 FAB·더보기·설정 진입 숨김.
- 그대로: 결산·성과·상세 화면 코드 무수정(데이터 공급만 교체), CTA 슬롯 상태, 정적 미리보기 ③⑤(#48 판독 전 제거 안 함). `?trial=1`이 없는 일반 방문자의 렌더·지연은 main과 동일해야 한다.

### 4. 사업 절에 대한 의견
- `동의`. 목표(체험 진입률 ≥20%, 진입·시작 2값, 가드레일)와 결산 창 전 머지/불발 시 12/11 이월에 동의한다.
- 사업 절 이견 반영:
  1. **링크 발견성**: 수용. 8주 진입률 10% 미만이면 링크 위치·크기를 재검토한다(이번엔 #48 때문에 CTA 슬롯 구조 유지).
  2. **출시 조건(iOS/WebView 실기기)**: 실기기 검증은 팀이 할 수 없다(알려진 한계 C9). 대신 주입 전 검증 4종 fail-closed로 막아, 지원되지 않는 환경에서는 체험이 열리지 않고 일반 화면으로 간다(데이터 무접촉). 실패 시 분리 출시는 cto 컷 규칙으로 정리됨(아래 5).
  3. **측정 한계**: 체험 페이지 GA 전부 끔 → 체험 시간·화면 조회 측정 불가, 판정은 진입·시작 2값(동의).

1. **왜 지금**: 첫 발견→첫 등록 전환에 기여. 웰컴 7기기 → 등록 시도 1 → first_asset_saved 0(계측 이후 13일). 두 병목(유입 월 약 17기기 / 전환) 중 전환 쪽 후보이며 인앱 도착자(#60)가 가치를 만질 수 있는 유일한 수단이 된다. 리텐션 기여는 없음. 대표 착수 결정(10/31) 확정이라 보류 권고는 아님
2. **누구를 위해**: 엑셀·노션으로 정리하던 3040 주식 투자자 중 "스크린샷을 올리기 전에 결과 화면부터 보고 싶은" 처음 온 사람. 자산 0건 방문자 한정
3. **성공의 모습** (익명 기기 기준, 기존 GA 이벤트 + 계획된 값 2개):
   - 체험 진입률 = `feature_use{demo}` 기기 ÷ `welcome_view` 기기, 8주 누적 ≥ 20%(보수 하한. spec 가정 40%는 링크가 라벨 행의 작은 링크라 낙관)
   - 체험 후 시작 = `onboarding_action{trial_start}` 기기 8주 ≥ 2, 그중 `first_asset_saved` 1기기 이상이면 방향 확인
   - 가드레일: 체험 중 `settlement_view`·`ai_prompt`·`asset_count_bucket` 변화 0(#51·#54 판독 보호), welcome→onboarding_action 기존 14%(1/7) 미악화(표본 작아 정성)
4. **하지 않으면 잃는 것**: 약함~중간. 월 신규 정착 약 +1기기 규모라 하지 않아도 서비스가 무너지지 않는다. 다만 웰컴 정적 미리보기만으로는 성과·결산을 보여줄 수 없어 "가치를 모른다" 가설이 검증도 해소도 안 된 채 남는다. 산식·표본 한계는 `4.38-business.md`
