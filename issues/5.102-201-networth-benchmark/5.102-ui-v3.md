# [5.102] ui v3 · '가계 통계와 나란히' 핵심만 재설계 (ui-designer, 2026-11-14)

대표 피드백 3건: ① 태블릿에서 블록이 절반 폭 ② 내 구간이 가계 평균 대비 어디인지 첫눈에 안 보임 ③ 핵심만 추릴 것.
근거 코드: `networth-benchmark-block.tsx`(origin/issue-5.102, d925a35). 캡처: `screenshots/v3-before-{768,1024,390,1280}-dark.png`(DPR1, preview `?demo=1`, 성과 → 자산 성적표).

## 1. 진단
- 절반 폭 원인: 외피 `<section>`은 전폭(768=672px, 1024=928px, 1280=1184px)인데 **목록+자산 구성 래퍼가 `sm:max-w-xl`(576px)** 이다. 640px 이상에서 모두 576px 고정 → 1024에서 62%, 1280에서 49%(절반), 오른쪽은 빈 공간. 문장·라벨은 전폭이라 정렬도 어긋난다.
- 첫 시선: 문장(`text-sm font-medium`)과 목록 10행이 같은 크기 텍스트라 위계가 없다. 가장 큰 덩어리는 "금액 문자열 10줄"이고, 내 구간은 한 줄 배경 하이라이트 + 칩뿐이다. 10줄 = 순번 없이 금액만 읽어야 해 "10개 중 어디쯤"이 위치로 안 보인다(②의 원인).
- 기본 노출 정보 약 45개 단위: 제목·등급 안내·문장·기준 라벨(3)·열 머리·경계 금액 10행+칩·구성 소제목·기준 줄·표 머리 3+셀 16·주석 2·출처(4). 390 높이 833px(화면 1개 초과), 1024도 770px.

## 2. 재설계안 (공통 원칙)
- 첫 줄 = 한 문장 결론, 승인 문형 재사용(`benchmarkSentence`): "가구 100곳 중 약 10곳이 이 구간, 약 20곳이 이보다 높은 구간이에요." 보조 한 줄: `내 구간 4억 6,180만~6억 9,380만`. **"N번째·상위·하위·평균보다" 금지**(서열). 문장은 `text-base font-semibold`로 승격(현 text-sm), 보조 줄 `text-sm text-muted-foreground tabular-nums`.
- 시각 요소 1개 = **10칸 가로 막대**: 칸 = 구간 1개(동일 폭, 칸 사이 2px gap, 높이 `h-3`(12px), `rounded-sm`). 내 칸 `bg-foreground`, 나머지 `bg-foreground/15`(중립; 손익색·주황 불사용). 내 칸 위에 마커 `▾`(`size-3`) + 칩 `내 구간`(기존 `SCOPE_MAIN` 재사용, 칸 중앙 정렬, 양 끝 칸이면 가장자리에 붙임). 막대 아래 양 끝 경계만: 왼쪽 `1,210만 미만`, 오른쪽 `11억 20만 이상`(`text-xs text-muted-foreground tabular-nums`). 나머지 경계 금액은 펼침 안.
- 자산 구성 핵심 2줄(표 대체): `비슷한 가구  예금·주식 등 19% · 전·월세보증금 6% · 부동산 69%` / `나  예금·주식 등 9% · 부동산 91%`. 부채 행·금액 열은 펼침. 행 머리 `text-xs text-muted-foreground w-16`, 값 `text-sm tabular-nums`, 줄 높이 min-h-8. 내 값이 없는 항목(보증금 `—`)은 생략하고 펼침 표에서 `—`. 부동산 미등록(hidden)이면 "나" 줄·내 구간 표시 없이 기존 `benchmark-hidden-note`만.
- `자세히` 펼침(`market-basis-toggle` 패턴 재사용: 버튼 `min-h-10 w-full`, `aria-expanded`/`aria-controls`, 패널 항상 마운트 `grid-rows-[0fr↔1fr]`·접힘 `inert`·`aria-hidden`, 120ms, `motion-safe`, 재마운트 없음): 경계 금액 10행 목록(내 구간 강조 유지) · 구성 표 4×3(금액 열 포함, 대표 결정 유지) · 주석 2줄 · 기준 라벨 · 출처. 열린 기본값 접힘.
- 등급 안내 `등급 점수에는 반영되지 않아요.`는 제목 아래 유지(CAPTION 1줄, 오해 방지 필수).

### 안 A · 단일 열 전폭
세로: 헤더 → 결론 → 막대 → 구성 2줄 → 자세히 → 출처. 모든 폭에서 같은 구조. 구현 단순, 1280에서 막대가 1136px로 늘어짐(칸 비중 10%라 왜곡은 없으나 길고 휑함).

### 안 B · 2단 (권고)
`md`(768) 이상 `grid grid-cols-2 gap-x-8`(왼쪽 결론+막대, 오른쪽 구성 2줄), 미만은 안 A와 같은 단일 열. 자세히·출처는 두 열 아래 전폭. 이유: 태블릿·PC의 폭을 쓰되 막대가 ≤ 560px로 제한돼 읽기 쉽고, 결론(위치)과 구성(비교)이 한 화면에 나란히 보여 ②에 직접 답한다. 왼쪽·오른쪽 높이는 구성 2줄(약 64px)이 막대 영역(약 110px)보다 작으므로 오른쪽은 `self-center`. `sm:max-w-xl` 제거.

기본 노출 정보 before → after: **약 45 → 약 12**(제목, 등급 안내, 결론 1, 구간 줄 1, 막대 칸 10은 1요소로 계산, 끝 경계 2, 구성 2줄(값 5), 자세히, 출처 1줄 압축은 펼침). 펼침 안 = 기존 정보 100% 보존. 기본 높이 390 약 380px(−55%), 1280 약 250px.

## 4. 토큰·간격
신규 토큰 0. 블록 `SECTION` 그대로, 내부 `space-y-4`(16px), 결론↔구간 줄 4px, 막대↔마커 영역 `mt-3`, 막대↔끝 경계 `mt-1.5`, 구성 줄 간 `gap-1`. 2단 `gap-x-8`(32px). radius 칸 `rounded-sm`, 외피 불변. press scale·모션은 자세히 버튼 기본(`active:scale-[0.96]`), 막대 진입은 외피 ENTER 공유(별도 없음). `transition: all` 금지. tabular-nums.

## 5. testId 변경
유지: `benchmark-block`·`-title`·`-grade-note`·`-sentence`·`-label`·`-source`·`-hidden-note`·`-top-note`·`-comp-*`·`-bars`·`-row-N`·`-mine-chip`(펼침 목록 안, 이름 유지). 신규: `benchmark-meter`(막대 `role=img`), `benchmark-meter-cell-N`(N=0..9, 내 칸 `data-mine="true"`), `benchmark-marker`(마커+칩), `benchmark-range`(내 구간 줄), `benchmark-comp-brief`(핵심 2줄 래퍼), `benchmark-comp-brief-household`·`-mine`, `benchmark-more-toggle`·`benchmark-more-panel`(`data-open`). 기존 `benchmark-bars`·`-comp`은 패널 안으로 이동(항상 마운트라 DOM 존재, 가시성 검사는 `aria-hidden`/`inert` 기준으로 갱신 필요 → 기존 테스트 수정 대상).

## 6. C104 폭 검수
핵심 4폭 360·390·430·1280(다크, 390 라이트 1장). 반응형 경계 `md`(768)가 새로 생기므로 **767·768 1쌍** 추가(767=1열, 768=2단 전환, 가로 스크롤 0·잘림 0). 1024(기존 `sm:max-w-xl` 제거 확인)는 선택 1장. main 대비 줄 수·높이 대조: 기본(접힘) 높이가 감소해야 한다.

## 7. 접근성
- 막대: 컨테이너 `role="img"` `aria-label="순자산 10개 구간 중 8번째 구간에 해당해요. 가구 100곳 중 약 10곳이 이 구간"`(구간 번호는 설명용이며 화면 문구에는 쓰지 않음 — planner 확인 요청: aria의 "N번째 구간"이 서열 완화 조건 위반인지). 칸·마커는 `aria-hidden`. 색만으로 구분하지 않도록 칩 텍스트 `내 구간` + 마커 모양 병행. 대비: `bg-foreground`/`foreground/15` vs 배경 라이트·다크 모두 3:1 이상(내 칸 ≈ 최대 대비, 나머지 칸은 보조 정보라 비텍스트 3:1 대상 아님이나 다크 `/15`가 약하면 `/20`으로 올린다).
- 자세히 버튼 `aria-expanded`·`aria-controls`, 히트 40px, 키보드 Enter/Space, 포커스 링 기본. 접힘 패널 `inert`.
- 구성 2줄: `<dl>` 대신 단순 `<p>` 2개(행 머리 + 값), 스크린리더는 `비슷한 가구, 예금·주식 등 19퍼센트…` 순으로 읽힘.

## 8. 문구·금지
존댓말·조언 없음. 새 문구: `자세히`(펼침 후 `접기`), `내 구간`, `비슷한 가구`, `나`. "상위·하위·평균보다·높다/낮다" 금지(결론 문장의 `이보다 높은 구간`은 기존 승인 문형). 내 금액·순자산 값 화면 표기 없음 유지(구간 범위는 통계 경계). `data-screenshot-hide` 불필요(성적표 캡처 영역 외) — 기존과 동일.

## 9. 품질 체크리스트 (qa)
1. 390·768·1280에서 첫 화면(접힘)에 결론 문장·막대·구성 2줄이 스크롤 없이(390은 스크롤 1회 이내) 보인다.
2. 1024·1280에서 블록 내용이 외피 폭 대부분을 쓴다(`sm:max-w-xl` 576px 제한 없음, 2단).
3. `benchmark-meter-cell-*` 10개, `data-mine=true` 정확히 1개, 부동산 미등록이면 0개.
4. 막대 안 칸 폭이 동일(±1px), 칩이 외피 밖으로 나가지 않음(첫·끝 칸 포함).
5. 접힘 상태 기본 노출 텍스트 단위 ≤ 12, 경계 금액 10행·표는 `자세히` 열면 모두 보인다(금액 열 포함).
6. 자세히 연타·열린 채 월 전환/리렌더에서 접힘 애니메이션 유지(재마운트 없음), 접힘 패널 `inert`.
7. "N번째·상위·하위·평균보다·많다/적다" 문구 0, 손익색 클래스 0, 신규 hex 0.
8. 767/768 전환에서 가로 스크롤 0, 360·390·430 모두 줄바꿈이 항목 단위(어절 중간 꺾임 0).
9. `role=img` 막대의 aria-label이 결론 문장과 일치, 자세히 버튼 40px 이상.
10. 라이트·다크 모두 내 칸과 나머지 칸 구분 가능(스크린샷 육안), `tabular-nums` 적용.
11. 구성 부채 행·보증금 `—`·주석 2줄이 펼침 안에 보존, 부동산 미등록 시 `benchmark-hidden-note` 표시·"나" 줄 없음.
12. 통계 상수 비어 있으면 블록 전체 미표시(`null`) 유지.


## 오케스트레이터 결정(11-14)
- 안 B(md 이상 2단) 채택.
- 막대 aria-label은 "N번째" 대신 화면 문장과 같은 문형(가구 100곳 중 약 N곳이 이 구간, 약 M곳이 이보다 높은 구간)을 쓴다 — 서열 표현 통일.
