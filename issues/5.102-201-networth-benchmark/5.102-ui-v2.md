## 1. 위치·트리

`<div data-testid="benchmark-comp">` 안: 소제목 → 기준 줄 → 표 → 주석 2줄. 소제목 `text-sm font-semibold text-foreground text-pretty break-keep`, 기준 줄 `text-xs text-muted-foreground tabular-nums mt-0.5`. 소제목 위에 v1 목록과 구분은 `pt-3 border-t border-border/50`(블록 내부 구획, 외피 새 카드 없음). 컨테이너 `sm:max-w-xl`.

## 2. 기준 줄 (조건 A)
`순자산 {범위} 가구(20%) 평균` — 범위는 `5,108만 미만` · `5,108만~1억 6,472만` · `1억 6,472만~3억 3,050만` · `3억 3,050만~6억 9,380만` · `6억 9,380만 이상`(P20·P40·P60·P80 파생). 0건: `전체 가구 평균`. 조각 nowrap: `순자산` / `{범위}`(`~` 앞뒤 각각 nowrap, `~`에서만 꺾임) / `가구(20%)` / `평균`. "분위" 글자 없음.

## 3. 표 — 4행 × 3열(대표 결정)
- `<table>` 시맨틱, `w-full text-sm tabular-nums`, `<caption class="sr-only">` = 소제목. `<th scope="col">` 열머리 `text-xs text-muted-foreground font-normal`, 행머리 `<th scope="row" class="text-left font-normal text-foreground">`.
- 열: 행머리 `1fr`, `가구 평균` 칸 `w-[5.5rem]`(88px, 최장 `13억 3,829만`), `가구 비중`·`내 비중` 각 `w-11`(44px, 최장 `140%`). 숫자 칸 전부 `text-right whitespace-nowrap tabular-nums`. 금액은 앱 기존 억·만 포맷터 재사용(새 포맷터 0), 열머리 `가구 평균`(값에 `만`·`억` 단위가 있어 `(만원)`은 중복이라 생략). 320px(콘텐츠 256px): 행머리 80px 확보 → `예금·주식 등`은 공백에서 2줄로 꺾일 수 있다(어절 중간 꺾임 금지, 허용). 가로 스크롤 0.
- 행 `h-9`(36px)→ 터치 요소 아님, 40px 규칙 비대상. 행 사이 구분선 없음(여백만), 헤더 아래 `border-b border-border/50`.
- **부채 행**(조건 구분선): `border-t border-border/50` + 행 위 `pt` 없이 `h-9` 유지. 합산 대상이 아님을 선만으로 전달, 라벨 변경 없음.
- 값: `가구 평균`·`가구 비중` `text-foreground`(`9,960만`·`18%`), `내 비중` `font-semibold text-foreground`. 둘 다 색·굵기 외 강조 없음. 손익색·화살표·막대·배경 서열 표현 0. 보증금 행 내 비중 `—` `text-muted-foreground`, `aria-label="앱에 없는 항목"`.
- 부동산 0건: `가구 평균`·`가구 비중` 2열만, 숫자 칸 2개. 소제목 `전체 가구의 자산 구성`, 기준 줄 `전체 가구 평균`. 표 폭은 같은 `sm:max-w-xl`, 숫자 칸 우측 정렬 유지(좌측 쏠림 방지로 표는 전폭).
- 부채 비중 100% 초과: 값 그대로(`140%`), 칸 64px에 들어간다(최장 `140%`).

## 4. 주석 (조건 C)
`CAPTION`(text-sm 아님 — `text-xs text-muted-foreground text-pretty break-keep`) 2개 `<p>`, 표 아래 `mt-2 space-y-1`.
1. `비중은 자산 합계 대비예요. 자동차·귀금속 같은 기타 실물자산 줄은 뺐어요.`
2. `전·월세보증금(세입자가 낸 돈)은 따로 등록하는 항목이 없어요. 현금으로 등록했다면 예금·주식 등에 들어가 있어요.` — 320에서 3줄 이하면 통과(2줄 목표, 실측 후 ui-review). 4줄이면 문구 재확인.
이하 출처 줄 v1 그대로(`(통계표 1~10, 12)` 추가).
