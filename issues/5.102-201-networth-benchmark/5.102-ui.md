# [5.102] 내 순자산이 어디쯤인지 · ui (ui-designer, 2026-11-13)

- 기준: direction 3절(합의)·challenge(축소). 코드 origin/main `views/activity/asset-report-view.tsx`, `layout/ui/report-section.tsx`, `composition-block.tsx`.
- 통계 값은 이 문서에 한 줄도 적지 않는다. 아래 라벨·수치는 전부 자리 표시(`A억~B억`, `p%`)다. 문구 확정은 spec, 여기서는 위치·줄바꿈·토큰을 정한다.
- preview 실측 없음(블록 미구현). 폭 계산은 코드 클래스 기준이며 ui-review에서 실측한다.

## 1. 위치·컴포넌트 트리 (위→아래)
'5축 측정' `SECTION` 닫힘 바로 뒤, 'AI 평가 프롬프트' 박스 앞. 부모 `CardContent space-y-4`를 그대로 받아 위아래 16px. `hasAssets` 분기 안이라 자산 0건이면 블록 없음(새 분기 0).

## 2. 분포 막대 목록 — 수치 (375 기준, 괄호는 320)
- 머리줄(`aria-hidden`): `flex justify-between text-xs text-muted-foreground` — 왼쪽 `순자산 구간`, 오른쪽 `가구 비중`. 아래 4px.
- `<ul aria-label="순자산 구간별 가구 비중" class="sm:max-w-xl">`, 행 간격 0. 순서는 낮은 구간이 위.
- 행 `<li>`: `-mx-2 px-2 grid grid-cols-[4.5rem_1fr_3rem] items-center gap-x-2 py-1 rounded-md`(높이 28px).
  - 라벨 칸 72px: `text-sm text-muted-foreground tabular-nums whitespace-nowrap`. 표기 = 가운데 구간 `A억~B억`, 최하 `A억 미만`, 음수 구간은 원문 표기 그대로, 최상 `B억 이상`. 최장 라벨이 72px를 넘으면 4px 단위로 칸을 넓힌다(열 폭은 한 값으로 고정, 행마다 달라지지 않게).
  - 막대 칸: 폭 187px(132px). 막대 `h-2.5 rounded-full`, 폭 = 그 구간 비중 ÷ 최대 구간 비중 × 100%(선형, 0 초과는 최소 4px). 트랙 배경 없음. `aria-hidden`.
  - 값 칸 48px: `text-sm text-right tabular-nums text-muted-foreground whitespace-nowrap`, 공표값 그대로 `p%`(반올림·재계산 금지).
- 색(신규 토큰 0, 손익 빨강·파랑·주황·brand 미사용 — 4.81 '내 기준값은 중립' 규약과 같은 판단, 주황은 경고 인상·brand는 액션 전용):
  - 일반 막대 `bg-foreground/25`. 값은 옆 숫자가 전달하므로 막대는 보조 표현이다.
  - **내 구간 행**: 행 배경 `bg-muted/40`, 막대 `bg-foreground`, 라벨 `font-semibold text-foreground`, 값 `font-bold text-foreground`. 라벨 아래 둘째 줄에 칩 `내 구간`(`SCOPE_MAIN` = `bg-foreground/10 text-foreground`, 기존 성적표 상수) → 행 `py-1.5`, 높이 약 54px. 색 + 굵기 + 글자 + 높이 4중 구분(색만으로 구분하지 않는다).
- 1280: 외피는 전폭, 목록만 `sm:max-w-xl`(576px) 좌정렬 — 막대가 800px 이상으로 늘어져 비중 차이가 과장돼 보이는 것을 막는다. 문장·캡션은 전폭. 열 폭·글자 크기는 모바일과 같다(§2 text-sm 공통).
- 다크: 토큰 그대로(`foreground` 반전). 일반 막대가 카드 면과 구분되는지 ui-review에서 4조합 확인.

## 4. 문구·줄바꿈 (C25, 320·375)
- 모든 산문에 `break-keep`. 숫자+단위 묶음은 `whitespace-nowrap` span: `100곳 중`, `약 N곳이`, `약 M곳이`.
- 라벨 줄은 3조각 각각 nowrap: `가구 기준` `· 등록한 자산 기준` `· {연도}년 조사`(연도는 상수 파생). 320에서 2줄이 되면 조각 경계에서만 꺾인다.
- 출처 줄: `자료: {기관} 「{조사명}」 {연도}년({기준일} 기준)` — 기관명 묶음·`「…」`·괄호 구간 각각 nowrap. 원문 확인 뒤 확정.
- 톤: 존댓말, 평가어(상위·하위·평균 이하·부자)·권유·목표·남은 금액·축하·위로·느낌표·이모지 0.
- `data-screenshot-hide` 대상 없음(조작 요소 0). 인증카드·AI 프롬프트에 블록 내용 미포함.

## 5. 인터랙션·접근성
- 블록 안 인터랙티브 요소 0 → 히트영역 40px 대상 없음. 행에 hover·press·cursor 효과를 주지 않는다(눌릴 것처럼 보이면 안 된다). `transition` 클래스 0.
- 스크린리더: 행의 라벨·값은 실제 텍스트라 그대로 읽힌다(`A억~B억 p%`). 막대만 `aria-hidden`. 내 구간은 보이는 칩 글자 `내 구간`으로 전달하고 그 `<li>`에 `aria-current="true"`. 부동산 0건에서는 `aria-current` 없음.
- 대비: 본문 `text-foreground`·`text-muted-foreground` 기존 토큰(4.5:1 이상), 출처 `/70`은 성적표 기존 보조 캡션과 같은 값. 다크·라이트 모두 색 의미 없이 명도만 쓴다.
- 포커스 순서 변화 0(탭 정지 0개 추가).

## 7. 품질 체크리스트 (qa 판정용)
1. 블록이 '5축 측정' 섹션 아래·'AI 평가 프롬프트' 위에 있고 위아래 간격이 이웃 섹션 간격(16px)과 같다.
2. 기본 상태에서 `data-mine="true"` 행이 정확히 1개, 부동산 0건에서 0개이며 `benchmark-sentence`·`benchmark-mine-chip`이 없고 `benchmark-hidden-note`가 1개다.
3. 블록 안에 `button`·`a`·`[role=button]`·`[tabindex]`가 0개다.
4. 블록의 계산 색에 rose·blue·orange·brand 인디고가 0건(막대·글자·배경 전부 foreground/muted 계열).
5. 320·375에서 새 문구 전부 어절 중간 줄바꿈 0(C25). `약 N곳이`·`100곳 중`·라벨 3조각·출처 묶음이 줄 사이에서 쪼개지지 않는다 — 기본·최상위·부동산 0건 3상태 모두.
6. 320에서 블록 가로 넘침 0(`scrollWidth === clientWidth`), 모든 행의 라벨·값이 잘림(…)·겹침 없이 1줄, 막대 칸 폭 ≥ 120px.
7. 모든 행의 라벨 왼쪽 x·값 오른쪽 x가 같고(열 정렬), 숫자 요소 computed `font-variant-numeric`에 `tabular-nums`.
8. 막대 폭이 비중에 선형(최대 구간 = 칸 100%), 화면 값 `p%`가 상수 공표값과 문자 단위로 같다. 값 합·경계는 vitest.
9. 최상위 구간에서 문장에 `이보다 높은`이 없고 `benchmark-top-note`가 보인다. 순자산 0 이하 픽스처에서 문형이 기본과 같고 '하위' 글자 0.
10. `등급 점수에는 반영되지 않아요.`가 제목 바로 아래, 라벨 줄(`가구 기준 · 등록한 자산 기준 · N년 조사`)이 3상태 모두, 출처 줄이 블록 맨 아래에 보인다. 블록에 내 순자산 금액 표기 0.

12. `prefers-reduced-motion`에서 진입 애니메이션 0, 블록 안 hover·press 변화 0.
13. C2: 제목·캡션·행 글자 크기와 섹션 radius·padding이 '5축 측정' 섹션과 같은 토큰이다(제목 14/16px bold, 본문 14px, 캡션 12px).

## 8. developer·spec에 넘기는 것
- 문구 확정본(spec)이 4절 길이 한도(안내 70자, 출처 1개 줄 묶음)를 넘으면 ui 재확인.
- 원문 구간이 14개를 넘거나 라벨이 `A천만~B천만` 꼴로 길어지면 열 폭·행 높이를 ui가 다시 정한다. 구간 5개 미만은 cto 재판정 대상(direction).
- `SCOPE_MAIN`은 성적표 로컬 상수다. 새 파일에서 쓰려면 같은 클래스 문자열을 가져다 쓰되 새 색 조합을 만들지 않는다(공용화 여부는 tech-review).
