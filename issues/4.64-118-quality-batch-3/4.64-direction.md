# 4.xx 품질 정돈 묶음 3 — 연 수익률 0 빨강·허브 손익 줄 320 끊김·맞추기 창 포커스 — direction

> GitHub 이슈 번호 미배정. 코드 기준 main 9a28a9f(v4.62). business-pm 사업 절 초안, 경험 절은 planner-designer.
> 성격: **p2 묶음**(LEARNINGS 10-29: 소규모 수정은 자율 과제 주력이 아님). 단독 우선순위를 주지 않고, '12월 결산 창 리허설' 이슈에서 수정 릴리스가 생기면 같은 릴리스에 싣는다. 리허설에서 결함이 0이면 단독 risk:low로 위임 머지한다.

## 사업 (business-pm 초안, 2026-11-09)

### 1. 왜 지금 — 리텐션(약), 첫 발견 없음
- 4.62가 손익 0을 회색으로 통일했는데, 같은 카드를 펼치면 `연 +0.0%`가 아직 빨강이다. 한 화면 안에서 "0은 회색" 규칙이 깨진다. 12월 결산 창에 상세를 다시 여는 사람이 보게 된다.
- 비용이 작고(표시·클래스 수준), 4.60·4.62 qa가 이미 재현 위치를 확정해 두어 조사 비용이 0이다.

### 2. 누구를 위해
- 매입가와 평가액이 같은 부동산·주식 보유자(연 수익률 0), 320px 소형 폰 사용자(허브 손익 줄), 키보드·스크린리더 사용자(맞추기 창 포커스).

### 3. 성공의 모습
- GA로 가를 수 없다. **qa 완료 기준이 주 판정**이다: ① 연환산 0(±0.05% 미만 표기 `0.0%`)이 회색·부호 없음 ② 320 허브 손익 줄 어절 중간 끊김 0 ③ 보유 현황·잔액 맞추기 창이 열리면 포커스가 창 안 ④ FAB 경유 창(부동산·현금 잔액 맞추기 등)을 닫으면 포커스가 '자산 업데이트' 버튼.
- 가드레일: CSV `보유 현황 맞추기 적용`·`잔액 맞추기 저장` 활성 사용자가 머지 뒤 0으로 떨어지지 않는다.

### 4. 하지 않으면 무엇을 잃나 — 약함(솔직히)
- 대상은 활성 수십 명 중 일부, 잃는 것은 "숫자가 이상해 보이는" 인상과 접근성 결함이다. 데이터 손실은 없다.
