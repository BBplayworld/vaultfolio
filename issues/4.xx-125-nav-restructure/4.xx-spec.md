# 4.xx #125 하단 네비 6칸 → 5칸 — spec

작성: planner-designer 2026-11-09 · 기준 코드 origin/main dc4133d · 근거 4.xx-direction.md(안 A, 합의), 4.xx-challenge.md(S1~S6)
위험 low · **대표 승인 대상**(위임 ⑦: PWA 주 네비 구조 변경 + 대표 채택 기능 진입 축소)

## 1. 문제
PWA 하단 네비 6칸 중 강조 버튼 '업데이트'가 4번째라 가운데가 아니고, 탭 순서(홈·상세·성과·업데이트·인증카드·더보기)가 스와이프 순서(`PAGE_ORDER` 홈→상세→성과→더보기)와 어긋난다. 가끔 쓰는 '인증카드'가 고정 칸을 차지하고, 하단 탭 열기는 GA·`recordVisit` 모두 기록되지 않는다.

## 2. 목표 행동
- PWA 사용자가 하단 5칸의 **가운데** '업데이트'로 업데이트 시트를 연다.
- 장소 탭 순서(홈·상세·성과·더보기)가 스와이프 순서와 같다.
- 인증카드는 더보기 › 도구 › '인증카드' 행(또는 홈 기능 팁)으로 열고, 열 때마다 기록된다.

## 3. 범위
- 포함: ① `bottom-nav.tsx` NAV_ITEMS 5칸(홈·상세·**업데이트**·성과·더보기), `screenshot` 항목·분기·`ShareScreenshotDialog` 제거 ② `tool-menu.tsx` `more-section-tools`에 '인증카드' 행(S1~S3) ③ top-bar 버튼 클릭에 `recordVisit("share-card")` 1줄(S6) ④ `app-features.ts` `share-card` 설명에서 '상단의' 위치 표현 제거(S5)
- 그대로: 브라우저 상단 바·FAB·튜토리얼, 홈 결산 팁·결산 화면, 웰컴, 업데이트 시트, 인증카드 대화상자·카드 내용, `PAGE_ORDER`·`getActiveId`, 9월 공지
- 도구 섹션 행 순서·행 이름·설명 문구는 ui-designer가 ui.md에서 확정(#124 '표로 복사' 포함 순서 고정, 권고: 세금 관리 → 인증카드 → 표로 복사)

## 4. 사용자 흐름
1. PWA(모바일) 홈 → 하단 5칸 표시, 가운데 '업데이트' 강조.
2. 가운데 탭 → 업데이트 시트 열림(기존과 동일 이벤트 `open-add-asset-sheet`).
3. '더보기' 탭 → 더보기 화면 → 도구 섹션 '인증카드' 행 탭 → 인증카드 대화상자가 더보기 화면 위에 열림.
4. 대화상자 닫기 → 더보기 화면 그대로.
5. PC PWA: 상단 가로 바(최대 600px)에 같은 5칸, 같은 순서.
6. 브라우저: 상단 인증카드 아이콘으로 기존과 같이 열림(+ 더보기 행으로도 열림).

## 5. 엣지 케이스
- **자산 0건/공유 대기**: 하단 네비·상단 바 숨김(기존). 더보기 행은 `hasAnyAssets` 거짓이면 숨김(S3).
- **체험 모드 PWA**: 업데이트·더보기가 빠져 3칸(홈·상세·성과), 인증카드 진입 없음 — 수용(체험 PWA 사실상 0, 브라우저 체험은 상단 아이콘 그대로). `justify-around`라 빈 자리 없음.
- **첫 사용자/기존 PWA 사용자**: 3번째 칸이 성과 → 업데이트로 바뀜. 오터치 시 시트만 열림(데이터 변화 0). 별도 공지 없음.
- **일부 갱신·오래된 데이터**: 무관(네비·진입 위치만 바뀜, 데이터 표시 무변경).
- **320px**: 5칸 × 최소 52px = 260px, 여백 확보.
- **대화상자 열림 중 FAB**: 더보기 행도 `screenshot-dialog-toggle`(open true/false)을 발송해 FAB 숨김 동작이 기존과 같다.
- **홈 기능 팁**: 어느 경로로 열어도 `share-card` 방문이 기록돼 이미 쓴 사람에게 '인증카드' 팁을 재추천하지 않는다. 결산 팁은 기능 팁보다 우선이라 영향 없음.

## 10. 대표 승인 요청 문안 초안 (owner-review 🟥 양식에 사용)
- **무엇**: 앱을 홈 화면에 설치해 쓰는 분들의 하단 메뉴를 6칸에서 5칸으로 줄입니다. '업데이트'를 가운데로 옮기고, '인증카드'는 더보기 › 도구로 옮깁니다. 인증카드 기능은 그대로이고 브라우저 화면은 바뀌지 않습니다.
- **왜**: 강조 버튼이 가운데에서 벗어나 있고, 탭 순서와 좌우 넘김 순서가 어긋나 있습니다. 인증카드 저장은 최근 4주 0건이라 고정 칸을 둘 근거가 약합니다. 인증카드를 열 때 기록이 안 남던 경로도 함께 고칩니다.
- **비용**: 설치 사용자는 인증카드까지 1번 → 2번 누릅니다. 체험 모드로 설치한 화면에서는 인증카드 진입이 없습니다(사실상 사용 없음).
- **위험**: 낮음. 저장 데이터·동기화와 무관하며, 되돌릴 때는 PR을 되돌리면 됩니다.
- **결정**: 머지 = 반영, 닫기 = 미반영.
