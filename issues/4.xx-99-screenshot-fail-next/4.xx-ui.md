### 3.2 문구 (최종)
- 날짜 확신: `{Y}년 말 값은 {M/D} 기록이에요 · 고치기` (예: `2025년 말 값은 12/20 기록이에요 · 고치기`). M/D는 0 패딩 없음(`tabular-nums`), 연도는 Hero 제목의 Y와 동일.
- 날짜 없음: `{Y}년 말 값은 자동으로 기록된 값이에요 · 고치기`.
- '12/31 종가' 같은 표현 금지(LEARNINGS 14). 투자 조언 0. `·`은 `aria-hidden`이 아닌 일반 텍스트(스크린리더가 "가운뎃점"으로 읽는 문제: 구분자 `<span aria-hidden>·</span>`로 처리).
- 320 줄바꿈(C25): 날짜 문구 약 25자, 날짜 없음 약 31자. 320(본문 약 288px, text-sm 14px, 한글 약 14px/자 -> 약 20자/줄)에서 2줄이 된다. **줄바꿈은 `· 고치기`가 한 줄에 고아로 남지 않게**: 문장 `{Y}년 말 값은 ... 기록이에요`를 한 덩어리로, ` · 고치기`는 `whitespace-nowrap`으로 묶어 끝에 붙인다(`<span className="whitespace-nowrap"><span aria-hidden>· </span><button>고치기</button></span>`). 이러면 2줄일 때 `고치기`가 둘째 줄에 같이 오고 어절 중간 끊김 0. 375는 날짜 확신 문구 2줄 가능(허용), 1280은 1줄.
- 높이 영향(C35): 캡션은 신규 줄 1~2줄(약 20~40px)이 연 탭 자동 prev 조건에서만 추가된다. 폭(320/375/1280) x 케이스(날짜 있음/없음) 행 높이를 ui-review 표로 main과 비교, 월·일 탭 diff 0 확인.

### 3.3 [고치기] 링크
- `<button type="button" className="inline-flex min-h-10 items-center align-baseline font-medium text-brand underline underline-offset-2">`: 기존 `YearlyAddLink`(`net-asset-chart.tsx:88`)와 **동일 클래스** 재사용(`min-h-10` 히트영역 40px, 인라인 줄 높이를 키우지 않도록 캡션 `<p>`는 `leading-5`, 버튼 `-my-2`로 시각 높이 보정 + 히트영역 확보). 대비: `text-brand`(인디고) on 배경. 라이트 `--brand` AA 4.5:1 이상, 다크는 밝은 인디고(`MAIN_PALETTE[0]` 다크 매핑) -> ui-review에서 computed 대비 측정. 밑줄로 색 비의존 식별.
- `aria-label`: `{Y}년 말 값 고치기`(짧은 '고치기'만으로 맥락이 없음). 클릭 = `handleEdit(prev)` -> 수정 대화상자(연도 잠김, 값 채움, 지난 연도 '자동'은 메모 빈 칸). 수정 대화상자 닫으면 포커스는 `고치기` 버튼으로 복귀(Radix 기본, 재마운트로 사라지지 않도록 캡션은 같은 key 유지).
- 저장 후 캡션 사라짐: 즉시 제거(fade-out 불필요). 높이가 줄어 아래 블록이 올라옴 -> 의도된 변화. 저장 중 깜빡임 방지를 위해 저장 완료 후 렌더(낙관 제거 금지).

### 3.4 모션·접근성
정적 텍스트, 등장 `motion-safe:fade-in duration-150`(탭 전환 때만; 이미 `ChangeHero`가 `contentKey` 기반 fade를 하면 그 컨테이너 안에 두어 **중복 모션 금지**). 스크린리더: `<p>` 일반 텍스트, 버튼 `aria-label`. `aria-live` 불필요.
