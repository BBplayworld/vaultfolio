## 2. 인계 호스트 확정 사양
- 파일: `src/app/(main)/_components/ratio/ratio-handoff-host.tsx`
- **마운트 시 1회** `peekHandoff()`. null이면 영구히 `null` 렌더(구독·`StockScreenshotImport` 마운트 없음). 인계가 없을 때 렌더 결과는 main과 같다.
- 열기 조건 순수 함수 `canOpenHandoff(s)`. 다음을 **모두** 만족해야 연다.
  - `isDataLoaded`
  - `!isPwaLocked()`
  - `!isSharePending`
  - `!wizardIsOpen`
  - `!isTrialMode()`: 방어용이다(체험 메모리 금고에 저장되는 것을 차단). 정상 경로에서는 동시에 일어나지 않는다
- `activeStep` 조건은 **없다**(Q2).
- 재평가 시점: 위 값 변화와 `PWA_UNLOCKED_EVENT`(`app-lock.ts`) 수신. `isPwaLocked()`는 반응형이 아니므로 이 이벤트를 반드시 듣는다.
- 열 때 `takeHandoff()`로 소비한다. 소비 결과가 null(만료)이면 열지 않는다.
- 렌더는 `<StockScreenshotImport open onOpenChange initialParsed={raw} onSaved={...} />`. 닫히면 호스트 state를 비워 언마운트한다.
- `onSaved`(기존 optional prop)에서 `track("feature_use", {category:"ratio_preview", method:"submit", result:"create"})`를 1회 보낸다. 컴포넌트 안에 GA 분기를 추가하지 않는다.

## 4. 서버 한도 확정 (spec 13절과 tech-review 표기 통일)
- 시그니처: `reserveGeminiCalls(request, n, limitMessage, pool?: { name: "ratio"; dailyLimit: number; perIpDailyLimit: number })`
- 키
  - 입구 IP: `rl:gemini-ratio:<ip>:<today>`
  - 입구 전역: `rl:gemini-ratio:<today>`
  - 둘 다 `incrementCounter`를 쓰고 TTL은 KST 자정까지
- 순서는 IP 일반 → 입구 IP → 입구 전역 → 전역(`reserveGeminiDaily`)이다. 실패하면 그 앞 단계를 전부 −n으로 되돌린다.
- 입구 판정 `isRatioEntry(request, entry)`
  - `entry==="ratio"`이면 입구다
  - 또는 Referer의 `pathname.replace(/\/$/,"") === "/ratio"`이면 입구다
  - 파싱 실패는 false
- 입구 요청은 **모든 429**(일반 IP·입구·전역)에 spec 5절 마감 문구를 쓴다. 문구는 route가 `limitMessage`로 넘기며, pool 인자는 문구를 갖지 않는다.

## 6. GA UTM 수정 (challenge·spec 7절 정정 — cto 자기 정정)
- **결함 의심 → 설계 정정**: `ga.ts`의 `track`·`trackScreen`은 모든 이벤트에 `page_location: pageLocation()`(= origin + `/v/<화면>`)을 **이벤트 단위로 덮어쓴다**. `send_page_view:false`라 세션 첫 hit는 `trackScreen("ratio")`의 page_view이고, 이 값에는 UTM이 없다. 그래서 인라인 gaConfig에만 UTM을 붙이면 캠페인이 귀속되지 않는다.
- 확정
  - 순수 함수 `src/lib/analytics/utm-allow.ts` `allowedUtmQuery(pathname, search)`: pathname이 `/ratio`일 때만 `?utm_source=…&utm_medium=…&utm_campaign=…`(허용 3키, 값 `^[A-Za-z0-9._-]{1,50}$`, 순서 고정)을 반환하고 아니면 `""`
  - `ga.ts` `pageLocation()` = 현재 식 + `allowedUtmQuery(window.location.pathname, window.location.search)`. `router.push("/")` 뒤에는 pathname이 `/`라 자동으로 붙지 않는다
- **루트 `layout.tsx` 인라인 gaConfig는 수정하지 않는다.** 정규식 복제와 문자열 대조 테스트(tech-review 5-2)도 필요 없어진다. `layout.tsx` diff는 OG_IMAGE import뿐이다.
- vitest 대상
  - 허용 3키 통과, 그 밖의 키·해시 제거
  - 값 길이 51·특수문자·인코딩된 `<`는 거부
  - `/ratio/`는 허용, `/ratio-x`·`/`는 `""`
  - `pageLocation`이 `/ratio`에서만 UTM을 포함
- GA4의 실제 캠페인 인식은 preview에서 GA가 꺼져 확인할 수 없다(알려진 한계 C9).
