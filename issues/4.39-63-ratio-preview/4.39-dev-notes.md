## spec과 어긋난/주의한 사실
1. `mapParsedStocks`는 design-final 3절의 "stocks 반환"과 달리 **공통 일괄 변환을 하지 않은 매핑 결과**를 돌려준다(호출자가 `applyCommonDefaults` 적용). 공통 변환 결함을 vitest로 고정하려면 둘이 분리돼야 해서다. 반환 키·`isMixed`는 동일. `usdRate` 옵션은 받지만 쓰지 않는다.
2. `ParsedStock`에 `originalCurrency`를 타입에 포함(서버 응답에 이미 있는 필드). 커밋 ③(`49f5d72`)에서 tsc 오류가 있는 채 push했고 직후 커밋 `9c4d24d`로 수정(amend 금지로 별도 커밋). 커밋 ④(`aac72bd`)도 GA 스냅샷·trial-guards 테스트가 실패한 채 push됐고 `2829518`에서 수정. 원인은 내 점검 스크립트의 종료 코드 누락이며 이후 게이트 스크립트로 전 커밋 통과를 확인했다.
3. `welcome-guide.test.tsx` PARAM_VALUES 스냅샷에 `ratio_preview` 1줄 추가(의도된 변경, 테스트 삭제·우회 아님).
4. `allowedUtmQuery`는 trial-guards 등 `window.location.pathname` 없는 window 스텁에서도 throw하지 않도록 비문자열 입력을 `""`로 처리.
5. 입구 풀 vitest는 파일 모드 메모리 카운터 공유 때문에 `beforeEach`로 입구 전역 카운터를 0으로 되돌린다.
6. 인앱 외부 이동 URL은 `origin + /ratio + 허용 UTM`. 이 URL로 열면 새 브라우저가 `/ratio`에서 다시 시작한다.
7. 환율 `JPY` 응답이 없으면 JPY 930 폴백 + fx 노트(해외 종목이 있을 때만) 표시. USD 실패 시 1380 폴백.
8. UI 사양 대비 단순화: 드래그&드롭 없음(사양 4절과 동일), 결과 진입 stagger는 행에만 적용, 막대 scale 전환은 rAF 1회 후 `grown` 플래그. Playwright preview 점검·ui-designer 검수는 이 실행에서 하지 않았다(preview URL 확인 전).
9. 서버 `RATIO_LIMIT_MESSAGE`는 route 모듈 상수(입구 요청의 모든 429에 적용). 다른 호출부(xray-classify)는 인자 생략으로 동작 불변.
