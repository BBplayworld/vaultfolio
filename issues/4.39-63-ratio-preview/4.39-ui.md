## 4. 인터랙션·모션
- **노드 유지 구조(C3)**: `<input type=file>`은 페이지 생애 내내 1개(sr-only, `ratio-file-input`). Dropzone·Result·Skeleton은 항상 마운트 + 높이 펼침 패턴(#4.35: 바깥 `grid motion-safe:transition-[grid-template-rows,opacity,visibility] duration-300 ease-out`, 닫힘 `grid-rows-[0fr] opacity-0 invisible inert`, 안 `min-h-0 overflow-hidden`). 상태 전환은 클래스 토글만 → 재마운트로 모션이 사라지지 않고, 전환 중 재탭은 현재 값에서 역전(인터럽터블). reduced-motion은 즉시.
- 전환 순서: idle → (파일 선택) loading: Dropzone 유지(내용만 교체)·Skeleton 펼침 → result: Skeleton 접힘 + Dropzone 접힘 + Result 펼침(동시 300ms). 오류 → Dropzone 유지·콜아웃만 `motion-safe:animate-in fade-in` 150ms.
- **결과 진입**: 요약·행에 `motion-safe:animate-in fade-in slide-in-from-bottom-1`(진입 한 번, subtle). 행은 `animationDelay = i*40ms`(최대 8행 320ms). 막대 fill은 `scale-x-0 → scale-x-100` `motion-safe:transition-[scale] duration-500 ease-out`(Tailwind 4.1 `scale` 속성 — 전환 목록에 `scale`), 펼침 시작 후 `requestAnimationFrame` 1회로 클래스 전환. reduced-motion은 처음부터 최종값.
- 다시 보기: "다른 사진으로 다시 보기"는 **파일 선택창을 바로 연다**(input.click). 선택 취소 시 결과 유지, 선택 시 loading 전이(결과는 접힘). 연타는 loading 중 무시(`disabled`).
- 결과 노출 후 포커스: 결과 요약 제목(`tabIndex=-1`)으로 이동, 오류 시 콜아웃(`role=alert`가 낭독). 스크롤은 결과 카드 상단이 헤더 아래에 오도록 `scrollIntoView({block:"start"})`(`motion-safe:smooth`).
- 누름: 모든 Button 기본 0.96 내장. `transition: all` 금지, `will-change` 미사용.
- 드래그&드롭은 v1 범위 밖(모바일 캡처 중심, spec에 없음).

5. 한글 문구 전체가 320·375에서 어절/가운뎃점 중간 줄바꿈 없음(computed `word-break: keep-all`) — 새 문구 전수(C25).
6. 모든 버튼·dropzone 히트영역 ≥40px, 키보드 Tab/Enter로 업로드→저장 완주, focus-visible 링 보임.
7. 결과에 금액(원·$)·평가 문구 0, 목록 % 합 100.0±0.1, 1~7종목/8종목 이상/국내만/해외만 4케이스 레이아웃 정상.
8. 노드 동일성: 업로드 반복(성공→다시 보기→성공) 동안 `ratio-file-input`·`ratio-dropzone`·`ratio-result` DOM 노드가 교체되지 않고 클래스만 변함(C3, Playwright 노드 비교).
9. 모션: 막대 `scale` 보간 샘플링으로 중간값 존재, 행 stagger 40ms, `prefers-reduced-motion`에서 즉시 최종값·스피너 정지.
10. 로딩 중 Skeleton 높이와 결과 높이 차이로 인한 레이아웃 점프(CLS) 육안 없음, 로딩 중 재선택 무시.
11. 오류 4종(empty/fail/limit/device) 콜아웃 문구가 spec 5절과 동일, limit·device는 dropzone 비활성(`aria-disabled`), 오류 후 재업로드 가능.
12. 인앱 UA(카카오톡·`barcelona`)에서 저장 버튼이 "브라우저에서 열어 저장하기"로 바뀌고 재업로드 안내 문장이 보임. 일반 UA는 brand 저장 버튼.
13. `SCREENSHOT_UPLOAD_NOTICE` 미렌더, 전용 고지가 dropzone 바로 아래에 있고 투자 조언·서버 단정 문구 0(C26).
14. 로고/헤더에 도메인·워터마크 문구 없음, 앱 안 진입 링크 없음.
15. 아무것도 조작하지 않은 첫 상태(SSR, JS 끔 포함)에서 h1·설명·고지·업로드 버튼이 보인다(LEARNINGS 2026-10-30).
