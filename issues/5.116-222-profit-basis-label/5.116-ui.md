# #222 ui — 국내·해외 날짜 맞춤 (XS, design-review)

근거: spec 3·4·8장, design-system §2(v5.114)·§6·§7, components.md InlineSelector. 신규 토큰·컴포넌트 0.

## 1. 컴포넌트 트리
- 성과 `기준 종가 비교` CollapsibleContent 안, 날짜 표 바로 위(기존 Switch 자리):
  `div.flex.items-center.gap-1.5.w-fit.ml-auto` > `InfoHint`(유지) + `InlineSelector`(재사용, 수정만)
- 기존 `bg-muted/40 py-1.5 px-2` 래퍼는 제거한다. 선택기 자체 배경(`bg-muted/60 dark:bg-muted/40`)이 있어 이중 박스가 된다(§동심 radius·박스 중첩 금지). 글자 3요소(글자/Switch/글자) -> 선택기 1개.
- 더보기 `표시` 섹션: 구조 유지. 이름 줄(제목 + InfoHint) 아래 선택기.

## 2. 선택기 형태 (히트영역 판정)
- 현재 더보기는 `size="sm"`(text-xs, py-1 = 높이 약 24px)라 히트영역 40px 미달. AC-7(40px)을 지키려면 **두 곳 모두 `fullWidth` + `tight`** 로 통일한다(칸 `min-h-10`=40px, text-sm, 썸 이동 모션·키보드 로빙 내장). `size="sm"` 제거.
- 성과: `className="w-[208px]"`(칸 각 약 104px). 더보기: `className="w-full"`(1280에서도 카드 폭 안, 늘어나도 무방).
- ariaLabel = 상수 name(`국내·해외 날짜 맞춤`). 로딩 전(`!hydrated`) 선택기 미렌더는 기존대로. 자리 점프 방지는 불필요(접힘/설정 안).

## 3. 설명 3줄 — InfoHint 유지
- 신규 UI 없음. InfoHint 팝오버/펼침을 그대로 쓰고 요약 + 설명 1~3을 상수 배열 map으로 그린다. 3줄째는 `text-muted-foreground`(보조), 1~2줄은 `<span font-semibold text-foreground>` 선택지명 + 본문(기존 모양 그대로). 성과 일별 환율 줄은 4번째로 기존처럼 덧붙임.
- 줄바꿈: 본문 `text-pretty`(어절 중간 끊김 금지, `break-keep`). 가장 긴 줄은 설명 2(약 60자) -> 320에서 4줄 이내 기대.
- (i) 히트영역 40px 미달 시 기존 InfoHint 트리거 규격 그대로 유지(이번 범위 밖, 변경 금지).

## 4. 폭별 기대 (한 줄·말줄임 없음)
산식: 칸 = 글자 + 좌우 4px. `같은 거래일` 6자 약 84px, `시장별 최신` 약 76px(14px 기준) -> 칸 최소 약 92px.
| 폭 | 성과 [(i)20 + gap6 + 208 = 234px] | 더보기 |
|---|---|---|
| 320 (카드 안쪽 약 256px) | 들어감(여유 약 22px). 안 들어가면 선택기를 `w-[184px]`로 줄이고, 그래도 안 되면 아래 대체 | 한 줄 |
| 360·390·430 | 한 줄 | 한 줄 |
| 1280 | 한 줄, 우측 정렬 유지(`ml-auto`) | 한 줄 |
- 모든 폭: 칸 높이 40px 이상, `truncate`로 잘리지 않아야 함(잘리면 FAIL).
- **대체 문구(320에서 실측 잘림 시만)**: `같은 날` / `각자 최신`(3자·4자). 의미: 같은 날짜 종가 / 시장마다 자기 최신 종가로 원 의미 유지하나 `각자`가 모호하다는 소지 있음 -> **적용 시 planner 재확인 표시 필요(의미 변경 경계)**. 설명 1·2 머리말도 같이 바꿔 AC-3 일치 유지.

## 5. 상태
기본(`같은 거래일` 선택) / hydrate 전 미렌더 / 주식 0개: 성과 표 미표시(기존) / 체험: 기존 저장 / 오류·로딩 상태 신규 없음. 선택 상태: 썸 `bg-card dark:bg-foreground/15 shadow-sm`, 선택 글자 `font-semibold`.

## 6. 모션·접근성
- 썸 translateX 200ms, 연타·중간 전환은 InlineSelector 내장(재마운트 없이 transform이라 모션 유지). `motion-safe` 내장. 같은 칸 재선택은 무동작.
- 날짜 표는 값 바뀌면 즉시 갱신(전환 모션 없음, 기존).
- role=radiogroup 류는 컴포넌트 내장, ←/→·Home/End 지원. 포커스 링 `ring-ring/50`.
- 다크: 선택 칸 `dark:bg-foreground/15`로 비선택(muted/40)과 구분, 글자 대비 4.5:1 이상.

## 7. 새 소식 1줄 (확정)
`국내·해외 날짜 맞춤 설정을 쉬운 이름으로 바꾸고, 성과에서도 같은 모양으로 고를 수 있어요.`
- 존댓말·금액·투자 판단 어휘 없음. business 방향 문안에서 `이름을 쉬운 말로 바꾸고` -> `설정을 쉬운 이름으로 바꾸고`(어색한 중복 `설정 이름` 정리). PR 본문 `새 소식: <id>` 1줄.

## 9. 품질 체크리스트 (qa 판정용)
1. 320·360·390·430·1280 x 라이트·다크 모두 `같은 거래일`/`시장별 최신`이 한 줄, 말줄임 0.
2. 두 곳 칸 높이(`getBoundingClientRect().height`) >= 40px.
3. 성과 펼침 안 Switch 0개, `bg-muted/40` 래퍼 박스 없음(박스 중첩 0).
4. 성과 선택기+(i)가 카드 밖으로 넘치지 않음(scrollWidth <= clientWidth, 320 포함).
5. 두 곳 이름·선택지·설명 요약·1~3줄 글자 동일(성과 일별 환율 줄만 추가).
6. 설명 본문 어절 중간 줄바꿈 0, 3줄째 보조색.
7. 선택 칸 썸이 선택값을 가리킴, 다른 곳에서 바꾼 뒤에도 일치(AC-4).
8. 같은 칸 재선택 시 썸 이동·GA 0건. 연타해도 썸이 정지 상태로 끝에 안착.
9. 키보드 ←/→로 이동, 포커스 링 보임. `prefers-reduced-motion`에서 썸 즉시 이동.
10. 다크에서 선택/비선택 칸 구분이 육안 확인 가능(비선택 글자 대비 >= 4.5:1).
11. 화면 문자열 `동일 영업일`·`KST 접속일`·`종가 기준 옵션` 0건.
12. 숫자 표(날짜·종가) tabular-nums·기존 정렬 변화 0, 표 머리 `(KST)` 유지.
13. CHECKLIST UI 항목(히트영역·다크·320) 재확인.
