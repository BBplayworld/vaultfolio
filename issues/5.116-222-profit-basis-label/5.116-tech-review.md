## 2. 상수 형태
```ts
export const PROFIT_BASIS_COPY = {
  name: "국내·해외 날짜 맞춤",
  summary: "국내·해외 종가를 어느 날짜로 묶어 더할지 정해요.",
  options: [{ value: "sameBusinessDay", label: "같은 거래일" }, { value: "kstAccessDay", label: "시장별 최신" }] as const,
  notes: [/* 설명1·2·3: { label?: "같은 거래일", text } */],
} as const;
```
- 옵션 배열은 두 화면이 **동일 참조**를 `InlineSelector options`에 전달(`readonly Option<T>[]` 수용, 복사 불필요). 설명 1·2의 굵은 라벨은 `options[i].label`을 재사용해 글자 불일치를 구조적으로 막는다.
- 성과 쪽: `<InfoHint>` + `<InlineSelector size="sm" ariaLabel={name} …>`을 기존 `flex … w-fit ml-auto` 래퍼에 넣고 `profitBasisHydrated`일 때만 렌더(기존 래퍼는 hydrate 조건이 없었음 → 조건 추가, 깜빡임 방지). 폭: 칸 2개 `text-xs px-1.5` 한 줄, 320에서 넘치면 ui 지시대로 글자만 축소.
