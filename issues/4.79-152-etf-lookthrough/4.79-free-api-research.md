# 4.79 무료 ETF 구성종목(holdings) 데이터 출처 조사

- 작성일: 2026-11-11 / 대상: #152 'ETF 속까지 합친 내 주식'
- 전제: 서버(Next.js API 라우트)에서 공개 데이터만 조회, 하루 1회 캐시. 사용자 보유 정보는 서버로 보내지 않음(ETF 코드 목록만 조회 키로 사용하거나, 인기 ETF 전체를 사전 캐시).

## 0. 조사 한계 (중요)
- 이 세션의 네트워크 정책상 **openapi.krx.co.kr, data.krx.co.kr, samsungfund.com, tigeretf.com, sec.gov, alphavantage.co, ishares.com 직접 접속 불가**(DNS 차단). 웹 검색 결과(색인된 페이지 발췌)와 기존 지식으로만 판단함.
- 따라서 아래 "확인됨"은 검색 색인 근거, "추정"은 지식 기반·미검증. **최종 채택 전 9장 게이트를 developer가 preview(Vercel) 서버에서 실제 호출로 확인해야 한다.**

## 2. 국내

### 2.1 KRX OPEN API (openapi.krx.co.kr)
- 접속 불가로 서비스 목록 직접 확인 못함. 서드파티 클라이언트(krx-rs `etp.rs`) 구조상 증권상품 카테고리는 **ETF/ETN/ELW 일별매매정보**(시세·NAV·기초지수명) 위주로, **PDF(구성종목) API는 없는 것으로 추정**.
- 약관: 인증키 신청 필수, API·데이터 저작권은 KRX, 위반 시 이용 철회. 시장데이터 이용정책 문서는 "제3자가 정보를 가공·저장·재분배할 수단 제공 엄격 금지" 문구 확인 → 앱 화면 노출은 회색지대.
- 출처: https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO005.jsp , https://docs.rs/crate/krx-rs/latest/source/src/data/etp.rs , https://data.krx.co.kr/inc/datasale/Market%20Data%20Usage%20Polices_ko.pdf

### 2.2 KRX 정보데이터시스템 ETF PDF 화면 (data.krx.co.kr)
- 국내 상장 ETF 전체 PDF를 일자별로 조회 가능(기사·운용사 안내로 확인). pykrx `get_etf_portfolio_deposit_file`가 내부 JSON(getJsonData.cmd)을 호출하는 방식.
- **위험**: 2025년 이후 KRX 웹 보안 강화로 pykrx의 비인증 요청이 400/세션 로그아웃을 받는다는 보고 확인. 공식 API 아님 + 재분배 금지 정책 → **운영 의존 부적합**. 유료 데이터 상품(데이터 마켓플레이스) 존재 여부·가격은 확인 못함.
- 출처: https://www.gpters.org/nocode/post/domestic-fear-greed-index-pANIWFxFxypMBEd , https://github.com/sharebook-kr/pykrx , https://github.com/sharebook-kr/pykrx/issues/193 , https://www.blockmedia.co.kr/archives/837611

### 2.3 공공데이터포털 금융위원회
- `금융위원회_증권상품시세정보`(15094806): ETF/ETN/ELW **시세만**(시가·종가·거래량 등). 구성종목 오퍼레이션 없음.
- 15151180은 `금융위원회_ESG지수정보`(지수 구성종목수 등)로 ETF PDF 아님. `KRX상장종목정보`(15094775)도 기본정보.
- 결론: **ETF 구성종목을 주는 공공데이터 API는 찾지 못함.**
- 출처: https://www.data.go.kr/data/15094806/openapi.do , https://www.data.go.kr/data/15151180/openapi.do , https://www.data.go.kr/data/15094775/openapi.do

### 2.4 자산운용사 홈페이지 PDF
- 국내 ETF는 매일 PDF 공시 의무 → 운용사 상품 상세에 "구성종목(PDF)" 표가 있음(확인: RISE 번호·종목명·종목코드·수량·비중·평가금액, 하나 PLUS/HANARO "PDF/자산구성내역", TIGER "구성종목(PDF)현황"+기준일 표기, ACE 상세 모달).
- 해외형(예: TIGER 미국S&P500)도 운용사 PDF에는 해외 종목이 포함되나, 식별자가 티커/ISIN/영문명 중 무엇인지는 운용사마다 다름(미확인).
- 엑셀/CSV 다운로드 버튼 유무·URL 패턴은 직접 접속 불가로 **미확인**. 삼성(KODEX)은 `m.samsungfund.com/sheet/…pdf` 형태 문서가 색인되나 이는 보고서 PDF로 구성종목 파일 아님.
- 약관: 자동수집·재배포 명시 허용 없음 → **스크래핑 위험**. 운용사 4~5곳 파서 유지보수 필요, 사이트 개편 시 중단. 국내 ETF 대부분(점유율 상위 운용사)은 커버되나 소형 운용사 누락.
- 출처: https://www.riseetf.co.kr/prod/finderDetail/4481 , https://www.hanaroetf.com/fund/43B6A0EDD99B490A , https://investments.miraeasset.com/tigeretf/ko/reference/list.do , https://www.aceetf.co.kr/modal/fund/K55101DU8887
- 참고(집계 사이트, 스크래핑 대상일 뿐 출처로 부적합): FunETF https://www.funetf.co.kr/product/etf/view/KR7360750004 — 비중은 설정현금 제외 현금성 자산 포함 계산 명시.

### 2.5 금융투자협회
- 협회 전자공시(dis.kofia.or.kr)는 펀드 공시 중심, ETF 일별 PDF API는 검색으로 확인되지 않음. 직접 접속도 못함 → **미확인**.

## 3. 미국

### 3.1 SEC EDGAR N-PORT (공식·무료)
- DERA가 N-PORT-P 원문을 분기 데이터셋으로 공개, 라이선스 us-pd(공공 도메인). 월말 기준 전체 보유종목(CUSIP/ISIN/이름/비중 pctVal/기준일).
- 공개 지연: 분기 3번째 달 기준 60일 후(2차 출처) → **최대 약 3개월 묵은 데이터**. 개별 EDGAR 제출 XML을 받으면 분기 데이터셋보다 빠르지만 그래도 월말+수십일.
- 티커가 없는 경우가 있어 CUSIP→티커 매핑 필요. EDGAR는 User-Agent 명시·초당 10회 제한.
- 출처: https://www.sec.gov/data-research/sec-markets-data/form-n-port-data-sets , https://catalog.data.gov/dataset/form-n-port-data-sets , https://sec-api.io/datasets/form-nport

### 3.2 발행사 홈페이지 CSV/XLSX
- iShares: 상품별 `…/products/<id>/<slug>/latest-holdings.csv`(또는 `1467271812596.ajax?fileType=csv&fileName=<TICKER>_holdings&dataType=fund`) — 티커·비중·기준일("as of") 포함 확인.
- SPDR(SPY 등): 상품 페이지 "Download Daily Holdings"(xlsx) 존재 확인, 정확한 URL은 스크립트 생성으로 미확인.
- Invesco(QQQ)·Schwab(SCHD)·Vanguard(VOO): 공식 다운로드 경로 검색 미확인. Vanguard는 월 1회 공개로 알려짐(추정).
- 약관: 자동 수집·재배포 허용 문구 없음. 발행사별 포맷 상이 → **스크래핑 위험·유지보수 비용 큼**.
- 출처: https://www.ishares.com/us/products/239742/ishares-global-financials-etf/latest-holdings.csv , https://www.ssga.com/us/en/intermediary/etfs/state-street-spdr-sp-500-etf-trust-spy , https://www.schwabassetmanagement.com/resource/schd-portfolio-holdings

### 3.3 Alpha Vantage ETF_PROFILE
- 공식 문서에 "ETF Profile & Holdings"(순자산·보수·회전율·holdings·섹터/자산배분) 존재. holdings 비중은 소수(최대 4자리)로 반환된다는 2차 실측 보고.
- 무료 키 25회/일(2차 출처) → 하루 1회 캐시라면 ETF 25종/일. **holdings 개수 상한(상위 N 여부)·기준일 필드·상업 이용 허용 여부 미확인**.
- 출처: https://www.alphavantage.co/documentation/ , https://qveris.ai/guides/free-etf-holdings-api/ , https://eulerpool.com/blog/alpha-vantage-alternative

### 3.4 FMP / Finnhub / Twelve Data
- FMP: `/stable/etf/holdings?symbol=SPY`(전체·비중·`date` 파라미터로 과거). 무료 250회/일(2차 출처)이나 holdings 엔드포인트의 무료 플랜 포함 여부 공식 확인 못함(지식상 유료 플랜 전용 추정). https://site.financialmodelingprep.com/developer/docs/stable/holdings
- Finnhub: `/etf/holdings`(symbol 또는 ISIN, date) — 지식상 **프리미엄 전용**. https://docs.rs/crate/finnhub/0.2.2/source/src/endpoints/etf.rs
- Twelve Data: `/etfs/world/composition` — ISIN/CUSIP은 애드온, FIGI는 Ultra 이상. 지식상 상위 플랜 전용. https://qveris.ai/tools/twelvedata.etfs.world.composition.retrieve.v1.fa2aaf4c
- 결론: **무료 조건으로는 채택 불가 추정**(게이트로 1회 확인).

### 3.5 Yahoo (비공식)
- `v10/finance/quoteSummary?modules=topHoldings` — 상위 10개·비중만, 기준일 불명. 약관상 상업 이용 불가, 크럼/쿠키 차단 빈번 → **채택 금지**.
- 출처: https://ranaroussi.github.io/yfinance/reference/api/yfinance.scrapers.funds.FundsData.html

## 4. 결론
- **무료·공식·상업 허용·국내 전체 구성**을 동시에 만족하는 출처는 **찾지 못했다.** 국내 PDF의 사실상 원천은 KRX 정보데이터시스템과 운용사 홈페이지뿐이며 둘 다 공식 API가 아니다.
- 미국은 SEC N-PORT가 유일하게 무료·공식·재배포 가능이나 지연이 크다.

## 5. 권고 조합
- **1순위(축소 범위)**: 국내 주식형은 **KIS 상위 30**(이미 연동, 대형 지수형은 상위 30이 비중 대부분) + "상위 N개 기준·기타 n%" 명시. 미국 ETF는 **SEC N-PORT 월말 기준**(기준일 표기, "최대 약 3개월 전" 안내). 국내 해외형(360750 등)은 **기초지수 동일 미국 ETF의 N-PORT 비중을 대용**(예: S&P500 추종 → SPY/VOO 비중, 나스닥100 → QQQ)으로 근사하고 "추정" 라벨. 스크래핑 0, 공식 출처만.
- **대안 A(정확도 우선, 위험 수용)**: 국내 상위 5개 운용사(삼성·미래·KB·한투·신한/키움) 홈페이지 PDF 하루 1회 수집. 운용사별 파서 + 실패 시 KIS 상위 30 폴백. 약관 회색지대 → cto 위험 판정·대표 확인 대상.
- **대안 B(미국 최신성)**: Alpha Vantage 무료 키로 인기 미국 ETF 20종 이내 하루 1회(25회/일 한도) — 게이트 통과 시에만.
- **제외**: KRX 정보데이터시스템 내부 호출(차단 보고·재분배 금지), Yahoo, FMP/Finnhub/Twelve Data 유료 플랜.

## 6. 앱에서 실제 확인할 게이트 (developer, preview 서버에서)
1. KRX OPEN API 서비스 목록에 ETF PDF/구성종목 API가 있는지(로그인 후 목록 확인) — 있으면 1순위 교체.
2. SEC EDGAR: SPY·VOO·QQQ·SCHD의 최신 NPORT-P XML 수신 가능 여부, 기준일(repPdDate)과 오늘 차이, Vercel 서버에서 User-Agent 지정 시 403 없는지.
3. N-PORT CUSIP→티커 매핑 방법(SEC company_tickers는 발행사 기준이라 부족 → 종목명/ISIN 매칭 정확도 측정).
4. 국내 해외형 근사: 360750 ↔ SPY/VOO 상위 10 종목·비중 차이 ±1%p 이내인지(운용사 PDF 화면과 수기 대조 1회).
5. KIS 상위 30이 국내 주식형 대표 ETF(069500·102110·KRX300 등) 비중 합계의 몇 %를 덮는지 측정 — 80% 미만이면 "기타" 표기 UX 필수.
6. Alpha Vantage ETF_PROFILE(QQQ, SPY): holdings 개수(전체 vs 상위 N), 기준일 필드 유무, 약관 상업 이용 조항.
7. FMP `/stable/etf/holdings` 무료 키 호출 시 데이터 반환 여부(402/403이면 제외 확정).
8. 운용사 PDF(대안 A 검토 시): 각 사 엑셀/CSV 다운로드 URL·robots.txt·이용약관의 자동수집 조항, 해외 종목 식별자(티커/ISIN) 형식.
9. 모든 경로: 요청에 사용자 보유 수량·금액이 포함되지 않음(ETF 코드만) — 절대 규칙 점검.
