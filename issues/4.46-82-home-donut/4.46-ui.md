## 1. 조각 라벨 (홈 = screenshotMode=false 전용)
- 내용: **이름 / %** 2줄. 금액 제거(정본은 범례, spec §7).
- 타입: 이름 `fontSize 11 · bold`(캡션 단계, 차트 라벨 예외), % `fontSize 13 · bold · tabular-nums`(SVG는 `style={{fontVariantNumeric:"tabular-nums"}}`). 두 줄 모두 `x={x}` 동일(현재의 `x-1`·`x+3` 광학 보정 삭제, 가운데 정렬), 줄 간격 `dy`: 이름 `-7`, % `+15`(박스 높이 약 28px). % 반투명(0.85) 제거 — 알파가 대비를 깎는다.
- 위치: 기존대로 링 중간 반지름(55~130, 두께 75 → r=92.5). 도넛 크기·높이 무변경(320도 같은 반지름, 260px 차트).
- **표시 기준 = "라벨 상자가 조각 안에 들어가는가".** 상자 폭 w ≈ 이름 글자수×11(+2), 높이 28. 전 방향(조각이 어느 각도에 놓여도) 들어가는 최소 비율을 계산(반지름 1px 여유, 샘플 격자 검사): 이름 3자(w34) 9%, 4자(w46) 10.5%, 5자(w56) 12%. 구현 근사 상수:
  `const DONUT_LABEL_MIN_PCT = (name: string) => 9 + Math.max(0, name.length - 3) * 2;` → 3자 9 / 4자 11 / 5자 13. `pct < DONUT_LABEL_MIN_PCT(name)`이면 `null`. 기존 `pct<5` 대체.
- 결과: 5.0%(금융자산)·3.0%(부채) 라벨 없음 → 범례에서만. [80/12/8]은 12% 금융자산(4자 11% 통과) 라벨, 8% 부채(2자, 9% 미만) 없음. [50/50] 둘 다. [100] 1개. 선택 필터 상태는 선택 조각만 + 같은 기준.
- 도넛 가운데 텍스트·SVG 구조·`screenshotMode` 렌더는 무변경: `DonutLabel`에 `legacy={screenshotMode}` prop을 받아 true면 현재 코드 그대로 반환(웰컴 SVG outerHTML 동일 보장). testid도 `!screenshotMode`일 때만 부여(SVG outerHTML 차이 방지).

## 3. 외곽 링 제거
- 원인: `stroke="var(--card)"`(Pie·Cell 모두) vs 홈 카드 `contentCard` 투명 → 실제 바탕 `--background`.
- 변경: 홈(`!screenshotMode`)에서 Pie·Cell `stroke="var(--background)"` 두 곳 모두. `strokeWidth={2}` 유지(조각 사이 2px 배경색 간격, 인접 조각 선이 겹쳐 2px로 보임). 바깥·안쪽 가장자리의 선은 배경과 같은 색이라 보이지 않음. `screenshotMode`는 기존 `var(--card)` 유지(웰컴 동일). 선택 상태 `activeShape`는 이미 stroke 없음.
- 라이트 #F0F2F4·다크 #0B0D12 배경 위에서 육안 링 0이어야 함.

## 4. 범례 정렬
현재: `flex gap-1 px-1.5 py-2`, 금액 `ml-auto`, `(pct%)` 폭 가변, tabular-nums 없음.
변경(홈 전용 클래스 분기, `screenshotMode`는 hidden이라 영향 없음):
- 행: `flex items-center gap-2 min-w-0 min-h-10 px-1.5 rounded-md cursor-pointer` (py-2 제거). 컨테이너 grid `gap-y-0 gap-x-2 grid-cols-1 sm:grid-cols-2`(gap-y-1→0). 이유: 행 36px+gap 4px=40px 피치였던 것을 행 40px+gap 0으로 바꿔 **카드 높이 증가 0px**, 히트영역은 40px 확보(§7).
- 이름: `truncate text-sm text-foreground min-w-0`(5자 이름·320에서도 말줄임, 어절 중간 줄바꿈 없음 `whitespace-nowrap`).
- 금액: `ml-auto text-sm tabular-nums whitespace-nowrap`(색 기존 유지 liability/default).
- %: `w-[4.5rem] shrink-0 text-right text-sm font-bold tabular-nums` + 기존 `style={{color}}`. 폭 4.5rem=72px(14px bold "(100.0%)" 약 62px 여유) → 금액 끝 x가 모든 행에서 동일, % 열 정렬. 괄호 문구는 유지(문구 변경 0).
- 320 폭(약 288px 행) 예산: 점10+gap8+이름≤56~70+금액≤75+gap8+%72 ≈ 240 → 여유 약 45px, 초과 시 이름이 말줄임.
- 1280 2열: 각 열 안에서 동일 규칙(열마다 금액 끝 동일).
