# 4.46 홈 도넛·범례 정돈 — 명세 (#82)

방향: `4.46-direction.md`. 대상 파일 예상: `src/app/(main)/_components/views/home/dashboard.tsx`의 `DonutLabel`·`AssetDonutChart` 범례(홈 경로만). 시각 사양(라벨 크기·간격·색 값)은 ui-designer `4.46-ui.md`(11/20까지, 미완이면 #82는 4.48).

## 1. 문제
홈 도넛에서 5~12% 조각의 3줄 라벨이 조각 경계를 넘고, 흰 글씨가 황금·초록·빨강 조각 위에서 대비 4.5:1 미만이며, 투명 카드 위 `--card` 색 스트로크가 링으로 보이고, 범례 금액 열이 줄마다 어긋난다.

## 2. 목표 행동
사용자가 홈 도넛에서 큰 조각은 라벨로, 작은 조각은 범례로 이름·금액·%를 막힘 없이 읽는다. 기존 필터 이동(조각·범례 누름)은 그대로 한다.

## 3. 범위
- 포함: 라벨 표시 규칙·내용(이름+%), 라벨 글자색, 조각 경계 처리, 범례 열 정렬.
- 제외: 1280 재배치·도넛 높이·우측 공백, 팔레트·조각 배정, 최소 각도 보정, 웰컴 미리보기(`screenshotMode`), HomeTipBox, 결산 화면, 데이터 계산, GA 계측.

## 4. 사용자 흐름
1. 자산 보유자(또는 체험 모드)가 홈에 들어온다.
2. 도넛 가운데 순자산, 들어갈 수 있는 조각에만 "이름 / %" 2줄 라벨이 보인다.
3. 들어가지 않는 조각은 라벨이 없고, 아래 범례에서 같은 이름·금액·%가 보인다.
4. 조각 또는 범례 줄을 누르면 기존처럼 해당 필터로 바뀌고 나머지가 흐려진다.

## 5. 엣지 케이스
- 항목 1개(부채 없음·금융자산만): 100% 조각 1개, 라벨 1개, 스트로크 링 없음.
- 50:50 등 큰 조각만: 모두 라벨.
- 아주 작은 조각(0.1~1%): 비율 그대로 얇게, 라벨 없음, 범례에 표시. 크기 보정 없음.
- 경계값: 라벨 판정은 고정 %가 아니라 "라벨 상자가 조각 안에 들어가는가" 기준(구현은 임계 %로 근사 가능, 근사값은 ui.md에 명시). 5.0% 정확값 픽스처 포함.
- 금액 가리기·큰 금액(억 단위 3자리): 라벨에 금액이 없어 영향 없음, 범례 열 폭이 넘치지 않음.
- 필터 선택 상태: 선택 조각 라벨만 표시(기존 규칙 유지)도 같은 겹침 규칙을 따른다.
- 첫 사용자(자산 0): 웰컴이 뜨므로 대상 아님. 웰컴 미리보기 도넛은 변화 없음.
- 오래된 데이터·일부 갱신: 값 계산 무변경이라 해당 없음.

## 6. 완료 기준 (qa 관찰 가능)
1. 픽스처 [92/5/3], [80/12/8], [50/50], [100], [60/39.9/0.1]에서 표시된 모든 조각 라벨의 텍스트 경계 상자가 해당 조각(내·외 반지름과 시작·끝 각으로 이룬 영역) 안에 완전히 들어간다(SVG getBBox 기하 검사, 320·375·1280).
2. 라벨 글자색과 조각 채움색의 대비가 모두 4.5:1 이상이다(WCAG 상대 휘도 계산값 목록 기록). 참고: 흰색은 인디고 4.7만 통과, 황금·초록·빨강은 어두운 글자 필요.
3. 라벨은 이름과 %만 있고 금액이 없다. 금액·%는 범례에 모든 조각에 대해 있다.
4. 라이트·다크 모두 도넛 바깥·안쪽 가장자리에 주변 배경과 다른 색의 링이 없다(조각 사이 구분은 배경색 간격 또는 동일 처리, ui.md 기준).
5. 범례 각 줄의 금액 끝 x좌표가 줄 사이 ±1px 이내로 같고, %도 같은 열에 정렬되며 숫자에 tabular-nums가 적용된다(1280 2열이면 열마다). 320에서 범례 줄 넘침·어절 중간 줄바꿈 0(C25).
6. 범례 줄 높이 40px 이상, 누르면 기존과 같은 필터로 바뀐다.
7. 375·1280에서 도넛 카드 높이 변화가 +16px 이하이고 HomeTipBox가 같은 순서로 보인다(측정값 기록).
8. `git diff main`에서 `welcome-guide.tsx`·`(main)/page.tsx`·`home-tip-box.tsx`·`settlement-view.tsx`·`asset-change-view.tsx` 0줄, 웰컴 미리보기 도넛 SVG outerHTML이 main과 문자열 동일.
9. 저장 키·스키마·GA 이벤트·문구 변경 0(위임 머지 ④⑤).
10. 320·375·1280 × 라이트·다크 스크린샷 12장(홈) + 웰컴 375 1장을 ui-review에 첨부.
