# 4.xx 이어서 맞추기 — ui (ui-designer, 2026-11-09)

> 기준: origin/main `floating-add-button.tsx` holdings 단계, design-system §1·§3·§5·§6·§7·§11. **신규 색·토큰·컴포넌트 0.** 재사용: `Sheet`, `Button variant="brand"`, lucide `Check`(§11 선택 ✓ = `text-brand`), 시트 `ENTER` 클래스.

## 0. planner와 충돌·결정 지점
1. **'맞춤' 표시**: direction은 "체크 아이콘 1개, 문구 없이", spec은 "`오늘 맞춤` + ✓". → **✓ 아이콘 + 보조 문구 `오늘 맞춤` 병기로 확정.** 이유: 색(brand)만·아이콘만으론 스크린리더·색각 구분이 약하고, 보조 줄 자리는 어차피 `업데이트`가 차지하던 곳이라 폭·높이 증가 0. direction의 "문구 없이"는 폐기 요청.
2. **결산 '다음 달 준비' 진입**: 화면 UI diff 0이고 도착 후 흐름만 바뀜 → v1 **포함 권고**(디자인 비용 0, 같은 플래그). 제외는 planner/developer 판단.
3. **상단 1줄 `{자산군} 맞췄어요`**: 토스트와 같은 사실의 반복이지만 시트가 다시 열린 맥락 설명이라 유지. 단 금액·건수 없음.
4. spec §4-2 '미보유 보조 문구 `추가`'는 현행 `업데이트`를 대체. 부동산·실물은 보유 시 `업데이트`, 미보유 시 `추가`.

## 2. 행 사양 (기존 행 클래스 유지, 변경점만)
- 컨테이너: `flex items-center gap-1 rounded-lg bg-card dark:bg-muted overflow-hidden` 불변. 메인 버튼 `py-3 px-3` → 높이 ≥ 56px(텍스트 sm+xs 2줄), 히트 ≥40 충족. 연필 버튼 `p-3`+size-4 = 40×40 불변.
- 아이콘: 보유 `text-primary`(현행), **미보유 `text-muted-foreground`**(약화). 라벨은 두 경우 모두 `text-sm font-medium truncate` 불변(가독 대비 유지).
- 보조 줄(`text-xs text-muted-foreground`, 기존 자리, 신규 text-xs 아님): 보유·오늘 미맞춤 `업데이트` / 보유·오늘 맞춤 `오늘 맞춤` / 미보유 `추가` / 과거 순자산 `기록`.
- **오늘 맞춤 ✓**: 우측 chevron 앞에 `Check` `size-4 text-brand shrink-0`(aria-hidden), 행 버튼 `aria-label="{라벨}, 오늘 맞춤"`. chevron 유지(다시 누를 수 있음). 행 배경·테두리 변화 없음(색 추가 금지).
- 오늘 판정: `lastRefreshedAt(category)`의 KST 날짜 == 오늘 KST. 부동산·실물·과거 순자산은 ✓ 없음.

## 5. 인터랙션·모션 (CSS, `motion-safe`)
- 복귀 = 시트 **새로 열림**(Sheet 기본 슬라이드/페이드 불변). 복귀 진입에서는 행 stagger를 **끄고**(`animationDelay` 0, ENTER 클래스 생략) 시트 전환만 쓴다 — 방금 보던 목록이 다시 나타나는 것이라 7행×40ms 재생은 지연으로 느껴짐. 일반 진입은 현행 stagger 유지.
- 복귀 진입의 강조는 **상태 줄 1곳**만 `motion-safe:animate-in motion-safe:fade-in motion-safe:duration-300`, ✓는 해당 행에서만 `motion-safe:animate-in motion-safe:zoom-in-50 motion-safe:duration-200`(최초 1회). reduced-motion은 즉시 표시.
- 재마운트 주의: 상태 줄은 조건부 렌더(진입 시 1회 애니메이션이 목적이라 의도적). ✓는 행 key=type 안에서 mount되므로 같은 시트 세션 안에서 다른 행을 눌러도 이미 표시된 ✓가 다시 튀지 않는다(시트가 닫혔다 열릴 때만 재생).
- 연타: 저장 신호가 연속 2회 와도(일부 경로 중복 호출) 시트는 이미 열린 상태면 무시, 플래그는 첫 신호에서 소비. 시트가 닫히는 중(Esc·드래그)에 신호가 오면 닫힘 의도 우선 — 플래그가 이미 해제된 상태여야 한다.
- 포커스: 복귀 시 시트 내 **첫 미맞춤 보유 행 버튼**으로 이동(없으면 [완료]). 닫힘 시 FAB 버튼으로 복귀(품질 묶음 (b)와 동일 규칙). 키보드: Tab 순서 = 상태 줄(비포커스) → 행 → 연필 → [완료], Esc 닫힘.
- 누름 피드백: 행 버튼 `active:scale-[0.98]` + `transition-[background-color,scale]`(현행에 없으면 추가; 카드류 0.98).

## 6. 접근성
- 상태 줄 `role="status"` `aria-live="polite"`(시트 열림과 함께 읽힘). ✓ 아이콘 aria-hidden, 의미는 행 aria-label과 보조 문구로 전달.
- 히트영역: 행 메인 버튼 ≥56px, 연필 40×40, [완료] 44px.
- 대비: `text-brand`(#5b6fbf)는 라이트 bg-card 위 3:1 이상(아이콘 용도), 문구는 foreground. 다크 `bg-popover`/`bg-muted` 행 위에서도 동일 토큰 → 별도 값 없음. 약화 아이콘(`muted-foreground`)은 장식이라 가독 필수 아님.

## 7. 문구 (최종, 존댓말, 투자 조언 없음)
- 상태 줄: `주식 맞췄어요` / `암호화폐 맞췄어요` / `현금성 자산 맞췄어요` / `대출 맞췄어요` / `보유한 자산을 모두 맞췄어요`
- 행 보조: `업데이트` · `오늘 맞춤` · `추가` · `기록`
- 버튼: `완료`
- `data-screenshot-hide`: 해당 없음(시트는 인증카드 캡처 영역 밖).

## 9. 진입 경로별 동일성
홈 최신화 팁(`open-add-asset-sheet`+category)·결산 '다음 달 준비' 행·FAB 직접 진입 모두 저장 성공 후 **같은 시트 화면**(§4 복귀 진입)으로 돌아온다. 도착 화면(팁·결산)의 UI는 변경 0. 마법사(`directInput="add"`)·상세 탭 편집·거래 스크린샷은 복귀 없음.

## 10. 품질 체크리스트 (qa 판정용, 320/375/1280 × 라이트/다크)
1. 보유 주식·현금 데이터에서 holdings 행 순서가 주식·현금 → 부동산·암호화폐·실물·대출 → 과거 순자산이다(testId 순서 대조).
2. 미보유 행은 보조 문구 `추가`, 아이콘 색이 `muted-foreground`, 보유 행 아이콘은 `text-primary`다(computed color 상이).
3. 보유군과 미보유군 사이에만 헤어라인 1줄이 있고, 한쪽이 0이면 없다.
4. 저장 성공 직후 시트가 holdings로 열리고 탭 0회로 상태 줄 `{라벨} 맞췄어요`와 해당 행 ✓(`text-brand`, `오늘 맞춤`)가 보인다.
5. ✓가 생겨도 행 순서가 바뀌지 않는다(저장 전·후 testId 순서 동일).
6. 모든 보유 4종 맞춤 후 상태 줄이 `보유한 자산을 모두 맞췄어요` 1줄(320에서도 어절 중간 줄바꿈 없음, C25).
7. 복귀 진입 하단은 [완료] brand 버튼(높이 ≥44px), 일반 진입은 [이전으로]다. [완료]·Esc·바깥 탭으로 닫으면 재열림 없음.
8. 창을 취소로 닫으면 시트가 열리지 않는다. 상세 탭 편집·마법사 저장도 열리지 않는다.
9. 모든 행 메인 버튼 높이 ≥40px, 연필 40×40, 행 내 텍스트 1줄(320 포함), 가로 스크롤 0.
10. 복귀 진입에서 행 stagger 없음(행 `animation-delay` 0·ENTER 클래스 없음), 상태 줄만 페이드. reduced-motion 에뮬레이션에서 전부 즉시 표시(C3: computed style로 판정).
11. 같은 시트 세션에서 다른 행 선택 → 창 → 저장 후 복귀 시 이전 ✓가 유지되고 새 ✓가 추가된다.
12. 복귀 시 포커스가 첫 미맞춤 보유 행(또는 [완료])에 있고, 닫으면 FAB 버튼으로 돌아온다.
13. 신규 색 hex·`transition: all`·신규 컴포넌트 파일 0(diff 확인), 새 localStorage 키 0.
14. 어제 맞춘 자산군에는 ✓가 없다(날짜 모킹 가능 시), 자정 넘김은 다음 열기에서 반영.
15. 인터랙션 후 C46: 승인 뒤 문구·UI 증분은 커밋 해시와 함께 ui-review에 기록.
