# 4.xx 이어서 맞추기 — spec (planner-designer, 2026-11-09)

> direction 합의 완료(business-pm·planner-designer, 수정안 1·2 및 design-review 결정 반영). 코드 기준 origin/main 41fbc03. FAB 파일은 4.58(issue-4.56)과 겹치지 않음(diff 0) → 4.58과 병렬 개발 가능.

## 1. 문제
자산군 2개 이상 보유자가 월말에 숫자를 맞출 때, 자산군 하나를 저장할 때마다 FAB 시트가 닫혀(`floating-add-button.tsx:137-140`) 자산군당 3~4탭을 반복하고 "다 했나"를 기억해야 한다. 홈 팁은 첫 자산군만 연다(`home-tip-box.tsx:132`).

## 2. 목표 행동
한 번 연 시트에서 보유 자산군을 차례로 맞추고 [완료]로 닫는다. 두 번째 자산군부터 재진입 탭 0.

## 3. 범위
- 대상 자산군: 최신화 4종(주식·코인·현금·대출, `RefreshCategory`). 부동산·실물·과거 순자산은 정렬만 적용, 저장 후 복귀 없음(현행).
- **핵심 재사용**: 4종의 모든 저장 성공 지점은 이미 `markCategoryRefreshed(category)`를 부른다(직접 입력 4·스크린샷 4·잔액 맞추기·보유 현황 맞추기 — `asset-refresh-status.ts:41`, 호출 14곳). 저장 완료 신호를 이 함수 1곳에서 window 이벤트로 내보내면 각 창을 고치지 않는다(이벤트 이름·방식은 tech-review 판정).
- '맞춤' 표시는 새 상태·새 저장 키 없이 기존 `lastRefreshedAt(category)`가 **오늘(KST)**이면 ✓. 스키마·저장 키 0.
- 하지 않을 것: 경과일 배지(정본은 결산 '다음 달 준비'), 위저드 강제, 새 메뉴, 취소 시 복귀, 거래 기록 흐름 변경, 부동산·실물 복귀.

## 4. 사용자 흐름
1. FAB(또는 하단 네비 +) → 보유 현황 업데이트 → 목록. 순서: 보유 자산군(기존 순서 유지) → 미보유 자산군(보조 문구 `추가`) → 과거 순자산(`기록`, 맨 아래 고정).
2. 보유 자산군 행 보조 문구: 오늘 맞췄으면 ✓ + `오늘 맞춤`(병기), 아니면 현행 `업데이트`. 미보유 행은 `추가`(부동산·실물 포함), 과거 순자산 `기록`. ✓ 여부로 재정렬하지 않는다.
3. 자산군 선택 → 방법 선택 → 해당 창이 열리고 시트는 닫힌다(현행). FAB는 "이어서 대기" 플래그를 메모리에 1개 둔다(어느 경로에서 열었는지).
4. 창에서 저장 성공 → 신호 수신 → 플래그가 있으면 시트를 holdings 단계로 다시 연다. 상단 1줄 `{자산군} 맞췄어요` + 하단 [완료](brand). 방금 자산군 행은 `오늘 맞춤` ✓.
5. 다른 자산군을 누르면 3으로. [완료]·바깥 탭·Esc → 시트 닫힘, 플래그 해제.
6. 창을 취소로 닫으면 플래그 해제, 시트 재열기 없음(현행처럼 원래 화면).
7. 홈 최신화 팁·결산 '다음 달 준비' 행 진입(`open-add-asset-sheet` + category)도 3과 같이 플래그를 세운다 → 저장 후 4로 복귀. **결산 행 진입 v1 포함**(같은 경로, 결산 UI diff 0).
8. 상단 줄 `보유한 자산을 모두 맞췄어요`는 **보유한 최신화 4종이 모두 오늘 맞춤이고 부동산·실물 미보유**일 때만. 그 외(부동산·실물 보유 포함)는 항상 `{자산군} 맞췄어요`.

## 5. 엣지 케이스
- 빈 데이터(보유 0): 정렬 결과 = 현행 순서, 복귀 흐름은 첫 등록에도 적용(등록도 markCategoryRefreshed 호출). 첫 사용자 온보딩 마법사 경로(`directInput="add"`)는 플래그를 세우지 않음 → 마법사 흐름 불변.
- 일부 갱신: 보유 현황 맞추기에서 일부 행만 적용해도 저장 성공이면 ✓(기존 markCategoryRefreshed 기준과 동일).
- 오래된 데이터: 어제 맞춘 자산군은 ✓ 없음(오늘만). 자정 넘김은 다음 시트 열기 때 반영.
- 신호 오인: 상세 탭 편집·거래 스크린샷(`crypto-trade-screenshot-import.tsx:183,268`)도 신호를 내지만 플래그가 없으면 무시.
- 스크린샷 인식 실패 → #99 안내 [직접 입력]: 같은 자산군 창으로 이어지므로 플래그 유지, 저장 시 복귀.
- FAB가 숨은 화면(성과 등, `:89-91`)에서 결산 행으로 진입: 시트는 화면과 무관하게 열린다 — 복귀도 같은 시트.
- 포커스: 시트 재열기 시 포커스는 시트 안 첫 미맞춤 행. 품질 묶음 (b)와 같은 영역이라 같은 릴리스면 (b) 규칙(닫힘 → FAB 버튼)과 함께 qa.

## 7. 완료 기준 (qa가 그대로 검사)
1. 주식·현금 보유, 코인·대출 미보유 데이터에서 목록 순서가 주식·현금 → 부동산·코인·실물·대출(미보유, `추가`) → 과거 순자산이다. (미보유 내 순서는 기존 상대 순서)
2. FAB → 주식 → 직접 입력 저장 → 탭 0회로 시트가 holdings로 다시 열리고 주식 행에 `오늘 맞춤` ✓, 상단 `주식 맞췄어요`가 보인다.
3. 이어서 현금 → 잔액 맞추기 저장 → 다시 목록, 주식·현금 모두 ✓, 상단 `보유한 자산을 모두 맞췄어요`. 같은 흐름을 부동산(또는 실물) 1건 추가 보유 데이터로 반복하면 상단은 `현금성 자산 맞췄어요`다.
4. 창을 취소로 닫으면 시트가 다시 열리지 않는다.
5. 홈 최신화 팁 → 저장, 결산 '다음 달 준비' 행 → 저장 모두 같은 목록(상태 줄·[완료])으로 복귀한다.
6. 상세 탭에서 직접 편집 저장 시 시트가 열리지 않는다. 온보딩 마법사 저장 시 시트가 열리지 않는다.
7. 새 localStorage 키 0, 저장 스키마 diff 0, 결산 화면 UI diff 0.
8. 320·375·1280, 라이트·다크에서 목록 행 히트영역 ≥40px, ✓·보조 문구 줄바꿈 없음.
9. GA: page_title `이어서 맞추기` 1개만 추가(파라미터·자산 값·금액 0). 복귀한 목록에서 방금 맞춘 자산군이 아닌 행을 고를 때 1회. 그 외 신규 title·이벤트 0. vitest로 조건별 전송 횟수 확인: 복귀 목록 다른 행 선택 = 1, 복귀 목록 같은 행 재선택·연필·[완료]·Esc/바깥 탭 = 0, 처음 연 목록(FAB·홈 팁·결산 진입)의 선택·취소·완료 = 0. 이벤트 이름·전송 방식은 tech-review 판정.
