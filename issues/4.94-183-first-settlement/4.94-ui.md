# 4.94 UI 사양 (#183) — ui-designer, 2026-11-13

기준: direction.md(합의)·challenge.md(조건 ②: A 끝난 달은 range 이름)·origin/main 8a7bdc9 코드·design-system §2·§3·§5·§6·§7·§11.
원칙: **새 컴포넌트·색·토큰·모션 0.** 기존 상태(`settled`·`range`·`in_progress`)를 A 구간이 그대로 받는다. 시각 변화는 "문구·배지 유무"뿐이다. 다크 기준(라이트는 동일 토큰 자동 대응).

## 1. 이름 규칙 (단일 함수 `settlementName`류 1개, 3곳 공용) — 최종안
| 구간 | 이름 | 배지 | 설명 줄/구간 |
|---|---|---|---|
| settled | `N월 결산` (다른 해 `25년 N월 결산`) | 허브만 `N월 결산` 배지 | `M/D → M/D` |
| range(구간 ≥25일 또는 **A 끝난 달**) | `M/D → M/D 변화` | 없음 | 이름 = 구간이므로 구간 줄 생략(중복 방지) |
| in_progress(A 진행 중 포함) | `N월 · 진행 중` (다른 해 접두) | 결산 화면은 기존 `진행 중` GROUP_BADGE | `M/D → M/D` |
- 이름과 구간이 다른 말을 하지 않는다: "N월 결산"은 settled일 때만 쓴다. A 끝난 달은 **"11월 결산" 금지**, `11/7 → 11/28 변화`.
- 해가 다르면 range도 `25/11/7`이 아니라 기존대로 `M/D`만(연 접두는 월 이름에만). 구간이 해를 넘는 경우만 spec에서 확정.
- 금지어: "첫 기록", "처음", 금액, 투자 조언 어투.

## 2. 홈 결산 팁 (`home-tip-box`, 재사용·문구만)
컴포넌트 트리: HomeTipBox 셸(보더리스 카드) › 아이콘 `CalendarCheck` › 배지 `결산` › 제목 › 설명 › X. 변경 없음.
| 상태 | 제목 | 설명 |
|---|---|---|
| settled | `11월 결산이 열렸어요`(유지) | `순자산이 무엇 때문에 바뀌었는지 볼 수 있어요.` |
| range / A 끝난 달 | `11/7 → 11/28 변화를 볼 수 있어요` | 동일 |
| in_progress / A 진행 중 | `11/7 이후 변화를 볼 수 있어요` | 동일 |
- 토큰: 기존 팁 셸 그대로(제목 `text-sm font-semibold`, 설명 `text-sm text-muted-foreground`, `break-keep wrap-break-word text-pretty`). 날짜 숫자는 `tabular-nums`를 제목 span에 추가(자릿수 정렬).
- **320/375 줄바꿈(C25)**: 제목 최장 `11/27 → 12/10 변화를 볼 수 있어요`(약 24자) → 375에서 2줄 허용, 날짜 쌍(`11/27 → 12/10`)이 `→` 앞뒤에서 끊기지 않게 날짜 쌍을 `whitespace-nowrap` span으로 감싼다. 320에서 2줄까지, 3줄 시 FAIL. 설명 2줄 이내.
- 히트: 카드 전체 클릭, X 40px(`after:-inset-1`) 기존 유지. 우선순위·창·닫기 로직 diff 0.
- testId: `home-tip`·`home-tip-title`·`home-tip-close`(기존).

## 3. 성과 허브 자산 변화 카드 (`performance-hub`, KpiCard 재사용)
트리: KpiCard › 제목 `자산 변화`(+배지) › 설명 › primary 증감 › secondary `+n.n% 지난 기록 대비` › HubChangeRows.
| 상태 | 배지 | 설명 줄 | primary |
|---|---|---|---|
| settled(창 안) | `hub-change-settlement-badge` `N월 결산`(기존 `bg-primary/10 text-primary text-xs`) | `M/D → M/D` | 증감, 손익색 |
| range | 없음 | `M/D → M/D 변화` | 동일 |
| in_progress·A 진행 중 | 없음 | `N월 · 진행 중` | 동일 |
| A 7일 미만·시작점 없음 | 없음 | `다음 달부터 결산이 열려요`(유지) | 금액 없음 |
- **배지는 settled만**(range·in_progress에 "N월 결산" 배지 금지 = 이름 모순 제거). 배지 없는 상태에서 제목 줄 높이가 흔들리지 않게 제목 줄 `min-h-6` 유지(기존 inline-flex 줄 높이와 동일하면 추가 없음, qa가 배지 유무 카드 높이 차 ≤2px 확인).
- 숫자: primary `tabular-nums`(기존 KpiCard), 증감·% 손익색 `getProfitLossColor`(빨강 이익/파랑 손실). 설명 줄 날짜 `tabular-nums`.
- 320: 설명 `M/D → M/D 변화` 1줄(≤14자). 카드 전체 클릭(기존 히트 충족).
- 숫자 일치: 허브 primary = 결산 Hero 증감 = 팁이 가리키는 구간(원 단위 `data-value` 비교, C65).

## 4. 결산 화면 Hero (`SettlementView › ChangeHero`)
트리(위→아래): ChangeHero(이름 줄 `min-h-10`: 이름·구간·배지·‹ › 화살표 `size-10`) › 증감 `text-2xl sm:text-3xl font-bold tabular-nums` + `%` `text-base` › `시작 → 끝` `text-sm tabular-nums` › [일부 이전 값 배지] › [note] › CauseBlock › (A는 CompositionBlock·월별 기록·AI 숨김 유지 — 첫 결산 경로는 원인 블록까지).
| 상태 | 이름(`settlement-title`) | 구간(보조) | 배지 | 본문 |
|---|---|---|---|---|
| settled | `11월 결산` | `10/28 → 11/28` | — | 증감+원인 |
| range / A 끝난 달 | `11/7 → 11/28 변화` | **생략**(이름이 구간) | — | 증감+원인 |
| in_progress / A 진행 중 | `11월 · 진행 중` | `11/7 → 11/27` | `settlement-inprogress` `진행 중` | 증감+원인 |
| A 7일 미만·없음 | 이름 줄 없음 | — | — | `settlement-first-month` `다음 달부터 결산이 열려요` 유지 |
| 로딩 | 기존 ChangeHero `change-hero-loading` | | | |
| 오류 | 이름 + `settlement-error` | | | 기존 |
- 이름·구간은 한 줄에서 넘치면 이름 줄 `flex-wrap`(기존)으로 구간이 아래로 내려간다 — 화살표는 오른쪽 고정(`shrink-0`). 320에서 `11/27 → 12/10 변화`(16자) + 화살표 2개(80px)는 한 줄 불가 가능 → 이름 `min-w-0 break-keep`, 2줄 허용·화살표 세로 중앙(기존 `items-center`). 이름 줄 높이 `min-h-10` 유지, 증감은 항상 이름 줄 아래.
- 모션: `contentKey`=month fade만(기존). A 화살표 이동 시 구간 종류가 바뀌어도 재마운트로 fade가 사라지지 않게 `contentKey` 유지(`CauseBlock key={month}` 그대로).
- 원인 블록(CauseBlock scope="month", 5항목 40ms stagger, 기존): A 구간에서 `기록 안 된 변화` 항목이 커질 수 있다 — 기존 `cause-unrecorded-hint`(`UNRECORDED_HINT_RATIO` 0.5)를 그대로 쓰며 새 경고 박스 금지. 힌트 문구 "이번 달 입출금을…"은 range 이름일 때 어긋나므로 **`입출금을 기록하면 더 정확해져요`**로 중립화(scope month 한정, 문구 1곳). 추정 배지는 기존 `cause-estimated-badge`.
- 화살표: 월 이동 시 A 달은 기록 없는 달 건너뜀 기존 규칙 유지, 히트 `size-10`, aria `이전 달`/`다음 달`.
- `longGap` note(`settlement-gap-note`) 기존: A에서 시작 날짜가 30일 롤링으로 밀려도 날짜 라벨이 그대로 사실을 보인다(별도 안내 추가 안 함).

## 5. 체험 홈 Hero (S3)
- **시각·레이아웃·문구 변경 0.** `전일 대비` 줄의 숫자만 데이터 재기준으로 |Δ|≤0.5%가 된다. 코드 diff는 `demo-data.json`(방식은 tech-review).
- 확인 기준: 증감 색은 기존 `getProfitLossColor`, `tabular-nums` 유지, 375에서 줄바꿈 위치 변화 없음(숫자 자릿수 감소로 더 짧아짐), `isBig`(큰 변동 강조)·`negligible`(변동 없음) 분기 중 어느 쪽이 떠도 기존 모양.
- 체험 허브·결산 숫자도 같은 데이터이므로 Hero 숫자와 모순 없는지 qa 확인.

## 6. 접근성·모션 공통
- 클릭 대상(팁 카드·허브 카드) 전체 영역, X·화살표 40px. 키보드: 기존 button·focus-visible ring.
- `aria-live`는 ChangeHero 기존. 날짜 문구는 `aria-label` 추가 없이 텍스트 그대로(`→`는 스크린리더가 "화살표"로 읽는 기존 패턴과 동일).
- 신규 애니메이션 0(기존 `BODY_ENTER`·fade, `motion-safe`).
- `data-screenshot-hide`: 화살표(기존), AI 버튼·준비 블록(기존). 신규 대상 없음.

## 8. 품질 체크리스트 (qa 판정, 375·1280 × 다크, 라이트 보조)
1. A 픽스처(11/3 2건·11/6 3건 등록 후 기록)에서 11/27 홈 팁이 뜨고 제목이 `11/7 이후 변화를 볼 수 있어요`다.
2. 같은 날 허브 카드 설명 `11월 · 진행 중`·배지 없음, 결산 화면 이름 `11월 · 진행 중`+`진행 중` 배지+구간 `11/7 → 11/27`이다.
3. 12/2에는 세 곳 모두 `11/7 → 11/28 변화`로 표기되고 어디에도 `11월 결산`이 없다. 허브 배지도 없다.
4. 허브 primary·결산 `change-hero-delta`·(팁 대상 구간)의 `data-value` 원 단위가 같다.
5. settled 사용자(기존)는 `N월 결산` 팁·배지·제목이 이전과 동일하다(회귀 0).
6. 팁 제목이 320px에서 2줄 이내이고 날짜 쌍 `M/D → M/D`가 중간에서 끊기지 않는다(C25).
7. 결산 화면 이름 줄이 320에서 화살표와 겹치지 않고 높이가 이름 1~2줄에서도 증감 위치가 밀려 보이지 않는다(상단 `min-h-10`).
8. 모든 날짜·금액 span에 `tabular-nums`(computed `font-variant-numeric`)가 적용된다.
9. 팁 X·허브 카드·월 화살표 히트영역 ≥40×40px(경계 박스).
10. 배지 유무(settled ↔ range/in_progress)로 허브 카드 높이 차 ≤2px, 레이아웃 시프트 없음.
11. A 7일 미만·시작점 없음은 팁 미노출, 허브 `다음 달부터 결산이 열려요`, 결산 `settlement-first-month` 유지(세 곳 일관).
12. A 결산 화면에 CompositionBlock·월별 기록·AI 버튼이 없다. 원인 블록 5항목이 stagger로 진입한다(`motion-safe`), 화살표 월 이동 시 fade 유지.
13. 원인 `기록 안 된 변화` 비중 ≥50%일 때 기존 `cause-unrecorded-hint`만 뜨고 새 박스가 없다. 문구에 "이번 달"이 없다.
14. 체험 홈 Hero `전일 대비` |Δ|≤0.5%, 레이아웃 diff 0, 체험 허브·결산 숫자와 모순 없다.
15. 다크 대비: 팁 설명·허브 설명 `text-muted-foreground`가 카드(`#191C22`) 위 4.5:1 이상, 손익색은 기존 토큰.
16. 새 색·border·그림자·z-index·애니메이션이 diff에 0개(grep).
