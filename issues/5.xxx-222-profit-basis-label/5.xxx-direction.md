# #222 방향 정의 — 종가 기준 설정 쉬운 말로·한 모양으로 (XS)

근거: `_discovery/2026-11-15-d2-selection.md`(cto 축소 통과), `2026-11-15-d-planner.md` 2순위. 이미 결정된 범위(①문구 공용 상수 ②성과 Switch → InlineSelector 2칸 ③GA title 1개)는 다시 열지 않는다.

## 사업 절 (business-pm, 1차)

**성격: 대기열 채움.** 월 활성 100명에 직접 기여하지 않는다. 직접 기여 후보(홈 도넛 3중 표시)는 12/11 판독 뒤에 연다. 그전까지 비용 XS로 묶어 진행하는 정리 과제다(LEARNINGS 10-29: 소규모 정리를 주력으로 삼지 않음).

- **왜 지금**: 리텐션에는 간접적으로 기여한다(이해·정확성). 첫 발견 기여는 없다. 지금 하는 이유는 두 가지다. D는 매 실행 수행이 원칙이고, 열린 릴리스가 없어 비용이 가장 낮을 때다. 근거 강도는 **약함**이다.
- **누구를 위해**: 엑셀·노션에 국내·해외 주식을 함께 정리하던 3040이다. 이들은 기간 수익을 시장별 날짜로 맞춰 보고 싶어 한다. 'KST 접속일'이라는 말과 켜고 끄는 스위치로는 무엇이 바뀌는지 알기 어렵다. 성과에서 바꾸면 성적표·시장 비교까지 함께 바뀐다는 점도 모른다.
- **하지 않으면 잃는 것**: **약함.** 기본값(동일 영업일)과 접힌 영역 때문에 노출이 적다. 잃는 것은 해외 보유자의 오해 가능성 정도다. 그래도 이번에 이 설정을 쓰는 사람이 있는지 처음 잰다는 점은 의미가 있다(아래 지표).

### 지표 (익명 기기, 기존 GA)
1. **주 지표**: 기존 `feature_use`의 title '종가 기준·변경' 기기 수와 source(설정/성과) 비율. 머지 후 4주 동안 절대 기기 수로 본다. 새 이벤트명은 0이다.
   - **4주 동안 0기기면** 다음 D에서 '설정 자체 축소(빼기)' 후보로 올린다. 이 과제의 실질 산출물은 이 판단 근거다.
   - 표본이 작다(월 활성 약 50). 비율보다 '0인가 아닌가'만 판정한다.
2. **가드레일**: `change_week_all`(4.90 C)과 '성과·자산 성적표' 기기 수가 머지 전 4주보다 줄지 않아야 한다.

### 측정·판독 경계
- 머지 시각을 4.90 판독 메모에 경계로 기록한다. 4.90 C의 도착 화면은 같지만 접힌 영역 안 컨트롤 모양이 바뀌기 때문이다.
- 4.86 웰컴·#183 결산·#219 홈 팁은 무접촉이라 기록하지 않아도 된다.
- 판독일은 머지일 + 28일이다(머지 ≤11/19 기준 ≤12/17).
- 한계: 에이전트에게 GA 조회 수단이 없다. 판독은 대표 화면 수치나 다음 D 근거로 대신한다.

### 범위 가드
- 저장 키·값·기본값·계산·공유 데이터 변경은 0이다. 성과 컨트롤 삭제·이동, Hero·표 구조 변경, 첫 화면·결산 화면 변경도 0이다.
- ui 폭 문제로 S를 넘으면 ②를 빼고 ①만 진행한다. qa가 문구와 계산 의미가 어긋난다고 판정하면 ①을 빼고 ②만 진행한다.
- 마케팅: 알리지 않는다. 문구 정리라 threads 1건 소재로도 약하다. 필요하면 주간 초안에서 '설정 이름 쉬워짐' 한 줄로 묶는다.

## 경험 절 (planner-designer)

근거 코드(origin/main bee7856): `header-menu/settings-page.tsx` 230-252, `views/activity/profit-chart.tsx` 583-606, 계산 `api/finance/profit/route.ts` 64-77(sameBusinessDay = 국내·해외를 같은 영업일 날짜로 정렬, kstAccessDay = 시장별로 각자 마지막 종가). 값을 쓰는 곳: 기간 수익·성적표(`asset-report-view`)·시장 비교(`use-market-compare`)·공유 링크.

### 1. 사용자 행동 (관찰 가능)
- 더보기 `표시` 또는 성과 `기준 종가 비교`를 펼친 뒤, 두 곳 모두 같은 2칸 선택에서 한 칸을 누른다. 같은 이름이 보인다.
- 성과에서 바꾸면 바로 아래 표의 국내·해외 날짜가 바뀌는 것을 본다. 설명(i)을 열면 성적표·시장 비교에도 함께 적용된다는 문장을 읽는다.

### 2. 두 곳 화면 흐름
- 더보기: 더보기 → 표시 → 설정 이름 + (i) → 2칸 선택. 순서·위치는 그대로다. 이름·선택지 글자만 바뀐다.
- 성과: 기간 수익 → `기준 종가 비교` 펼침(기본 접힘 유지) → 우측 (i) + 2칸 선택 → 아래 날짜 표가 즉시 갱신. `글자 / Switch / 글자` 3요소가 2칸 선택 1개로 줄어든다.

### 3. 문구 확정안 (공용 상수 1개, 두 곳 동일)
| 항목 | 현재 | 확정안 |
|---|---|---|
| 설정 이름(+aria-label) | `기간 수익 종가 기준` / 성과 aria `종가 기준 옵션` | `국내·해외 날짜 맞춤` |
| 선택지 sameBusinessDay | `동일 영업일` | `같은 거래일` |
| 선택지 kstAccessDay | `KST 접속일` | `시장별 최신` |
| 설명 요약 | 국내·해외 종가를 어느 날짜로 묶어 합산할지… | 국내·해외 종가를 어느 날짜로 묶어 더할지 정해요. |
| 설명 1 | 동일 영업일 — … (해외는 익일 새벽 마감) | `같은 거래일` — 국내·해외 모두 같은 날짜의 종가로 더해요. 해외 종가는 다음 날 새벽에 정해져요. |
| 설명 2 | KST 접속일 — KST 접속일 기준으로… | `시장별 최신` — 지금(한국 시간) 기준으로 각 시장의 마지막 종가를 더해요. 두 시장 날짜가 다를 수 있어요. |
| 설명 3(신규 1줄) | 없음 | 기간 수익·성적표·시장 비교에 함께 적용돼요. |
- 후보 `한국 날짜로 맞춤`은 불채택. kstAccessDay는 '한국 날짜에 맞추는' 것이 아니라 시장마다 각자 마지막 종가를 쓰는 방식이라 뜻이 어긋난다(Q3 위험). `같은 거래일로 맞춤`은 의미는 맞지만 9자라 320 폭 2칸에 빠듯해 `같은 거래일`(6자)로 줄인다.
- 이름에서 '종가 기준'을 뺀다. 상세 '오늘' 칩의 '종가 기준 등락'(#132)과 용어가 섞이지 않는다.
- '함께 바뀐다' 전달은 설명 3 한 줄로만 한다(토스트·확인창·경고 배지 없음). 성과 쪽 일별 환율 문장(`period === "daily"`)은 성과에만 덧붙이는 기존 동작 유지.
- 선택지 글자는 ui가 폭 확인 후 더 줄일 수 있다(예: `같은 날`/`각자 최신`). 의미 변경은 planner 재확인 필요.

### 4. 범위
- 포함: ① 이름·선택지·설명 공용 상수 1개 ② 성과 Switch → InlineSelector 2칸(설정과 같은 옵션 배열 재사용) ③ GA `feature_use` title 1개.
- 줄이는 것: 설명 문단 복붙 2벌 → 1벌, 성과 컨트롤 3요소 → 1요소, aria-label 2종 → 1종, 선택지 이름 '영업일·KST·접속일' 3개 어려운 말 → 0개.
- 하지 않을 것: 성과 컨트롤 삭제·이동(cto 불채택), `기준 종가 비교` 접힘 제목·표·`(KST)` 머리·마감 기준 줄 변경, 보유 구성(국내만·해외만)에 따라 컨트롤 숨기기, 바꿀 때 토스트·확인창, 저장 키·값·기본값·계산·공유 데이터 변경, 첫 화면·결산 화면.

### 5. 바뀌는 곳 / 그대로인 곳
- 바뀜: 더보기 표시 섹션 글자, 성과 `기준 종가 비교` 펼침 안 선택 컨트롤 모양.
- 그대로: 기본값(`같은 거래일`), 펼침 기본 접힘, 날짜 표·합계, 성적표·시장 비교 화면(자기 컨트롤 없음, 값만 따름), 상세 '오늘' 칩.

### 6. 엣지
- 국내만·해외만 보유: 컨트롤은 그대로 보인다. 계산상 국내만 보유해도 `같은 거래일`은 해외 영업일 달력으로 날짜를 맞춰 결과가 달라질 수 있어 숨기면 안 된다. 날짜 표는 기존처럼 보유 시장 행만 나온다.
- 주식 0개: 성과 쪽 표는 기존 조건대로 안 나온다. 더보기 쪽은 그대로 보인다(바꿔도 무해).
- 320 폭: 성과 펼침 안은 카드 안쪽 폭이 좁아 (i) + 2칸이 한 줄에 들어가야 한다. 안 들어가면 (i)를 이름 줄로 올리지 말고 선택지 글자를 줄인다(Q4). 히트영역 40px 이상.
- hydrate 전: 더보기는 기존처럼 확정 후 노출. 성과도 같은 조건을 따른다(기본값 깜빡임 방지).
- 공유 링크로 받은 값·구버전 기기 값: 값이 같아 새 이름으로 바로 보인다.
- 체험(`?trial=1`): 기존 저장 동작 그대로(Q5).

### 7. 사업 절 의견
동의. 지표 '0인가 아닌가' 판정과 '4주 0기기 → 설정 빼기 후보' 연결에 동의. 보충 1건: GA source는 `설정/성과` 2값으로 고정하고, 같은 값 재선택(변경 없음)은 세지 않아야 '바꾼 사람' 수가 된다(spec 완료 기준에 넣는다).
