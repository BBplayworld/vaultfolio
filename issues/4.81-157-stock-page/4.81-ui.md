## 2. 진입 링크 — 펼침 그룹 머리 '종목 보기 ›' `stock-page-entry`

현재 펼침 머리 행: 좌 `flex-1 min-w-0`(종목명·(티커·시장)·분류 배지, wrap) / 우 `총 {N}주`(shrink-0, `items-start`). 이 행은 분할·비분할 모두 같은 코드 한 곳이다 → 링크는 **이 행 우측 열에 한 번만** 넣어 분할·비분할이 자동으로 같은 자리다.

- 우측 열을 세로 스택으로 바꾼다: `flex flex-col items-end shrink-0` — 1줄 `총 N주`(기존 그대로), 2줄 링크.
- 링크: `<button type="button">` 텍스트 `종목 보기` + `ChevronRight size-3.5`. 클래스: `-mr-2 -mb-2 inline-flex min-h-10 min-w-10 items-center gap-0.5 px-2 text-sm font-medium text-brand dark:text-indigo-300 active:not-disabled:scale-[0.96] transition-[scale,color] motion-safe:duration-150`.
  - **히트영역 40px는 `min-h-10`을 쓰되 `-mb-2`/`-mt-2`로 시각 행 높이를 줄여** 행이 +24px 이상 커지지 않게 한다(스택 총 시각 높이 ≈ 20+24). 이웃 칸(`StockDetailGrid`)을 가리지 않는다(헤어라인 `cardSection` 위쪽 영역 안에서 끝남).
  - 색: 라이트 `text-brand`(#5b6fbf, 흰 배경 4.9:1), 다크는 brand가 카드(#191C22) 위 3.6:1이라 **`dark:text-indigo-300`**(§13 ON 배지에서 이미 실측한 값, 신규 색 0).
- 접힌 상태에서는 `CollapsibleContent` 안이라 `inert`로 포커스 불가(기존 동작). 인증카드(`screenshotMode`)는 펼침 미렌더라 diff 0.
- 클릭: `setTradeTarget`과 같은 store 방식으로 `groupStockIds`·이름·티커 저장 후 navigate. 탭이 행 토글(`CollapsibleTrigger`)로 새지 않게 `stopPropagation` 불필요(트리거 밖이지만 확인).
- **시장 비교 `market-list-row`**: 현재 `<li>`에 텍스트만. 종목(`kind==="stock"` 중 보유 종목과 매칭되는 것)만 `<li>` 안을 `<button class="flex w-full min-h-11 items-center justify-between gap-3 py-2.5 text-left active:bg-muted/40 transition-[background-color]">`로 감싸고 우측 등락 뒤에 `ChevronRight size-4 text-muted-foreground`. 지수·비매칭 행은 기존 그대로(눌리지 않음, chevron 없음). 기존 구분선·정렬·`data-testid` 유지, 표 계산 diff 0. 행 단위 히트영역 44px(`min-h-11`).

## 4. 차트 사양

**종류**: 면적선(`Area`, 선 1.75px, 아래로 흐리는 채움 12%→0). net-asset-chart와 같은 recharts 구성, `margin={{ top: 20, right: 12, bottom: 4, left: 12 }}`. 축: **Y축 없음**(값은 평단 라벨·탭 읽기로 대체, 눈금 숫자 군더더기 제거), **X축은 시작·끝 날짜 2개만**(`YYYY.MM`, 11px muted, 5년은 `YYYY`), 그리드 없음. 로고성 장식 없음.

**선 색 = 차트 구간 등락의 부호**: 끝 종가 ≥ 시작 종가 → 빨강(`text-rose-600 dark:text-rose-400`을 래퍼에 주고 `stroke="currentColor"`·채움 `currentColor`), 아래 → 파랑(`text-blue-600 dark:text-blue-400`). 하드코딩 hex 금지(`getProfitLossColor` 값 파생). 이 색은 차트 머리 `stock-page-change`와 동일 규칙. **'내 수익' 색(머리, 매입 대비)과는 독립**이므로 머리가 파랑·차트가 빨강인 화면이 정상(spec §4.4가 라벨로 분리). 같은 화면의 오해를 줄이려 차트 머리 라벨은 반드시 `주가 등락`.

**평단선** `stock-page-avg-line`: `ReferenceLine`, `stroke="currentColor"` 래퍼 `text-foreground/70`, `strokeDasharray="4 3"`, 1.25px. 색 의미: 손익도 액션도 아닌 **중립 기준선**이라 전경색(브랜드·주황·손익색 금지 — 주황은 순자산 전용, 인디고는 액션). 라벨 칩(신규 소패턴): SVG `<g>` = rect(`fill: var(--card)` 불투명 85%, rx 6, 높이 20, 패딩 6) + text 11px `font-medium tabular-nums`, 문구 `내 평단 {가격}`. 위치: 선 **왼쪽 끝 위**(데이터 시작 가까운 쪽은 선이 평단 위·아래 어디든 칩이 위에 올라가도 card 면이라 읽힘). 선이 플롯 위쪽 28px 안이면 칩을 선 **아래**로 뒤집는다. 칩이 `stock-page-avg-line` 안 `<text>`로 들어가 testId 하나로 값 단언 가능.

**평단이 차트 값 범위 밖일 때 (결정)**:
1. y 도메인 = `[min, max]` 각각 8% 패딩이 기본.
2. 평단이 `[min − 0.4·span, max + 0.4·span]` 안이면 **도메인을 평단까지 넓힌다**(선이 그대로 보임, 가격선은 조금 납작해짐 — 허용 한계가 40%).
3. 그 밖이면 도메인은 기본 유지, 평단선은 **플롯 위/아래 가장자리에 고정**하고 라벨을 `내 평단 {가격} ↑`(평단이 위) / `↓`로 바꾼다. 선은 점선→**더 옅은 점선(`text-foreground/40`)**으로 구분. `stock-page-avg-line`에 `data-clamped="up|down|none"`.
- 이유: 가격이 한쪽에 몰려 선 1개 때문에 차트가 납작해지는 것을 막으면서 '평단이 저 멀리 있다'는 사실(평단 대비 어디쯤)은 지킨다. 평가어는 붙이지 않는다.
- 해석 문장·색 경고 없음.

**매수 점** `stock-page-buy-dot` (거래 `type==="buy"`만, spec §4.6):
- 위치 x = 거래 날짜의 그날(주봉은 그 주) 종가 포인트, y = 그 포인트의 종가. 거래 단가 사용 금지.
- 모양: 원 r=4, `fill` 매수색 빨강(`rose-500`, 매수=빨강 규약), `stroke: var(--card)` 2px(선 위에서 분리되는 고리 — 선이 빨강일 때도 구분). 아이콘·그림자 없음.
- 같은 위치(같은 날·같은 주) 거래 여러 건 = 점 1개, 크기 동일.
- 히트영역: 점마다 투명 `r=20` 원(=40×40) 겹침 시 가까운 점 우선. `role="button" tabindex="0" aria-label="{날짜} 매수 {수량}주 · {단가}"`, Enter·Space 토글.
- 선택: 점 r=6 + 바깥 고리 `ring` 2px brand(`MAIN_PALETTE[0]`, 선택=brand 규약), 전환 `transition-[r]`(SVG 속성은 CSS 전환 불가 → 두 겹 원의 `opacity` 전환 150ms). 선택 해제: 같은 점 재탭·차트 빈 곳 탭·기간 전환.
- 상태 줄 슬롯에 `stock-page-buy-detail`: `{YYYY.MM.DD} 매수 {수량}주 · {거래 단가}`(한 줄 13px, 숫자 `tabular-nums`, `매수`는 빨강 아님·전경색). 같은 점에 여러 건이면 줄 나열 최대 3줄 + `외 N건`(슬롯 높이는 max 3줄까지 `min-h-10`이 자라는 것을 허용, 차트는 안 움직이게 슬롯은 차트 **아래**).
- 개수 많으면(5년 주봉 60+ 건) 점 반경 3으로 줄이지 않는다 — 겹침은 허용, 히트영역은 가까운 점 우선.

**일반 탭/드래그 읽기**: 차트 빈 곳 탭 시 기본 recharts `ChartTooltip`(세로선 cursor)으로 `{날짜} · {종가}` 표시. 이미 net-asset-chart가 쓰는 툴팁 그대로. 매수 점 탭은 툴팁이 아니라 상태 줄(위에서 결정) — 툴팁이 점을 가리지 않는다.

**창 밖 매수** (상태 줄 슬롯):
- 1년: 버튼 `1년보다 전 매수 {N}건 · 5년에서 보기`, `5년에서 보기`만 `text-brand dark:text-indigo-300 font-medium`(link 색 한정), 나머지 전경색 text-sm. `min-h-10 w-full text-left`. 탭 → 기간 5년 전환(조회 시작). `stock-page-outside`.
- 5년: 같은 슬롯에 일반 텍스트 `5년보다 전 매수 {N}건`(버튼 아님, muted). `stock-page-outside`(`data-clickable=false`).
- 점 상세 선택 중이면 상세가 우선, 해제되면 안내 복귀.
- 거래 0건(창 안·밖 모두): 슬롯에 muted 12px `거래를 기록하면 산 날이 점으로 표시돼요` `stock-page-no-trades`. `purchaseDate`로 점 생성 금지(C74). 창 안엔 없고 창 밖만 있는 경우는 outside 문구(0건 문구 아님).

**정의 줄** `stock-page-basis`: `액면분할 등을 반영한 가격이에요. 점은 기록한 거래 날짜에 찍혀요.` + 해외면 줄 끝에 ` 달러 가격 기준이에요.` + 상장 짧으면 ` 상장 이후 기간만 있어요.`(전부 같은 줄에 이어 붙이고 `text-pretty`로 줄바꿈). 최대 3줄(320 기준 ≈ 2줄 + α).

## 6. 모션

- **페이지 진입**: `BODY_ENTER`(`change-hero.tsx`와 같은 `motion-safe:animate-in fade-in slide-in-from-bottom-2 duration-200`) 두 카드에 `animationDelay` 0/40ms stagger. 라이트·다크 동일.
- **선 그리기**: 첫 마운트 1년 데이터 도착 시에만 recharts `isAnimationActive`(600ms ease-out)를 `motion-safe` 한정(`window.matchMedia('(prefers-reduced-motion)')` 대신 기존 net-asset-chart 방식 따름). **기간 전환(1년↔5년)은 선 그리기 없음**: 차트 박스 컨테이너는 **재마운트하지 않고**(key는 데이터에만, 차트 인스턴스 유지) 새 데이터로 `animate-in fade-in duration-200`. 재마운트로 모션이 사라지거나 반복되지 않는다.
- **기간 연타·중간 방향 전환**: 최신 선택만 적용(요청 id 비교), 이전 응답 폐기. 5년 로딩 중 1년 재탭 → 즉시 1년(캐시) 표시, 5년 응답은 무시하지 않고 캐시만 채움(다시 5년 탭 시 즉시).
- **점 선택**: 선택 고리 opacity 150ms. 상태 줄 텍스트 교체는 `fade-in 150ms`(높이는 min-h-10 고정, 최대 3줄 확장 시에만 부드럽게: 높이 전환 없이 즉시, 위쪽 차트가 안 움직임).
- **링크·버튼 누름**: 버튼 `active:scale-[0.96]`, 링크 행 `active:bg-muted/40 transition-[background-color]`(전체 폭 요소는 scale 대신 배경). `transition: all` 금지, `will-change` 사용 금지.
- exit는 절제(기존 화면 전환 규칙 그대로, 별도 exit 없음).
- `motion-safe:` 없는 모션 0 → reduced-motion에서 전부 즉시.

## 7. 접근성

- 히트영역 ≥40px: 진입 링크 40×40, 기간 선택 40, 점 40(r=20 투명원), `다시 시도` 40, 링크 행 48, 창 밖 버튼 40, 시장 비교 행 44.
- 차트 `role="img"` `aria-label="{기간} 주가 흐름, 등락 {±%}, 내 평단 {가격}{ ↑|↓ }"`; 점은 `role="button"`(위 aria-label). 상태 줄 `aria-live="polite"`. 로딩 박스 `aria-busy`. 기간 선택은 InlineSelector 기본(`aria-pressed`/radiogroup).
- 색만으로 구분 금지: 등락·내 수익은 부호(+, −)와 색을 함께, 평단선은 라벨 텍스트, 매수 점은 상태 줄 텍스트로 정보 중복 제공.
- 키보드: Tab 순서 = 뒤로 → 기간 선택 → 창 밖 버튼(있으면) → 점들(좌→우) → 거래내역 링크. 포커스 링은 전역 `outline-ring/50`, SVG 점은 `focus-visible:outline` 2px brand.
- 대비: 다크 `rose-400/blue-400` on `#191C22` ≥ 6:1, `text-indigo-300` 링크 ≥ 8:1(§13 실측), 평단 라벨 칩은 card 면+전경색 14:1 이상. muted 위 추가 투명도 금지(`text-muted-foreground` 단독, §11): 정의 줄·축 날짜에 `/NN` 안 붙인다.

## 8. 문구 최종안 (존댓말 해요체, 조언 금지)

`종목 보기` · `내 수익` · `총 {N}주` · `1년 주가 등락`/`5년 주가 등락` · `내 평단 {가격}`(`↑`/`↓`) · `{YYYY.MM.DD} 매수 {N}주 · {가격}` · `거래내역 {N}건` · `거래를 기록하면 산 날이 점으로 표시돼요` · `1년보다 전 매수 {N}건 · 5년에서 보기` · `5년보다 전 매수 {N}건` · `가격 흐름이 없는 종목이에요` · `가격 흐름을 불러오지 못했어요` · `다시 시도` · 정의 줄은 spec §7대로 + `달러 가격 기준이에요.` / `상장 이후 기간만 있어요.`

## 11. 품질 체크리스트 (qa가 스크린샷·Playwright로 판정)

1. [펼침] 분할·비분할 모두 `stock-page-entry`가 `총 N주` 아래 우측 같은 자리에 있고 박스 ≥40×40, 펼침의 다른 요소(칸·버튼·메타·메모) 위치·크기가 main과 같다(높이 증가 ≤ 28px).
2. [라이트·다크] 링크 색 대비: 라이트 ≥ 4.5:1, 다크 ≥ 4.5:1(`indigo-300`). 클릭 시 눌림 스케일 0.96.
3. [375·320·1280] 가로 스크롤 0, 머리 4행·차트 머리 행이 잘리지 않고 겹치지 않는다(320에서 줄바꿈 허용).
4. [머리] 평가·내 수익(금액·%)·총 주수가 누른 행·펼침 값과 문자열까지 같다(전체 탭·계좌 필터 탭 각각). 라벨은 `내 수익`, 차트 머리는 `N년 주가 등락`(둘 다 서로의 단어 미포함).
5. [색] 내 수익·등락은 이익 빨강·손실 파랑·부호 병기, 평단선은 전경 중립 점선(주황·인디고·손익색 아님), 매수 점은 빨강+card 고리, 선택 점은 brand 고리. 파랑이 손익 외에 안 쓰였다.
6. [평단선] 라벨 `내 평단 {가격}`이 보이고 값이 펼침 평단과 같다. 평단이 범위 밖이면 `data-clamped=up|down`·라벨 `↑/↓`, 40% 이내면 도메인이 넓어져 선이 보인다. 평단 0이면 선·라벨 없음.
7. [점] 거래 0건 → 점 0 + `stock-page-no-trades`(`purchaseDate` 점 없음). 점 탭 → 상태 줄 `날짜 매수 N주 · 단가`, 같은 점·빈 곳 탭·기간 전환 시 해제. 분할 전 매수는 점이 선 위에 있고 탭 시 원단가.
8. [창 밖] 1년에서 `1년보다 전 매수 N건 · 5년에서 보기` 버튼(40px) → 5년 전환, 5년에서는 버튼 아님 텍스트.
9. [상태] 로딩·오류·가격 없음·상장 짧음에서 차트 박스 높이가 정상 상태와 같고(점프 ≤ 2px) 카드 위치가 안 변한다. 오류 시 `다시 시도`(40px)가 해당 기간만 재조회. 가격 없음은 선택기·정의 줄 없음 + 서버 요청 0.
10. [모션] 진입 stagger 0/40ms, 기간 전환은 선 그리기 없이 200ms 페이드, 연타·중간 방향 전환 시 마지막 선택이 최종 화면(응답 순서 뒤집어도), reduced-motion 시 전부 즉시. 차트 DOM이 기간 전환 중 재마운트되지 않는다.
11. [접근성] 점·링크·버튼 Tab 순서 위 §7, 차트 `role=img` aria-label 존재, 키보드 Enter로 점 선택.
12. [시장 비교] 종목 행만 chevron·눌림 배경, 지수 행은 변화 없음. 탭 → 종목 한 장(뒤로 라벨 `뒤로`), 거래내역→뒤로→종목 한 장→뒤로 체인 단언.
13. [다크] 카드가 `bg-card` 톤차로 분리되고 테두리 없음, 평단 라벨 칩·점 고리가 카드색과 어긋나지 않는다(칩 가독 ≥ 4.5:1).
14. [문구] §8 문구 외 평가어·조언 없음, 해시·page_title에 종목명 없음.
15. [CHECKLIST] C65 같은 값은 같은 계산(머리·평단), C74 `purchaseDate` 점 금지, C76 6구간을 화면 상태로 대응(§5 표 행과 1:1).
