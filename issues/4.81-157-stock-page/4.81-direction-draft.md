# 4.xx 종목 한 장 — 경험 방향 초안 (planner-designer, 2026-11-11)

대표 지시(11-11): "상세-주식에 깊게 가는 것도 괜찮은데 **인증카드 주식과 확실한 노선 정리나 차별성** 필요."
근거: origin/main 코드 실측(`share-card.tsx`·`share-menu.tsx`·`stock-tab.tsx`), GA 11/03~09(`상세·주식` 활성 6·조회/사용자 4.5, `X-Ray` 1, `거래내역` 1. 인증카드는 다이얼로그라 page_title 없음).

## ① 현 상태 표 (코드 실측)

| | 인증카드 '주식 현황' | 상세·주식 행 / 펼침 | (신규) 종목 한 장 |
|---|---|---|---|
| 목적 | 내 주식 **전체를 이미지 1장**으로 남에게 보여 준다 | 보유 목록 관리(행) + 종목 숫자 확인·거래 입력·수정(펼침) | 종목 **하나의 매수 이후 시간**을 나 혼자 본다 |
| 사용자 질문 | "내 주식 지금 이렇게 생겼어"(보여주기) | 행: "뭐가 얼마고 오늘 어땠나" / 펼침: "평단·현재가가 얼마였지, 거래 넣자" | "산 뒤로 이 종목은 어떻게 흘렀고, 내 평단은 그 흐름에서 어디인가" |
| 보여주는 정보 | **상세·주식 목록 컴포넌트를 그대로 캡처**(`StockSummaryHeader`+`StockCategorySection`+`StockCard screenshotMode`): 총 평가·손익, 비중 막대·범례(상위 7+그 외), 행=이름·수량·평가·손익(%) 상위 7. 펼침·오늘 칩·시장 줄·X-Ray 없음 | 행: 이름·수량·비중%·평가·손익(%)·오늘 칩. 펼침: 종목코드·시장·계좌 배지·총 N주 / 평단·총 매입·현재가·총 평가(+환차·매입환율) / 거래입력·거래내역 / 나누기·수정·삭제 / 담보대출 / 보유기간·매수일·연환산·메모 / 증권사별 항목 | 행 머리(같은 계산) + **가격 흐름·내 평단선·매수 기록 점** + 기간 등락·시장 줄 + 이 종목 거래·배당 일정·분류 |
| 공유 | 예(저장·공유, 금액 표시 스위치) | 아니오 | **아니오** |
| 시간축 | 지금 한 시점(스냅샷) | 행=지금·오늘 / 펼침=매수일 누적(평단·연환산) | 매수 이후 흐름(기간) |
| 단위 | 포트폴리오(종목 여러 개) | 목록 + 종목 | 종목 1개 |

실측 발견: ⓐ 인증카드 '주식 현황'은 상세·주식 목록의 **사진**이다 — 새 지표가 없고 종목 한 장과 단위(전체 vs 1개)가 다르다. 겹침은 대부분 **상세·주식 펼침 ↔ 종목 한 장**에서 생긴다. ⓑ **금액 표시를 꺼도 행의 'N주'는 그대로 노출**된다(`StockRowHeader` 수량 줄은 마스킹 대상 아님). 수량×공개 시세로 평가금액이 역산된다 — '금액 가리기'가 약속을 못 지킨다.

## ③ 권고: 안 3 (펼침은 '옮김'만, 모양 재설계 없음)

**노선 한 줄**: 인증카드 = 남에게 보여 줄 **지금의 내 주식 전체** / 상세·주식 = **관리**(목록·입력·수정) / 종목 한 장 = 나만 보는 **이 종목의 시간**.

지표 정본(전수 대조, LEARNINGS 2026-10)
| 지표 | 정본 | 나머지 |
|---|---|---|
| 평가·손익(%)·수량 | 상세·주식 행 | 인증카드=같은 컴포넌트 캡처 / 종목 한 장 머리=같은 계산 함수(제목 역할, 새 숫자 아님) |
| 비중 % | 상세·주식 행·막대 | 인증카드 범례(같은 값) / 종목 한 장 **없음** |
| 오늘 등락 | 상세·주식 행 칩 | 종목 한 장은 기간 등락의 '오늘' 칸으로 같은 값 / 인증카드 없음 |
| 평단·총 매입·현재가·총 평가·환차·매입환율 | 상세·주식 펼침(유지) | 종목 한 장=그래프의 평단선 라벨만(칸 반복 없음) |
| 보유기간·매수일·연환산 | **종목 한 장으로 이동** | 펼침에서 제거 |
| 기간 등락·시장 대비 | 종목 한 장(종목 1개) | 성과 › 시장 비교 = 포트폴리오 표(4.72), 종목 줄은 종목 한 장으로 연결 |
| 거래 목록 | 종목 한 장 '거래' 절 | 펼침 '거래내역' 버튼 → '종목 보기 ›'로 교체. '거래입력'은 펼침 유지 |
| 배당 일정·분류 | 성과·배당 / X-Ray(정본) | 종목 한 장은 이 종목 1줄씩만 |
| 가격 흐름·평단선·매수 점 | 종목 한 장(신규) | 인증카드·펼침 **넣지 않음** |

진입: 펼침 안 '종목 보기 ›' 1곳 + 성과 › 시장 비교 종목 줄 탭(4.72에서 뺀 '종목 줄 탭 이동'을 여기서 연다). 행 탭 동작(펼침)은 그대로. 새 메뉴·새 하단 칸 0.

**뺀 것(대표 알림에 명시)**
- 종목 단위 공유(인증카드 4번째 타입) — 노선 유지.
- 인증카드에 기간 등락·시장 대비·가격 흐름 넣기.
- 펼침 '요약 2줄' 재설계(4.79 사업 절 ③) — 피로 영역이라 '옮김 1줄'로 축소.
- 가격 흐름은 **최근 1년 고정**. 매수 1년 넘은 장기 보유자의 '매수 이후 전체'는 v1 제외(LEARNINGS 11-11: 장기투자자 기간은 대표에게 보인다). → 대안 '매수일부터(최대 5년)'를 cto 비용 판정으로 결정.
- 목표가·알림·평가어('비싸다/싸다'), 다른 종목과 비교, 비상장·상장폐지 종목의 가격 흐름(종목 한 장은 열리되 흐름 칸은 '시세 없음').
- 매수 점은 사용자가 적은 날짜를 **표시만** 한다(판별·자동 연결에 쓰지 않음, LEARNINGS 11-11).

사업 절(4.79 C)에 대한 의견: **이견** — ③ '펼침 요약 2줄 축소'를 '보유기간·매수일·연환산 줄 이동 + 거래내역 버튼 교체'로 줄인다(대표 피로 영역 회피). 성공 지표 중 `상세·주식 거래내역` 활성 1→2는 거래내역이 종목 한 장 절로 흡수되면 측정 불가 → 새 title 기준으로 바꿔야 함.

## ④ 넘길 질문
**business-pm**
1. 인증카드 '금액 끔 → 수량도 가림'을 이 릴리스에 묶을지, 별도 품질 수정(빠른 경로)으로 먼저 낼지.
2. 성공 지표 재설계: `상세·주식·종목` 활성·조회/사용자 + 거래내역 흡수 후 대체 지표. 가드레일 `상세·주식` 활성 6 유지.
3. 가격 흐름 기간: 1년 고정 vs 매수일부터 — 대상 사용자(장기 보유) 기준 판단.
4. 노선 문장('보여주기/관리/시간')을 대표 알림 첫 줄로 쓸지.

**cto**
1. 가격 이력 출처·캐시(국내·미국·ETF 일봉, 종목코드만 서버 전송, 사용자 공통 CDN 캐시 가능한지). 1년 vs 5년 비용 차이.
2. 라우팅·식별: 새 view(`{type:"stock", key}`)의 키를 그룹 키(종목코드 기준, 시스템 값)로 — 증권사 나눔 종목은 합산 1장인지.
3. 인증카드 수량 노출이 '보안·데이터 문구' 범주(머지 위임 ⑤)에 해당하는지, 인증카드 변경의 대표 확인 필요 여부.
4. 펼침 1줄 이동이 '기존 화면의 큰 UI 방향 변경'(위임 ⑦)인지 판정.
