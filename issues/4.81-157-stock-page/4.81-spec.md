# 4.81 종목 한 장 — spec (#157, planner-designer, 2026-11-11)

입력: `4.81-direction-draft.md`, `4.81-business.md`, `4.81-challenge.md`(판정: 축소, 전부 반영), origin/main 9394371 코드.

**노선(대표 알림 첫 줄)**: 인증카드는 **보여 주기**(내 주식 전체의 지금, 공유), 상세·주식은 **관리**(목록·입력·수정), 종목 한 장은 **이 종목의 시간**(나만 보는 매수 이후 흐름). **같은 숫자는 같은 계산으로만 보이고, 새 숫자는 각자 한 곳에만 있다.**
차별점(알림 둘째 줄): 여러 증권사에 나눠 산 종목의 **합산 평단선**, 그리고 **5년** 흐름.

## 1. 문제
상세·주식(활성 6, 1인당 4.5뷰)에서 종목을 눌러도 숫자 칸(펼침)만 열린다. 증권사 앱 차트의 평단선은 그 계좌 기준이고, 엑셀의 매수 기록은 가격 흐름 위에 얹을 수 없다. "산 뒤로 이 종목이 어떻게 흘렀고, 합친 내 평단은 그 흐름의 어디인가"를 볼 곳이 없다.

## 2. 목표 행동
- 상세·주식 펼침에서 '종목 보기 ›'를 눌러 종목 한 장을 연다. 1년/5년을 바꿔 보고, 매수 점을 눌러 그날 거래를 확인한다.
- 여러 종목을 연달아 보거나 다시 온다(`상세·주식·종목` 조회/사용자 2 이상).

## 3. 범위
- **포함**: ① 새 화면 `#detail/stocks-item`(종목 한 장) ② 가격 흐름(1년 일봉 기본·5년 주봉, 수정주가) + 합산 평단선 + 매수 점 ③ 진입 2곳: 펼침 '종목 보기 ›' 1개, 성과 › 시장 비교 `market-list-row` 탭 ④ 새 서버 조회 1(요청값 `ticker`·`range`만).
- **바뀌는 곳**: 펼침 그룹 머리에 링크 1개 추가(분할·비분할 같은 자리). 시장 비교 종목 줄이 눌린다. 거래내역의 '뒤로'가 연 곳으로 돌아간다.
- **그대로**: 펼침의 기존 칸·버튼·메타 줄·메모·증권사별 항목, 상세·주식 행·막대·정렬, 인증카드 전부(diff 0), 시장 비교 표·계산, 저장 스키마·키·동기화.

## 4. 사용자 흐름
1. 상세·주식 → 종목 행 탭 → 펼침이 열린다(지금과 같음).
2. 펼침 그룹 머리의 '종목 보기 ›' 탭 → 누른 행의 그룹(`groupStockIds`, 지금 탭의 `groupKeyOf` 기준) 그대로 종목 한 장이 열린다. 상단 뒤로 라벨 '주식'.
   - 성과 › 시장 비교 종목 줄 탭 → '전체' 그룹(`t:ticker`)으로 열린다. 뒤로 라벨 '뒤로'(진입 화면으로 복귀).
3. 머리: 종목명·(티커 · 시장)·계좌 배지 / 평가금액 / **내 수익** 금액(%) / 총 N주. 값은 누른 행과 같은 계산(`mergeStockGroup`+`computeStockMetrics`).
4. 가격 흐름: 기간 선택 `1년 | 5년`(기본 1년, 5년은 탭 시 조회). 선 아래 정의 1줄. 차트 머리 라벨은 **'1년 주가 등락' / '5년 주가 등락'**(내 수익과 같은 라벨 금지).
5. 평단선: `mergeStockGroup` 가중 평단(종목 통화). 라벨 `내 평단 {가격}`. 차트 범위 밖이면 축을 넓히거나 `평단 ↑`/`평단 ↓` 표시(ui.md에서 결정).
6. 매수 점: 그룹 거래 기록 중 `type === "buy"`만, 기록 날짜의 **차트 위 위치**(그날·그 주 종가)에 찍는다. 거래 단가를 y값으로 쓰지 않는다. 점 탭 → `{날짜} 매수 {수량}주 · {거래 단가}`.
7. 창 밖 매수: 1년에서 `1년보다 전 매수 N건 · 5년에서 보기`(누르면 5년 전환), 5년에서 `5년보다 전 매수 N건`.
8. 링크 줄 `거래내역 N건 ›` → 기존 거래내역 화면(같은 `useTradeViewStore` target). 거기서 뒤로 → 종목 한 장.

## 9. 완료 기준 (qa가 그대로 검사)
1. 상세·주식 펼침(분할·비분할 모두)에 `stock-page-entry`가 1개 있고 히트 영역 40×40px 이상이다. 그 밖의 펼침 DOM(칸·버튼·메타 줄·메모·증권사별 항목)은 main 대비 변경이 없다.
2. 진입 시 URL 해시는 `#detail/stocks-item`이고 GA `page_title = 상세·주식·종목` page_view가 1회 기록된다. 해시·page_title·page_location에 종목명·티커가 없다.
3. 머리의 평가·내 수익·수량, 평단선 값이 누른 행·펼침 값과 같다(전체 탭, 계좌 필터 탭 각각, 테스트 단언).
4. 가격 조회 요청의 URL·본문 키는 `ticker`·`range` 2개뿐이고 `range`는 `1y|5y` 외 값이 거부된다. 수량·평단·날짜 전송 0. 5년은 탭 전 요청 0.
5. C76 수용 6구간: ① 거래 0·분할 0 → 점 0 + `stock-page-no-trades` ② 증권사 2곳 → 합산 평단선·두 계좌 점 ③ 1년 밖 매수 → `stock-page-outside` N건, 5년에서 점 표시 ④ 분할 전 매수 → 점이 수정 차트 위, 탭 시 원단가 ⑤ 상장 1년 미만 → 있는 구간만 + 정의 줄 ⑥ 비상장·상장폐지 → `stock-page-no-price`, 서버 요청 0.
6. 매수 점은 거래 기록으로만 생기고 `purchaseDate`만 있는 종목에는 생기지 않는다.
7. `stock-page-change` 라벨에 '수익'이 없고 머리 라벨에 '등락'이 없다.
8. 시장 비교 종목 줄 탭 → 종목 한 장(전체 그룹), 뒤로 → 시장 비교. 종목 한 장 → 거래내역 → 뒤로 → 종목 한 장 → 뒤로 → 상세·주식.
9. 새로고침 시 상세·주식으로 이동, 오류 0. 인증카드 3종·시장 비교 계산·저장 키 diff 0. 320·375·1280 가로 넘침 0.
