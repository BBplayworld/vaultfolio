## 경험 절 (planner-designer)

**누구**: 성과 › 배당에서 월별 배당 종목 표를 보는 보유자. 확인하려는 것은 "이 종목에서 얼마 받았고 얼마 받을 예정인가"다.

**이후 관찰 가능한 행동**: 행을 볼 때 종목 이름 → 지급·예상 금액으로 시선이 바로 간다. 코드 줄을 건너뛰지 않는다. 누를 수 없는 행에 마우스를 올려도 반응이 없어서 클릭을 시도하지 않는다.

**바뀌는 화면 (이 표 1곳뿐)**
- ① 종목 코드 삭제: md 이상 이름 옆 코드(232행), md 미만 보조 줄의 코드(224행). 이름은 `stock.name || ticker` 폴백을 유지한다.
- md 미만 보조 줄에는 주기 배지(연간·반기·분기·월배당)만 남긴다. **주기가 없으면 보조 줄 자체를 그리지 않는다**(빈 줄의 `mt-0.5` 여백도 없앤다).
- ② 행의 `hover:bg-muted/30 transition-colors` 삭제.
- ③ 지급·예상 금액(원화 굵은 값)은 md 이상에서 `text-sm`. 모바일은 ui가 360·390에서 실측한다. 3.5rem 열에 말줄임·줄바꿈 없이 들어갈 때만 키우고, 아니면 `text-xs`를 유지한다.

**그대로인 곳**: 그룹 머리, 열 머리, 열 폭·배치(5.115 R-2 B 확정), 패딩·gap, 배당월 칩, 주당 열, `매수 날짜` 줄, $ 보조 값(text-xs 유지), 계산, 빈 상태 문구, 배당 탭의 다른 블록, 다른 탭.

**줄이는 것**: 코드 표시 2곳, hover 1곳. 추가하는 요소는 0이다.

**하지 않을 것**: 행을 누를 수 있게 만들기(상세 이동), 열 재배치·폭 변경, 주당 열·$ 값 크기 변경, 결산 화면·자산 변화 달력(d3 B·C, 12/11 이후).

**엣지**
- 이름 없는 종목: 이름 자리에 티커가 1회만 나온다. 같은 행에 코드가 또 나오지 않는다.
- 640~767px(sm 열 폭, md 미만): 보조 줄은 주기 배지만 남는다. 금액은 이 구간에서 `text-xs`를 유지한다(md 기준). 코드 줄이 빠져도 오른쪽 열(주당 3줄)이 행 높이를 정하면 높이가 그대로이며, 이것이 정상이다(C115).
- 주기 정보 없음: 보조 줄이 사라진다. 행 높이는 줄거나 같아야 하고 늘면 안 된다.
- 데이터 로딩 중·배당 없음·선택 월 종목 없음: 기존 표시와 같다.
- 국내(원화만) 종목과 USD 종목(USD는 $ 보조 줄 + 원화 값) 모두 금액 정렬이 오른쪽 끝에서 맞는다.

## spec

1. **문제**: 표의 핵심 값인 지급·예상 금액이 12px이고, 행마다 종목 코드가 시선을 나눈다. #224에서 대표가 지적한 모양이 같은 성과 허브의 다음 탭에 남아 있다.
2. **목표 행동**: 이름 → 금액 순서로 바로 읽는다. 누를 수 없는 행을 누르려 하지 않는다.
3. **범위**: 위 경험 절 ①~③. 범위 밖 변경이 생기면 위임 머지 대상에서 제외하고 cto가 재판정한다.
4. **흐름**: (1) 성과 › 배당 진입 → (2) 전체 또는 월 선택 → (3) 그룹별 표에서 종목 이름 확인 → (4) 같은 행 오른쪽 지급·예상 금액 확인. 흐름의 단계 수는 바뀌지 않는다.
5. **정보 구조 대조**: 이번에 새로 생기거나 옮겨지는 지표는 0이다. 종목 코드만 이 표에서 빠진다. 코드의 정본 위치는 종목 상세·거래 화면 머리(`stock-page-view`·`stock-trades-view`)이고 그대로 둔다.

**완료 기준 (qa가 그대로 확인)**
- AC-1. 360·390·430·1280 다크와 390 라이트에서, 전체·월 선택 두 상태 모두 이 표의 어느 행에도 종목 코드(font-mono 티커)가 보이지 않는다.
- AC-2. 이름 없는 종목은 이름 자리에 티커가 정확히 1회 표시된다.
- AC-3. 767px에서는 보조 줄에 주기 배지만 있다(주기가 없으면 보조 줄이 없다). 768px에서는 배지가 이름 옆에 있다.
- AC-4. 768px 이상에서 지급·예상 원화 금액의 계산된 font-size가 14px 이상이다. 모바일은 ui 실측 결과(유지 또는 확대)와 일치한다.
- AC-5. 행에 마우스를 올려도 배경색이 바뀌지 않는다.
- AC-6. 각 행의 높이·줄 수가 main 이하다(늘면 FAIL). 360에서 이름 잘림 외 가로 넘침 0, 금액 말줄임·줄바꿈 0, `document.documentElement.scrollWidth` = 뷰포트 폭.
- AC-7. 주당·지급·예상 금액, $ 보조 값, `-` 표시가 국내·USD 종목 모두 main과 같다.
- AC-8. 열 폭(grid-cols)·패딩·gap 클래스 diff가 0이다. 저장·동기화·서버 전송·계산 diff가 0이다(C11 grep 0줄). type-scale-guard·tsc·vitest를 통과한다.
