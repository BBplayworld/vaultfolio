## 1. 눈금·오늘 가격 (행 밴드 + 종목 한 장 공통)

### 1-1. 구조(우측 가격 칸)
- SVG는 **픽셀 좌표**(`useBoxSize` 패턴, `preserveAspectRatio="none"` 폐기 — 글자 찌그러짐 방지). 행 밴드도 종목 한 장과 같이 박스 실측 폭·높이로 그린다.
- 플롯 오른쪽에 가격 칸 폭 `gutter = clamp(오늘 가격 글자수 × 6.4 + 10, 46, 76)`px. 목업 실측: KRW `70,000원` 54.8px, USD `$214.3` 48.4px. 플롯 폭 = 박스 폭 − 좌 여백 − gutter (320 행 밴드 256 → 플롯 ≈ 199px).
- 그리는 순서(아래→위): 눈금선 → 면적(종목 한 장과 같은 gradient 12%→0, **행 밴드에도 동일 적용**) → 가격선 → 평단선 → 매수·매도 점 → 오늘 점 → 가격 칸 글자.
- 눈금선: 실선 1px, `stroke: var(--foreground)` 불투명도 **0.12**(라이트·다크 같은 값, 목업 다크에서 식별 확인), 플롯 폭 전체. **평단선(점선 4 3, foreground/70)과 반드시 구별**(실선·훨씬 옅음).
- 눈금 라벨: `text-[10px] tabular-nums fill-muted-foreground`, 가격 칸 왼쪽 정렬(x = 플롯 끝 + 6), 세로 중앙 = 선 y(baseline y+3.5). 선 위에 올리지 않는다.

### 1-2. 눈금 선택 규칙 `niceTicks`
1. 후보 간격 = {1, 2, 5} × 10^k (2.5 제외 — 라벨 소수 방지). **도메인은 기존 `computeYDomain` 결과**(평단 포함·PAD 8%)를 그대로 쓰되 **입력 min·max는 원본 points(다운샘플 40점 아님) + 오늘 가격**을 포함한다. 눈금 숫자는 읽는 값이라 선이 최고 눈금 위로 삐져나가면 안 된다(tech-review 1항).
2. 간격이 **픽셀로 12px 이상**인 후보만. 눈금 y는 플롯 위·아래 **6px 안쪽**만 허용.
3. 충돌 제거: 평단선과 |Δy| < 10px 이면 그 눈금을 버린다(점선과 같은 높이 중복 방지). 오늘 태그와는 눈금이 태그 **위**면 ≥12px, **아래**면 ≥20px(태그 2줄 높이) 떨어져야 한다.
4. 제거 후 남는 개수가 **2~3인 가장 작은 간격**을 택한다. 없으면 1개, 그것도 없으면 0개(눈금 없이 오늘 가격만 — 정상 상태, 오류 아님). 눈금 사이가 비어 보여도 등차를 억지로 채우지 않는다.
- 목업 결과: 삼성 1y 평단 61,000·오늘 70,000 → `5만`·`4만`(2줄), USD 평단 183.4 → `$160`·`$200`(1280은 `$220` 포함 3줄), 삼성 5y 진동 → `5.5만`·`6만`·`7만`.

### 1-3. 라벨 표기 `formatAxisPrice(value, currency, step)` (신규 1개, stock-page.ts)
| 통화 | 규칙 | 예 |
|---|---|---|
| KRW | ≥1억 `1.5억`, ≥1만 `5만`·`7.5만`·`12만`(소수 둘째 자리까지, 뒤 0 제거), 1만 미만 `5,000` — 단위 글자 `원` 생략 | `4만` `5.5만` `1.2억` |
| USD | `$` + 정수(간격 ≥1), 간격 <1이면 간격 자릿수만(`$12.5` `$0.25`), 천 단위 쉼표 | `$160` `$1,500` `$12.5` |
| JPY | `¥` + 정수, 천 단위 쉼표 | `¥1,500` |
- C58·C59 적용: 눈금은 **정확히 1·2·5×10^k인 둥근 값**이라 축약으로 해상도를 잃지 않는다(`7.5만` = 75,000 정확). 부동소수 방지: 눈금 값은 정수 단위 곱으로 생성(`Math.round(i*step)`), 곱셈 뒤 floor 금지. 정밀 값(호버·태그·칩)은 기존 `formatPrice` 그대로.
- 라벨 소수 자릿수는 라벨마다 따로 trim(`5.5만`과 `6만` 혼재 허용 — 0 붙이기 `6.0만`은 노이즈).

### 1-4. 오늘 가격 태그
- 값 = **`head.merged.currentPrice`**(머리 평가금액이 쓰는 값, C65 — tech-review 1항 권고 채택). history 마지막 점이 아니다. 같은 값을 행 이름 줄 아래 둘째 줄 문구에도 쓰지 않는다(중복 금지 — 태그가 유일한 가격 노출).
- 위치: 플롯 오른쪽 끝(x = 플롯 끝), y = `yOf(currentPrice)`. **작은 점(r 3.5, 선 색, `--card` 2px 외곽)** + 가격 칸에 **2줄**: 위 `formatPrice(currentPrice)` `text-[11px] font-semibold fill-foreground tabular-nums`, 아래 `오늘` `text-[10px] fill-muted-foreground`. 선 끝점과 값이 장중에 조금 달라도 점은 `currentPrice` y에 찍는다(차이는 80px 밴드에서 1px 미만이 일반적).
- 도메인 min·max에 포함하므로 태그가 범위 밖으로 나가지 않는다. `currentPrice`가 없거나 0이면 태그·점 생략(눈금은 유지).
- 폭 부족(가격 칸이 플롯의 40% 초과)이면 `오늘` 줄만 생략하고 가격만.

### 1-5. 행 밴드(상세·주식 펼침 이름 줄)
- 구조: 버튼(줄 전체, 불변) = [이름 블록 flex-1 + `›`] 위줄 / 밴드 아래줄(`basis-full`, `mt-2`, **h-20(80px)**, `aria-hidden`). 둘째 줄 `1년 주가 등락 +90.6%`(whitespace-nowrap)·평단 점선·색 규칙(선 = `getProfitLossColor(change)`)은 4.83 그대로. 평단 라벨: 가격 칸에 `평단`(10px muted) — 오늘 태그와 |Δy|<26px면 생략(평단선만 남김, 목업 삼성 375).
- 플롯 상하 여백 8px, 좌 2px, x축 날짜 라벨 없음(둘째 줄이 "1년"을 말함).
- 상태·높이 불변(4.83 qa D1 유지): 로딩 = 밴드 크기 `bg-muted/60 rounded animate-pulse` 예약 / 성공 / 실패(fallback)·geom 없음 = 같은 80px 빈 슬롯(`aria-hidden`) → **로딩=성공=실패 높이 동일**. `none`(가격 흐름 없는 종목)은 밴드 없음(현행 `내 평단 보기`). `screenshotMode`면 밴드 없음.
- 접근성: 밴드는 `aria-hidden`(버튼 안). 버튼 `aria-label`을 `${이름} 주가 흐름과 평단 보기, 1년 등락 ${+x.x%}, 오늘 ${가격}`로 확장(가격 정보를 스크린리더가 놓치지 않게). 키보드·포커스 링 불변.
- 모션: 밴드 진입 `motion-safe:animate-in fade-in duration-200`(스파크와 같음). 펼침 grid 전환은 기존 — **밴드는 펼침 패널 안 항상 마운트 구조 불변**, 재마운트 모션 소실 없음(데이터 도착 시 skeleton→chart 교체만 fade).

### 1-6. 종목 한 장 `price-chart.tsx`
- 우측 여백 `M.right 12` → gutter(위 공식). x축 끝 라벨(`2026.11`)은 플롯 끝에 맞춘다. 좌 여백 12 유지. 호버 라벨(y=12)·세로 가이드 불변 — 눈금 라벨은 가격 칸에 있어 호버 라벨과 안 겹친다.
- 눈금선·오늘 태그·점은 §1-1~1-4와 동일. 평단 칩(플롯 안 `내 평단 61,000원`)은 유지(이게 정확값 표기).
- 크기: 1280은 1152×288에서 눈금 3줄, 320은 264×192에서 2줄 — 목업 확인.

## 2. 평단 칩 폴백 (종목 한 장, 4위치 전부 겹침)
기존: 좌·우 끝 × 선 위·아래 4곳 중 "덜 겹치는 곳". 변경: **겹침 0인 곳만** 쓰고, 없으면 단계적 폴백.
1. **기본 4곳** 중 겹침 0(가격선·점)이 있으면 현행대로(동률 앞 후보). 점 여유 = 점 중심 ±8px 안은 겹침으로 본다.
2. 없으면 **스캔**: 평단선 기준 세로 오프셋 {−24, +4, −32, +12, −40, +20}px × 가로 8px 간격으로 겹침 0인 첫 칸(오프셋 작은 순). 평단선에서 멀어져도 같은 높이대라 읽힌다.
3. 스캔도 없으면 **짧은 글자**: `평단 6.15만`(`formatAxisPrice`), 1→2 반복.
4. 그래도 없으면 **가격 칸 라벨**: `평단`(10px foreground) + 아래줄 축약가(10px muted)를 평단선 y에. 오늘 태그와 |Δy|<26px이면 이 라벨은 태그 반대 방향으로 최대 10px 이동, 그래도 겹치면 `평단`만.
- 칩 글자 스타일 불변(외곽선 글자 `paintOrder stroke var(--card) 3px`, 면 없음). 평단이 범위 밖(clamped)이면 기존 `↑/↓` 유지, 폴백 단계는 동일 적용.
- 구현: 위치 계산을 **순수 함수 `placeAvgChip({points,dots,avgY,plot,full,short})→{x,y,mode:"plot"|"short"|"gutter"}`** 로 추출(테스트용). 테스트 데이터 = 삼성 5y형 진동(`screenshots/mock-chipfallback-*`: 320에서 `short` 위치 확인, 375·1280 기본 위치 확보).

## 3. 매도 점
- **모양·색**: 매수 = 채운 원 r5 `fill-rose-500`(현행). 매도 = **마름모**(정사각 45° 회전, 반대각 반경 6.5px = 면적 원 r5와 동급) `fill-blue-500`. 둘 다 `--card` 외곽 2.5px. 선택 시 매수 r7 / 매도 반경 8.5 + 기존 brand 고리 r11(2px). 라이트·다크 같은 색(매수 점 현행과 동일 방식).
- **같은 봉·인접(가로 12px 미만)에 매수+매도**가 있으면 매수 −6px, 매도 +6px 가로로 벌린다(점 위치 y = 그 봉 종가 불변). 같은 종류끼리는 기존처럼 한 봉 한 점.
- **히트**: 반경 = 이웃(매수+매도 모두) 거리의 절반, 최소 10·최대 20. 단 벌린 쌍은 6(기존 최소 10과 충돌하면 좌우 반분). 키보드 순서 = 날짜순, 같은 봉이면 매수→매도. 선택 키 = `{kind, index}`. `aria-label` = `2026.09.18 매도 10주 · 67,800원`, `aria-pressed` 유지.
- **상세 줄**: 앞에 8~12px 모양 아이콘(●/◆, 색, `aria-hidden`) + `2026.09.18 매도 10주 · 67,800원`(글자 foreground, 13px tabular-nums — 의미를 색에 의존하지 않음). 최대 3줄 + `외 N건` 현행.
- **범례/힌트**(슬롯 min-h-10 유지, 높이 점프 0): 점에 매수·매도가 **둘 다** 있으면 위줄 `● 매수  ◆ 매도`(12px muted, 아이콘 색) + 아랫줄 `점을 누르면 매수·매도 기록을 볼 수 있어요`. 한 종류만이면 아이콘 범례 없이 `점을 누르면 매수 기록을…`(현행)/`매도 기록을…`. 점 없음(거래 없음) `매수를 기록하면 산 날이 점으로 표시돼요` 현행 유지.
- **창 밖 건수**: 매수만이면 `1년보다 전 매수 N건`(현행·`5년에서 보기` 링크 유지), 매도 포함이면 `1년보다 전 거래 N건`. 5년 창 동일. 정의 줄 `점은 기록한 매수 날짜에 찍혀요` → 매도 점이 있으면 `점은 기록한 매수·매도 날짜에 찍혀요`.
- **불변**: 평단선·합산 평단은 매수만(매도는 점 표시 전용). 5년 주봉 규칙 `placeBuyDots(W)` 그대로 재사용. 행 밴드(미니)에는 점 없음.

## 4. 시트·홈 팁 X, 더보기 포커스
- **홈 새 소식 팁 X**: 현재 버튼 `-m-2 p-2` + 아이콘 16 = 박스 32px(+`after:-inset-1`로 실효 40이지만 측정 박스가 32라 검수마다 걸림). → **`-m-3 p-3`로 박스를 40×40으로**, `after` 제거. 시각(아이콘 16px 위치)·카드 레이아웃 불변(음수 마진 상쇄), 카드 p-4 안이라 가장자리 넘침 없음. `home-tip-close` 기준 getBoundingClientRect 40×40.
- **PC 시트 X**(공용 `sheet.tsx` Close, 아이콘 size-5 sm:size-6 = 20~24px): 아이콘 크기·위치 불변, 버튼에 `after:absolute after:content-[''] after:-inset-2.5 sm:after:-inset-2`(= 40px) 추가(버튼이 `absolute`라 pseudo 기준 성립). 사용처 3곳(whats-new PC·사이드바 모바일·FAB 시트 PC)에 영향 — 시각 변화 0이라 허용, 사이드바 우측 겹침만 qa 확인. 포커스 링은 현행(버튼 박스).
- **Esc 후 포커스**(`whats-new-sheet.tsx onCloseAutoFocus`): 이동 경로(`goneRef`)만 예외, 나머지(홈 팁·더보기 포함)는 `main`에 `tabindex=-1` 포커스. `main` 포커스 시 **포커스 링 안 보임**(outline-none 확인). 문구·모션 변경 없음.

## 8. 품질 체크리스트 (qa 판정용, 375·320·1280 × 라이트·다크, 쿠키 theme_mode + 캡처마다 html.dark 로그 C81·C85)
1. 행 밴드: 펼친 행에 눈금 2~3줄(또는 규칙상 1~0줄)·오늘 태그(`오늘`+가격)·평단 점선이 보이고, 태그 가격 문자열 = 같은 종목 머리 `현재가` 문자열(C65).
2. 눈금 값 = 1·2·5×10^k(`4만`·`$160` 등)이고 도메인 안, 서로·평단선·태그와 글자 겹침 0, 가장 높은 눈금보다 가격선이 위로 삐져나가지 않음(원본 min/max 기준 단위 테스트).
3. 행 높이 로딩=성공=실패 동일(320·375·1280 각각, 4.83 D1 회귀 0), 접힌 행·`none` 행 높이 불변, 가로 스크롤 0.
4. 320에서 밴드 폭 ≈256·플롯 ≥190px, 가격 칸 글자 잘림 0, 둘째 줄 `1년 주가 등락 +x.x%` 한 줄.
5. 종목 한 장 1y·5y에 같은 눈금 규칙·같은 가격 칸 표기(KRW `만`, USD `$`), 평단 칩·호버 라벨·점과 겹침 0, x축 라벨 정상.
6. 칩 폴백: 삼성 5년(4위치 전부 겹침) 칩이 가격선을 가리지 않음(`data-mode` plot|short|gutter), `placeAvgChip` 단위 테스트가 합성 데이터로 3분기 통과.
7. 매도 점: 파랑 마름모, 매수 빨강 원과 모양으로 구분(흑백 캡처에서도 구분). 같은 봉 매수+매도는 ±6px로 둘 다 탭 가능, Tab 순서 날짜순·매수→매도, `aria-label`에 `매도`.
