## 결함 (developer가 바로 고칠 수 있게)

**D1 (중, 필수) 5년 차트 y눈금 `$-0` 표기** — NVIDIA 5년 @1280 다크(`uirev-D1-…neg0.png`, 가격 칸 맨 아래 눈금이 `$-0`). 원인: 도메인 하한이 0 미만일 때 `niceTicks`의 `first = Math.ceil(lo/step)`이 `-0`이 되고 `v = i*m*pow` = `-0` → `formatAxisPrice`가 `(-0).toLocaleString()` = `"-0"` 출력. 같은 종목 375는 `$50`, 320은 `$50`으로 정상이라 폭에 따라 나타남(눈금 개수 규칙 때문).
- 파일: `src/lib/finance/stock-page.ts` `niceTicks`(v 계산 직후)·`formatAxisPrice`
- 기대값: 눈금 값 `-0`/음수 없음. v를 `v === 0 ? 0 : v`(또는 `+ 0`)로 정규화하고, 가격 눈금은 `v < 0` 제외(주가는 0 미만 눈금이 무의미). 0 눈금이 남아도 라벨은 `$0`·`0`. 단위 테스트 `formatAxisPrice(-0,"USD",50)` → `$0`, `niceTicks(-3, 220, …)`에 `-0` 없음, 5년 NVDA형 픽스처(최저가≈0 부근) 추가. 수용 기준 A2·A3 보강.

**D2 (중, 필수, C25) 320px에서 지연 문구 `평소보다 오래 걸려요. 잠시만 기다려 주세요`가 어절 중간에서 끊기고 레이아웃이 밀린다**
- 시장 비교 카드(`uirev-D2-market-slow-320-dark.png`): `…기다려 주 / 세요` 어절 중간 줄바꿈. 5초에 문구가 바뀌면서 표가 +19px 내려갔다가 완료 시 되돌아옴(`보유 종목` 머리줄 y 237 → 완료 218). 375·1280은 한 줄이라 점프 0(218=218, 199=199 확인).
- 성과 허브 배당 카드(`uirev-D2-hub-slow-320-light.png`): `…기다 / 려 주세요` 어절 중간 줄바꿈, 카드 +17px(허브 H 913 vs 완료 894). 
- 종목 한 장 차트 pill(320): 두 줄 줄바꿈(`기다려 / 주세요`, 어절은 유지)·스피너가 두 줄 사이에 떠 정렬이 어긋남. 점프는 박스 고정이라 0.
- 파일: `src/components/ui/loading-note.tsx`(`SLOW_LABEL`, `<p>` 클래스), 호출처 `market-compare-view.tsx`(`market-loading-slot` min-h-5)·`performance-hub.tsx`(`className="min-h-5"`).

## 권고 (소, 수정 권장·비차단)

**R1 평단 칩이 가격 칸 눈금·현재가 태그와 붙어 보임** — 삼성전자 1년 @320 라이트/@375 다크(`uirev-D3-samsung-1y-320-light-chip.png`): 칩 `내 평단 61,000원` 오른쪽 끝이 gutter 첫 눈금 `10만`과 약 2.5px, 그 아래 `70,000원`과 세로 20px로 3개가 한 덩어리처럼 읽힘(겹침 0, C25 위반 아님). 기대: 칩 `plot` 모드의 right 한계를 plot 오른쪽 −4px 이상으로(`placeAvgChip`), 또는 칩 y가 gutter 눈금·태그 y ±12px 안이면 `short` 모드로 폴백.

**R2 성과 허브 `aria-busy` 없음** — `#activity` 로딩 중 `[aria-busy=true]` 0개(시장 비교·종목 한 장은 1개 정상). ui-loading §접근성 8번. 허브 카드(배당·시장 비교 타일) 영역에 `aria-busy={loading}` 추가.

**R3 종목 한 장 로딩 윤곽선 위로 문구가 겹침** — 박스 안 흐린 곡선·가로선 위에 문구가 올라 라이트에서 글자가 선과 부딪힘(`ld-pg 320 light`). 문구 pill에 `bg-card/80` 정도 배경 또는 윤곽선 투명도 낮추기. 가독 문제는 크지 않아 비차단.

## 참고 (결함 아님, 대표/qa가 알아둘 것)
- **trial 데모 데이터 불일치**: 데모 `현재가`(삼성 70,000원·Apple $225 등)와 실시세 history 스케일이 달라 선 끝과 현재가 점이 떨어져 보이고(Apple 1년: 선 끝 $350대, 점 $225) 평단 점선·점이 맨 아래에 붙음. challenge 판정 ③(history 조작 금지, 점은 currentPrice y)대로이며 실데이터는 선 끝 ≈ 점. 대표 전/후 캡처는 이 영향이 가장 작은 삼성전자 행(선 끝 20만대·점 70,000원)이지만 육안으로 어긋남이 보임 → 알림에 "데모 값 기준" 한 줄 권장.
- **펼친 행 높이 증가 실측 +71px**(375, 삼성전자: `평단가` y 598→740 @2x ÷2). challenge의 "+88px"는 밴드 80+간격 기준, 실제는 배지가 이름 줄 안으로 올라가 줄어듦. 알림 문구는 `+71px`로 정정 권장.
- 종목 한 장 매수·매도 점 hit 영역은 22px(5년 주봉에서 서로 5~6px 간격, 같은 봉 ±6px 규칙대로 근접 점은 최근접 선택). 40px 규칙은 점 표현 한계상 4.81 매수 점과 동일 적용(회귀 아님).
- 사이드바 `SidebarMenuSkeleton`은 앱 화면에서 렌더되지 않음(해당 없음).
