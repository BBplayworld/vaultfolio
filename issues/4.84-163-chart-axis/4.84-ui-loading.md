# 4.84 공통 로딩 UI — 디자이너 의견·사양 (ui-designer)

대표 요청(2026-11-11): 시장 비교 등 외부 데이터 대기 화면이 빈 블랭크로 보임 → '불러오는 중'이 분명한 공통 UI.
근거 캡처: 운영 `?trial=1`, 375px, `theme_mode=dark` 쿠키(html class `dark` 실측, C81·C85). `/api/finance`·`/api/xray-classify`를 지연시켜 로딩 상태를 고정. 파일은 `screenshots/loading-*`.

## 1. 현황 전수 (외부 데이터 대기 화면)

| 화면 | 현재 표현 | 체감 문제 |
|---|---|---|

기존 공용: `ui/skeleton.tsx`(`bg-accent animate-pulse`, 사용처 사실상 사이드바뿐), `ui/spinner.tsx`(aria-label 영어 "Loading", motion-safe 아님), `Progress`. 화면마다 `bg-muted animate-pulse`를 즉석으로 써서 색·문구가 제각각 → **공통화 대상**.

## 2. 제안 — 3요소 공통 패턴

1. **보이는 스켈레톤(shimmer)**: 최종 모양·높이 그대로 예약(레이아웃 점프 0). 색은 `bg-foreground/[0.13]`(다크·라이트 자동, 신규 토큰 없음)에 가로로 흐르는 하이라이트 `foreground/[0.08]` 1.4s ease-in-out 반복. 카드 대비 명도차 약 0.1 이상으로 "비어 있음"이 아니라 "채워지는 중"으로 읽힘. `motion-safe:`만 움직이고 reduced-motion은 정적 막대(pulse도 정지). 하이라이트는 `::after`에 `transform`만 사용(`transition: all` 금지, will-change 불필요).
2. **상태 문구(`LoadingNote`)**: 스피너 14px(`motion-safe:animate-spin`, reduced-motion은 정적 링) + 13px muted 문구. **영역 맨 위**(표·차트 바로 위, 차트는 박스 중앙 pill)에 둔다. 카드 아래에 두지 않는다. 문구 자리는 처음부터 예약(min-h-6)해 나타나도 점프 없음.
3. **시간 단계(훅 `useLoadingPhase(active)`)**:
   - 0~0.5초: 스켈레톤만(빠른 응답은 깜빡임 없이 바로 내용으로)
   - 0.5초~: 상태 문구 페이드인(150ms, `motion-safe`) — "시세를 불러오는 중…"
   - 5초~: 보조 문구 교체 — "평소보다 오래 걸려요. 잠시만 기다려 주세요"
   - 실패·한도 소진: 스켈레톤 제거 → "불러오지 못했어요" + `Button size="sm" variant="secondary" min-h-10` "다시 시도". 시장 비교는 기존 60초 자동 재시도(최대 2회)를 유지하고, 소진 후에만 오류+버튼
   - 로딩 중 탭·기간 전환은 직전 상태 유지(재마운트로 스켈레톤이 되살아나지 않게 `key` 고정), 연타해도 단계 타이머는 영역 단위로 1개

**완료 전환**: 스켈레톤 → 내용은 내용만 `motion-safe:animate-in fade-in duration-150`(퇴장은 즉시, §6 subtle exit). 스켈레톤 높이=내용 높이라 점프 0.

### 문구(존댓말·투자 조언 아님, 명사만 화면별로 교체)
- 시장 비교·종목 시세: "시세를 불러오는 중…" (기존 '기준가 조회 중…'은 내부 용어라 폐기)
- 차트: "가격 흐름을 불러오는 중…" / 배당: "배당 정보를 불러오는 중… 3/8"(진행 수 `tabular-nums`) / X-Ray: "종목을 분류하고 있어요 · 0/6"
- 지연: "평소보다 오래 걸려요. 잠시만 기다려 주세요" / 실패: "불러오지 못했어요" + "다시 시도"
- 숫자 자리(허브 배당 등)에 문구를 값 크기로 쓰지 않는다: 값 자리는 스켈레톤, 문구는 작은 LoadingNote.

### 접근성
- 영역 `aria-busy="true"`, 스켈레톤 `aria-hidden`.
- 화면당 `role="status"`(live polite) 1개: 문구는 sr-only로 0초부터 존재(시각 문구는 0.5초 뒤). 중복 낭독을 막으려고 시각 LoadingNote 자체는 `aria-hidden`.
- 오류만 `role="alert"` 대신 polite 유지(버튼으로 포커스 이동 없음). 다시 시도 버튼 40px 이상.
- `Spinner`의 영어 aria-label을 쓰지 않고 LoadingNote가 문구 담당. 라이트·다크 모두 문구 `text-muted-foreground`(대비 AA).

## 4. 구현 지침 (developer 전달용)
- `ui/skeleton.tsx`를 shimmer로 교체(공용), `globals.css`에 `@keyframes shimmer` 1개 + `motion-safe` 전용 유틸. 화면별 `bg-muted animate-pulse` 7곳을 `Skeleton`으로 치환.
- 신규 공용 2개를 `components.md`에 등록: `LoadingNote`(문구·단계·sr-only role=status), 훅 `useLoadingPhase`. 색·간격 신규 토큰 없음(`foreground/13`, 4px 그리드, gap-2). design-system §6에 "로딩 패턴" 3줄 흡수 필요.
- 서버·저장 변화 0(UI 전용). 투자 조언·금액 문구 없음.

## 5. 품질 체크리스트 (qa 판정용)
1. 지연 주입(`/api/finance` 5초+) 상태의 375 다크 캡처에서 시장 비교·종목 차트·배당·X-Ray 각각에 "불러오는 중" 문구가 화면 안에서 보인다(스크롤 없이).
2. 스켈레톤이 카드 바탕과 구분된다(캡처 육안, 현재의 거의 투명 상태가 아님). 라이트·다크 둘 다.
3. 응답 300ms 이내인 경우 상태 문구가 한 번도 노출되지 않는다(`data-testid="loading-note"` 부재).
4. 0.5초 후 문구 페이드인, 5초 후 보조 문구로 교체된다(Playwright fake timers).
5. 완료 전후 영역 높이·콘텐츠 y좌표 차이 0px(레이아웃 점프 0, 375·1280).
6. 실패 시 "불러오지 못했어요"+"다시 시도"가 있고 버튼 높이 ≥40px, 누르면 재요청.
7. `prefers-reduced-motion: reduce`에서 shimmer·스피너 애니메이션 정지(computed `animation-name: none`), 문구는 동일.
8. 로딩 영역 `aria-busy=true`, 스켈레톤 `aria-hidden`, 화면당 `role=status` 1개, 완료 시 `aria-busy` 제거.
9. 기간·탭·시장 선택을 연타해도 스켈레톤 깜빡임·타이머 중복 없음(재마운트 없음).
10. "조회 중…" "조회 중..." "기준가 조회 중" 구 문구가 화면에 남지 않는다(전수 grep).
11. 허브 배당 값 자리에 큰 굵은 문구가 없다(값 크기 문구 금지).
12. CHECKLIST C81·C85: 캡처마다 html class·배경 RGB 기록, 대표용은 다크.
