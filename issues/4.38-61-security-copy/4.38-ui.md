## 3. 가운뎃점(·) 줄바꿈
- `·`(U+00B7) 앞뒤는 `keep-all`에서도 줄바꿈 기회가 될 수 있다. 카드2 "저장·전송되지 않아요"가 "저장· / 전송되지"로 끊기면 결함(C25)
- 처리: ui-review에서 320·375 실측. 끊기면 `SECURITY_COPY` 문자열에서 `·` 앞뒤에 WORD JOINER(`⁠`)를 넣는다(보이지 않음, 구조 변경 없음). 신뢰 한 줄은 이미 nowrap 묶음이라 해당 없음

## 4. 상태·모션·접근성
- 보안 상세 펼침(§6 grid-rows, `inert`)·앱가이드 다이얼로그 동작 무변경. 문구가 짧아져 펼침 높이가 줄어드는 것 외 변화 없음
- 다크·라이트: 토큰 무변경. 업로드 박스는 테두리 제거 후에도 라이트에서 다이얼로그 면(`bg-popover` 화이트) 위 `bg-muted/50`(0.88 계조) 톤차로 구분, 다크는 기존과 동일 수준
- 업로드 박스 본문은 사용자가 읽어야 하는 고지 → `text-muted-foreground`에 추가 투명도 금지(§11)

## 6. 교차 검토 의견(planner-designer, 문구 확정 범위 밖 — 수정 요청 아님, 후보 기록)
- 동기화 메뉴 설명·앱가이드 설명은 앞 문장이 "~합니다"체, 새 문장이 "~요"체라 한 단락 안 어투가 섞인다. 이번엔 spec대로 문장만 교체하고, 어투 통일은 후속 후보.
- 웰컴 `FeatureCard`·앱가이드 카드의 `text-[15px]`·`text-[13px]`은 §2 4단계 밖(기존 부채). 이번 범위 아님.
