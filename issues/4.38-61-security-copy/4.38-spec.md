# #61 보안 안내 문구 정정 — spec (초안)

기준(대표 확정): ①자산은 동기화를 켜지 않는 한 기기에만 저장 ②동기화는 이중 암호화로 관리자도 알 수 없음 ③서버 역할 나열·단정 금지. **모든 신 문구 [대표 동의 대기]**, 승인 전 코드 반영 금지.

## 1. 문제
실제 동작과 다르거나 단정적인 안내가 있다. 예) "데이터가 기기를 절대 벗어나지 않습니다"는 동기화·스크린샷 인식 사용 시 사실과 다르고, 업로드 박스의 "개인정보 측면에서 문제없습니다"는 법적 단정이며 이미지가 분석 요청으로 전송된다는 사실(`/api/parse-screenshot`)을 알리지 않는다.

## 2. 목표 행동
사용자가 스크린샷 업로드 전 안내를 읽고 오해 없이 진행/중단한다. (측정: 정성 — 기존 `screenshot_parse` 지표는 0건이라 판독 불가.)

## 4. PRINCIPLES 2장 (대표만 변경 가능 — 제안만)
현행: "사용자 자산 데이터는 기기 로컬에만 저장한다. 서버 역할은 두 가지뿐: 시세 제공, E2EE 동기화·공유 중계."
제안: "사용자 자산 데이터는 기기에 저장한다. 사용자가 동기화를 켠 경우에만 이중 암호화된 형태로 중계된다. 서버는 자산 내용을 알 수 없다. 서버로 보낼 수 있는 값은 사용자 보유 정보를 역산할 수 없는 값(종목코드·시세 조건)이다."
- 에이전트가 직접 수정하지 않는다. 대표 승인 시 반영(승인 방식은 대표 결정). 사업 절·PRINCIPLES 6장(마케팅)의 "자산은 내 기기에만" 계열 문구도 같은 기준으로 후속 정리 후보.
