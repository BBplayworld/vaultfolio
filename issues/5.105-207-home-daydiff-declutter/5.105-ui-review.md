## 1. 실측 폭 (ui.md 가정과 다름)
| 뷰포트 | 카드 안쪽 W(실측) | ui.md 가정 | 지수 구간 | 보조 줄 내용 폭 |
|---|---|---|---|---|
| 320 | 264 | 256 | 숨김(<300) | 187 |
| 360 | **304** | 296 | **표시(≥300)** | 304 (꽉 참) |
| 375 | 319 | 311 | 표시 | 319 (꽉 참) |
| 1280 | 548 | - | 표시 | 327 |
페이지 좌우 패딩이 16이 아니라 12여서 W가 +8. **임계값 300에서 360(W=304)이 숨김이 아니라 표시** → 요구("360 숨김")와 불일치.
- 전부 표시에 필요한 폭 = 라벨 60(`환율 상승`)+6+금액 55+6+`외 1개` 38+6+지수 구간 135+6+˅16 = **328**. 실제 라벨(`주식 시세 상승` 92px)이면 360. 이 폭이 안 나오는 360·375에서 라벨이 먼저 잘린다.
- 실제 결과: **360 `환…`, 375 `환율 …`로 라벨(변동의 핵심 정보)이 말줄임**. ui.md의 "③ 라벨 truncate = 마지막 완충"이 지수 구간을 살리려고 가장 중요한 라벨을 희생하는 방향으로 동작. main은 360·375 모두 라벨 전체 표시.
- `외 N개` 260 임계는 W=264(320)에서도 표시되고 내용 187 ≪ 264라 사실상 발동하지 않음(뷰포트 304 미만에서만 숨김). 보정 불필요.
- 보정 제안(택1, 구현은 developer): (A·권장) 지수 구간 `@max-[300px]:hidden` → **`@max-[360px]:hidden`**(W<360 숨김 = 뷰포트 <~404 숨김, 375·360 모두 라벨·금액·`외 N개` 온전). 지수는 패널 맨 아래 줄과 시장과 비교에 이미 있음. 대표 요구 "360 숨김"에 부합하나 ui.md의 "375 표시"는 포기. (B) 375 표시를 유지하려면 360 근처에서 `외 N개`를 먼저 숨기고(`@max-[330px]`) 라벨 `shrink-0`(truncate는 지수 쪽에) — 단, 긴 종목명에서 다시 잘리므로 비권장. 어느 쪽이든 숫자는 C99 쌍(`max-[N]`↔`min-[N]`) 규칙.

## 2. 히트 영역
- 보조 줄 버튼 높이 40px(상하 padding 10 포함) PASS(375). 패널 `접기` 40px PASS. 연타 6회 후 상태 일관(`aria-expanded=false`, 패널 `inert`) PASS.
- 경미: 카드 좌우 끝까지 확장(`after:-inset-x-4`)은 미작동 — 버튼 좌우 14px 바깥은 카드가 잡힘(버튼 폭 = 텍스트 영역 319px). 40px 기준엔 영향 없음, 기대값과 다름(참고).

## 4. 디자인 판단 (before / after)
- 줄 수: 접힘 상태 main = 변동 줄 + 보조 줄 1줄(지수는 카드 밖 별도 줄, 펼쳐야 보이던 패널과 분리) → PR = 보조 줄 1줄로 통합, 카드 밖 줄 0. **구조는 '깔끔'(1280에서는 확실한 개선)**.
- 인지성: 360·375에서는 한 줄에 라벨·금액·`외 N개`·지수·˅ 5요소가 몰려 **라벨이 말줄임** → '무엇 때문에 변했나'가 읽히지 않아 인지성은 main보다 후퇴. 지수 회색 `·` 구간이 시선만 분산.
- 펼침: 지수 줄이 패널 맨 아래로 들어가 헤어라인·정렬은 깔끔(+). 다만 접기와 맞닿아 아래 여백 약간 빡빡(참고).
- 결론: 의도 달성은 1280·넓은 폭 한정. 모바일 달성은 1번 보정 후.
