## 4. 원인 정렬·접기 규칙 (월 탭 전용)
1. 표시 순서 = `|amount|` 내림차순, 같으면 `mapped.causes`의 기존 순서(안정 정렬). 순수 함수(예: `orderMonthCauses`)로 분리해 단위 테스트한다. **`mapped` 자체는 바꾸지 않는다**(AI 질문 프롬프트·다른 소비처 순서 불변).
2. 분기: `CauseBlock` 안에서 `scope === "month"`일 때만 1번 정렬 + 3번 접기를 적용한다. `year`·`week`는 현행 `mapped.causes.map` 경로를 그대로 타서 DOM·순서·애니메이션 diff 0. 주 탭·홈의 `sortCausesByDate` 미변경.
3. 원인 3행 이하 → 정렬 순서로 전부 표시, `외` 줄 없음. 4행 이상 → 상위 2행 표시 + 나머지 패널(항상 마운트, 접힘 시 `inert`·`aria-hidden`·`grid-rows-[0fr]`, monthly-log/BenchmarkMore와 같은 패턴) + 토글 줄.
4. 토글 줄(접힘): 왼쪽 `외 N개`(N = 전체 − 2), 오른쪽 `signed(나머지 합)`·`getProfitLossColor`, chevron. 나머지 합 = `mapped.deltaNet − 상위 2행 합`(원 단위) → **보이는 2행 + 외 줄 합 = Hero 증감**. 펼침: 패널에 나머지 행이 정렬 순서대로 이어지고 토글 줄은 `접기`(금액 숨김, 이중 집계 방지). 버튼 높이 40px 이상, `aria-expanded`·`aria-controls`.
5. 예측 배지: 그룹 배지(예측 행 2개 이상 → 제목 옆 1개) 판정은 전체 원인 기준 그대로, 행 배지는 해당 행에 그대로. 그룹 배지가 없고 예측 행이 접힌 쪽에만 있으면 `외 N개` 줄에 같은 문구 배지(`estimatedLabel`, testId 없음) 1개.
6. `cause-row-*`·`cause-estimated-badge` testid는 패널 안에서도 유지. 행 등장 stagger는 보이는 2행만.

## 6. 연 탭 Hero 수정 (컷 1순위 · qa 재현 확정 후에만)
`currentYear` = KST 오늘의 연도. `latest` = 연도별 배열 마지막 항목.
- `latest` 없음 또는 `latest.year >= currentYear` → 현행 그대로.
- `latest.year === currentYear − 1`(올해 항목 없음, 작년 말 값 있음) → 비교·원인·`진행 중` 배지·자동 캡션 없음, 메시지 `올해 순자산이 기록되면 {latest.year}년 말과 비교해 드려요`(추가 링크 없음).
- `latest.year < currentYear − 1` → 메시지 현행 `작년 말 순자산을 넣으면 올해와 비교할 수 있어요` + `YearlyAddLink`.
- 체험 시드에 올해 항목 추가는 하지 않는다(C27). 연도별 목록·차트 변경 0.
