## 판단 요청 건 — 칩 코드 diff ≠ 0
**수용.** `WelcomeTrialLink`에 `inApp` prop이 붙었지만 바뀌는 것은 GA 인자뿐이다. 칩의 좌표·크기·문구·class 문자열이 운영과 같고(위 2번), 일반·설치 앱 화면은 픽셀 diff 0이다. cto 판정이 요구한 title 2종 구분('체험 모드·인앱' / '체험 모드·인앱 버튼')을 하려면 칩에 구분값이 필요하므로 '렌더 diff 0'이 지킬 수 있는 최선이다. AC-8의 '칩 관련 diff 0'은 '칩 렌더 diff 0'으로 읽는 것이 맞고, 문구 정리는 planner-designer 몫이다.
