# 4.xx 홈 전일대비 영역 정돈 — UI 사양 (ui-designer, 2026-11-14)

근거: `4.xx-spec.md` · discovery A안 · 코드 origin/main `home/dashboard.tsx`(Hero), `activity/market-entry-line.tsx`(`MarketLine`) · design-system §2·§3·§6·§7·§11. **신규 토큰·패턴 0**(현행 grid-rows 펼침·`SKELETON_FILL`·`@container` 재사용). 스크린샷은 못 찍음 → 폭 수치는 글자 폭 계산값이며, 구현 후 ui-review가 실측으로 확정(오차 ±8px)한다.

## 1. 미결 확정

### 1-1. Hero 전체 폭 배치
- 현행 원인 줄·패널은 좌측 열 안(`mt-1` div)이라 총자산·총부채 열(~110px)만큼 폭을 잃는다. **보조 줄·패널을 좌측 열 밖, 카드 내부 `px-4` 안쪽 전체 폭으로 옮긴다.**
- 구조: 카드 `rounded-lg px-4 py-4` 를 세로(`flex-col`)로 바꾼다. 위 행 = 기존 `flex items-center justify-between`(좌: 닉네임·순자산·금액·변동 줄 / 우: 총자산·총부채), 아래 = 보조 줄 + 패널 래퍼 `mt-1 w-full`. `hasRightSide` 없는 경우(성적표 배지)도 같은 래퍼.
- 우측 열 세로 중앙 기준이 (기존) 원인 포함 좌측 열 → (변경) 위 행으로 바뀐다. 우측 열이 약 10~20px 아래→위로 이동하는 건 의도(금액 줄과 맞춰짐). 우측 열·좌측 열 내부 텍스트의 줄바꿈은 불변이어야 한다(C98·C103).
- 히트 영역: 보조 줄 버튼 `after:absolute after:-inset-x-4 after:-inset-y-2.5`(카드 좌우 끝까지 · 높이 20+20=40px). 현행 `py-2.5` + 접힘 시 `-mt-1.5 -mb-2.5` 마진 트릭 그대로(레이아웃 높이 20px 유지).

### 1-2. 360 폭 임계값 (보조 줄 컨테이너 쿼리, 카드 안쪽 폭 W 기준)
W = 뷰포트 − 페이지 좌우 32 − 카드 좌우 32 → 320:256 · 360:296 · 375:311 · 1280:충분. 보조 줄 버튼에 `@container`(JS 측정 금지, 뷰포트 `max-[359px]` 폐기 — Hero 폭이 바뀌어 기준이 어긋남).
| 구간 | 필요 폭(14px, 표준 픽스처 `삼성전자 +820만 외 2개`) | 숨김 클래스(C99: <N 숨김 / ≥N 표시, N−1 금지) |
|---|---|---|
| ① 지수 구간 `· 코스피 종가 +0.8%` | 구분자 `mx-1`(12) + 114 = 126 → 전체 ≈ 308 | `@max-[300px]:hidden` → W<300 숨김, ≥300 표시 |
| ② `외 N개` | 40 | `@max-[260px]:hidden` → W<260 숨김 (320 뷰포트에서 숨김) |
| ③ top 라벨 | `min-w-0 truncate` | 항상 마지막 완충 |
- 결과: **375(W≈311) 지수 표시, 360(W≈296) 지수 숨김(원인 구간만 ≈182px, 여유 114px), 320 `외 N개`까지 숨김.** 360에서 지수를 억지로 넣으려면 12px가 모자라 라벨 truncate·`종가` 삭제(C80 위반)밖에 없다 → 숨김 확정. 값은 패널에 있다.
- 검증 필수: 실측 W가 위 가정과 다르면(페이지 패딩) 임계값 상수 2개만 조정(ui-review가 `삼성전자 +820만 외 2개 · 코스피 종가 +0.8%` 의 scrollWidth를 잰 값 +4px).
- 기본 규칙: 줄바꿈 금지 `whitespace-nowrap`, 한 줄 `min-h-5`.

## 2. 컴포넌트 트리 (위→아래)
```
Hero 카드 (수정: flex-col)
├ 행 [flex items-center justify-between]  — 불변
│  ├ 좌: 닉네임·순자산·실시간 배지 / 순자산 금액 / 변동 줄
│  │     변동 줄 = ▲금액 (%)  [라벨 + (예측 칩) + (˅ 입구)]   ← 예측 칩 이동(수정)
│  └ 우: 총자산·총부채 (불변)
└ 래퍼 mt-1 w-full  (이동·수정)
   ├ 보조 줄 `home-cause-line` (원인 top1 있음)
   │   [top 라벨 truncate][금액 semibold 손익색][외 N개 muted]
   │   [· 지수 구간 `home-cause-market`][˅ size-4]
   └ 패널 `home-cause-panel` (항상 마운트)
       구간 `M/D → M/D` · 원인 목록 · 상쇄 캡션 · 기록 목록 ·
       지수 줄 `home-market-today`(variant=패널) · 접기
(원인 없음·예측만) Hero 밖 `MarketLine` — 현행 그대로(카드 밖, -mt-2)
```
- **변동 줄 `예측` 칩(재사용 문구·신규 토큰 0)**: `shrink-0 rounded bg-muted px-1.5 py-0.5 text-xs font-medium text-muted-foreground`(§2 칩 예외 존속), 위치 = 라벨 span 바로 뒤, 같은 `inline-flex items-center ml-1.5` 래퍼 안 → 라벨과 칩이 한 덩어리로 줄바꿈된다(칩이 홀로 떨어지지 않음). 원인 줄·패널의 칩은 제거. 캡처 모드에서도 표시(testId `home-cause-estimated`, 홈 최대 1개).
- **보조 줄**: `flex w-full items-center gap-1.5 text-sm`. 라벨 `text-foreground`, 금액 `font-semibold tabular-nums`+`getProfitLossColor`, `외 N개`·지수 구간 `text-muted-foreground`, 지수 값만 `font-medium text-foreground tabular-nums`(`MarketIndexValues` 서식·`formatCompareRate`·U+2212). 구분자 `·` `text-muted-foreground/60 mx-1`. 끝 `ChevronDown size-4` (내용 바로 뒤, 우측 정렬 아님).
- 지수 구간 문구: `코스피 종가 +0.8%` / 휴장 `코스피 휴장`(0.0% 금지). 첫 시장 1개(`values[0]`), 구간은 라벨 `전일 대비`+지수 on일 때만. 값 문자열 = 패널 지수 줄·시장과 비교 '하루'와 동일(같은 `market.values`).
- **패널 지수 줄**: `MarketLine` 에 `variant="panel"` 추가 — 카드 밖 전용 클래스(`-mt-2`·`px-4`·`after:` 히트)를 빼고 `mt-2 min-h-10 w-full max-w-xs border-t border-border dark:border-border/40 px-0 text-sm`(§5.1 헤어라인). 내용·`data-testid="home-market-today"`·`data-screenshot-hide`·로딩/빈 분기는 현행. `data-placement="panel"`(카드 밖은 `slot`) 추가. 목록(`max-w-xs`)과 같은 열 폭으로 정렬.
- 패널 수직 간격: 변동 줄 ↔ 보조 줄/패널 첫 요소 8px(래퍼 `mt-1` + 마진 트릭), 패널 내부 `space-y-1`, 목록→상쇄 `mt-1.5`, 기록→지수 줄 `mt-2`, 지수 줄 ↔ 접기 0(둘 다 `min-h-10`), 카드 하단 `py-4`.

## 3. 상태 와이어 (W 기준, ▪ = 변동 줄)
**일반 · 360 (지수 숨김)** / **375·1280 (지수 표시)**
```
360                                    375
순자산 · 실시간      총 자산 12.3억     순자산 · 실시간       총 자산 12.3억
12억 3,456만원       총 부채 1.2억      12억 3,456만원        총 부채 1.2억
▪ ▲+1,234만 (+1.0%) 전일 대비           ▪ ▲+1,234만 (+1.0%) 전일 대비
삼성전자 +820만 외 2개 ˅               삼성전자 +820만 외 2개 · 코스피 종가 +0.8% ˅
```
**예측 상태**: `▪ … 전일 대비 [예측]` — 360에서 줄바꿈되면 `전일 대비 [예측]`이 함께 다음 줄로.
**M/D 이후(접속 간격 ≥2일)**: `▪ ▲+1,234만 (+1.0%) 11/10 이후` / 보조 줄 `삼성전자 +820만 외 2개 ˅`(지수 구간 0 — 기간 다른 1일 지수 병치 금지). 패널 하단 `11/13 종가 코스피 +0.8% · S&P 500 −0.3% ›`.
**휴장**: 보조 줄 `… · S&P 500 휴장 ˅`(`종가`·`0.0%` 없음), 패널 줄 `11/28 S&P 500 휴장 ›` 류 현행 문구.
**체험(데모)**: 일반과 동일 규칙, 문자열 `지난 접속` 0.
**펼침**: 보조 줄이 접히고 같은 자리에 패널(구간 · 목록 · 상쇄 · 기록 · 지수 줄 · `접기 ˄`).
**그 밖**: 지수 로딩 = 지수 구간 자리 `h-4 w-28 rounded SKELETON_FILL`(원인 구간은 즉시, 폭 고정으로 이동 0, 완료 시 값 `motion-safe:animate-in fade-in duration-200`), 지수 조회 실패 = 구간 생략. 원인 없음(변동 없음·예측만)+지수 on = 현행 `MarketLine`이 카드 밖 보조 줄 자리(변경 0). hasCause·top1 없음 = 라벨 옆 ˅(현행). 첫 저장 당일·빈 데이터 = 변동 줄·보조 줄·지수 0. 캡처·인증카드(`screenshotMode`) = 패널 펼침, 보조 줄·지수 줄 없음, 예측 칩은 라벨 옆. 긴 종목명 = 라벨 truncate, 금액·`외 N개`는 보존, 2줄 금지.

## 4. 모션·인터랙션
- 열기/닫기: 현행 그대로 — 보조 줄 `grid-rows-[1fr↔0fr]+opacity+margin`, 패널 `grid-rows-[0fr↔1fr]+opacity`, `motion-safe:transition-[…] duration-200 ease-out`, 접힌 쪽 `inert`(`visibility` 전환 금지, #4.90). 두 요소 항상 마운트(재마운트로 모션 소실 0). **지수 로딩·값 도착은 보조 버튼 안쪽 span만 바뀌므로 버튼·패널은 재마운트되지 않는다**(보조 줄 `key` 금지).
- 연타·중간 방향 전환: CSS transition이라 인터럽트 가능, `focusTo` ref 로 포커스(열림→패널 / 접기→보조 줄, `preventScroll`). 펼침 상태는 기억하지 않음(`useState`).
- press 피드백: 텍스트 줄이라 scale 금지(overflow 클립), `active:text-foreground` + `focus-visible:ring-2 ring-ring/50 ring-inset`.
- 신규 모션 0. `예측` 칩은 모션 없음.

## 5. 접근성
- 보조 줄 `aria-label` = `변동 원인 펼치기, {라벨} {금액} 외 N개{, 코스피 종가 +0.8%}` — **시각적으로 숨긴 지수도 포함**(숨김 클래스는 aria에 영향 없음). `aria-expanded`·`aria-controls="home-cause-panel"` 유지, 구분자 `aria-hidden`. 패널 `role=region aria-label="변동 원인"`, 지수 줄 `aria-label` 현행.
- 히트 ≥40px: 보조 줄(20+after 20), 패널 지수 줄·접기 `min-h-10`, 라벨 옆 ˅ `-my-2 p-2`(현행).
- 다크: 칩 `bg-muted`·muted 글자 현행 토큰(대비 현행 승인값), 지수 값 `text-foreground`. 라이트·다크 동일 구조.

## 8. 품질 체크리스트 (qa·ui-review, 360·375·1280 × 라이트·다크)
1. 주식 보유·원인 있는 평일: 변동 영역 = 변동 줄 + 보조 줄 1줄, 카드 밖 `home-market-today[data-placement=slot]` 0, 패널 안 `[data-placement=panel]`만 존재.
2. 보조 줄 높이 = 20px 1줄(2줄·줄바꿈 0), scrollWidth ≤ clientWidth. 375·1280에서 `· 코스피 종가 +x.x%` 표시. **360: 지수 구간 숨김·원인 구간 전부 표시.**
3. 임계 경계(C99): 보조 줄 W=299·300(지수), W=259·260(`외 N개`)에서 보이는 구간이 정확히 한쪽(둘 다 숨김/둘 다 보임 0). diff의 `@max-[N]` 숫자 ↔ 사양 숫자 일치, 뷰포트 `max-[359px]` 잔존 0.
4. C98: 360·375에서 Hero 좌측 열(순자산 금액 단위 쪼개짐·변동 줄 줄 수·라벨/예측 위치)과 우측 열(총자산·총부채)을 main vs PR 표로 대조 — 줄 수·말줄임 불변, 우측 열 y 이동만 허용(px 기재).
5. C103: 카드 padding·구조를 바꾸므로 카드 안 모든 형제(닉네임·배지·금액·변동·라벨·칩·총자산·총부채·보조 줄) 줄 수·행 높이 표(main vs PR, 360·375).
6. C80: 보조 줄·패널 지수 표기에 항상 `종가` 또는 `휴장`, 휴장 픽스처 `0.0%` 0, 화면 전체 `지난 접속` 0.
7. C97: 보조 줄 값 픽스처 `+1,234만`·`−9,999만`·`+1.2억`(원인 금액)과 지수 `+12.3%`·`−10.5%`에서 320·360·375 scrollWidth ≤ clientWidth(숨김·truncate 순서 ①→②→③ 확인).
8. `예측` 칩: Hero 최대 1개(`home-cause-estimated`), 패널 안 0, 360 줄바꿈 시 라벨과 같은 줄.
9. 접속 간격 ≥2일: 라벨 `M/D 이후`, 보조 줄 지수 구간 0, 패널 지수 줄 날짜로 구분.
10. 값 일치: 보조 줄 지수 문자열 = 패널 지수 줄 같은 시장 값 = 시장과 비교 '하루'.
11. 모션: 열기·접기 200ms, `motion-safe` 외 전환 0(reduced-motion 시 즉시), 열림/닫힘 연타 6회 후 상태 일관, 지수 로딩 완료 시 보조 버튼 DOM 노드 동일(재마운트 0), 포커스 열림→패널·접기→보조 줄.
12. 히트: `elementFromPoint`로 보조 줄 상·하 10px, 카드 좌우 끝, 패널 지수 줄·접기 높이 ≥40px.
13. 상태: 로딩(스켈레톤 폭 고정·이동 0)·지수 실패(구간 생략)·원인 없음(카드 밖 현행 `MarketLine`)·첫 저장 당일(0)·캡처(보조 줄·지수 0, 예측 칩 유지)·체험 각각 §3대로.
14. 다크: 칩·muted·지수 값 대비 현행과 동일 토큰, 구분 헤어라인 `dark:border-border/40`, 신규 색 0.
