# 4.xx 홈 전일대비 영역 정돈 — spec (planner-designer, 2026-11-14)

근거: 대표 지적 11-14 "홈 전일대비 영역에 정보가 너무 많다. 깔끔하고 알아보기 쉽게" · `_discovery/2026-11-14-home-daydiff-declutter.md` A안 · 코드 origin/main b2608a0 `home/dashboard.tsx`(Hero `causeOpen`·`home-cause-line`·`home-cause-panel`), `activity/market-entry-line.tsx`(`MarketLine`).

## 1. 문제
Hero 아래에 변동 줄(금액·%·`지난 접속(M/D) 이후`) · 원인 1줄(예측·라벨·금액·외 N개 ˅) · Hero 밖 지수 줄(`M/D 종가 코스피 · S&P ›`)이 같은 크기로 쌓여 360에서 3~4줄, 정보 약 11개, 펼침 입구 2개(˅·›)다. 접속 간격이 길면 날짜가 2~3번(라벨·구간·지수) 다르게 나온다.

## 2. 목표 행동
홈을 열면 숫자 한 덩어리(금액·%·기간)와 이유 한 줄만 읽고 지나간다. 더 알고 싶으면 입구 1개를 눌러 원인·기록·지수를 한 패널에서 본다.

## 3. 범위
- 포함: (a) 라벨 `지난 접속(M/D) 이후` → `M/D 이후`(`전일 대비`는 그대로) (b) `예측` 칩을 변동 라벨 옆 1곳으로 이동(원인 줄·패널에서 제거) (c) 원인 1줄 + 지수를 **보조 1줄**로 합침 (d) 지수 전체 줄(`MarketLine`, 날짜·둘째 시장·› 링크)을 펼침 패널 맨 아래로 이동 (e) 보조 줄·패널은 Hero 카드 전체 폭(총자산·총부채 열 아래까지).
- 줄일 수 있는 것: Hero 밖 지수 줄 1줄, 입구 2→1, 기본 노출 날짜 표기 0~1회.
- 하지 않을 것: **정보 삭제 0**(전부 위치 이동), 원인·금액·지수 계산 변경, 7일 카드·홈 팁·도넛 변경, 신규 GA 이벤트·파라미터, 저장 키·스키마·동기화·서버 전송 변경, 투자 조언 문구.
- 결정 정합: 4.18 대표 결정(원인 목록 기본 접힘) 유지 — 기본은 1줄, 목록은 펼침. 4.90 결정 ①(`종가` 생략 금지, C80) 유지 — 지수는 어디서든 `종가`(또는 `휴장`)를 붙인다. 4.90 B(원인 1줄)·A(지수 노출 조건 `marketLineState`)·팁 억제 규칙은 그대로.

## 4. 보조 줄 규칙
| 상태 | 보조 줄(접힘) | 누르면 |
|---|---|---|
| 원인 top1 있음 + 지수 on + 라벨 `전일 대비` | `[top 라벨] [금액] 외 N개 · 코스피 종가 +0.8% ˅` (첫 시장 1개, 휴장이면 `코스피 휴장`) | 패널 열림 |
| 원인 top1 있음 + (지수 off 또는 라벨 `M/D 이후`) | `[top 라벨] [금액] 외 N개 ˅` — 기간이 다른 1일 지수를 나란히 두지 않는다 | 패널 열림 |
| 원인 top1 없음(예측만·변동 없음) + 지수 on | 현행 `MarketLine` 그대로(`M/D 종가 …  ›`) | 시장과 비교 '하루' |
| hasCause인데 top1 없음 + 지수 off | 보조 줄 없음, 라벨 옆 ˅(현행) | 패널 열림 |
- 폭 부족 시 숨김 순서(컨테이너 쿼리, JS 측정 금지, 줄바꿈 금지): ① 지수 구간 → ② `외 N개`(현행 <360) → ③ top 라벨 truncate. 숨긴 지수는 패널에 있다.
- 지수 로딩 중엔 지수 구간 자리만 스켈레톤, 원인 구간은 즉시 표시. 두 지수 조회 실패면 지수 구간 생략.
- 패널 순서: 구간 `M/D → M/D` · 원인 목록 · 상쇄 캡션 · 기록 목록 · 지수 전체 줄(`home-market-today`, 날짜·`종가`·둘째 시장·›) · 접기.

## 5. 사용자 흐름
1. 홈 진입 → 순자산·변동 줄·보조 줄 1줄이 보인다(패널 접힘).
2. 보조 줄 탭 → 같은 자리에서 패널이 열리고 포커스가 패널로 간다(현행 모션·inert 재사용).
3. 패널 지수 줄 탭 → 시장과 비교 '하루'. 뒤로 → 홈(패널은 다시 접힘).
4. `접기` → 보조 줄로 복귀, 포커스 보조 줄.
- **펼침 상태는 기억하지 않는다**(현행 `useState`, 홈 재진입마다 접힘). 근거: 4.18 기본 접힘 결정, 저장 키 신설 금지, sessionStorage도 쓰지 않음.

## 7. GA
신규 0. `home_cause_open`(보조 줄·라벨 ˅ 공유 핸들러, 열 때만 1건) 재사용, `home_market`(패널 지수 줄·원인 없는 상태의 지수 줄) 재사용. 판독 경계 = 머지 시각. `홈·오늘 시장` 누름은 직접 입구가 패널 안으로 들어가 구조적으로 줄 수 있다 — 4.90 기준선과 비교하지 않고 경계 후 절대값만, `홈 변동 원인 열기`는 증가 예상(같은 경계).

## 8. 엣지 케이스
- 빈 데이터·첫 저장 당일: 변동 줄·보조 줄·지수 0(현행 `headerChange===null`), 웰컴 diff 0.
- 일부 갱신(지수 한 시장 실패): 보조 줄은 성공한 첫 시장, 패널은 현행 규칙.
- 오래된 데이터(지난 접속 ≥2주): 라벨 `M/D 이후`(연도 넘김은 `formatAttributionDate` 현행), 보조 줄에 지수 없음, 패널 구간·지수 날짜로 기간 구분.
- 휴장(11/27 추수감사절 다음 날 등): 보조 줄 `S&P 500 휴장`/`코스피 휴장`, 0.0% 표기 0.
- 체험: 데모 데이터에서 같은 규칙, `지난 접속` 문자열 0(4.90 후속 p2 해소).
- 캡처·인증카드(`screenshotMode`): 현행처럼 패널 펼침·보조 줄 없음, 지수 줄 미노출(`data-screenshot-hide`), 예측 칩은 라벨 옆.
- 긴 종목명·큰 금액: 4절 숨김 순서, 2줄 금지.

## 9. 완료 기준 (qa 그대로 검사)
1. 360·375·1280 × 다크·라이트 6조합에서 주식 보유·원인 있는 평일 홈의 변동 영역은 변동 줄 + 보조 줄 1줄이며, Hero 밖 `home-market-today`는 없다(패널 안에만 존재).
2. 보조 줄은 줄바꿈 없이 1줄이고, 1280·375 표준 픽스처(`삼성전자 +820만 외 2개`)에서 `· 코스피 종가 +x.x%`가 보인다. 360에서는 원인 구간이 항상 보이고 지수 구간은 숨겨질 수 있으며 숨긴 값은 패널에 있다.
3. 화면 전체에 `지난 접속` 문자열 0, 접속 간격 ≥2일이면 라벨 `M/D 이후`, 그때 보조 줄에 지수 구간 0.
4. `예측` 칩은 홈 Hero에 최대 1개(라벨 옆), 패널 안 0개.
5. 보조 줄 지수 값 문자열 = 패널 지수 줄 같은 시장 값 = 시장과 비교 '하루' 지수 열 값. 지수 표기엔 항상 `종가` 또는 `휴장`이 붙고 휴장 픽스처에서 `0.0%` 0.
6. 보조 줄 탭 시 `home_cause_open` 1건, 닫을 때 0건. 패널 지수 줄 탭 시 `home_market` 1건 후 '하루' 선택된 시장과 비교 도착. 새 이벤트명·파라미터 0.
7. 홈을 나갔다 오면 패널은 접혀 있다. localStorage·sessionStorage 신규 키 0(diff 검사).
8. 원인 없는 상태(변동 없음·예측만)에서는 지수 줄이 보조 줄 자리에 현행 형식(`M/D 종가 … ›`)으로 1개만 보인다.
9. 체험 모드·캡처 모드·첫 저장 당일 각각 8절대로 표시되고, 기존 테스트 id(`home-cause-line`·`home-cause-panel`·`home-market-today`) 유지, 히트 영역 ≥40px, `motion-safe` 전환 현행.
