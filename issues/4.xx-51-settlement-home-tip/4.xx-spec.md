# 4.xx 결산 창 홈 팁 — spec (#51)

기준: 4.xx-direction.md(합의 완료), 4.xx-challenge.md. 시각 수치는 ui.md 몫.

## 1. 문제
v4.34 월 결산은 활동 탭 허브 카드에서만 열린다. 홈만 여는 사용자는 결산 창이 열린 것을 모른다(재방문 장치의 도달 부족).

## 2. 목표 행동
결산 창에 홈을 연 사용자가 팁을 눌러 해당 달 월 결산 화면을 연다. 지표: 창 `settlement_view` 기기 ÷ 창 활성 기기(기준 10-28~11-10 vs 비교 11-27~12-10, 목표 상대 +50%). 11-26까지 머지.

## 3. 범위
- 포함: `HomeTip`에 `{ kind: "settlement"; window: SettlementWindow }` 1종, 우선순위 1줄, source 값 1개, 문구, p2 줄바꿈 2건.
- 제외: 첫 달 안내, 홈 .ics, 푸시·리마인더·이메일, 새 진입점·URL·메뉴, 새 저장 키·스키마·동기화, 새 GA 이벤트, 홈 Hero 의미 변경·결산 화면·계산 변경, 팁에 금액 표기.

## 4. 노출 조건·우선순위
- `pickHomeTip`에서 `pickSettlementCard(readMonthlySnapshots(), today)` 결과가 non-null이면 결산 팁. 새 판정 로직 금지. today는 KST(`performance-hub.tsx`와 같은 식).
- 창: 말일−3일~다음 달 10일. 첫 달(`first_month`)은 null이므로 미노출. `hasAssets` false면 미노출(기존 홈 팁 전제).
- 순서: 공지 > 백업 > 세금 > **결산** > 최신화 > 기능. 상위 팁이 있으면 결산은 그 세션에 안 보인다(수용).
- `pickHomeTip` 입력에 today를 주입 가능하게 하되(기본값은 현재 KST) 기존 호출부 동작은 불변.

## 5. 문구 초안
- 배지 "결산", 제목 "{N}월 결산이 준비됐어요", 설명 "이번 기간 순자산이 무엇 때문에 바뀌었는지 볼 수 있어요." 금액·갱신 요구·투자 조언·"~하세요" 독촉 없음. N월은 허브 카드와 같은 `settlementName(window.month, today, true)` 규칙 재사용(창이 다음 달 초면 직전 달 결산). 최종 문구 확정은 ui.md와 맞춘다.

## 6. 탭 이동
- `activate`: `navigate({ type: "activity", tab: "change", init: { scope: "all", period: "month", month: window.month, source: "home_tip" } })` — 허브 카드와 동일 형태에 source만 다름.
- 타입: `navigation-context.tsx` `ChangeInit.source`를 `"card" | "menu" | "home_tip"`, `settlement-view.tsx` `SettlementView`의 source prop 타입도 동일하게 확장. `asset-change-view.tsx`가 전달하는 타입 정합 확인.
- 이동 후 팁은 `setTip(null)`로 해제하지 않고 기존 feature/tax 분기처럼 두되, 홈 복귀 시 재노출은 7장 규칙을 따른다.

## 7. 닫기·재노출
- X = 기존 `SESSION_DISMISS_KEY`(sessionStorage) 세션 숨김. 영구 dismiss·새 저장 키 없음. 새 세션에 창 안이면 다시 뜬다. 창이 끝나면(다음 달 11일) 자연 소멸.
- 눌러서 결산을 연 뒤 홈 복귀 시 창 안이면 재노출 가능(별도 "봤음" 상태 없음). 가드레일(close÷view)로 감시.

## 8. GA
- 팁 노출/클릭/닫기는 기존 `feature_use` `{category:"home_tip", method:"view|click|close"}` 그대로.
- 결산 화면 진입 시 기존 `settlement_view`에 source=`home_tip`(ga.ts 허용 값에 이미 있음). 새 이벤트·새 파라미터 이름 없음.

## 9. p2 동승
- ① `views/home/dashboard.tsx` `NetAssetSummaryBox` 증감 span의 `formatShortCurrency(change.deltaNet)` 금액 토큰에 `whitespace-nowrap`(금액·단위 분리 줄바꿈 방지). 라벨·% 줄바꿈 허용, 의미 변경 없음. 375px 기준.
- ② `layout/copyright-footer.tsx` 고지 `<p>` 2개에 `break-keep`(+`text-pretty`).

## 10. 정보 구조 — 지표 단위 전수 대조표

| 허브 카드 자산 변화 구간 증감 | 허브 카드 | 그대로(진입로가 하나 더 생길 뿐) |

| .ics 내려받기 | 결산 화면 | 홈에 두지 않음 |

## 11. 엣지 케이스
- 월 기록 0건·첫 달·창 밖·자산 0건: 팁 없음, 기존 순서 그대로.
- 일부 갱신/오래된 시세: 팁은 판정만 쓰므로 영향 없음.
- 말일−3일처럼 창 시작일, 다음 달 10일(포함)·11일(제외) 경계.
- 백업/세금/공지 해당 사용자: 해당 세션 결산 팁 미노출.

## 12. 데이터 영향 없음 근거
읽기만 한다: `readMonthlySnapshots()`(기존 로컬 읽기). 쓰기·스키마·저장 키·동기화 페이로드·서버 전송 변경 없음. 팁 상태는 sessionStorage 기존 키만 사용. 이전 버전 데이터 복원 영향 없음 → 마이그레이션 불필요, 위험 low.
