## 5. spec 수정 요청
- **수정 요청: 5장 제목과 창 앞쪽 구간** — `pickSettlementCard`는 말일−3일~말일, 그리고 "1~10일인데 직전 달 기록의 date가 21일 미만"인 경우 **이번 달(진행 중, kind `range`/`in_progress`)** 을 돌려준다. 이때 "{N}월 결산이 준비됐어요"는 아직 끝나지 않은 달에 "준비됐어요"라고 말하게 된다. 허브 배지도 같은 이름을 쓰지만 배지는 명사형이라 단정이 약하다. 판정은 그대로 두고 **문구만 kind로 분기하기를 요청한다**: `settled`면 "{N}월 결산이 준비됐어요", 그 밖이면 "{N}월 결산이 곧 열려요" 같은 결과 안내. 최종 문구는 ui.md가 정한다. 완료 기준 9에 "말일−3일 날짜에서 진행 중 문구" 1건을 추가하면 된다.
- 참고(수정 아님): 10번 "대상 달이 팁의 N월과 같다"는 결산 화면 제목 testid로 비교한다. 6장 "이동 후 `setTip(null)` 안 함"은 그대로 구현한다(홈 복귀 시 effect가 다시 판정한다).

## ui.md 교차 검토 (developer)

**수정 요청** (2건, 나머지는 승인)

- **수정 요청: 누름 피드백 전환 속성(2장 셸 3번째, 9장 11번)** — Tailwind 4.1의 `scale-[0.99]`는 `transform`이 아니라 CSS `scale` 속성을 쓴다(`node_modules/tailwindcss` 확인). 그래서 `transition-[transform]`로는 누름이 애니메이션되지 않고 즉시 바뀐다. `transition-[scale]`(또는 v4 `transition-transform`, scale 포함)로 바꿔 달라. qa 11번도 computed `transform`이 아니라 computed `scale`(0.99) 샘플로 고쳐야 한다. 진입 모션(`animate-in`)은 `transform` 키프레임이라 `scale`과 겹치지 않는다.
- **수정 요청: Hero 증감 320 넘침(2장 p2 ①)** — 증감 `span`은 `inline-flex`(줄바꿈 없음)이다. 금액과 %를 모두 `whitespace-nowrap`으로 묶으면 최소 폭이 대략 금액 ~103 + % ~59 + 라벨 최장 어절 "접속(10/28)" ~86 + 원인 쉐브론 34 ≈ 282px가 된다. 320의 가용 폭(약 264px)을 넘어 가로 넘침이 생길 수 있다(375는 약 319px라 들어간다). 이 span에 `flex-wrap`(+`gap-y-0.5`)을 더해, 좁은 폭에서는 금액+%가 1행에 남고 라벨·쉐브론이 다음 행으로 내려가게 하자. 375 기대 레이아웃은 그대로다. 9장 8번에 "320 + 원인 쉐브론 있는 데모에서 `scrollWidth ≤ clientWidth`"를 추가해 달라.
- 결산 분기·아이콘: 승인. `CalendarCheck`는 lucide-react 0.453에 있다(`calendar-check`, class `lucide-calendar-check`). 제목 "열렸어요"는 settled·range·in_progress 세 kind에 모두 맞으므로, 앞 5장에서 낸 내 수정 요청(kind별 문구 분기)은 **철회한다**(ui.md 문구로 해결). 판정과 문구의 today를 맞추려고, 구현에서는 settlement 팁 값에 `today`를 함께 담아(`{ kind, window, today }`) `contentOf`가 그 값을 쓰게 한다. 별도 계산이 없으니 자정 경계에서 어긋나지 않는다.
- 셸 공통 변경의 6종 회귀: 위험 낮음. `break-keep`은 공백이 없는 긴 토큰(세금 제목의 `[마감 라벨]`, 기능 팁 영문)에서 넘칠 수 있으니 안전장치로 `wrap-break-word`를 같이 붙인다(띄어쓰기 단위 줄바꿈이 우선이고, 넘칠 때만 끊긴다). X는 `relative after:absolute after:-inset-1`로 32→40px이 된다. v4 `after:`는 content를 자동으로 넣고, 카드 패딩 16 안(가장자리에서 4px)에 들어온다. pseudo 클릭도 버튼 `stopPropagation`을 그대로 탄다. 참고: X를 누를 때 부모 카드에도 `:active`가 걸려 0.99로 눌린다. 시각 차이가 1%라 수용한다.
- testid 3종(`home-tip`+`data-kind`, `home-tip-title`, `home-tip-close`): 승인. origin/main에 겹치는 testid가 없다. 6종 공통으로 붙여도 동작 변화는 없다.
- 하단 고지 `break-keep text-pretty`: 승인(문구가 짧아 넘칠 위험 없음).
