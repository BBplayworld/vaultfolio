## 2. 컴포넌트 변경 (`home-tip-box.tsx`, 다른 파일은 spec 그대로)
1. `contentOf` 분기: `{ Icon: CalendarCheck, badgeLabel: "결산", title: \`${settlementName(tip.window.month, today, true)}이 열렸어요\`, description: "한 달 동안 순자산이 무엇 때문에 바뀌었는지 볼 수 있어요." }`. `today`는 `pickHomeTip`에 넘긴 값과 같은 KST 값(달이 바뀌는 자정 경계에서 판정과 문구가 어긋나지 않게)
2. 셸(공용, 6종 모두 적용, 작은 정리 3건 — C25·§7 대응):
   - 제목 `p`·설명 `p`에 `break-keep` 추가(기존 `text-pretty` 유지)
   - X 버튼에 `relative after:absolute after:-inset-1` 추가 → 32 → **40×40** 히트영역. 시각 크기·위치 불변
   - 카드 누름 피드백 `motion-safe:active:scale-[0.99] transition-[transform]`(§6 카드류 0.98~0.99). 기존 `transition-colors` 없음, `transition-all` 금지
3. testid: 박스 `data-testid="home-tip"` + `data-kind={tip.kind}`, 제목 `home-tip-title`, X `home-tip-close` (6종 공통)
4. 기간 라벨(M/D → M/D)·금액·"진행 중"은 팁에 넣지 않는다(spec 10장. 결산 화면이 정본)

### p2 ① 홈 Hero 증감 (`dashboard.tsx` `NetAssetSummaryBox`)
- 금액 텍스트 `{"▲ +"/"▼ "}{formatShortCurrency(...)}`를 `<span className="whitespace-nowrap">`로 감싼다. 퍼센트 `span`에도 `whitespace-nowrap`. 라벨 "지난 접속(10/28) 이후"는 `break-keep`(어절 단위 줄바꿈 허용)
- 375 기대 레이아웃: 1행 `▼ -1,311만원 (-2.0%)` + 라벨 열 "지난 접속(10/28)" / "이후"(2줄, 같은 inline-flex 안 오른쪽) + 쉐브론. 금액과 단위가 한 줄. 320에서도 금액은 1줄이고 라벨만 2~3줄
- 1280: 변화 없음(1줄). 글자 크기·색·굵기·쉐브론 위치 불변. screenshotMode(웰컴 미리보기) 결과도 같은 규칙

### p2 ② 하단 고지 (`copyright-footer.tsx`)

## 3. 레이아웃 수치
- 위치: 기존과 같은 홈 분포 카드 아래 1곳(HomeTipBox 자리). 새 자리·새 간격 없음
- 셸: `rounded-xl bg-card shadow-xs p-4`, 아이콘-본문 `gap-2`, 배지-제목 `gap-1.5 flex-wrap`, 설명 `mt-1`. 모두 기존 값
- 예상 높이(제목 1줄 + 설명 2줄): 375 ≈ 100, 320 ≈ 122(제목이 배지 아래로 내려가 2행), 1280 ≈ 77(설명 1줄)
- 본문 가용 폭: 375 → 351−32(패딩)−24(아이콘+gap)−16(X) ≈ 279px, 320 ≈ 224px. 제목 "10월 결산이 열렸어요"(14~15px semibold ≈ 150px)는 375에서 배지 옆 1줄, "25년 12월 결산이 열렸어요"는 320에서 배지 아래 1줄

## 4. 인터랙션·모션
- 카드 전체 탭 = 결산 화면 이동(spec 6장 navigate, source `home_tip`). 키보드 Enter/Space 동일(기존 `role=button`·`tabIndex=0`)
- X = 이번 세션 팁 박스 숨김(기존 `SESSION_DISMISS_KEY`), `stopPropagation` 유지. 숨김은 즉시 언마운트(§6 subtle exit, 별도 퇴장 모션 없음)
- 진입: 기존 `motion-safe:animate-in fade-in slide-in-from-bottom-2 duration-300` 재사용. reduced-motion이면 즉시
- 결산 화면에서 뒤로 오면 창 안이면 같은 팁이 다시 진입 모션과 함께 뜬다(spec 7장, 별도 "봤음" 상태 없음)
- 연타: 이동은 navigate 1회. 홈이 언마운트되므로 중복 이동 없음

## 5. 상태
| 상태 | 팁 |
|---|---|
| 창 안(말일−3일~다음 달 10일), 월 기록 비교 가능, 상위 팁 없음 | 결산 팁(settled·range·in_progress 같은 문구) |
| 창 밖(11일~말일−4일) | 결산 없음 → 기존 순서(최신화·기능) |
| 첫 달(`first_month`)·월 기록 0건 | 없음 |
| 자산 0건(`hasAssets` false) | 없음(홈 팁 전체 미노출, 기존) |
| 공지 미열람·백업·세금 대상 | 해당 팁이 대신 노출(결산은 그 세션 밀림) |
| X로 닫은 세션 | 팁 박스 전체 없음, 새 세션에 창 안이면 재노출 |
| 연말→연초(1월 1~10일) | "25년 12월 결산이 열렸어요"(연도 접두) |
| 로딩·오류 | 해당 없음(동기 로컬 읽기, 실패 시 null → 팁 없음) |

## 6. 접근성
- 카드 `role=button` 접근 이름 = 배지+제목+설명 텍스트(기존). X `aria-label="닫기"`, 히트영역 40×40(after 확장)
- 대비: 배지·아이콘 orange-600/400(기존 6종과 같음), 설명 `text-muted-foreground` 투명도 중첩 없음(§11 라이트 AA)
- `data-screenshot-hide`: 해당 없음(홈 팁은 인증카드 캡처 대상 아님)

## 7. 문구 최종안
| 위치 | 문구 |
|---|---|
| 배지 | 결산 |
| 제목 | {N}월 결산이 열렸어요 (연도가 다르면 "{YY}년 {N}월 결산이 열렸어요") |
| 설명 | 한 달 동안 순자산이 무엇 때문에 바뀌었는지 볼 수 있어요. |

## 9. 품질 체크리스트 (qa·ui-review)
1. 창 안 데모(시간 고정)에서 `home-tip[data-kind=settlement]`가 1개, 배지 "결산", 제목이 `/^(\d{2}년 )?\d{1,2}월 결산이 열렸어요$/`에 맞고, 팁 텍스트에 숫자+원/만원/억·%·"갱신"·"최신화"가 없다.
2. 제목의 N월이 탭 후 열린 결산 화면 제목의 달과 같다.
3. 아이콘이 `CalendarCheck`(svg class `lucide-calendar-check`), 배지·아이콘 색이 다른 팁과 같은 orange 토큰이다(라이트 orange-600, 다크 orange-400).
4. X 버튼 히트 박스(after 포함 `elementFromPoint` 샘플) ≥ 40×40. X를 누르면 카드 탭(navigate)이 일어나지 않는다.
5. X 후 같은 세션 홈 재진입에서 `home-tip` 0개, sessionStorage 초기화 뒤 다시 1개.
6. 진입 모션: 마운트 직후 opacity < 1 → 300ms 뒤 1(같은 노드). reduced-motion 에뮬레이션에서는 즉시 1.
7. **C25** 320·375 × 라이트·다크: 팁 제목·설명, 하단 고지 두 줄이 어절 중간에서 끊기지 않는다(각 줄 끝 글자 뒤가 공백 또는 문장 끝). 기존 5종 팁(공지 등)도 같은 결과.
8. 375·320 Hero 증감에서 금액 토큰(예 "-1,311만원")의 줄 수가 1이다(`getClientRects` top 1종). 1280 Hero 1행·글자 크기 불변.
9. 하단 고지 320: "투자 조/언"처럼 쪼개지지 않음, 다크 색 pin 불변.
10. 창 밖(15일)·첫 달 데모에서 `data-kind=settlement` 0개, 기존 팁 순서 결과와 같다.
11. 팁 카드 누름 시 scale 0.99(computed transform 샘플), `transition-property`에 `all` 없음.
12. 375·320 가로 스크롤 0, 팁 박스 높이가 기존 공지 팁 높이 범위(±20px) 안이다(새 패턴 아님).
13. 라이트·다크 1280·375 스크린샷: 팁이 분포 카드 아래 같은 자리, 다른 팁과 시각 차이는 아이콘·문구뿐이다(C2).

## 흐름 검토 (planner-designer)
수정 요청: 카드 press scale 0.99(`active:scale-[0.99]`) 제거 — 6종 팁 전체의 상호작용 변경이고 요청 범위 밖이다. 문구 "{N}월 결산이 열렸어요"는 승인(spec 5장을 이 단일 문구로 맞춰 kind 분기 삭제, spec 완료 기준 9 수정). 셸 공통 `break-keep`·X 40×40은 줄바꿈·접근성 결함 수정이라 동승 허용으로 spec 3장·완료 기준 17에 반영했다. 나머지(흐름·상태·testid·p2 두 건) 승인.
