# 4.67 월별 기록 R3 — 시트 폐지, 월 탭 인라인 카드 (ui-designer 2026-11-10)

대표 R3: 차이 금액을 다른 색으로 인지하기 쉽게, 다이얼로그 대신 성과 페이지 UI로 변화 금액까지 정확히.
시안(DOM 주입, 지난 달 자산군은 데모에 없어 합성): `screenshots/ui-r3-inline-w375-dark|w375-light|w320-light|w1280-dark.png`. 4 화면 모두 페이지 가로 스크롤 0(scrollWidth=clientWidth).
**신규 색·토큰·공용 컴포넌트 0, 저장 스키마 변경 0, 가로 스크롤 0(표 폐지).** 이전 R1~R2 대응(최소 비중 바·가로 스크롤 2개·순자산 열 순서)은 표 폐지로 소멸.

## 2. 행 (MonthRow, 줄 전체가 `button` — 펼침 가능한 full 줄만; 나머지는 `div`)
- 레이아웃: `flex items-center gap-2 min-h-14 py-3`. 좌: `flex-1 min-w-0 flex flex-wrap items-baseline gap-x-1.5` — `11월`(`font-semibold text-foreground`) + 이번 달만 `진행 중`(GROUP_BADGE) + 줄바꿈 후 기록일(`text-sm text-muted-foreground`; `오늘`·`10/28`·`2026-08 기록`; 표와 달리 `text-xs` 불필요). 우: `flex flex-col items-end tabular-nums` 1줄 순자산(`text-sm font-semibold text-foreground`, 원 단위 전체 `661,316,081원`, **짧은 표기 폐지** — 정확 금액), 2줄 **전월 대비 변화**. 끝: `ChevronDown size-4 text-muted-foreground`(펼침 시 `rotate-180`, `motion-safe:transition-transform duration-200`). 펼침 불가 줄은 같은 폭 빈 `span size-4`로 우측 정렬 유지.
- 변화 2줄: `text-sm font-semibold`, 색 `getProfitLossColor(Δ)`(상승 빨강/하락 파랑), 부호 `+`/`−`(U+2212) + 원 단위. Δ=0 → `0원` `text-muted-foreground`(부호·손익색 없음). 정확 금액이므로 반올림 `Math.round`.
- 비교 대상: 바로 앞 기록 달. 사이에 기록 없는 달이 있으면 2줄 끝에 `· 9월 대비`(`text-muted-foreground font-normal`). 바로 앞 달이면 접미사 없음(캡션이 설명).
- 첫 기록 달: 2줄 `첫 기록`(`text-muted-foreground`, 색·부호 없음). 
- `기록 없음`(gap) 줄: 좌 `9월`, 우 `기록 없음`(`text-muted-foreground`), 비교·펼침 없음, `min-h-10`.
- 레거시(`net-only`) 줄: 순자산·변화는 정상 표시, 펼침 없음, 줄 아래 `종류별 기록 없음`(`text-sm text-muted-foreground`). 앞 기록이 net-only라 자산군 비교가 불가한 full 줄은 패널에 금액만(변화 줄 없음) + `이전 기록에 종류별 값이 없어 금액만 보여요`(muted).

## 3. 펼침 패널 (자산군별 금액·변화)
- 기본: **최신(이번 달) 줄만 펼침**, 나머지 접힘. 상태 `Set<month>` 로컬 useState(토글, 다중 펼침 허용). `aria-expanded`/`aria-controls`.
- 패널: `mt-2 rounded-lg bg-muted/50 px-3 py-2 space-y-2`(동심 radius: 카드 12 → 패널 8). 자산군 줄 = `log.columns` 중 이번·앞 달 둘 중 하나라도 0 아닌 것만, 표시 순서 유지. 줄: 좌 라벨(`text-sm text-muted-foreground`), 우 2줄(1줄 금액 `text-sm text-foreground`, 부채는 `−`+절댓값=`formatMonthlyLogAmount(v,"full",true)`; 2줄 변화 `font-semibold` 손익색). `sm`(≥640)에서는 한 줄 `sm:flex-row sm:gap-4`(금액·변화 나란히, 1280 시안은 2줄이라 이 한 가지만 개발 시 적용).
- **자산군 변화 = 순자산 기여 변화**: 기여 c(k)=부채(대출·임차보증금)? −|v| : v, Δk = c(이번)−c(앞). 대출이 늘면 파랑 `−`(순자산 감소) — 자산군 Δ 합 ≈ 순자산 Δ(±1원). 색 의미 일관.
- 펼침 모션: `grid grid-rows-[0fr]→[1fr]` `motion-safe:transition-[grid-template-rows] duration-200`, 내부 `overflow-hidden`(연타 중간 방향 전환 OK, 언마운트 대신 항상 렌더 → 재마운트 모션 소실 없음, 접힘 시 `inert`/`aria-hidden`).
- 더 보기: `button` `w-full min-h-10 rounded-lg text-sm font-medium text-muted-foreground hover:bg-muted/40`, `이전 N개월 더 보기` → 전부 표시(되접기 없음, 버튼 사라짐). 7개월째부터 `BODY_ENTER` 없이 즉시. 

## 4. 문구 (존댓말)
캡션 `금액 아래 숫자는 바로 앞 기록보다 늘거나 줄어든 금액이에요`(`상승/하락` 어휘·조언 없음). `atLimit`이면 캡션 아래 `최근 13개월까지 보여요`(muted, `mt-1`). `hasNetOnly` 안내는 행별 `종류별 기록 없음`으로 대체되어 캡션 불필요. 빈(0줄)은 블록 미렌더(진입 조건 recordedCount≥2).

## 5. 순수 함수 (lib/report/monthly-log.ts 추가, 스키마·저장 0)
```ts
export interface MonthlyLogChange {
  /** 비교한 앞 기록 달 YYYY-MM */ vsMonth: string;
  /** 앞 기록과 사이에 기록 없는 달이 있나(문구 '· 9월 대비') */ skipped: boolean;
  /** 순자산 변화(원, 반올림) */ net: number;
  /** 자산군 순자산 기여 변화. 두 줄 모두 full일 때만, 아니면 null */ groups: Partial<Record<MonthlyLogKey, number>> | null;
}
/** rows(최신순)와 같은 월 키 → 변화. 첫 기록 달·gap 줄은 키 없음(undefined) */
export function buildMonthlyLogChanges(rows: MonthlyLogRow[]): Map<string, MonthlyLogChange>;
/** 변화 금액 표기: 0→"0원", 양수 "+1,234원", 음수 "−1,234원"(U+2212), 원 단위 */
export function formatMonthlyLogDelta(v: number): string;
```
구현: rows 역순(과거→현재) 순회, 마지막 non-gap 줄을 prev로 보관; `skipped`=월 인덱스 차>1. 단위 테스트: 첫 기록 키 없음 / gap 건너뜀 skipped / net-only 끼면 groups null / 대출 증가=음수 / Δ합≈net(±1) / 0원·U+2212.

## 6. 상태·다크·320
- 라이트·다크 모두 토큰만(`bg-card`·`bg-muted/50`·`text-*`, 손익색은 theme 클래스라 dark 변형 자동). hairline `border-b border-border dark:border-border/40`(마지막 줄 없음). 320: 우측 2줄 폭 ~150px(`1,234,567,890원` 가능)·좌측 `진행 중` 배지 줄바꿈 허용(시안 확인) — 금액은 `whitespace-nowrap`, 좌측만 줄바꿈.
- 로딩 없음(로컬 동기). 오류 시 결산 오류 상태가 블록을 가림(기존). 첫 사용·1개월뿐이면 미렌더.
- 인터랙션: 줄 눌림 `motion-safe:active:scale-[0.99]` 금지(줄 안 가장자리 잘림) → `hover:bg-muted/40` + 포커스 링 `focus-visible:ring-2 ring-ring/50`. 히트영역 줄 전체 ≥56px, 더 보기 40px.

## 8. 품질 체크리스트 (qa)
1. 월 탭에 `monthly-log-block`이 구성 블록 아래·AI 버튼 위, `monthly-log-button`·`monthly-log-sheet`·`role=dialog` DOM 0.
2. 320/375/1280 × 라이트·다크에서 `documentElement.scrollWidth<=clientWidth`, 블록 내부 가로 스크롤 요소(`overflow-x:auto|scroll`) 0.
3. 모든 줄 순자산이 원 단위 전체(`\d{1,3}(,\d{3})*원`), 짧은 표기(`만`/`억`) 0.
4. 상승 달 Δ 색 = rose(빨강), 하락 = blue(파랑), 0 = muted; 부호 `+`/`−`(U+2212); 값이 홈 월 Hero Δ와 일치(이번 달·직전 달).
5. 첫 기록 달 `첫 기록` 표시·Δ 없음·손익색 없음; gap 줄 `기록 없음` 비교 없음; 건너뛴 달 뒤 줄에 `· N월 대비`.
6. 이번 달만 기본 펼침, 토글 시 `aria-expanded` 갱신, 연타·중간 방향 전환에도 패널 높이 정상, `prefers-reduced-motion`에서 전환 없음(`motion-safe`).
7. 자산군 Δ 합 = 순자산 Δ(±1원); 대출 증가 시 대출 Δ가 파랑 `−`; 부채 금액 표기 `−`+절댓값.
8. net-only 줄: 토글 없음, `종류별 기록 없음`, 순자산·Δ는 표시.
9. 7개월 이상이면 6개 + `이전 N개월 더 보기`, 누르면 전체·버튼 소멸; 6개 이하면 버튼 없음.
10. 월 화살표로 달 이동 전후 블록 DOM 노드 동일(리마운트 없음)·펼침 상태 유지.
11. 줄·버튼 히트영역 ≥40px(줄 ≥56px), 포커스 링 가시, Tab 순서 위→아래.
12. 새 색 토큰 0, `transition: all` 0, 저장·네트워크 변화 0(localStorage diff 0), 다크 대비 AA(muted 텍스트 포함).
13. 문구에 '월말'·투자 조언 0, 캡션 글자 일치.
14. `buildMonthlyLogChanges` 단위 테스트(§5 6건) 통과, 기존 `buildMonthlyLog` 테스트 무변경.
