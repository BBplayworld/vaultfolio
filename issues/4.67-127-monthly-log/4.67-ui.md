# 4.xx 월별 기록 — ui (#127)

작성: ui-designer 2026-11-09 · 근거 origin/main dc4133d, design-system §1~§7·§11, spec 5·7·11절. **신규 색·토큰·공용 컴포넌트 0.** 재사용: `SECTION` 외피(AI_ROW_SURFACE), `GROUP_BADGE`, `BODY_ENTER`, `Sheet side="bottom"`, `COMPOSITION_LABELS`.

## 1. 컴포넌트 트리
```
SettlementView (전체·월·ok·!firstMonth·기록 달 ≥2)
 ├ CompositionBlock
 ├ MonthlyLogButton            ← 신규(SettlementAiButton과 같은 파일·같은 외피)
 ├ SettlementAiButton
 └ MonthlyLogSheet (open 시 마운트)   ← 신규, Sheet side="bottom" 재사용
     SheetHeader: SheetTitle "월별 기록" + SheetDescription(캡션)
     [조건부 캡션 0~2줄]
     MonthlyLogTable (단일 스크롤 컨테이너)
```
순수 함수 `buildMonthlyLog(...)`(`lib/report/monthly-log.ts`)만 신규 로직. 표는 실제 `<table>` 의미 요소(caption sr-only `월별 자산군 금액`, `th scope="col"`, 월 칸 `th scope="row"`).

## 2. 진입 행 `MonthlyLogButton`
- `SettlementAiButton` 복제 수준 재사용: 외피 `${AI_ROW_SURFACE} flex w-full min-h-14 items-center gap-3 px-4 py-3 text-left hover:bg-muted/40 motion-safe:active:scale-[0.99] motion-safe:transition-[background-color,scale] motion-safe:duration-150 outline-none focus-visible:ring-2 focus-visible:ring-ring/50 ${BODY_ENTER}`, `animationDelay: "120ms"` + fillMode backwards(AI 행은 `160ms`로 한 칸 뒤 — stagger).
- 아이콘 칩: `size-7 rounded-lg bg-sky-500/15 text-sky-600 dark:text-sky-400` 안에 lucide `Table2` `size-4`(`aria-hidden`). sky 칩은 AI 행과 같은 '보조 행' 규약(새 색 아님). 오른쪽 `ChevronRight size-4 text-muted-foreground`.
- 텍스트: 1줄 `월별 기록`(`text-sm sm:text-base font-semibold text-foreground break-keep`), 2줄 `8월~11월 · 4개월 기록`(`text-sm text-muted-foreground break-keep tabular-nums`). 기간 라벨 규칙: 시작~끝 월, 해가 다르면 `25년 12월~26년 3월`(길면 줄바꿈 허용, 말줄임 금지).
- 순서: 구성 블록 → **월별 기록** → AI 질문 → 캘린더 추가(brand 유일). 채움 버튼 아님.
- `data-testid="monthly-log-button"`, `data-screenshot-hide`, `aria-haspopup="dialog"`. 월 화살표로 달을 바꿔도 행은 리마운트 없이 유지(key에 month 넣지 않음 → 모션 재생 안 됨, 문구 동일).

## 3. 시트
- `SheetContent side="bottom"`: 전 폭 공통. 내부 래퍼 `mx-auto w-full max-w-[1040px]`(1280px은 중앙 정렬 컬럼, 슬라이드 transform 충돌 없음). `max-h-[85dvh]`, `rounded-t-2xl`(기본), `pb-[max(1rem,env(safe-area-inset-bottom))]`. 열림 슬라이드 기본(500ms in/300ms out)은 `motion-safe`로 감싸 reduced-motion 즉시. 닫기 X 기본 제공(히트영역 40px 확보: `after:-inset-2`), 바깥 탭·Esc 기본.
- 헤더 `px-4 pt-4`(1280 `px-6`): 제목 `월별 기록` `text-base font-bold text-balance`(우측 X와 겹치지 않게 `pr-10`). 캡션 `그 달 마지막으로 앱을 연 날, 그때까지 맞춘 값이에요` 제목 바로 아래 `text-sm text-muted-foreground text-pretty break-keep mt-1`(`SheetDescription`). 조건부 캡션은 같은 스타일로 캡션 아래 `mt-1` 순서: ① `—인 달은 순자산만 기록돼 있어요` ② `최근 13개월까지 보여요`. 캡션 영역은 스크롤되지 않고 표만 스크롤.
- 표 컨테이너 위 간격 `mt-3`, 좌우 `px-2`(375px 폭 확보 목적, 헤더 `px-4`와 의도된 차이 — 표 셀 `px-1`이라 글자 시작선은 12px로 맞음). 1280은 `px-6`.
- 오류 아님: 0줄이면 표 대신 `기록된 달이 없어요`(`text-sm text-muted-foreground py-8 text-center`, `data-testid="monthly-log-empty"`).

## 4. 표 레이아웃
- 컨테이너: `overflow-auto max-h-[60dvh] sm:max-h-[65dvh]`, **세로·가로 한 컨테이너**(sticky top·left 동시 동작). 표는 `w-full border-separate border-spacing-0 text-sm tabular-nums whitespace-nowrap`. 폭이 모자라면 컨테이너가 알아서 가로 스크롤(스크롤바 얇게, 기본). 가로 스크롤을 별도로 켜고 끄지 않는다 — **sticky는 항상 적용, 넘칠 때만 스크롤**이 생긴다(분기 코드 0).
- 열 순서(U3): 월 · 순자산 · (부동산 · 실물 · 주식 · 암호화폐 · 현금성 · 대출 · 임차보증금 중 보이는 것). 고정은 월 열만, 순자산은 함께 이동. 1280도 같은 순서.
- 월 열(sticky left-0 z-10): `w-14 min-w-14 text-left px-1`. 1줄 `11월`(`font-medium text-foreground`, 다른 해 `25년 12월`은 `break-keep`로 2줄 허용), 2줄 기록일 `11/28`·`오늘`·`2026-07 기록`(`text-xs text-muted-foreground`; 캡션 역할 예외). 이번 달만 3줄에 `진행 중`(`GROUP_BADGE`, 배지 예외 text-xs). `th scope="row"`, 배경 sticky 보강 `bg-background dark:bg-popover`(시트 면과 동일, 투명 금지).
- 순자산 열(월 다음 2번째, sticky 아님): `text-right font-semibold text-foreground px-1`. 월 열 오른쪽·순자산 열 오른쪽(`EDGE_R`)에 경계선 — 순자산과 자산군 구분.
- 자산군 열: `text-right px-1 min-w-[56px]`. 머리 라벨 `text-xs font-medium text-muted-foreground`(구조적 제약 예외, 헤더 전용), `break-keep`. `임차보증금`은 `임차<wbr>보증금`으로 2줄 허용(모바일 열 폭 확보). 머리줄 `sticky top-0 z-20`(월·순자산 머리 칸 코너는 `z-30`), 같은 불투명 배경, 아래 hairline `border-b border-border/10`. 정렬: 머리 라벨도 숫자 열과 같이 우측.
- 행: 높이 `min-h-12`(셀 `py-2`), 구분 hairline `border-b border-border/10`, 마지막 행 선 없음. 줄무늬·hover·cursor 반응 0(읽기 전용, 클릭 요소 없음).
- 금액 표기(셀 하나에 두 span, 화면폭으로 전환; 보이지 않는 쪽은 display:none이라 스크린리더 중복 없음)
  - `<sm`: `formatShortCurrency` 결과에서 **1만원 이상은 끝의 `원` 제거**(`1,234만`·`12.3억`), 1만원 미만은 `5,000원`, **0은 `0원`**. 표 아래/캡션에 단위 문구 안 둠(`만`·`억`이 단위). 목적: 375px에서 자산군 4개가 가로 스크롤 없이 들어가는 폭 확보(열당 약 53px 내용 폭).
  - `sm`(≥640): `formatCurrency` 원 단위 `1,234,567,890원`(1280 요구). 열 폭은 내용에 맡김.
  - 음수/부채: 앞 부호를 **U+2212 `−`** 로 통일(`formatShortCurrency`의 `-` 치환). 대출·임차보증금 칸은 항상 `−` + 절댓값(0이면 `0원`, 부호 없음). 순자산 음수도 `−`. 색은 전부 `text-foreground`(손익 빨강/파랑·`getProfitLossColor` 사용 금지).
  - `—`: 순자산만 있는 줄의 자산군 칸에만. `text-muted-foreground`, 폭 최소. `aria-label="종류별 기록 없음"`. `0원`은 `text-foreground`로 `—`와 색·글자 모두 구분.
- `기록 없음` 줄: 월 칸 `th`(월 라벨, 기록일 줄 없음) + `td colSpan={자산군수+1}` 한 칸 `기록 없음`(`text-muted-foreground text-left px-1 sticky left-14`, 배경 동일 불투명 — 가로 스크롤에도 글이 보이게).
- 스크롤 힌트: 없음(그림자 장식·화살표 추가 안 함). 넘칠 때 hairline 경계가 힌트 역할.
- 접근성 낭독: 금액 span에 `aria-label` 불필요(텍스트 그대로 "1,234만"). 각 `td`에 `headers`/scope로 "11월, 주식 1,234만" 낭독. `—` 칸은 위 aria-label.

## 6. 모션·인터랙션
- 행: 눌림 `scale-[0.99]`, `BODY_ENTER`(+120ms). 월 화살표 이동 시 행은 재마운트 안 함.
- 시트: Radix 기본 슬라이드. `motion-safe:` 접두로 reduced-motion 즉시. 표 행 stagger·카운트업 없음(읽는 화면, 모션 절제).
- 연타: 열기 버튼은 `onOpenChange` 토글 단일 상태라 중복 열림 없음. 닫는 도중 재탭은 Radix가 현재 상태에서 역전.
- 시트가 열린 채 `snapshotVersion` 변경: 표만 새 데이터로 갱신, 시트·스크롤 위치 유지(표에 `key` 부여 금지 → 재마운트로 스크롤 초기화 금지).
- 닫힘 후 포커스: 진입 행 버튼으로 복귀(Radix 기본 복귀, `onOpenAutoFocus` 기본 preventDefault 유지). 결산 화면 스크롤·선택 달 불변.

## 7. 접근성·다크
- 시트 `role="dialog"`(Radix), 제목·설명 연결. 닫기 X 히트 40px. 키보드: Tab은 닫기 X → 표 컨테이너(`tabIndex={0}`, `aria-label="월별 기록 표"`, 가로 스크롤 키보드 접근) 순. 포커스 링 `focus-visible:ring-2 ring-ring/50`.
- 대비: 본문 `text-foreground`, 보조 `text-muted-foreground`(기존 토큰, WCAG 통과 값). 다크 시트 면 `dark:bg-popover`, sticky 칸·머리줄 같은 면 불투명. 카드/시트 안 추가 박스·테두리 없음, hairline `border-border/10`만.
- 진입 행 히트영역 56px 이상.

## 8. 문구 최종안 (존댓말·조언 금지·'월말' 금지)
- 행: `월별 기록` / `8월~11월 · 4개월 기록`
- 시트 제목 `월별 기록`, 캡션 `그 달 마지막으로 앱을 연 날, 그때까지 맞춘 값이에요`

- 줄: `진행 중` / `오늘` / `11/28` / `2026-07 기록` / `기록 없음` / 빈 `기록된 달이 없어요`

## 10. 품질 체크리스트 (qa 측정 가능)
1. 진입 행: `monthly-log-button`이 구성 블록 아래·AI 행 위, 높이 ≥56px, 외피 radius/그림자가 `settlement-ai-button`과 동일(스크린샷 비교), `data-screenshot-hide` 존재, 화면의 brand 채움 버튼은 캘린더 1개뿐.
2. 보조 줄 `8월~11월 · 4개월 기록`이 월 화살표 이동 전후 동일, 행이 리마운트되지 않음(DOM 노드 동일).
3. 375px 자산군 4개(부동산·주식·암호화폐·현금성 등): `monthly-log-table`의 `scrollWidth <= clientWidth`, 어떤 셀도 말줄임/잘림 없음. 라이트·다크.
4. 375px 자산군 5개 이상 및 320px: 월 열만 컨테이너 왼쪽에 고정(scrollLeft 최대로 밀어도 불변), 순자산 포함 나머지 열은 함께 이동. scrollLeft 0에서 `월|순자산|부동산…` 순서, 겹침·잘림 0.
5. 13줄: `scrollTop` 최대로 내려도 머리줄이 컨테이너 상단에 고정, 머리줄 아래 행 글자가 비치지 않음(머리줄 배경 불투명).
6. 숫자 열 우측 정렬, 각 셀 `font-variant-numeric: tabular-nums`, 같은 열 셀의 `right` 좌표 동일.
7. 375px 셀에 `원` 접미사 없음(1만원 이상), 0은 `0원`; 1280px 금액이 `\d{1,3}(,\d{3})*원` 원 단위; 1280에서 시트 내부 컬럼 폭 ≤1040px, 가로 스크롤 없음(자산군 7개 포함).
8. `—` 칸(레거시 줄)과 `0원` 칸(실물 신규 이전 달)이 서로 다른 글자·색이며 혼동되지 않음; `기록 없음` 줄이 한 칸으로 합쳐지고 가로 스크롤 시에도 글자가 보임.
9. 대출·임차보증금 값은 `−`(U+2212)로 시작, 순자산 음수도 `−`. 시트 안 계산된 색에 빨강/파랑(손익색) 0 — 모든 셀 `color`가 foreground 또는 muted-foreground.
10. 이번 달 줄: 맨 위, `진행 중` 배지(GROUP_BADGE)·`오늘`, 값이 홈/결산 Hero와 같음. 다른 줄에 강조(굵은 배경·색) 없음.
11. 시트 안 클릭 가능 요소는 닫기 X와 표 컨테이너(포커스)뿐: 행·머리·셀 클릭해도 시트·화면 변화 0, 복사·공유 버튼 0.
12. 닫기: X·바깥 탭·Esc로 닫히고 포커스가 `monthly-log-button`으로 복귀, 결산 화면 선택 달·scrollY 불변.
13. 시트 열린 채 `snapshotVersion` 변경 시 표 갱신되고 표 `scrollTop/Left` 유지(재마운트 없음).
14. `prefers-reduced-motion: reduce`에서 시트·행 진입 애니메이션 없음(`motion-safe` 접두), 행 눌림 외 transition 속성에 `all` 없음.
15. 다크: 시트 면·sticky 칸·머리줄이 동일 불투명 면이고 경계 hairline만 보임(테두리 박스 없음), 텍스트 대비 AA.
16. 표 의미: `table > caption(sr-only)`, 머리 `th[scope=col]`, 월 칸 `th[scope=row]`, 접근성 트리에서 "11월 … 주식 1,234만" 형태로 읽힘.
