## 참고(비차단)
- 데모 10월 `—`(breakdown 644,300,000 vs netAsset 644,450,000)은 합 검증 설계대로의 표시. 캡션 ①이 설명하므로 UI 변경 불필요. 실사용에서도 오차 줄은 `—`로 나오는 점은 spec 의도.
- `0원` 칸은 데모에 없어 미확인(단위 테스트 범위). `font-variant-numeric` 계산값이 `normal`로 나옴 — Tailwind `tabular-nums`가 `table`에 걸렸는데 컨테이너 측정 한계(`t`=컨테이너)로 판정 보류, 셀 단위 확인은 qa에 위임.
- 열린 시트 위 튜토리얼 토스트가 겹치는 것은 데모 특성(범위 밖).
