## 2. 성과 › 배당 압축 (`A/dividend-chart.tsx`, `A/monthly-dividend-stocks.tsx`)
### 2.1 머리·Hero 트리
```
CardHeader: [CardTitle 배당 + InfoHint] / sub-slot(설명·월 배지, 현행)      ← 오른쪽 InlineSelector 삭제(div 포함)
CardContent
 └ Hero
    ├ 라벨행: `올해 배당`(월 선택 시 `{m}월 …` 현행 + 지급/예상치/일부 예상 칩 현행)
    ├ 금액 text-2xl font-bold tabular-nums (연간 = annualTotal)
    ├ 결론 줄(신규)  data-testid="dividend-conclusion"
    └ 투입 대비 배당(현행, mt-2 → mt-3)
```
- 머리: 헤더 flex는 왼쪽 열만 남는다. 높이가 InlineSelector만큼 줄 수 있으나 월 선택·해제와 무관하므로 이동 0(월 선택 슬롯은 현행 grid 공유 유지).
- **결론 줄**: `mt-1 flex flex-wrap gap-x-1 gap-y-0.5 text-sm text-muted-foreground tabular-nums` + `DOT_WRAP_ROW`/`DOT_WRAP_FIRST`/`DotLead`(종목 한 장과 같은 패턴), 조각 `whitespace-nowrap`.
  - 위계: Hero 24 bold(주인공) > 결론 14 (라벨 muted + 값 `font-semibold text-foreground`) > 투입 대비 배당(라벨 14 medium muted + 값 16 semibold) > 캡션 11. 결론은 Hero 바로 아래 4px, 투입 대비 배당과는 12px(`mt-3`)로 떼어 '결론 묶음'과 '부가 지표'를 분리.
  - 조각: `지급 {P}원`(값 foreground) · `예상 {E}원`(라벨·값 muted, 값 semibold) · `다음 지급 {m}월 {k}종목`(전체 nowrap, 값 foreground semibold). P=0·E=0·다음 없음이면 조각 생략. 합계 규칙: E = Hero − P.
  - 줄 수(추정): 320(296px) 지급 6자리 ≈98 + 예상 ≈98 + 다음 ≈126 + 점 32 = 354 > 296 → **2줄**(`지급 · 예상` / `· 다음 지급 …`). 390(366) 1줄 또는 2줄. 지급·예상이 둘 다 8자리(≈140+140+점16=296)면 320에서 3줄이 되므로 줄이기 1순위(`{k}종목` 삭제)로 처리 요청 없이 qa가 실측해 3줄이면 spec §12-1 적용.
  - 월 선택 시: 투입 대비 배당과 같은 클래스(`transition-opacity duration-150 motion-reduce:transition-none`, `opacity-0 select-none` + `aria-hidden`), 높이 유지 → 차트·표 이동 0. 해제 시 같은 전환으로 복귀(항상 마운트, 조건부 렌더 금지 — 재마운트 모션 소실 방지).
  - 연간 라벨은 칩 없이 `올해 배당`만(`지급`/`예상치` 칩은 월 선택 때만, 현행).
- **차트**: 항상 지급(진함)+예상(옅음), 막대 값 라벨 = 합계. 범례의 `(예상 옅음)` 항목은 모드 조건 삭제 후 **E>0일 때 상시 표시**(E=0이면 예상 막대가 없어 범례만 남는 소음 방지 — spec '상시' 대비 보정, planner 확인).
- **InfoHint**: summary 현행 + 2줄(`거래 기록이 있으면…`, `투입 대비 배당은…`). `inModal` 아님, `break-keep`. 요약 문구와 겹치는 2줄 삭제. 팝오버를 **직접 열어** 320 캡처(C113).
