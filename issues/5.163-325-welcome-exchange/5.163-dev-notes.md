## spec과 다른 점·판단
- **현재가 0 코인**: `cryptoSchema`가 `currentPrice > 0`을 요구해 저장소에서 읽을 때 0인 행은 실제로 들어오지 않는다(데모 주입 시 검증 실패 확인). 계산 함수·단위 테스트는 spec대로 0도 처리한다. 실측은 `0.0001`(평가금 `0원`)로 대체.
- **320 긴 금액**: 금액 칸(평가금 10자리 + 손익·수익률)이 이름 최소 폭 64px과 한 줄에 못 들어가면(약 192px 초과) 5.160 행의 `flex-wrap`대로 금액 칸이 이름 아래 줄로 내려간다. 버튼이 없는 코인 행은 그 줄에서 왼쪽에 붙어 보여 `ml-auto`로 오른쪽 끝에 맞췄다. **ui-designer 확인 필요**(디자인 판단: 내려간 금액 칸의 정렬).
- 자유 텍스트 거래소 묶음 키 = 공백만 뺀 글자 그대로(대소문자 구분, 5.160 `sameBroker`와 같음). 목록 거래소만 대소문자 무시.
- 새 소식 id `20261127-01`: `whats-new.test.ts` '미래 날짜 없음(KST 오늘 이하)' 때문에 KST 11/27 0시 전에는 vitest 1건이 실패한다(자정 뒤 통과 확인). 11/27이 아닌 날 머지하면 id를 머지일로 바꿔야 한다.
