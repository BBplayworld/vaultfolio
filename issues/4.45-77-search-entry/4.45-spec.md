작성: planner-designer, 2026-11-06 / 반대 검토: d6-selection 3절 #1 `축소`(가이드 3→2편, 금액·권유·새 보안 문구 0, 글 끝은 /ratio·체험만, /asset·SSR 홈 제외) 반영 / direction 합의 완료(2026-11-06), tech-review 반영(정본 호스트 방법·PWA 도메인 고정)

## 1. 문제
검색으로 우리 도메인에 닿을 문서가 없다(sitemap 루트 1건, `/ratio` 미등재). 정본(canonical·sitemap)이 리다이렉트되는 비 www 주소를 가리킨다.

## 2. 목표 행동
검색·채널로 가이드에 온 사람이 본문을 읽고 `/ratio` 업로드 또는 체험으로 넘어간다.

## 3. 범위
direction 2절 '포함' 1~5. 줄일 것·하지 않을 것도 direction 그대로.

## 4. 라우트·메타
| 경로 | title | canonical·OG url | sitemap |
|---|---|---|---|
| `/` | 기존 | www 루트 | priority 1.0, weekly |
| `/ratio` | 기존 | www/ratio | 0.8, monthly |
| `/guide/stock-ratio` | "여러 증권사 주식 비중 한 번에 보기 — 시크릿에셋" | www/guide/stock-ratio | 0.6, monthly |
| `/guide/net-worth` | "월말 순자산 정리하는 법 — 시크릿에셋" | www/guide/net-worth | 0.6, monthly |
- 가이드 metadata는 `/ratio`처럼 openGraph·twitter를 images까지 재선언(자식 선언이 부모를 통째로 대체). description은 본문 요약 1문장, 금액·권유 0.
- lastModified: 문서별 고정 날짜(글 수정 시 갱신). 루트 JSON-LD는 `@type: WebApplication`, name·url·description(`APP_CONFIG.meta.description` 그대로)·applicationCategory·operatingSystem만. 가격(offers) 넣지 않음.
- 정본 호스트 방법(tech-review 1절): `src/config/app.ts` `siteUrl` 코드 기본값을 `https://www.secretasset.xyz`로 변경(환경변수 신설 없음). Vercel Production에 `NEXT_PUBLIC_SITE_URL`이 설정돼 있으면 그 값이 덮으므로 조건부 대표 설정 1건(삭제 또는 www 값) — 머지 후 운영 스모크(완료 기준 1·2)로 검출.
- PWA 안내 그림 도메인 표기는 현재 표시("secretasset.xyz") 그대로: `pwa-guide-illustrations.tsx`의 `DOMAIN`을 siteUrl 파생 대신 리터럴 `"secretasset.xyz"`로 고정(1줄). `(main)` 안 유일한 변경이며 결산·웰컴·홈 팁 영역 아님.

## 5. 가이드 2편
**공통 구조**(위→아래): `/ratio`와 같은 헤더(로고+서비스명) → h1 → 요약 1~2문장 → h2 단계 3~4개(도구 무관한 정리 방법) → h2 "시크릿에셋으로 하면"(기능 사실만) → 행동 블록(주 버튼 1 + 보조 링크 1) → 다른 가이드 1줄 링크 → 브랜드 마무리 "안전한 자산 관리, 시크릿에셋". 본문 800~1,500자, 이미지 없음, 해요체(`/ratio`와 같은 앱 문구 톤). 본문 중간 행동 링크는 최대 1곳.

| | 가이드 1 `stock-ratio` | 가이드 2 `net-worth` |
|---|---|---|
| 검색 의도 | 여러 증권사에 나뉜 주식 비중을 합쳐 보고 싶다 | 월말·연말에 순자산을 정리하고 싶다(엑셀 대체) |
| 단계 개요 | 증권사별 보유 화면 모으기 → 같은 종목 합치기 → 국내/해외·종목별 비중 보기 → 매달 같은 날 다시 보기 | 자산군 목록(부동산·주식·현금·코인) → 대출 빼기 = 순자산 → 매달 같은 날 기록 → 변화를 입출금과 시세 변화로 나눠 보기(매수·매도·상환은 앱 안 이동) |
| 기능 사실 | 보유 종목 캡처를 올리면 종목별·국내/해외 비중을 보여 줌(`/ratio`), 업로드 고지는 `RATIO_PREVIEW_UPLOAD_NOTICE` 원문. `/ratio`는 캡처 1장만 받음(`ratio-preview.tsx` files[0]); 여러 증권사 합친 비중은 저장 후 상세 > 주식 '전체'에서 확인(`groupStocksByTicker`) | 성과 > 자산 변화 > 월 탭에서 지난달 대비 변화와 원인을 봄. 주식·코인·현금·대출은 캡처 인식, 부동산·연도별 순자산은 직접 입력 |
| 주 버튼 / 보조 | "캡처로 내 비중 보기"(`/ratio`) / "예시 데이터로 둘러보기"(`/?trial=1`) | "예시 데이터로 둘러보기"(`/?trial=1`) / "캡처로 내 비중 보기"(`/ratio`) |

**문구 원칙(qa 금지어 검사 대상)**
- 금액 0: 원·만·억 단위 수치, 예시 금액 없음. 예시는 비중(%)조차 쓰지 않는다(C27 예시 불일치 원천 차단).
- 투자 권유 0: "줄이세요·늘리세요·리밸런싱하세요·사세요·파세요·추천", 종목명·티커, 세금 절약 조언 없음.
- 보안 문구: 새로 쓰지 않는다. 필요하면 `SECURITY_COPY`(local)·`RATIO_PREVIEW_UPLOAD_NOTICE` 원문만 인용. "서버로 아무것도 안 보내요·완벽·절대·원천" 금지(캡처는 AI 인식을 위해 전송됨).
- 사실과 다른 기능 설명 금지(연도별 순자산은 수동 입력).
- 320·375에서 어절 중간 줄바꿈 없음(C25).
- 본문 문구 초안: business-pm(business.md 부록), 교차 승인 후 developer가 문구 상수 파일로 옮긴다.

## 6. GA·UTM
- page_title(단일 규칙): 화면 키 `guide:stock-ratio` → "가이드·주식 비중", `guide:net-worth` → "가이드·순자산 정리". 가이드 진입 시 1회 page_view(`/ratio`의 `trackScreen` 방식). 새 이벤트명·맞춤 정의·referrer 파라미터 0.
- 체험 이동: `trackThenNavigate("feature_use", {category:"demo"}, TRIAL_ENTRY_URL)` 재사용 → title "체험 모드", 페이지 경로 `/v/guide/<slug>`로 출처 구분(`/?trial=1`은 GA 전체 꺼짐이라 클릭 시점에 보낸다).
- `/ratio` 이동: 일반 링크, UTM 붙이지 않음(내부 UTM은 세션 출처를 덮음). 측정은 경로 탐색(가이드 → 비중 미리보기).
- 외부 채널 → 가이드 UTM: 허용 경로 `/ratio`·`/guide/*`, 키 utm_source·medium·campaign, 값 규칙 기존 그대로. utm_source=threads|cafe|blog, utm_campaign=guide_v1(`/ratio` 직행은 ratio_v1 유지).

## 7. 사용자 흐름
1. 검색/채널 → `/guide/<slug>` 도착(SSR 본문, GA page_view 1건).
2. 본문을 읽고 주 버튼 또는 보조 링크를 누른다.
3a. `/ratio` → 기존 업로드·예시·인계 흐름 그대로.
3b. 체험 → 이벤트 전송 후 `/?trial=1` → 기존 체험(자산이 있는 기기는 기존 거부 안내).
4. 하단 링크로 다른 가이드로 이동 가능.

## 8. 엣지 케이스
- JS 없음·크롤러: 본문·링크 전부 HTML에 있다(GA만 빠짐).
- 이미 자산이 있는 기기가 체험을 누름: 기존 거부 동작 그대로(변경 없음).
- 인앱 브라우저: 가이드는 정적이라 그대로, `/ratio` 이후는 기존 인앱 분기.
- preview: GA 꺼짐, Vercel preview 기본 noindex. 운영 sitemap·canonical 확인은 머지 후 운영 스모크.
- 글 수정(오래된 데이터): lastModified 날짜를 함께 바꾼다. 기능 설명이 앱과 달라지면 글을 고친다(qa 회귀: 화면 이름 대조).
- 첫 사용자: 가이드는 사용자 데이터를 읽지 않아 상태 무관.

## 10. 완료 기준(qa)
1. 운영 `/sitemap.xml`에 `https://www.secretasset.xyz` 기준 4개 URL이 있고 각 URL이 200(리다이렉트 아님)이다. robots의 Sitemap 줄도 www.
2. `/`·`/ratio`·가이드 2편의 canonical·og:url이 각자 자기 www 주소다.
3. JS 끈 요청(curl)으로 가이드 HTML에 h1·h2 전부·두 행동 링크(`/ratio`, `/?trial=1`)·브랜드 문장이 있다.
4. 가이드 문자열에 금액 단위 수치·금지 권유어·종목명·새 보안 문장이 0이다(문구 상수 grep + 보안 문장은 `security-copy.ts` 원문과 일치).
5. 가이드 진입 시 page_title "가이드·주식 비중"/"가이드·순자산 정리" page_view 1건, 체험 클릭 시 "체험 모드" 이벤트(page_location `/v/guide/<slug>`) 1건 후 이동, `/ratio` 링크에 UTM 없음(vitest).
6. `allowedUtmQuery`가 `/guide/<slug>`에서 허용 UTM만 남기고 그 밖 경로는 빈 문자열(vitest).
7. 루트 JSON-LD가 유효 JSON이고 offers·금액이 없다. `/` 첫 화면 375·1280 스크린샷이 main과 같다.
8. 결산·웰컴·홈 팁·`(main)/page.tsx`·`security-copy.ts`·`/ratio` 파일 diff 0(git diff 목록). `(main)` 변경은 `pwa-guide-illustrations.tsx` `DOMAIN` 리터럴 1줄뿐.
10. PWA 설치 안내 그림의 도메인 텍스트가 "secretasset.xyz"(www 없음)로 main과 같다. `APP_CONFIG.siteUrl`은 `https://www.` 접두(vitest).
9. 가이드 320·375·1280 × 라이트·다크 스크린샷에서 어절 중간 줄바꿈 0, 버튼 히트영역 40px 이상.
- 알려진 한계: 실제 색인·검색 노출은 머지 후 4~8주, 에이전트는 Search Console 조회 수단 없음 → 판독은 GA로만.
