- **왜 지금 — 첫 발견 기여**: 유입 병목(first_visit 월 약 17)에 닿는 무료 경로 중 우리 도메인에 남는 자산은 검색 문서뿐이다. 색인에 4~8주가 걸려 11/20 머지여야 12월 결산·연말 정리 검색 시기(12월 중순~1월 초)에 걸린다. 결산 창(11/27~12/10) 영역과 파일이 겹치지 않는다. 리텐션 기여는 없음.
- **누구를 위해**: 엑셀·노션으로 직접 정리하는 3040 주식 투자자 중 ① 증권사 2곳 이상에 나눠 보유해 합친 비중을 손으로 계산하는 사람 ② 월말·연말에 시트로 순자산을 맞추는 사람. 이들은 앱 이름이 아니라 "여러 증권사 비중", "월말 순자산 정리"로 검색한다. 지금 우리 도메인에는 닿을 문서가 없다(운영 sitemap 루트 1건, `/ratio` 미등재).
- **정본 호스트(운영 실측)**: sitemap·canonical·OG url이 `https://secretasset.xyz`(비 www)인데 이 주소는 `www`로 307 리다이렉트된다. 정본이 리다이렉트면 새 문서 색인 신호가 흔들린다 → **www 정렬 동의**(합의 절).
- **지표(익명 기기, 기존 GA만 — 새 이벤트·맞춤 정의 0, 대표 기기 `?ga-optout=1` 제외)**
  1. 주 지표: 가이드 2편 page_title("가이드·주식 비중"·"가이드·순자산 정리") 활성 사용자 합
  2. 행동 지표: 가이드 다음 행동 기기 = 경로 탐색(가이드 → '비중 미리보기') + '체험 모드' 이벤트 중 페이지 경로 `/v/guide/*` 기기(중복 기기는 1로)
  - 참고(기준선 없음): 가이드 세션의 기본 채널 그룹(자연 검색 vs utm_source=threads·cafe·blog). 판정에는 쓰지 않고 해석에만 쓴다.
- **판독(머지일+8주 ≈ 2027-01-15) — 제안선 확정**: 주 지표 ≥ 10 그리고 행동 지표 ≥ 3.
  - 근거: 기준선이 월 신규 약 17, 활성 약 33이라 8주 10기기는 신규 유입의 약 3할을 가이드가 맡는 수준(낙관 아닌 하한). 3기기는 /ratio·체험 전환을 "있다/없다"로만 가르는 최소치다. 표본이 작아 비율(30%)이 아니라 절대 수로 둔다.

## 경험
### 1. 이 기능 후 사용자가 하는 행동 (관찰 가능)
- 검색 결과에서 가이드에 들어와 JS 없이도 본문 전체를 읽는다.
- 가이드 끝(과 본문 중간 1곳)에서 '캡처로 내 비중 보기'(`/ratio`) 또는 '예시 데이터로 둘러보기'(`/?trial=1`)를 누른다.
- 외부 채널(Threads·카페·블로그) 링크로 가이드에 들어온 방문은 UTM으로 출처가 남는다.

### 2. 범위
- **포함**
  1. 정본 호스트 정리: sitemap·robots의 sitemap 줄·canonical·OG url을 실제 응답 호스트(www)로 맞춘다. 사용자 데이터는 origin(www) 기준이라 영향 없음. 방법(코드 기본값/환경변수)은 tech-review가 정한다. PWA 설치 안내 그림의 도메인 표기는 그대로 둔다.
  2. sitemap: 루트 + `/ratio` + 가이드 2편 = 4건. lastModified는 매 요청 시각이 아니라 문서별 고정 날짜.
  3. 공개 가이드 2편(`(main)` 밖 정적 SSR, `/ratio`와 같은 껍데기): `/guide/stock-ratio` "여러 증권사 주식 비중 한 번에 보기", `/guide/net-worth` "월말 순자산 정리하는 법". 각 글의 metadata에 title·description·canonical·OG·twitter를 새로 선언(OG 이미지는 공용 `OG_IMAGE` 재사용).
  4. 루트 JSON-LD(WebApplication) 1개: 기존 `APP_CONFIG.meta` 문구만 쓴다(새 문구 0). head에만 넣고 body 렌더 diff 0.
  5. GA: 가이드 화면 키 2개와 page_title 2개 추가, UTM 허용 경로를 `/guide/*`까지 확장(키·값 규칙 동일).
- **줄일 수 있는 것**: 가이드 목록 페이지(`/guide`) 없음(2편이라 서로 링크로 충분) · 가이드 전용 OG 이미지·본문 이미지 없음(텍스트만) · 가이드 JSON-LD(Article) 없음 · 새 GA 이벤트·맞춤 정의 0(체험 이동은 웰컴 칩과 같은 `trackThenNavigate(feature_use, demo)` 재사용) · 루트 JSON-LD는 tech-review가 첫 화면 렌더 무영향을 보장 못하면 뺀다.
- **하지 않을 것**: `/asset` 서버 리다이렉트, 루트 SSR 소개 문구(4.48), 3편째 글, 가이드에 사용자 데이터·계산 수치·예시 금액 표시, 실제 종목명, 새 보안 문구, 가이드 안 저장·업로드 기능, 외부 게시(채널은 business-pm 초안만), `/ratio` 화면·문구 변경(p2 캡션은 별건 — 업로드 고지 문장은 보안·데이터 문구라 고치면 위임 ⑤ 위반, 문장 수정 대신 예시 상태에서 숨김 방식 권고).
