## 0. 반려 이력 확인
- LEARNINGS 11-09: "더보기 = 설정 전용. 기능 진입점을 더보기로 옮기는 안 금지." 본 건은 반대 방향(더보기에서 **빼냄**)이라 충돌 없음. 단 "핵심 기능은 보이는 자리에" 교훈을 후보 평가 기준으로 삼음.

## 1. 현행 사실 (planner 서술과 다른 점)
1. 세금 화면은 하단 내비에서 **어느 탭도 켜지지 않는다**. `bottom-nav.tsx:26-32 getActiveId`가 tax → null. ("더보기가 켜진다"는 `navigation-context.tsx:90 mainTypeOf`의 스와이프 방향 계산일 뿐, 탭 강조와 무관.)
2. **체험(?trial=1)은 더보기·업데이트 탭을 숨긴다**(`bottom-nav.tsx:88`, 캡처 확인: 홈·상세·성과 3칸). 체험에서 세금 관리는 주식 도구 타일(11/1~12/31·해외주식 보유 시)로만 도달. 더보기 이동은 체험 진입점도 늘린다.
3. 진입점 전수 4곳: 더보기 행(`tool-menu.tsx:253`), 주식 도구 타일 `stock-tool-tax`(시뮬레이터 탭 지정, `stock-tools.tsx:117-129`), 홈 팁 kind=tax(`home-tip-box.tsx:127`), 기능 팁 `tax-simulator`·`tax-schedule`(`app-features.ts:37,45`). 모두 `navigate({type:"tax"})` 한 경로. **이동은 더보기 행 1개의 위치만 바꾸면 되고 나머지는 불변.**
4. 뒤로(`back`)는 history pop이라 어느 입구에서 왔든 원래 화면으로 복귀. 새 위치와 무관.

## 3. 권고 (A) 상세 허브 하단 "세금 관리" 행 1개

### 3-1. 컴포넌트 트리 (`detail-hub.tsx`)
```
DetailHub
 ├ 헤더(상세 + HubShareButton)             유지
 └ grid gap-3 sm:gap-4 lg:grid-cols-2
    ├ KpiCard 주식·부동산·암호화폐·현금·(실물)·대출   유지
    └ [신규] TaxEntryRow  (grid 마지막 자식, col-span-full → Tailwind 클래스 `lg:col-span-2`로 명시)
```
- 재사용 근거: `stock-tools.tsx ToolTile`(bg-muted/50, dark:bg-card dark:shadow-sm, rounded-lg→dark:rounded-xl, 아이콘 text-primary size-4, ChevronRight) 패턴의 가로형. 자산 카드(KpiCard)와 다른 "도구 행"으로 읽히게 면 높이만 작게. 신규 토큰·색 0. ToolTile을 `components.md`에 공용 추출할지는 developer 판단(2곳째 사용), 이번엔 복제도 허용·등록 필수.
- 목업 주의: 1280 목업(`mock-detail-1280-dark.png`)은 `col-span-full`이 빌드에 없어 짝 칸에 들어간 모습. **구현은 반드시 `lg:col-span-2`로 전폭**(카드와 같은 폭 한 줄). 실물 카드 유무로 카드 수가 달라져도 전폭이라 안전.

### 3-2. 수치 (375px / 1280px)
- 행: `min-h-16`(64px), `px-4 py-3`, `gap-3`, radius `rounded-xl`(카드와 동일), 면 `bg-card shadow-sm`(다크, §2 면 토큰·테두리 대신 그림자). 라이트는 ToolTile과 동일하게 `bg-muted/50`.
- 아이콘 Receipt `size-5 text-primary`(기존 세금 헤더의 주황 아이콘과 달리 허브 카드 아이콘 색에 맞춤), 제목 `text-sm font-semibold`, 보조 `text-sm text-muted-foreground truncate`, 마감 날짜 토큰만 `tabular-nums font-medium text-orange-600 dark:text-orange-400`(§1 주의 유도, 임박 시에만), 우측 ChevronRight `size-4 text-muted-foreground`.
- 카드 그리드 gap과 같은 간격(gap-3 sm:gap-4). 행과 푸터 사이 기존 간격 유지. 1280: 전폭 한 줄, 높이 64px 유지(늘리지 않음).
- 히트영역: 행 전체 버튼 64px, 40px 이상 충족. `active:scale-[0.98]`, `motion-safe:transition-[background-color,transform] duration-150`(§6, `transition: all` 금지), focus-visible ring.

### 3-3. 보조줄 문구 (투자 조언 금지, 존댓말 톤)
- 내 자산에서 파생된 일정이 있을 때: `getAssetDrivenHighlights(assetData, todayKst(), 1)[0]` → `{dueLabel} {title}` 예 `12/1~12/15 종합부동산세 신고·납부`. 임박(`isImminentTaxMatch`)이면 dueLabel만 주황, 아니면 muted.
- 파생 일정 없음/자산 0건: `세금 일정과 연말 절세 시뮬레이션`.
- 홈 팁 닫기(`taxNotice` dismiss)와 **독립**: 허브 행은 dismiss 상태를 읽지 않고 항상 하이라이트 계산 결과를 보인다.
- 긴 문구: 1줄 `truncate`(375에서 dueLabel+title 한 줄 확인, 320에서 말줄임). 아주 긴 제목은 `title` 속성 불필요(탭 후 상세에서 전문).
- 클릭 = `navigate({ type: "tax" })`, `initialTab` 지정 안 함(일정 탭). 첫 사용·체험: 행은 항상 표시(체험에서도 세금 진입 가능해짐 — 이점). 로딩: 자산 로딩 전에는 보조줄을 기본 문구로(스켈레톤 불필요, 계산이 동기).
- testid: `detail-hub-tax-row`, 보조줄 `detail-hub-tax-sub`. `data-screenshot-hide`: 행 전체(인증카드·공유 스크린샷에 도구 행 불필요).

### 3-4. 하단 내비 활성 탭 (필수 수정)
- `bottom-nav.tsx getActiveId`: `tax` → `"detail"`로 추가. 현재 null(아무 탭도 안 켜짐)이라 어느 입구에서든 길 잃음 → 개선이지만 홈 팁에서 들어와도 상세가 켜짐. 판단: 홈 탭이 켜져 있다 뒤로 가면 홈으로 돌아오는 모순보다 "세금 관리는 상세 소속"이라는 일관 규칙이 낫다(설정이 더보기에 소속된 것과 동일 구조).
- `navigation-context.tsx:90 mainTypeOf`: tax → `"detail"`(스와이프·슬라이드 방향이 상세 기준), settings만 more 유지. 주석("settings·tax는 더보기 하위") 수정.
- 상세 탭을 다시 누르면 허브로(기존 `navigate({type:"detail",tab:"hub"})`) → 세금에서 상세 탭 탭 = 허브 복귀, 자연스러움.
- 스와이프: tax에서 좌우 스와이프 시 상세 기준 이웃(홈/성과)으로 이동. 기존 PAGE_ORDER 불변.

### 3-5. 모션·인터랙션
- 행은 허브 진입 애니메이션(`animate-in fade-in slide-in-from-bottom-3`)에 컨테이너째 포함, 별도 stagger 없음. 연타: 단순 navigate, 중복 방지 불필요(같은 view 재진입은 history push 1회 — 기존 더보기 행과 동일 동작).
- 허브 재마운트로 사라질 모션 없음(정적 행).

### 3-6. 접근성
- 네이티브 `<button>`, 이름 = "세금 관리" + 보조줄 포함 읽힘. 아이콘 `aria-hidden`. 다크·라이트 대비: 주황 `orange-400`/`orange-600` on card 4.5:1 이상(기존 세금 배지와 동일 쌍).

## 5. 홈 원인 펼침 계측 (화면 변화 0)
- 대상 `views/home/dashboard.tsx:305-316` Hero 쉐브론 버튼. 시각·간격·모션 변경 **없음**, DOM 추가 없음. 열 때(false→true)만 이벤트 1회, 닫을 때는 미전송. `screenshotMode`에서는 버튼이 없어 무영향. 체험은 `track` no-op.
- 이름은 기존 규칙(`ga.ts` `feature_use` + category → `CATEGORY_TITLES`) 재사용: category `home_cause_open`(신규 1개, `ga.ts:89` 사전과 `CATEGORY_TITLES`에 추가), page_title 예 `홈 변동 원인 열기`. 새 이벤트명 만들지 않음. GA 판독 기준 page_title로 열기 누름 기기 수 + 홈 사용자 대비 비율.
- qa: 버튼 탭 전후 스크린샷 픽셀 동일, 열고 닫고 다시 열면 이벤트가 열 때마다 1회(세션 중복 제한 여부는 developer 선택, 권고: 제한 없음 — 횟수가 곧 관심도).

## 7. 품질 체크리스트 (qa 판정용)
1. 더보기 화면에 '도구' 라벨·세금 관리 행이 없고 섹션 순서가 프로필·공유·백업·지원·설정이다(375 다크 캡처).
2. 상세 허브 마지막 자식으로 `detail-hub-tax-row`가 있고 375에서 대출(또는 마지막 카드) 아래 같은 gap으로 붙는다.
3. 1280에서 행이 `lg:col-span-2` 전폭 한 줄이다(짝 칸 한쪽에 들어가지 않는다).
4. 행 높이 64px 이상, 클릭 영역 40px 이상, 카드와 같은 radius(rounded-xl).
5. 행 클릭 시 세금 화면(`#tax`, 일정 탭)으로 가고, 하단 내비에서 '상세'만 켜진다(홈·성과·더보기 비강조). 체험에서도 동일(3칸 중 상세).
6. 세금 화면에서 상세 탭 탭 = 상세 허브, 뒤로 = 진입한 화면(허브·홈 팁·주식 도구 타일 각각 확인).
7. 기존 입구 3곳(주식 도구 타일 → 시뮬레이터 탭, 홈 세금 팁, 기능 팁 2종)이 모두 그대로 동작하고 탭 강조는 상세다.
8. 보조줄: 파생 일정 있으면 `dueLabel title` 한 줄(375·320 말줄임, 줄바꿈 0), 없으면 기본 문구. 임박(0~6일)에서만 날짜가 주황.
9. 홈 팁 '세금'을 닫은 뒤에도 허브 행 보조줄은 그대로 일정을 보인다.
10. 다크·라이트 두 모드에서 행 면·텍스트 대비 정상(라이트 `bg-muted/50`, 다크 `bg-card`), 신규 색 0, 펼침 `transition: all` 0.
11. 인증카드/공유 스크린샷(`screenshotMode`)에 세금 행이 나오지 않는다.
12. 홈 Hero 쉐브론 열기: 전후 화면 변화 0, GA 이벤트 `feature_use`(category `home_cause_open`)가 열 때만 1회, 닫을 때 0회, 체험 0회.
13. CHECKLIST.md UI 항목(터치 40px·tabular-nums·다크 대비·모션 `motion-safe`·재마운트) 이상 없음.
