# 5.181 #371 ui — 종목 한 장 배당 줄 '투입 대비 X%'

기준은 main 1725ec6이다. 근거는 5.181-spec.md 3~5절, design-system §6·§7·§11, components `DotLead`, CHECKLIST C152·C160·C164·C166·C168·C169다. 바꾸는 곳은 `StockPageDividendRow`의 ready 상태 하나다. 새 토큰, 새 컴포넌트, 새 모션은 0개다.

## 1. 구조·위계 (위→아래, 버튼 안 `div.min-w-0`)
- **첫 줄** `p`: 현행 클래스(`text-sm tabular-nums flex flex-wrap gap-x-1 gap-y-0.5 DOT_WRAP_ROW`)를 그대로 쓴다.
  - 머리 조각(DOT_WRAP_FIRST)을 **두 덩이로 나눈다.** `<span class="min-w-0 ml-2"><span nowrap>올해 세전 배당</span>{" "}<span nowrap>지급 <b>A</b></span></span>` 형태다. 예상만 있으면 `지급 A` 대신 `예상 B`가 오고 muted를 유지한다. 이렇게 나누는 이유는 `세전 ` 3자 때문에 320~322에서 10자리 금액이 한 덩이로 넘치기 때문이다(실측 오른쪽 넘침, 셰브런 침범). 나누면 그 폭에서만 덩이 안에서 `배당` 뒤로 접힌다(StockPageDecision plan 조각과 같은 패턴). 다른 폭에서는 nowrap 한 덩이와 높이가 같다(실측 차이 0). 숫자에는 truncate를 쓰지 않는다(C169).
  - 금액은 현행대로다. 지급은 `font-semibold text-foreground`, 예상 조각은 `text-muted-foreground`, 예상 금액은 `font-semibold`다. 둘째 조각 앞에는 `<DotLead />`를 둔다.
- **둘째 줄** `p`: 현행 `mt-0.5 text-xs text-muted-foreground flex flex-wrap gap-x-1 gap-y-0.5 DOT_WRAP_ROW`에 **`tabular-nums`를 더한다.**
  - 조각은 `다음 지급 N월`(있으면 FIRST)과 `<DotLead />투입 대비 X%`다. 각 조각은 `whitespace-nowrap`으로 묶는다(C152). 다음 지급이 없으면 투입 대비 조각이 FIRST가 된다.
  - X는 색·굵기 강조 없이 muted로 둔다. 손익색을 쓰지 않는 이유는 수익이 아니고 평가 어휘·색도 금지이기 때문이다. 현행 상위 정보인 금액보다 위계를 낮춘다.
  - 두 조각이 모두 없으면 `p`를 렌더하지 않는다(빈 `mt-0.5` 금지).
- 오른쪽 `ChevronRight`, `min-h-12`, `py-2.5`, 누름(`active:bg-muted/40`), 포커스 링, 진입 `motion-safe:fade-in 200ms`는 현행 그대로다. 투입 대비 조각에는 별도 모션을 주지 않는다. 금액과 같은 렌더에서 함께 나오므로 재마운트나 깜박임이 없다.

## 2. 문구 표 (C166, 새 안내·오류 문구 0)
| 상태 | 첫 줄 | 둘째 줄 |

## 3. 높이 실측 (로컬 prod 1725ec6, `next build --webpack`, 데모 + 배당 API 목, 행 복제 DOM 주입, 라이트·다크 쿠키 `theme_mode`, 320~440 2px + 1280)

## 4. 접근성
- 접근 이름은 버튼 안 글자다(aria-label·describedby 신규 0). 실측 이름은 `올해 세전 배당 지급 456,789원 예상 123,456원 다음 지급 12월 투입 대비 3.2%`다. DotLead는 aria-hidden이며 단락 사이는 공백으로 이어진다. `%`·`미만`은 글자 그대로 읽힌다.
- 히트영역은 행 전체(min-h-12)로 현행과 같다. 키보드 Enter/Space와 포커스 링도 현행이다. 다크에서 대비는 muted 토큰을 현행 둘째 줄과 같게 쓴다.
- `data-screenshot-hide`는 불필요하다. 종목 한 장은 캡처·공유 대상이 아니다.

1. 표시 픽스처에서 `stock-page-dividend-yield` 글자가 `투입 대비 X%`이고 X는 spec 5절 ①②③과 일치한다(C150).
2. 화면 전체에 `세전 추정` 0, `연 `·`평단 대비` 0이다. 첫 줄은 `올해 세전 배당 지급` 또는 `올해 세전 배당 예상`으로 시작한다.
3. 숨김 3조건마다 yield 0개, `data-yield="hidden"`이고 금액·다음 지급은 main과 같다. 지급만 + 숨김이면 둘째 `p`가 0개다.
4. USD 환율 1300과 1450에서 같은 글자, 해외 캡션 0이다.
5. 320~440 2px × 라이트·다크 × 금액 4/4~10/9 × 3모양에서 main 대비 높이 증가가 3절 표 구간 안에만 있다. 둘째 줄 줄 수 증가 0이다(C160·C164·C168).

8. 둘째 줄에 `tabular-nums`가 적용되고, X는 muted이며 손익색 클래스가 0이다.
