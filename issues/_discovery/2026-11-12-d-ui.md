# 2026-11-12 D 근거 수집 — UI 품질 (ui-designer)

대상: 운영 v4.84 `?trial=1`, 다크(theme_mode 쿠키, html class=dark 실측, C81·C85) + 라이트 1건, 320·375·1280. 스크린샷: `screenshots/2026-11-12-*`.

## 후보 (우선순위 순)

### 1. 배당 화면 차트·표 — 숫자 겹침·잘림 (신규, 가장 심함)
- 근거: `dividend-375-dark.png`, `dividend-320-dark.png`, `dividend-chart-1280-dark.png`
- 375: 6·7·9·10월 막대 값 라벨(1,875원·1,989원)이 서로 겹쳐 읽히지 않음. 표에서 `72,800원`이 `72,80/0원`으로 줄바꿈, 헤더 `지급금액`도 `지급금/액` 2줄, `매수 2026-03-/12` 줄바꿈.
- Y축 눈금 라벨이 `6만·4만·3만·1만·0`: 등간격 눈금(0·1.5·3·4.5·6만)을 정수로 반올림해 4.5만이 "4만"으로 표시, 격자 간격과 숫자가 불일치(1280에서도 동일).
- 위반: design-system §6 tabular-nums·줄바꿈 금지(금액 nowrap), 정보 설계(숫자 신뢰). 배당 화면은 대표가 자주 보는 성과 허브 하위라 영향 큼.
- 안: 라벨은 겹치면 생략(최대값·합계만), 금액 셀 `whitespace-nowrap`+열 폭/축약, Y축 눈금을 만 단위 소수 1자리(1.5만) 또는 라운드 눈금.

### 2. 종목 한 장 평단 칩 — 눈금선·눈금 라벨과 충돌 (기존 후보 재확인: 유효)
- 근거: `stockpage-375-dark.png`, `avg-chip-375-dark.png`, `stockpage-320-dark.png`
- 실측(375): 칩 글자 `내 평단 61,000원` x203–292, y488–502 / 10만 격자선 y491 → 격자선이 글자 윗부분을 관통. 칩 우측 292와 `10만` 라벨 시작 293 → 간격 1px. 현재가 라벨(`70,000원`, y495)이 10만 라벨(y485–497)과 세로로 2px 겹침. 320도 동일(칩 237 / 라벨 238, 칩 y495–509 vs 현재가 y502–516).
- 평단 점선(y509)과 칩 사이도 약 7~20px 떨어져 어느 선의 라벨인지 모호.
- 안: 칩-눈금 라벨 최소 6px 간격(칩 우측 끝을 축 라벨 시작 −6px), 격자선과 겹치면 칩을 선 아래/위로 ±8px 회피, 칩에 배경색 halo(현재 글자 외곽선만) 사용 여부 재검토. 가격 칸 라벨 3개(눈금·평단·현재가)에 겹침 0 규칙.

### 3. 라이트 종목 한 장 로딩 박스 — 문구가 윤곽선·격자와 겹침 (기존 후보: 유효)
- 근거: `load-box-375-light.png`(라이트 실측, API 지연 주입)
- `가격 흐름을 불러오는 중…`이 스켈레톤 곡선·가운데 격자선 위에 그대로 올라가 취소선처럼 보임. 박스 아래에 ~100px 빈 구간(차트 높이 예약 후 범례 자리)도 남음.
- 안: 문구는 박스 가운데 배경 칩(bg-card/80 rounded)로 받치거나 윤곽선·격자 제거 후 문구만. 박스 높이를 실제 차트와 일치.

### 4. 성과 허브 자산 변화 카드 — 행 목록 정렬 4px 어긋남 (기존 "배당 허브 2px" 재측정: 4px)
- 근거: `perf-375-dark.png`, DOM 실측
- 카드 머리 구분선 컨테이너 x64·w283, 바로 가기 행 버튼(최근 7일·월별 기록·시장과 비교) x60·w283 → 행이 4px 왼쪽, 우측 쉐브론이 카드 머리 쉐브론보다 4px 안쪽(343 vs 347). 구분선 시작점도 머리 구분선(64)과 행 구분선(60)이 다름. 카드 머리와 행 사이 빈 공간(약 30px)도 큼.
- 안: 행 버튼을 `-mx-` 없이 컨테이너와 동일 폭으로 하고 히트영역은 after로 확장.

### 5. PC 새 소식 시트 — X 24px·바로 가기 76×20 (기존 후보: 사실상 해소, 종결 권고)
- 근거: `whatsnew-1280-dark.png`
- 보이는 X 박스는 24×24지만 `sheet.tsx`의 `sm:after:-inset-2`로 실제 히트영역 40×40 (design-system 40px 충족). 바로 가기 버튼 보이는 크기 76×20, `after:-inset-y-2.5 -inset-x-2`로 실제 92×40. 행 간 간격이 있어 이웃 항목과 히트영역 겹침 없음.
- 결론: 접근성 위반 아님. 개선 가치 낮음(후보에서 제외 권고). 단 8개 항목 모두 같은 "바로 가기"가 반복돼 스캔성은 낮음(low).

## 근거 참고
- 데모 데이터에서 삼성전자 현재가(70,000원)와 1년 차트 가격대(10~30만)가 맞지 않아 차트가 어색해 보이는 것은 데모 데이터 문제로, 이번 후보에서 제외.
- 홈(375/1280)·상세·성과 허브·주식 탭은 육안 결함 없음. 홈 변동 원인 보기 30×30 버튼은 눈으로 보이는 크기이며 히트영역은 미확인(미측정).
