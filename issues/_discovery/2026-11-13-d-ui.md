# 2026-11-13 D 자율 발굴 UI 근거 (ui-designer)
대상: 운영 /?demo=1 (v4.92) 비로그인 첫 화면. 375·320 다크 + 375 라이트 전체 캡처 (screenshots/2026-11-13-home-{375-dark,320-dark,375-light}.png). 로그인 이후 탭은 미캡처(한계). 이미 알려진 3건·LEARNINGS 반려 방향 제외.

## 후보 1. 홈 미리보기 도넛 라벨이 조각 밖으로 넘침 (정보 가독성)
- 화면: 포트폴리오 미리보기 도넛. '부채 9,500만원 12.8%' 3줄 라벨이 12.8% 조각(작은 조각)보다 커서 조각 경계·중앙 구멍 쪽으로 삐져나옴. 320에서 더 심함(구멍과 거의 접촉).
- 근거: design-system §6 광학 정렬·정보 설계 §11, 첫인상 화면. 파일: home-375-dark.png, home-320-dark.png
- 수정 방향: 조각 비율이 일정 미만(예 15%)이면 라벨을 2줄(이름+%)로 줄이거나 조각 밖 리더라인/하단 범례로 이동. 금액은 중앙·범례로.

## 후보 2. '예시 데이터' 미리보기 안에 '첫 번째 자산을 추가해보세요' 빈 상태 카드 혼재 (상태 모순)
- 화면: 순자산 551,159,778원·도넛이 채워진 바로 아래에 '첫 번째 자산을…' CTA 카드가 같은 카드 위계로 끼어 있어, 데이터 있음/없음 신호가 충돌. 주식 미리보기와의 구분도 흐림.
- 근거: design-system 상태 설계(첫 사용 vs 예측/예시), 한 화면 CTA 위계. 파일: home-375-dark.png
- 수정 방향: CTA를 미리보기 블록 하단/상단 sticky 단일 CTA로 이동하거나 '예시' 영역과 시각 분리(섹션 gap-5, 구분 헤더), 미리보기는 하나의 카드군으로 묶기.

## 후보 3. 미리보기 헤더·종목 로고 로딩의 320/375 불일치
- 화면: 320에서 '포트폴리오 미리보기' 헤더의 '예시 데이터' 칩이 다음 줄로 떨어져 우측 '직접 둘러보기'와 정렬이 깨짐(375는 한 줄). 또 375 캡처에서는 종목 로고가 단색 원 플레이스홀더인 반면 320에서는 실제 로고(엔비디아·애플·테슬라) — 로고 로드 전/후 레이아웃·색 점프 가능성(캡처 타이밍 차이일 수 있어 재확인 필요).
- 근거: design-system §6 광학 정렬·tabular, 이미지 로딩 상태. 파일: home-320-dark.png, home-375-dark.png
- 수정 방향: 헤더 칩을 제목 옆 고정(flex-nowrap, 제목 truncate) 또는 칩을 카드 내부로 이동. 로고는 고정 크기 스켈레톤→fade-in(motion-safe).

참고(라이트): home-375-light.png 촬영만 함, 별도 결함 후보로 채택 안 함.
