## ② 반대 검토 — 안 I를 최선형으로 다시 그리면
**I\* '내 투자' 허브**: 투자 = 주식·코인 목록(D2·D7) + 거래(주식·코인) + 종목 한 장(D5) + X-Ray(D4) + 시장과 비교(P7) + 주식 수익(P6) + 배당(P8) + 불리기(P10) + V1′ / 상세 = '내 재산 장부'(현금·대출·부동산·실물 + 전체 KPI) / 성과 = 전 자산 변화·결산·성적표. → '내 주식이 두 탭에 쪼개짐'(planner 반론)은 해소된다.

**I\*의 가장 강한 논거**: 사용자는 '투자(주식·코인)'와 '재산(집·현금·빚)'을 다른 덩어리로 인식하고(증권 앱 vs 가계부 앱), 지금 투자 기능은 입구가 탭을 넘는다(도구 타일 4개 중 2개가 성과로 점프, 시장과 비교 입구 4곳). 한 탭에 모으면 "내 주식 얘기는 여기"가 한 문장으로 성립한다 — LEARNINGS 10월 '인식 단위로 묶기'에 오히려 맞는 면이 있다.

**I\*의 가장 약한 고리 — 성과와의 경계가 다시 무너진다.**
1. 성적표 5축 중 3축(장기 순자산·레버리지·습관)은 전 자산이라 투자로 못 옮긴다 → '성적표·불리기' 한 카드를 둘로 쪼개야 하고, 불리기는 성적표 분산 축과 같은 분류를 쓴다(겹침 5 그대로).
2. 성과 '자산 변화'의 원인 분해·월/올해 결산에는 주식 손익이 그대로 들어간다 → "주식으로 얼마 벌었나"가 성과(결산 원인)와 투자(P6) 두 곳에서 답해진다. 시장과 비교도 '변한 것'이라 성과 질문과 같다. 즉 I\*는 '가진 것/변한 것' 축을 '투자/비투자' 축으로 바꾸는데, 변화 화면은 자산군을 가로질러야 의미가 있어 두 축이 직교한다 — **어떤 축으로 잘라도 한쪽에 중복이 남는데, P는 중복이 0인 쪽(시장 역사)만 뺀다.**
3. 상세가 비어 간다: 주식만 가진 사용자(신규 대다수 추정)에게 상세는 빈 장부, 현금·부동산만 가진 사용자에게 투자는 빈 탭. 두 탭 중 하나가 사용자 절반에게 빈 화면.
4. 비용: 가장 많이 쓰는 화면(상세·주식)과 첫 자산 마법사 착지·체험 흐름(#249)·튜토리얼·해시 5+·GA 상세·주식* 9종 개명 → #245 판독 단절. 큰 UI 방향 변경 2건 동시.

**판정: P 유지.** I\*의 강점(입구 분산)은 탭 이동 없이 '바로가기는 그대로, 정본은 하나'로 해결된다(현재 뒤로 규칙이 이미 출발 화면으로 돌려보냄).
