**권고 — 2단계 줄이기**
- **1단계(지금, risk:low, 저장·서버 0)**: 시장과 비교 타일 제거(대표 결정 ① 앞당김 — 적용 조건 '11/25 CSV ≤1기기'는 이미 충족, 12/20은 R2 묶음 일정이었을 뿐) + 해외주식 세금 타일 제거. 남는 2개(X-Ray·내 자산 점검)는 한 줄 → 375 166→약 64px(−100px), 320 224→약 84px(반 칸에서 점검 값 2줄 예상, ui-designer 실측). 375 첫 종목 행이 첫 화면에 들어온다.
  - 판독 영향: 내 자산 점검 타일이 둘째 줄 → 첫 줄로 올라가 #245 보조 지표 '타일 경유 수'가 오를 수 있다(주 지표 `·정함` 정의 불변) → 판독 경계 기록(C144). 세금 시뮬 1/10 판정은 '입구 합산(허브 행·홈 팁)'으로 재정의. 둘 다 받아들일지 CEO 판정.
  - 보완: 11~12월에는 상세 허브 '세금 관리' 행이 시뮬 탭을 바로 열게 한다(아래 C3) — 세금 직행 손실 0.
- **2단계(12/20 R2)**: 내 자산 점검 타일은 원칙 ④대로 제거(판독이 '타일 경유가 주력'이면 결정 ⑤로 대표 상정) → **X-Ray 1개만**. 전체 폭 1줄 타일 유지 또는 비중 바 머리 1줄로 합치기(ui-designer 판단).
- 하지 않음: 3개를 지금 한꺼번에 제거(결정 ④의 '12/20까지' 위반), 접기·기억 키, 가로 스크롤 칩 줄(4.67 '가로 스크롤 2개' 지적 — 카테고리 줄이 이미 가로 스크롤).

지표 정본 대조(1단계): 시장 대비 1주 = 자산 변화·주식 시장 타일(홈 지수 줄은 바로가기 유지) / 점검 차례 N = 성과 성적표(홈 팁·행 표시 유지, 타일은 2단계 제거) / 세금 일정·시뮬 = 세금 관리(허브 행 정본) / 쏠림 = X-Ray(타일 유지).
엣지: 해외 없음 → 지금도 3개 이하(1단계 후 X-Ray·점검 2개) / 이름표 행 0 → X-Ray 1개 전체 폭(기존 홀수 규칙) / 주식 0 → 묶음 없음(불변) / 체험 모드 동일.
완료 기준(초안): 375·320 다크·라이트에서 시장·세금 타일 DOM 0, 첫 종목 행 top이 375에서 667 이하, 행선지 4곳(홈 지수 줄·자산 변화 시장 타일·허브 세금 행·홈 세금 팁) 그대로 동작, 인증카드 캡처 불변.
