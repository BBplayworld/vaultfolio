## 2. 선정: 현금·대출 잔액 한 번에 맞추기 — 반대 검토
- **누구의 어떤 문제**: 엑셀 습관대로 매달 계좌·대출 잔액을 고치는 사람이 대상이다. 지금은 계좌 하나를 고치려면 '상세 › 현금 탭 › 카드 펼치기 › 수정(6~10필드)'을 거쳐야 하고, 이걸 계좌 수만큼 반복해야 한다. 입구 3곳은 모두 엉뚱하게 추가 폼으로 간다.
- **꼭 해야 하나**: 하지 않으면 매달 돌아온 사람이 갱신을 마치지 못하고, 순자산이 낡은 채로 남는다. PRINCIPLES 4 진단 '숫자가 낡아 이탈'의 직접 원인이다.
- **축소(v1 범위)**: ① 현금·대출을 **1건 이상 보유한 사람**에게만, FAB 현금성·대출의 `직접 입력`을 **잔액 목록 시트**로 바꾼다(0건이면 지금처럼 추가 폼). ② 행 하나에는 이름·현재 잔액·새 금액 칸만 둔다. 외화 계좌는 통화 표기를 그대로 쓴다. 합계·비중·순자산은 넣지 않는다(정본은 상세 탭과 홈 도넛, C1). ③ 저장은 1회다. 바뀌는 행만 기존 업데이트 함수로 저장하고, 나머지 필드는 건드리지 않는다. 바뀐 항목 수를 버튼 문구에 보여 준다. ④ 새 계좌 추가는 시트 하단 링크 1줄로 기존 폼을 연다. ⑤ 시트에서 저장하면 해당 카테고리 `markCategoryRefreshed`를 호출한다(B와 연결).
  **v1에서 뺄 것**: 차액을 입출금 기록으로 자동 생성하는 기능(#91 K와 같은 원칙), 대출 금리·만기 편집, 현금 0원 처리(스키마 `balance>0`, 기존처럼 상세에서 삭제), 계좌 정렬·숨김, 스크린샷 경로 변경.
- **빼거나 합치기**: 새 메뉴를 늘리지 않는다. 기존 `직접 입력` 항목의 도착지를 바꾸고, 홈 팁·결산 행은 diff 0으로 같은 시트에 닿는다. 상세 탭의 개별 수정은 그대로 둔다(세부 필드 편집의 정본).
- **LEARNINGS·DECISIONS 대조**: 새 진입점이 아니다(LEARNINGS '이미 있는 동선이면 새 진입점 금지'와 충돌 0). 경과일 알림·신선도 표시(S-4.26 철회, 2026-08 교훈)는 늘리지 않는다. 결산 홈 팁 노출 개선(11-06 반려)도 건드리지 않는다. 원인에 부채 상환을 넣지 않는다(10월 교훈). 대출 잔액 변화는 기존 대출 항목 의미를 유지한다.
- **COO 위험(C24)**: 직접 고친 현금 차액은 결산에서 '기록 안 된 변화'로 잡힌다. 매달 반복하면 이 항목이 최대 항목이 될 수 있다. spec 완료 기준에 넣을 것: 실사용 형태 픽스처(현금만 매달 고치는 사용자)에서 결산 원인과 문구(`change-hero.tsx:283`)를 사용자 행동과 연결할 수 있는지 확인. 연결할 수 없으면 v2에서 '차액을 입출금으로 남기기(선택)'를 검토한다. C20·C21 픽스처는 필수다.
- **위험 등급: low**. 근거: 스키마·저장 키·동기화·서버 전송·보안 문구 변경 0이고, 기존 업데이트 경로를 재사용한다. 데이터 위험은 '잘못된 행 저장'뿐이며 바뀐 행만 저장해 줄인다. 롤백은 revert 1회.
- **결산 창 영향**: 결산 화면 코드는 diff 0이다. 다만 '다음 달 준비' 행과 홈 최신화 팁의 **도착지가 바뀌므로** 결산 영역 변경으로 보고 **머지는 12/11 이후**로 한다. 개발·qa는 창 기간에도 진행한다.
- **위임 머지 가능성**: ①~⑥·⑧은 충족할 수 있다(⑥은 12/11 이후 머지로 충족). ⑦은 ui-review에서 '기존 시트·행 패턴 재사용, 큰 UI 방향 변경 아님'을 확인해야 한다. 확인되지 않거나 코드1(sync)이 동승하면 대표 승인으로 전환한다.
- **일정**: planning ①~③ 11/8~11/12 → design-review ~11/18(ui.md: 시트·행·버튼, tech-review: 업데이트 경로·C11 목록) → 4.50 머지 직후 새 버전(예상 4.51) 브랜치, 개발 11/27~12/5 → ui-review·qa 12/6~12/9 → COO 12/10 → **위임 머지 12/11**(마감 12/18, #58 12/27 전). #83은 그 뒤 번호를 받아 ≤12/18에 머지한다. 4.50이 12/1을 넘겨 밀리면 A 개발도 같은 폭만큼 밀린다(마감은 유지).
- **판정: 통과(위 축소 범위로)**.
