## 선정 — `[5.103] 320 화면 정돈: 맞추기 항목 선택 칸·성적표 축 제목·배당 예정 칩`
type:bug(UI), priority:p2, **risk:low → COO 위임 머지 가**.
- 위임 ④~⑧: 저장·키·동기화·공유 토큰·서버 전송·GA 변경이 0이다. 보안·데이터 문구도 0이다. 결산·홈·첫 화면은 diff 0이다. 큰 UI 방향 변경이나 반려 방향 재도입이 아니다.
- 판독 오염: 바꾸는 화면은 맞추기·성적표·배당뿐이고 웰컴·홈·결산 diff는 0이다. 12/11 이후로 미룬 항목은 넣지 않았다.

**범위(v1)**
- A: 트리거에 보이는 값을 왼쪽 정렬한다(`text-left`, `min-w-0`). 두 줄 모두 `truncate`로 말줄임한다. 목록 안 SelectItem의 2줄 표시는 그대로 둔다(diff 0). 트리거 높이 40px은 유지한다. 1줄 요약 방식으로 바꿀지는 ui-designer가 정하되, 수량은 반드시 보여야 한다(후보를 구분하는 값).
- B: 320에서 축 제목이 최대 2줄이고 어절 중간 꺾임이 없어야 한다. 방법(측정불가일 때 빈 별 숨김, 또는 오른쪽 묶음을 아래 줄로)은 ui-designer가 고른다. 수정은 645~676행 안에서만 한다.
- C: `12월 예정` 칩과 날짜 사이 간격을 4px 이상 확보한다. 320 전용 분기는 360·375에 새지 않게 한다(C98·C99).

**뺀 것**: 새 소식(정돈 수정이라 해당 없음, 사유는 PR 본문에, C82), GA, 맞추기 match·merge·diff 로직, 성적표 점수·문구, 배당 계산.

**컷 순서**: C → B. A는 컷하지 않는다. 11/19까지 B가 PASS하지 못하면 A(+C)만 머지한다.
