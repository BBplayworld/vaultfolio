# KIS Open API 약관 — 기존 운영 기능 충돌 판정 (cto)

작성 2026-11-22 · 대표 지시 "약관 원문 확인 후 cto 판정" · 법률 자문 아님

## 1. 원문 확인 여부
- **원문 확인함.** KIS Developers 포털 공개 API `apiportal.koreainvestment.com/api/terms/public?termsType=MARKET|AGENCY`(포털 하단 '이용약관'·'제휴기관 이용약관' 팝업의 원본, 로그인 불필요).
  - 「오픈 API 서비스 이용 약관(고객)」 version 28, 최종 수정 2024-04-11, 시행 2022-10-01
  - 「오픈 API 서비스 이용 약관(제휴 이용기관)」 version 31, 최종 수정 2024-04-11
- 제휴 안내(`/provider-doc1`): 절차는 "01 제휴 제안 등록 → 02 접수 → 03 담당자 검토 → 04 결과 회신"뿐이고 비용·조건은 공개돼 있지 않다.
- 확인 못 한 것: FAQ 본문(포털 API가 500 응답), `securities.koreainvestment.com` 전자금융 기본약관(접속 차단), KRX 정보이용 계약과 요금(공개 문서를 찾지 못함). 제3자 블로그에 있던 "제휴사는 KRX·해외거래소와 정보이용계약이 필요하다"는 말은 **원문에서 확인되지 않았다**.

## 2. 조항 원문
**고객 약관(지금 우리가 맺은 계약)**
- 제3조: "고객이 회사의 오픈 API 서비스를 이용하여 처리하는 조회(**시세정보**, 계좌정보, 잔고, 거래내역 등)…에 대하여 적용된다."
- **제5조③**: "고객은 회사에서 제공하는 시세(국내주식, 해외주식, 국내선물/옵션 등)정보를 고객이 직접 개발한 프로그램 등 **개인의 업무에 한하여** 이용해야 하며, **제3자에게 제공해서는 아니 된다**." (블로그 인용과 글자까지 같음)
- 제5조②: 앱키·시크릿키를 "제3자에게 대여, 위임, 양도…해서는 아니 된다."
- 제5조④: "회사가 약관 이행 여부를 점검하고자 할 경우 적극 협조하여야 한다."
- 제9조①·제10조①(중지·해지 사유): 수수료 부족, 금융당국 권고, 불법 대여 계좌, "회사의 서버에 일정수준 이상의 부하를 유발하는 등…필요하다고 인정하는 경우". 제5조③ 위반은 사유로 따로 적혀 있지 않지만 제17조①(의무 불이행 시 손해배상), 제16조②6(회사 사정에 따른 서비스 중지)이 있다.
- '재배포'·'상업적 이용'이라는 단어는 없다. 그러나 '개인의 업무에 한하여' + '제3자 제공 금지'가 그 둘을 포함한다.

**제휴 이용기관 약관**
- 제7조②: 사업자등록증 사본, 법인인감증명서(개인사업자는 대표자 인감증명서) 제출.
- 제12조: "이용기관 수수료는 회사가 정하며, 이용기관과 협의할 수 있다." (금액 비공개)
- **제5조⑦**: "이용기관은 회사에서 제공하는 시세…정보를 **회사의 거래고객 대상 오픈 API 서비스에 한하여** 이용 허용되며 이외의 목적으로 사용하여서는 아니 되며 부당 사용에 대하여 발생하는 **과태료 등**에 대해서는 이용기관이 부담하여야 한다."
- 제2조3: "사용자"는 "이용기관의 연계 금융 서비스를 통해… 회사의 계좌를 보유한 자".

## 3. 해당 여부 판정
- **해당한다(명확).** 우리 서버가 대표 계정의 앱키로 KIS를 호출하고, 그 결과를 Redis·CDN에 캐시해 **불특정 사용자 전원**에게 응답한다. 사용자는 계약 당사자(고객)가 아닌 '제3자'이고, 공개 서비스는 '개인의 업무'가 아니다. 사용자 기기 요청 시점에 호출해도, 무료여도 결론은 같다.
- **제휴로도 해결되지 않는다.** 제휴 약관 제5조⑦은 시세를 "회사의 거래고객 대상" 서비스로 한정한다. 시크릿에셋 사용자 대부분은 KIS 계좌가 없을 것이고, 서비스도 KIS 계좌와 연결되지 않는다. '과태료 등' 문구는 거래소 정보 규정에 따른 제재가 있음을 시사한다(근거 조항 미확인).
- 이 계약의 위반자는 **대표 개인 계정**이다(앱키 소유자). 따라서 대표 개인의 KIS 이용 관계에도 위험이 생긴다.

## 5. 위험 등급 (위반 명확성 × 집행 가능성 × 영향)

|---|---|---|---|---|
| 보유 종목 현재가·수익·차트·분류 | 높음 | 낮음 | **치명**(앱 핵심 정지) | **high** |
| 환율 | 중('시세…등'에 포함되는지 다툼 여지) | 낮음 | 큼 | **medium** — 한국은행·수출입은행 공식 환율로 바꿀 수 있음 |
| 지수 3기능(시장과 비교·홈 변화 줄·알림) | 높음(+지수 회사 권리 이중) | 낮음 | 작음(보조) | **high**(위반 대비 이득이 가장 작음) |

- 사용자가 늘수록, 수익화·광고·외부 게시를 할수록 집행 가능성이 커진다(제9조④ '부하', 제5조④ '점검').

## 6. 선택지
- **(a) 그대로 유지·위험 수용**: 비용 0. 그러나 위반이 명확하고, 대표의 #263 기준("상업적 이용에 문제 없는 데이터만")과 어긋난다. 갑자기 끊기면 대체 출처가 없다.
- **(b) KIS 제휴**: 사업자 등록·법인인감이 필요하고, 수수료는 협의다. **제5조⑦ 때문에 KIS 계좌가 없는 사용자에게 시세를 보여 주는 문제는 풀리지 않는다** → 사실상 해결책이 아니다.
- **(c) 재배포 허용 벤더로 교체**: 표시·재배포 라이선스가 있는 시세 공급사(국내 정보 벤더, 해외 시세 API의 display 라이선스). 유일한 근본 해결이지만 월 비용(거래소 정보이용료 포함, 미조사)과 큰 개발(시세 경로 전부)이 든다. 환율만은 공공 출처로 바꾸면 비용 0이다.
- **(d) 표시 축소**: 지수 3기능을 끈다. 위반 범위는 줄지만 핵심(보유 종목 시세)의 위반은 그대로다.
- (참고) 사용자 본인 KIS 키 입력: 약관상 깨끗하지만 KIS 계좌 보유자만 쓸 수 있다. 목표(월 활성 100명)와 반대라 권고하지 않는다.

## 7. cto 권고
1. **핵심 시세는 당장 끄지 않는다. 다만 '기한부 위험 수용(a)'은 대표가 명시적으로 결정해야 한다.** 끄면 앱이 서지 않는다.
2. **(c) 견적 조사를 착수한다**(business-pm): 국내·미국 주식 지연 시세의 재배포 허용 벤더 2~3곳의 조건·월 비용·지연 허용 여부(15~20분 지연 시세는 거래소 요금이 낮거나 없는 경우가 많다는 일반 관행 — 확인 필요). 결과가 나오면 대표가 비용을 결정한다.
3. **환율을 KIS에서 한국은행 또는 수출입은행 공식 환율로 바꾼다**(작은 과제, DECISIONS 11-22 '환율 사용 가능' 범위 안). 위험 1건이 비용 0으로 없어진다.
4. **지수 3기능: 신규 노출 확대를 금지한다**(#263 투자 탭 KIS 사용 금지 — 이미 권고). 끌지(d) 여부는 (c) 결과와 함께 대표가 결정한다. 위반 대비 이득이 가장 작아서, 벤더 비용이 크면 가장 먼저 끌 대상이다.
5. **트리거**: KIS의 점검 요청·경고·키 제한, 또는 수익화·외부 게시 결정 → 그 즉시 (d)를 실행하고 (c)를 앞당긴다.

## 8. 대표 결정 필요 사항
- ① 기존 기능을 (a) 기한부 수용할지(기한 예: (c) 견적 회신까지), 아니면 지수 3기능을 지금 끌지(d)
- ② (c) 벤더 비용을 쓸 의향(상한)
- ③ 앱키가 대표 개인 계정이라는 점, 즉 위반 책임이 대표 개인에게 있다는 점을 인지했는지 확인
- 환율 교체(권고 3)와 견적 조사(권고 2)는 팀이 결정 없이 바로 진행할 수 있다.
