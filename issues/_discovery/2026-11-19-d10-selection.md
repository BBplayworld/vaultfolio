## 4. 선정 과제 — 둘러본 사람이 그 자리에서 내 자산으로 넘어간다
- **누구의 어떤 문제**: 자산을 넣지 않고 `직접 둘러보기`에 들어간 방문자. 예시 화면을 보다 마음이 움직여도 홈으로 돌아가야만 시작할 수 있고, 돌아오면 방금 본 것과 무관한 처음 화면이다. 상세·성과에는 예시라는 표시도 없다.
- **왜 지금**: 2단(웰컴 첫 화면)의 A/B를 고르려면 둘러보기의 복귀율이 길 문제를 뺀 값이어야 한다. 지금 머지해야 12월 초 판독에 4주가 쌓인다.
- **최소 범위(이 아래로 줄이면 선정 취소)**
  1. 체험 중 모든 화면에 `예시 자산` 표시 + `내 자산으로 시작` 1개(홈 배너와 같은 문구·모양, 화면당 1개, 자리는 ui-designer).
  2. 복귀하면 보던 자산군의 등록으로 이어진다(주식 → 주식 등록 방법 선택부터, 홈·성과에서 왔으면 현행). 새 버튼 0, 등록 칸 시작 상태만.
  3. 복귀 title `웰컴·체험·<자산군>` 1종(실제 페이지에서 전송).
- **병행(코드 0)**: 2단 준비 — 웰컴 첫 화면 A/B/C 390·320 목업과 대리 검토(C135·C137). 머지 판단은 발동 기준 충족 시에만. ⓒ 판독 메모 정정.
- **하지 않는 것**: 체험 중 GA 전송(ⓑ), 웰컴 첫 화면(체험 복귀가 아닌 도착) 변경, 체험 진입 추가, `trial-boot.ts`·`TrialGate`·`ga.ts` 체험 가드·`layout.tsx` 인라인 스크립트 변경, 저장 키·스키마·동기화·서버 전송 변경.
- **필수 수용 기준**
  - 체험이 아닌 방문의 웰컴·홈 렌더 diff 0(스냅샷), 체험 페이지 gtag 호출 0건 유지(기존 `trial-guards.test` 그대로 통과).
  - 이어진 등록 칸의 방법 버튼은 기존 `웰컴·<버튼>` title을 그대로 보낸다(4.86 분자 유지).
  - 복귀 전달값은 화면 키 허용 목록만, 1회 읽고 지운다. 모르는 값이면 현행 동작.
  - 자산 보유 기기의 `/?trial=1` 거부 동작 불변. 인앱 체험 복귀(U3 미집계 한계)는 표로 상태 명시.
  - 390·320 목업 + 대리 검토, 전 체험 화면(홈·상세 5탭·성과·종목 한 장) 캡처, 하단 탭·FAB 자리와 겹침 0.
- **성공 지표**(머지 후 4주, 절대 기기 수, 기준선은 11/25 title CSV): 복귀 `웰컴·체험` 2기기 이상, 그중 홈 밖에서 나온 `웰컴·체험·<자산군>` 1기기 이상, 복귀 기기의 `첫 자산 저장·*` 1기기 이상. 가드레일: `웰컴·스크린샷 등록`·`웰컴·직접 입력`·`체험 모드` 진입 불감소.
- **판독이 정하는 것**: 진입 4기기 이상인데 복귀 0 → 둘러보기는 설득하지 못한다 → 2단 A 탈락. 복귀 2 이상·첫 저장 1 이상 → 2단 A 후보 유지. 진입 3기기 이하 → 판정 불가, 2단은 발동 기준으로만 정한다.
- **위험 등급**: **medium**(첫 화면의 복귀 상태 변경, #59 인접). 롤백 = revert 1커밋, 데이터 영향 0. '하지 않는 것'의 체험 주입부를 바꿔야 하면 risk:high로 재분류.
- **대표 승인**: **불필요**(CEO 승인, 사후 알림). 2단은 별도 판정 — A안은 대표가 11-16에 직접 정리한 체험 진입 배치를 바꾸므로 채택 시 대표 승인 대상으로 올린다(정리본 1건).

**제목**: `[4.xx] 둘러본 사람이 그 자리에서 내 자산으로 넘어간다 — 체험 모든 화면의 '내 자산으로 시작'·복귀 뒤 이어지는 등록`
**라벨**: `type:improvement` `status:planning` `risk:medium`(예상)

### 문제
`직접 둘러보기`로 예시 화면을 보는 방문자는 홈으로 돌아가야만 `내 자산으로 시작`을 만난다. 상세·성과 화면에는 예시라는 표시가 없다. 시작을 눌러 돌아오면 방금 보던 것과 무관한 처음 화면이다.

### 대상
자산을 넣지 않은 첫 방문자 중 둘러보기에 들어간 사람. 자산 보유자와 둘러보지 않은 방문자의 화면은 바뀌지 않는다.

### 범위
1. 체험 중 모든 화면: `예시 자산` 표시 + `내 자산으로 시작` 1개(홈 배너와 같은 문구·모양)
2. 복귀: 보던 자산군의 등록으로 이어짐(등록 칸 시작 상태만 변경, 새 버튼 0)
3. GA: 복귀 title `웰컴·체험·<자산군>` 1종(실제 페이지에서 전송)
4. 병행(코드 0): 웰컴 첫 화면 A/B/C 목업·대리 검토 준비, '홈' 기기 수 판독 정의 정정

### 하지 않는 것
체험 중 GA 전송, 웰컴 첫 화면(일반 도착) 변경, 체험 진입 추가, `trial-boot.ts`·`TrialGate`·`ga.ts` 체험 가드·`layout.tsx` 인라인 스크립트 변경, 저장 키·스키마·동기화·서버 전송 변경

### 완료 기준
- 체험이 아닌 방문의 웰컴·홈 렌더 diff 0, 체험 페이지 gtag 호출 0건 유지
- 이어진 등록 칸의 방법 버튼이 기존 `웰컴·<버튼>` title을 그대로 보냄
- 복귀 전달값은 화면 키 허용 목록만, 1회 읽고 삭제. 모르는 값이면 현행 동작
- 자산 보유 기기의 체험 거부 동작 불변
- 390·320 목업 대리 검토, 체험 전 화면 캡처, 하단 탭과 겹침 0
