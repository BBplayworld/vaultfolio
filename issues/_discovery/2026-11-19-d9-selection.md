## 1. 후보 1 반대 검토
1. **꼭 해야 하나** — 한다. 5.125·5.127은 '정한다'까지만 만들었고 정한 결과는 성과 › 셋째 카드 안에만 있다(성적표 3명·2초). 사용자가 실제 머무는 곳은 상세·주식(6기기·78초)이다. 안 하면 방금 낸 주력 기능이 '정하고 잊는 기능'이 된다.
2. **후보 문서의 약점** — 홈 팁은 지금 거의 아무에게도 뜨지 않는다. `dueOf`는 ±% 조건(점검 대상 + 조건을 넣은 종목만)과 기간(가장 빨라야 2027-02)만 차례로 본다. 홈 팁 1종이 중심이면 11-16 '버튼 1개 수준' 지적의 재발이다. 후보 문서가 '줄일 수 있는 것'으로 적은 **상세·주식 행 표시가 오히려 본체**다.
3. **더 작게** — 미정 종목 권유, 남은 거리 정렬·색, 푸시, 새 저장 키는 뺀다(후보 문서 그대로). 홈 미니 배지는 만들지 않는다(팁과 같은 도착 2개, 11-16).
4. **반려 대조** — 경과일 리마인더(2026-08) 아님: 사용자가 정한 조건·기간만 쓴다. 사실 여러 줄 나열(11-18) 금지: 종목 한 장은 결론 1문장. 더보기·투자 조언·서버 전송 해당 없음.
5. **익명 기기 확인** — 누름 출처별 GA title을 따로 둔다(아래 3절).

## 2. 선정 과제 — 내 종목 화면이 내 결정을 안다
- **누구의 어떤 문제**: 종목을 1개 이상 정한 주식 보유자. 종목을 보는 화면(상세·주식, 종목 한 장)에 내가 정한 결정과 조건이 없어서, 조건에 닿았는지 보려면 성과 탭 안쪽까지 가야 한다.
- **왜 지금**: 5.125(11/18)·5.127(11/19) 직후라 정한 사람이 가장 많이 생기는 2~4주다. 이때 돌아올 자리가 없으면 M+56 `·다시 봄`은 읽기 전에 죽는다. 계산은 이미 순수 함수(`labelFactsOf`·`dueReasonText`)라 새 계산·새 저장이 없다.
- **최소 범위(이 아래로 줄이면 선정 취소)**
  1. 상세·주식 목록 행: **정한 종목에만** 내 결정(`장기 보유`·`점검 대상`) 표시, 차례면 `점검 차례`.
  2. 종목 한 장 머리: 내 결정 + 정한 조건 + 정한 날 대비를 **결론 1문장**으로(읽기 전용). 차례면 점검 한 장으로 간다.
  3. 홈 팁 1종: 차례가 있을 때만. 자산 수 + 이유 1줄, 누르면 종목 점검의 해당 묶음.
- **동승(줄이기)**: 홈 기능 팁 중 기본 탭 소개 5종 정리, p2(성적표 제목 중복·`1종목 모두 점검 차례`·1280 ⓘ 끊김).
- **하지 않는 것**: 미정 종목에 '정하기' 진입·권유(후보 3), 불리기 화면 블록 변경, 푸시, 저장 키·스키마·동기화·서버 전송 변경.
- **성공 지표**(머지 후 4주, 절대 기기 수): `내 자산 불리기·점검` 2기기 이상, 그중 상세·주식 출처 1기기 이상. 가드레일: `월 결산`·결산 팁 누름·`상세·주식` 기기 수 불감소.
- **필수 수용 기준(planning에 넘김)**
  - 홈 팁의 수 = 허브 카드 `점검 차례 N` = 목록 차례 수(같은 함수, #243 필터 포함).
  - 미정·정하지 않음 기기에서는 세 곳 모두 렌더 diff 0(스냅샷으로 증명).
  - 손실 종목·조건 없는 종목·코인(주식 외) 3상태 목업(C138), 390 시각 목업 + 대리 검토(C135·C137), 전수 표기 점검(C139).
  - 홈 팁 순위: 백업·세금 임박·결산 아래, 알림 받기·기능 소개 위.
- **위험 등급**: low(저장·서버 0, 표시만). 홈 팁 순위 변경과 상세·주식 행 밀도가 있어 UI 승인 필수. CEO 승인 트랙.
- **규모**: M. '#239·#242 수준'의 근거는 줄 수가 아니라 절차(목업·대리 검토·3상태)와 주 무대 화면 변경이다.

### 문제
5.125·5.127에서 사용자는 종목마다 `장기 보유`·`점검 대상`과 다시 볼 조건을 정한다. 그런데 그 결정은 성과 › 자산 성적표·불리기 안에서만 보인다. 사용자가 실제로 종목을 보는 상세·주식과 종목 한 장에는 흔적이 없고, 조건에 닿아도 홈은 말하지 않는다.

### 대상
종목을 1개 이상 정한 주식 보유자. 정하지 않은 사용자의 화면은 바뀌지 않는다.

### 범위
1. 상세·주식 목록 행: 정한 종목에만 내 결정 표시, 차례면 `점검 차례`
2. 종목 한 장 머리: 내 결정·정한 조건·정한 날 대비를 한 문장으로(읽기 전용), 차례면 점검 한 장으로 이동
3. 홈 팁 1종: 차례가 있을 때만 자산 수 + 이유 1줄, 누르면 종목 점검의 해당 묶음
4. 동승: 홈 기능 팁의 기본 탭 소개 5종 정리, p2 3건(성적표 제목 중복·`1종목 모두 점검 차례`·1280 ⓘ 끊김)

### 하지 않는 것
미정 종목에 '정하기' 권유·진입, 조건까지 남은 거리 정렬·색 강조, 푸시 알림, 경과일만으로 재촉하는 문구, 불리기 화면 블록 변경, 저장 키·스키마·동기화·서버 전송 변경
