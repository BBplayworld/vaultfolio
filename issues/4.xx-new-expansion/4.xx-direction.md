### 3-4. 정본 규칙 — 지표 2개, 섞지 않는다 (C1 대조표)
| 지표 | 뜻 | 정본 | 나머지 |

### 3-6. 범위
- 포함(R1): ①②, 올해 지난 일정 한 번에 확인, 직접 추가(보유 종목·날짜·금액), 확인 되돌리기.
- **줄일 수 있는 것**: 종목별 보기(월별 목록만으로 시작), 연 선택, 팔아 버린 종목 직접 추가, 엔화 종목(일정 계산이 엔화를 환산하지 않는다 — 직접 추가만).
- **하지 않을 것**: 배당 목표·달성률·재투자 계산·종목 추천·평가어, 세금 자동 계산과 세율 숫자(#79), 예금 이자 기록, 거래내역 화면에 배당 행 중복 표시, 새 달력 화면(11-06 중복 제외), 파일·붙여넣기·이미지로 과거 배당 가져오기, 내보내기(C54), 현금 잔액 자동 가감(R1), 푸시 알림.

### 3-7. 데이터 모델·위험 — **risk:high, 복원 테스트 필수**
- 새 기록 `DividendRecord { id, ticker, name, category, scheduleYM?, receivedDate, amount, currency, amountKrw, source: "schedule"|"manual", createdAt }`.
- 저장은 **분리 키**(#58 `secretasset.physical_assets` 방식: 읽기 완화 스키마·`undefined`면 손대지 않음)를 권고한다. 현금 입금 기록 + id 규칙(#103)은 **현금 계좌가 없는 기기에서 쓸 수 없어** 탈락. 등록은 대부분 주식 스크린샷이라 그 형태가 가장 흔하다(C49).
- 기존 데이터 변환은 없다(추가만). 필수 검증: 구버전 백업 → 새 버전 복원, 새 버전 → 구버전 기기 동기화 왕복에서 기록 보존, 맞추기·일괄 저장 경로가 기록을 떨어뜨리지 않음. 공유 토큰에는 넣지 않는다.
- 일정 ↔ 기록 짝 = (종목, 계좌 유형, 일정 연-월). 추정일(15일)이 공시일로 바뀌어도 같은 건으로 본다. 외화는 외화 금액 + 확인 시점 원화 환산을 함께 저장한다.
- 자산 간 흐름(C42·C49): R1은 **잔액·순자산을 바꾸지 않는다**(기록만).
| 사용 형태 × 통화 | R1 | R2 결산 |
|---|---|---|
| 현금 잔액을 맞추기·스크린샷으로 갱신(원화·외화) | 기록만 | `기록 안 된 변화`가 +일 때 구간 받은 배당만큼 `배당`으로 떼어 냄(대출 줄 `splitLoanCause`와 같은 구조, 합 불변) |
| 입출금을 직접 기록 | 기록만(입금 기록은 사용자가 따로) | 순유입에 남음 → '현금에 함께 넣기'(#103 id 규칙)는 R2 선택 과제 |
| 현금 계좌 없음 | 기록만 | 줄 없음(앱 순자산이 안 바뀜) |
- 알려진 한계(cto 판정 요청): 해외 일정은 현지 기준일(`fetchDividendOverseas`)이라 입금이 뒤따른다 → 목록은 달 단위로 느슨하게. 일정 API는 올해분만 준다 → 연초에 전년 12월 미확인 일정이 사라진다(직접 추가로 보완). 스크린샷 등록 종목은 매수일 = 등록일이라 등록 전 지급분은 일정에 없다.

### 3-8. 절대 규칙
서버로 가는 값은 지금처럼 종목코드뿐(`/api/finance/dividend`), 새 API 0. 기록은 기기와 E2EE 동기화 암호문에만 있다. GA에는 금액·종목·건수를 싣지 않는다(page_title만). 권유·평가 문구 0, 인증카드에 금액 0.

### 3-9. 릴리스 분할·지표
- **R1**(high, 대표 승인): ①② + 저장 + 배당 화면 줄이기 + 진입 3곳. **R2**(결산 금액 규칙이라 high): 결산 연동 + ③(시안이 서지 않으면 제외) + 홈 반복 신호(추가 조회 비용 판정 뒤).
- 성공(R1 머지 후 8주, 대표 기기 제외): `배당 받음 확인` 활성 3명 이상·조회수/사용자 2 이상, 새 title `성과·배당·받은 기록` 활성 3명 이상, `성과·배당` 감소 없음. 0~1명이면 확인 블록과 업데이트 행을 걷되 **남긴 기록과 페이지는 지우지 않는다**.

### 3-10. 사업 질문 9개 답
1. 자리: 업데이트 시트 3번째 행 + 허브 배지 + 신규 기능 팁. 결산 홈 팁 영역은 손대지 않는다.
2. 정본: 3-4. 혼합 숫자를 만들지 않고 '지급' 어휘를 없앤다.
3. 기본값: 일정 금액으로 1탭 확인, 고치면 `입력`으로 표시. 세율·세금 계산 0.
4. 현금 함께 반영: R1 제외. 맞추기와 겹치면 이중 가산이고, 현금 없는 기기가 흔하다. 결산 줄은 현금 연결 없이 성립한다(3-7).
5. 일괄 확인: 허용. 범위는 앱이 이미 보여 주던 올해 일정뿐이라 가져오기가 아니다.
6. 분할: 3-9. 결산 줄은 R2.
7. 인증카드: 기록 기반 '받은 달·종목 수'는 스트릭 반려와 닿아 뺀다. 일정 기반 '배당 달력 카드'로 바꿔 R2 조건부. 빼도 단위 2개가 남는다.
8. 줄일 것: 3-5.
9. 이견 없음. A가 가장 크고 안전하다. 순서 A → C → B 동의.
