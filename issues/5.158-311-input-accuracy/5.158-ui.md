# 5.158 ui — 기록 입력 정확도 (#311)

근거: 5.158-spec(main v5.155 코드 대조), design-system §1~§7·§11, components.md(InlineSelector `fullWidth`·`tight`). 신규 토큰·컴포넌트 0, 전부 재사용.

## 1. 과거 날짜 질문 (현금 입출금 · 주식 거래)

**위치**: 반영 체크박스 상자(`rounded-lg bg-muted/40 p-3`) 바로 위, 같은 폼 gap(`space-y-3`)의 독립 블록. 날짜·메모 칸 다음, 체크박스 상자 앞.

**구조(위→아래)**
1. 질문 `<p id=...>` : `text-sm font-medium break-keep text-pretty`
2. 답 2칸: `InlineSelector fullWidth tight`(재사용). 칸 높이 `min-h-10`(히트영역 40px). 2칸 균등.
3. (아래 기존) 체크박스 상자. 도움말은 기존 문장 그대로, 새 설명 문장 0.

**컨트롤 규약**: 답은 상호배타 2택이라 Checkbox가 아니라 InlineSelector(세그먼트). 체크박스는 같은 상태의 직접 입구로 남긴다. `role=radiogroup`+`aria-labelledby`=질문 id, 칸은 `aria-checked`. value는 `answered ? (reflected ? "add" : "in") : null`(components.md: null=선택 없음 허용, v5.1x 반영). 기본 선택 표시 없음(둘 다 비활성 상태)이 "아직 답 안 함"의 표시다. 체크박스는 현행 값(체크)으로 보인다. 칸을 누르면 선택 칸 `fg/15` 면+`ring`(다크 `ring-inset fg/50`, 기존 토큰), 뒤 체크박스가 즉시 따라 바뀐다.

**문구(확정)**
| | 질문 | 칸1 | 칸2 |
|---|---|---|---|
| 현금 | 이 돈이 지금 잔액에 이미 들어 있나요? | 이미 들어 있어요 | 아니요, 더해 주세요 |
| 주식 | 이 거래가 지금 보유 수량에 이미 들어 있나요? | 이미 들어 있어요 | 아니요, 더해 주세요 |
- 칸1 = 체크 해제(= 기록만), 칸2 = 체크 유지. '기록만'은 새로 쓰지 않고, 답 뒤 기존 도움말(`기록만 남고 잔액은 그대로예요`/`기록만 남아요`)이 #295 용어로 설명한다.
- 질문은 날짜 칸 바로 아래가 아니라 체크박스 위: 사용자가 날짜→메모를 입력한 뒤 반영 결정과 한 덩어리로 읽힌다.

**표시 조건**: `date < todayKst()`이고 날짜 비어 있지 않음, 주식은 `!isNewSelected`. 날짜를 오늘로 되돌리면 질문 숨김(체크 값 유지).

**겹침 정리(경고와 질문)**: 질문이 보이고 `answered=false`면 `ResyncTxWarning`·연결 계좌 경고 숨김. 답한 뒤 현행 조건으로 표시. 한 화면에 질문+경고가 동시에 뜨지 않는다. 예상 잔액/포지션 줄은 현행(체크 상태 따름).

**모션**: 질문 블록 진입 `motion-safe:animate-in fade-in-0 slide-in-from-top-1 duration-150`(tw-animate-css), 숨김은 즉시(subtle exit 불필요, 레이아웃 점프 최소화를 위해 블록을 언마운트). 칸 전환은 InlineSelector 기존 전환. 연타해도 상태는 마지막 탭만 반영. 폼 reset 때 `answered=false`.

**줄 수**: 질문 390에서 주식 문구 2줄(`break-keep`), 320에서 2~3줄까지 허용(칸 높이 고정, 질문만 늘어남). 답 칸 라벨은 1줄(`이미 들어 있어요` 9자, `아니요, 더해 주세요` 11자: 320의 칸 폭 약 140px에서 `text-sm`으로 1줄 확인, 넘치면 `tight`가 줄바꿈 대신 `text-xs`로 내려가지 않고 `break-keep` 2줄을 허용).

**testId**: `past-date-question`(블록), `past-date-answer-in`, `past-date-answer-add`.

## 2. 해외 체결 환율 칸

- 칸 위치·라벨 그대로(`체결 환율 (원/$)` 또는 `(원/100¥)`). 종목 선택 즉시 현재 환율이 값으로 채워져 보인다(`0` 표시 0). 값은 일반 입력 색(placeholder 아님) — 저장될 값이기 때문.
- 안내 1줄(칸 바로 아래, `text-sm text-muted-foreground break-keep text-pretty mt-0.5`, 단가의 `USD (소수점 3자리 가능)` 줄과 같은 스타일): `지금 환율이에요. 체결 때 환율로 고칠 수 있어요`. 사용자가 값을 고치는 순간 사라짐(자동 채움 값일 때만). 사라질 때 높이 변화는 `grid-rows` 전환 없이 즉시(입력 중 점프를 줄이려 줄을 항상 `min-h`로 예약하지 않는다: 키 입력 중 한 번만 접힘, 허용).
- 환율 미수신: 칸 비움, placeholder `환율을 불러오지 못했어요`, 안내 줄 없음.
- 통화 전환(USD↔JPY) 시 자동 채움 값이면 새 값으로 교체, 사용자가 고친 값이면 유지.
- 줄 수: 안내 390 1~2줄, 320 2줄. 다크: muted-foreground 기존 대비 통과(변경 0).
- testId: `exrate-input`(칸), `exrate-auto-help`(안내).

## 3. `현재가 넣기`

- 위치: 체결 단가 칸 바로 아래. USD면 기존 `USD (소수점 3자리 가능)` 줄이 있으므로 **그 줄 위가 아니라 아래**가 아니라, 도움말 줄과 같은 줄에 두지 않고 별도 줄로: 단가 칸 → `현재가 넣기` 줄 → (USD) 도움말 줄. 이유: 입력 직후 눈이 닿는 거리 확보.
- 패턴: `보유: N주 [전량]`과 같은 `text-sm text-muted-foreground` 줄, 단 라벨 없이 버튼 하나. 버튼은 `text-primary underline`을 쓰되 **히트영역 40px 규약**을 위해 `inline-flex min-h-10 items-center px-1 -mx-1 -my-2`(시각 높이는 줄 그대로, 눌림 영역만 40px). 눌림 `active:scale-[0.96]` + `motion-safe:transition-transform`, `transition: all` 금지.
- 문구: `현재가 넣기` (금액·시각 표기 0). aria-label: `현재가를 단가에 넣기`.
- 숨김: 신규/미선택/검색 신규 종목, `currentPrice ≤ 0`, USD `원화로 입력` 켜짐.
- 누른 뒤: 단가 칸 값이 바뀌고 포커스는 단가 칸으로 이동하지 않는다(모바일 키보드 불필요 팝업 방지). 값은 통화별 자릿수 반올림. 미리보기가 즉시 갱신. 토스트 0.
- 매도 시 위 줄 `보유: N주 [전량]`과 간격 `gap-0`(각 줄 min-h-10이 겹치지 않도록 `전량` 줄과 단가 칸 사이는 폼 gap 유지).
- testId: `fill-current-price`.

## 4. 긴 메모 (현금·대출·코인 목록)

- 구조: 날짜 줄(`<span class="whitespace-nowrap tabular-nums">날짜</span>`, `text-sm max-[359px]:text-xs text-muted-foreground`)과 메모를 분리. 메모는 날짜 아래 별도 `<p>`.
- 메모 규칙: `text-sm max-[359px]:text-xs text-muted-foreground break-keep [overflow-wrap:anywhere] line-clamp-2`. 부모 `min-w-0` 유지.
- 1탭 전문: 메모 `<p>`를 `<button type="button">`로 감싸 눌림 시 `line-clamp-none`으로 **그 자리 펼침**(모달·토스트 0, 다시 누르면 접힘). 잘리지 않은 메모는 버튼이 아니라 `<p>`(누를 수 없음). 잘림 판정은 렌더 후 `scrollHeight > clientHeight`(ResizeObserver로 폭 변경 대응).
- 히트영역: 버튼은 행 폭 전체(`w-full text-left`), 높이는 메모 2줄(약 40px)이라 40px 충족. 1줄만 잘린 경우는 없음(2줄 초과일 때만 버튼).
- 펼침 신호: 잘린 상태에서 끝 말줄임(`…`)이 신호이고, `aria-expanded`·`aria-label="메모 전체 보기"/"메모 접기"`. 별도 아이콘 0(밀도 유지).
- 모션: `motion-safe` 높이 전환은 line-clamp에 불가하므로 전환 없이 즉시(재마운트 아님, 같은 DOM 상태 토글). 삭제 버튼·금액 위치 불변.
- 줄 수: 2줄 고정(펼침 시 N줄). 320에서 `max-[359px]` 줄바꿈 레이아웃(행 아래 `pl-11`)에서도 폭 `basis-full` 내 말줄임 동작. 무공백 100자는 `anywhere`로 2줄 안에서 끊겨 넘침 0.
- testId: `tx-memo`(잘림 가능 메모 버튼 또는 p), 펼침 상태 `aria-expanded`.

## 5. 말투·결산 오류 문구

| 위치 | 확정 |
|---|---|
| 현금 | 입금을 기록했어요 / 출금을 기록했어요 |
| 대출 | 상환을 기록했어요 / 추가 대출을 기록했어요 |
| 주식·코인 | 매수 거래를 기록했어요 / 매도 거래를 기록했어요 |
| 연결 계좌 | 매수 거래를 기록했어요. 현금 기록도 남겼어요 |
| 중복 | 이미 반영된 거래예요 |
| 유지 | 기존 기록을 그대로 뒀어요 / 기존 거래를 그대로 뒀어요 |
| 현금 오류 | 저장하지 못했어요… (그대로) |
| 결산 오류 | 결산을 계산하지 못했어요. 다시 열어도 같으면 '의견·요청 보내기'로 알려 주세요 |
- 결산 오류: 현행 오류 카드 스타일 유지(`text-sm text-muted-foreground break-keep text-pretty`, 중앙). 390 3줄, 320 4줄 허용. 메뉴명 따옴표는 tool-menu와 동일 표기. 투자 조언 0, 금액 0. testId `settlement-error`.
