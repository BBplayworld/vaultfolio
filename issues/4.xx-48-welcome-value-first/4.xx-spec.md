# 4.xx 첫 화면 "가치 먼저" 재배열 + 링크 미리보기 정비 — spec (#48)

근거: 4.xx-challenge.md(통과·축소), 4.xx-direction.md(합의됨). 시각 수치·토큰은 ui.md 몫. 코드 기준: origin/main `src/app/(main)/_components/layout/onboarding/welcome-guide.tsx`, `src/app/layout.tsx`, `src/lib/analytics/ga.ts`.

## 1. 문제
- 375x812 첫 화면이 제목 + 보안 카드 3장(PBKDF2·Ed25519·blob/pubKey)으로 가득 차고 예시 미리보기(순자산·주식)는 스크롤 2~3번 뒤다.
- 모바일 웹(미설치)은 자산 등록 CTA를 숨기고(`ctaVisible`) 미리보기 아래 보조 텍스트 링크("설치 없이 웹에서 바로 시작")로만 노출한다.
- 링크 미리보기는 OG 이미지 없음, twitter `card: "summary"`.

## 2. 목표 행동
첫 화면 첫 스크롤에서 예시 순자산을 보고 시작 버튼(모바일 웹은 설치 또는 "웹에서 바로 시작")을 누른다. 주 지표: 28일 `first_asset_saved`÷`welcome_view`(기기) 상대 +30%. 가드레일: `pwa_install` 비율 30% 이상 하락 금지.

## 3. 범위
포함
- `welcome-guide.tsx` 블록 순서 재배열, 보안 카드 3장 접힘 압축, 모바일 웹 CTA 위치 변경.
- `layout.tsx` metadata의 openGraph.images + twitter(summary_large_image) + 정적 OG 이미지 1장(public).

줄일 수 있는 것: 히어로 서브 문구(로그인 없이... 2줄)는 신뢰 한 줄과 중복이라 삭제. 설치 박스 3단계는 CTA 아래 1줄 요약(ui.md가 결정, 못 줄이면 유지). 모바일 맨 아래 링크 제거.

제외(하지 않음): 체험 모드·데모 주입, 새 URL·쿼리·진입점, #33, 마법사·입력 폼·저장 키·스키마·동기화 변경, 새 GA 이벤트·파라미터 값(`PARAM_VALUES` 무변경), `welcome-preview-data.json` 변경, 미리보기 컴포넌트(`NetAssetSummaryBox`·stock-tab 부품) 수정, sitemap·서버 렌더, 앱가이드 보안 카드 원문 변경.

## 4. 화면별 요구 (순서 = 위에서 아래)
공통 순서(모든 환경): ① 히어로(배지 "시작하기" 유지 여부는 ui.md, 제목, 쉬운 말 한 줄) ② 신뢰 한 줄 + "자세히 보기" 토글(보안 상세는 이 토글 바로 아래에서 제자리 펼침, 기본 접힘) ③ 예시 순자산 미리보기(`NetAssetSummaryBox`) ④ 시작 CTA ⑤ 이하 예시 미리보기 나머지(주식 요약·카테고리) + 안내 문구 ⑥ 설치 안내 박스(데스크톱·태블릿 미설치만; 모바일 웹은 CTA 슬롯이 설치를 대신하므로 박스 미렌더, 설치 안내는 슬롯 캡션 1줄).
- 시작 CTA 자리는 한 곳(컴포넌트 내 단일 슬롯). #33이 이 슬롯을 대체할 수 있어야 한다. 플로팅 CTA 금지(PRINCIPLES 5장).
- 접힘 상태 기본 닫힘, 탭 1회로 열림. 열림 상태 저장 안 함(저장 키 없음). 펼침 내용은 기존 3카드 제목·본문 원문 그대로.

환경별
- 모바일 웹 375x812 (미설치): ①②③ 후 CTA 슬롯에 "앱으로 설치"(brand, `PwaInstallFlow` 그대로) + "웹에서 바로 시작"(보조) 나란히/연속. 첫 화면(스크롤 0)에 제목·신뢰 한 줄·예시 순자산 숫자가 보이고, CTA 슬롯은 순자산 숫자 바로 아래라 첫 화면에 들어오지 않으면 순자산 카드까지만 보이게 하고 CTA를 그 아래 고정 순서로 둔다(direction 합의). "웹에서 바로 시작" 탭 시 기존 `skip_install` 후 기존 자산 등록 CTA(스크린샷 등록·직접 입력·가져오기 팝오버)를 같은 슬롯에서 노출.
- PWA 설치 상태: 설치 박스 없음. CTA 슬롯에 바로 자산 등록 CTA(기존 `isStandalone` 문구 "자산을 등록해보세요" 유지).
- 모바일 웹 인앱 브라우저: `PwaInstallFlow` 기존 동작 유지(인앱 이동 안내 포함). 순서 동일.
- 데스크톱 1280: 순서 동일. 설치 박스는 기존 조건(`canInstallPWA`) 중 모바일 웹 제외, ⑥ 위치. 데스크톱은 설치가 주 버튼이 아니므로 CTA 슬롯에 자산 등록 CTA가 바로 노출(기존 `ctaVisible` 로직 유지).
- 로딩(`mounted` 전): 기존처럼 환경 분기 전에는 CTA 슬롯을 깜빡임 없이 처리(ui.md). 서버/클라 불일치로 hydration 경고 없음.

## 5. 문구 초안 (존댓말, 투자 조언·금액 없음, 담백하게)
- 제목: "나만의 비밀 자산 금고" (유지)
- 쉬운 말 한 줄: "흩어진 자산을 한 화면에서 정리해 보세요."
- 신뢰 한 줄: "로그인 없음 · 자산은 내 기기에만 · 기기 간 암호화 동기화"
- 토글: "자세히 보기" / 열림 "접기"
- 보안 한 줄 요약(펼침 맨 위, 선택): "서버에는 암호문만 있어 운영자도 내 자산을 볼 수 없습니다."
- 모바일 웹 CTA: 주 "웹앱 설치하기"(기존), 보조 "웹에서 바로 시작"
- 미리보기 라벨: 기존 "포트폴리오 미리보기"+"예시 데이터" 유지
- 금지: "안전 보장/100%" 같은 과장, 수익·매수·매도 권유, 금액 수치(예시 미리보기 제외).
- 사실 검증: 동기화는 선택 기능이므로 신뢰 한 줄은 "기기 간 암호화 동기화 지원"으로 오해 없이 표기(필수 아님을 해치지 않을 것).

## 7. GA 불변 조건 (`ga.ts`·`PARAM_VALUES` 무변경)
- `welcome_view`: 마운트 시 1회, `source` = pwa(standalone) / inapp / web, 판정식 그대로. 접힘 토글·재배열로 재발생·중복 없음.
- `onboarding_action`: wizard(스크린샷 CTA)·manual(주식 직접 입력)·import·sync_connect는 기존 클릭에서만 1회. 위치만 이동.
- `skip_install`: "웹에서 바로 시작" 탭 1회당 1회(기존 `method: "skip_install"`). 버튼이 보조 버튼으로 바뀌어도 모바일 웹 미설치에서만 존재, 다른 환경에서 발생 불가.
- `first_asset_saved`: 로직 미수정(`trackAssetSave`). 웰컴 변경은 저장 경로를 호출하지 않는다.
- 토글(자세히 보기)은 이벤트 없음(새 이벤트·값 금지). `pwa_install` 흐름(`PwaInstallFlow`)은 수정하지 않는다.

## 8. OG·twitter 요구

## 9. 데이터 영향 (없음 근거)
localStorage·STORAGE_KEYS·스키마·동기화·공유 토큰 미접촉(`welcome-guide.tsx` 표시 순서·로컬 UI 상태 `useState`만, `layout.tsx`는 metadata 정적 값). `applyImportedPayload`·`saveAssetData`·`notifyAssetUserEdit` 호출 추가 없음, 렌더/effect에서 호출 없음(C16). 접힘 상태는 메모리 state(저장 안 함). 데이터 안전 위험: 없음. 위험 초안 low.

## 10. 엣지 케이스
- 첫 사용자(자산 0건)만 웰컴 노출(기존 조건 불변). 빈 데이터·오래된 데이터 개념 없음(예시 데이터 정적).
- 설치 프롬프트 미지원(iOS 사파리 등): 기존 `PwaInstallFlow` 안내 흐름 그대로, "웹에서 바로 시작"으로 우회 가능.
- 가로 모드·작은 화면(320): CTA 버튼 줄바꿈 가능, 가로 스크롤 없음.
- reduced-motion: 기존 `motion-safe` 진입 모션 유지, 펼침 전환은 즉시(ui.md).
- `?`/해시 변경 없음: 링크 미리보기 변경이 URL 구조에 영향 없음.
