## 3. "자세히 보기" 펼침 — 재마운트 없는 구조 (신규 패턴, design-system §6 흡수 대상)
- 상세는 조건부 렌더(`{open && …}`) 금지. 항상 마운트하고 높이만 전환한다.
- 바깥: `grid motion-safe:transition-[grid-template-rows,opacity,visibility] motion-safe:duration-300 ease-out`
  - 닫힘 `grid-rows-[0fr] opacity-0 invisible` + `inert` / 열림 `grid-rows-[1fr] opacity-100 visible`
  - 안쪽 `min-h-0 overflow-hidden` (0fr에서 높이 0)
- `visibility`를 전환 목록에 넣어 닫힐 때 300ms 동안 보이다가 끝에 숨는다. 열 때는 즉시 visible
- 인터럽트: 전환 중 다시 탭하면 CSS 전환이 현재 값에서 반대로 돌아간다(큐 없음). 연타해도 state 토글만
- reduced-motion: 전환 없음, 즉시 열림/닫힘. 쉐브론 회전도 즉시
- 열림 상태는 `useState`만(저장 안 함, 새로고침 시 닫힘). gtag 호출 없음
- 열린 뒤 스크롤 이동 없음(제자리 펼침이라 필요 없음). 포커스는 토글에 남는다
- design-system §6에 "높이 펼침 = grid-rows 0fr↔1fr + 항상 마운트" 1줄 등록(developer KB 배치 때)

## 6. 모션 요약
- 진입: 기존 `ENTER`(fade+slide-in-from-bottom-3, 500ms) 재사용, stagger 0·60·120·180ms(히어로·신뢰·순자산·슬롯). 첫 화면 밖 블록은 진입 모션 없음(현행 미리보기와 동일)
- 버튼 누름 0.96은 `Button` 내장. `transition-all` 금지
- 슬롯 콘텐츠 교체·펼침은 위 3·5장. `will-change` 쓰지 않음

## 7. 접근성
- 히트영역: 토글 `min-h-10`(40), 슬롯 버튼 `size="lg"` 40px·full width, Popover 항목 기존
- 토글 `aria-expanded`/`aria-controls`, 상세 `role=region` + 닫힘 `inert`(포커스·스크린리더 차단)
- 장식 구분자 `aria-hidden`, `ShieldCheck` `aria-hidden`
- 키보드: Tab 순서 = 토글 → (열림 시 카드 텍스트 없음, 포커스 대상 없음) → 설치 → 바로 시작. Enter/Space로 토글
- 대비: 신뢰 줄 `text-muted-foreground` 투명도 중첩 없음(§11, 라이트 AA). 구분자만 /50(장식 허용). secondary 버튼 라이트·다크 모두 배경 톤차로 경계 인지
- `data-screenshot-hide`: 해당 없음(웰컴은 인증카드 캡처 대상 아님)

## 11. 품질 체크리스트 (qa·ui-review 판정용)
1. 375×812 모바일 웹, 스크롤 0, 진입 모션 종료 후(또는 reduced-motion): h1·신뢰 한 줄·순자산 금액·`welcome-install-btn`·`welcome-skip-install-btn`의 bounding bottom ≤ 812.
2. 1280×800: 순자산 금액과 `welcome-cta-wizard` bottom ≤ 800.
3. 루트 직계 섹션 간 세로 간격이 20px(±2)이다(기존 32px 아님). 접힘 상태에서 토글 bottom ↔ "포트폴리오 미리보기" 라벨 top = 20px(±2, 상세가 여백을 남기지 않음). 펼친 FeatureCard 간격 12px.
4. 접힘 상태에서 `welcome-security-detail`의 높이 0, `visibility: hidden`, `inert` 존재, "PBKDF2"·"Ed25519"·"blob"이 보이지 않는다.
5. 토글 탭 후 **같은 노드**(탭 전후 element handle 동일)의 높이가 0 → 콘텐츠 높이로 바뀌고, 전환 중간(150ms) 샘플 높이가 0과 최종값 사이다. reduced-motion 에뮬레이션에서는 탭 직후 최종 높이(C3).
6. 전환 중 재탭 시 높이가 현재 값에서 0으로 되돌아가며 튀지 않는다(150ms·200ms 샘플 단조 감소).
7. 토글·슬롯 버튼의 히트 박스 높이 ≥ 40px. 토글 `aria-expanded`가 열림/닫힘과 일치.
8. `welcome-cta-slot`은 `data-state`가 install → asset으로 바뀌어도 같은 노드이고, 전환 후 `document.activeElement`가 `welcome-cta-wizard`다.
9. 모바일 웹에서 "웹앱 설치하기"가 화면 전체에 1개뿐이고 `welcome-install-box`가 없다. 데스크톱에서는 설치 박스에 1개, 슬롯에 0개.
10. 페이지에 `variant="outline"` 버튼이 없다(보조는 secondary, 테두리 없는 배경 톤). 주 버튼은 brand(#5b6fbf 배경).
11. 배지 "시작하기"·히어로 서브 2줄·설치 3단계 숫자 원·맨 아래 링크가 DOM에 없다. "로그인 없" 문자열은 접힘 상태 가시 텍스트에 1회(C1).
12. 첫 로드 시 콘솔 hydration 경고 0, 마운트 전후 `welcome-preview-stock` top 이동 ≤ 8px(pending 셸 자리 확보).
13. 375·320에서 `scrollWidth ≤ clientWidth`, 신뢰 한 줄은 구분자 위치에서만 줄바꿈(항목 단어 중간 끊김 없음).
14. 라이트·다크 각 1장(375·1280): 신뢰 줄·캡션이 배경 대비 4.5:1 이상, secondary 버튼 면이 배경과 구분된다(C2 — 홈 Hero와 같은 토큰·밀도, 컨트롤 줄 수는 기존보다 늘지 않음: 토글 1 추가·링크 1 삭제).
15. OG: `/og-image.png` 1200×630, ≤1MB, 이미지 텍스트 목록이 9장과 일치, 숫자·금액 없음.

## 12. spec 교차 검토
**수정 요청**: 4장 공통 순서 "⑦ 보안 상세(펼침 내용, 기본 접힘)"를 "② 신뢰 한 줄 + 토글 바로 아래 제자리 펼침"으로, 11장 완료 기준 3의 DOM 순서를 "히어로 < 신뢰 한 줄 < 보안 상세 < 순자산 < CTA 슬롯 < 주식 미리보기"로(설치 박스는 데스크톱만 CTA 이후). 사유는 1장 표 4행. 접힘 기본이라 완료 기준 1·4(첫 화면)는 영향 없음.
**수정 요청**: 4장 모바일 웹 "설치 안내 박스(해당 환경만)"에 "모바일 웹은 CTA 슬롯이 설치를 대신하므로 박스 미렌더"를 명시. 완료 기준 2의 "설치 박스보다 위"는 데스크톱에만 적용.
그 밖 항목(문구·GA 불변·OG 요건) 승인.

## 흐름 검토 (planner-designer)
승인. spec 수정 요청 2건(보안 상세 제자리 펼침 + DOM 순서, 모바일 웹 설치 박스 미렌더) 모두 동의, spec 4·6·11장에 반영함.
- 흐름: 위쪽 토글이 열면 바로 아래가 열리므로 변화가 보이고 CTA까지 흐름이 끊기지 않음. 모바일 웹에서 "웹앱 설치하기" 중복(C1)이 사라짐. 바로 시작 탭 후 포커스를 자산 등록 버튼으로 옮기는 처리, 기존 CTA 카드 재사용, GA 호출 조건 불변 모두 타당.
- 참고(비차단): 접힘 기본이라 완료 기준 1·4는 영향 없음. 슬롯 `pending` 자리 확보로 마운트 전후 밀림 방지는 ui 체크리스트 12번으로 판정.
