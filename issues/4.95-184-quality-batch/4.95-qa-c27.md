# 4.xx-184 후보 4 결함 확인 (C27)

판정: **확정** (C27 위반)

C27 원문: 예시 화면이 둘 이상이면 같은 "예시" 라벨 아래 순자산·구성이 같거나, 다른 이유가 화면에서 드러난다.

## 근거
- 웰컴 미리보기: `welcome-preview-data.json` 정적 고정값(부동산 4억·외화주식 3종·부채 0.95억)에서 계산한 순자산 551,159,778원(5.5억, 부동산 54%). 라벨 "예시 데이터".
- 체험: `src/lib/preview/demo-data.json`(부동산 6.3억, 금융 3,596만, 부채 2,050만, 부동산 91.8%)에서 645,463,200원(6.45억). 라벨 "예시 데이터로 둘러보는 중이에요". 서로 다른 별도 JSON이며 실시간 시세 차이가 아니라 데이터 구성 자체가 다르다(구성 비중도 상이).
- 운영 375 다크 캡처에서 두 화면 모두 순자산이 다른 이유를 설명하는 문구가 없다 (의도된 차이라는 코드 주석·화면 문구 없음).
- 참고: 운영에서 `?demo=1`은 preview 전용 게이트라 일반 홈이 뜬다. 운영의 체험 진입은 `?trial=1`(trial-gate, 같은 demo-data.json 주입)으로 확인했다.

## 영향
기존 사용자 데이터 영향 없음(예시 화면 표시만). 처음 온 사용자가 웰컴→체험 이동 시 "같은 예시인데 순자산이 달라짐" 혼란.

## 수정 방향
웰컴 미리보기를 demo-data 합계와 일치시키거나, 한쪽에 "예시마다 금액이 달라요" 같은 이유 문구를 표시.
