# 5.109 핫픽스 — 성적표 하단 빈 공간 (dev-notes)

## 원인
접힌 '자세히'(benchmark-more.tsx) 패널 안 가계 통계 표의 `caption`·`th`가 `sr-only`(position:absolute)다. clip 박스(`min-h-0 overflow-hidden`)가 containing block이 아니라서 절대위치 자손이 박스 밖 문서 스크롤 높이를 늘렸다(패널 높이는 0이 맞음). 성적표 맨 아래 블록이라 버튼 아래 빈 스크롤로 보였다. 5.107에도 같은 코드였으나 5.108이 가계 통계 블록 위치·콘텐츠 길이를 바꿔 노출됨(5.107 빌드 직접 실측은 하지 않음, 코드 diff 근거).

## 실측 (390x844 다크, 체험 모드)
- 운영(f5149e9): 문서 1933px vs main 1788px → 145px 초과. 접힌 grid 패널 높이는 전부 0px. clip 박스에 position:relative 주입 시 1788로 해소(원인 특정 실험).
- preview(371a37c): 문서 1788 = main 1788 (초과 0).
- 월 탭(자산 변화 > 월별 기록): 문서 894 = main 894, 영향 없음. 월별 패널 자손에 sr-only/absolute 없음 → 변경 없음.

## 변경
- `views/activity/benchmark-more.tsx`: clip 박스에 `relative` 추가(펼침 모션 유지).
- `views/activity/__tests__/benchmark-more.test.tsx` 신규: 접힘 `grid-rows-[0fr]`·inert, clip 박스 relative 단언.

## 확인 방법
preview `/?demo=1` → 직접 둘러보기 → 성과 → 자산 성적표 → 맨 아래 버튼 아래로 스크롤해 빈 공간이 없고, '자세히' 펼침/접기 정상인지 확인.

## 한계
다른 접힘 패널(report 축·change-hero·monthly)은 현재 sr-only/absolute 자손이 없어 미변경. 새 패널에 sr-only를 넣을 때는 clip 박스에 relative 필요.
