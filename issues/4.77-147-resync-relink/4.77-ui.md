# 4.77 #147 UI 사양 — 끊긴 거래 다시 잇기

ui-designer · 2026-11-11 · spec(4.77-spec.md) 승계. 기존 패턴만 사용: HomeTipBox 셸, 맞추기 확인(`PreviewStep`/`CheckRow`)·결과·토스트 되돌리기. **신규 패턴 0.**

## 1. 컴포넌트 트리
1. **홈 팁** `relink` — `HomeTipBox` 기존 셸(카드 전체 클릭=유일 동작, X 40px). 신규 아이콘은 기존 팁 종류가 쓰는 lucide 계열 중 `Link2`(1종, 기존 아이콘 크기·색 토큰). 제목 `break-keep wrap-break-word`. 우선순위: 새 공지 다음·백업 위(spec 5). 판정 로직 `home-tip.ts` 에 kind 추가(디자인 영향 없음).
2. **상세 거래내역 안내 줄** `relink-entry` — 주식 거래내역·코인 거래 화면 **목록 위**. 기존 안내 줄 패턴: `rounded-lg bg-muted/40 px-3 py-2.5` 전체 버튼(`w-full text-left`, min-h-10) + 좌측 `Info`(맞추기 notice 아이콘 규격 `size-4 text-sky-600/70 dark:text-sky-400/70`) + 문구 + 우측 `ChevronRight size-4`. 후보 0이면 미렌더. 거래 목록 첫 카드와 `gap-3`.
3. **확인 Dialog** `relink-dialog` — 맞추기 `HoldingsResyncDialog`와 같은 셸(Dialog·헤더·본문 `px-5` 스크롤·`DialogFooter flex-col gap-2 border-t border-border/40 px-5 pt-3 pb-5 sm:flex-row sm:justify-end`). 본문 위→아래:
   - 설명 `text-sm text-muted-foreground text-pretty break-keep`
   - 종목 행 리스트(`CheckRow` 규격 재사용: 체크박스 기본 `Checkbox` 자동 brand)
   - 고지 2줄(notice 규격 `Info` 아이콘 + 문구, 맞추기 `resync-notice-1` 동일 스타일)
   - 푸터: `다시 잇기` `Button variant="brand"` / `그대로 두기` `variant="secondary"`
4. **결과 화면** — 맞추기 `resync-result` 박스(`rounded-xl bg-muted/40 p-4`, `aria-live=polite`, `data-screenshot-hide`) 재사용. 푸터 `되돌리기`(secondary) / `닫기`(brand).
5. **토스트** — 맞추기 토스트 패턴 그대로(Sonner, 8000ms, `actionButtonStyle minHeight 40`, 고정 id `relink-undo-toast`).

## 2. 종목 행 (`relink-row-{S.id}`)
```
[체크] 종목명                         (text-sm font-medium, truncate 금지 → break-keep, 2줄 허용)
       증권사 · 거래 3건 다시 잇기 · 2024-03-04 ~ 2025-01-20   (text-sm text-muted-foreground tabular-nums)
       매수일 2025-11-11 → 2024-03-04                          (바뀔 때만, text-sm, 새 날짜만 text-foreground)
       전량 매도로 끝난 이전 거래 2건은 빼요                  (잘렸을 때만 `relink-row-cut-`, muted)
```
- 행 셸 `rounded-lg bg-muted/40 px-3 py-2.5`, 행 간 `space-y-2`. 행 전체가 체크 라벨(min-h-10), 체크박스 `mt-0.5`.
- **대상 2개 이상**(`relink-row-target-{groupId}`): 행 아래에 라벨 `이을 종목 고르기` + 기존 `Select`(h-10, w-full) 또는 2개 이하면 `InlineSelector`. 기본 미선택 → 체크 비활성(`disabled`)·행 하단 muted 안내 없음(라벨이 안내). 선택 시 체크 활성·자동 체크.
- 첫 번째 줄 `종목명 · 증권사` 로 한 줄에 못 들어가면 증권사를 다음 줄. 320에서 날짜 구간은 `~` 앞에서 줄바꿈 허용하되 날짜 자체는 쪼개지 않음(`whitespace-nowrap` 개별 날짜 span).
- 금액 없음·손익색 없음(건수·날짜만).

## 3. 상태
| 상태 | 표시 |
|---|---|
| 기본 | 대상 1개 짝 = 체크됨, 2개 이상 짝 = 미체크·선택 필수 |
| 체크 0개 | `다시 잇기` disabled |
| 적용 중 | `다시 잇기` Spinner·disabled, 그대로 두기 disabled, 닫기(X) 막지 않음 불필요(저장 1회 즉시) |
| 재감지로 일부 사라짐 | 결과 건수에 실제 적용분만 반영(문구 동일 형식) |
| 전부 사라짐 | 결과 `이을 거래가 더 없어요`(muted), 푸터 `닫기`만 |
| 되돌린 뒤 | 결과 박스 문구 `되돌렸어요`(직접 고친 항목 있으면 맞추기와 같은 `… N건은 그대로 뒀어요`), 되돌리기 버튼 숨김 |
| 오류 | `toast.error("다시 잇지 못했어요")`·`toast.error("되돌리지 못했어요")`, 다이얼로그 유지 |
| 빈 후보 | 진입 없음(팁·줄 미렌더). 데모·체험·공유·잠금 중 미렌더 |
- 긴 목록: 본문 영역 스크롤(`max-h` 기존 맞추기와 같음), 푸터 고정.

## 4. 문구 (spec §7 승인)
- 홈 팁: `맞추기 때 끊긴 거래 기록이 있어요. 확인하고 다시 이어 보세요`
- 안내 줄: `끊긴 거래 {n}건을 다시 이을 수 있어요`
- 제목 `끊긴 거래 다시 잇기` / 설명 spec 7 그대로
- 고지: `수량·평단은 바뀌지 않아요` · `전량 매도 뒤 다시 산 종목이면 체크를 풀어 주세요`
- 결과: `{m}개 종목의 거래 {n}건을 다시 이었어요` + `이 창을 닫기 전에는 되돌릴 수 있어요`
- 토스트: `끊긴 거래를 다시 이었어요` [되돌리기] / 되돌린 뒤 `되돌렸어요`(2000ms, 맞추기와 동일)
- 버튼: `다시 잇기` · `그대로 두기` · `되돌리기` · `닫기`
- 투자 조언 없음. 어절 갈림 0(`break-keep text-pretty`).

## 5. 인터랙션·모션
- 모두 기존 패턴: Dialog 기본 진입/exit, 체크 토글 즉시, 결과 박스는 단계 전환 시 기존 `step` 교체(재마운트 모션 기존 맞추기와 동일). 신규 모션 0, 별도 `motion-safe` 불필요.
- 안내 줄: press scale 0.96(`active:scale-[0.98]` 카드 규약이 있으면 그것, 없으면 생략 — 기존 안내 줄 버튼 규격 따름), `transition-colors`만.
- 안내 줄은 후보가 0이 되면(적용 직후) 목록 위에서 바로 사라짐; 높이 점프는 허용(저빈도, 이후 재사용 패턴 없음).
- 연타: `다시 잇기`·`되돌리기` 중복 클릭 무시(처리 중 disabled). 팁 X = 세션 숨김.
- `그대로 두기` 뒤 다이얼로그 닫힘, 토스트 없음(조용히). 안내 줄 유지.

## 6. 접근성
- 팁·안내 줄 `button`/`role=button`, min 40px. X 40px(`after:-inset-1`) 기존.
- 체크박스+라벨 연결(`htmlFor`), 행 전체 40px+. Select에 `aria-label="이을 종목 고르기"`.
- 결과 `aria-live=polite`. Dialog 포커스 트랩·Esc 기존.
- 다크: 토큰만(`bg-muted/40`·`text-muted-foreground`·sky 아이콘 `dark:` 짝) 사용, 하드코딩 색 0.

## 7. testId
spec §11 그대로 + 토스트 `relink-toast`(고정 id 확인용). GA `feature_use category:"relink" method:view|apply|undo|keep`.

## 8. 품질 체크리스트 (qa 판정용)
1. 후보 있는 운영형 픽스처에서 아무 조작 없는 홈 첫 화면에 `home-tip-relink` 노출(라이트·다크·375·1280), 카드 높이·셸이 다른 팁과 동일 규격.
2. 홈 팁 우선순위 = 새 공지 > relink > 백업. X 후 같은 세션 재노출 없음, 새 세션엔 `그대로 두기` 미사용이면 재노출.
3. 거래내역 안내 줄: 목록 위, 높이 ≥40px, 후보 0·데모·체험·공유 보기에서 DOM 없음. 클릭 시 확인 화면 열림.
4. 확인 화면 320·375: 종목명·날짜 구간이 가로 스크롤 없이 줄바꿈, 날짜가 중간에서 쪼개지지 않음, 문구 어절 갈림 0.
5. 대상 1개 짝 = 기본 체크, 2개 이상 짝 = 미체크·`이을 종목 고르기` 선택 전 체크 불가. 체크 0개면 `다시 잇기` disabled.
6. 매수일 변화 줄은 바뀔 때만, 회차 잘림 줄은 잘렸을 때만 표시. 금액 표기 0.
7. 버튼: `다시 잇기`·`닫기` = brand, `그대로 두기`·`되돌리기` = secondary(`variant` 확인), 체크박스 기본 brand, 모든 히트 ≥40px.
8. 적용 → 결과 문구 `{m}개 종목의 거래 {n}건…` 정확, 닫으면 토스트 되돌리기 8초·버튼 높이 ≥40px. 되돌리기(결과·토스트) 후 `되돌렸어요`.
9. `그대로 두기` → 새로고침 시 홈 팁 없음·안내 줄 있음. X(닫기)는 아무것도 기록하지 않음.
10. 신규 색·radius·shadow·패턴·`transition: all`·하드코딩 색 0(diff 확인). Info 아이콘·셸이 맞추기 notice/preview와 시각적으로 일치(라이트·다크 나란히 비교).
11. 팁·안내 줄·확인 화면 모두 라이트·다크 대비 AA, 결과 박스 `data-screenshot-hide`.

## 9. 교차 검토 의견
- spec 승인. 요청 1건: 홈 팁 아이콘을 신규 도입하는 대신 기존 팁 종류가 쓰는 아이콘 규격(크기·색) 그대로 `Link2` 1종만 사용(design-system 신규 색 불필요).
- 홈 팁 결산 창과의 우선순위는 디자인상 문제 없음(1회 해결형, 해당 사용자만).
