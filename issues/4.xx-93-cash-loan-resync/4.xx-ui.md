## 3. 본문 구성 (위→아래)
행 리스트 → 하단 링크 `새 계좌 추가`(`새 대출 추가`).
- 리스트 바깥 래퍼 없음(카드 중첩 금지 §5.1). 행끼리 `divide-y divide-border/40`, 행 `py-3`.
- **행 = 2줄 스택**(320에서도 금액 잘림 0, C35):
  - 1줄: 좌 이름 `text-sm font-medium truncate`(외화는 이름 뒤 `USD`·`JPY` muted `shrink-0`), 우 `현재 1,234,000원` `text-sm text-muted-foreground tabular-nums whitespace-nowrap`. 외화는 `현재 1,234.56 USD`(원통화 단위). 이름이 길면 truncate(이름은 title 속성), 현재값이 우선 보존.
  - 2줄: `Input h-10 w-full text-right tabular-nums text-sm` `inputMode="decimal"`(원화는 `numeric`), 자리표시 `새 잔액`, `aria-label` `{이름} 새 잔액`. 외화는 칸 안 좌측 접두 `USD`(`text-sm text-muted-foreground`, 포인터 무시). 쉼표는 표시만(입력 중 포맷, 저장값은 숫자). 음수·문자 입력 단계 차단.
  - 행 DOM 순서 = 상세 탭 순서. 키보드 Enter → 다음 행 칸, 마지막 Enter → 저장 포커스.
- **바뀐 행 표시**(색에만 의존 금지): 입력 칸 `ring-1 ring-brand` + 이름 앞 4px 점 대신 **이름 줄 끝 라벨 `변경`**(`text-sm font-semibold text-brand`, 이름 우측 `shrink-0`). 변경 아님(빈 칸·같은 값)이면 라벨·ring 없음. 라벨 등장/소멸은 `motion-safe:animate-in fade-in duration-150`, 행 높이 변동 0(라벨은 이름 줄 안).
- **오류(차단)**: 칸 아래 `text-sm text-destructive`+`AlertCircle size-4` 한 줄. 현금 0: `0원은 여기서 저장할 수 없어요` + 이어 muted `상세에서 관리할 수 있어요`(`삭제` 문자열 0, 링크 아님). 칸 `aria-invalid`, `aria-describedby`. 오류 1개라도 있으면 저장 비활성.
- **경고(허용)**: `자릿수를 확인해 주세요` `text-sm` 주황(`importantHex`) + `AlertCircle` 아이콘. 저장 비활성화 안 함. 같은 행에 오류와 경고가 겹치면 오류만.
- 오류·경고 등장 시 아래 행이 밀리는 높이 변화는 `grid-rows` 펼침 레시피(§6, 재마운트 없음, `motion-safe:duration-200`)로 처리, reduced-motion이면 즉시.
- **외화 행 추가 안내 없음**(환율·원화 환산 노출 0, C1). 합계·비중·순자산·경과일 0.
- **하단 링크** `새 계좌 추가`/`새 대출 추가`: 리스트 아래 `Button variant="ghost"` 풍 텍스트 링크(`min-h-10 px-0 text-sm font-medium text-brand`, 앞 `Plus size-4`). 누르면 이 창 닫고 기존 추가 대화상자(GA 0). 변경 ≥1이면 입력이 사라지므로 링크 아래 muted 없이 **닫힘 전 확인 없음**(spec 4-8): 변경 ≥1 상태에서는 링크를 disabled로 두고 `저장하거나 취소한 뒤 추가할 수 있어요`는 두지 않는다(문구 최소) → disabled만, `title` 없이 툴팁 0. (결정: 입력 유실 방지가 우선.)
- 목록 8행 이상이면 본문만 스크롤, 푸터·헤더 고정. 활성 칸 포커스 시 `scroll-margin-block 80px`로 푸터에 가리지 않게.
