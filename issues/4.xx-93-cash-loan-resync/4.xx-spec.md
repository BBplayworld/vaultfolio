## 1. 문제
현금·대출 갱신 입구 3곳(FAB `보유 현황 업데이트`, 홈 최신화 팁, 결산 '다음 달 준비')이 모두 `○○ 추가` 폼을 연다. 기존 잔액은 계좌마다 상세 › 탭 › 펼치기 › 수정(필드 6~10개)으로만 고칠 수 있다.

## 2. 목표 행동
현금·대출 보유자가 월말에 카테고리당 한 화면에서 바뀐 잔액만 입력하고 저장을 1번 누른다. 결산 '다음 달 준비'로 돌아오면 그 카테고리 행이 사라져 있다.

## 3. 범위
- **포함**: 현금(대출) 1건 이상 보유자의 FAB `select-method` 제목·보조 문구 변경, `직접 입력` 도착지를 **잔액 맞추기 화면**(카테고리 인자 1컴포넌트)으로 변경, 데모 시드 보강(7절), GA 2건(9절), p2 6건(11절).
- **그대로**: 0건 사용자의 추가 흐름·`first_asset_saved`·#48 퍼널, 상세 탭 개별 수정, 스크린샷 경로, 홈 팁·결산 코드, 거래 기록.
- **하지 않음**: '그대로 확인' 저장(S-4.26 철회), 차액 입출금 자동 생성, 금리·만기·이름 편집, 정렬·숨김·삭제, 합계·비중·순자산 표시, undo, 현금·대출 합친 화면, 새 메뉴·URL, 공지 ID 교체(C38), `/api/sync` 동승.

## 4. 사용자 흐름
1. 입구 3곳 중 하나 → FAB `select-method`. 보유자는 제목 `현금성 자산 업데이트`(`대출 업데이트`), `직접 입력` 보조 문구 `계좌별 잔액 고치기`(`대출별 잔액 고치기`). 0건이면 현행 그대로.
2. `직접 입력`(현행대로 `자산 추가 시작` 1건 전송) → 제목 `현금성 자산 잔액 맞추기`(`대출 잔액 맞추기`). 보유 여부는 화면을 열 때 1회 판정.
3. 머리말 `바뀐 잔액만 입력하세요. 입출금 기록은 생기지 않아요.`
4. 행(상세 탭 순서): 이름(외화는 `USD`·`JPY` 표기) / 보조 `현재 1,234,000원`(외화는 원통화 단위) / 빈 칸(자리표시 `새 잔액`).
5. 값 입력 → 행 검사(5절). 바뀐 행은 강조(ui.md). 하단 고정 `바뀐 N개 저장`(brand), N=0 또는 차단 오류 1개 이상이면 비활성.
6. 저장 → 6절 계약대로 `saveData` 1회 → 성공 시 `markCategoryRefreshed` 1회, GA(9절), 토스트 `잔액 N개를 고쳤어요`(N = 실제 반영 건수), 닫힘 → 원래 화면.
7. 하단 링크 `새 계좌 추가`(`새 대출 추가`) → 화면 닫고 기존 추가 대화상자. GA 재전송 0.
8. 이탈: 바뀐 행 ≥1이면 바깥 탭·끌어내림으로 닫히지 않음. `취소`·닫기 버튼으로만 닫히고 입력은 버림(저장 0·GA 0). 확인 대화상자 신규 0.
