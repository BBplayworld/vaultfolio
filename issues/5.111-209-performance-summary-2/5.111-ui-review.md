대상: preview issue-5.111 (cc1bff1) vs main(www.secretasset.xyz). 성과 > 자산 변화 > 주식 > 월 > 전체 시장.
방법: `?demo=1` 주입 뒤 localStorage 주식을 21종목으로 확장(국내 10·해외 7(1개 기준가 없음)·ISA 2·연금저축 1). 기준가 `/api/finance/profit`은 두 사이트 모두 같은 값으로 route mock(결정적 비교). 캡처 `screenshots/` (prev-*, main-*, *-expanded, mid-anim). 라이트는 `#theme=light` (이 앱은 prefers-color-scheme을 따르지 않음).
주의: 기본 `?demo=1`은 그룹당 3종목 이하라 `외 N개`가 보이지 않는다. 기능은 5종목 이상 보유 시에만 노출됨(검수는 확장 픽스처로 수행).

## 판정: **UI 승인** (수정 요청 0, 권고 2건은 비차단)

## ① 상위 3 + 외 N개 / 펼침·접힘 — 통과
- 국내 10종목: 행 3개(삼성전자 +761,280·삼성SDI +374,400·삼성바이오 -326,400, |손익| 큰 순) + `외 7개 +765,600원`. 해외 7종목: 3행 + `외 4개 +238,788원`. 3행 + 외 = 그룹 머리 손익 일치(국내 761,280+374,400-326,400+765,600=1,574,880 / 해외 -363,959+238,788=-125,171).
- 4개 이하 그룹(ISA 2·연금저축 1)은 `외` 줄 없음, 전부 표시.
- 펼침: aria-expanded true, 패널 높이 0→706px(7행), 토글 글자 `접기`(금액·두 번 세기 없음), 접힘 때 패널 `inert`+`aria-hidden`. 키보드 Enter·Space 모두 토글. 연타 5회 후 상태 일관(홀수 → 닫힘), 전환 끊김 없음. 90ms 중간 프레임 정상.
- 토글 줄 좌측 텍스트가 종목 행 텍스트와 같은 x(px-4)에 정렬, 금액은 손익색(빨강/파랑)·tabular-nums.

## ② 1종목 그룹 머리 — 통과
- 연금저축(1종목): 점+이름만, 값은 종목 행에만. ISA(2종목): 머리 금액·시작→끝 유지. 해외 1종목 외화·환차 표기 케이스는 이 픽스처에 없음(코드상 hasRef일 때만 생략, 머리와 행 값 동일 → C2 충족).
- 이름만 있는 머리는 얇은 띠(약 32px)로 보여 어색하지 않음. 360·390·399·430·1280 모두 동일.

## ③ 기간·시장 전환 — 통과
- 월에서 펼침 → 주 → 월 복귀: 전부 접힘. 시장 전체→국내→전체: 접힘(key 재생성). 기간 4개 forceMount라도 `useId` id 중복 없음(`_r_32_`/`_r_33_` 서로 다름).
- 전환 직후 시세 재조회 중에는 `외 N개`만 보이고 금액이 빠지는 순간이 있다(기준가 로딩 중 행이 `기준가 없음`으로 보이는 현행 동작과 같음). 로딩 후 금액 복구.

## ⑥ 사용자 관점 판정: **통과**
클릭 없이 그룹마다 손익이 큰 3종목과 나머지 합이 보여 4.44의 "변화가 바로 보일 것"에 부합한다. 20종목급에서 첫 화면 정보 밀도가 눈에 띄게 오른다.

## 권고 (비차단, 수정 요청 아님)
1. 펼친 뒤 `접기`가 7행(약 700px) 아래 맨 끝에 있어 위에서 닫으려면 스크롤해야 한다. 5.108 `MonthCauseRows`와 같은 패턴이라 이번 범위에선 유지. 불만이 나오면 후속에서 펼침 시 상단 토글 고정을 검토.
2. `외 N개` 금액은 순합계라 나머지 안의 이익·손실이 상쇄돼 보인다(예: 외 7개 +765,600원 안에 손실 종목 포함). 정보 삭제는 아니고 펼치면 개별 값이 나오므로 현행 유지.
