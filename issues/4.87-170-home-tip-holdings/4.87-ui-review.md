# #170 [4.87] UI 검수 (ui-designer)

대상: PR #171 62e193b, preview issue-487. 320·375·1280 x 다크·라이트. 캡처: `screenshots/ur-*`.

## 판정: UI 승인 (비차단 메모 2건)

## 결과
1. 429 라우팅(성과>자산 변화>주식): 히어로에 `지금은 불러오지 못했어요, 다음에 열면 다시 불러올게요` 표시, 스켈레톤 없음. 6조합 모두 어절 중간 끊김 0·가로 스크롤 0. 320은 `지금은 불러오지 못했어요, 다음에 열면 / 다시 불러올게요` 2줄 균형 분할. (ur-profit-fail-*)
2. 점검(X-KIS-Unavailable, 503) 라우팅: 기존 `점검 중 · 외부 증권 API 점검으로 정보를 불러올 수 없어요` 우선, 불변. 실패 박스와 같은 자리·같은 높이(320 라이트 비교 동일). (ur-profit-kis-*)
3. 높이 점프: 실패 상태에서 일·주·월·연 전환 시 문서 높이 780(320·375)·900(1280) 고정.
4. 320 배당 '분기' 배지: 티커 아래 둘째 줄 왼쪽 정렬로 내려가 종목명·배당월 열과 겹침 0(행 열 bounding 교차 0, 가로 스크롤 0). 375는 티커 옆 한 줄, 1280은 이름 옆 인라인. (ur-div-*)
5. 홈 팁(localStorage 구성): 현금만 + 세금 팁 닫음 -> `현금` 팁, 국내주식만 -> `주식` 팁(주식 구성에 현금 팁이 아닌 보유 일치 팁). 박스 마크업·간격·문구 형태 불변. 국내주식 보유 시 세금 팁(12/31 기준일)이 기능 팁을 이김 확인. 후보 0(전 항목 dismiss) 시 박스·빈 여백 없음, 날짜 줄과 푸터 간격 정상. (ur-home-*)

## 비차단 메모
- 카드형 실패 박스(`profit-fetch-failed`)는 앱 내 ProfitCard 사용처가 `period` 제어형 1곳뿐이라 도달 불가(히어로 경로만 렌더). 캡처 불가, 코드(`text-center text-balance break-keep px-4`)만 확인. 향후 단독 사용 시 재검수.
- 320 배당 KO 행: `12월 예정` 점선 칩이 배당월 열 폭을 넘어 좌측 `매수 2024-` 날짜 글자에 1px 가량 닿음(ur-div-320-*). 4.87 변경과 무관한 기존 현상(배당월 열 3.25rem 고정). 후속 후보로만 기록.
