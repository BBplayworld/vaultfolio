# #170 [4.87] UI 사양 (ui-designer)

근거: design-system §6·§7, C70, `profit-chart.tsx:386-412`, `monthly-dividend-stocks.tsx:244-251`. 신규 토큰·컴포넌트 0.

## 1. 수익 칸 '전부 실패' 문구 (`fetchFailed && !kisUnavailable`)
- **문구 (카드·히어로 동일, 1문장)**: `지금은 불러오지 못했어요, 다음에 열면 다시 불러올게요`
  - 원인 단정 없음, 투자 조언·금액 없음, 존댓말(해요체는 기존 `점검 중 · …어요`와 같은 톤).
  - 히어로 `message`는 점검 문구의 접두 `점검 중 ·`를 붙이지 않는다(점검이 아니므로). 문구 그대로.
- **자리·스타일**: 기존 박스 재사용, 문구만 교체.
  - 히어로: `ChangeHero message` 그대로 (`contentKey={period}` 유지, 기간 전환 시 기존 전환 모션 유지).
  - 카드: 기존 점선 박스 `h-48` 그대로. `<p>`에 `text-center text-balance break-keep px-4` 추가해 320에서 어절 중간에 끊기지 않고 2줄 균형 분할(`지금은 불러오지 못했어요,` / `다음에 열면 다시 불러올게요`). 점검 문구 `<p>`는 변경 없음(C70).
  - 히어로 message에도 `break-keep text-balance` 적용 가능한 래퍼가 없으면 `<span className="break-keep text-balance">`로 감싼다.
- **다시 시도 버튼: 불필요.** 기존 kisUnavailable 박스에 버튼이 없고(`:386-412` 확인), 불완전 결과는 캐시 안 하므로 재진입·기간 전환 시 자동 재조회. 문구가 그 사실을 알려준다. 버튼은 신규 패턴이라 도입하지 않는다.
- 우선순위: `kisUnavailable`이 `fetchFailed`보다 항상 먼저(점검 문구 유지). 스켈레톤은 `fetchFailed` 시 사라져야 한다.
- 다크: 기존 `text-muted-foreground`·`border-dashed` 그대로라 대비 변화 0.

## 2. 320 배당 '분기' 배지 (`:244`)
- 모바일 줄 클래스 `flex items-center gap-1 sm:hidden mt-0.5` → `flex flex-wrap items-center gap-x-1 gap-y-0.5 sm:hidden mt-0.5`.
- 폭이 충분하면(375) 티커·배지 한 줄, 기존과 동일. 320에서 합이 열 폭을 넘으면 배지가 **티커 아래 둘째 줄, 왼쪽 정렬**로 내려간다. 줄 간격 2px(`gap-y-0.5`), 배지 높이 `h-4` 유지, 티커 라인 높이 16px이라 줄 높이 차 없이 정렬된다.
- 배지는 `shrink-0` 유지(글자 안 깨짐). 열은 `min-w-0`이므로 우측 '배당월' 열과 겹치지 않는다. 늘어난 행 높이(+약 18px)는 `items-center`로 우측 열이 세로 중앙 정렬되어 문제 없음.
- sm 이상 표시(`hidden sm:inline-flex` 줄)는 변경 0.

## 3. 홈 팁 시각 변화
