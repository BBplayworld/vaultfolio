# 5.101 resync 항목 선택 UI 문구 확정 (ui-designer)

대상: holdings-resync-dialog.tsx 1049~1070행 ambiguous 선택 블록. 기존 문구·구조 유지, 추가는 캡션 1줄뿐.

## ① 보조 캡션 (신규 reason, 예: `otherTypeOnly`)
- 문구: **고른 유형에는 없고 다른 계좌에 있어요**
- 위치: 기존 "같은 종목이 여러 곳에 있어요. 어느 항목을 맞출까요?" 바로 아래, 기존 "계좌가 달라 하나로 정할 수 없었어요" 자리와 동일 스타일(`text-sm text-muted-foreground text-pretty break-keep`).
- 두 캡션 동시 해당 시 `multiAccount` 캡션을 숨기고 이 캡션만 표시(중복 방지, 의미가 더 구체적). 해당 reason이 없으면 표시 안 함.
- 판정: 후보가 모두 고른 유형(category) 밖일 때만. 일부만 다르면 캡션 없이 후보 라벨로 구분.

## ② 후보 1줄 표시 형식
- 현행 유지: `증권사 · 유형 라벨(categoryShort) · 메모` (1줄) / 아래줄 `수량 N주 · 매수일 …` (muted, tabular-nums).
- 같은 증권사의 다른 유형이 나란히 뜨므로 유형 라벨이 구분 핵심 → 유형을 증권사 바로 뒤 고정(메모보다 앞). 예: `미래에셋 · 연금저축 · 노후`, `미래에셋 · IRP`.
- 320px(C25): 1줄 span에 `break-keep text-pretty` 추가, 말줄임(truncate) 금지 → 길면 2줄로 줄바꿈하고 유형 라벨이 잘리지 않게 한다. 메모만 길 때도 줄바꿈 허용. SelectItem `min-h-10` 유지.
- 고른 유형과 다른 유형 후보에는 별도 배지·색 추가 없음(신규 패턴 금지).

## ③ '새로 추가' 선택지
- 현재 이 선택 목록에 '새로 추가' 항목이 없고 이번 변경 범위 밖 → **라벨 추가 안 함**. (신규 생성은 기존 행 제외/포함 흐름이 담당.) 

## 변경 없음
'항목 선택'(placeholder), '이 항목도 맞추기', 기존 두 문구 그대로.

## COO 수정 문구 (U1·U2 확정)
- U1: 후보가 다른 유형 1개뿐(otherType)일 때 사유(첫 줄) = **고른 유형에는 이 종목이 없어요. 다른 계좌 항목을 맞출까요?** / 이 경우 캡션 '고른 유형에는 없고 다른 계좌에 있어요'는 사유에 흡수되므로 숨김(중복 방지). 후보 2개 이상이면 기존 사유 '같은 종목이 여러 곳에 있어요. 어느 항목을 맞출까요?' + 기존 캡션 유지. 스타일 기존과 동일(`break-keep text-pretty`), 320·375에서 2줄 허용·말줄임 금지.
- U2: otherType 행 '항목 선택' 목록 마지막 선택지 라벨 = **새 항목으로 추가** (선택 시 고른 유형으로 새 항목 추가, 기존 다른 유형 항목은 그대로 두고 갱신·삭제하지 않음). 기존 후보와 구분되도록 목록 맨 끝, 별도 배지·색 없음, SelectItem `min-h-10` 유지. 이전 '③ 라벨 추가 안 함'은 본 절로 번복. 변경 없음: '항목 선택', '이 항목도 맞추기', '체크하지 않으면 그대로 둬요', '계좌가 달라 하나로 정할 수 없었어요'.
