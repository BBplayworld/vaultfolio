# 4.88 (#172) 자산 변화·주식 '시장과 비교' 입구를 도구 타일로 — UI 사양

근거: 4.83 상세›주식 `ToolTile`(stock-tools.tsx), design-system §2 면 토큰·§6 폴리시·§11. 신규 색·토큰 0. 목업 `screenshots/mock-after-{375,320,1280}-dark.png`, 현행 `before-{375,320,1280}-dark.png`(운영 ?trial=1, 성과›자산 변화›주식·월 탭, 스크립트 주입, 코드 수정 아님).

## 1. 현재 문제 (before-375-dark)
- 기간 선택 아래 헤어라인 + 지수 글줄 + `시장과 비교 >` 링크가 Hero 카드 안에 얹혀 있다. 숫자(코스피 -15.8%)가 탭 대상처럼 보이지 않고, 라벨이 값 아래에 따로 있어 위계가 거꾸로다(§11 '숫자 있는 행').
- 4.83 이후 상세›주식·성과 허브는 같은 입구가 타일인데 여기만 글줄 → 같은 입구 모양 2종(4.83 기준 위반).

## 2. 결정
1. **공용 추출 필요**: `ToolTile`을 stock-tools.tsx 내부 함수에서 `src/app/(main)/_components/layout/ui/tool-tile.tsx`로 이동·export(코드 변경 없이 위치만, stock-tools는 import로 교체). 두 번째 소비처가 생겼으므로 components.md 등록 대상. 시장 값 조각(`1주 코스피 −x%` 로딩·빈·값 3분기)도 중복되므로 `MarketTileValue({market, label})`을 market-entry-line.tsx에 같이 둔다(stock-tools·여기 공유; stock-tool-market-value testid는 prop).
2. **배치 = 단일 타일, 전폭**(2열 짝 없음). 주식 범위에 다른 도구 후보는 X-Ray(분야 비중)·세금(시즌)뿐이고 둘 다 '변화' 화면의 기간 맥락과 무관한 구성·세무 도구다. 짝을 만들면 기간 연동 값과 고정 값이 한 줄에 섞여 오독된다. 상세›주식이 이미 그 둘의 자리.
3. **위치**: Hero 카드(`ChangeHeroFrame`) 안 footer가 아니라 **Hero 카드 바로 아래 형제**(gap-3 리듬). 이유: 다크에서 타일 면(`bg-card`)이 Hero 카드 면과 같아 카드 안에서는 타일 경계가 사라진다. 구현: `footer` 슬롯 제거(ChangeHeroFrame의 footer prop은 호출 0이 되므로 삭제 가능, 단 PR 범위 밖이면 유지해도 무방) 후 asset-change-view에서 `ChangeHeroFrame` 다음 첫 자식으로 렌더.
4. 폭: 모바일 `w-full`, `sm` 이상 `sm:max-w-md`(기간 선택기와 같은 폭, 기존 글줄 규칙 유지). 1280에서 타일이 길게 늘어나지 않는다.

## 3. 컴포넌트 트리(주식 범위)
`h2·범위 선택` → `ChangeHeroFrame(기간 선택까지)` → **`MarketTile`(신규 얇은 래퍼: ToolTile + 값)** → `ProfitCard`.
- ToolTile 그대로: `min-h-16 rounded-lg bg-muted/50 px-3 py-3`, 다크 `rounded-xl bg-card shadow-sm`, 아이콘 `ChartNoAxesColumn` size-4 text-primary(<360px에서 숨김), 이름 `text-sm font-semibold`, 우측 `ChevronRight`, hover/press scale 0.98, focus ring.
- 이름 `시장과 비교`. 값 줄 `text-sm text-muted-foreground`, 지수 수치만 `font-medium text-foreground tabular-nums`.

## 4. 미리보기 값 (C65·C84)
- 같은 훅 `useMarketEntryValue(COMPARE_PERIOD[period])`·`MarketIndexValues` 재사용(4.83 시장 타일·허브 행과 같은 함수·같은 반올림). 접두만 선택 기간으로: `COMPARE_PERIOD_LABEL`(하루/1주/1개월) + 지수 → `1개월 코스피 −15.8%`. (4.83 상세 타일은 weekly 고정 `1주`, 여기는 기간 탭에 연동 — 기존 글줄 동작 유지.)
- `MarketIndexValues restBelowSm`: 320·375(sm 미만)는 첫 시장 1개, 640+ 는 `코스피 −x% · S&P 500 −y%`. 현행 글줄은 375에서 2개를 보였으나 320에서 줄바꿈 위험이라 4.83 타일과 규칙 통일. 도착 화면은 시장 전체를 보여 주므로 누락 오해 없음.
- 연 탭(`linkOnly`, #150): 값 없음 → 값 줄 `올해 지수와 나란히 보기`(기존 링크 `올해 시장과 비교`의 대체, 값 없음 규칙 유지).
- 지수 값 0건(빈): `지수와 나란히 보기`.
- 금액·차이(%p)·투자 판단 문구 없음(P1 유지).

## 5. 상태
- 비교 종목 0(`!hasTickerStock`): 타일 미렌더. 판별 후 0시장(`open=false`): 4.72와 같이 grid-rows 접힘 유지 대신 **즉시 미렌더**(타일 높이 64 접힘 모션은 과함). 판별 전(`markets===null`)은 렌더.
- 로딩(4.84 공통 로딩): `!ready`면 값 자리에 `SKELETON_FILL` h-4 w-20 스켈레톤(4.83 타일과 동일). 타일 자체는 첫 렌더부터 자리 잡아 레이아웃 시프트 0. 탭 가능은 ready 전에도 허용(도착 화면이 자체 로딩을 가짐) — 기존 `disabled` 폐지.
- 실패(지수 조회 오류): `values=[]` 경로 = `지수와 나란히 보기`. 재시도 UI 없음(도착 화면 책임).
- 기간 전환 중: 값 줄만 교체(`key=period`, `motion-safe:animate-in fade-in duration-200`), 타일은 재마운트 안 됨.
- 긴 문구: 이름·값 `whitespace-nowrap`+`break-keep`, 320에서 `1개월 코스피 −15.8%`가 한 줄(목업 320 확인).

## 6. '새' 표시
**새 chip 없음.** `stock-market`(상세›주식)·`hub-market`은 같은 entryId(20261111-02)·visitKey를 공유하며 화면당 1개 규칙(new-spots.ts). 자산 변화 화면은 이미 도착 경로의 한 단계이고, 새 spot을 추가하면 4.83 규칙·판독과 중복·충돌. `new-spots.ts` 변경 0. (이 입구를 눌러도 `activity:change-market` 방문 기록은 navigate가 그대로 남겨 상세·허브 chip이 꺼지는 현행 동작 유지.)

## 7. 레이아웃 수치
- 375: 타일 폭 327(좌우 24 패딩), 높이 ≈ 64~68. Hero 카드와 간격 gap-3(12). 목업 375 참조.
- 320: 폭 272, 값 `1개월 코스피 −15.8%` 1줄, 아이콘 숨김 구간 아님(≥360 미만이므로 아이콘 숨김 → 이름부터 시작). 가로 스크롤 0.
- 1280: 콘텐츠 영역 안 `sm:max-w-md`(448) 좌측 정렬. 두 지수 표시.
- 접근성: 타일 전체 button(히트 ≥ 64×폭), 포커스 링, `aria-label` 불필요(이름+값이 텍스트), 값 줄은 button 안이라 낭독됨. 다크 대비는 4.83 타일과 동일 토큰.
- 모션: press scale 0.98·bg 전환 150ms `motion-safe`, 값 교체 fade 200ms. `transition: all` 없음.
