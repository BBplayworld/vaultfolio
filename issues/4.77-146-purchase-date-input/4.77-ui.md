# 4.77 #146 UI 사양 — 새 종목 매수일 일괄 입력

ui-designer · 2026-11-11 · spec(4.77-spec.md) 문구·testId 승계. **신규 패턴 0** — 맞추기 `새 해외 종목 매입 환율` 줄(`holdings-resync-dialog.tsx` 910행대)과 같은 셸을 재사용한다. design-system 흡수 항목 없음.

## 1. 컴포넌트 트리 (위→아래, 재사용)
`새 종목 매수일` 줄 = 로컬 조각 `NewDateRow`(맞추기·첫 등록 공유 1개, 두 파일이 쓰면 `forms/asset-update/screenshot/`에 두고 components.md 등록)
- 셸: `rounded-lg bg-muted/40 px-3 py-2.5` (FX 줄과 동일, 테두리 없음 §3 shadow/톤 우선)
- 제목 줄: `text-sm font-medium break-keep` 제목 + (주식만) `InfoHint inModal` (제목 바로 뒤 `ml-1`, 인라인)
- 보조 줄: `text-sm text-muted-foreground text-pretty break-keep` `새로 들어가는 {N}개에 모두 적용돼요`
- 입력: 기존 `Input type="date"` (직접 추가 폼과 동일, `max`=KST 오늘, `h-10`, `tabular-nums`)
- 오류: `text-sm text-destructive` (`role="alert"`), 입력 `aria-invalid`
- 위치: 맞추기 = `새 해외 종목 매입 환율` 줄 바로 위 / 첫 등록 = 공통 적용 설정 아래. 신규 0개면 미렌더(마운트 자체 안 함, 모션 없음)
- 삭제: `resync-notice-3`(안내 줄 흡수). notice-1·2 불변.
- 매수일 지표 정본은 이 줄 1곳. 미리보기 행에는 날짜 표시 안 함.

## 2. 레이아웃 (px)
| 폭 | 구성 |
|---|---|
| 320 (dialog 내부 폭 약 280, 줄 안쪽 256) | **세로**: 제목·보조 줄 → 입력 `w-full h-10`. 가로 배치 시 문구 폭 100px로 어절 갈림 발생하므로 금지 |
| 375 | 동일 세로(`flex-col gap-2`) |
| ≥sm(640)·1280 | 가로 `sm:flex-row sm:items-center sm:justify-between gap-3`, 입력 `sm:w-40`. 모달 폭은 기존 max-w 그대로, 1280에서도 다이얼로그 폭 불변 |
- 간격: 줄과 이웃 줄 gap은 기존 `space-y-3`/`gap-3` 따름(4px 그리드). radius `rounded-lg`(내부 Input `rounded-md` 동심 유지).
- 첫 등록 화면의 위치 배치도 같은 셸 폭 `w-full`.

## 3. 상태
| 상태 | 표시 |
|---|---|
| 기본 | 값 = KST 올해 1/1, 오류 없음 |
| 신규 0개 | 줄 없음 |
| 신규 N개 | 보조 줄 `{N}개`(N은 실제 신규만, tabular-nums) |
| 오류(빈 값·오늘 이후) | 입력 아래 `오늘이나 그 이전 날짜를 골라 주세요`, `맞추기`/`등록` `disabled`. 오류는 즉시(입력 변경 시) 해제. 보조 줄은 유지 |
| 주식 / 코인 | 주식 제목 `새 종목 매수일` + InfoHint, 코인 `새 코인 매수일` InfoHint 없음 |
| 로딩 | 인식 중에는 미리보기 자체가 없으므로 줄 없음 |
| 과거 연도 선택 | 허용, 별도 경고 없음(spec §7) |
- 긴 문구: 모든 문장 `break-keep text-pretty`. 어절 갈림 0 (320·375).

## 4. 인터랙션·모션
- 모션 없음(정적 줄). 날짜 선택은 네이티브 picker. 줄은 미리보기 렌더와 함께 나타나며 단계 전환 애니메이션 기존 것만 사용 → 재마운트로 사라질 모션 없음.
- 신규 수가 편집으로 바뀌어 0이 되면(예: 행 체크 해제) 줄이 바로 사라지고 오류도 같이 사라져야 한다(남은 오류로 버튼이 잠기면 안 됨). 입력값은 상태에 유지해 다시 1개 이상이 되면 복원.
- 연타: 버튼 `disabled`는 저장 중 기존 로직 따름.

## 5. 접근성
- 입력 `aria-label`=줄 제목, 오류 `aria-describedby`. 포커스 링 기존 Input.
- 히트영역 40px: Input `h-10`, InfoHint는 `pointer-coarse:after:-inset-[13px]` 규약(기존 InfoHint 내장) — 제목 옆이라 이웃 버튼 없음, 충돌 없음.
- InfoHint `inModal` 필수(`modalHint` 10003). 다크: `bg-muted/40`·`text-muted-foreground`·`text-destructive` 토큰만(하드코딩 색 금지)으로 대비 유지.
- 키보드: Tab 순서 = 제목 InfoHint → 날짜 → 하단 버튼. Esc는 popover 닫기 후 다이얼로그.

## 6. 문구 (spec §5 승인 + 보정)
- 줄 제목: `새 종목 매수일` / `새 코인 매수일`
- 보조: `새로 들어가는 {N}개에 모두 적용돼요`
- InfoHint summary: `매수일 이전에 지급된 배당은 성과 › 배당의 올해 지급 예상에서 빠져요`
- InfoHint 상세: `올해 1월 1일로 두면 올해 배당이 모두 들어가요. 나중에 종목 수정에서 바꿀 수 있어요` (summary+상세 2문장, 3문단 상한 내)
- 오류: `오늘이나 그 이전 날짜를 골라 주세요`
- 투자 조언·금액 없음. `data-screenshot-hide`: 줄 전체(스크린샷 공유 대상 아님, 기존 미리보기 단계와 같이 이미 hide면 상속).

## 8. 품질 체크리스트 (qa 판정용)
1. 320·375: 줄이 세로 배치, 입력 폭 = 줄 안쪽 폭, 가로 스크롤 0, 문구 어절 갈림 0 (라이트·다크 4컷).
2. 1280: 가로 배치(제목 좌·입력 우), 입력 `sm:w-40`, 다이얼로그 폭 기존과 동일.
3. 줄 셸이 `새 해외 종목 매입 환율` 줄과 bg·radius·padding 동일(`bg-muted/40 rounded-lg px-3 py-2.5`), 테두리 없음.
4. 주식 줄에만 InfoHint, 코인 줄 없음. InfoHint 팝오버가 다이얼로그 위에 열려 가려지지 않음(320 포함, 화면 밖 잘림 0).
5. InfoHint·입력 터치 히트영역 ≥40×40px (coarse 에뮬레이션).
6. 기본값 `올해-01-01`, `max` = 오늘(KST). 빈 값·내일 → 오류 문구 노출 + `맞추기`/`등록` disabled, 값 고치면 즉시 해제.
7. 신규 0개 장: 줄 DOM 없음, `resync-notice-3` 어디에도 없음. 신규 N개: 보조 줄 `N개`.
8. 첫 등록 3경로(FAB·온보딩·/ratio 인계) 모두 줄이 같은 문구·셸로 보임, 라이트·다크 대비 AA(muted 보조 문구 포함).
9. 하단 `맞추기`/`등록` 버튼 `variant="brand"` 유지, 줄 추가로 푸터 버튼이 가려지거나 본문 스크롤 영역이 깨지지 않음(375×667에서 스크롤로 도달 가능).
10. `transition: all`·신규 색·신규 radius·신규 컴포넌트 패턴 0(diff 확인), CHECKLIST UI 항목(실기기형 확인: 아무 조작 없는 실제 상태에서 줄 노출) 충족.
11. 날짜 입력 iOS Safari 네이티브 picker에서 폭이 줄을 넘지 않음(`min-w-0`, `w-full`).
