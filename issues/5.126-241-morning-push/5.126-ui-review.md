## 광학 정렬 판정 (①, design-system §6)
- 운영은 `›`가 두 줄 가운데라 % 굵은 숫자(16px bold)보다 처져 "어느 줄의 화살표인지"가 흐렸다. 지금은 %와 같은 중심선에 놓여 `이름 — 막대 — % — ›`가 한 줄로 읽힌다. 14px 화살표의 꺾인 점이 % 숫자 x-높이 가운데에 온다(2배 캡처 확대 확인).
- 둘째 줄 `점검 차례`는 % 오른쪽 끝에 맞고(차 0), 화살표 열 아래는 비어 있다 — 화살표가 첫 줄에 속한다는 점이 더 분명해져 문제없다.
- 320 이름 두 줄 행(`TIGER 미국S&P500`, 행 90)도 %·막대·`›`가 같은 중심선(이름 두 줄의 가운데)이다.

## ⓘ 위치 판정 (③)
- Hero radius 16, 안쪽 여백 20(1280은 24), ⓘ는 12·12 — 모서리 곡선 안쪽에 들어오고 트로피(가운데)와 94~532px 떨어져 가운데 정렬 구성을 건드리지 않는다. 색은 정보 아이콘 토큰(sky /70) 그대로.
- 1280에서는 트로피와 멀지만(오른쪽 끝) 카드 오른쪽 위 모서리는 보조 설명 자리로 읽히고, 아래 `투입 대비 성과` ⓘ와 같은 색·크기라 일관된다.
- Hero 진입 모션(fade + zoom 95, motion-safe)에 ⓘ가 같이 움직인다 — 따로 튀지 않는다. 세그먼트 전환은 `hidden` 토글이라 재마운트 없음.

## 참고(수정 요청 아님)
- 5축 ⓘ `수익의 질·` / `레버리지`, 1280 `구조·` / `습관을`: 가운뎃점이 **줄 끝**에 남는 나열 끊김이라 허용. 문구 변경 없음, 운영과 같다.
- InfoHint 버튼에 `focus-visible` 링 클래스가 없어 브라우저 기본 윤곽선이 뜬다 — 공용 컴포넌트 기존 상태, 이번 범위 밖(주간 후보).
- 320에서 `PREVIEW · v5.126` 배지가 화면 제목 위에 겹친다 — preview 전용 표시, 운영 영향 없음.
- 세그먼트가 없는 화면(구획 제목 + ⓘ 유지)은 체험·데모에서 만들 수 없어 렌더로 보지 못했다. 코드상 기존 줄 그대로(diff는 조건 감싸기뿐)이고 테스트가 있다 — qa가 주식·코인 0종목 금고로 확인 필요.
- C140(고정 폭 칸의 날짜·금액): 이번 diff는 그런 칸을 건드리지 않았다. 행 % 칸(3.625rem)은 `+16.7%`~`+30.3%`에서 넘침 0.
