## 3. developer 지시
1. `quotes.ts`: `KR_TARGETS`·`fetchKrQuotes`는 그대로. 환율 대상을 상수로 꺼내 `fetchFxQuote(today, ctx, first)` 추가(같은 `fetchTargets`·날짜 검증). 아침 환율만 오늘 값 = 전일 값이면 생략하고 상태 `flat`(`QuoteStatus`에 추가). `estimateKisCalls`는 미국·환율·국내를 각각 세도록(아침 최대 3, 미국 반복일 1, 16시 3).
2. `cron-run.ts`: `loadPushQuotes`가 `{us, fx, kr, status}`를 돌려준다. 아침 = 미국(반복이면 생략) + 환율(오늘), 16시 = 국내 3종(오늘). `needKr = needed.has("kr")`, 아침 `hasContent = us.length + fx.length > 0`. 미국 기대일은 `message.ts`의 `expectedCloseDate`를 내보내 한 곳에서 계산한다(본문 날짜 = 조회 날짜). 주석 3곳(`:14·41·104`) 사실대로.
3. `message.ts`: `buildMorningMessage(today, us, fx, cond)`. 미국 머리 `미국 ${M/D} 종가 `, 환율 묶음은 머리말 없이 `환율 …`. 국내 묶음·`국내 M/D 휴장` 분기 삭제(`isRepeatedClose`의 `"kr"` 인자는 쓰는 곳이 없어지면 함께 정리). pm2 = 미국 또는 환율.
4. `test-payloads.ts`: 아침 = 미국 + 오늘 환율, 국내 장 마감 미리보기는 지금처럼 직전 영업일 종가(제목 날짜 포함) — 16시 문자열 꼴 불변.
5. 문구: `catalog.ts:13·14`, 예시 알림, 새 소식(spec 5절 최신), 주석(`push-host.tsx`·`sw.js`).
6. 로그: `subs=`는 `needed` 계산에 쓰는 구독 배열에서 센다(추가 조회 0).
7. 테스트: ① spec 표 1~19행·합침 2건 글자 단위 ② cron — 아침에 `fetchKrQuotes` 호출 0, 환율 기대일 = 오늘, 값 0이면 플래그 미설정, 예산 추정 3 ③ `flat`·`stale`·`fail` 각 1건 ④ pm2 코스피 단독 급등 날 아침 미발송·16시 발송 ⑤ 16시 기존 테스트 무수정 통과.
8. 진단 라우트 `src/app/api/diag/fx-daily` 삭제 — 실측 16:05·11/20 09:01 기록 뒤, qa 인계 전. `git diff origin/main --stat`에 0줄을 dev-notes에.
