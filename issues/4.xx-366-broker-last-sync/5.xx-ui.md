## 1. 증권사별 행 메타 줄 (주식 `BrokerRow`만)
- 구조: 메타 줄 `<p data-testid="broker-row-meta" className={`flex flex-wrap gap-x-1 text-sm text-muted-foreground tabular-nums ${DOT_WRAP_ROW}`}>`
  - 첫 조각은 `broker-row-count`. `whitespace-nowrap ${DOT_WRAP_FIRST}`, 글자는 `N종목`(현행)이다.
  - 둘째 조각은 `broker-row-synced`(`data-date="YYYY-MM-DD"`). `whitespace-nowrap`이고 맨 앞에 `<DotLead />`를 둔다. 글자는 `11/20 맞춤` 또는 `2025.12.3 맞춤`이다.
  - 표시 조건이 안 맞으면 조각을 아예 그리지 않는다(DOM 0). 이 경우 DotLead도 없다.
- 위계: 줄 전체를 `muted-foreground`로 두고 날짜에 강조·굵기·색을 쓰지 않는다(경과 경고는 범위 밖). 둘째 조각은 `inset`을 쓰지 않는다(조각 안에서 접히지 않음). 라이트·다크 같은 토큰이라 대비는 현행 메타와 같다.
- 비중 조각(`broker-row-share`)은 주식 행에서 제거한다(별도 커밋). 코인 행은 그대로 둔다. 구현할 때 `BrokerRow`에 주식 전용 prop(예 `syncedText?: string | null`, 넘어오면 dot-wrap 메타·비중 0)을 추가한다. 넘기지 않는 코인 `ExchangeTotalsBlock`은 현행 인라인 `· 27.5%` 마크업을 바이트 그대로 유지한다.
- 1280: 행 폭이 충분해서 모든 픽스처가 1줄이고 증가 0이다. 모션은 없다(펼침 전환은 현행 그대로).

## 2. 맞추기 대화상자 — 변경 0 경로
- 버튼: `resync-apply`는 현행 그대로 `Button variant="brand"`이고 문구도 `맞추기`이다(경로 A와 같은 동사, 의미 설명은 안내 문구가 맡는다). 활성 조건은 `!applying && (changes>0 ? !newDateInvalid : kind==="stock" && 쓰기 가능 범위≥1)`이다. 경로 B는 동기 처리라 `맞추는 중` 스피너를 쓰지 않는다. 연타는 클릭 즉시 `applying` 가드로 1회만 처리한다.
- 안내는 한 요소다. 현행 `바뀌는 내용이 없어요` `<p>`를 그대로 두고 `id`(`useId`)와 `data-testid="resync-same-note"` `data-state="confirm|blocked"`, `aria-live="polite"`만 붙인다. 글자만 바꾸고 요소는 재마운트하지 않는다.
  - confirm: `바뀌는 내용이 없어요. 맞추면 오늘 맞춘 날로 남아요`. 버튼이 켜지고 `aria-describedby`로 이 문구를 연결한다.
  - blocked(범위 0, 코인 변경 0 포함): `바뀌는 내용이 없어요`. 버튼이 꺼지고 `aria-describedby`로 같은 id를 연결한다. `changes>0`이면 연결하지 않는다.
  - 상단 `resync-summary`가 이미 `바뀌는 내용이 없어요`(모든 수 0)라면 confirm 문구는 `맞추면 오늘 맞춘 날로 남아요`만 둔다(같은 문장 두 번 금지, C161). `확인 필요 N개…` 안내와는 현행처럼 함께 보인다.
  - 클래스는 현행 `text-sm text-muted-foreground text-pretty break-keep sm:mr-auto sm:self-center`이다. 320에서 2줄을 허용한다.
- 결과(B): 제목은 현행이다. `resync-result` 상자 안의 `summaryParts` 줄과 `ReconcileLines`는 그리지 않는다. 그리면 `바뀌는 내용이 없어요`가 겹치기 때문이다(C161). 첫 줄은 `resync-result-same` `바뀐 내용 없이 오늘 맞춘 날로 남겼어요`(`text-sm text-foreground text-pretty break-keep`), 다음 줄은 현행 `이 창을 닫기 전에는 되돌릴 수 있어요`이다. 버튼은 현행 `되돌리기`(secondary)·`닫기`(brand)이다.
  - 되돌린 뒤에는 `resync-result-same`을 숨기고 현행 `되돌렸어요`만 남긴다(사실이 아닌 문장 제거).
- 토스트: 닫은 뒤에는 현행 `보유 현황을 맞췄어요` + `되돌리기`(8초)이고 A·B가 같다. B의 되돌리기 토스트는 현행 `되돌렸어요`이다.
- 쓰기 실패(B): `toast.error("맞춘 날을 남기지 못했어요")`가 뜬다. 미리보기·안내·버튼은 그대로 두고, 버튼은 다시 켠다. 포커스는 버튼에 그대로 둔다. A는 문구가 없다.

## 4. 완료 기준·qa 체크리스트
1. 데모 preview 375 라이트·다크에서 `데모증권` 행은 `N종목 · M/D 맞춤`이고, 연금저축 행은 `1종목 · 2025.12.3 맞춤`(다른 해 표기)이고, ISA 행은 `N종목`만 보인다.
2. 주식 행 메타의 textContent는 `A · B` 모양이다. 줄 머리·줄 끝에 `·`만 남는 경우가 0이고, 조각 안 꺾임도 0이다(C152). 최장 이름 픽스처 320~440 2px로 판정한다.
3. 날짜 조각 색은 메타 줄과 같은 `muted-foreground`이고, `font-weight`도 메타 줄과 같다.
4. §1-1 실측표 밖에서 행 높이 증가가 0이고, 3줄 메타가 0이다(라이트·다크 각각, C164·C168).
5. 주식 행에 `broker-row-share`가 0개다. 코인 거래소 행 DOM 스냅샷은 main과 같다(비중 유지).
6. 변경 0이고 범위 ≥1이면 `resync-apply`가 켜져 있고 `aria-describedby`가 `resync-same-note`를 가리키며 `data-state=confirm`이다.
7. 범위 0 또는 코인 변경 0이면 버튼이 `disabled`이고 `aria-describedby`가 연결돼 있으며 `data-state=blocked`이고 문구는 `바뀌는 내용이 없어요`이다.
8. 결과(B) 상자 안에 `바뀌는 내용이 없어요`가 0개이고 `resync-result-same`이 1개다. 되돌린 뒤에는 `resync-result-same`이 0개다.
9. 쓰기 실패를 주입하면 오류 토스트 1개가 뜨고 step은 preview로 남으며 버튼은 다시 켜진다.
10. `resync-apply`를 연타해도 기록은 1회, GA `resync_confirm_same`도 1건이다.
11. 히트영역: 행 `맞추기`와 대화상자 버튼은 40px 이상이다(현행 유지). 대화상자 문구는 320에서 넘침 0이다.
12. 1280 라이트·다크에서 모든 픽스처 메타가 1줄이고 대화상자 footer 정렬은 현행과 같다.
