# 5.112 dev-notes (공유 v73A)

## 변경 요약
- `src/lib/asset/share-crypto.ts` 신규: AES-256-GCM, PBKDF2(PIN, URL키16B‖salt16B, 200k = cloud-sync/crypto 상수 재사용), AAD "v73A", 압축 후 암호화. URL 키 CSPRNG base62(0-9A-Za-z) 22자(62^22 ≈ 2^131, rejection sampling, `_` 없음). 새 일회성 코드 전체 길이 39자(`share:`6 + 서버키10 + `_` + URL키22; 기존 49자). 직접 입력 UI(pwa-connect-prompt)에는 maxLength·형식 제한이 없어 변경 불필요.
- `generateShareToken`·`parseShareToken` async, 호출부(tool-menu·use-share-artifacts·asset-data-context) 수정. localKey는 CSPRNG. 링크 형식 불변. tool-menu 미리 생성은 PIN 변경 시 이전 응답 무시(cancel 플래그).
- `/api/share`: POST v73A만. GET v72Z 허용(B안, 대표 11-14), TTL 연장 중지(cache-storage 두 구현), `BLOCK_LEGACY_V72Z_GET=false` 플래그(true면 410).
- 문구: 간편 공유 안내에서 "안전하게"·"서버 관리자도 복호화할 수 없습니다" 제거 -> 서버만으로는 열 수 없음 + 링크 노출 시 PIN만 남는다는 안내(C26).
