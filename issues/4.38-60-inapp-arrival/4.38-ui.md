# 4.38 인앱 브라우저 도착 개선 — ui (#60)

근거: 4.38-spec.md 4·5·8·10장, 4.38-direction.md 5장(문구), design-system.md §1.2·§2·§3.3·§3.4·§5·§6·§7, components.md(WelcomeGuide CTA 슬롯·Button). 코드 실측: issue-4.37 `welcome-guide.tsx`(슬롯 191-199, `WelcomeAssetCta` 337-347 제목·본문 패턴), `in-app-browser-gate.tsx`(루트 94 `fixed inset-0 bg-background` + `Z_LAYER.gate`), `in-app-external-guide.tsx`(앰버 안내 19-27, `lastStep` prop). 슬롯 안쪽 폭: 320=264px, 375=319px(`p-4`), 1280 `sm:p-6`.

## 1. 결정
| 항목 | 결정 | 근거 |
|---|---|---|
| inapp 슬롯 구성 | `WelcomeAssetCta`와 **같은 골격**(가운데 정렬 제목 `text-lg` + 본문 `text-sm muted` + brand `size="lg"` 버튼 1개). 아이콘·경고색 박스 추가 안 함 | 상태가 바뀌어도 슬롯이 같은 위계로 읽혀야 한다(#48 셸 유지). 본문은 사실 안내이지 위험 경고가 아니라 주황·앰버 미사용 |
| iOS 안내 | 버튼 아래 **항상 마운트된 높이 펼침** 영역에 캡션 + `InAppExternalGuide` | §6 재마운트 없음 패턴(`welcome-security-detail`과 동일). 슬롯이 152→약 470px로 커지는 점프를 보간 |
| 가이드 중복 제거 | `InAppExternalGuide`에 선택 prop **`notice?: ReactNode`** 추가: 넘기면 상단 앰버 블록의 내용(제목+"앱 설치 기능이 지원되지 않으므로…")을 대체. 기본값은 기존 그대로(설치 흐름·게이트 무변경) | 그대로 쓰면 "주소가 복사되었습니다!"가 캡션과 두 번 보이고, "앱 설치 기능" 문장은 웰컴 맥락과 다르다. 컴포넌트 신규가 아닌 prop 1개(components.md 등록 대상) |
| 빈 덮개 | 게이트 **같은 루트 노드**(`fixed inset-0 bg-background`, `Z_LAYER.gate`)를 내용 없이 렌더 → 로드 후 0건이면 노드 제거, 1건 이상이면 같은 노드에 기존 게이트 내용 삽입 | 덮개→게이트 사이 노드 교체가 없어 깜빡임 0. z-index 신규 없음(§3.4) |

## 2. 웰컴 CTA 슬롯 `data-state="inapp"`
셸(`welcome-cta-slot`) 클래스·`min-h-[152px] sm:min-h-[160px]` 무변경. 안쪽만 교체:
```
WelcomeInAppCta (welcome-guide.tsx 로컬 export, 기존 WelcomeInstallCta·WelcomeAssetCta와 나란히)
div.space-y-5.motion-safe:animate-in.motion-safe:fade-in-0.motion-safe:duration-200
  div.text-center.space-y-1
    h2.text-lg.font-semibold.text-balance.break-keep
      "자산 등록은 " + span.whitespace-nowrap "Chrome·Safari에서" + " 시작해요"
    p.text-sm.text-muted-foreground.text-pretty.break-keep "이 화면에서는 입력한 내용이 사라질 수 있어요."
  div.flex.justify-center
    Button variant="brand" size="lg" data-testid="welcome-cta-inapp" className="w-full gap-2 break-keep sm:w-auto"
      ExternalLink size-4 aria-hidden + "외부 브라우저에서 시작하기"
  div#welcome-inapp-guide[data-testid=welcome-inapp-guide][role=region][aria-label="외부 브라우저 이동 방법"]
     항상 마운트, 닫힘 grid-rows-[0fr] opacity-0 invisible + inert / 열림 grid-rows-[1fr] opacity-100 visible
     motion-safe:transition-[grid-template-rows,opacity,visibility] motion-safe:duration-300 ease-out
    div.min-h-0.overflow-hidden > div.pt-1.text-left
      InAppExternalGuide notice={<p role="status" data-testid="welcome-inapp-caption" className="text-sm font-semibold break-keep text-pretty">주소가 복사됐어요. 브라우저에 붙여넣어 주세요.</p>}
                         lastStep="이동한 브라우저에서 주소로 접속하면 이어집니다."
```
- `Chrome·Safari에서`를 nowrap으로 묶는 이유: `·`(U+00B7) 뒤 줄바꿈 기회가 있어 "Chrome· / Safari에서"로 끊길 수 있다. 320(264px)에서 제목은 "자산 등록은 / Chrome·Safari에서 시작해요" 2줄
- 수치(375): 제목 2줄 56 + 4 + 본문 1~2줄 20~40 + 20 + 버튼 40 ≈ 140~160 → 기존 min-h 안. 펼침 후 약 +320px(가이드). 1280: 버튼 `sm:w-auto` 가운데, 본문 한 줄
- `lastStep`은 spec "접속하면 이어집니다" 주입. 기존 기본 문구의 "복사된 주소" 반복을 줄인 형태(문구 확정 범위 안: 마지막 단계 문장만)
- 버튼 상태: 기본 / hover `bg-brand/90` / focus-visible 링 / 누름 0.96(내장) / **처리 중**(iOS 클립보드 Promise 대기·Android 스킴 호출): `disabled` + `Loader2 motion-safe:animate-spin`, 끝나면 복귀. iOS 재탭 = 재복사(영역은 열린 채 유지, 닫는 컨트롤 없음 — 읽기 안내)
- 버튼 `aria-controls="welcome-inapp-guide"`, `aria-expanded`는 iOS에서만(Android는 영역을 열지 않음)
- 포커스: 펼친 뒤 포커스 이동 없음(캡션 `role="status"`가 낭독)
- 슬롯 상태 우선순위: `pending`(마운트 전) → `inapp` → `install` → `asset`. `inapp`에서는 등록·설치·바로 시작 버튼, 직접 입력 팝오버, 숨은 file input 모두 미렌더
- 같은 웰컴의 #59 "직접 둘러보기" 칩은 inapp에서도 ③ 행에 노출(#59 ui 2장)

## 3. 빈 덮개(로드 전)
- `InAppBrowserGate`: 마운트 후 `isInApp && !standalone`이고 `isDataLoaded=false`인 동안 `div[data-testid=inapp-gate-cover][aria-hidden=true].fixed.inset-0.bg-background` (`style={{zIndex: Z_LAYER.gate}}`), 자식 없음·스피너 없음·전환 없음
- 로드 후 판정 true → 덮개 즉시 제거(웰컴 자체 `ENTER` stagger가 진입을 담당, 덮개 페이드아웃 없음). false → 같은 노드에 기존 게이트 내용(`max-w-md` 헤더·버튼) — 기존 화면·문구 무변경
- 다크·라이트 모두 `bg-background`(테마 클래스는 hydration 전에 적용되므로 흰 섬광 없음)

## 4. 문구 최종(팀 확정)
제목 "자산 등록은 Chrome·Safari에서 시작해요" / 본문 "이 화면에서는 입력한 내용이 사라질 수 있어요." / 버튼 "외부 브라우저에서 시작하기" / iOS 캡션 "주소가 복사됐어요. 브라우저에 붙여넣어 주세요." / 가이드 3단계 "이동한 브라우저에서 주소로 접속하면 이어집니다." 게이트 기존 본문 무변경.

## 5. testid
`welcome-cta-slot[data-state=inapp]`, `welcome-cta-inapp`, `welcome-inapp-guide`, `welcome-inapp-caption`, `inapp-gate-cover`. 기존 `welcome-cta-wizard`·`welcome-cta-more`·`welcome-install-btn`·`welcome-skip-install-btn`은 inapp에서 부재가 계약.

## 6. 품질 체크리스트
1. 카톡 UA·0건·해시 없음, 375·1280 × 라이트·다크: 슬롯 `data-state="inapp"`, 제목·본문·brand 버튼 1개만 보이고 등록 관련 testid 4종 부재.
2. 슬롯 셸 노드가 `pending`→`inapp` 전환에서 같은 노드(Playwright element handle 동일)이고 `min-height` 152px(sm 160px) 유지.
3. 320: 제목이 "자산 등록은 / Chrome·Safari에서 시작해요"로 끊기고 "Chrome·"/"Safari" 분리 0, 가로 넘침 0.
4. 버튼 높이 ≥ 40px, 배경 #5b6fbf, 모바일 전체 폭·1280 자동 폭 가운데.
5. iOS UA: 버튼 탭 후 `welcome-inapp-guide`가 같은 노드에서 `grid-template-rows` 0fr→1fr로 보간(C3 실제 동작), 닫힘 상태에서 `inert`, reduced-motion은 즉시.
6. iOS 펼침 후 "주소가 복사됐어요…" 문장이 화면에 1회만 보인다(가이드 앰버 블록 원문 "현재 웹페이지 주소가 복사되었습니다!"·"앱 설치 기능" 문장 부재).
7. 설치 흐름(`pwa-install-flow`)·1건 이상 게이트의 iOS 가이드는 기존 문구 그대로(`notice` 미전달 회귀).
8. 로드 전 프레임: 경고 문구·웰컴 문구 모두 0, 덮개 배경이 `bg-background`(라이트·다크). 1건 이상 인앱은 덮개 노드가 그대로 게이트가 된다(노드 동일).
9. 처리 중 버튼 `disabled`, 연타해도 `pwa_install inapp_move` 탭당 1건.
10. 새 문구 전부(제목·본문·버튼·캡션·3단계) 320·375 어절 중간 줄바꿈 0, computed `word-break: keep-all` 또는 nowrap 묶음(C25).
11. `transition-property`에 `all` 없음, 덮개·슬롯 z-index가 `Z_LAYER` 값(신규 z 클래스 0).
12. C2: inapp 슬롯의 버튼 줄 수(1)가 asset 상태(1~2)보다 늘지 않는다.
