## 4. 인터랙션·모션
- 진입: 현행 `motion-safe:animate-in fade-in-0 duration-200` 1회(첫 마운트만). 화면 전환에는 재생하지 않는다 — key 래퍼 밖이라 재마운트 0(developer는 화면 전환 5회 뒤 같은 DOM 노드인지 확인).
- sticky 전환은 CSS 위치뿐(그림자·크기 변화·JS 스크롤 리스너 0). `will-change` 금지.
- 버튼: 공용 `Button` 누름 0.96, 연타는 `busy`로 1회.
- 안내 펼침: 현행 `grid-rows 0fr↔1fr` 300ms(항상 마운트·`inert`), `닫기`는 로컬 상태로 접고 포커스를 `trial-start-btn`으로 돌려준다. 다시 누르면 다시 복사·펼침(현행 동작).
- 팝오버: `onOpenAutoFocus`에서 `preventDefault` 후 해당 행 `focus()`. 짚는 표시는 `data-picked` 속성 + `bg-accent`·`font-semibold`·아이콘 `text-foreground`(전환 없음, 팝오버가 열릴 때 이미 그려져 있다). 다른 행에 hover·포커스가 가도 짚는 표시는 남는다(닫았다 다시 열어도 같음). 첫 행 `focus()`는 포인터·터치로 연 경우 링을 그리지 않는다(`focus-visible`만 링) — 5개 상태 모두 면만 보인다.

## 5. 접근성
- 표시: `section aria-label="체험 안내"`(현행). 글은 `p` 1개 — 읽기 순서 `예시 자산 저장되지 않아요` → 버튼. 버튼 이름 `내 자산으로 시작`.
- 히트영역: 버튼 151.5×48(카드 높이 전체, `elementFromPoint`로 위 가장자리 확인). `닫기` 52×40.
- 키보드: 표시는 DOM 첫 자식이라 본문보다 먼저 탭 순서. sticky가 포커스된 본문 요소를 가리지 않게 `[data-content-area]`에 `scroll-padding-top` 대신 **세금 관리 `scrollIntoView` 대상(`이번 달`)에 `scroll-mt` = 표시 높이 + 세금 머리**가 필요한지 developer가 확인(현행은 세금 머리 높이만큼 이미 가려지는지 5.126 대조).
- 등록 칸: 복귀 시 포커스 = 강조 버튼(부동산만 직접 입력). 팝오버 짚는 행은 `aria-current="true"`(선택 상태가 아니라 '방금 본 것' 표시).
- 대비(다크, 토큰 값으로 계산·화면 미측정): `저장되지 않아요` muted-foreground on card 약 7.4:1, 버튼 흰 글자 on brand 약 4.7:1(현행 버튼과 같음).

| 앱 안 브라우저로 온 사람(iOS) — 성과에서 | 버튼 → 안내가 표시 안에서 펼쳐지고 320에서도 화면 안, `닫기`로 접힘 | 효용 있음. 이어짐은 없다(현행 한계, spec 3-4) |
개선 반영: 초안의 '점(·) 구분'을 빼고 굵기·색 차로만 나눔(1줄 폭 확보), 버튼 h-10 → h-9 + 누름 48(높이 56 → 48).
