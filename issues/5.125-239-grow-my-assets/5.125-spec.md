- 화면별 진입 수(C124): 성과 허브 → 불리기 1개(셋째 카드). 불리기 화면 → 종목 페이지는 행당 1개, X-Ray는 분산 축 링크 1개. 홈 미니 배지는 현행(홈 diff 0).
- **기간 표기(행·허브 카드 공통)**: 지난 달력 월 수로 센다. 같은 날 `오늘`, 1개월 미만 `N일 전`, 1~11개월 `N개월 전`, 12개월 이상 `N년 N개월 전`(나머지 0이면 `N년 전`). `…한 지` 꼴은 `오늘부터`·`N일`·`N개월`·`N년 N개월`. 허브 카드 둘째 줄은 보유 중인 '점검할 자산'의 가장 최근 점검일 기준이고, 경과 문구·배지·색이 없다(cto 쟁점 2).
- 엣지: 점검 기록 없는 '점검할 자산'의 주기는 이름표를 붙인 날부터 센다(문구 `점검하기로 한 지 N개월`) / 주기를 바꾸면 그 자리에서 다시 계산 / 전량 매도·삭제된 티커의 이름표는 저장소에 남기고 화면·개수에서 뺀다(다시 보유하면 예전 날짜 그대로 보임 — 알려진 한계) / 원문 티커가 달라 행이 둘로 나뉜 같은 종목은 이름표를 함께 쓴다 / 비중 분모는 전체 탭과 같아(티커 없는 종목 포함) 행 비중 합이 100%가 아닐 수 있다 / 시세 미조회 종목은 사실 줄의 해당 값만 `—`.
- 데모 시드 소비 화면은 허브 카드·불리기 화면 2곳뿐이다(C125). 다른 데모 화면 숫자 diff 0.

## 인사이트 4종 (11/17 대표 지시 확정 — DECISIONS 11/17 마지막 줄. `5.125-insight-selection.md`의 제외·연기 판단을 대체한다)
**경계 한 문장: 앱은 정한 날의 내 기록과 지금의 내 기록을 나란히 놓고, 그 차이가 좋은지 나쁜지 말하지 않는다.**
공통 규칙: 이름표 종류와 관계없이 **같은 문장·같은 클래스·같은 색**(본문 보조색 + 값만 `font-semibold text-foreground`). 손익색·주황·배지·아이콘·화살표 색 없음. 이 값들로 정렬하지 않는다. 이름표별 합계·평균·순위 없음.

**화면 위치와 위계**
| 자리 | 내용 | 보이는 조건 |
|---|---|---|
| 블록 요약 영역 1 | ③ 무게 줄 3묶음 | 이름표 1개 이상 |
| 블록 요약 영역 2 | ④ 연결 문장 최대 2줄(배당 → 결산 순) | '오래 둘' 1개 이상 + 각 문장 조건 |
| 행 1줄째(지금 줄, 현행) | `내 주식의 18.3% · 내 매입가 대비 +91.0%` | 전 행 |
| 행 2줄째(이름표 줄, 현행) | `오래 두기로 한 지 5개월` / `마지막 점검 4개월 전 · 내가 정한 주기 3개월이 지났어요` | 이름표 있는 행 |
| 행 3줄째(정한 뒤 줄, 신규) | ② `정한 날 가격 대비 +12.0%` · ① `정한 뒤 수량 그대로 5개월` 또는 `정한 날 10주 → 지금 12주` | 이름표 있는 행, **정한 날 다음 날부터** |
| 행 4줄째(매매 줄, 신규) | ① `이 앱에 기록한 매매 최근 3개월 2건` | 이름표 있는 행, **붙인 즉시** |
- **접지 않는다.** 대표 지시가 "실제 화면으로 제공"이라 인사이트를 펼침 안에 두지 않는다. 길이는 기존 '상위 3행 + 전체 보기'가 막는다. 수량 비교는 이전 보강의 '이름표 줄 끝'에서 정한 뒤 줄로 옮긴다(가격 %와 같은 기준일을 쓰는 조각을 한 줄에 모은다).
- 정한 뒤 줄 안 순서는 가격 → 수량. 390에서 2줄이 되면 가운뎃점 자리에서만 줄을 바꾼다(조각 안 줄바꿈 금지, C130). 행 높이는 폭별로 다시 잰다(C103·C115).
- 이름표 없는 행에는 3·4줄째가 없다. 이름표 0개 상태의 화면은 이전과 같다(조건 1).
- 허브 카드는 diff 0(둘째 줄 = 무게). 홈·알림·AI 프롬프트 노출 없음.

**① 원칙 vs 행동 (행)**
- **매매 줄** `이 앱에 기록한 매매 최근 3개월 N건`. 0건도 `0건`으로 쓴다. 센 대상: 그 이름표 키(`normalizeTicker`)의 주식 거래 기록(`assetData.transactions`, 매수·매도 합) 중 거래일이 오늘에서 달력 3개월 전 다음 날부터 오늘까지(KST)인 것. 미래 날짜는 세지 않는다. **종목 페이지 거래 기록 목록에서 같은 기간을 세면 같은 수**(정본). 거래일은 사용자가 고칠 수 있는 값이지만 판별·자동 연결이 아니라 목록과 같은 수를 보여 주는 표시라 목록과 같은 필드를 쓴다(LEARNINGS 11-11과 구분, 필드·반영 여부 조건은 tech-review 확정).
- **수량** 같으면 `정한 뒤 수량 그대로 N개월`(기간은 `labeledAt`부터, 기존 `…한 지` 규칙: `3일`·`5개월`·`1년 2개월`), 다르면 `정한 날 10주 → 지금 12주`. 표기·'같음' 판정·합산 규칙은 이전 보강 그대로(종목 페이지 `총 N주`와 같은 표기, 표시 문자열이 같으면 같음, 같은 키의 행 수량 합).
- '오래 둘' 행은 이름표 줄과 정한 뒤 줄에 같은 기간이 한 번씩 나온다. 이름표 종류에 따라 문장을 달리하지 않는 규칙이 우선이라 그대로 둔다.

**② 이름표 이후 결과 (행)**
- `정한 날 가격 대비 +12.0%` = (지금 시세 − `base.price`) ÷ `base.price`. **종목 통화 그대로**(환율 효과 없음), 소수 1자리, 부호 표기는 `내 매입가 대비`와 같은 함수. 0이면 `0.0%`.
- **표시 시작: 정한 날 다음 날(KST)부터.** 당일은 정한 뒤 줄 전체가 없다(값이 0이거나 장중 변동뿐이라 뜻이 없다). 수량 조각과 같은 규칙 1개다.
- 한 행에 % 3개(비중·매입가 대비·정한 날 가격 대비)가 선다. 값마다 기준을 글자로 앞에 붙여 구분한다(design-system §11 '분모가 다른 값은 기준 명시').
- `base.price` 없음(정한 날 시세 없음) → 가격 조각만 영구 생략, 수량 조각은 나온다. 지금 시세 없음 → `정한 날 가격 대비 —`.

**③ 무게 (요약 영역 1, 반영됨·diff 0)**
- 형식: `오래 둘 N종목 · 내 주식의 N.N%` / `점검할 N종목 · N.N%` / `정하지 않음 N종목 · N.N%`. 소수 1자리, 합 100.0%.
- 계산: 행 평가액 합 ÷ 행 비중과 같은 분모(`buildGrowRows`의 `totalValue`). `정하지 않음` = 100 − 나머지 둘의 표시값. 행 표시값을 더하지 않는다.
- 허브 카드 둘째 줄 `오래 둘 자산 · 내 주식의 N.N%`는 같은 함수의 같은 문자열. '오래 둘' 0개면 `마지막 점검 N개월 전`.
- 주기 안내 문장은 주기를 고르기 전에만 보인다.

**④ 기존 기능 연결 (요약 영역 2, '오래 둘' 1개 이상일 때만. '점검할'·'정하지 않음' 몫은 쓰지 않는다 — 이름표끼리 비교 금지)**
- **배당** `올해 예상 배당 중 오래 둘 자산 몫은 N%예요`.
  - 분모 = 성과 허브 배당 카드의 `올해 배당 (지급 + 예상)`(`useDividendAnnualTotals`, 정본). 분자 = 그중 '오래 둘' 종목 몫. 같은 쿼리 키·같은 종목 대상·같은 매수일 조건을 써서 **분모가 배당 카드 금액과 같다.** 정수 %, 금액은 쓰지 않는다.
  - 조회 중 → 줄 자리 스켈레톤 1줄. 조회 실패가 1건이라도 있으면(`failedCount > 0`) 줄 없음(비율이 틀려진다. 실패 안내는 배당 카드가 이미 한다). 분모 0(배당 없음) → 줄 없음. 분자 0·분모 양수 → `0%` 그대로.
- **올해 결산** `올해 내 주식에서 불어난 돈 중 오래 둘 자산 몫은 N%예요` — 아래 3갈래.
  - 종목별 올해 변동 = **지금 보유 수량 × (지금 시세 − 기준 시세) × 지금 환율**. 기준 시세 = 전년 마지막 거래일 종가(기존 `price-history` API `range=1y`, 요청은 종목코드·범위뿐). 분자 = '오래 둘' 종목 합, 분모 = 티커 있는 내 주식 전체 합.
  - **연초 이후 보유 변동 처리**: ⓐ 올해 편입한 보유 행은 기준 시세 대신 내 매입가(평단)를 쓴다(올해 산 종목의 변동은 산 뒤의 변동이다). ⓑ 연중에 더 사거나 일부 판 종목은 지금 수량 전부를 같은 규칙으로 계산한다(보정 없음). ⓒ 올해 전량 판 종목은 빠진다.
  - **'올해 편입' 판정 = 매수일(`purchaseDate`)이 올해인 보유 행**(cto 허용 — 판별·병합이 아니라 표시 계산의 기준이고 배당 카드가 같은 필드를 같은 뜻으로 쓴다). 조건 3개: ① 판정은 **티커 묶음이 아니라 보유 행마다** 한다(같은 종목을 작년·올해 나눠 산 행은 행별로 기준이 다르다. 종목 값은 행별 계산의 합) ② 매수일이 비었거나 형식이 틀리거나 미래면 '연초 전 보유'(기준 시세)로 본다 ③ 도움말에 `올해 산 종목은 내 매입가부터 계산해요.`를 넣는다.
  - `결함 의심(tech-review 확인)`: 스크린샷·파일 가져오기가 매수일 기본값을 가져온 날로 넣으면 오래 가진 종목이 '올해 편입'으로 잡힌다. 그 형태 픽스처 1건으로 값을 대조하고, 기본값이 '가져온 날'이면 알려진 한계로 적는다(보정 없음).
  - 연 탭 결산의 '불어난 돈'(월 기록 기준, 모든 자산·환율 효과 포함)과 **계산이 다르다.** 그래서 문장에 `내 주식에서`를 넣고 금액 없이 %만 쓴다. 도움말에 차이를 적는다.
  - **문장 3갈래**(같은 자리·같은 색·같은 굵기, 금액 없음, N은 정수):
    | 조건 | 문장 |
    |---|---|
    | 분모 > 0, 분자 ≥ 0, 0~100% | `올해 내 주식에서 불어난 돈 중 오래 둘 자산 몫은 N%예요` |
    | 분모 < 0, 분자 ≤ 0, 0~100% | `올해 내 주식에서 줄어든 돈 중 오래 둘 자산 몫은 N%예요` |
    | 부호가 섞임(100% 초과 포함) | `올해는 불어난 쪽과 줄어든 쪽이 섞여 있어 몫을 비율로 나타내지 않아요` |

## 추천 아님 조건 5개 (challenge 1절 그대로, AC-8~12)
1. 이름표 0개 상태의 허브 카드·화면에 앱이 센 숫자·분류를 두지 않는다. `오래 둘 6 · 점검할 3`은 사용자가 붙인 개수일 때만 나온다.

3. 성적표 축 문장·점수가 개별 종목이나 이름표를 가리키지 않는다. 축 문장에서 이름표 블록으로 가는 링크 없음.
4. 이름표는 AI 프롬프트 본문에 넣지 않는다(v1, 본문 diff 0).
5. "주기가 지났어요"는 화면 안 사실 문구만. 푸시·홈 팁 없음.
