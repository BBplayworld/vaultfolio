# 4.66 UI r3 — 타일 없는 브랜드 심볼 3안 (ui-designer)

대표 반려: 검정 타일 + 필기체 S. 요청: 토스뱅크처럼 배경 없는 심볼. 모양 모방 없이 "안전·자산·S"를 고유하게.

## 3안 (viewBox 32, SVG 원본 `ui-r3-symbol-{a,b,c}.svg`, 모두 gradient·타일 없음)
| 안 | 컨셉 | 특징 |
|---|---|---|
| A 방패 S | 방패 실루엣 안에 S를 투명 컷아웃(mask) | 인디고 그라데이션 단색 면. 28px에서도 윤곽·S 모두 선명, "안전"이 한눈에 읽힘 |
| B 다이얼 S | 금고 다이얼: 2분할 회색 링 + 인디고 원판 + S 컷아웃 | 입체감은 가장 높으나 20~28px에서 링이 잔잔하게 번잡 |
| C 레이어 S | 굵은 S를 대각 틈으로 가른 2톤(연/진 인디고) 두 면 | 가장 독창적·현대적. 단 틈이 작은 크기에서 S를 끊어 보이게 하고 "보안" 단서는 약함 |

## 락업 검토 (375, 심볼 28px + 워드마크 19px bold, gap 8px)
- 워드마크: 다크 #e5e8eb / 라이트 #191f28, bold(700), tracking-tight. 토스(#c9cdd4급 회색, bold)보다 대비를 약간 높여 가독 우선.
- 라이트 배경은 gradient 시작색이 옅어 보이므로 한 단계 진한 톤 사용(캡처 적용값): A `#a9b6f2→#8091e6`, `#4f62b3→#38479a` / B 링 `#dfe3ee→#aab1c4`, `#7d869c→#5b6379`, 원판 `#9aaaf0→#7185e0`, `#5468b8→#3a4a9c` / C `#c3ccf8→#97a8f0`, `#8396e4→#6379d8`, `#6a7fd0→#4c60bc`, `#43529f→#2f3c85`. 구현 시 stop-color를 CSS 변수(라이트/다크)로 분리.
- 인증카드 버튼: 청록 채움 사각은 타일 없는 락업과 충돌한다. 왼쪽은 가벼운 면 없는 심볼인데 오른쪽만 채워진 큰 면이라 시선이 우측 버튼으로 쏠리고 "타일 제거"의 가벼움이 상쇄된다. 토스처럼 배경 없는 아웃라인 아이콘 버튼(회색 톤, IdCard stroke 1.7, 26px, 히트영역 40px 유지)이 더 어울린다. 각 안별 `*-ghostbtn.png`로 비교 캡처. (위치는 상단 오른쪽 유지, 더보기 이동 없음. 색 변경은 대표 결정 대상.)

## 권장: A 방패 S + 아웃라인 인증카드 아이콘
이유: ① 28px 이하에서 가장 선명하고 다크·라이트 모두 윤곽이 분명 ② "안전한 자산 관리" 브랜드 문구와 직결 ③ 브랜드 인디고(#5b6fbf) 계열이라 앱 색 체계와 일치 ④ 토스의 추상 곡면 심볼과 형태 겹침 없음 ⑤ 단순해 공식적. 차선 C(독창성 우선일 때).
적용 지점: `src/components/brand-symbol.tsx` 내부만 교체(BrandLockup 변경 없음). 대표 승인 후 developer 반영.
