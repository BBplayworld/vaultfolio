# 4.66 #125 UI r1 — 홈 상단 헤더 허전함·로고 중복 (ui-designer)

대표 지적: "상단 왼쪽 s 글씨만 있는 게 허전하고, s와 하단 왼쪽 홈 아이콘 중복 UI가 보인다."
대상: PR #126 커밋 17a9a96, 코드 수정 없음. 근거 캡처 `screenshots/ui-r1-before-{375,320,1280}-{light,dark}.png`(PWA standalone 에뮬레이션, ?trial=1).

## 1. 진단 (실측)
- 모바일 PWA 홈 맨 위 줄: 높이 40px, 왼쪽 `Logo` "S"(13×22 px, x=12,y=9)만 있고 오른쪽에 인증카드 40×40. 가운데가 텅 비어 "S 한 글자"만 떠 보임(허전).
- 하단 네비 홈 탭 아이콘도 같은 `Logo` "S"(20px, 인디고) → 화면 위·아래 양 끝에 같은 글리프가 동시에 보임(중복). 하단은 좌측이라 대각선 정렬까지 겹쳐 눈에 띔.
- PC PWA(1280)는 이미 로고를 숨겨(`.pwa-home-logo{display:none}`) 줄에 아이콘만 있어 같은 줄이 비어 보이는 문제는 있으나 중복은 없음.
- 같은 PWA의 상세·성과 허브는 본문 상단에 **h2 제목("상세"/"성과", `text-base sm:text-lg lg:text-2xl font-bold`) + 오른쪽 인증카드**를 쓴다. 홈만 이 패턴에서 벗어나 있음(제목 없음 + 로고).

## 2. 후보 비교
| 안 | 허전함 | 홈 탭과 중복 | 일관성 | 비고 |
|---|---|---|---|---|
| A 로고 제거만 | 더 허전(아이콘만 덩그러니) | 해소 | 낮음 | 기각 |
| B 로고+워드마크 "시크릿에셋" | 해소 | **S 글리프 중복 잔존** | 낮음(허브는 제목 구조) | 기각 |
| **C 로고 제거 + 화면 제목 "홈"(허브 h2와 동일 스타일)** | 해소(좌 제목·우 아이콘 대칭) | 해소(글리프 아님, 페이지 제목) | 높음(홈·상세·성과 모두 "제목 + 우측 인증카드") | **권장** |
| D 화면 제목 "내 자산" | 해소 | 해소 | 허브 제목이 탭명과 같은 규칙과 불일치 | 기각 |

## 3. 권장안 C — 사양
**적용 범위: standalone(PWA) 전용. 브라우저 모드는 diff 0**(브라우저는 하단 네비가 없어 로고가 브랜드 역할, [상세|성과] 선택기도 그대로).

변경 대상: `src/app/(main)/_components/header-menu/top-bar.tsx`(홈 분기 마크업), `src/app/globals.css`(standalone 규칙 2개). 신규 컴포넌트·토큰 0.

### 마크업 (top-bar.tsx, 홈 분기 `<>…</>` 안)
`pwa-home-logo` span 바로 뒤, `pwa-hide-actions` 래퍼 앞에 추가:
```tsx
<h2 className="pwa-home-title hidden text-base sm:text-lg lg:text-2xl font-bold text-foreground truncate min-w-0" data-testid="top-bar-home-title">홈</h2>
```
- 클래스는 `detail-hub.tsx`/`performance-hub.tsx` h2와 완전 동일(`text-balance`만 한 줄 제목이라 `truncate`로 대체).
- `hidden`은 기본(브라우저) 숨김, standalone에서 아래 CSS가 표시.
- 문구 "홈" 고정(신규 문구 0, 하단 탭 라벨과 동일). 투자 조언·금액 없음.

### CSS (globals.css)
기본(미디어 밖)은 `hidden` 유틸로 처리했으므로 규칙은 standalone 블록 안에만 추가:
```css
/* 홈 헤더(#4.66 r1): 하단 네비 홈 탭 로고와 중복 → 로고 숨기고 화면 제목 표시 */
.pwa-home-logo { display: none !important; }
.pwa-home-title { display: block !important; }
```
- 기존 `html[data-device="pc"] .pwa-home-logo{display:none}`는 위 규칙이 포괄하므로 삭제 가능(남겨도 무해).
- `.pwa-home-title`은 PC PWA에서도 표시(허브 h2가 PC에서도 보이는 것과 일치, `lg:text-2xl`=24px).

### 수치
| 항목 | 모바일 PWA(320·375) | PC PWA(1280) |
|---|---|---|
| 줄 높이 | 40px + safe-area (불변) | 44px (불변) |
| 제목 폰트 | 16px(`text-base`), sm(≥640) 18px | 24px(`lg:text-2xl`), bold |
| 제목 x | 12px (header `px-3`, 순자산 카드 왼쪽 끝과 일치) | `lg:px-12` = 48px (본문 카드 왼쪽 끝과 일치) |
| 제목 세로 | 줄 중앙(`items-center`) | 줄 중앙 |
| 제목 색 | `text-foreground`(라이트 #0a0a0a계/다크 화이트, 토큰 그대로) | 동일 |
| 인증카드 | 40×40 `MAIN_PALETTE[5]` 그대로, x=right 12px | 44×44 그대로 |
| 홈 첫 카드 top | 변화 0 | 변화 0 (margin-top 77px, padding 0.25rem 유지) |
- 줄 높이·margin·padding 불변이라 레이아웃 시프트 0. 세로 높이 증가 0.
- 320: "홈" 1글자라 줄바꿈 없음. `min-w-0 truncate` + 오른쪽 `shrink-0`이므로 폰트 확대(접근성 200%)에서도 아이콘 밀림 없음.
- 대비: 다크 `text-foreground`(흰색) on `bg-background`(블랙) ≥ 15:1. 라이트 동일 토큰 반전.

### 접근성·인터랙션
- `h2` 제목은 비인터랙티브(탭 불가, 홈 이동 버튼 아님 → 하단 홈 탭과 기능 중복 0).
- 스크린리더: 로고는 `aria-hidden`이라 기존에도 읽히지 않음 → 제목 "홈"이 첫 읽기 대상이 되어 개선.
- 모션: 없음(정적). 재마운트 영향 없음(TopBar 항상 마운트, 홈 분기 전환 시에만 교체).
- 홈 → 다른 화면: 홈 분기가 사라지고 뒤로가기 헤더/허브 제목으로 교체(기존 동작 불변).
- 웰컴/자산 0건: TopBar가 null → 영향 없음.

### 유지·금지
- 인증카드 상단 오른쪽 배치 유지. 더보기로 이동·앱→외부 내보내기 방향 사용 안 함.
- 브라우저 모드: 로고 + [상세|성과] 선택기 + 아이콘 그대로. 설치·더보기 `pwa-hide-actions` 그대로.

## 4. 체크리스트 (qa·ui-review 판정용)
1. 모바일 PWA 홈(375·320, 라이트·다크): `[data-testid=top-bar-logo]` 비표시(rect 0×0), `[data-testid=top-bar-home-title]` 표시, 텍스트 "홈".
2. 화면 위·아래 양쪽에 "S" 글리프가 동시에 보이지 않는다(상단 S 0, 하단 홈 탭 S 1).
3. 제목 x=12px(375/320), 순자산 카드 왼쪽 끝과 ±1px. 제목 세로 중심 = 인증카드 세로 중심 ±1px.
4. 제목 폰트 computed: 375에서 16px·700, 상세·성과 허브 h2와 font-size·weight·color 동일.
5. 헤더 높이 40px(+safe-area 0/47) 변화 0, 홈 첫 카드 top 변화 0(전 대비).
6. PC PWA 1280: 제목 표시(24px·700, x=48), 아이콘 44×44 우측, 상단 네비(73px)와 겹침 0, 줄 높이 44px 불변.
7. 브라우저 모드 375·1280: 로고·[상세|성과] 선택기·아이콘 diff 0, `top-bar-home-title` 비표시.
8. 인증카드 아이콘 히트영역 ≥ 40×40, 탭 시 대화상자 1개(기존 동작).
9. 320에서 제목·아이콘 겹침 0, 줄바꿈 0, 가로 스크롤 0.
10. 하단 네비 5칸(체험 3칸) 구성·홈 탭 로고(20px, 활성=인디고) 불변.
11. 체험(?trial=1) PWA에서도 제목 "홈" + 인증카드 표시.
12. 홈 → 상세 탭 전환 시 상세 허브 h2 "상세"만 보이고 "홈" 제목이 남지 않는다(분기 교체).
13. 콘솔 오류 0, 라이트·다크 모두 제목 가시.
