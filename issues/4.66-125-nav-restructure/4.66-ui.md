# 4.xx #125 하단 네비 개편 — ui (ui-designer)

기준: origin/main dc4133d. 신규 색·토큰·패턴 0 (design-system §6·§7 범위, `MAIN_PALETTE[0]`·`MENU_*` 재사용). 코드 수정 없음.

## 결론 (도구 섹션 순서 고정)
**세금 관리 → 인증카드 → 표로 복사** (COO #125 권고 채택).
근거: ① 기존·대표 채택 기능이 신규보다 앞, 신규(#124)는 말미라 반려·지연돼도 행 삭제만으로 순서 불변 ② 이동형(세금, 화면 전환) 다음에 출력형(이미지 → 표 복사)을 묶음 ③ 이미지 출력(인증카드)이 텍스트 복사보다 사용 맥락이 넓음. #124가 먼저 머지돼도 인증카드는 세금 관리와 표로 복사 사이에 끼워 넣는다(늦은 쪽이 merge 후 이 순서 적용).

## 1. 하단 5칸 (홈 · 상세 · [업데이트] · 성과 · 더보기)
- 컨테이너: `flex justify-around` → **`grid` 균등 칸(`grid-cols-5`, 체험은 `grid-cols-3`)** 로 변경. 칸 폭이 같아야 업데이트가 정확히 가운데(수학적 중앙). 기존 `min-w-[3.25rem]` 제거, 칸 `w-full`. 바깥 패딩 `px-2`, 하단 패딩·safe-area 불변.
- 폭: 375 → (375-16)/5 ≈ 71.8px, 320 → 60.8px (모두 ≥ 52px). PC PWA 상단 바(max 600px, 기존 CSS 불변) → 칸 ≈ 116px, 아이콘·라벨 가운데 정렬 유지, 좌우 쏠림 없음.
- 칸 내부(현행 유지): `flex-col items-center justify-center gap-0.5 min-h-[44px] py-1.5`, 라벨 `text-[11px] leading-tight`, 아이콘 `size-5` (홈은 Logo 20). 히트영역 = 칸 전체(≥60×44px, ≥40 충족).
- 업데이트 강조: 기존 `size-8 -mt-1 rounded-lg` brand 채움 + `PlusCircle size-5 text-white` 유지, 라벨 "업데이트" `text-muted-foreground font-medium`(액션이라 활성 색 없음). 크기 확대 없음(상단 바에서 높이 증가 방지).
- 활성 표시(불변): 아이콘+라벨 `MAIN_PALETTE[0]`, 아이콘 strokeWidth 2.5, 라벨 semibold. `getActiveId`·`PAGE_ORDER` 불변. 인증카드 칸 제거로 "눌러도 활성 없음" 칸이 업데이트 1개만 남음.
- 아이콘 import에서 `IdCard` 제거, `ShareScreenshotDialog`·`screenshotOpen` 상태·`screenshot-dialog-toggle` 발송은 bottom-nav에서 제거(더보기 행이 가져감, S1).
- 모션: 기존 `active:scale-95 duration-100`만. 신규 모션 0, 전환 없음.

## 3. 오탭 완화 — 불필요
3번째 칸이 성과→업데이트로 바뀌어도 결과는 시트가 열릴 뿐 데이터 변화 0, 닫기 1탭. 업데이트는 brand 채움 박스+가운데라 형태로 식별되고 성과(아이콘만)와 시각적으로 확연히 다름. 확인 단계·모션·툴팁 추가하지 않음(기존 사용자 학습은 위치가 아닌 라벨·모양 기준).

## 4. 체험 PWA 3칸
`isTrialMode()`면 업데이트·더보기 제외 → 홈·상세·성과, `grid-cols-3` 균등(375에서 ≈119px). 강조 버튼 없음, 활성 표시 동일. 인증카드 진입 없음(수용, challenge 3절). 빈 칸·쏠림 없음.

## 5. 상태·접근성
- 상태: 웰컴(자산 0·공유 대기) 네비 렌더 0(불변). 로딩/오류 UI 없음. 긴 문구 없음(라벨 최대 4자, 320에서 한 줄).
- a11y: 칸 `aria-label` 유지, 활성 칸 `aria-current="page"` 추가 권장, 키보드 포커스 `focus-visible` 링 기본값. 다크: 기존 토큰이라 대비 불변.
- 브라우저 모드: 네비 숨김 CSS 불변, 상단 바·FAB 무변경.
