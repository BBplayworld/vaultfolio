# 4.66 #125 하단 네비 정리 — spec v2 (인증카드 상단 통일, 권고 A)

작성: planner-designer 2026-11-09 · 기준 origin/main dc4133d, PR #126 82e5186 · 근거 `4.66-direction-v2.md`(A, 사업·경험 합의), `4.66-challenge-v2.md`(통과 조건부 V1~V8)
대체: `4.66-spec.md`(더보기 이동안)는 폐기. 위험 low · **대표 승인 대상**(위임 ⑦ 주 네비 구조 + 반려 이력 영역 재시도)

## 1. 문제
PWA 하단 6칸에서 강조 버튼 '업데이트'가 가운데가 아니고, 탭 순서가 스와이프 순서(홈→상세→성과→더보기)와 다르다. 핵심 기능인 인증카드는 PWA에서 회색 하단 5번째 칸에만 있다. 이 칸은 계측되지 않고, 위치도 브라우저(상단 오른쪽)와 다르다. 그래서 기능 팁 "상단의 인증카드 버튼"이 PWA에서는 사실이 아니다.

## 2. 목표 행동
- PWA 사용자가 하단 **가운데** '업데이트'로 업데이트 시트를 연다.
- 두 환경 모두 홈·상세 허브·주식·성과 허브·자산 변화에서 **맨 위 오른쪽** 인증카드 아이콘으로 대화상자를 연다.
- 어느 경로로 열어도 `feature_use` 1회와 `recordVisit("share-card")` 1회가 남는다.

## 3. 범위 (구현 방식 고정 — COO V1)
- **유지(#126)**: `bottom-nav.tsx` 5칸 grid(홈·상세·**업데이트**·성과·더보기), aria-current, 인증카드 칸·대화상자 제거. top-bar 버튼 클릭 시 `recordVisit("share-card")` 1줄. 5칸 정적 테스트(tool-menu 단언은 삭제).
- **되돌림(main diff 0)**: `tool-menu.tsx` 인증카드 행, `app-features.ts` 문구("상단의" 유지), KB의 더보기 행 기재
- **신규**
  1. 홈·주식·자산 변화: **기존 top-bar 헤더 인스턴스**를 standalone에서 보이게 한다(globals.css·top-bar 클래스 조정). 오른쪽 그룹에서는 인증카드만 보이고, 선택기·설치·설치 안내·더보기는 계속 숨긴다.
  2. 상세·성과 허브: h2 제목 블록 오른쪽에 **PWA 전용 발송 버튼**을 둔다. 이 버튼은 `dispatchOpenShareCard`만 호출하고 대화상자·리스너는 없다. 브라우저에서는 CSS로 숨기고, `data-tutorial`은 붙이지 않는다.
  3. top-bar 리스너의 출처를 `detail.source ?? "home_tip"`으로 받는 1줄 확장. 허브 버튼은 `top_bar`를 보낸다.
  4. 정적 테스트(V1)
- **금지**: 새 `ShareScreenshotButton`·`ShareScreenshotDialog` 인스턴스, 새 버튼 컴포넌트·대화상자, 더보기 인증카드 행, 콘텐츠 영역 버튼, 브라우저 화면 변경, `PAGE_ORDER`·튜토리얼·FAB 변경
- 시각 사양(홈 줄 높이·허브 아이콘 정렬·PC PWA 로고·배지 간격)은 ui-designer가 ui.md에서 정한다.

## 4. 사용자 흐름
1. PWA 모바일 홈: 맨 위 줄에 인증카드 아이콘이 있고(로고 표시는 ui.md에서 정함), 하단 5칸의 가운데 '업데이트'가 강조된다.
2. 가운데 탭 → 업데이트 시트(`open-add-asset-sheet`, 기존과 같음)
3. 홈 아이콘 탭 → 인증카드 대화상자(기본 카드 투자 유형) → 닫으면 홈 그대로
4. 하단 '상세' → 상세 허브 → 제목 줄 오른쪽 아이콘 탭 → 같은 대화상자. 성과 허브도 같다.
5. 상세 › 주식 / 성과 › 자산 변화 → 뒤로가기 헤더 오른쪽 아이콘 → 같은 대화상자
6. 그 밖의 화면(더보기·설정·배당·성적표·세금 등) → 하단 '홈' → 아이콘(2탭)
7. PC PWA: 상단 가로 5칸(최대 600px), 같은 순서. 아이콘 자리는 1~6과 같다.
8. 브라우저: 전과 같다(상단 바 아이콘, 더보기는 홈 맨 위 오른쪽).

## 5. 엣지 케이스
- **웰컴(자산 0·공유 대기)**: TopBar·BottomNav 모두 null이라 렌더 0. 허브 버튼도 자산 0건이면 숨긴다. #48·#113은 영향 없음.
- **체험 PWA**: 하단 3칸(홈·상세·성과)이고 빈 자리가 없다. 상단·허브 아이콘은 보인다(브라우저 체험과 같다).
- **safe-area 0 / 47**: 홈 첫 카드 top y 증가 ≤48px(V2). 기존 `pwa-show-header`를 그대로 쓰면 iOS에서 +64px이라 기준을 넘는다. 홈은 별도 규칙이 필요하다. 허브·하위 화면의 높이 증가는 0이다.
- **PC PWA**: 상단 5칸 네비(로고가 홈 칸) 바로 아래 홈 줄에 로고가 또 생긴다. 생략할지는 ui.md에서 정한다(차단 아님).
- **성적표 트로피 배지**: 홈 아이콘 바로 아래 순자산 카드 오른쪽 위에 조건부로 붙는다. 강조 두 개가 세로로 겹쳐 보이지 않는지 ui-review에서 스크린샷으로 확인한다.
- **기존 PWA 사용자 오탭**: 버튼 폭 기준 매핑(아래 표)대로 화면 이동이나 시트 열림만 일어나고, 데이터 변화는 0이다(C55).
- **첫 사용자·일부 갱신·오래된 데이터**: 표시 데이터 변경이 없어 무관하다.
- **홈 기능 팁**: 어느 경로로 열어도 share-card 방문이 기록돼 같은 팁을 다시 추천하지 않는다. 결산 팁이 먼저라 변하지 않는다(C38).

**C55 오탭 매핑(버튼 폭 기준, 옛 버튼 52px)**
| 폭 | 옛 칸(구간 px) | 새 칸 |
|---|---|---|
| 320 | 업데이트 164~216 | 190.4 왼쪽은 업데이트, **오른쪽 절반은 성과** |
| 375 | 성과 132~184 | 151.6까지 **상세**, 나머지 업데이트(시트 열림) |
| 375 | 업데이트 191~243 | 223.4~243 **성과**(약 38%) |
| 375 | 인증카드 251~303 | 성과, 295~303은 **더보기** |
나머지 칸은 같은 칸으로 간다. 모두 1탭으로 되돌릴 수 있다.

## 6. 인증카드 진입점 전수 대조표 (정본 = "맨 위 줄 오른쪽", 두 환경 공통)
| 진입점 | 브라우저 전→후 | PWA 전→후 | 열기 기록(후) |
|---|---|---|---|
| 상단 헤더 아이콘(홈·주식·자산 변화) | 있음→있음 | 숨김→**있음**(같은 인스턴스) | top_bar + visit |
| 허브 제목 줄 아이콘(상세·성과) | 상단 바 아이콘→그대로(발송 버튼 숨김) | 숨김→**발송 버튼** | top_bar(source 전달) + visit |
| 하단 칸 | — | 있음(미계측)→**없음** | — |
| 홈 기능 팁(share-card 3종) | 있음→있음 | 있음→있음 | home_tip + visit |
| 더보기 행 | 없음→없음 | 없음→없음(C57) | — |
| 튜토리얼 3단계 | 있음→있음 | 해당 없음 | — |
업데이트 진입은 PWA 하단 가운데가 정본(브라우저는 FAB)이다. 홈·상세·성과·더보기 장소 탭은 PWA 하단이 정본이고 스와이프는 유지한다. 새로 표시하는 지표는 없다.

## 7. 데이터 계약 (기존 키만, 스키마·저장 키·동기화·서버 전송 변경 0)
- GA: `feature_use { category: "share_card", method: "open", source: "top_bar" | "home_tip" }`. 둘 다 기존 허용 값이다. 새 GA 정의는 없다.
- 로컬: `recordVisit("share-card")` → 기존 `STORAGE_KEYS.featureUsage`(기기 로컬, sync 제외)
- 열기 1회당 기록 1회씩(V5): 상단 버튼은 onClick에서, 허브·홈 팁은 리스너에서 기록한다.
- 판독: 머지 시각을 STATE·DECISIONS에 '인증카드 열기 계측 경계'로 적는다(#51·#54 경계와 함께). '인증카드 열기'와 '열기 대비 저장'은 머지 후 절대값만 본다. 전후 비교는 '인증카드 저장'(전 경로 합산)과 업데이트 결과 사용자당 건수만 한다.

## 9. 대표 승인 요청 문안 초안 (🟥 양식)
- **무엇**: 앱을 설치해 쓰는 분의 하단 메뉴를 6칸에서 5칸(홈·상세·업데이트·성과·더보기)으로 정리합니다. '업데이트'를 가운데로 옮깁니다. 인증카드는 브라우저와 같은 '화면 맨 위 오른쪽' 아이콘으로 옮깁니다(홈·상세·주식·성과·자산 변화). 더보기는 지금처럼 설정 메뉴만 둡니다. 브라우저 화면은 바뀌지 않습니다.
- **왜**: 강조 버튼이 가운데가 아니고, 탭 순서가 좌우 넘김 순서와 다릅니다. 인증카드 자리가 환경마다 다르고, 앱에서 연 기록도 남지 않았습니다. 이번에 자리를 하나로 맞추고 기록도 남깁니다.
- **비용**
  - 앱에서 인증카드가 엄지 쪽 하단에서 위쪽으로 갑니다.
  - 위 5개 화면이 아닌 곳에서는 2번 눌러야 합니다(홈으로 간 뒤 아이콘).
  - 앱 홈 맨 위에 한 줄(48px 이하)이 생깁니다.
  - 예전 자리를 누르면 화면만 이동하고 데이터는 바뀌지 않습니다. 320px 화면에서는 옛 '업데이트' 자리의 오른쪽 절반을 누르면 '성과'로 갑니다.
  - 실기기 앱에서는 아직 확인하지 않았습니다(에뮬레이션으로만 확인).
- **대안**: 하단 유지를 원하시면 `수정: 하단 유지`로 답해 주세요. 하단은 홈·상세·업데이트·성과·인증카드로 두고, 더보기는 앱 홈 맨 위 오른쪽(브라우저와 같은 자리)으로 옮겨 다시 작업합니다. 이 경우 스와이프 순서도 고쳐야 해서 작업 범위가 커집니다.
- **위험**: 낮음. 저장 데이터·동기화와 관계없고, 되돌릴 때는 PR을 되돌리면 됩니다. **결정**: 머지하면 반영, 닫으면 미반영입니다.
