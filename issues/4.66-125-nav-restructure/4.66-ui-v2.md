## 2. PWA 홈 맨 위 줄 (V2 ≤48px)
기존 `pwa-show-header`를 쓰지 않는다(+64px 문제). 홈 전용 헤더 모드 `pwa-home-header`(top-bar가 `view.type === "home"`일 때 header에 부여)를 둔다.
- 모바일 PWA (`@media (display-mode: standalone)`)
  - `header.pwa-home-header`: `display:flex !important; margin-top:0 !important; padding-top: env(safe-area-inset-top,0px); height: calc(2.5rem + env(safe-area-inset-top,0px))`. 줄 본체 40px = 아이콘 높이.
  - `header.pwa-home-header + [data-content-area]`: `padding-top: 0.25rem !important`(4px). 브라우저에서 아이콘 하단~카드 간격(48px 줄 안 4px)과 같다.
  - 홈 첫 카드 top = 40 + sa + 4. 기존 = max(24, sa).
  - 증가량: sa=0 → 44−24 = **+20px**, sa=47 → 91−47 = **+44px**. 둘 다 ≤48(여유 4px).
- 줄 내용: 왼쪽 `Logo size 22`(`text-foreground`, 기존 마크업 그대로), 오른쪽 인증카드 버튼. 상세/성과 `InlineSelector`는 `pwa-hide-actions` 래퍼로 감싸 standalone에서 숨김(하단 네비와 중복). 설치·설치 안내·더보기는 기존 `pwa-hide-actions` 컨테이너 안에 그대로 두어 계속 숨김(V3).
- 좌우: 기존 `px-3 lg:px-12`. 로고 왼쪽 끝 = 순자산 카드 왼쪽 끝, 아이콘 오른쪽 끝 = 카드 오른쪽 끝(±1px).
- **PC PWA** (`html[data-device="pc"]`, 상단 네비 65px 고정)
  - 상단 네비 안에 로고가 이미 홈 칸이므로 **줄의 로고는 숨긴다**(`.pwa-home-logo`를 PC PWA에서 `display:none`). 오른쪽 아이콘만 남는다.
  - `header.pwa-home-header`: `margin-top: calc(65px + 0.25rem); height: 2.5rem; padding-top:0`. 다음 `[data-content-area]` `padding-top: 0.5rem`.
  - 홈 첫 카드 top = 69+40+8 = 117, 기존 85 → **+32px**.
  - 줄 안 아이콘이 본문 최대폭 오른쪽 끝과 어긋나지 않게, 헤더 안쪽 컨테이너는 기존 `px-3 lg:px-12` 유지. 어긋나면 ui-review에서 수정 요청.
- 다크/라이트: 토큰 동일, 헤더 `bg-background`.

## 3. 상세·성과 허브 제목 줄 (높이 0)
현 구조 `<div><h2/><p/></div>`(h2 24px + mt-0.5 2px + p 20px = 46px).
- 변경: 이 div를 `flex items-start justify-between gap-3`으로 바꾸고, 왼쪽 `min-w-0 flex-1`에 기존 h2·p를 그대로, 오른쪽에 발송 전용 버튼 1개.
- 버튼 40px < 블록 46px이므로 1줄 부제 기준 높이 변화 0. 부제가 버튼 폭(52px)만큼 좁아져 줄 수가 늘 수 있는 화면(상세 부제 약 300px)은 qa가 측정한다. 늘면 `gap-3 → gap-2`로 줄이고, 그래도 늘면 ui-review에서 문구 변경 없이 부제에 `pr` 대신 버튼 `-mb-3`(부제 첫 줄과 겹치지 않는 범위)로 조정 요청. 브라우저는 버튼이 `display:none`이라 부제 폭도 변화 0.
- 버튼: top-bar `ICON_BTN` 상수를 export해 재사용, `style={{backgroundColor: MAIN_PALETTE[5]}}`, `aria-label="인증카드"`, `title="인증카드"`. `data-tutorial` 없음(V4). 클릭 시 `dispatchOpenShareCard(undefined, "top_bar")`만 호출(대화상자·리스너 없음, 열기는 헤더 인스턴스).
- 표시 규칙: CSS 클래스 `pwa-only-action`(globals: 기본 `display:none`, standalone에서 `display:inline-flex`), 자산 0건이면 렌더하지 않음(`hasAnyAssets`).
- 신규 컴포넌트 0: 두 허브에 같은 짧은 `<button>` 인라인. 중복이 신경 쓰이면 developer가 10줄 헬퍼로 묶고 components.md에 등록(범위 판단은 developer).
- 모션: 허브 루트의 기존 `animate-in fade-in slide-in-from-bottom-3`에 버튼이 포함돼 따로 모션 없음. 헤더는 항상 마운트라 재마운트로 모션이 사라질 일 없음.

## 4. 주식·자산 변화 (기존 PWA 뒤로가기 헤더)
- 헤더는 이미 `pwa-show-header`(높이 48+sa). 오른쪽 컨테이너를 둘로 분리: ① 설치·설치 안내·더보기 = `pwa-hide-actions` 유지 ② `ShareScreenshotButton` = 그 밖(숨김 해제). 버튼 40px가 48px 줄에 세로 중앙.
- 높이·뒤로가기 영역 변화 0. 제목이 길어도 왼쪽 `min-w-0 truncate`가 먼저 줄어든다(오른쪽 `shrink-0`).
- 홈/허브/주식/변화 외 화면(settings, 부동산 등)은 `showShare` false라 변화 없음.
- **인스턴스 1개 유지(V1)**: `ShareScreenshotButton`(+Dialog)은 top-bar 1곳. 홈·주식·변화는 이 인스턴스를 보이게 하는 것뿐이고 허브는 CSS로 가려진 채 리스너 역할만 한다.

## 5. 트로피 배지 겹침
- 배지는 순자산 카드 **안쪽** `absolute top-2 right-2`(36px 내외). 아이콘은 카드 **바깥** 위 줄(카드 상단 4px 위에서 끝남). 서로 겹치는 영역 0: 아이콘 하단 → 카드 상단 4px → 배지 상단 8px = 세로 12px 떨어짐.
