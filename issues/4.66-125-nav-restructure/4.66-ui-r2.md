# 4.66 #125 UI r2 — 홈 상단 왼쪽 '공식 서비스' 락업 (ui-designer)

대표 2차 지적: R1 "홈" 텍스트 제목이 UI적으로 어색. 없거나 공식 아이콘적 요소, Official 느낌 필요. (1차 유지: 상단 S 허전 + 하단 홈 아이콘과 S 중복)
대상: PR #126 94e54ec, 코드 수정 없음. 캡처: `screenshots/ui-r2-option-*.png` (preview 375, 라이트·다크, standalone 에뮬 + DOM 주입).

## 1. 브랜드 자산 조사
- 앱 아이콘 `public/icons/icon-192x192.png`(512도 있음, manifest·홈화면 아이콘): **검정 그라디언트 둥근 사각 + 흰 필기체 S**. 대표가 홈 화면에서 보는 "공식 얼굴"이 이것.
- `Logo` 컴포넌트(Leckerli One "S" 글리프)는 텍스트 글리프라 단독으로는 약함(파비콘 동일 서체). 워드마크 별도 자산 없음 → 브랜드명은 `APP_CONFIG.name`("시크릿에셋") 시스템 폰트 bold.

## 3. 확정안 — 브랜드 락업 + 하단 홈 탭 표준 아이콘
**한 줄: 상단 왼쪽 = 앱 아이콘 타일(32px, r8) + "시크릿에셋" 워드마크(bold 18px), 하단 홈 탭 = lucide `Home` 표준 아이콘.**

### 3-1. 신규 컴포넌트 `src/components/brand-lockup.tsx` (`BrandLockup`)
```tsx
<span className="flex items-center gap-2 min-w-0 text-foreground" data-testid="top-bar-brand">
  <img src="/icons/icon-192x192.png" alt="" width={32} height={32}
       className="size-8 rounded-lg shrink-0 ring-1 ring-foreground/10" />
  <span className="pwa-home-wordmark hidden text-lg lg:text-xl font-bold tracking-tight whitespace-nowrap truncate">{APP_CONFIG.name}</span>
</span>
```
- 타일 32×32, `rounded-lg`(8px, 우측 인증카드 버튼 `rounded-lg`와 동일 radius), `ring-1 ring-foreground/10`로 다크에서 검정 타일 윤곽(그림자 대신 헤어라인, 아이콘 이미지 outline 규약 §6). alt 빈값(장식, 워드마크가 이름 제공). 별도 aria-label 불필요.
- 워드마크: 18px/700, `tracking-tight`(-0.025em), `text-foreground`. 1280(`lg`): 20px. 줄바꿈 금지.
- 타일-워드마크 gap 8px(`gap-2`). 전체 높이 32 < 줄 높이 40 → 줄·카드 위치 변화 0. 좌측 x=12(헤더 `px-3`) 유지, 순자산 카드 왼쪽 끝과 일치.
- 비인터랙티브(탭 불가 → 하단 홈 탭과 기능 중복 0).

### 3-2. `top-bar.tsx` 홈 분기
- `pwa-home-logo` span + `<Logo size=22>` + R1의 `h2.pwa-home-title`("홈")을 **`<BrandLockup />` 하나로 교체**. `Logo`·`pwa-home-title`·`top-bar-home-title`·`top-bar-logo` 제거.
- **브라우저 모드**: 타일(32px)만 노출, 워드마크 `hidden` 유지 → 기존 S 글리프(13×22)를 같은 자리에서 앱 아이콘으로 교체(브랜드 심볼 일관). [상세|성과] 선택기 `ml-3` 그대로. 375에서 폭 +19px뿐이라 설치·인증카드·더보기와 겹침 없음(구현 후 320 확인 필수).
- 인증카드: **상단 오른쪽 유지, 40×40 `MAIN_PALETTE[5]` 청록 채움 `rounded-lg` 그대로 변경 없음.** 균형 판단: 타일 32 vs 버튼 40은 8px 차이지만 radius 동일·좌우 모두 둥근 사각이라 시각 균형 양호. 톤다운(`bg-muted`) 대안(`option-A-tonal`)도 렌더했으나, 상세·성과 허브 인증카드 버튼(청록)과 PWA 안에서 색이 갈라져 **기각(일관성 우선)**. 사양 변경 없음.

### 3-3. `globals.css`
- standalone 블록: R1의 `.pwa-home-logo{display:none}`·`.pwa-home-title{display:block}` 삭제 → `.pwa-home-wordmark { display:block !important }` 추가. 기본(브라우저)은 `hidden`.
- PC PWA(1280): 줄 44px·margin-top 불변. 타일 32 + 워드마크 20px, x=48(`lg:px-12`). 상단 NAV 홈 칸도 House라 중복 없음.

### 3-4. `bottom-nav.tsx`
- 홈 탭의 `Logo` 특수 분기 삭제 → 다른 탭과 동일 렌더: `<Icon className="size-5 transition-colors" style={isActive?{color:MAIN_PALETTE[0]}:undefined} strokeWidth={isActive?2.5:2}/>` (`Home` 아이콘은 이미 NAV_ITEMS에 있음). `Logo` import 제거. 라벨·testId(`bottom-nav-home`) 불변.
- 효과: 위=앱 아이콘+이름, 아래=표준 집 아이콘 → 같은 글리프 중복 0 (`option-A-tile-*-nav.png`).

## 4. 상태·접근성
- 로딩/빈/오류: 정적 이미지·텍스트. 웰컴(자산 0)은 TopBar null → 영향 0. 체험(?trial=1) 동일 노출.
- 320: 타일 32 + 워드마크 ~86px(18px) + 인증카드 40 → 약 170px, 여유 충분. 폰트 200% 확대 시 `truncate`+우측 `shrink-0`로 아이콘 밀림 없음.
- 다크: 타일이 검정이라 `ring-foreground/10`으로 윤곽 확보(캡처 확인). 라이트: 타일 검정이 대비 최대. 워드마크 `text-foreground` 대비 ≥15:1.
- 모션 없음. 스크린샷 캡처 대상 아님(`data-screenshot-hide` 불필요).
