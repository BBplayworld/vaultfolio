## 3. 정의 (한 정의 = 한 벌)
- **오른 해(A2·A3 공통)**: A1과 같다. `view.ret > 0`(소수 2자리 반올림 값), 그 밖은 내린 해.
- **A2 기준 4종** — PatternSection과 **같은 함수**(`classifyDelta(rateDelta(d,"us",y−1,y))`, `spreadNegMonths(d,y,"a")`, `blsYear`)를 쓴다. 해의 범위 = 기준 자료와 그 지수 연간 등락이 모두 있는 해. 각 기준의 행은 배타이고 행 n 합 = 그 열의 전체 해 수(테스트).
  1. 금리(미 연준 목표, 범위면 상단): 전년 12월 말→그해 12월 말 Δ, |Δ|<0.25%p 거의 그대로, ≥+0.25 올라간, ≤−0.25 내려간. **1983~**(월 금리 1982-09 시작).
  2. 물가: CPI 연평균 전년 대비(저장값 소수 1자리) ≥ 4.0 / 그 밖. 1961~2024(2025 `—`).
  3. 실업률: 연평균(저장값 소수 1자리)이 전년보다 큼 / 그 밖(같음 포함). 1962~2024.
  4. 금리차: 10년−2년 월평균이 0 미만인 달 ≥1 / 없음. 1976~(1976-06 시작, PatternSection과 같은 처리).
- **A2 검산(S&P·나스닥·코스피, 셀 = n해 중 k해)**: 금리 올라간 16·11 / 15·12 / 16·11, 내려간 18·14 / 16·12 / 18·12, 거의 그대로 9·8 / 9·9 / 9·6 · 물가 4% 이상 22·15 / 7·5 / 9·5, 그 밖 42·32 / 32·27 / 34·23 · 실업률 오른 19·13 / 11·7 / 12·6, 그 밖 44·33 / 28·25 / 31·22 · 금리차 있던 14·10 / 9·6 / 10·5, 없던 36·28 / 31·27 / 34·24. S&P 금리 n(16/18/9)은 머리 l3·PatternSection L3와 같아야 한다.
- **A3**: 구간 = `d.rec` 9개(`s`=NBER 고점 다음 달, `e`=저점 달). 전해 = `s`의 해−1, 시작 해 = `s`의 해, 끝난 다음 해 = `e`의 해+1. 값 = 그해 연간 등락, 없거나 마지막 해 뒤면 `—`. 검산: 2008-01~2009-06 S&P +3.5%·−38.5%·+12.8%, 나스닥 +18.7%·−41.9%·+19.2% / 2001-04~11 나스닥 −36.8%·−32.7%·−37.6% / 1960-05~1961-02 S&P `—`·`—`·−11.8%.
- **A6**: N = 기간 카드의 `ey−sy`. 시작 해 = 지수 시작 해 ~ `last−N`(개수 n). 해마다 평균 = 기간 카드 `periodResult().lumpCagr`와 같은 함수(소수 1자리, 부호 +/−). 손실 = `lumpMult < 1`(반올림 전). 검산: S&P 10년 56개 −3.0~+16.0% 7개, 20년 46개 +2.7~+13.9% 0개, 나스닥 5년 36개 −15.3~+55.8% 5개, 코스피 10년 35개 −4.7~+21.8% 6개.
- **B1**: Y = 현재 주식(상장폐지·수량 0 제외) 중 유효한 `purchaseDate`의 가장 이른 해. 칩을 누르면 `sy = Y−1`(=Y년 초), `ey = last`. 기기 안 계산만, 저장·전송·GA 값 0.
- **B2**: y = 주식 X-Ray **지역 축과 같은 계산**(`groupStocksByTicker→mergeStockGroup→computeBreakdown("region")`, `formatBreakdownPct`)의 `한국` 항목 %, x = 100 − y(소수 1자리). 분류는 기기 캐시 읽기만(수집 요청 0). 노출 조건은 `holdingSplit` 선례(기기 안 판정)와 같다. 누르면 `setInitialAxis("region")` 후 상세·주식 X-Ray. `holdingSplit` 값은 화면에 쓰지 않는다(X-Ray와 다른 값이 되므로).
- **G2 표**: 시작 = `last−5k`(k=1~5, 현재 2000·2005·2010·2015·2020년 말), 끝 = `last` 말. 값 = 기간 카드 `periodResult`의 `lumpMult`·`dcaMult`(소수 2자리). 검산: S&P 2015 3.35/2.01(기간 카드 10년과 같음), 2000 5.18/4.02 · 나스닥 2010 11.38/4.60.
