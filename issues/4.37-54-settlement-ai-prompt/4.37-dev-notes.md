## scale 전환 조사 (수정 안 함, 범위 밖)
- 빌드 CSS 확인: `active:…:scale-[0.96]` → `scale:.96`(CSS scale 속성). `transition-[color,box-shadow,transform]`은 `transition-property: color,box-shadow,transform`이라 scale을 보간하지 않음(즉시 변경). v4 `transition-transform`은 `transform,translate,scale,rotate`라 해당 없음
- `scale-[0.9x]`와 `transition-[…transform]`이 같이 쓰인 곳 9곳: 공용 `components/ui/button.tsx`(모든 Button 누름), `toggle.tsx`, `inline-selector.tsx`, `kpi-card.tsx`, `welcome-guide.tsx`(보안 토글), `attribution-records.tsx`, `pwa-guide-illustrations.tsx`, `asset-report-view.tsx`, `settlement-view.tsx`(MonthArrow·prep-stale-row). 고치려면 각 전환 목록에 `scale` 추가 — 별도 정리 과제 후보
