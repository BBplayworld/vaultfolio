## 2. 절세 시뮬 '(추정)' (참고 2)
- 통과. UI 코드 변경은 0이다. tax-utils의 `estimated`에 partialRate를 OR로 더했을 뿐이고, 표시는 기존 `c.estimated && <span className="ml-1 text-xs font-medium text-muted-foreground">(추정)</span>`를 그대로 쓴다. 섞인 AAPL·7203·QQQ의 span 클래스와 색이 통제군 MSFT와 같다(라이트 oklch(0.45 0 0), 다크 oklch(0.74 0.016 265)).

- **경미(기록, 수정 요청 아님)**: 긴 이름 9자리 손익 QQQ 행은 320~334(라이트·다크 같음)에서 '(추정)'이 새로 붙으면서 `보유 1,555.568주` 줄이 2줄이 되어 +16px 늘어난다. 기존 후보 행 레이아웃이 원래 그렇게 동작하고(main에서도 추정 종목이면 같다) 극단 픽스처라 의도된 증가 구간으로 적는다. 후보 행 메타 줄 nowrap 정리는 별도 후보로 남긴다.
