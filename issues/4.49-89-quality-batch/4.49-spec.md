## 4. 사용자 흐름
1. 상세·성과·설정·결산 어디서든 ⓘ 주변(아이콘 둘레 약 13px 안)을 탭 → 팝오버가 열림. 데스크톱 hover 동작 그대로.
2. 성과 › 배당에서 월 막대 탭 → 배지 'N월 · 전체 보기 ×' 표시, 차트 위치 그대로 → 배지 탭(또는 Enter) → 전체로 복귀, 위치 그대로.
3. 더보기 › 설정(다크) → 다크 모드 행 ON 배지가 색으로 보임 → 탭해 라이트로 → OFF/ON 라이트 외형 main과 동일.
4. 320 화면 상세 › 주식 → 억 단위 손익 종목도 이름·수량과 금액·손익이 겹치지 않음.
5. 홈 또는 상세 허브 FAB → 과거 순자산 → 성과 › 기간별 변화 › 전체 › 연 탭으로 이동하며 추가 입력창이 1회 열림.

## 5. 엣지 케이스
- ① 힌트 옆에 다른 버튼이 붙은 곳(배당 제목 옆 월 배지 gap 8px, 원인 행 '추정' 배지): 확장 영역이 이웃 버튼을 덮으면 안 됨 — 이웃 버튼 중심 좌표 탭은 이웃 동작.
- ① 다이얼로그 안(`inModal`), 인증카드 캡처(`data-screenshot-hide`) 경로 외형 불변.
- ② 320에서 배지가 제목 옆에 안 들어가면 다음 줄 고정 높이 영역에 두되, 배지 없을 때도 같은 높이(흔들림 0).
- ④ 이름이 한 어절로 긴 종목(공백 없음): 어절 보존 원칙이 넘침을 만들면 2줄 말줄임 유지(가로 스크롤 0 우선). 거래정지·상장폐지 배지 동반, 외화 종목, 금액 가리기(maskFn) 상태.
- ④ 빈 데이터(주식 0): 행 없음, 변화 없음.
- ⑤ 이동 후 사용자가 마운트 전에 다른 화면으로 가면 요청은 버려지고, 나중에 연 탭을 직접 열어도 입력창이 저절로 열리지 않음. 연타(2회) 시 입력창 1개.
- ⑤ 첫 사용자(연도별 순자산 0건)·체험 모드(FAB 미표시)·연 탭 데이터 부족 상태에서도 동작 동일.
