## ④ 수정 요청 (320 다크, 억 단위 픽스처)
측정(이름 보이는 글자수 / 이름 폭 / 행 높이 / 수량 줄바꿈):
- 320 라이트: main 3자/줄(77px, 수량 2줄) -> PR 4자/줄, 2줄 합 약 7자, 폭 59px, 행 63.5, 수량 1줄. 통과.
- 320 다크: main 1자/줄+겹침(77) -> PR **3자/줄(삼성전/자, 가나다/라마…), 폭 46px, 합 5~6자, 행 77, 수량 `5,000`/`주` 2줄로 깨짐**. 목표(7자 이상, 수량 1줄) 미달.
- 원인: 다크는 카드 안쪽 패딩으로 행 내용폭이 256px(라이트 288). 우측 열이 `max-sm:max-w-[58%]`로 상한에 걸려 우측 폭 148px(=58%)인데, 손익 줄은 두 줄로 접혀 실제 필요 폭은 금액 최장 약 112px뿐이라 여유 36px가 낭비됨. 좌측이 46px로 눌림.
- 수정(파일 `src/app/(main)/_components/views/detail/tabs/stock-tab.tsx` StockRowHeader, 비 screenshotMode 가산 문자열만): 우측 열 `max-sm:max-w-[58%]` -> `max-sm:max-w-[48%]` 근처로 낮춰 우측 폭 약 123~138px(금액 112px 수용), 좌측 폭 약 75px 이상(이름 5자/줄, 2줄 합 약 10자). 375(우측 상한 약 150~165px): 일반 행 손익 줄 142px 한 줄 유지되어 높이 Δ0여야 하므로 재검수에서 375 일반 행 높이·320 라이트 재측정. 값은 developer가 48~50% 사이에서 조정하되 판정 기준은: 320 다크 이름 합 7자 이상, 수량 한 줄, 375 일반 행 높이 main 동일, 좌우 겹침 0.
