## ① InfoHint 히트영역 40px (`layout/ui/info-hint.tsx`)
- 방식: **래퍼 없이 버튼에 투명 `after` 확장**(레이아웃 폭 불변이라 외형·정렬 Δ0). 아이콘 14px(모바일)·16px(sm+).
- 버튼 className 끝에 추가:
  `relative pointer-coarse:after:absolute pointer-coarse:after:content-[''] pointer-coarse:after:-inset-[13px] sm:pointer-coarse:after:-inset-3`
  (14+26=40, 16+24=40). **터치 기기(pointer: coarse)에서만 확장** → 데스크톱 마우스는 hover 팝오버가 40px 영역에서 오작동하지 않음(hover 영역 Δ0). 데스크톱 터치 노트북은 coarse로 잡혀 확장됨(정상).
- 아이콘·색·`inline-flex items-center`·팝오버 Δ0. 포커스 링은 기존 전역 규약 유지(추가 없음).
- **이웃 겹침 규칙**: 확장 영역은 non-positioned 이웃 위에 그려지므로, 힌트 이웃에 **인터랙티브 요소가 있으면 그 요소에 `relative z-10`** 을 준다(이웃 중심 탭=이웃 동작). 비인터랙티브 텍스트/배지는 덮여도 무방(탭하면 힌트가 열리는 정도, 동작 손실 0).
- 사용처별:
  | 사용처 | 이웃 | 조치 |
  |---|---|---|
  | 배당 제목(dividend-chart) | 월 배지(버튼) | ②로 배지를 제목 줄에서 분리 → 이웃 없음. 배지에 `relative z-10`도 유지 |
  | 결산 원인 행(change-hero) `gap-1.5` | '추정' 배지(span, 비인터랙티브) | 조치 없음. **change-hero.tsx diff 0** |
  | 설정 '기간 수익 종가 기준'(settings-page)·profit-chart | 라벨 텍스트 | 없음 |
  | 성적표 제목(asset-report-view) | 'Plus' 배지(span) | 없음 |
  | 보유 X-Ray 집중도(stock-xray-view) | 인접 컨트롤 확인 필요 | 개발 시 인접 button 있으면 `relative z-10` |
  | FAB 시트(floating-add-button, inModal) | 문장 텍스트 | 없음. 시트 가장자리 12px collisionPadding 내 |
  | 부동산 입력(real-estate-input) | 폼 라벨 | 없음 |
- 세로 확장(±13px)이 윗/아랫 행의 **버튼**을 덮는 경우(결산 원인 행 사이 간격 ≥ 행 높이라 해당 없음, 설정 카드 `space-y-2`의 InlineSelector 위 8px): 설정 '표시' 카드에서 힌트 하단 확장 13px이 아래 InlineSelector 상단 5px와 겹침 → InlineSelector 래퍼에 `relative z-10`(settings-page, 개발 시 확인).
- 캡처 경로: 결산 원인 행의 `data-screenshot-hide` 래퍼 유지, 확장은 투명이라 캡처 외형 Δ0.

## ② 배당 헤더 월 배지 (`activity/dividend-chart.tsx` 230~250행 영역)
구조(위→아래, 좌측 열 `space-y-1.5 min-w-0` 유지):
1. 제목 줄: `<div className="flex items-center gap-2">` — `CardTitle`에 `shrink-0 whitespace-nowrap` 추가(320에서 '배당' 1줄 고정), `InfoHint`. **배지는 여기서 제거.**
2. 배지/설명 공용 슬롯(신규): `<div className="grid min-h-6 items-center [&>*]:[grid-area:1/1]" data-testid="dividend-sub-slot">`
   - `CardDescription`('보유 주식 기준 올해 배당금'): 월 선택 시 `invisible`, 선택 해제 시 보임(레이아웃에 남아 높이 유지, 320 2줄이어도 높이 동일).
   - 배지(월 선택 시만 렌더): `justify-self-start`.
   → 슬롯 높이 = max(설명, 24px) 고정이라 선택·해제 시 차트 top Δ0(320·375·1280). 슬롯 min-h-6으로 미선택 상태가 기존 대비 최대 +4px(1회성, 흔들림 아님).
- 배지 = 버튼 의미: `<Badge asChild variant="outline"><button type="button" data-testid="dividend-month-badge" onClick=…>`
  className: `h-6 cursor-pointer overflow-visible relative text-xs px-2.5 after:absolute after:-inset-y-2 after:inset-x-0 after:content-[''] z-10 hover:bg-accent focus-visible:border-brand focus-visible:ring-[3px] focus-visible:ring-brand/40 motion-safe:transition-[transform,background-color,box-shadow] motion-safe:active:scale-[0.96] motion-safe:animate-in motion-safe:fade-in motion-safe:duration-150`
  - 히트 24+16=**40px**(`overflow-visible`로 Badge 기본 overflow-hidden 해제), 가로는 배지 폭(≥ 90px).
  - 접근 이름 = 보이는 문구 'N월 · 전체 보기 ×'(aria-label 추가 금지: 문구 0 원칙). 키보드: Tab 포커스 → brand 링 3px → Enter/Space 해제. 해제 후 포커스는 사라진 배지 대신 body로 가므로 변화 없음(허용).
  - 문구·`text-xs`·outline 외형 Δ0. 긴 문구 대비: `whitespace-nowrap`(Badge 기본), 좌측 열 폭 ≥ 배지 폭(320에서 ~160px vs ~105px).
- 셀렉터 영역(`opacity-40 pointer-events-none`)·Hero·차트 Δ0.

## ④ 320 주식 행 (`detail/tabs/stock-tab.tsx` StockRowHeader, `!screenshotMode` 한정)
정책: 우측 열 폭 상한 + 손익 줄 필요 시에만 줄바꿈. screenshotMode(웰컴·인증카드) 클래스 문자열은 **한 글자도 바꾸지 않는다**(`screenshotMode ? "" : " …"` 가산 방식).
- 우측 열(330행 `cardInfoRight`): `${ASSET_THEME.cardInfoRight}` + 비스크린샷 `" max-sm:max-w-[58%]"`. (320 내용폭≈252px → 우측 ≤146px, 좌측 ≥106px ≈ 이름 7자 이상. 요구 ≥4자 충족)
- 손익 줄(`cardAmountProfitRow`): 비스크린샷 `" max-sm:flex-wrap max-sm:justify-end"`; 금액·(%) 두 span에 `whitespace-nowrap`. 한 줄에 들어가면 지금과 동일, 넘칠 때만 [금액]/[(%)] 두 줄(우측 정렬, 행 gap 유지).
  - 판정: 375 일반(+1,234,567원 (+12.3%) ≈142px < 190px 상한) 한 줄 → **행 높이 Δ0**. 320 억 단위(+265,417,500원 (+43.0%) ≈166px > 146px) 두 줄 → 행 높이 +약 18px(rv4 ≤78 → 약 ≤96, 칩 포함 4줄 상한). 의도된 증가.
- 이름(nameCls span): 비스크린샷에 `break-keep [overflow-wrap:anywhere]` 추가(어절 단위 줄바꿈, 공백 없는 긴 이름만 글자 단위 폴백) — `line-clamp-2`·`max-sm:line-clamp-1`(상태 배지 동반) 유지. 가로 스크롤 0.
- 1280(sm+): 접두사가 `max-sm:`라 Δ0. 금액 가리기(•••) 상태: 짧아 한 줄. 외화/거래정지 배지: 기존 규칙.
- testid: 우측 열 `data-testid="stock-row-right"`, 좌측 `stock-row-left`(qa 박스 겹침 판정용; 마크업 diff는 속성뿐).
