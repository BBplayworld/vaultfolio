## (1) 방향 검토 — 새 필드 없이 가능, 결산 잔차 = 국내와 같음
**A. 새 필드 0 확인.** 거래 `exchangeRate`(optional, 동기화 압축 `asset-storage.ts:771`·복원 938에 이미 있음), 짝 기록은 기존 KRW `CashTransaction`·`LoanTransaction` + id 규칙 `ctx_/ltx_link_<거래 id>` 그대로. 타입·zod·저장 키·동기화·공유 토큰 diff 0 → 마이그레이션 불필요. `LinkTrade`(메모리 전용 인터페이스)에 `exchangeRate?` 추가는 저장 형식이 아니다.

**B. 필수 구현 규칙(어기면 qa FAIL).**
- **환산은 저장되는 거래 자체에서 계산한다**: `stockLinkTrade(t)`가 `t.exchangeRate`를 넘기고 `buildLink`가 그것으로 원화 금액을 낸다. 폼 미리보기 따로, 저장 따로 계산 금지(evaluateLink도 같은 buildLink).
- **환산 배수는 엔진의 `tradeKrwRate`(asset-report.ts:941) 하나를 export해 재사용**(JPY = 원/100엔 ÷ 100). change-hero 인라인 식과 같은 결과여야 하며 사본 3번째 금지.
- **원화 금액 = roundMoney((수량×단가 ± 수수료) × 배수, "KRW")** — USD 0.01 반올림을 먼저 하지 않는다(중간 반올림 시 엔진과 최대 약 7원 차, 미리 반올림 없으면 ≤ 0.5원).
- **환율 채움은 buildTransaction에서 보장**: 외화 거래 + 원화 계좌·대출 연결이면 `exchangeRate`가 비었거나 0일 때 현재 환율(USD 원/$, JPY 원/100엔)로 채워 저장. 화면 setValue만으로는 부족(사용자가 칸을 지우고 저장하는 경우). 현재 환율도 0·미수신이면 사유 `rate`로 저장 차단(문구는 ui).
- 계좌 선택 시 칸이 비었으면 현재 환율을 칸에 채워 보이게 한다(수정 가능). `연결 안 함`으로 되돌려도 채운 값은 그대로 둔다(되돌림 분기 추가 안 함 — 사용자가 본 값).
- `evaluateLink`·`linkPreviewText`의 표시 통화 = **선택 계좌 통화**(지금은 거래 통화로 고정 — 그대로 두면 원화 계좌에 `$` 표시).

**C. 결산·홈 짝 잔차.** 엔진 id 짝 = `min(기록 KRW, 거래 수량×단가×tradeKrwRate)`. 체결 환율이 채워져 있으므로 두 값의 차이는 **수수료 몫 + 반올림 ≤ 0.5원**뿐이고, 수수료 몫은 v4.58 국내 연결과 같은 동작이다(새 잔차 유형 0). 환율을 비워 두면 엔진이 현재 환율로 다시 계산해 날마다 잔차가 생기므로 B의 채움이 필수 조건이다. 엔진 코드(change-hero·asset-report) 로직 수정 0 — `tradeKrwRate` export 1줄만 허용.

**D. 부수 효과(qa 회귀 항목, 의도된 변화로 수용).**
- 가중평균 환율(`trade-utils.ts:75`): 원화 연결 매수만 '빈 환율 = 기존 평균 유지'에서 '채운 환율 반영'으로. 실제 돈이 그 환율로 나갔으므로 더 맞다. 첫 매수(평균 0)는 오히려 개선.
- 양도세 추정(`tax-utils.ts:127`): 원화 연결 매도는 `estimated` 표시가 빠지고 저장 시점 환율로 고정. 계좌에 들어온 원화와 같은 환율이라 일관.
- 연결 없는 외화 거래·국내 거래·코인: 동작 diff 0.

## (2) 첫 매수 티커 경로 — **제외**
거래 입력은 보유 종목만 고를 수 있고 처음 사는 티커는 보유 현황으로 먼저 등록해야 한다. 이는 **국내·해외 공통의 입력 경로 결손**이지 통화 축 문제가 아니며, 거래 폼 안 티커 검색·신규 종목 생성은 새 기능이다. 보유 현황 등록에 연결을 붙이면 앱 도입 시 '이미 가진 종목 옮겨 적기'에서 현금이 이중 차감된다. → #119 범위 밖, spec 알려진 한계에 1줄, 별도 후보('첫 매수를 거래로 기록')로 STATE 후보 목록에 올린다(C49 판정은 그 기획에서).

## (3) 외화 대출 — **포함**
대출은 원화 고정이라 원화 현금과 같은 환산 분기 하나를 쓴다(오히려 `currency` 거부 분기가 사라짐). 픽스처 +2(USD 매수 대출 증가, USD 매도 상환). 일정이 밀리면 **첫 번째 축소 대상**(후보에서 외화 거래의 대출만 다시 제외).

## (4) 숨김 시 안내 1줄 — **지난달 거래일 때만 포함**
연결 후보가 있는데 거래일이 이번 달이 아니어서 행을 숨기는 경우에만 muted 1줄(뜻: 지난달 거래는 계좌 잔액을 함께 바꾸지 않음, 문구 ui-designer, 금지어 규칙 동일, `연동`·`자동` 금지). 공용 LinkAccountRow라 국내·코인에도 같이 나온다(일관, 추가 비용 0). 즉시 반영 끔(토글이 바로 위)·현금·대출 계좌 0개(고를 것 없음)는 숨김 유지. 미리보기는 줄을 늘리지 않고 **기존 보조 줄 문구를 환산식으로 바꾼다**(예: `$1,234.56 × 1,385원만큼 현금이 줄어요 (수수료 포함)`), 360px 1~2줄.
