# 4.97 UI 검수 (간이) — 배당 조회 실패 안내 1줄
대상: head b823a40 preview, `/api/finance/dividend*` 500 가로채기. 캡처: screenshots/ui-hub-{320,375}-dark.png, ui-div-{320,375}-dark.png

- 위치·위계: 성과 허브 배당 카드는 "0원" 아래, 배당 탭은 부제 아래에 1줄. text-sm muted(숫자·제목보다 약함), 주변 여백 정상(허브 카드 내부 간격·탭 헤더~빈 카드 24px). 통과.
- C25: 375는 2줄("다음에 열면 / 다시 불러올게요" 어절 단위), 320 허브 3줄·탭 2줄. break-keep+text-pretty로 어절 중간 끊김·고아 글자 없음. 통과.
- design-system: market-compare-view:339 클래스 재사용, 신규 토큰 0, 상태색(빨강/파랑) 미사용. 통과.
- 라이트 캡처: 이 앱은 class 테마라 colorScheme 에뮬레이션이 적용되지 않아 라이트 1장 미획득(토큰 muted-foreground라 대비 동일 계열, 위험 낮음).
- 비차단 관찰(수정 요청 아님): (1) 실패 시 허브에 "0원"이 그대로 보여 안내문과 함께 읽힘. (2) 배당 탭은 실패 안내 아래 빈 카드가 "배당금이 없거나 KIS API가 설정되지 않았습니다"라고 따로 말해 원인 안내가 이중. 둘 다 전체 실패 시 한정이라 이번 릴리스 범위 밖, 후속 후보.

## f38a3a2 재검수
대상: preview ?demo=1, 다크, `/api/finance/dividend*` 500 주입(전부 / NVDA 1종목), 320·375. 캡처: screenshots/ui-r2-{all,one}-{hub,tab}-{320,375}.png (fullPage)

- '—' 패턴: 전부 실패 시 허브 배당 카드 primary가 `—`(muted-foreground, 안내문과 같은 톤). market-compare-view의 미확정 `—`(text-muted-foreground)와 같은 계열이며 상태색(빨강/파랑) 없음. 큰 숫자 대신 muted 대시라 "0원"으로 오독될 여지 해소. 통과.
- 배당 탭 안내만: 전부 실패 시 제목·부제·토글 아래 안내 1줄만 남고 푸터가 바로 이어짐(빈 카드 없음). 위계는 제목(배당)>부제>안내 순으로 유지, 안내가 부제와 같은 좌측 정렬·16px 여백 안에 있어 어색한 빈 영역은 없음. 단 375에서 안내 아래~푸터 사이 정보가 없어 화면 하단 절반이 비어 있음(푸터 하단 고정 아님, 앱의 다른 빈 탭과 동일 구조) — 비차단.
- 1종목 실패: 허브 합계 162,315원(지급·예상 보조줄)+안내 1줄, 탭은 성공 종목 카드·차트+안내 1줄. 정상.
- C25: 문구 2줄, 어절 단위(320: "…종목이 / 있어요. 앱을 다시 열면 / 다시 불러올게요" 허브 3줄·탭 2줄, 375: 2줄). 가로 넘침 0, 고아 글자 없음. 통과.
- 요청 수 6 = 종목 수 6(재요청 루프 없음). 라이트 미촬영(이전과 동일 사유, 토큰 동일).
