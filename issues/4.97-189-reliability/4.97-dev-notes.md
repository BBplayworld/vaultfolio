## qa FAIL 수정 (재요청 루프)
- 원인(코드 확정): `fetchDividend` throw 후 실패 쿼리는 status=error·data 없음. `dividend-chart`가 `!isLoading && annualTotal>0`일 때만 `MonthlyDividendStocks`(같은 queryKey 관찰자)를 마운트하는데, 새 관찰자가 마운트되면 retryOnMount 기본값 true로 재조회 → react-query가 data 없는 쿼리의 fetch 시작 시 status를 pending으로 되돌림 → `isLoading` true → 로딩 뷰로 전환되며 관찰자 언마운트 → 실패 → 다시 마운트 → 재조회 무한 반복. 기존엔 실패가 `[]` 성공이라 발생하지 않았음.
- 수정: `dividendQueryOptions`(dividend-client.ts)로 3곳 옵션 통일, `retryOnMount:false` 추가(실패 쿼리는 마운트로 재조회 안 함, 새 진입 시에는 gc 후 1회). 로딩 판정은 그대로 pending+fetching이며 루프가 끊겨 부분 실패 시 성공 종목 표시 + 안내 1줄.
- 테스트: `dividend-client.test.ts` — QueryObserver 재마운트 5회 × 3종목(1개 KIS 불가)에서 fetch 수 = 3, 실패 쿼리 error·data undefined.
- 점검: 다른 useQueries(`use-market-compare.ts`)는 로딩 뷰로 관찰자를 언마운트하는 구조가 아니라 대상 아님(기본 retryOnMount 유지, 미변경). 서버 route 불변.
