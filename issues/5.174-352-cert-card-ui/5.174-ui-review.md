## 375 제어 바 2줄 판단 — **현 상태 수용 안 함, 아래 대안으로 1줄 유지**
- 실측: 브랜치는 320~382에서 2줄. 375 제어 바 높이 **main 32px → 브랜치 92px(+60px)**(dev-notes의 +48은 1줄 44 기준). 2줄째에 복사·저장 두 버튼만 오른쪽에 떠 있어 왼쪽이 비고(`rv-bar-after-*-375.png`), 주식 현황은 금액 표시 줄까지 3줄이라 카드 첫 화면이 그만큼 내려간다. 증가 원인은 히트 40을 **시각 크기**로 해결한 것(타입 칸 40·트랙 44, 아이콘·저장 40). design-system §7은 `after:` 확장으로 시각 크기를 지키는 것을 허용·권장하고(정렬 트리거 `h-8 after:-inset-y-1`, GrowKindTabs `min-h-8 after:-inset-y-1`), 1280에서도 트랙 44·버튼 40으로 높이가 4px 어긋난다(`rv-type-after-light-1280.png`).
- 라벨 숨김 없이 가능한 대안(권장, 시뮬레이션 `rv-alt-E-sim-dark-375.png`): **시각은 main과 같게(행 32px), 히트만 40으로**
  - 타입 선택 `className`: `[&>button]:min-h-10` → `[&>button]:min-h-7 [&>button]:relative [&>button]:after:absolute [&>button]:after:inset-x-0 [&>button]:after:-inset-y-1.5` (칸 28 + 6×2 = 40, 트랙 32)

  - `저장/공유`: `h-10 px-3 …` → `relative h-8 px-3 text-sm gap-1.5 after:absolute after:-inset-y-1` (66×40 히트)
  - 제어 바 행: `gap-x-3` → `gap-x-2`
  - 결과(측정): 한 줄 필요 폭 332.4 → 320.4px, **1줄 시작 폭 384 → 372**(375 여유 4.6px), 1줄 높이 44 → 32(main과 동일). 히트 확장은 바 `py-2`(8px) 안에 들어감. 320~370은 2줄 유지(정상, 라벨 그대로).

## 확인 결과(통과)
- **테마 전환**: 라이트·다크 모두 실제로 전환됨(쿠키 강제). 개발자 캡처의 "라이트도 어둡다"는 캡처 방법 문제이지 앱 결함 아님.
- **범례 %**: 인증카드 주식 현황·포트폴리오(도넛 라벨·분야·보유 유형) 전부 `text-foreground` — 라이트 17.84 / 다크 17.52:1(main 라이트 1.95~3.53). 상세 › 주식 범례도 같은 처리(라이트 17.84, main 2.71~4.19), `그 외` %는 muted 그대로(6.64/8.43). 상세·인증카드 모두 이름 regular + % bold 같은 색 → 일관(`rv-detail-legend-*.png`).
- **쪽지 글자**: 6색 전부 검정, 5.31(퍼플)~9.60:1(main 흰 글자 2.19~3.96). 회전·압정 배치 불변(`rv-tags-*.png`).
- **스위치·아이콘**: 스위치 checked `rgb(91,111,191)` = brand, 저장 버튼과 같은 색. 라벨 40px 높이, 라벨 오른쪽 끝 클릭으로 토글 확인. 제목 아이콘 brand.
- **포커스**: 열면 제목 `인증카드`(H2)에 포커스(링 없음, 정상), Tab → 투자 유형 → 주식 현황 → 포트폴리오 → 이미지 복사 → 저장 → 닫기 → 다시 투자 유형, 밖으로 0회(main은 홈 요소로 이탈). 타입 칸 포커스 표시는 브라우저 기본 outline(InlineSelector 기본 경로 기존 동작, 범위 밖).

- **R32**: 3종 × 2테마 저장 PNG가 375와 1280에서 바이트 동일(브랜치·main 모두).
- **PNG diff(main 대비, 375)**: 투자 유형 = 부제 칩 + 쪽지 6개, 주식 현황 = 범례 % 3줄, 포트폴리오 = 도넛 라벨 6개 + 분야·보유 유형 범례 %. 그 밖 픽셀 차이 0(`rv-png-diff-*.png`, 자홍 = 차이). 압정 색 동일(팔레트 참조 치환 무손실). ceo.md 4 목록과 일치(8종목 이상 그 외 색은 데모 6종목이라 미노출).
