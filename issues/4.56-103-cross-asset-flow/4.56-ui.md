## 1. 홈 '지난 접속 이후' 원인 목록 (dashboard.tsx:298-340, 접힘 영역 안)
컴포넌트 트리(위→아래, 모두 기존): 구간 라벨 `rangeLabel`(text-xs) → 원인 `ul` → **[신규 1줄] 캡션** → `AttributionRecordList`.
- 원인 `ul`: 구조·타이포 변경 0 (`w-full max-w-xs space-y-0.5`, 라벨 text-sm foreground / 금액 text-sm semibold tabular-nums 손익색). 상쇄 후 항목이 줄어들 뿐.
- 캡션: `<p data-testid="home-cause-offset-caption" className="mt-1.5 text-xs text-muted-foreground break-keep text-pretty leading-relaxed max-w-xs">자산 사이에 옮긴 돈은 원인에서 뺐어요</p>`
  - 위치 = 원인 `ul` 바로 아래(원인과 한 덩어리로 읽힘), 기록 목록 위. `rangeLabel`과 같은 text-xs muted(메타 캡션 역할, §2). 굵기·색 강조 없음(§11 muted+semibold 금지). 금액·아이콘·툴팁 없음. 투명도 `/NN` 금지(안내 문장, 라이트 대비).
  - 조건: 상쇄 합 ≥ 1만일 때만. `screenshotMode`에서도 원인과 함께 표시(원인 목록이 보이므로 문맥 필요), `data-screenshot-hide` 아님.
  - 높이: 12px×1.5 = 18px 1줄. 19자 ≈ 215px라 320·375 모두 1줄(`max-w-xs`=320 이내, 320뷰포트 컨텐츠 288px < ... 215px OK). 1280도 같은 `max-w-xs` 좌정렬. 컷 사유 없음 → **유지**(컷 기준: 320에서 2줄이 되면 뺌 — 현 문구는 해당 없음).
- 상쇄 후 모습 (S1b/S4b/S5b, 시세 +5% 가정; 375, 접힘 펼친 상태):
  ```
  ▲ +105만원 (+x.x%) 지난 접속(11/8) 이후 ⌄
  11/8 → 11/9
  주식 시세 상승            +105만원
  자산 사이에 옮긴 돈은 원인에서 뺐어요
  [기록 목록: 주식 매수 / 현금 출금 등 그대로]
  ```
  S4b `주식 시세 상승 +85만원`, S5b `+75만원`. 부분 상쇄는 `기록 안 된 변화 +40만원` 행(날짜 없음, 목록 맨 아래, 금액 손익색) + 캡션. 단방향(상쇄 0)은 캡션 없음.
- 폭: 320(컨텐츠 ≈288) / 375(≈343) / 1280(max-w-xs 320 좌정렬). 라벨 `break-keep` 유지, `기록 안 된 변화`(8자)+금액 `+1,234만원`은 320에서 한 줄(≈190px). 2줄 필요 없음. C35: 행 수가 줄거나 같고 캡션 +18px만 증가 → 폭×금액(수십만·수백만·억) 표에서 행 높이 증가 = 캡션 18px 한 가지뿐이 의도.
- 모션: 기존 chevron 펼침 그대로. 캡션은 목록과 같이 나타나며 별도 모션 없음(재마운트로 사라질 모션 없음).
- 접근성: 캡션은 일반 `p`(스크린리더가 목록 뒤에 읽음). 다크 대비 muted-foreground 기존 토큰(rangeLabel과 동일).
- 문구 최종: `자산 사이에 옮긴 돈은 원인에서 뺐어요`. 남는 몫 라벨 `기록 안 된 변화`(결산과 동일). 투자 조언·금액 없음.

## 2. 거래 입력 '연결 계좌' 행 (대표 결정 ②+③, 구 B' 교체)
대상: `trade-input.tsx`(주식)·`crypto-tx-input.tsx`(코인) 수동 폼. 위치 = `보유 수량에 즉시 반영` 행 박스(`FormItem rounded-lg bg-muted/40 dark:bg-muted/20 p-3`) **바로 아래 별도 박스**(같은 마크업), 포지션 미리보기 위.
순서: 즉시 반영 → **연결 계좌** → (4.52 경고) → (오류) → 포지션 변경 미리보기 → 버튼.
- 재사용만: 즉시 반영 박스 마크업, 기본 `Select`(cash-tx-input.tsx:170과 동일 Trigger·radius lg), 오류 박스(포지션 oversell과 동일), 4.52 경고. 신규 컴포넌트·토큰·색 0.
- **1행 구조(360 유지)**: `flex items-center gap-2` — 좌 라벨 `연결 계좌`(text-sm font-medium, shrink-0 whitespace-nowrap, ≈56px) / 우 `Select`(flex-1 min-w-0, 값 `truncate`). 박스 높이 ≈ 60px(Select 36 + p-3). 320(컨텐츠 288)에서도 Select ≈ 224px로 `연결 안 함`·계좌명 1행 유지.
- **선택지 = 1개 Select, 그룹 구분**: `연결 안 함`(기본, 맨 위) / 그룹 `현금 계좌`(같은 통화 계좌명) / 그룹 `대출`(원화 거래일 때만). 그룹 라벨은 기존 `SelectGroup/SelectLabel` text-xs muted. 항목에 잔액 미표기(1행·truncate 유지, 잔액은 미리보기에서). 그룹이 비면 그 그룹만 숨김, **둘 다 비면 행 자체 숨김**. 통화 다른 계좌는 목록에 없음(설명 문구 불필요).
- 노출: 즉시 반영 ✓ + 수동 입력 신규 거래. 숨김: 즉시 반영 해제(값은 `연결 안 함`으로 리셋), 스크린샷 가져오기·보유 맞추기·미반영 저장·거래 수정(수정 화면 없음). 껐다 켜도 `연결 안 함`(기억 저장 없음). 종목·통화 변경 시 선택 계좌가 목록에 없으면 `연결 안 함`으로 복귀.
- **잔액 미리보기**(`cash-link-preview`): 연결 선택 + 금액 입력 시에만, 같은 박스 안 Select 행 아래 `mt-2 text-sm tabular-nums` 1줄. 확장 `grid-rows-[0fr→1fr] motion-safe:transition-[grid-template-rows,opacity] duration-300`, 항상 마운트·`inert`·`invisible`(§6 높이 펼침). 연타·방향 전환 시 값만 바뀜(재마운트 0), reduced-motion 즉시.
  - 매수·현금(감소): `{계좌명} 1,000만원 → 900만원` / 매도·현금(증가): `… → 1,100만원`
  - 매수·대출(증가): `{대출명} 3,000만원 → 3,100만원` / 매도·대출(상환): `… → 2,900만원`. 화살표 muted, 후 값 semibold. 금액식 = 수량×단가 ± 수수료(거래 통화), 외화는 `$`.
  - 보조 1줄(text-xs muted, 미리보기 아래): 현금 `거래 금액만큼 현금이 줄어요|늘어요`, 대출 매수 `대출이 늘어요`, 대출 매도 `대출이 줄어요`. 수수료 있으면 `(수수료 포함)`. `break-keep text-pretty`.
- 4.52 경고(연결 선택 + `shouldWarnTxAfterResync` 참): **기존 마크업 그대로 재사용**(`data-testid="tx-after-resync-warning"`, `AlertCircle` + important 주황, text-sm break-keep text-pretty, 기존 `resyncWarningText` — 현금/대출 종류만 전달), 연결 계좌 박스 바로 아래. 차단 아님. **문구 정정(qa F3)**: 입출금 폼의 `…체크를 꺼 주세요`는 거래 폼에 체크박스가 아니라 선택 행이라 오해되므로, 연결 행에서는 끝맺음만 바꾼 `{M월 D일에|오늘} 맞춘 {현금|대출} 잔액에 이미 들어간 금액이면 연결 안 함으로 바꿔 주세요`(구현 `linkResyncWarningText`, 입출금 폼은 기존 문구 유지).
- **오류(저장 차단, 거래·짝 기록·잔액 전부 미저장)**: oversell 박스와 동일 `rounded-lg bg-destructive/10 dark:bg-destructive/20 p-3 text-sm text-destructive font-medium break-keep text-pretty`, `role="alert"`, 입력 중 실시간 + 제출 시 동일 차단(버튼 비활성화 아님, 기존 패턴).
  - 현금 부족(매수): `{계좌명} 잔액이 부족해요. 다른 계좌를 고르거나 연결 안 함으로 저장해 주세요.` testid `cash-link-error`
  - 대출 초과 상환(매도 > 대출 잔액): `{대출명} 잔액보다 많이 갚을 수 없어요. 다른 계좌를 고르거나 연결 안 함으로 저장해 주세요.` testid `loan-link-error` (분할 상환 없음)
  - 잔액 전액 매수 차단(zero, cto 5-6): `{계좌명} 잔액을 0원으로 둘 수 없어요. 연결 안 함으로 저장하거나 맞추기로 잔액을 고쳐 주세요.` testid `cash-link-error`, 위치·클래스·`role="alert"`·저장 차단 동일(현금 매수만, 대출 무관).
  - 연결 대금 0 이하(수수료가 매도 대금 이상 등, spec 3-L 6-1): `연결할 금액이 0원 이하예요. 수수료를 확인하거나 연결 안 함으로 저장해 주세요.` testid `cash-link-error`(현금·대출 공통 재사용, 새 testId 0), 같은 위치(연결 계좌 박스 아래, 4.52 경고 다음)·클래스·`role="alert"`, 실시간+제출 차단 동일. 이 오류가 있으면 잔액 미리보기는 숨기고 부족·초과 오류와는 동시 표시하지 않는다(대금 오류 우선). 연결 안 함이면 오류 없음. 체크리스트 9번에 포함.
- 중복 거래 다이얼로그: 문구 변경 0, '추가'도 같은 연결 적용.
- **저장 토스트**(`toast.success` 한 문자열, 2문장 `duration=3000`): `매수|매도 거래가 기록되었습니다. 현금 기록도 남겼어요` / 대출 연결 `… 대출 기록도 남겼어요`. 연결 안 함은 기존 토스트 그대로. 액션 버튼 없음.
- 접근성: Select `aria-label="연결 계좌"`, 오류 `role="alert"`, 미리보기 `aria-live="polite"`. 키보드: Tab 즉시 반영 → 연결 계좌 Select(방향키·Enter) → 수량. 히트영역: 박스 전체 ≈60px로 40px 충족. 다크: 박스 `dark:bg-muted/20`, 오류 destructive/20, 경고 기존 important 주황.
- GA: 금액·계좌명 없음, 현금·대출 구분도 보내지 않음(spec 3-L 12).

## 3. 거래 삭제 확인 — 되돌림 1줄 (구 3절 교체)
삭제 후 토스트 변경 없음(아래 한 문장 예외). 확인 **다이얼로그 안 1줄**(결정 전에 읽힘):
- 주식 `DeleteRollbackDialog`(delete-rollback-dialog.tsx) `삭제 시 자동 롤백` 박스(`bg-muted/30 p-3`) 아래 `space-y-3` 슬롯, 코인 `crypto-tx-view.tsx` 모달도 같은 위치·클래스: `<p data-testid="delete-linked-record-note" className="text-sm text-muted-foreground break-keep text-pretty">`
  - 현금: `연결된 현금 기록도 함께 지워져요. {계좌명} 잔액 +100만원`(매수 삭제 = 현금 복구) / 매도 삭제는 `-100만원`
  - 대출: `연결된 대출 기록도 함께 지워져요. {대출명} 잔액 -100만원`(매수 삭제 = 대출 감소) / 매도 삭제는 `+100만원`
  - 부호는 계좌 잔액 증감 기준, 손익색 없음(muted 안내), 금액 `tabular-nums`.
- **하한 0 꼬리(cto 5-5 ①)**: 되돌림이 *감소 방향*(매도 삭제의 현금 입금 되돌림 / 매수 삭제의 대출 증가 되돌림)이고 되돌릴 금액 > 현재 잔액이라 0에 걸릴 때만, 같은 `<p>` 안(testid 동일)에서 금액을 **실제 줄어드는 값(= 현재 잔액)** 으로 보이고 문장 끝에 꼬리를 붙인다. 표시 = 저장 결과(같은 `removeLink` 계산).
  - 현금: `연결된 현금 기록도 함께 지워져요. {계좌명} 잔액 -150만원, 잔액이 부족해 1원만 남아요`(현금 하한 1원, cto 5-6)
  - 대출: `연결된 대출 기록도 함께 지워져요. {대출명} 잔액 -150만원, 남은 대출보다 커서 0원이 돼요`
  - 이미 하한이면 금액 대신 현금 `{계좌명} 잔액은 더 줄지 않아요`, 대출 `{대출명} 잔액은 이미 0원이에요`(꼬리 생략; `이미 0원이에요`는 대출만). 증가 방향(매수 삭제의 현금 복구·매도 삭제의 대출 복구)은 하한이 없어 꼬리 없음. 기본 색 muted 유지(경고색·아이콘 없음), 다른 기록은 지우지 않음. 새 testId 0, `break-keep text-pretty`로 2줄 허용(320에서 다이얼로그 스크롤 0). 금지어(spec 3-L 11)·금액 예시 규칙은 실제 계산값이라 해당 없음.
- 조건: 짝 기록(`ctx_link_<id>`/`ltx_link_<id>`)이 **실제로 존재**할 때만. 이미 없으면 안내 없음(거래만 삭제). 연결 없는 거래 다이얼로그는 현행 그대로. 연결 거래는 항상 반영 거래라 다이얼로그를 반드시 거침.
- 확인 후 삭제 토스트: 되돌림이 있었으면 기존 문구 뒤 `연결된 현금|대출 기록도 지웠어요` 한 문장 추가(한 문자열, 3000ms). 없으면 현행.
- 높이 +20~40px(2줄 가능), 320에서 스크롤 없이 전체 보임. 짝 기록을 따로 지워 연결이 풀린 거래는 UI 표시 0.
