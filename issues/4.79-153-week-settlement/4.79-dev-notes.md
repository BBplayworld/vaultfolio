## 4. spec·tech-review와 다른 점·보고 사항
1. **GA `source`는 GA로 나가지 않는다**(ga.ts 머리 주석 — page_title만 전송, source는 제목 결정용 내부 값). spec 5-5·12절의 '`source:home_tip`으로 구분'은 불가. 팁 진입 1건은 `source:"home_tip"`을 호출에 넣었지만 직접 진입과 GA에서 구분되지 않는다(허용 목록엔 `home_tip` 있음). 구분이 필요하면 별도 category(`change_week_all_tip`) 필요 — cto 판단.
2. **5-4 전제 확인**: `buildLiveAttributionCurr`의 순자산은 `summary.netAsset` 그대로이고 홈 Hero(`NetAssetSummaryBox netAsset={summary.netAsset}`)와 주 탭 `change-hero-end`가 같은 `getAssetSummary()` 값이다. 테스트(원 단위 `data-value` 대조)로 고정. 시작 `data-value` = 날짜별 마감 기록 fromDate 행(원 단위) 일치도 테스트.
3. **visitKey**: `viewToKey`는 `init`을 무시하므로 target만으론 `activity:change`와 같은 키 → `visitKey:"change-week"`로 분리(미기록 키라 `change` 방문 집계에 안 섞임). 테스트로 고정.
4. **종목 등락 보기 1주**: 시장과 비교 목록 기간은 `useState("weekly")` 로컬 기본값이라 저장 구조가 없다 → 저장 기간 불변 문제 없음, `rememberChangeInit`만 호출.
5. **T12 '현금 등록 + 짝 없는 매수 = 순유입 양수'는 성립하지 않는다**. 홈 Hero 항목이 이미 `unrecorded`(+1,440,000)로 나온다(짝 없는 매수 + 풀 상쇄 잔여 1e-10 부동소수 잡음 때문에 상쇄 경로로 들어가 `buy:stock`이 `unrecorded`로 합쳐짐 — 기존 Hero 동작, 이번에 안 고침). B = Hero 합산이므로 `기록 안 된 변화`. 테스트는 이 실제값을 단언(Hero와 같음이 정본). 순유입은 입금·출금 기록과 Hero가 `buy:*`/`sell:*`로 남기는 경우에만.
6. 비교 시작일이 월 표기(`YYYY-MM`)이면 D·`M/D 이후`는 `windowFrom`(실제 기록일)을 쓴다(spec은 `fromDate`). 월 스냅샷이 14일 안이면 `M/D 이후` 표기가 정확해지는 방향의 보정.
7. pct: 시작이 0 이하면 홈은 0%, 주 탭은 % 생략(null). 홈과 같은 식은 시작 > 0일 때만 해당.
8. 접힘 카드는 기록이 오늘 것뿐이어도 rows가 있으면 `week-insufficient`일 때 보이고, `week-empty`(attr=null)일 때만 숨김.
