## 수정 요청
1. **[필수] `날짜별 마감 기록` 캡션 어절 중간 줄바꿈** — `asset-change-view.tsx` WeekClosingCard `<p className="text-sm text-muted-foreground text-pretty">`. 375에서 `다를 수 있/어요`로 어절 중간 분리(ur-week-open-375-*). 기대: `break-keep` 추가(`text-pretty` 유지) → `...조금 다를 수 / 있어요`처럼 어절 단위. 체크리스트 9(C25) 위반.
2. **[필수] 320 마감 행 금액의 `원` 단독 줄바꿈** — 같은 파일 `week-row`. 320에서 `660,983,823/원`, `+4,183,823/원`으로 단위가 떨어지고 날짜도 `11/11/(수)`로 갈라져 행이 2줄이 된다(ur-week-open-320-*). 기대: 금액 두 span `whitespace-nowrap`, 전일 대비 열 `w-24` 고정 → `shrink-0 min-w-24`, 날짜 span은 `min-w-0`(줄바꿈 허용은 날짜 쪽만). 그래도 320에서 한 줄이 안 되면 전일 대비가 마감 순자산 아래 우측 정렬 2줄로 떨어지는 것까지 허용(단위 분리만 금지). 375·1280은 현 상태 OK.
3. **[필수] 기록 내역 펼침 시 제목 잘림 (developer 지적 건 판정: 수정 필요)** — `week-records` 래퍼 `min-w-0 flex-1`가 `종목 등락 보기`(≈110px)와 한 줄을 나눠 펼침 목록이 약 197px(375)·≈142px(320)만 쓴다. 날짜 44+라벨+금액을 빼면 `truncate` 제목이 375에서 ≈35px, 320에서 거의 0 → 제목이 사실상 사라져 홈 Hero 펼침과 정보량이 달라진다. 또 링크가 펼친 목록 오른쪽 위에 떠 있어 어색하다. 기대: 래퍼에 `has-[[aria-expanded=true]]:basis-full`(펼치면 전폭, 링크는 `flex-wrap`+`ml-auto`로 목록 아래 오른쪽) — `AttributionRecordList` 자체는 수정하지 않는다. 데모에는 기록 내역이 없어 실측 불가 → qa가 기록이 있는 데이터로 375·320 펼침 확인(제목 ≥ 8자 보임, 링크는 목록 아래 오른쪽).
