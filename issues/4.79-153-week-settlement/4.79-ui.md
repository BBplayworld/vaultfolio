# 4.79 #153 최근 7일 변화 원인(주 탭) — UI 사양 (ui-designer, 2026-11-11)

기준: design-system §1~§7·§11, components.md(ChangeHero·ChangeHeroFrame·CauseBlock·AttributionRecordList·MonthlyLogBlock), spec 사전 초안(4.79-spec.md), LEARNINGS(대표 UI 피로도 — 새 패턴 최소).
한계: 이 사양은 코드·문서 기반이다. 운영 데모 실측 스크린샷은 찍지 않았다(ui-review에서 375·1280 × 라이트·다크 실측). 신규 토큰·신규 컴포넌트 패턴 0.

## 0. 판정 요약
| 항목 | 판정 |
|---|---|
| O-5 제목 | **`이번 주` 폐기 → `최근 7일`.** 달력 주(월~오늘)로 읽혀 수요일에 7일치 숫자가 나오면 어긋난다. 탭 이름 `주`는 그대로. spec 5-2·6·8-1 문구 변경(아래 2절) |
| 배치 | 기존 월 결산과 같은 순서·같은 컴포넌트(`CauseBlock` scope=`week`). 6줄 고정 순서, 0원 줄 숨김 |
| 날짜별 마감 기록 | `MonthlyLogBlock`과 같은 `SECTION`+`Table2` 헤더 행 접힘, 기본 접힘, 항상 마운트 grid-rows |
| 연결 줄 | 시세 줄 아래가 아니라 **원인 블록 맨 아래 한 줄**(기록 내역과 같은 줄 오른쪽). 라벨 `종목 등락 보기` |
| 신규 기능 팁 | 1종. `market-compare` isNew 내림 |
| 새 패턴 | 0. `CauseBlock`에 scope `week`·footer 슬롯 추가, 접힘 카드는 기존 패턴 복제 |

## 1. 화면 구성 (전체 자산 › 주, 위→아래)
1. 헤더 `자산 변화` + 범위 선택 — 변경 없음
2. `ChangeHeroFrame`(재사용, 기간 선택 노드 유지) 안 Hero: `ChangeHero` 재사용
3. **변화 원인** `CauseBlock scope="week"` (수정) — `SECTION`+`BODY_ENTER`, 40ms stagger 그대로
   - 줄(SpecRow): 시세 변동 → 평가 갱신 → 환율 효과 → 순유입 → 대출 → 기록 안 된 변화. 0원 줄 없음
   - 푸터 행(신규 슬롯): 왼쪽 `AttributionRecordList`(재사용, 기록 있을 때만) / 오른쪽 `종목 등락 보기 ›`(주식 보유 시만)
4. **날짜별 마감 기록** 접힘 카드(신규 조립, 기존 패턴): 기본 접힘, 펼치면 기존 `week-row` 7행 그대로
5. 구성 블록·AI 행 등 주 탭에 없던 것은 추가하지 않는다

## 2. Hero 표기 (O-5 반영, spec 5-2 대체)
| 조건 | 제목(`week-title`) | 구간(`week-range`) | 본문 |
|---|---|---|---|
| 7 ≤ D ≤ 9 | `최근 7일` | `M/D → 오늘` | 증감·%·`시작 → 끝` |
| D < 7, 10 ≤ D ≤ 14 | `M/D 이후` | **없음**(제목이 구간 시작을 이미 말함, 중복 제거) | 동일 |
| D > 14 | `최근 7일` | 없음 | message `최근 7일 기록이 부족해요` + note `기록이 쌓이면 원인을 나눠 보여드려요`. 원인 블록 없음 |
| 기록 0(attr=null) | `최근 7일` | 없음 | message `기록이 쌓이면 더 보여드려요`(기존 문구) |
- `7일 전 대비` 문구 삭제. 구간 표기는 항상 실제 시작일. `이번 주` 문구는 화면·팁 어디에도 쓰지 않는다.
- 증감 색 `getProfitLossColor`, 금액 `text-2xl sm:text-3xl font-bold tabular-nums`, % `text-base font-bold` — ChangeHero 그대로(수치 변경 0). 순자산 `시작 → 끝`은 muted `text-sm`(주황은 홈 Hero 전용, 여기 쓰지 않음).
- 예측 줄이 있어도 Hero에는 배지를 달지 않는다(증감은 실측 끝점 차, 예측은 원인 줄 한정).
- 요구 변경: spec 8-1·T3의 `week-range` 존재 조건을 위 표(7≤D≤9만)로 고친다. testId `week-title`은 유지.

## 3. 변화 원인 블록 수치·상태
- 외피 `SECTION`(rounded-xl bg-card p-4 space-y-3 dark:shadow-sm), 헤더 `SectionHeader ListChecks`·`변화 원인`. 카드 간격은 부모 `gap-3 sm:gap-4`(변경 없음).
- 줄 `SpecRow`: 라벨 `text-sm text-muted-foreground break-keep`, 값 `text-sm font-semibold tabular-nums`(손익색). 줄 사이 간격 `space-y-3`의 12px. 한 줄 불가 시 값이 다음 줄 우측(기존 동작) — 320에서 라벨+`예측`+`ⓘ`+억 단위 금액이 넘치는 경우 허용.
- 예측 배지: 기존 `CAUSE_BADGE`(`text-xs` 예외 규정 그대로). 2줄 이상이면 제목 옆 1개(기존 규칙). 라벨 `예측`.
- 줄별 도움말 `InfoHint`(기존, `data-screenshot-hide`). **scope별 문구 분리**(`CAUSE_HINT`를 scope 키로):
  - 순유입 `입출금과, 짝이 되는 출금 기록 없이 사거나 판 금액이에요`
  - 대출 `이 기간 늘거나 줄어든 대출이에요`
  - 기록 안 된 변화 `새로 등록한 자산이나 직접 고친 잔액처럼, 시세·환율·입출금·대출로 설명되지 않는 금액이에요`
  - 월 탭의 대출 이자(추정) 문구는 쓰지 않는다.
- 빈 줄 0개: `뚜렷한 변화 원인이 없어요`(기존 `CAUSE_CAPTION`). `showUnrecordedHint`는 week에서 미사용.
- **푸터 행**: `flex flex-wrap items-center justify-between gap-x-3`, 줄과 구분 `border-t border-border dark:border-border/40 pt-1`(MarketEntryLine 래퍼와 같은 규칙, 신규 값 아님).
  - 왼쪽 `AttributionRecordList`(수정 없이 재사용, `-mx-2 px-2 min-h-10`). 펼침은 기존 조건부 렌더(기존 동작 유지·이번에 건드리지 않음).
  - 오른쪽 `종목 등락 보기` + `ChevronRight size-3.5`: `<button>`, 스타일은 기록 내역 트리거와 동일(`inline-flex min-h-10 items-center gap-1 text-sm text-muted-foreground hover:text-foreground motion-safe:active:scale-[0.96] transition-[color,transform]`), 오른쪽 정렬은 `ml-auto`(기록 내역이 없을 때도 오른쪽에 둬 위치 고정). `data-screenshot-hide`, `data-testid="week-market-link"`. 숫자·색 없음(시장과 비교의 1주 종가 기준과 정의가 달라 값을 옮기지 않는다 — spec 7절).
  - 이유(시세 줄 아래에서 푸터로 이동): 6줄 사이에 40px 터치 행을 끼우면 줄 리듬이 깨지고 시세 줄만 높이가 달라진다. 푸터는 터치 한 줄로 묶여 엄지 동선도 짧다. 연관성은 라벨 `종목 등락`으로 전한다.
  - 폭: 320에서 `기록 내역 12건 ⌄`(≈112) + `종목 등락 보기 ›`(≈118) = 230 < 가용 264 → 한 줄. 넘치면 `flex-wrap`으로 다음 줄(오른쪽 정렬 유지).
  - 동작: `rememberChangeInit({scope:"all", period:"week"})` 후 `navigate({type:"activity", tab:"change-market"})` + 목록 기간 1주. 뒤로 1회로 전체·주 복원(주식 범위 MarketEntryLine과 같은 방식).

## 4. 날짜별 마감 기록 (접힘)
- 컨테이너 `SECTION` + `BODY_ENTER`(120ms), **토글과 패널을 한 래퍼 안에** 둔다(접힘 시 `space-y-3` 12px 잔여 여백 방지, design-system §6). 접힘 높이 = p-4 + 40px 헤더 행.
- 헤더 행 `<button>` 전폭 `min-h-10`, `aria-expanded`·`aria-controls`, 좌: `Table2 size-5 text-sky tone`(`SectionHeader tone="info"` 재사용) + `날짜별 마감 기록` `text-sm sm:text-base font-bold`, 우: `ChevronDown size-4 text-muted-foreground` `transition-transform duration-200`, 열림 `rotate-180`. 누름 `motion-safe:active:scale-[0.98]`(카드류).
- 패널: 항상 마운트 `grid motion-safe:transition-[grid-template-rows,opacity,visibility] duration-300 ease-out`, 접힘 `grid-rows-[0fr] opacity-0 invisible inert`, 열림 `grid-rows-[1fr]`. 안쪽 `min-h-0 overflow-hidden`. 전환 중 재탭은 CSS 역전(인터럽터블). 탭 전환·재마운트와 무관하게 접힘 기본값 복귀(저장 안 함, GA 없음).
- 패널 안: 맨 위 캡션 `날짜별 마감 기준이라 위 금액과 조금 다를 수 있어요`(`text-sm text-muted-foreground text-pretty`, 홈·Hero 실시간 끝점과의 차이를 미리 설명 — C65 같은 이중 노출 오해 방지), 그 아래 기존 `week-row` 마크업 그대로(날짜·마감 순자산·전일 대비, `divide-y`). 7행 미만이면 기존 `기록이 쌓이면 더 보여드려요`.
- 행 폭: 기존 `w-24` 전일 대비 열 유지. 320에서 `+12,345,678원`이 넘치면 기존과 같은 동작(변경 없음) — ui-review에서 320 확인.
- testId: 토글 `week-closing-toggle`, 패널 `week-list`, 행 `week-row`.

## 6. 인터랙션·모션
- 탭 전환(일·주·월·연): 기간 선택 노드는 `ChangeHeroFrame` 유지(썸 슬라이드 그대로). Hero 숫자 `contentKey="week"` fade 200ms, 원인 블록 `key="week"`로 마운트 시 stagger 1회. 같은 탭 재탭은 무시(기존).
- 접힘 토글과 `AttributionRecordList` 펼침은 부모 리렌더로 재마운트되지 않게 `CauseBlock`·접힘 카드를 WeekList 안 안정 키로 두고, 데이터 갱신(시세 폴링)은 값만 바꾼다. 펼친 상태가 시세 갱신으로 닫히지 않아야 한다.
- 연타: 토글 연타는 grid-rows 역전. 링크 연타는 navigate 1회(이동 후 언마운트).
- reduced-motion: `motion-safe` 전부 즉시.

## 7. 접근성
- 히트영역 전부 40px 이상(푸터 두 버튼 `min-h-10`, 토글 `min-h-10`+행 전폭).
- 접힘 `aria-expanded`/`aria-controls`/패널 `inert`+`aria-hidden`. 푸터 링크 `aria-label="종목별 등락, 시장과 비교로 이동"`(시각 라벨 `종목 등락 보기` 포함).
- 원인 줄 값은 부호(`+`/`−`)와 색 둘 다 사용(색 단독 의존 없음). Hero `aria-live="polite"` 유지.
- 다크: 접힘 카드 `dark:shadow-sm`, 구분선 `dark:divide-border/40`, `text-muted-foreground` 대비 기존 화면과 동일 토큰만 사용.

## 9. 신규 기능 팁 (1회)
- `APP_FEATURES`에 `id:"week-causes"`, 제목·설명은 위 표, 아이콘 `ListChecks`(CauseBlock 헤더와 같은 아이콘), `isNew:true`, target `{type:"activity", tab:"change"}`+init `{scope:"all", period:"week"}`(O-4, developer 확인).
- `market-compare` isNew 제거(신규 배지 1종만). 닫으면 기존 `dismissTip`으로 재노출 없음. 결산 창에서는 월 결산 팁 우선(기존 우선순위 유지). 반복 팁·배지 추가 없음.

## 10. data-screenshot-hide / testId
- hide: `week-market-link`, 줄 `InfoHint`. 공유 캡처가 주 탭을 포함하면 접힘 카드를 캡처용으로 펼칠지 여부는 developer가 확인해 보고(캡처 변경 없음이 원칙이므로 기존 7행이 사라지지 않게).
- testId: spec 9절 + `cause-block[data-scope=week]`, `week-closing-toggle`, `week-market-link`, `week-records`(푸터 왼쪽 래퍼), `week-title`, `week-range`(7≤D≤9만 존재), `week-insufficient`, `week-empty`.

## 11. 품질 체크리스트 (qa 판정용, 375·1280 × 라이트·다크 + 320)
1. 주 탭에 `이번 주` 문구가 없고 제목은 `최근 7일` 또는 `M/D 이후`이다. 7≤D≤9에서만 `week-range`(`M/D → 오늘`)가 있고 M/D가 실제 시작일이다.
2. `cause-block[data-scope=week]`의 줄 순서가 시세 변동·평가 갱신·환율 효과·순유입·대출·기록 안 된 변화이고 0원 줄이 없다. 줄 `data-value` 합 = `change-hero-delta`의 `data-value`.
3. 원인 블록 외피·헤더·행 스타일이 월 탭 `CauseBlock`과 픽셀 동일(신규 색·radius·간격 0). 원인 행 stagger 40ms가 진입 때 1회만 돈다.
4. `종목 등락 보기`가 푸터 오른쪽에 있고(주식 보유 시), 높이 ≥40px이며 숫자·색이 없다. 누르면 시장과 비교(1주)가 열리고 뒤로 1회에 전체·주로 돌아온다. 주식 미보유 시 없다.
5. `날짜별 마감 기록`은 기본 접힘이고 접힘 높이가 한 줄 헤더(≈72px)다. 펼침 전환 300ms grid-rows, 연타 시 끊김·점프 없음, 접힘 때 `inert`. 펼치면 `week-row` 값·순서가 main과 같다.
6. 시세 갱신·재렌더 후에도 펼침 상태(날짜별 마감 기록, 기록 내역 N건)가 닫히지 않는다. 탭 `주→월→주` 후에는 기본 접힘으로 돌아온다.
7. D>14 상태: Hero에 `최근 7일 기록이 부족해요`+note, 원인 블록 없음, 접힘 카드 있음. 기록 0: `기록이 쌓이면 더 보여드려요`만.
8. 예측 줄에 `예측` 배지, 예측 2줄↑은 제목 옆 1개. 줄별 InfoHint 문구가 spec 대로(월 탭 이자 문구 없음), 터치 40px.
9. 320·375에서 Hero 구간·원인 라벨·푸터 두 버튼·팁 문구에 어절 중간 줄바꿈과 가로 스크롤이 없다. 푸터는 320에서 한 줄 또는 오른쪽 정렬 두 줄.
10. 1280에서 카드 폭·간격이 월 탭과 같다(주 탭만 좁거나 넓지 않음). 다크에서 접힘 카드 그림자·구분선·muted 텍스트 대비가 월 탭과 같다.
11. 신규 기능 팁은 1종(`주간 변화 원인`)이고 `market-compare`의 신규 배지가 없다. 닫으면 재노출 없음. 결산 창에서 결산 팁이 먼저다. 아무것도 조작하지 않은 데모 상태에서 확인(LEARNINGS #51).
12. 주식 범위·일·월·연 탭, 홈 Hero는 main과 픽셀 동일. 마감 기록 캡션이 홈·Hero 수치와 다를 수 있음을 알린다(C65 이중 노출 점검: 주 합계 증감은 Hero 1곳에만 있다).
13. 모든 인터랙티브 요소 `<button>`, `aria-expanded`·`aria-controls`·`aria-label`, reduced-motion에서 전환 즉시.
