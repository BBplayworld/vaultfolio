## 2. 진입점 — FAB 시트 (`floating-add-button.tsx`)
- `ASSET_TYPES`에 `{ type:"physical", label:"실물 자산", icon: Gem, hasScreenshot:false, navigateTab:"physical" }`를 **현금성 자산 다음·대출 앞**에 추가. 기존 행 구조(보유 현황 업데이트 단계 목록, 우측 연필 = 탭 이동) 재사용. 행 보조문구는 기존 "업데이트" 그대로.

## 3. 등록·수정 폼 (`physical-input.tsx`, `real-estate-input.tsx` 골격 복제 — Dialog + react-hook-form)
Dialog 제목: 등록 "실물 자산 추가" / 수정 "실물 자산 수정". 설명(DialogDescription, 기존 관행): "금, 은, 귀금속처럼 직접 보관하는 자산을 평가액으로 기록해요."
위→아래(모두 `space-y-4`, 라벨 위·입력 아래, 기존 폼 간격):
1. **이중 계상 안내(등록 모드만)** `physical-double-count-note`: 한 줄 `rounded-lg bg-muted/40 px-3 py-2 text-sm text-muted-foreground break-keep text-pretty` — "현금·부동산에 금을 넣어 두셨다면 그 항목은 지워 주세요." (아이콘 없음, 경고색 금지: 의무가 아니라 안내.) 수정 모드에서는 숨김.
2. **종류** (`InlineSelector`, 기존 부동산 종류와 같은 컨트롤): 금 / 은 / 귀금속 / 수집품 / 기타. 짧은 라벨(`shortLabel`)로 5개가 320px 한 줄에 들어가지 않으면 InlineSelector 기본 래핑을 따른다(어절 중간 끊김 없음, 칩 단위 줄바꿈). 기본 선택 "금". 전체 라벨은 상세 카드에 표시: 금 · 은 · 귀금속·보석 · 수집품·미술품 · 기타 실물. 모르는 값(`other`로 읽힌 미래 유형)은 수정 시 "기타" 선택.
3. **이름 \*** placeholder는 종류별: 금 "예: 골드바 100g" · 은 "예: 실버바 1kg" · 귀금속 "예: 다이아 반지" · 수집품 "예: 한정판 시계" · 기타 "예: 기타 실물". 최대 30자.
4. **현재 평가액 \*** (NumberInput, 원, 라벨색은 기존 폼처럼 `accent-teal`): 퀵버튼 `+10만 +100만 +1천만`(`quickButtonPresets.physical` 설정 1항목 추가, 컴포넌트 아님). 라벨 아래 도움말 1줄(`FormDescription`, text-xs): "직접 확인한 시세나 감정가를 입력해 주세요. 자동으로 바뀌지 않아요."
5. **매입가** (선택, NumberInput): 도움말 등록 모드 "비우면 현재 평가액과 같게 기록돼요(손익 0)." / 수정 모드 "일부 팔았다면 평가액과 매입가를 판 금액만큼 함께 줄여 주세요."(R6, 4.55 ui-review G4 증분 승인) 상속·증여 케이스를 위한 것.
6. **매입일 \*** (기존 날짜 입력, 기본값 오늘): 도움말 "오래전에 사셨다면 실제 구매일을 골라 주세요. 결산에 반영돼요." (매입일이 결산 유입 판정에 쓰이므로 필수 유지.)
7. **메모** (선택, Textarea 2줄, 최대 100자) placeholder "예: 은행 보관, 2023년 돌반지".
8. 푸터: `취소`(outline) / `저장`(`Button variant="brand"`, 수정 모드 "수정"). 저장 중 `Loader2`, 중복 제출 방지(`isSubmitting`). 2열 grid(매입가/평가액 나란히)는 쓰지 않는다(금액이 `tabular-nums` 12자리라 320px에서 잘림, 세로 배치).
- 검증 문구(`FormMessage`, 해요체): 이름 "이름을 입력해 주세요." / 평가액 "평가액을 1원 이상 입력해 주세요." / 매입일 "매입일을 선택해 주세요." 매입가는 0 이상 허용(빈 값 허용).
- 저장: 성공 토스트 `toast.success("실물 자산을 저장했어요.")`(수정 "수정했어요."). `trackAssetSave{asset_type:"physical", method:"manual"}`, 자산 0건이었으면 `first_asset_saved`. 금액·이름 GA 금지.
- 입력 포커스 시 iOS 줌 방지(기존 Input 16px 규약), Dialog는 기존 스크롤 규약(모바일 `max-h` 스크롤). 자동 포커스는 이름 칸.
- 허브/탭에서 수정: 이벤트 `trigger-edit-physical{id}` (기존 `trigger-edit-real-estate` 패턴).

## 5. 상세 탭 (`physical-tab.tsx`, `real-estate-tab.tsx` 복제 후 축소)
- `Card ASSET_THEME.contentCard` > `CardHeader`(CardTitle "실물 자산") > `CardContent space-y-4`.
- `DetailSummaryHeader label="총 실물 평가액" value inline={<ProfitMetric label="평가손익" .../>}` 그대로 재사용(숫자 `tabular-nums`).
- 요약 아래 캡션 1줄 `text-xs text-muted-foreground text-pretty`: "평가액은 직접 입력한 값이에요. 시세에 따라 자동으로 바뀌지 않아요." (현금·부동산·코인과의 차이를 여기서 한 번만 설명.)
- 카테고리 InlineSelector·항목별 비중 막대 없음. 리스트는 `data-testid="detail-list-box-physical" className="space-y-2 {ASSET_THEME.listBox}"`, 정렬은 평가액 내림차순.
- `PhysicalCard`(= `RealEstateCard`의 `Collapsible` 구조): 아이콘 원 `size-6 sm:size-7` 배경 `MAIN_PALETTE[8]`에 흰 `Gem`. 이름 + 보조줄 "금 · 42.0%"(종류 shortLabel + 비중, 비중 `text-primary font-semibold`). 우측: 평가액(`cardAmountMain`)·손익(`cardAmountSub`, `getProfitLossColor`)·비율. 하단 0.5px 비중 바 색 [8]. 펼침: 종류(전체 라벨) / 매입가 / 매입일 / 평가손익, 메모가 있으면 `col-span-2 sm:col-span-4`로 한 줄. 매입가를 비워 저장한 항목은 손익 0이 `text-muted-foreground`(0은 빨강·파랑 아님). 수정(Pencil)·삭제(Trash2) 버튼은 `ASSET_THEME.cardActionButton`(히트영역 40px 유지, `title`+`aria-label`).
- **삭제 흐름**: 부동산과 같은 `confirm` 패턴을 유지하되 문구만 해요체로: `confirm("이 실물 자산을 삭제할까요?")` → `deletePhysicalAsset(id)`(컨텍스트 액션, 부동산 `deleteRealEstate` 패턴) 후 `toast.success("삭제했어요.")`. 마지막 1건을 지우면 `navigate({type:"detail",tab:"hub"})`로 허브 복귀(빈 탭에 머물지 않음, 허브 카드는 사라짐). 다른 자산이 하나도 없으면 기존 동작대로 웰컴으로 전환.
- **수정 흐름**: 연필 → 같은 폼(값 채워진 상태). 평가액을 바꾸면 당일 월 스냅샷이 갱신되고 토스트 "수정했어요." 카드 숫자는 즉시 갱신(전환 없음, 값만 바뀜).
- 빈 상태(해시로 직접 진입 등 방어): 점선 박스 `h-36` "등록한 실물 자산이 없어요." + `Button variant="brand" size="sm"` "실물 자산 추가"(`dispatchAddPhysical`). 기존 부동산 빈 박스 구조와 동일.
- 긴 이름: 이름 `truncate min-w-0`, 금액은 `whitespace-nowrap`(320px에서 이름이 먼저 줄어듦). 큰 금액은 `formatPriceByMode` 단축 표기 + 요약 헤더만 전체 금액(기존).

## 6. 홈 (도넛·범례만)
- `useAssetTreemapData`(공용 훅, 인증카드 공유): `treemapRawAssets`에 `{key:"physical", name:"실물", value: s.physicalValue}`(>0일 때만), 색 [8] 고정(1절), `totalAsset`·`grossTotal`에 실물 포함. `financialAssetValue`는 불변.
- 도넛 조각 라벨 규칙(4.46): "실물" 2자 → 비중 9% 이상에서만 라벨, 미만은 범례만. 100%(실물만 보유)일 땐 "실물 / 100%" 한 조각.
- 조각 클릭: 홈 탭에 `physical`이 없으므로 `onSegmentClick` 래퍼에서 `key==="physical"`이면 `navigate({type:"detail",tab:"physical"})`, 그 외는 기존 `setActiveDetailTab`. 탭 필터(InlineSelector)에는 "실물"을 넣지 않는다.
- 범례 행: 기존 행 구조(색점 · 이름 · 금액 · %)를 따르며 신규 코드 없이 데이터 항목만 추가.
- 인증카드(`share-card`)·웰컴 미리보기: 무접촉(`screenshotMode` 렌더 바이트 동일 유지). `ShareCard`가 `useAssetTreemapData`를 쓰는 경로라면 실물 조각이 인증카드에 섞여 들어가지 않는지 개발 시 확인(섞이면 `screenshotMode`에서 제외 요청).
- 홈 Hero 순자산·재방문 팁: 합산 값만 바뀜(문구·레이아웃 무변경).

## 8. 복원 코드·가져오기 안내 문구 (보안·데이터 문구 규칙: "안전/절대/완벽/100%" 등 단정 표현 금지, 사실만)

- 서버 전송 관련 신규 문구 없음(동기화 설명은 기존 문구 그대로).

## 9. 모션·접근성·다크
- 폼 Dialog·시트·카드 펼침은 기존 컴포넌트 모션만 사용(신규 모션 없음). 카드 펼침 `Collapsible` + chevron 회전 `duration-200`은 기존. 신규 카드가 생기면 `motion-safe:animate-in fade-in`만(탭 전환 시), `transition: all` 금지. 목록 갱신 시 재마운트가 없도록 `key={item.id}`.
- 히트영역: 종류 칩·퀵버튼·수정/삭제 40×40 이상, 시트 행 `py-3`+연필 `p-3`(기존). 키보드: 폼 Tab 순서 종류→이름→평가액→매입가→매입일→메모→취소→저장, Esc 닫기(Dialog 기본), 삭제 버튼 `aria-label="{이름} 삭제"`, 수정 `aria-label="{이름} 수정"`.
- 다크: 아이콘 원·바 [8]은 라이트와 같은 색(다크 배경에서 대비 충분). 안내 박스는 `bg-muted/40`(다크에서도 토큰 자동), 카드는 `dark:` 기존 규약(`cardWrapper`, `listBox`)을 그대로 사용하므로 4.44 다크 BOX 규약과 동일.
- 문구 투자 조언 금지: "늘리세요/좋아요/수익 낼" 등 없음.

## 10. 줄바꿈(C25)·반응형

## 12. 품질 체크리스트 (qa: 375·320·1280 × 라이트·다크 스크린샷/Playwright)
1. FAB 시트 "보유 현황 업데이트" 단계에 "실물 자산" 행이 현금성 자산 아래·대출 위에 있고, 탭하면 폼 Dialog가 열리며 시트는 닫힌다. 실물 0건이면 연필 아이콘이 없다.
2. 등록 폼 종류는 5개 칩, 기본 "금". 종류를 바꾸면 이름 placeholder가 바뀐다. 수량·단위 입력이 없다.
3. 등록 모드 상단에 이중 계상 안내 1줄이 있고 수정 모드에는 없다. 320·375에서 어절 중간 줄바꿈이 없다(C25).
4. 필수(이름·평가액·매입일) 비우면 해요체 검증 문구가 뜨고 저장되지 않는다. 매입가를 비우고 저장하면 평가액과 같은 값이고 손익이 0, 색이 muted다.
5. 저장하면 토스트 "실물 자산을 저장했어요."가 뜨고 허브에 "실물 자산" 카드가 생긴다(0건에서는 허브에 카드가 없다). 확인 버튼은 brand 색이다.
6. 허브 카드 순서는 주식·부동산·코인·현금·실물·대출이고, 카드 탭 시 실물 탭으로 이동한다.
7. 실물 탭에 요약 헤더, 직접 입력 캡션, 평가액 내림차순 카드가 있고 카드 아이콘 원·비중 바 색이 `#7a6236`이다. 부동산 탭과 비교해 비중 막대·카테고리 선택기가 없다.
8. 카드 수정에서 평가액을 바꾸면 카드 숫자와 허브 카드 합계가 즉시 같은 값으로 바뀐다. 삭제는 확인창 후 토스트 "삭제했어요."이고 마지막 1건 삭제 시 허브로 돌아간다.
9. 홈 도넛에 "실물" 조각(색 `#7a6236`)이 생기고, 부동산/금융자산 조각 색은 실물 유무와 무관하게 같다. 9% 미만이면 조각 라벨이 없고 범례에만 있다. 조각 클릭 시 실물 탭으로 이동한다.
10. 실물만 1건 가진 기기: 웰컴이 아니라 홈이 뜨고 Hero 순자산 = 실물 평가액, 도넛 "실물 100%", 탭 필터 없음, FAB 노출. `/?trial=1`은 거부된다.
11. 복원 코드 화면은 실물이 있을 때만 미포함 안내 1줄을 보여 준다. 구 백업 가져오기 후 토스트 "실물 자산은 기존 값을 유지했어요."가 뜬다. 안내 문구에 "안전·절대·완벽" 표현이 없다.
12. 모든 신규 버튼·칩·아이콘 버튼의 히트영역이 40×40px 이상이고 다크 모드에서 텍스트 대비 4.5:1 이상(흰 글자 위 황토 5.79:1)이다.
13. 실물 0건 사용자의 홈·허브·FAB(연필 제외 행 추가분)·상세 화면이 main과 동일하다(실물 행 외 변화 없음, 스크린샷 비교). `screenshotMode`/웰컴 도넛 SVG outerHTML 불변.
14. `prefers-reduced-motion`에서 신규 진입 모션이 즉시 표시된다. 렌더·effect에서 저장 함수를 호출하지 않는다(C16).
