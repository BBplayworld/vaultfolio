## qa D1 수정 (구버전 push로 클라우드 사본에서 실물 키 소실)
- `reconcileAdditiveMerge`: 원격 `physicalAssets` 키가 없고 로컬 실물이 1건 이상이면 로컬 실물을 실어 `changed=true` 반환 → `mergedAdditions=true` → provider 즉시 재-push로 클라우드 사본 복구. 원격 `[]`(삭제 의도)는 키가 있어 기존 mergeById 규칙 유지(구분 유지). 구버전 기기는 편집 시에만 push하므로 핑퐁 없음.
- 테스트(physical-assets-sync): B 구버전 push → A pull mergedAdditions===true → A push → 새 신 기기 C 복원에 실물 존재 / B 3회 반복 편집·push마다 A 복구, B 무편집이면 추가 병합 0(무한 재push 없음). 한계: 구버전 로직은 4fee68c 파일 자체가 아니라 동일 동작의 테스트 사본(strip·clear·import)이다 — 원본은 현 스키마를 import해 strip이 재현되지 않기 때문.
