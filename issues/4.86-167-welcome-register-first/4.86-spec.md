## 6. 사용자 흐름
1. 모바일 웹(Safari·Chrome, 미설치, 비인앱)으로 `/` 진입 → 사전 조각 → 웰컴. CTA 슬롯은 `pending` 빈 셸 → 마운트 즉시 `asset`(설치 상태를 거치지 않음, 깜빡임 0).
2a. `스크린샷으로 자산 등록` → 온보딩 마법사(현행).
2b. `직접 입력 · 가져오기` → 팝오버(직접 입력 5행 + 가져오기 2행) → 자산군 1행 → 팝오버 닫힘 → 그 자산군 추가 다이얼로그.

4. 홈: #78 안내 1회(`shouldShowInstallNudge`: 모바일·비인앱·iOS 또는 설치 가능). 상단 설치 아이콘 상시(`top-bar.tsx:178`).
5. `추가하기` → Android: 브라우저 설치 창 / iOS: PIN → 복원 코드 생성·자동 복사(`pwa-install-flow.tsx:84-117`) → 가이드 → 홈 화면 추가 → 앱 첫 실행 `웹에서 쓰던 자산이 있나요?`(`pwa-connect-prompt.tsx:75`) → 붙여넣기 → 자산 보임.

## 8. 엣지 케이스
- **빈 데이터(0건)**: 주 경로. 현금·대출 행은 추가 폼(잔액 맞추기 아님, 보유 0이므로 분기 불필요).
- **첫 자산이 대출만**: 저장 후 홈(순자산 음수) — 현행 동작, 변경 없음.
- **일부 갱신**: 첫 저장 1건 후 웰컴은 사라지고 홈이 된다. 나머지 자산군은 FAB·상세 허브 0건 카드(4.85)로 추가. 웰컴 5행은 0건일 때만 보인다.
- **오래된 데이터**: 해당 없음(웰컴은 0건 또는 공유 대기). 공유 대기 중 기존 보유가 있는 기기에서 현금·대출 행을 누르면 새 계좌 추가 폼으로 간다(현행 주식 행과 같은 성격, 잔액 맞추기로 보내지 않음 — 수용).
- **첫 사용자**: 주 경로. 연타: 첫 탭에 팝오버가 닫히므로 이벤트 1회.
- **실물·과거 순자산**: 웰컴에서 진입 없음(리스너 미마운트). FAB에서 가능.
