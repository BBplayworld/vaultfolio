## 2. 레이아웃 수치 (실측 기준)
**슬롯 높이·점프(핵심)**: 운영 실측 asset 상태 카드 = 모바일(375·320 동일) **216px**, ≥640 **160px**(768·1280). install 상태·pending 셸 = 152px.
- main: 모바일 pending 152 → install ~152 → (바로 시작 후) asset 216. 4.86 제안대로 asset만 두면 pending(152) → asset(216)로 **+64px 점프**(아래 미리보기·페이지 높이 1445→1509). 
- **수정: pending 셸 `min-h-[216px] sm:min-h-[160px]`**(현 `min-h-[152px] sm:min-h-[160px]`의 모바일 값만 216으로). 점프 0, 데스크톱 불변. qa: pending→asset 전후 `welcome-cta-slot` boundingBox 높이 차 0(±1px), 아래 블록 top 변화 0.
- 카드 p-4, 내부 `space-y-5`, 버튼 사이 gap-3 — 현행 유지. 첫 화면(375×812) 카드 상단 y≈626 → 스크린샷 버튼은 접힘 아래(스크롤 필요). install 상태도 같았고, 카드 위치는 히어로·미리보기가 정하므로 이번 범위에서 순서 변경 없음(범위 밖).

**팝오버(수정 전: w-56=224px, 174px 높이 / 제안: 240px, 371px)**
- `PopoverContent`: `w-60 p-1.5` + `max-h-[min(var(--radix-popover-content-available-height),26rem)] overflow-y-auto overscroll-contain`(`space-y-0.5` 제거, 행 간격은 행 높이로). radius·보더·`shadow` 기본 Popover 규약 유지(xl, 안쪽 행 `rounded-md` = 동심).

- 직접 입력 행 5개: **`min-h-11`(44px) `px-3` `gap-2.5` `text-sm font-medium`, 한 줄**(보조 줄 없음). 아이콘 `size-4 text-muted-foreground shrink-0`(현 행과 동일 톤, 컬러 칩 금지) — 부동산 Building2·주식 TrendingUp·암호화폐 Bitcoin·현금성 자산 Wallet·대출 CreditCard(FAB와 동일).
- 구분: `mx-3 my-1.5 h-px bg-border/40`(§3.3 중립 헤어라인) + `role="separator"`. 가져오기 그룹 `role="group" aria-label="가져오기"`(보이는 라벨 없음 — 문구 diff 0).
- 가져오기 2행: 현행 2줄 구성 그대로, **`min-h-11 py-2`**(실측 52px). 아이콘 FolderInput·Link2 현행.

## 4. 인터랙션·모션 (§6)
- 팝오버 열림/닫힘: 기본 Popover(`animate-in fade-in zoom-in-95 slide-in-from-*`, 닫힘 `animate-out fade-out zoom-out-95` — subtle exit)이며 `motion-safe` 영향은 `tw-animate-css` 기본. 신규 모션 0.
- 행 탭 → 팝오버 닫힘(`setOpen(false)`) → 다이얼로그 열림 이벤트. 팝오버는 Radix가 항상 같은 노드로 열고 닫으므로 재마운트로 모션이 사라지지 않음. 연타: 첫 탭에 닫혀 이벤트 1회(spec 8절). 열림 중 트리거 재탭 = 닫힘(Radix 기본, 인터럽터블).
- CTA 슬롯 교체: 셸 노드 유지·콘텐츠 페이드만(현행). 슬롯 높이 고정으로 레이아웃 점프 없음.
- 눌림 피드백 `0.98`(행 = 카드류), 트리거 버튼 `0.96`(공용 Button 현행).

## 5. 접근성
- 히트영역: 행 44px 전폭(≥40). 트리거는 현행 40px.
- 키보드: 열림 후 Tab 순서 = 5행 → 2행(DOM 순서), Esc 닫힘 + 트리거로 포커스 복귀(Radix), Enter/Space 실행. 포커스 링 `ring-ring/50` inset(`mock-popover-focus-375.png`). 방향키 이동은 구현하지 않음(Menu가 아닌 Popover 내 버튼 — role="menu" 금지).
- 의미: 그룹 `role="group"`+`aria-labelledby`(직접 입력)/`aria-label`(가져오기), 구분선 `role="separator"`. 아이콘은 장식(`aria-hidden`), 행 이름이 접근 가능한 이름.
- 다크 대비: 행 텍스트 `text-popover-foreground`(≥7:1), 라벨·아이콘·보조줄 `text-muted-foreground`(현행 토큰, 라벨 12px는 ≥4.5:1 유지 확인 필요 → qa 측정), 라이트는 `bg-popover`(화이트)+`border`+`shadow-md` 현행 유지(같은 색 겹침 규칙 충족).

## 6. 문구·testId
- 문구: spec 5절 그대로(`직접 입력` 라벨, 행 `부동산·주식·암호화폐·현금성 자산·대출`, 가져오기 2행 문자 diff 0, 보조 줄 없음). 투자 조언·금액 0. 스크린샷 모드 `data-screenshot-hide` 신규 대상 없음(웰컴은 인증 대상 아님, 기존 규칙 유지).
- testId: spec 10절 그대로(`welcome-manual-{real-estate|stock|crypto|cash|loan}`, `welcome-import`, `welcome-sync-connect`, `welcome-cta-slot`의 data-state에 `install` 없음). 라벨은 `welcome-manual-label` 추가 권장(qa 순서 단언용).

7. 320×568: 팝오버 가로 넘침 0(좌우 8px 이상 여백), 팝오버 `scrollHeight>clientHeight`이면 `overflow-y:auto`, 5행은 스크롤 없이 보인다. 375×812: 스크롤 0.
8. 팝오버 열기 → Tab 순서·Esc 복귀 포커스(`welcome-cta-more`)·포커스 링 가시.
9. 행 탭 → 팝오버 닫힘 + 해당 자산군 추가 다이얼로그 1개, 연타해도 1개.
