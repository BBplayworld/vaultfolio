## 수정 요청
- **R-1 (문구, spec 4절 F1 정정)** fact F1 `…성과 > 자산 변화의 '연'에서 올해 전체 변화를…` → `…성과 > 자산 변화의 '연' 탭에서 올해 전체 변화를…`. 근거 C139(처음 보는 사람이 '연'만으로 뜻을 모름). 부수 효과: `'연'에서`(따옴표+조사, C114) 패턴이 사라져 nowrap 처리 불필요. AC-4 대조는 탭 라벨 `연` 글자 그대로라 영향 없음. spec 표기도 이 문장으로 본다(planner 승인).
- **R-2 (마크업, ui 2.2)** 하단 목록 제목 `<h3>다른 가이드</h3>` → `<h2 id="guide-other-title" className="text-sm font-semibold mb-1">` 로, `nav`는 `aria-label` 대신 `aria-labelledby="guide-other-title"`. 근거: h3이면 제목 탐색에서 fact box(`시크릿에셋으로 하면` h2)의 하위로 읽히고, aria-label+보이는 제목이 같은 이름을 두 번 읽음. 시각 diff 0.

## 비차단 관찰 (조치 불요)
- 루트 링크 순서(year-end·net-worth·stock-ratio)와 하단 목록 순서(`GUIDE_SLUGS`: stock-ratio·net-worth·year-end)가 다르다. 각 목록 안에서는 일관되고 AC-8·AC-9가 `GUIDE_SLUGS`에 묶여 있어 이번엔 그대로 둔다.
- year-end 글의 secondary CTA `캡처로 내 비중 보기`는 결산 글과 주제가 다르나 spec '새 CTA 0' 합의 사항. 판독(1/11) 때 `비중 미리보기` 0이면 2편째 검토 시 재논의.
