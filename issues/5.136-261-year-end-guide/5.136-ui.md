## 2. 컴포넌트 트리·클래스 (developer는 이 값을 그대로)
### 2.1 `RootGuideLinks` (신규 공용 1개, 카탈로그 등록 대상)
```
<nav aria-label="가이드" data-testid="root-guide-links" className="flex flex-col items-center">
  <span aria-hidden className="text-xs font-semibold leading-none text-muted-foreground mb-0.5">가이드</span>
  <div className="flex flex-wrap justify-center">
    <a href="/guide/<slug>" data-testid="root-guide-link-<slug>"
       className="inline-flex min-h-10 items-center rounded-md px-2 text-sm text-muted-foreground whitespace-nowrap
                  hover:text-foreground transition-colors outline-none focus-visible:ring-[3px] focus-visible:ring-ring/50">
      <span className="underline underline-offset-4 decoration-muted-foreground/40">{linkLabel}</span>
    </a>  ×3 (year-end, net-worth, stock-ratio 순)
  </div>
</nav>
```
- 일반 `<a>`(next/link·prefetch 금지). 누름: `onClick`에서 `e.preventDefault()` 없이 GA 후 이동하려면 spec `trackThenNavigate`를 따르되 **href 유지**, 연타 가드. 서버 HTML에 `<a href>`가 있어야 한다(client 컴포넌트여도 SSR).
- 링크 **항목 단위 nowrap**: 줄바꿈은 항목 사이에서만(어절 중간 0). 구분점·색 칩 없음(링크 간 `px-2`×2=16px 간격과 밑줄로 구분). press scale 없음(텍스트 링크, 푸터 톤), 색 전환만(`transition-colors`, `transition: all` 금지).
- 히트영역: 각 링크 `min-h-10`(40px) × 폭 ≥ 글자+16px. 줄 사이 겹침 없음(실측 40px 높이·줄 간 0 간격, nav 총 94px/2줄).
- 대비: muted-foreground는 라이트 oklch .45(배경 .96 약 6:1), 다크 .74(배경 .16 약 9:1). 밑줄은 40% 투명(장식), 링크 인지는 텍스트 밑줄 + 위치로 충분.
- 모션: 없음(진입 ENTER 금지 — 사전 조각 직후 웰컴은 이동 0 원칙). `motion-safe` 해당 없음.

## 7. developer 주의점
- 링크 줄을 `WELCOME_ROOT` 안에 넣지 않는다(AC-7). 사전 조각은 `WELCOME_ROOT` div와 형제, 웰컴은 `<CopyrightFooter>` 직전. 컴포넌트에 `mt-*`·`py-*` 바깥 여백 금지.
- `[data-first-paint]` 안이어야 보유자 CSS 숨김이 적용된다. 웰컴 분기 쪽은 `data-first-paint` 속성을 붙이지 않는다.
- `WelcomeGuide` 파일 diff 0, `welcome-intro`의 마크업 차이는 링크 줄뿐(스냅샷 테스트 갱신은 `RootFirstPaint`만).
- `withNowrap` 정규식 확장 시 기존 2편 출력이 바뀌면 안 된다(문구 diff 0) — 새 편에만 적용되는 방식(`\d+[월일]` 등)은 기존 문장에 해당 패턴이 있는지 먼저 확인.
- 완료 후 `components.md`에 `RootGuideLinks`·가이드 하단 목록 등록(KB 배치 갱신 시점).
