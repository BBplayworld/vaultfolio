## 사업
1. **왜 지금**: **첫 발견**에 기여한다. 신규는 월 17~40기기이고, 그중 검색 신규는 주 1기기다(`2026-11-07_13-channel-group.csv`). 공개 문서 3개(/ratio, 가이드 2편)는 28일 동안 도착 0기기였고, 네이버 색인은 4개 중 1개다. 루트에서 이 문서들로 가는 링크가 0개라서 수집기가 찾을 길은 sitemap뿐이다. 연말 결산 검색은 12월 말~1월 초에 몰리고 색인에는 1~3주가 걸린다. 그래서 **12월 첫 주 공개**가 기한이다. 앱의 '올해 결산'(v5.124)이 이미 있으므로 글이 실제 기능으로 이어진다.
2. **누구를 위해**: 12월 말에 엑셀·노션 시트를 열고 "작년 말보다 얼마 늘었나, 그중 내가 넣은 돈과 시세로 불어난 돈은 각각 얼마인가"를 직접 계산하려는 3040 주식 투자자. 증권사 2곳 이상, 현금·대출까지 한 시트에 적는 사람이고, 아직 시크릿에셋을 모른다.
3. **성공의 모습**(머지 후 4주 → **[정정 11-21 challenge 7절] 판독 기간 머지일~2027-01-11, 주 지표 = 가이드·* 3행 기기 − `웰컴·가이드 열기` 기기**, GA '페이지 및 화면' title CSV, 익명 기기 절대 수, 기존 측정 방식 그대로)
   - 주 지표: `가이드·올해 결산`(신규 title, 기존 `guide:<slug>` 맵에 1줄) + `가이드·주식 비중` + `가이드·순자산 정리` 활성 사용자 합 **4기기 이상**. 기준선은 28일 0기기다.
   - 보조 지표: `가이드·체험` + `비중 미리보기` **1기기 이상**(글에서 앱으로 넘어감).
   - 가드레일: `웰컴·스크린샷 등록`+`·직접 입력`+`·가져오기` 기기 수가 머지 전 같은 길이 구간보다 줄지 않을 것(웰컴 맨 아래 링크가 등록 흐름을 빼앗지 않는지 확인).
   - 판정: 4기기 이상이면 성공(1월에 2편째 검토). 1~3기기면 보류하고 8주에 재판독한다. 0기기면 8주에 재판독하고, 그때도 0이면 가이드를 더 늘리지 않는다(링크 줄을 남길지는 그때 판정).
4. **하지 않으면 잃는 것**: 1년에 한 번 오는 '연말 결산' 검색 시기를 놓친다. 다음 기회는 2027년 12월이다. 이미 만든 공개 문서 3개도 계속 고아로 남는다. 근거 강도는 '중'이다. 원인(들어오는 링크 0)은 코드로 확인했다. 하지만 검색 수요의 크기는 측정하지 않았고, 효과가 월 100명에 미치는 몫도 작을 수 있다(주 +1~3기기 가정).

## 경험 (planner-designer 관점)
- **바뀌는 화면 3곳**
  1. **새 공개 페이지 `/guide/year-end` '올해 자산 결산하는 법'**(새 URL → spec 필수, 새 API 0). 기존 `GuideDoc`·`GuideShell` 틀을 그대로 쓴다(재사용 우선).
     - 단계 4개: ① 기준 정하기(작년 말 순자산, 없으면 올해 처음 적은 날) ② 지금 순자산 ③ 올해 넣은 돈·뺀 돈 합계 ④ 나머지 = 시세·환율로 움직인 돈. 매수·상환은 자산 사이의 이동이라 빼는 이유도 적는다.
     - 사실 줄은 앱 동작과 1:1로 맞춘다. '성과 › 자산 변화 연 탭의 올해 결산이 넣은 돈·불어난 돈·빠져나간 돈으로 나눠 보여 줘요', '1월 10일까지는 지난해 결산을 보여 줘요', '지난 연도 순자산은 직접 입력해요', 저장 위치는 `SECURITY_COPY` 원문 import(새 보안 문장 0).
     - CTA는 기존 2종(체험·/ratio)을 쓴다.
  2. **루트 첫 화면 맨 아래 링크 줄 1개**: `RootFirstPaint`(서버 HTML)와 웰컴 분기에 같은 자리·같은 모양으로 둔다. 공개 문서 3개로 가는 일반 `<a>` 링크다. 사전 조각에서 웰컴으로 바뀔 때 위치가 흔들리지 않게 한다. **[정정 11-21 challenge 2절·C2] 링크 대상은 가이드 3편만(체험·/ratio 제외), 같은 컴포넌트 1개를 양쪽에 둔다. 링크 줄이 웰컴 버튼에 밀려 내려가는 것은 수용하고, '흔들림 0'은 '히어로·신뢰 줄 이동 0'으로 정정한다. 누름은 GA `웰컴·가이드 열기`.** 보유자 홈·체험·마법사에는 넣지 않는다. 히트영역 40px, text-sm muted, 위 버튼보다 눈에 띄지 않게 한다.
  3. **가이드 하단 '다른 가이드'**: 1개 링크를 나머지 2개 목록으로 바꾼다. sitemap에 1행을 추가하고 루트 lastModified를 갱신한다.
