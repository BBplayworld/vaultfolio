## 사업 (대리 초안 — business-pm 확정 필요)
- **왜 지금**: 4.45에서 세금 관리 분리를 이 이슈로 넘겼다(같은 파일 두 번 수정 방지). 해외주식 세금 시즌(11~12월) 안인 ≤12/5에 머지해야 '도구' 위치 효과가 남는다.
- **누구를 위해**: 기기를 바꾸거나 PWA로 옮기며 백업 파일로 복원하려는 기존 사용자. 지금은 백업은 더보기 1단, 복원(가져오기)은 더보기 › 설정 › 데이터에 있어 짝이 갈라져 있다.
- **월 활성 100 기여**: 작다(정리 과제). 신규 유입 0, 기존 사용자의 복원 실패·이탈 예방. 성장 주력으로 보고하지 않는다. 비용 소, 저장·GA 무변경, 롤백 = revert, 위임 머지 대상(①~⑧).
- **지표(page_title, 새 이벤트 0)**: 보조 `백업`(export+import) 사용자 수 — 머지 후 4주가 기준선(11/6~머지 전일) 이상. 가드레일 `데이터 관리`(캐시 초기화·전체 삭제) 사용자 수가 늘지 않는다(삭제 위치를 앞당기지 않았는지 확인). 표본이 작아 정성 판독.
- **하지 않으면 잃는 것**: 세금 관리가 계속 '지원(도움말)'에 묻혀 시즌을 놓치고, 복원 경로가 2단계 아래에 숨은 채로 남는다.

### 2. 정돈안 (1개)
**더보기** (탭 행 6 → 7, 섹션 3 → 4 + 무제 설정 행. 전체 두 화면 합계 행 11 → 11, 이동만)
1. 프로필 — 그대로
2. **공유 · 백업** — 자산 공유 · 동기화 / 데이터 백업(마지막 백업 줄 유지) / **데이터 가져오기(설정에서 이동)** / 저장 현황 줄(설정에서 이동)
3. **도구** — 세금 관리(지원에서 이동)
4. 지원 — 의견·요청 보내기 / 앱 가이드 · 공지사항
5. (무제) 설정

**설정** (탭 행 5 → 4)
1. 보안 — 그대로 / 2. 화면 — 테마 행 **"다크 모드" + 우측 ON/OFF 배지**(앱 잠금 행과 같은 패턴 재사용, 누르면 전환 동작 그대로) / 3. 표시 — 그대로 / 4. **데이터 — 캐시 초기화 / 모든 데이터 삭제(맨 아래로 이동)** / 5. 버전 — 그대로

**톤(두 화면 공통)**: 섹션 제목은 라이트·다크 같은 중립(muted) 톤, 행 아이콘 단색(삭제 행 rose 의미색만 예외), 데스크톱에서 행 폭을 읽기 폭으로 제한(헤더 시작선과 정렬 권장 — 수치·정렬은 ui-designer).
- 삭제를 더보기로 올리지 않는 이유: 백업·복원은 '지키는' 동작이라 앞에, 초기화·삭제는 드물고 되돌릴 수 없어 한 단계 안쪽에 둔다(현재 위치 유지 = 위험 노출 증가 0). "데이터 행이 흩어졌다"는 문제의 실체는 백업·복원 짝 분리(P1)이다.

### 3. 사용자 행동 (관찰 가능)
- 복원하려는 사람이 더보기에서 **1번 탭**으로 가져오기에 도달한다(지금 2번: 설정 → 가져오기).
- 세금 관리를 '도구' 제목 아래에서 찾는다(위치 탭 수는 같음, 인식 개선).
- 설정에서 현재 테마를 ON/OFF로 바로 읽는다.

### 4. 범위
- **포함**: 위 행 이동 3건(가져오기·저장 현황·세금 관리), 섹션 제목 1건 변경("공유 · 동기화" → "공유 · 백업"), 설정 섹션 순서 1건, 테마 행 상태 배지, 섹션 제목·아이콘 톤 통일, 데스크톱 폭 제한.
- **줄일 수 있는 것**: 세금 관리 화면 내부 톤(UI 후보 5)은 기본 제외 — ui-designer가 헤더 아이콘 단색화 1곳만 동승할지 판단. 다이얼로그(공유 선택·도움말·의견) 내부 톤은 제외.
- **하지 않을 것**: 백업·가져오기·캐시·삭제의 **행 라벨·설명·토스트·확인 창 문구와 동작**(보안·데이터 문구 규칙, 위임 ⑤), 삭제 확인 창 제거, 가져오기 확인 창 추가, 설정 페이지 통폐합·새 URL, 뒤로 라벨, 테마를 세그먼트로 바꾸기, GA 이벤트·page_title, 저장 키, 결산 영역(결산 화면·홈 결산 팁·첫 화면), 홈 백업 팁, 웰컴의 '기존 데이터 가져오기', 하단 탭·인증카드(4.48).
