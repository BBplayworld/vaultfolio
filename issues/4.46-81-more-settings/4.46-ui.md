기준: origin/main 5391ba3(v4.45) 코드 + d6-ui-shots(더보기·설정 1280 라이트/다크, 현행 캡처; 이 환경은 브라우저가 없어 신규 캡처 불가 — ui-review에서 375·320·1280 × 라이트·다크 재촬영). design-system §1.2·§3·§5·§6·§7·§11 준수. **신규 토큰·컴포넌트 0, 신규 파일 1(상수 모듈).** 문구·동작 변경 0(spec §7-4).

## 1. 현행 근거 (캡처)
- 섹션 제목 `text-primary`: 라이트 인디고/다크 회색 — 같은 클래스인데 모드별 색 다름(P3). 행 아이콘 `text-primary`는 §3.2 "칩 없는 단색" 위계와 달리 인디고가 12곳 반복되어 액션 brand(확인 버튼)와 구분 안 됨.
- 1280: 행이 콘텐츠 영역 폭(약 1180px)까지 늘어나 라벨과 우측 chevron/배지가 1000px 이상 떨어짐. 헤더 뒤로가기 화살표 왼쪽 끝과 행 왼쪽 끝은 이미 같은 시작선(콘텐츠 `md:px-12`).
- 삭제 행은 `bg-rose-500/5` + rose 텍스트로 이미 충분히 구분됨 → 유지.

## 2. 공용 상수 (신규 파일 1개, 재사용 우선)
`src/app/(main)/_components/header-menu/menu-styles.ts` — 두 화면의 중복 상수를 모은다(components.md 등록, 배치 갱신 때). 값:

| MENU_ROW | 현행 ROW 그대로(`w-full flex items-center gap-3 px-4 py-3.5 rounded-xl bg-card dark:shadow-xs hover:bg-accent dark:hover:bg-accent/60 transition-colors text-left disabled:opacity-50 disabled:cursor-not-allowed`) |

## 3. 결정 사항
1. **섹션 제목 톤**: `text-muted-foreground` (라이트 oklch .45 on 캔버스 .96 ≈ 6:1, 다크 .74 on .145 — 양 모드 AA, 양 모드 같은 위계). 인디고·투명도 중첩 금지(§11). 현행 `font-semibold text-sm` 유지로 위계 유지.
2. **행 아이콘 단색**: `text-muted-foreground`(MENU_ICON) 통일. 예외는 삭제 행 rose(`Trash2`는 클래스 없이 부모 text-rose 상속, 현행 그대로). 행 라벨은 `text-foreground`(기본)로 아이콘보다 한 단계 진하게 → 라벨 우선 위계. 프로필 행 `User` 아이콘, 앱 잠금 `ShieldCheck`, 화면 `Moon`, 가져오기/백업 `Download`/`Upload`, 세금 `Receipt`, 설정 `Settings`도 모두 MENU_ICON. 공유 행의 동기화 중 스피너 `RefreshCw`는 `size-4 text-primary`(활성 상태 신호) 유지. chevron은 현행(`size-4 text-muted-foreground ml-auto`).
3. **1280 폭·정렬**: 두 화면의 최상위 래퍼 `flex flex-col gap-5` → `MENU_COLUMN`(`max-w-2xl` = 672px). **좌정렬**(mx-auto 금지): 헤더 뒤로가기·제목과 시작선이 같다(캡처 확인). 모바일(<672px)은 w-full이라 375·320 무변화. 푸터·하단 영역은 건드리지 않는다.
4. **테마 행 ON/OFF**: 라벨은 항상 "다크 모드"(상태 반전 라벨 삭제 — spec §4-6), 아이콘은 `Moon` 고정(Sun 분기 삭제, import 정리). 우측 배지는 앱 잠금 배지 클래스를 그대로 재사용: ON `bg-primary/15 text-primary`, OFF `bg-muted text-muted-foreground`, 공통 `text-sm font-semibold px-2 py-0.5 rounded shrink-0`. 판정값 `themeMode === "dark"`. 행에 `aria-pressed={themeMode==="dark"}`(앱 잠금 행도 `aria-pressed={pwaAuthEnabled}` 같이 부여 — 변경 최소·접근성). 배지 텍스트 전환은 즉시(색 `transition-colors` 상속 불필요), 행 구조가 재마운트되지 않으므로 모션 소실 이슈 없음. 안내문(설명 줄)은 추가하지 않는다(문구 최소).
5. **'공유 · 백업' 구성**(순서 고정, 모두 MENU_ROW, 행 간 gap-2):
   ① 자산 공유 · 동기화 › (현행) → ② 데이터 백업 + 마지막 백업 줄(현행, 오래된 백업 orange 유지) → ③ 데이터 가져오기 + "JSON 백업 파일로부터 자산 복원"(Download 아이콘, `disabled={isImporting}`만, 현행 라벨·로딩 문구) → ④ 저장 현황 줄: `<p className="px-4 pt-1 text-sm text-muted-foreground tabular-nums text-pretty break-keep">` 현행 조건 `stats.itemCount > 0`. 구간 단위("자산 N개", "일별 기록 N일", "(+보관 N개월)", "약 N KB")는 각각 `<span className="whitespace-nowrap">`로 감싸 320에서 단위 중간 끊김 방지. 숨겨진 `<input type=file className="hidden">`는 tool-menu로 이동(settings에서 제거).
6. **삭제 행 rose 예외 위치**: 설정 › 데이터 안 맨 아래(캐시 초기화 다음), 위쪽 행과 `mt-2` 추가 간격(총 16px)으로 위험 행을 한 칸 분리. 스타일·문구·확인 창 불변. 저장 현황 줄이 빠지므로 삭제 행이 섹션의 마지막 요소가 된다. 더보기에는 두지 않는다.
7. **세금 관리 '도구' 섹션**: `<section>` + 제목 "도구"(MENU_SECTION_LABEL) + 행 1개(Receipt MENU_ICON, "세금 관리", chevron). 행 1개 섹션이어도 제목 유지(위계 일관). 순서: 프로필 → 공유 · 백업 → 도구 → 지원(의견·요청 보내기, 앱 가이드 · 공지사항) → 무제 설정 행(섹션 사이 gap-5 유지).
8. **세금 화면 헤더 아이콘 단색화**: **포함하지 않는다.** 근거: spec §7-9가 세금 관리 화면 diff 0을 요구하고, `tax-calendar-view.tsx:61`의 주황(`ASSET_THEME.important`)은 §1.2 "주목 유도" 의미색 용법에 해당해 오용이 아님. 필요 시 별도 과제.

## 4. 상태·엣지
- 기본·로딩: 가져오기 중 "데이터 가져오는 중..." 비활성(opacity-50, 현행). 자산 0: 백업·공유 행 disabled, 가져오기 활성, 저장 현황 숨김.
- 첫 사용(백업 이력 없음)/오래된 백업: 현행 문구·주황 유지. 긴 문구: 전 라벨 `break-keep`, 우측 배지·chevron `shrink-0`, 설명 `text-pretty`.
- 다크: 행 `bg-card`+`dark:shadow-xs`, 삭제 행 다크 `border-0` 현행. 라이트 박스 분리는 §3.3 bg-card 톤차 그대로.
- 숨은 GA 트리거("화면" 라벨 7탭 `handleGaOptoutTap`)는 라벨에 그대로 유지(onClick 이동 금지).

## 5. 인터랙션·접근성
- 신규 모션 없음. 화면 전환은 기존 `animate-in fade-in` 래퍼. 행 hover/press는 현행(`transition-colors`, `transition: all` 없음).
- 히트영역: 행 `py-3.5`+16px 이상 텍스트 → 높이 ≥ 52px(≥40px). 프로필 입력 행 `py-3` ≈ 44px. 행 전체가 button이라 확장 불필요.
- 키보드: 모든 행 `<button>`, 포커스 링은 전역 기본. aria-pressed는 위 4번.
- 대비: 제목·아이콘 muted AA, 배지 ON `text-primary on primary/15`(현행 앱 잠금과 동일 통과값).

## 6. data-testid (신규, qa용)

## 7. 문구
변경 문구는 섹션 제목 "공유 · 백업"(기존 "공유 · 동기화"), "도구"(신규)뿐. 테마 라벨 "다크 모드" 고정·배지 ON/OFF. 나머지 문자열 diff 0. 투자 조언 문구 없음.

## 8. 품질 체크리스트 (qa 판정용)
1. 더보기 섹션 제목 순서 프로필·공유 · 백업·도구·지원, 아래 설정 행(testid로 확인).
2. 공유 · 백업 행 순서: 공유 · 동기화 → 데이터 백업 → 데이터 가져오기 → 저장 현황 줄(자산 있을 때만).
3. 모든 섹션 제목 computed color가 라이트·다크 각각 `--muted-foreground`와 같고 인디고(`--primary`)가 아니다.
4. 행 아이콘 computed color = muted-foreground, 삭제 행 아이콘만 rose. 공유 동기화 스피너만 primary.
5. 1280에서 두 화면 행 width ≤ 672px이고 left가 헤더 뒤로가기 버튼 left와 같다(±2px, 좌정렬).
6. 375·320에서 가로 스크롤 0, 라벨·설명 어절 중간 줄바꿈 0(`word-break: keep-all` computed, C25), 저장 현황 줄의 "N개/N일/약 N KB" 단위가 쪼개지지 않음.
7. 화면 행: 라벨 "다크 모드" 고정, 라이트 OFF → 클릭 → 다크 + ON(배지 색 primary/15), 반대도 동일, aria-pressed 일치.
8. 앱 잠금 배지와 테마 배지의 className(색·크기·radius)이 같다.
9. 설정에 가져오기 행·저장 현황·hidden file input이 없고 섹션 순서 보안→화면→표시→데이터→버전, 데이터 안은 캐시 초기화→삭제.
10. 삭제 행이 마지막이며 캐시 행과 간격 16px, rose 스타일 유지, 클릭 시 확인 창 경유.
11. 모든 행 높이 ≥ 40px(실측 ≥ 52px).
12. 다크 모드 제목·아이콘 대비 ≥ 4.5:1(제목) / ≥ 3:1(아이콘).
13. 백업·가져오기·캐시·삭제 문자열 diff 0, 세금 관리 화면·홈·결산 파일 diff 0.
14. 가져오기 성공 후 홈 이동, 체험 모드 더보기 숨김 유지, 자산 0 상태 행 활성/비활성 규칙 준수.
