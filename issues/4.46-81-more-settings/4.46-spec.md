# 4.46 #81 더보기·설정 정돈과 백업 통합 — 명세

기준 코드: origin/main 5391ba3(v4.45). 방향: `4.46-direction.md`(합의 전 초안 — 합의·challenge 통과 후 확정). 유형 simplify, risk:low, 위임 머지 대상.

## 1. 문제
백업(더보기 1단)과 복원(설정 › 데이터)이 갈라져 있고, 세금 관리가 '지원'(도움말) 묶음에 섞여 있다. 섹션 제목·아이콘 색이 라이트(인디고)·다크(회색)에서 다르고, 1280에서 행이 화면 끝까지 늘어나며, 테마 행은 현재 상태를 보여 주지 않는다.

## 2. 목표 행동
- 복원하려는 사용자가 더보기에서 탭 1번으로 '데이터 가져오기'에 닿는다.
- 세금 관리를 '도구' 아래에서 찾는다.
- 설정 화면에서 지금 다크 모드인지 ON/OFF로 읽는다.

## 3. 범위
- 포함: 더보기 섹션 재배치(공유 · 백업 / 도구 / 지원), 가져오기 행·저장 현황 줄을 설정 → 더보기로 이동, 설정 섹션 순서(보안 · 화면 · 표시 · 데이터 · 버전), 데이터 섹션 안 순서(캐시 초기화 → 모든 데이터 삭제), 테마 행 ON/OFF 배지, 섹션 제목·행 아이콘 톤 통일, 데스크톱 행 폭 제한.
- 제외: direction 4절 "하지 않을 것" 전부. 특히 백업·가져오기·캐시·삭제의 라벨·설명·토스트·확인 창·동작, 저장 키·GA·결산·홈·웰컴.

## 4. 사용자 흐름
1. 하단 탭(또는 상단) 더보기 → 섹션 순서: 프로필 · 공유 · 백업 · 도구 · 지원 · (설정 행).
2. '공유 · 백업' 안 순서: 자산 공유 · 동기화 › / 데이터 백업(마지막 백업 줄) / 데이터 가져오기(JSON 백업 파일로부터 자산 복원) / 저장 현황 줄(자산 N개 · 일별 기록 N일 · 약 N KB).
3. 데이터 백업을 누르면 지금과 같이 즉시 파일이 내려가고 마지막 백업 줄이 갱신된다.
4. 데이터 가져오기를 누르면 파일 선택 → 성공 시 지금과 같이 토스트 후 홈으로 이동한다.
5. 도구 › 세금 관리 → 세금 관리 화면(기본 탭 일정), 뒤로가기 → 더보기.
6. 설정 행 → 설정: 보안(앱 잠금 ON/OFF) · 화면(다크 모드 ON/OFF) · 표시(종가 기준) · 데이터(캐시 초기화 · 모든 데이터 삭제 → 확인 창) · 버전.
7. 화면 행을 누르면 테마가 바뀌고 배지가 ON↔OFF로 즉시 바뀐다.

## 6. 엣지 케이스
- 자산 0건: 웰컴 상태에서는 더보기 진입이 숨겨진다(현행). 자산을 모두 삭제한 직후 등 더보기가 보이면 백업 행은 지금처럼 비활성, 가져오기 행은 활성(설정의 현행과 동일), 저장 현황 줄은 항목 0이면 숨김(현행 조건 `itemCount > 0`).
- 가져오기 진행 중: 행 라벨 "데이터 가져오는 중..."·비활성(현행). 실패 토스트 현행.
- 첫 사용자(백업 이력 없음): "아직 백업하지 않았습니다" 그대로. 오래된 백업: 주황 경고 그대로.
- 일부 갱신·오래된 데이터: 백업 시 화면 state와 저장소 불일치 가드(`isExportDataStale`) 그대로 — 호출 경로 변경 없음.
- 체험 모드: 더보기 숨김(현행) → 변화 없음. preview 데모: 가져오기 동작은 현행 그대로.
- 동기화 연결 상태: 삭제 확인 창의 동기화 해제 문장 조건(`cs.status !== "none"`) 그대로.
- 1280·라이트/다크·320: 섹션 제목·아이콘 색이 두 모드에서 같은 위계, 한글 행 라벨 어절 중간 줄바꿈 없음.

## 7. 완료 기준 (qa가 그대로 검사)
1. 더보기 섹션 제목이 위에서부터 "프로필", "공유 · 백업", "도구", "지원" 순이고 그 아래 '설정' 행이 있다. '지원' 안에 세금 관리 행이 없다.
2. '공유 · 백업' 안 행 순서가 자산 공유 · 동기화 → 데이터 백업 → 데이터 가져오기이고, 자산이 있으면 그 아래 저장 현황 줄 1개가 보인다.
3. 설정에 '데이터 가져오기' 행과 저장 현황 줄이 없다. 설정 섹션 제목 순서가 보안 → 화면 → 표시 → 데이터 → 버전이고, 데이터 안은 캐시 초기화 → 모든 데이터 삭제 순이다.
4. 백업·가져오기·캐시 초기화·모든 데이터 삭제의 행 라벨, 설명, 토스트, 삭제 확인 창 제목·본문·버튼 문자열이 5391ba3과 문자 단위로 같다(diff에서 해당 문자열 변경 0).
5. 가져오기 성공 시 홈으로 이동하고 자산이 복원된다. 백업은 파일이 내려가고 마지막 백업 줄이 갱신된다. 삭제는 확인 창을 거쳐야만 실행된다.
6. 라이트에서 화면 행은 "다크 모드 · OFF", 행을 누르면 다크로 바뀌고 "다크 모드 · ON"이 된다(반대도 동일). 앱 잠금 배지와 같은 모양이다.
7. 라이트·다크 모두 섹션 제목이 같은 중립 톤이고 인디고가 아니다. 행 아이콘은 단색이며 삭제 행만 rose다.
8. 1280에서 두 화면의 행 폭이 ui.md가 정한 최대 폭 이하다. 375·320에서 행·라벨이 잘리거나 어절 중간에서 줄바꿈되지 않는다(C25).
9. 결산 화면·홈(팁 포함)·웰컴·세금 관리 화면·저장 키·GA 관련 파일 diff 0. 변경 파일은 tool-menu.tsx·settings-page.tsx(+필요 시 공용 행 상수)와 KB 문서뿐이다.
10. 뒤로가기: 설정·세금 관리에서 뒤로 → 더보기, 더보기에서 뒤로 → 홈(현행, R31 콜드스타트 폴백 포함).
