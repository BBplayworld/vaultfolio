## 4. 모션
- 패널은 항상 마운트+`grid-template-rows,opacity 0.2s`, 닫힘 `inert`: 열기 t+20ms 0.44 → t+250ms 1.0(보간 확인), 닫는 도중(60ms) 31% 지점에서 역전, 3연타·열자마자 닫기 모두 마지막 상태로 수렴, 깜빡임 없음. reduced-motion에서는 즉시(`transition all 0s`). 포커스 입력 이동 통과, `바꾸기`도 입력 포커스·검색어 비움.
- **미흡(R-1)**: 위 보간은 패널만이고 `종목` Select·`다른 종목 찾기`·요약 카드는 조건부 렌더라 즉시 사라지고/나타난다.

## 5. 편차 판정
| 항목 | 판정 |
|---|---|
| `data-reason` `account`(spec) vs `match`(ui.md) | **수용**. spec AC-17이 정본이고 qa가 `account`로 검사. ui.md 표 상태 D·§9-8·§7 표기를 `account`로 정정 필요(문서 정정은 ui-designer 몫, 코드 변경 아님) |
| 보유 0개에서 매도 전환 시 빈 `종목` Select 재노출 | **수용**. 빈 계정에서 매도할 보유 종목이 없는 정상 상태이고 main도 동일한 빈 Select. 매수로 돌아오면 검색 복귀 확인(캡처 `ur-*-zero_sell`) |
| 결과 선택 뒤 증권사 트리거 포커스 이동 미구현(ui.md §4) | **수용(권고 수준)**. 선택 직후 포커스가 문서 흐름에 남음. 키보드 사용자는 Tab 1~2회라 차단 아님, qa 접근성 메모로 |

## 6. 수정 요청
- **R-1 (필수) 종목 영역 전환 시 높이 튐.** 재현: 보유 ≥1 + 매수에서 `다른 종목 찾기` 클릭 → 종목 영역 높이가 138 → 102(20ms, Select·버튼 즉시 사라짐) → 156 → 194px로 줄었다 늘어남, 닫기(`보유 종목에서 고르기`)는 반대로 Select·버튼이 즉시 나타나며 아래 폼이 한 번 튐(390 실측). 기대: ui.md §4 "항상 마운트+접힘, 버튼 opacity 150ms 교차" — `trade-input.tsx` 종목 FormItem의 Select·`다른 종목 찾기`(조건부 렌더 `!pickedNew && !showSearchPanel`)도 같은 방식(grid-rows 0fr↔1fr + `inert`)으로 접어 합계 높이가 단조 변화하게 하거나, 최소한 두 상태 높이 차를 한 컨테이너 전환으로 처리. reduced-motion은 즉시. 요약 카드는 현재 진입 애니메이션만 있고 `바꾸기` 시 즉시 사라지는 것은 허용.
- **R-2 (권고) 요약 카드 아래 간격.** 선택 후 요약 카드 하단→`자산 항목 *` 라벨이 약 24px로 다른 필드 간격(16)보다 넓음. 접힌 패널(`trade-stock-search`, 0px)이 `FormItem space-y-2` 슬롯으로 8px를 더함. 기대: 접힌 상태에서 추가 간격 0(패널에 `-mt-2` 보정 또는 접힘 시 `mt` 0 처리). R-1과 같은 컨테이너 정리 때 함께.
- **R-3 (권고, 관찰)** D1 안내(`이미 가진 종목이라 보유 종목에서 골랐어요`)가 이후 `신규 자산 등록`을 열고 일치 안내(`account`)가 뜨는 동안에도 남아 안내 2줄이 겹쳐 보임(`ur-390-light-match.png` 재현, 둘 다 사실이라 오표기는 아님). 기대: 신규 자산 등록을 고르면 ticker 안내는 숨김(선택, 미반영이어도 승인 영향 없음).
