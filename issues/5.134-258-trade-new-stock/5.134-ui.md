## 0. 핵심 결정
1. **진입은 보유 종목 Select 바로 아래 전폭 `variant="secondary"` 버튼 `다른 종목 찾기`**(검색 아이콘, h-10). 링크형·아이콘형 금지(히트·발견성). 매도면 없음.
2. **검색은 팝오버가 아니라 인라인 패널**(다이얼로그 안 겹침·키보드 가림 방지): `국내|해외` 세그먼트 → 입력 → 결과 목록(2줄 행 48px). 패널 바닥에 `보유 종목에서 고르기`(보유 ≥1일 때만). 제목 줄은 두지 않는다(바깥 라벨 `종목`과 중복, 320에서 줄바꿈).
3. **고르면 패널이 접히고 요약 카드로 바뀐다**(이름 / `코드 · 시장` / `현재가 …`), 오른쪽 `바꾸기`. 바로 아래 `자산 항목 *`이 `신규 자산 등록` 선택 상태로 열린다(기존 StockTargetPicker 그대로).
4. 보유 0개: 라벨 `종목` 아래에 박스 없이 검색 곧바로(세그먼트+입력). 빈 Select·`다른 종목 찾기` 없음.
5. 코인 안내는 **아이콘 없는 한 문단**, 실제 진입 이름을 적는다(`보유 현황 업데이트 › 암호화폐`). 320(콘텐츠 240px)에서 3줄, 390에서 2줄(planner design-review 수용: 진입 이름·`산 만큼` 우선).
6. ~~spec 변경 요청~~ **수용·spec 반영 완료**(design-review 1-(a)): 검색 오류·오프라인은 `검색하지 못했어요. 연결을 확인해 주세요.`
7. **picker 320 예외 수용·spec 반영 완료**(AC-14 ②): `<360px`에서 신규 증권사·종류 1열(`max-[359px]:grid-cols-1`, 360↑ 2열). 거래 입력·스크린샷 두 호출부에 함께 나타난다.

## 4. 인터랙션·모션 (CSS, `motion-safe`)
- **항상 마운트 + 접힘 전환**(§6 높이 펼침, 재마운트 없음): 검색 패널·신규 Select 2칸은 `grid motion-safe:transition-[grid-template-rows,opacity] duration-200 ease-out`, 닫힘 `grid-rows-[0fr] opacity-0 inert`(포커스를 옮기므로 `visibility` 전환은 뺀다, §6 변형). `다른 종목 찾기` 누르면 버튼은 패널과 교차(버튼 `opacity` 150ms 사라짐). 연타·열자마자 닫기는 CSS가 현재 값에서 역전.
- 결과 목록은 `key=ticker`(입력마다 전체 재마운트 금지, 깜빡임 방지). 행 진입 `motion-safe:animate-in fade-in duration-150`, stagger 없음(5행·즉시성 우선).
- 요약 카드 진입 `motion-safe:animate-in fade-in slide-in-from-bottom-1 duration-200`. 선택 카드 링 `transition-[background-color,box-shadow]`(기존). 전 요소 `transition: all` 금지, 누름 `active:scale-[0.96]`(Button 내장; 결과 행·카드는 `motion-safe:active:scale-[0.98]`).
- 포커스: `다른 종목 찾기` 누르면 입력으로. 결과 선택 뒤 `증권사 선택` 트리거로(키보드 흐름). `바꾸기` 누르면 검색 입력으로(이전 검색어는 비움). 시장 칸 바꾸면 같은 검색어로 재검색.
- 키보드: 입력에서 ↑↓ 활성 이동·Enter 선택(인라인 모드는 Esc를 가로채지 않는다 — Esc는 다이얼로그 닫기). 팝오버 모드(주식 추가)는 기존 ↑↓·Enter·Esc 그대로(AC-12).
- 연타·중간 전환: 매수→매도, 카테고리 변경, 시장 변경은 모두 진행 중 요청을 `AbortController`로 취소하고(기존 방식) 결과·요약을 위 표대로 해제.

## 5. 접근성
- 히트 40px: 진입 버튼 40, 세그먼트 칸 40, 결과 행 48, `바꾸기`·`보유 종목에서 고르기` 40, Select 트리거 36(기존, 이번 변경 아님).
- 입력 `role="combobox" aria-expanded aria-controls aria-autocomplete="list" aria-activedescendant`, 목록 `role="listbox"`, 행 `role="option" aria-selected`. 팝오버 모드(주식 추가)에도 같은 속성을 얹는다(시각 diff 0). 입력 라벨은 `종목`(`FormLabel`), 시장 세그먼트 `aria-label="검색할 시장"`(`role="tablist"` 아님 — 값 선택이라 `aria-pressed` 버튼 2개).
- 안내 줄(`price-note`·`empty`·`switched`)은 `role="status"`(오류 `role="alert"` 아님). 스켈레톤 `aria-busy`.
- 다크: 패널·요약·결과 활성은 `bg-muted/25~50` 톤차만(대비 1.08↑, §3.3), 입력은 기존 `dark:bg-muted/50` 유지. sky 아이콘은 `dark:text-sky-400/70`, 본문 보조색은 기존 `muted-foreground`(4.5:1 이상 기존 토큰).

## 9. 품질 체크리스트 (qa·ui-review 판정용)
1. 보유 ≥1 + 매수: `trade-find-other-stock`이 종목 Select 아래 전폭 40px로 보이고, 매도로 바꾸면 사라진다.
2. 누르면 패널이 200ms 안에 열려 입력에 포커스가 가고, `보유 종목에서 고르기`로 돌아오면 원래 Select 상태. `prefers-reduced-motion`에서는 즉시.
3. 보유 0개(delisted만 포함): 빈 Select 0개, 검색(세그먼트+입력)이 처음부터 보이고 박스 배경이 없다.
4. 결과 행 높이 ≥48px, `elementFromPoint`로 40px 이상 히트, 320·360·390에서 가로 스크롤 0(`documentElement.scrollWidth==clientWidth`).
5. 결과 0건·오류·오프라인 3상태 문구가 §6과 일치하고 오류 상태는 0건 문구와 다르다. 로딩은 스켈레톤 3행이 `aria-busy`.
6. 고른 뒤 요약 3줄(이름/`코드 · 시장`/현재가)이 320에서도 3줄이고 `·`이 줄 끝에 남지 않으며 시장 값이 결과 행과 같다. 시세 실패면 요약 2줄 + 안내 1줄이 보이고 체결일이 지난달이어도 유지.
7. 해외 검색 선택: 종류 Select에 `해외주식` 1개만, 국내는 4개(국내주식·IRP·ISA·연금저축펀드), 비상장 없음. 320에서 신규 2칸이 1열로 쌓이고 `증권사 선택`이 잘리지 않는다(360↑은 2열).
8. AC-17(D·D2): 신규에서 보유와 같은 증권사·종류를 고르면 신규 칸이 **열린 채** `data-reason=account` 안내 1줄이 보이고, 종류·증권사를 바꿔 일치가 풀리면 안내만 사라진다. 스크린샷 가져오기 행에도 같은 안내(fuzzy 후보만 있는 행은 없음). 저장 뒤 같은 ticker·broker·category 항목이 2개 생기지 않는다. AC-4(D1): 후보 1개 자동 선택·2개 미선택, 안내 `data-reason=ticker` 문구가 D와 다르다, 필터에 가려진 종목은 필터가 `전체`로.
9. 코인 폼: 안내가 **320 3줄 이하·390 2줄 이하**(실측 줄 나눔이 §6과 같음), 어절 중간 끊김 0(글자 단위, C114), 상세 진입(locked)에는 없음. 보유 코인 0개면 Select·`매수 기록` 없이 안내+`닫기`.
10. 라이트·다크 × 375·390·1280에서 요약·패널이 배경 톤차로 분리되고 테두리·장식 그림자·새 색 0, 다크 입력 경계 기존 유지.
11. 새 문자열 전수에 `연동`·`자동`·`동기화`·`추천`·`인기`·금액 예시·재등록 권유 0(AC-15) + 위 전수표를 qa 보고에 첨부(C139).
12. 열린 상태 캡처(C113): 검색 패널(결과·0건·오류), 요약+AC-9 안내, AC-17 안내, 코인 안내를 ui-review가 **실제로 열어** 320에서 캡처하고 C25 판정(상수 확인 금지).
13. `주식 추가` 검색은 시각 diff 0(팝오버 그대로, ↑↓·Enter·Esc 동일, AC-12); 상세 진입·스크린샷 거래 가져오기 화면 diff 0(picker 320 1열 예외 제외).
14. 연타: `다른 종목 찾기` 3회 연속·열자마자 닫기·시장 칸 빠른 전환에서 패널이 깜빡이거나 멈추지 않고 마지막 상태로 수렴한다(재마운트로 모션이 끊기지 않음).

## 10. developer 주의
- 접힘 패널은 조건부 렌더 금지(항상 마운트+`inert`). 결과 목록 `key`는 티커.
- 요약 3줄 고정, 이름만 truncate. 줄바꿈 한글은 `break-keep`, 코인·AC-9 문구는 어절 중간 끊김 0을 글자 단위로 직접 측정(C114).
