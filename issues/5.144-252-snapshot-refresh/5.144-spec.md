# 5.144 #252 spec — 등록한 날 재접속 없으면 다음 날 '신규 현금 +X' 반복
정본: `_discovery/2026-11-24-ceo-252.md`(범위 B안·ⓐ~ⓒ·risk:high), `_discovery/2026-11-20-252-snapshot-review.md`(원인·B안·테스트), `5.140-*`(`isCashTrackedForTrades` createdAt 경계 선례), CHECKLIST C143. 코드 기준 origin/main ca32e5c. **UI 변경 0**, 단독 릴리스.

## 1. 문제
일별 기록(`secretasset_daily_snapshots` 오늘 행)은 앱 열 때(`initAndSync`)·자산 0→양수 때만 쓰인다(`saveSnapshots` 2곳). D일 열고 자산을 등록한 뒤 다시 열지 않으면 행 D는 '등록 전'으로 남고, D+1 Hero 시작점이 이 행이라 같은 '신규 현금 +X'(주식 매수·대출 등도 동일)가 '전일 대비'에 한 번 더 나온다. #250 이후 주식만 가진 사용자의 현금 등록이 늘어 노출이 늘었다.

## 2. 목표 행동
등록·수정·삭제한 날은 그날 Hero에만 원인이 보이고, 다음 날 Hero는 그 뒤 생긴 변화만 보여 준다. 사용자는 다음 날 '전일 대비'를 실제 하루 변화로 읽는다.

## 3. 범위
포함
1. **행 계산 공유**: `saveSnapshots`의 행 계산부(nab·cost·fxBase·enrich)를 모듈 함수로 추출, 두 경로가 같은 수식 사용. 마지막 `refMap`·저장일을 ref에 보관.
2. **오늘 일별 행 1줄 재계산**: `ASSET_USER_EDIT_EVENT` 수신 시. 조건 = 평일 · 오늘 행 존재 · 이번 세션에서 오늘 `saveSnapshots` 성공(ref 날짜=오늘) · `saveSnapshotsBlockedRef`·`isBackgroundWorkBlocked()` 아님. 종가는 보관 refMap, 없는 종목은 `currentPrice`(기존 폴백과 동일). `grade` 보존. `setSnapshotVersion`만 올림. 월·연 행·`lastVisitDate`·assetData·네트워크 0.
3. **시작일 당일 경계 보정**: Hero 경로(`computeAttributionSince`→`resolveAttribution`, `getAttributionRecords` 같은 술어)에서 시작점이 **정밀(enriched)일 때만** 시작일 당일 현금·대출 기록은 `createdAt`(KST 날짜) > 시작일인 것만 포함(행이 닫힌 뒤 소급 입력). 거래 날짜(사용자 입력)는 판정에 쓰지 않음.
4. ⓐ 연속 편집은 디바운스로 묶어 1회 재작성, **동기화 push 디바운스(2.5초, `AUTO_PUSH_DEBOUNCE_MS`) 전에 완료**해 같은 push에 실린다.
5. ⓑ 데모·preview·백업 복원·동기화 pull 직후(차단 플래그 동안) no-op.
6. ⓒ 재작성은 계산 완료 후 한 번에 쓰기. 계산·파싱·쓰기 예외 시 기존 행 그대로(부분 쓰기 0).

제외: 일요일 행 갱신(일요일 Hero 시작점=토요일 행이라 갱신 시 그날 등록이 사라짐), 예측(레거시) 분기·#251 `estimatePeriodInflows`·결산(`computeAttributionBetween`)·월·연 행, 예측 구간 잔액 직접 수정 '시세' 표기, 행 작성 시각 필드 추가(스키마 변경), UI·문구.

## 4. 사용자 흐름
1. D일(평일) 앱 열기 → 행 D 저장(기존).
2. 현금 500만 등록 → 편집 신호 → (묶음 대기) → 행 D 재계산·저장 → 7일 카드 오늘 막대 즉시 반영 → 2.5초 뒤 동기화 push(행 D 포함, 암호문).
3. D일 Hero는 그대로 '신규 현금 +500만'(시작점=D 이전 행).
4. D+1 열기 → 시작점=행 D(등록 후) → 등록분 원인 없음.

## 6. 엣지 케이스
- 빈 데이터·첫 사용자: 0→양수는 기존 `saveSnapshots` 경로. 오늘 행 없으면 no-op.
- 오래된 데이터: 앱을 열어 둔 채 자정 경과(ref 날짜≠오늘) → no-op, 다음 열기에서 기존 경로.
- KIS 점검으로 오늘 `saveSnapshots` 스킵 → ref 날짜 불일치 → no-op.
- 일부 갱신: 신규 종목 종가 없음 → `currentPrice` 폴백.
