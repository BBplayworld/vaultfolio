## 변경 요약
- `src/lib/number-utils.ts`
  - `formatShortCurrencyDecimal`: `truncToFixed`(`Math.floor(n*100)/100`) 제거. 원 단위 정수 `won = Math.round(|v|)`(formatCurrency와 같은 기준)를 표시 최소 단위로 정수 나눗셈 후 버림 — 억 `floor(won/1e6)`, 백만 `floor(won/1e4)`, 만 `floor(won/100)`. 새 내부 헬퍼 `formatTruncatedUnits(units, digits)`가 정수부(천 단위 콤마)·소수부·끝 0 제거. 1만 미만은 `formatCurrency` 그대로. 부호 `-` 규칙 불변.
  - `formatShortCurrency`(0.1억): 같은 곱셈 뒤 버림 패턴(`Math.floor((abs/1e8)*10)/10`)을 `floor(abs/1e7)` 정수 나눗셈으로 정리. 1억~50억 100만원 배수·무작위 30만 값에서 표기 변화 0(예방 정리).
- 전수 grep 결과: 곱셈 뒤 `Math.floor`로 소수 자릿수 자르는 금액 표기는 `number-utils.ts` 2곳뿐. `asset-report.ts` `fmtManwon`은 만원 반올림 정수 → `toFixed(1)`(반올림 규칙, 결산 원인 금액)으로 이번 범위 밖(버림 오차 패턴 아님).
- `formatShortCurrencyDecimal` 사용처: 홈 `dashboard.tsx` 최근 순자산 막대 위 금액, `net-asset-chart.tsx` 순자산 달력 칸 금액. `formatShortCurrency` 사용처(결산·상세·차트 등 16파일)는 표기 변화 0.
- 4.67(#127) U2는 `formatMonthlyLogAmount` 자체 정수 경로로 별도 수정 중 — 이번 수정과 코드 겹침 없음. 두 릴리스 머지 후 월별 기록이 공용 함수로 되돌아갈지는 후속 판단(이번 범위 아님).
