## 4. 결론

**UI 수정 요청** (2건, 둘 다 작은 변경)

1. `src/app/(main)/_components/views/activity/profit-chart.tsx` → `ChangeHero` 호출부(약 555행)
   - 현재: `filteredProfits`에 `hasRef`가 하나도 없어도 `delta={totalProfit}`(0)·`start/end`(0)가 넘어가 "+0원 0원 → 0원"이 빨강으로 렌더됨
   - 기대: 기준가가 있는 종목이 0개이면(`!isLoading && filteredProfits.every(r => !r.hasRef)`) 증감·시작→끝 줄을 그리지 않고 Hero에 메시지 1줄(`text-sm text-muted-foreground`) "기준가를 불러오지 못했어요. 잠시 후 다시 확인해 주세요". 이미 API 점검 분기가 있으면 그 문구 "점검 중"을 재사용. 이름 줄·기간 선택은 그대로(ui.md §3 오류 상태와 같은 모양)
   - 확인: 해당 상태에서 `change-hero-delta`가 없음
2. `src/app/(main)/_components/views/activity/change-hero.tsx` → 이름 줄 월 화살표 그룹
   - 현재: `ml-auto`라서 1280에서 화살표가 "10월 결산"과 약 1,070px 떨어진 Hero 오른쪽 끝에 붙음. 무엇을 넘기는지 연결이 약하고 마우스 이동 거리가 김
   - 기대: 375는 지금처럼 오른쪽 끝, sm 이상은 구간 텍스트 바로 뒤(`ml-auto sm:ml-2`). 크기 40×40·`data-screenshot-hide`·aria는 그대로

수정 후 ui-designer가 해당 2개 화면(375 다크 주식 실패 상태, 1280 라이트·다크 월)만 다시 촬영해 승인함. 나머지 항목은 승인 상태.
