# #32 r2 spec — 성과 정보 구조 재설계: 결산·자산 변화·성적표 중복 제거 + 상단 컨트롤

근거: direction.md **합의 절(축소 반영본)만** + challenge.md 조건 S1~S10(괄호 `(S#)`). r1 spec(`r1/4.34-spec.md`)의 데이터 규칙은 §5에 재배치. 위험: 릴리스 v4.34 high, r2 증분 medium. 코드 기준 `issue-4.34` @e4af3dd.

## 1. 문제
- r1이 메뉴만 줄이고 항목은 복제했다. 변화 원인이 결산(`settlement-view.tsx`)과 성적표 "순자산 변화, 왜?"(`asset-report-view.tsx`)에 따로 있고, 월 증감은 허브 결산 카드·결산 헤더·순자산 비교·성적표 1개월에 4번 나온다.
- 자산 변화 상단은 컨트롤 3줄(주식은 4줄)이 Hero보다 먼저 온다. 스타일 두 종류(`tabList2` 캡슐, `tabList3` `border-2` 외곽선)에 `text-xs`·`transition-all`을 쓰고 Radix Tabs를 써서 §5 InlineSelector 통일에서 벗어나 있다. 결산 증감은 375px 화면에서 y≈525에야 보인다.

## 2. 목표 행동
결산 창에 허브 "자산 변화" 카드(배지 "N월 결산")를 눌러 월 탭에 들어온다. 스크롤 없이 증감액과 변화 원인을 읽는다. Hero 아래 기간 선택으로 일·주·월·연을 바꿔 같은 자리에서 숫자를 비교한다. 원인을 보러 성적표에 가지 않는다.

## 5. 화면 구성 (위→아래)
- **허브**(3카드): ①자산 변화 — 결산 창(말일−3일~다음 달 10일, 비교 가능)이면 배지 "N월 결산" + 구간 + 증감·% "지난 기록 대비", 창 밖이면 "N월 · 진행 중" 증감, 첫 달·스냅샷 0이면 "다음 달부터 결산이 열려요"(금액 없음). 누르면 월 탭(창 안이면 해당 달·`source=card`, 밖이면 `menu`) ②배당(기존) ③성적표(기존)
- **자산 변화**: ①제목 행 h-11: h2 "자산 변화" + 오른쪽 범위 선택 ②`ChangeHero`(`SECTION`): 이름 줄(월만 ‹ ›) → 증감 → "시작 → 끝" → 기간 선택 ③본문: 일=달력 / 주=일자 목록 / 월=변화 원인 → 다음 달 준비 / 연=차트·목록. 주식=시장 필터(sm, 오른쪽) → 종목 목록
- **월 탭 = N월 결산**: Hero 이름 "10월 결산"(진행 중이면 "11월" + `GROUP_BADGE` "진행 중", 전년도 "25년 10월 결산"), 구간 "9/28 → 10/28"(레거시는 "YYYY-MM 기록 기준"), 35일 초과면 Hero 아래 "기록 간격이 길어 N일 구간이에요". 본문 변화 원인(5항목) → 다음 달 준비(오래된 자산 행 + .ics 버튼 + 안내 문구)
- **성적표**: 등급 Hero → 투입 대비 성과 → 5축 → AI 프롬프트("왜?" 섹션·`attrPeriod` 상태·관련 import 삭제)
- 구조: 계산은 지금 위치에 둔다. `AssetChangeView`가 기간 선택 노드를 각 본문(`SettlementView`·`WeekList`·`YearlyNetAssetChart`·`ProfitCard`)에 넘기고, 각 본문이 자기 값으로 `ChangeHero`를 그린다(`views/activity/change-hero.tsx` 로컬, 카탈로그 미등록). `YearlyNetAssetChart`·`ProfitCard`는 제어 모드(`view`/`period` 지정)일 때만 자체 제목·Hero를 숨긴다.

## 6. 상단 컨트롤 사양 (375px, 콘텐츠 폭 351px)
- **InlineSelector `fullWidth`**(기본 false). 지정 시: `grid` 같은 폭 칸(`grid-template-columns: repeat(n,1fr)`), 트랙 `relative rounded-lg bg-muted/70 dark:bg-muted/50 p-0.5`, 썸 = 절대 위치 1칸 폭 `rounded-md bg-card dark:bg-foreground/15 shadow-sm`, 위치 `translateX(index*100%)`(JS 측정 없음, S3). 칸 `min-h-10 text-sm`, 선택 `text-foreground font-semibold`, 비선택 `text-muted-foreground hover:text-foreground`, 비활성 `text-muted-foreground/40` + `title`. 테두리 없음
  - 범위: `w-[164px]`, 칸 80×40. 기간: `w-full`, Hero 안 `mt-4`, 칸 ≈79×40
- **월 화살표**: `<button>` `size-10 rounded-full hover:bg-muted text-muted-foreground`, `aria-label` "이전 달"/"다음 달". 기록 없는 달은 건너뛰고(`listSettlementMonths().enabled`), 끝에서는 `disabled`
- **Hero 타이포**(홈 Hero와 동일): 이름 `text-sm font-semibold text-foreground` + 구간 `text-sm text-muted-foreground tabular-nums`, 증감 `text-2xl sm:text-3xl font-bold tabular-nums leading-tight` + `getProfitLossColor`, % `text-base font-bold`, 시작→끝 `text-sm text-muted-foreground tabular-nums`
- **상태 7종**(S9): 선택 / 비활성(화살표·칸) / 로딩(주식 기준가 조회: 증감 자리 `h-8 w-44 rounded-md bg-muted motion-safe:animate-pulse` + "기준가 조회 중…", 컨트롤 조작 가능. 조회 실패는 "점검 중") / 오류("결산을 불러오지 못했어요. 다른 달을 선택해 보세요", 화살표 동작) / 빈("아직 기록된 달이 없어요. 앱을 계속 쓰면 다음 달부터 결산이 열려요") / 첫 달("다음 달부터 결산이 열려요") / 추정(원인 행 "예측"·"일부 예측", Hero "일부 이전 값")
- **모션**(모두 `motion-safe`): 썸 `transition-[transform] duration-200 ease-[cubic-bezier(0.2,0.8,0.2,1)]`, 글자 `transition-[color] duration-150`, 칸 `active:scale-[0.96]`. Hero 숫자 위치 고정 + `fade-in duration-200`, 월 이동도 fade만(축소 5). 본문 `fade-in slide-in-from-bottom-1 duration-300`, 원인 행 40ms stagger. 퇴장 없음. `transition-all`·`will-change` 없음
- **접근성**: `role="radiogroup"` + `aria-label` "범위 선택"/"기간 선택", 칸 `role="radio" aria-checked`. ←/→·Home/End 이동 + 로빙 tabindex는 **fullWidth에만**(S2). Hero 증감 영역 `aria-live="polite"`. 히트영역 전부 ≥40×40
- **공유 이미지**: 범위·기간 선택은 남김(상태 표시). 월 화살표·"일부 이전 값" 배지·다음 달 준비는 `data-screenshot-hide`

## 7. 데이터 규칙 (r1 유지, 코드 이미 구현 — 변경 없음)
- 13개월 롤링 보존 `pruneMonthlySnapshots`(현재월 포함 13개, 연 경계 2026-01·2027-01 고정), 동기화 pull 병합 제외(알려진 한계)
- 결산 구간 = 직전 기록 → 해당 기록. 카드 대상 달은 전월 `date` 21일 이후면 전월 결산, 아니면 진행 구간. 간격 25일 이상이면 날짜 구간 표기, 35일 초과면 간격 안내
- 엔진 키 → 5항목 `mapSettlementCauses`(시세 변동·평가 갱신·환율 효과·순유입·기록 안 된 변화, 내부 이동 풀 상쇄, 현금 미등록 예외, 0원 숨김, 합계=Δ순자산, 50% 이상이면 입출금 안내)
- `.ics`: 1개 이벤트, `RRULE:FREQ=MONTHLY;BYMONTHDAY=-1`, 21:00 KST, 금액 없음, CRLF, RFC 5545 자동 검증. iOS PWA 실동작은 알려진 한계
- **GA `settlement_view`(S5)** — 현재 동작 그대로: `SettlementView` 마운트당 1회. 다른 기간·범위에서 월(전체)로 돌아오면 다시 마운트되므로 1회 발화(`source=menu`). 월 화살표 이동은 발화 안 함. 범위를 주식으로 바꾸면 발화 안 함. `source=card`는 결산 창 안에서 허브 카드를 눌러 진입했을 때만. `result`=settled/in_progress/first_month, 금액 미전송. 출시 전후 card 비율 하락은 정의 변경 결과(business.md 1줄)

## 9. 엣지 케이스
- 첫 달·스냅샷 0·자산 0: 허브는 금액 없이 안내, 월 탭은 빈/첫 달 상태. 화살표 비활성

- 1월 경계: 12월 결산의 시작(11월)이 보존됨, 화살표가 연을 넘어 "25년 12월 결산"으로 이동
- 주식 범위 기준가 조회 실패: Hero "점검 중", 본문 기존 처리. 일별 스냅샷 1건 이하: Hero 증감 줄 없이 "기록이 쌓이면 더 보여드려요"

- 예측 배지: 이자 추정이 금액에 들어가면 `estimated=true`(기존 "예측"/"일부 예측"·2행 이상이면 제목 옆 1개 규칙 그대로). 이자가 들어가지 않은 순수 잔액 증감분은 엔진 debt의 estimated를 따른다. 새 배지·문구 없음

### 2. "대출" 금액 정의 (C23 준수)
기존 매핑·짝짓기(matchRecordedTransfers)는 그대로 돌리고, 그 결과 "기록 안 된 변화" U(= Δ순자산 − 시세·평가·환율·순유입)를 **더 쪼개는 후처리**로만 만든다.
- 이자 추정 I = Σ(현재 대출 잔액 × 금리 ÷ 100) × 구간 일수 ÷ 365, 잔액>0·금리>0 대출 전체(엔진 `annualInterest`와 같은 식, 부동산 담보 포함). 구간 일수 = 시작일→끝일(연 = 앵커 12-31 → 오늘)
- 사용분 B = max(0, −Σ엔진 debt) — 구간에서 늘어난 대출(순증)만
- **대출 = −min( max(0, −U), I + B )**. 즉 U가 음수(순자산이 설명 없이 줄어듦)일 때만, U 크기를 넘지 않는 선에서 이자 추정+대출 순증을 "대출"로 뗀다. 기록 안 된 변화 = U − 대출
- 성질: ① U가 0 이상이면 대출 0 → 차입해 자산을 샀거나 현금으로 들고 있어 U≈0인 경우 행 자체가 안 생긴다(순자산 영향 0은 표시 안 함). ② 대출과 기록 안 된 변화는 부호가 같거나 0 → 서로 반대 큰 값이 나란히 나오지 않는다. ③ 합 항등식 불변(Σ원인 = Hero 증감). ④ 이자를 입출금으로 이미 기록한 사용자는 순유입에 반영돼 U에서 중복 차감되지 않는다(min 상한)
- 한계(명시): 잔액은 현재 값 기준 추정이라 과거 잔액이 달랐으면 이자가 어긋난다. 그래서 항상 "예측"이고 U 안에서만 뗀다
- 구현: `settlement.ts`에 `estimateLoanInterest(loans, days)`·`splitLoanCause(mapped, {interest, debtIncrease})` **추가만**(기존 `mapSettlementCauses` 본문 diff 0, 키 유니온에 `"loan"` 추가). `change-hero.tsx`의 `computeSettlementCauses`·`computeChainCauses`가 호출. `asset-report.ts`·홈 Hero·성적표 diff 0, 기존 3개 테스트 파일 무수정 통과
- 입출금 안내(`cause-unrecorded-hint`)는 대출을 뗀 **새 기록 안 된 변화** 기준으로 다시 판정

### 3. "기록 안 된 변화" 재정의
사용자 문장: **"새로 등록한 자산이나 직접 고친 잔액처럼, 시세·환율·입출금·대출로 설명되지 않는 금액이에요."** (InfoHint 신규, 행 라벨은 그대로). 남는 것: 상세 기록 없는 구간의 현금·자산 잔액 직접 수정, 짝 없는 매수·보증금 증감, 예측 구간의 시세 잔차(estimatedPriceAsUnrecorded 유지). 빠지는 것: 대출 이자·대출 순증 사용분.
