## 구현 판단·어긋난 사실
1. `assignColors`: 홈 dashboard 로컬 함수는 export되지 않고(홈 파일 무접촉 유지), asset-detail-tabs 것은 [1]부터라 spec의 "[3]부터"와 다르다. 같은 규칙을 `composition.ts`에 로컬 구현했다(재사용 불가 근거).
2. 범례: spec 문구는 "이번에 값이 있는 자산군만"이나, 과거 칸에만 값이 있는 군이 막대에 색으로 나오면 범례가 없어 구분 불가라 "어느 칸에든 값이 있는 군"을 범례로 했다(색 배정 규칙과 일치).
3. 선택 줄 이번 달 머리말은 "이번 달", 과거는 `N월 D일 기록`(date 없으면 `N월`). 비중이 0인 군은 선택 줄·aria에서 생략.
4. 320px 13칸: 칸 폭 약 19px라 월 라벨은 text-[10px]·nowrap. "10월"이 칸보다 약간 넓을 수 있어 qa/ui 실측 필요. 히트영역은 열 전체(min-h-10, 막대+라벨 높이 약 140px). 어절 끊김 없음(nowrap).
5. 막대는 recharts 없이 div flex 막대(신규 라이브러리 없음). 선택 해제는 없음(호버/포커스/탭으로 마지막 선택 유지).
6. 알려진 한계(spec 7장 그대로): 블록 page_view 뒤 월 탭으로 돌아가면 이후 이벤트 page_location이 /v/activity/change/composition. 복원 API 추가 안 함.
7. 음수 현금 등은 0 처리라 이번 달 칸이 성적표 비중과 1%p 이상 다를 수 있음(spec 기록 요구).
8. IntersectionObserver 50%: 카드 높이가 뷰포트 50% 이하라 항상 도달 가능. preview에서 gtag 없음이라 GA 실발송은 `?ga-debug=1` 운영 빌드에서만 확인 가능.
