## 3. 조회 비용 — preview 실측
캐시 키 날짜 구성(`getProfitCacheToken`): `{국내 기준일}_{해외 기준일}`. 실측 키 `…daily:2026-11-19_2026-11-18:000660,…,NVDA`. 바뀌는 때는 **평일 16:00 KST(국내)와 매일 06:00/07:00 KST(해외)** 두 번뿐, 자정에는 안 바뀐다. 티커 목록 필터·정렬은 `saveSnapshots`(680행)와 `stock-tab`(169행)이 글자까지 같다.

| 경로 (6종목, `/api/finance/profit` 요청 수) | 지금 | 비고 |
|---|---|---|
| 홈 재방문, 캐시 있음 | **0** | 홈에 줄이 생겨도 캐시 적중 → +0 |
| 홈 재방문, 캐시 없음(경계 뒤 첫 방문) | **2** (1.8초·2.9초, `saveSnapshots`) | 홈이 같은 키로 먼저 부르면 `saveSnapshots`가 진행 중 요청을 공유 → 합계 2, +0(시점만 0.7초쯤 앞당겨짐) |
| 상세·주식 직접 진입, 캐시 없음 = **마운트 즉시 조회 + `cancelThenRefetchProfit`** | **3** | 1.16초에 보낸 첫 배치가 2.0초에 다시 나간다 = **+1 실측** |
| 상세·주식 직접 진입, 캐시 있음 | 0 | |
| 체험(`?trial=1`) 홈 | **0** | 체험은 스냅샷 조회가 없다 → 홈 줄이 생기면 **+2**(종목 3개당 1) |

- **+1의 원인은 #138 경합이 맞다.** `syncTodayStockPrices` 진입 때 `dataResetVersion`이 오르고(484행), `useFilteredStockData` 안 effect가 `cancelThenRefetchProfit`을 부른다. 이 effect는 그 훅에만 있고 홈에는 지금 마운트되지 않는다.
- **방법(권고 1안)**: 홈은 **같은 queryKey·같은 `fetchProfitRef` 인자의 `useQuery`만 두고 취소 effect는 달지 않는다.** 컨텍스트 수정 0, 정상 경로 +0. 취소가 필요한 경우(데이터 삭제·불러오기)는 티커 목록이 바뀌어 키가 바뀌거나, 종가는 불변이라 그대로 써도 값이 같다.
- 1안에 남는 것 3가지(qa 관찰 항목):
  1. **요청 수는 같아도 겹친다.** 캐시 없는 날 홈의 종가쌍 배치(3개/초)가 시세 동기화 배치(3개/초)와 같은 시간에 나간다. 지금도 상세·주식 직접 진입에서 생기는 상태지만 홈은 모든 사용자의 첫 화면이다. 429가 나면 재시도 1회(+1)와 '일부만 받은 결과'가 생긴다.
  2. **스냅샷 저장의 선행 호출자가 홈이 된다.** 홈 조회가 진행 중일 때 홈을 떠나면 그 요청이 취소되고 `saveSnapshots`는 처음부터 다시 받는다(#141 처리 그대로, 스냅샷은 저장됨). 이때 이미 나간 배치만큼 요청이 는다(최대 `ceil(종목 수/3)`, 경계 뒤 첫 방문에서 몇 초 안에 떠날 때만).
  3. **장중에는 고른 종목이 시세 동기화 도중 바뀔 수 있다.** 장중 칩의 분자가 `currentPrice`라 시세가 3개씩 갱신될 때마다 다시 계산된다. spec 1-1 '받는 도중 종목이 바뀌어 보이지 않게'는 종가쌍 조회만 막고 이것은 못 막는다.
- **2안(1안에서 429·요청 증가·종목 바뀜이 보이면)**: 컨텍스트에 읽기 전용 값 1개('시작 동기화 끝남', `initAndSync`·0→양수 경로의 `finally`에서 true)를 내고 홈 조회·고르기를 그 뒤로 미룬다. 위 3가지가 구조상 없어지지만 `asset-data-context.tsx`를 건드리고(약 8줄) 줄이 몇 초 늦게 뜬다. v1은 1안, 전환 조건은 qa 실측.
- 그 밖의 상한: 홈을 켜 둔 채 경계(16시·06/07시)를 넘기고 창에 다시 초점이 오면 5분 `staleTime` 뒤 재조회가 캐시 없는 키로 나간다 = 하루 최대 2회 × `ceil(종목 수/3)+1`. 상세·주식과 같은 동작이다.
- 서버 한도: profit 라우트 분당 30요청. 10종목 4요청이라 한도와는 거리가 있다.
- 전송 값: `tickers`·`period`·`basis`뿐(실측 URL 확인). 보유 수량·금액·등락률 0, 역산 불가(종목코드는 지금 상세·주식 요청과 같은 값).

## 4. #245 팁과의 자리 규칙 — 같은 값 공유

## 5. 칩 값·반올림 공유
- 값: `computeTodayChip(묶음, refData, exchangeRates).rate`, 라벨: `todayChipLabel(chip, "row")` — `stock-tab.tsx` 1274~1275행과 같은 두 호출.
- 반올림·비교: `rateTenths`(`market-compare.ts`)가 `sortByChipRate` 안 `tenths`와 식이 같다(`Math.round(Number(r.toFixed(1))*10)`, −0 제거). 고르기 = `|rateTenths|` 최대, 동률은 원화 평가금, `rateTenths === 0`이면 줄 없음.
- **표기 차이 2건(spec 정정)**: ① 칩은 `▲3.2%`, 줄은 `formatCompareRate` `+3.2%`(spec 9절 ③ 그대로, ui 판정) ② **`formatCompareRate`의 음수 부호는 ASCII `-`** 다. spec 상태표의 `−4.1%`(U+2212)와 글자가 달라 AC-4 '글자 단위로 같다'가 깨진다. 바로 위 지수 줄이 `-0.2%`로 그려지므로(실측) 정본(`-`)을 따르도록 표를 고친다(#245 tech-review 10절 2와 같은 건).
- AC-3 보장은 공용 함수 + 테스트 1개(같은 입력에서 줄 값 = 행 칩 값, `market-compare-chip.test.ts` 선례).

## 7. qa 시간대(spec 9절 ⑦)
- 데모·체험 종목은 장중·마감 직후 칩이 숨는다(`today-chip.ts` 143행). preview에서 줄이 **보이는 시간대**: 국내 종목 평일 16:00~다음 거래일 09:00·주말, 미국 종목 KST 07:00(서머타임 06:00)~23:30(22:30)·주말. 두 시장이 다 보이는 창은 **평일 16:00~22:30 KST와 주말**이다.
- 한쪽 시장만 값이 있는 시간(예: 평일 10시 — 국내 숨김·미국 종가)은 미국 종목만으로 줄이 뜬다(S12와 다른 결과, 데모 한정). qa-report에 측정 시각을 적는다.
- 장중 문장(S2·S3·S12 `오늘`)은 preview로 못 본다 → `now` 주입 단위 테스트 + 머지 뒤 운영 스모크(장중 1회)로 대신한다.
- 요청 수(AC-7)는 `?demo=1`로 재고(체험은 기준이 다름), 캐시 없는 경로는 `secretasset_profit:` 키를 지우고 새로고침한다.

## 9. spec·ui에 돌려줄 것
1. 3절 ③ 펼침 상태 자리(`접기` 아래 1곳 vs 두 군데) — ui 판정.

4. AC-7 '정상 경로'에서 **체험 제외**를 명시(체험은 +`ceil(종목 수/3)`, 상세·주식에 가면 받을 요청을 앞당긴 것).
