## 1~5 검토
1. **꼭 해야 하나**: 기여는 작다(배당 화면 10월 3명). 다만 화면 1곳·저장 무변경·롤백 revert 1회라 비용이 더 작다. "등록 자산으로 새 가치"(LEARNINGS #71) 기준 충족. 통과.
2. **더 작게**: 이미 종목별 열·월별·허브 노출을 뺐다. 더 줄일 곳 없음. '지급만' %는 기존 토글에 따라오는 값이라 별도 비용 아님.
3. **중복**: 앱에 배당률 표시 0건(성적표 divYield는 점수 입력, 화면 미노출·분모 평가금액). 배당 화면 안 중복 없음.
4. **LEARNINGS·DECISIONS**: 반려 방향과 겹침 없음(공개 배당 달력 탈락과 무관, 앱 안 기능).
5. **측정**: `성과·배당` page_title 기존 행. 정성 판독·실패선(확장 후속 중단) 명시. 통과.

## 쟁점 판정
- **분모 환율 규칙**: planner안(평단×수량×**현재 환율**) 채택. 선정 문서의 "매입 환율 없으면 현재 환율"은 이 문서로 대체한다. 근거: 분자(배당 API 금액×현재 환율)와 같은 환율이라 USD 종목 %가 환율과 무관하고 엑셀 "달러 배당÷달러 평단"과 같은 값이 나온다. 앱 원금 정본 `computeAssetCost.stockCost`도 현재 환율(코드 확인). 매입 환율 분모는 환차가 섞여 기각.
  - 남는 차이: 상세 주식 '총 매입금액'(StockMetrics.cost)은 매입 환율을 쓴다. 배당 카드는 금액을 보여 주지 않고 캡션에 "해외는 현재 환율"을 적으므로 화면 간 숫자 불일치는 생기지 않는다. 수용.
- **엔화 제외**: 수용. 기존 배당 계산이 엔화를 환산하지 않아(별도 bug 후보) 넣으면 % 오답. 분자에서도 빠지므로 Hero 금액과 % 분자가 다를 수 있으나 "N종목 제외" 캡션 + InfoHint 정적 문장("평단이 없거나 엔화인 종목은 뺀 값이에요.", ui.md 6절 제안)으로 설명 — **이 문장 추가 승인**.
- **라벨 충돌(business-pm 이견) → 수정 확정**: 허브 성적표 카드에 이미 "투입 대비 N%"(전체 손익률, `performance-hub.tsx:186`)가 있다. 같은 글자에 다른 지표는 C1 취지 위반. 값 줄 라벨을 **"투입 대비 배당"**으로 한다(예: `투입 대비 배당 3.2%`). 375·320 값 줄 약 170px로 1줄 유지. spec 2·5절·9절, ui.md 1·2·6절의 "투입 대비" 문자열을 이 라벨로 읽는다(developer 반영, 문서 재작성 불필요).
- **월 선택 시 opacity 0 유지(ui)**: 레이아웃 시프트 방지 근거 타당. 수용.
