# 4.46 #80 배당 투입 대비 배당률 — 명세

작성: planner-designer. 상태: **초안(cto challenge 통과 전)**. 방향: `4.46-direction.md`. 기준 코드 main 5391ba3.

## 1. 문제
배당 보유자는 "투자금 대비 배당률"을 엑셀로 따로 계산한다. 앱 배당 화면(`dividend-chart.tsx`)은 금액만 보여 주고 %가 없다.

## 2. 목표 행동
성과 › 배당 첫 화면에서 클릭 없이 "투입 대비 N%"를 읽는다. '지급만' 토글로 받은 배당 기준 %도 본다.

## 3. 범위
- 포함: 배당 카드 Hero 금액 아래 % 1줄 + 캡션 1줄, InfoHint 문장 1개, 계산 순수 함수(`lib/` 신규 또는 기존 유틸, 재사용 지도 먼저 확인) + vitest.
- 제외: 종목별 % 열, 월별 %, 허브 카드·성적표·AI 프롬프트 노출, 시가 배당률, 평가 문구, 새 GA 이벤트, 저장 키·스키마.
- 수정 파일 예상: `dividend-chart.tsx` + 계산 함수 1곳 + 테스트. `useDividendAnnualTotals`·`performance-hub.tsx`·`monthly-dividend-stocks.tsx`·`ga.ts` 무변경.

## 4. 계산 정의
- 대상 목록 = 배당 화면과 같은 목록(종목코드 있음, 비상장·상장폐지 제외, `mergeStockGroup` 합산).
- 포함 종목 = 대상 중 평단 > 0 이고 통화가 KRW 또는 USD.
- 분모 = Σ 포함 종목 평단 × 수량 × (USD면 현재 환율, KRW면 1).
- 분자 = 포함 종목의 올해 배당. 예상 포함 모드 = 지급 + 예상, 지급만 모드 = 지급. 매수일 이전 지급분 제외, 지급/예상 구분은 `buildMonthlyTotals`와 같은 규칙(지급월 ≤ 이번 달 KST).
- 배당률 = 분자 ÷ 분모 × 100, 소수 첫째 자리 반올림. 0 < 값 < 0.05면 "0.1% 미만".
- 제외 수 = 대상 − 포함(평단 0 이하 + JPY).
- 서버 전송 없음(기존 배당 API 호출 그대로, 종목코드만).

## 5. 사용자 흐름
1. 성과 허브 › 배당 카드(또는 하단 성과 › 배당 탭)를 누른다.
2. 조회 중에는 기존 진행 표시만 보이고 % 줄은 없다.
3. 조회가 끝나면 Hero "올해 예상 배당 ₩X" 아래 "투입 대비 N%"와 캡션 "보유 주식 매입금액 기준 · 해외는 현재 환율"(제외가 있으면 " · N종목 제외")이 보인다.
4. '지급만'을 누르면 Hero가 "올해 지급 배당"으로, %가 지급분 기준으로 바뀐다.
5. 월 막대를 누르면 Hero가 그 달 금액으로 바뀌고 % 줄·캡션은 사라진다. 다시 누르거나 "전체 보기 ×"로 해제하면 돌아온다.
6. InfoHint를 열면 기존 3문장 + "투입 대비 %는 올해 배당 ÷ 보유 주식 매입금액이에요. 예상분은 작년 지급 기록으로 추정한 값이라 실제와 다를 수 있어요."가 보인다.

## 6. 엣지 케이스
| 경우 | 동작 |
|---|---|
| 배당 0(빈 데이터·KIS 미설정) | 기존 빈 상태 그대로, % 줄 없음 |
| 조회 중·일부만 도착 | % 줄 없음(전부 끝난 뒤 1회 표시) |
| API 실패 종목 | 기존처럼 배당 0으로 취급(구분 불가) → 분모에는 남아 %가 낮게 나옴. 알려진 한계 |
| 포함 종목 0(전부 평단 0·JPY) 또는 분모 0 | % 줄 없음, 캡션 없음 |
| 배당 없는 종목만 일부 | 분모에 포함, 계산 진행 |
| 올해 매수 종목 | 매수일 이후 배당만 반영(Hero와 같음). InfoHint 기존 문장으로 설명 |
| 1월 초(지급 0, 예상만) | 예상 포함은 값 있음, 지급만은 분자 0 → "0%"가 아니라 % 줄 숨김 |
| 첫 사용자(주식 0) | 배당 화면 기존 빈 상태 |
| USD만 보유, 환율 변경 | % 동일 |
