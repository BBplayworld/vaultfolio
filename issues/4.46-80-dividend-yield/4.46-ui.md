# 4.46 #80 배당 투입 대비 배당률 — UI 사양

작성: ui-designer. 기준: `4.46-direction.md`·`4.46-spec.md`, design-system §2·§3·§6·§7·§11, 코드 main 5391ba3 `dividend-chart.tsx`. 코드 수정 없음.
한계: CLAUDE.md "라이브 프리뷰 제외" 규칙과 이 환경(앱 미기동)으로 현재 화면 캡처는 못 했고, Hero 마크업(L261~281)·타이포 클래스를 코드로 대조해 톤을 맞췄다. 캡처 대조는 ui-review에서 preview로 한다.

## 1. 컴포넌트 트리 (재사용, 신규 컴포넌트 0)
`CardContent` > Hero `<div>`(기존) 안, 금액 `<p>` 바로 아래에 블록 1개 추가. 신규 토큰·패턴 없음(§2 4단계 안에서 흡수).
```
Hero div
 ├ 라벨 줄(기존)
 ├ 금액 p (기존 text-2xl sm:text-3xl font-bold tabular-nums)
 └ [신규] 배당률 블록 data-testid="dividend-yield"
     ├ 값 줄:  "투입 대비" + "3.2%"
     └ 캡션:   "보유 주식 매입금액 기준 · 해외는 현재 환율[ · N종목 제외]"
```
위계: 금액(30/24 bold) > % 값(16 semibold) > 라벨(14 medium muted) > 캡션(11 muted). Hero 대비 반 단계 이상 낮춰 금액이 1순위로 남는다. 색은 전부 중립(`text-foreground`/`text-muted-foreground`), 손익색·`ASSET_THEME.text.default`(주황 계열 여부 무관) 미사용.

## 2. 클래스 (그대로 사용)
```tsx
{showYield /* 아래 3절 */ && (
  <div
    data-testid="dividend-yield"
    aria-hidden={selectedMonth !== undefined}
    className={`mt-2 transition-opacity duration-150 motion-reduce:transition-none ${
      selectedMonth !== undefined ? "opacity-0 select-none" : "opacity-100"
    }`}
  >
    <p className="flex items-baseline gap-1.5 leading-tight">
      <span className="text-sm font-medium text-muted-foreground">투입 대비</span>
      <span data-testid="dividend-yield-value" className="text-base font-semibold tabular-nums text-foreground">
        {yieldText /* "3.2%" 또는 "0.1% 미만" */}
      </span>
    </p>
    <p data-testid="dividend-yield-caption" className="mt-1 text-[11px] leading-relaxed text-muted-foreground text-pretty break-keep">
      <span className="whitespace-nowrap">보유 주식 매입금액 기준 ·</span>{" "}
      <span className="whitespace-nowrap">해외는 현재 환율</span>
      {excluded > 0 && (<>{" "}<span className="whitespace-nowrap">· <span className="tabular-nums">{excluded}</span>종목 제외</span></>)}
    </p>
  </div>
)}
```
- 간격: 금액→값 `mt-2`(8px), 값→캡션 `mt-1`(4px). 4px 그리드. 카드 내부 gap(`space-y-6`)은 그대로.
- 값이 "0.1% 미만"이면 같은 span, 줄바꿈 방지 위해 `whitespace-nowrap` 추가.
- "N종목 제외"의 앞 `·`는 제외 span 안에 포함해 줄 시작에 올 수 있다(허용, 어절 분리는 없음).

## 3. 상태
| 상태 | 표시 |
|---|---|
| 기본(월 미선택, 예상 포함/지급만) | 값 줄 + 캡션. 모드 전환 시 값만 교체(블록 재마운트 없이 같은 DOM) |
| 조회 중·일부 도착 | 블록 미렌더(`isLoading` 동안 false). 조회 끝난 뒤 1회 등장 |
| 배당 0 / 포함 종목 0 / 분모 0 / 지급만 분자 0 | 블록 미렌더(Hero 자체가 `annualTotal>0` 조건이라 빈 상태와 충돌 없음) |
| 월 막대 선택 | **언마운트하지 않고** `opacity-0` + `aria-hidden`(위 클래스). 이유: 언마운트하면 Hero 아래 약 44~60px이 줄어 막대 차트가 위로 튀어, 손가락 아래 막대가 바뀌고 이웃 월 연속 탭이 어긋난다(§6 인터럽터블·레이아웃 시프트 금지). 빈 자리는 150ms 페이드 후 여백으로 남지만 Hero 월 배지·금액과 같이 읽혀 어색하지 않다 |
| 월 해제 | opacity 복귀(150ms), 값 동일 |
| 오류(API 실패) | 기존과 동일(배당 0 취급), 별도 UI 없음 |
| 긴 문구 | 캡션은 whitespace-nowrap 어절 묶음 3개 단위로만 줄바꿈, 최대 2줄 |

qa 주의: 월 선택 시 DOM에는 남아 있으므로 판정은 "보이지 않음"(opacity 0·`aria-hidden=true`)으로 한다. 완료기준 3의 "사라진다"는 이 의미로 해석(planner 확인 요청 아님, 시각 결과 동일).

## 3.2 줄바꿈 (C25) 계산, 카드 내부폭 기준
- 375: 카드 내부 약 311px → 캡션 1줄(≈250px). 제외 포함 시 2줄 가능.
- 320: 내부 약 256px → "보유 주식 매입금액 기준 ·"(≈140px)+"해외는 현재 환율"(≈95px)=약 240px로 1줄 경계. 넘으면 어절 묶음 단위로 2줄. 제외 span(≈75px)은 항상 2줄째로 내려가 최대 2줄, 3줄 불가.
- 1280: 카드 폭 내 1줄.
- `break-keep`+`whitespace-nowrap` 묶음으로 어절 중간 줄바꿈 0. 값 줄은 최대 약 150px이라 모든 폭에서 1줄.

## 4. 모션 (§6)
`transition-opacity duration-150`, `motion-reduce:transition-none`. transform·`transition: all` 없음. 연타 시 opacity는 인터럽터블(CSS transition 현재값에서 반전). 등장은 로딩 종료 시 즉시(진입 모션 없음 — Hero 금액도 동일하게 즉시 표시).

## 5. 접근성
- 텍스트 그대로 읽힘("투입 대비 3.2%"). 숨김 상태는 `aria-hidden`.
- 신규 인터랙션 0 → 히트영역 이슈 없음. InfoHint(기존 `설명 보기` 버튼)에 문장만 추가.
- 대비: 캡션 `text-muted-foreground` 11px는 라이트·다크 모두 기존 `총 N건`(L308) 캡션과 동일 조합. 값 `text-foreground`는 최고 대비.
- 다크/라이트: 시맨틱 토큰만 사용, `dark:` 분기 0.

## 6. 문구 최종안 (존댓말, 평가어 없음)
- 값 줄: `투입 대비 3.2%` / `투입 대비 0.1% 미만`
- 캡션: `보유 주식 매입금액 기준 · 해외는 현재 환율` (+ ` · 2종목 제외`)
- "N종목 제외" 표현 결정: 사유를 캡션에 쓰면 2줄을 넘기므로 `N종목 제외`만 쓴다. 사유는 InfoHint 새 문장 끝에 정적 문장 `평단이 없거나 엔화인 종목은 뺀 값이에요.`를 덧붙이는 것을 제안(planner 승인 필요, 새 문장 1개 추가라 spec 5절 6항 수정). 미승인 시 spec 원문 그대로.
- InfoHint 추가 문장은 spec 5절 6항 원문 그대로, 기존 3개 `<p>` 뒤 4번째 `<p>`로 추가.
- `data-screenshot-hide` 대상 없음(금액 아님, 비율. 스크린샷 공유 시 노출돼도 자산 금액 유추 불가).

## 7. testId
`dividend-yield`(블록), `dividend-yield-value`, `dividend-yield-caption`.

## 8. 품질 체크리스트 (qa 판정용)
1. 375 라이트·다크: Hero 금액 바로 아래 "투입 대비 N%" 1줄, 값이 라벨보다 크고 금액보다 작다(16/30px).
2. 값·라벨·캡션 색이 손익색(빨강·파랑)이 아니다(computed color가 foreground/muted-foreground).
3. 값 요소 computed `font-variant-numeric`에 tabular-nums 포함.
4. 320·375에서 캡션 어절 중간 줄바꿈 0, 캡션 2줄 이하(제외 있는 픽스처 포함), 값 줄 1줄.
5. 1280: 캡션 1줄, Hero 좌측 정렬선과 값·캡션 좌측 x가 같다.
6. 월 막대 선택 시 블록 opacity 0·aria-hidden=true이고, 선택 전후 막대 차트 y 위치 변화 0px.
7. 월 해제 시 같은 값으로 복귀.
8. '지급만' 전환 시 값 교체, 지급 0이면 블록 없음.
9. 조회 중에는 블록 없음, 완료 후 1회 등장(깜빡임 없음).
10. 배당 0 빈 상태에서 블록 없음, 기존 문구 그대로.
11. prefers-reduced-motion: transition 없음.
12. 새 문자열 금지어(추천·매수·매도·유리·불리·보장·확정·높·낮) 0 (※ "매입금액"은 허용 어휘).
13. 허브 배당 카드·월별 종목 표·성적표 화면 diff 0(스크린샷 동일).
14. InfoHint 열면 기존 3문장 + 신규 1문장, 320에서 팝오버가 화면 밖으로 잘리지 않는다.
15. 0.1% 미만 픽스처에서 "투입 대비 0.1% 미만"이 한 줄.
