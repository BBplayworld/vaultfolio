# #263 투자 탭 — 지수 데이터 경로 조사 (KIS 조회·크롤링·2차 가공·서술 인용)

작성 2026-11-22 · 대표 질문 "2차 가공 정보나 크롤링 등의 방법은 없을까?" · 기준: 상업적 이용에 문제 없는 데이터만
선행: `4.xx-license-options.md`(공개 출처 중 상업 자유 지수 데이터 없음), `4.xx-data-research.md` §8
**열람 한계**: apiportal.koreainvestment.com·investing.com·federalreserve.gov는 이번 세션에서 차단됐다. 약관은 검색 발췌·제3자 인용이고 `원문 미열람`으로 표시했다. KIS 예제 코드(GitHub `koreainvestment/open-trading-api`)만 원문을 확인했다. **법률 자문이 아니다.**

## 1. 결론 먼저
- **KIS로 받아 보여 주는 경로는 '문제 없는 데이터'가 아니다.** KIS 고객 약관 제5조③(제3자 인용, 원문 미열람): "시세…정보를 고객이 직접 개발한 프로그램 등 **개인의 업무에 한하여** 이용해야 하며, **제3자에게 제공해서는 아니 된다**." KIS 제휴 안내: 제3자 서비스 제공은 제휴 대상이고, 제휴사는 **KRX·해외거래소와 정보이용계약이 필요**하다.
- **이 위험은 이미 운영 중이다(새 위험 아님, 노출만 커짐).** 시장과 비교(#132)·홈 변화 줄·시장 알림(#179)이 KIS에서 받은 코스피·코스닥·S&P 500·나스닥 종합·원/달러 값을 사용자에게 보여 준다. 투자 탭에 수십 년 이력을 싣는 것은 같은 종류의 위험이지만 노출이 커지고(핵심 콘텐츠·장기 이력), 대표 기준("문제 없는 것만")은 충족하지 못한다.
- **크롤링은 위험 높음.** 사이트 약관 위반(계약)과 DB 제작자 권리·부정경쟁 문제가 더해지고, 지수 회사 권리는 그대로 남는다.
- **직접 계산한 등락률도 원권리자 약관상 '파생(derived)'이다.** 저작권만 보면 위험이 낮지만, 원자료를 얻은 경로의 약관(KIS·사이트·지수 회사)에 묶인다.
- **숫자 없는 서술 인용(연준 공식 문서)은 지금 쓸 수 있다.** 위험 낮음. 다만 '연도별 지수 등락' 화면은 만들 수 없다.

## 2. 조사 1 — 앱이 이미 쓰는 KIS 경로
**현재 코드(origin/main)**
| 화면·기능 | API·TR | 대상 | 캐시 |
|---|---|---|---|
| 시장과 비교(#132), 홈 변화 줄 | `/api/finance/market-index` → `fetchKospiDailySeries`(국내업종기간별시세 `FHKUP03500100`, 업종 0001) · `fetchOverseasIndexDailySeries`(해외 종목·지수·환율 기간별시세 `FHKST03030100`, 시장 N, `SPX`) | 코스피·S&P 500, 일봉 `D`만 | CDN만(다음 정시까지), Redis 0, 클라이언트 react-query 메모리 |
| 시장 알림(#179) | `src/lib/push/quotes.ts` 같은 함수 | S&P 500·나스닥 종합(`COMP`)·코스피·코스닥(1001)·원/달러(`FX@KRW`) | 서버 Cron |
- 코드·memory 어디에도 KIS 재배포 허용 근거나 제휴·거래소 정보이용계약 기록이 없다(`grep 제휴|정보이용계약` 결과 0건). 즉 기존 기능도 **약관 확인 없이 쓰는 상태**다.
- '사용자 기기 요청 시 조회'로 바꿔도 달라지지 않는다. 호출은 우리 서버가 우리 키로 하고 결과를 사용자에게 건네므로 '제3자 제공'에 해당한다(사용자 기기가 KIS를 직접 부르려면 사용자 본인 키가 필요 — 비현실적).

**KIS가 줄 수 있는 범위**(예제 코드 원문 확인, 실호출 미검증)
- 두 TR 모두 기간분류 **`D·W·M·Y`(일·주·월·년봉)** 지원. 해외 TR은 시장구분 N(지수)·X(환율)·I(국채)·S(금선물). 연속 조회(`tr_cont`)로 여러 번 나눠 받는다(1회 건수 상한은 국내 종목 TR 100건이라는 블로그 외 미확인).
- **1985~ S&P 500·나스닥100, 1980~ 코스피 제공 여부: 근거 없음.** 공식 문서·커뮤니티 어디에도 시작일이 적혀 있지 않다. 나스닥100 지수 코드(`NDX` 등)도 해외지수 마스터(포털 다운로드, 차단)에서 확인해야 한다. 예제 문구 "다우30·나스닥100·S&P500 **종목**만 조회 가능"은 구성 종목 얘기라 지수 제공 근거가 아니다. → 실호출 1회(년봉 `Y`, 1980-01-01~오늘)로만 확정 가능.

## 3. 조사 2 — 크롤링·2차 가공
| 대상 | 사이트 약관 | 남는 원권리 |
|---|---|---|
| Yahoo Finance | 2020 아카이브 약관: 허락 없는 봇·스파이더·스크레이퍼 접근 금지. 공식 시세 API 없음, yfinance도 "개인 용도" 명시 — 원문 미열람 | S&P DJI·Nasdaq·KRX |
| Investing.com | 원문 미확인(차단). 유사 금융 사이트 약관은 스크래핑·재배포·상업 이용 금지가 일반적 | 같음 |
| 네이버 증권 | 네이버 약관 "자동화 프로그램 등을 이용한 무단 수집" 금지(해설 인용), 2026-09 API 약관도 크롤러·우회 금지 — 원문 미열람 | KRX(시세 원천) |
- **한국 저작권법 제93조**: DB의 '상당한 부분' 복제와, 상당하지 않아도 반복·체계적 복제로 통상 이용과 충돌하면 침해. 대법원 2022.5.12. 2021도1533(야놀자·여기어때 형사)은 공개·수집 노력 등을 들어 침해를 좁게 봐 무죄였지만, **같은 사건 민사(서울고법 2021나2034740)는 부정경쟁행위로 손해배상 인정**, 네이버 부동산 사건 1심은 DB권 침해 인정. 형사 무죄 ≠ 안전.
- **사실 비보호 원칙·미국 Feist(1991)**: 사실 자체와 독창성 없는 배열은 저작권 대상이 아니다. '연 1개 등락률 수십 개'는 사실값에 가깝고, 우리가 직접 고른 형식으로 다시 적으면 **저작권 위험은 낮음~중**. 단 한국은 DB 제작자 권리(제93조)가 따로 있어 미국보다 넓다.
- **진짜 위험은 계약(약관)이다.** 사실값이라도 그것을 얻은 경로의 약관을 지켜야 한다(KIS 제5조③, 사이트 약관). S&P DJI는 "지수 데이터를 **사용·기반으로 하거나 언급하는** 제품"에 라이선스가 필요하다고 적고, SPICE 약관은 허락 없는 파생물 작성·재배포를 금지한다. Nasdaq은 '역산 불가능한 형태로 만든 정보'를 파생 데이터로 정의하고 **별도 파생 라이선스 요금**을 받는다. → **직접 계산한 등락률 = 파생 데이터**로 보는 것이 지수 회사 입장. 계약 당사자가 아니면 직접 구속은 약하지만, 원자료 취득 경로(KIS·사이트·FRED)가 모두 이 권리를 이어받는다.

## 4. 조사 3 — 숫자 없는(또는 공문서 숫자) 서술 인용
- 연준 이사회(federalreserve.gov) 자료는 별도 표시 없으면 공공 영역(§8.6 L2 원문 확인). FOMC 의사록 '금융 상황 검토'에 "equity indexes had dropped moderately"(2025-01), "the S&P 500 … roughly flat"(2020-07) 같은 서술이 회의마다 있다. 반기 통화정책 보고서·금융안정 보고서도 '주가' 절을 둔다.
- 화면 예: "2008년 10월 — 연준 기준금리 1.5%→1.0% 인하. 같은 달 의사록: '주가가 크게 하락'"(연준 문서 인용 + 날짜 + 출처 링크). 금리는 R1 확보분(연준·한은) 그대로.
- 주의: ① 의사록 안의 수치("S&P 500 fell 34%"류)는 공문서 문장 인용으로 위험 낮음이지만, 그것을 모아 연도별 표로 만들면 다시 '지수 데이터 표시'에 가까워진다 → 문장 단위로만. ② 지역 연은(FRBSF 등) 자료는 이사회 자료가 아니라 공공 영역 전제가 성립하지 않는다(미확인) → 이사회 문서만. ③ 지수명은 문장 속 인용에서만, 기능·제목 이름으로 쓰지 않는다. ④ R1~R6 인과 금지 규칙("때문에" 금지) 그대로 적용.

## 6. 권고
1. **대표 답변**: "크롤링·2차 가공으로는 '문제 없는 데이터'가 되지 않는다. 숫자는 사실이라 저작권은 약하지만, 그 숫자를 얻는 길(사이트·증권사 약관)과 지수 회사의 파생 조항이 막는다."
2. **1단계 = 서술 인용 + 금리·환율·사건**(`4.xx-license-options.md` §6(a)와 같은 범위)으로 기획 확정.
3. **기존 기능 위험 별도 처리(우선)**: 시장과 비교·알림의 KIS 값 표시가 약관 제5조③와 충돌할 수 있다. cto가 KIS 약관 원문(포털, 호스트 허용 필요)과 제휴 필요 여부를 확인해 판정. 투자 탭과 분리해 다룬다.
4. 라이선스를 산다면 **KIS 제휴+KRX·해외거래소 정보이용계약** 경로도 견적 후보에 넣는다(기존 기능 위험도 함께 해소되는 유일한 경로).
5. 다음 조사에 필요한 호스트: `apiportal.koreainvestment.com`(약관·해외지수 마스터), `www.federalreserve.gov`(의사록 문장 수집), `www.investing.com`. KIS 이력 시작 연도는 developer 실호출 1회(년봉 Y)로 확정.
