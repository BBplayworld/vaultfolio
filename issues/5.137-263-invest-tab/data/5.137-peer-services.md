# #263 투자 탭 — 다른 서비스의 지수 사용 방식과 우리가 쓸 수 있는 경로

작성 2026-11-22 · business-pm · 대표 지시(11/22) "지수는 필수 포함. x·y축 값을 보고 판단할 수 있게 표시. 다른 서비스의 지수 사용 방식 검토"
선행: `4.xx-license-options.md`(공개 출처 중 상업 자유 지수 없음), `4.xx-data-paths.md`(KIS 제3자 제공 금지 의심, 크롤링 금지)
**열람 한계**: 이번 세션은 WebFetch가 모두 막혔다(tradingview.com·twelvedata.com·data.krx.co.kr·hankyung.com·google.com에서 DNS 실패). 아래 내용은 모두 **웹 검색 발췌(원문 미열람)**다. 법률 자문이 아니다. "확인 못 함"은 근거가 없다는 뜻이고, 추측으로 채우지 않았다.

## 1. 결론 먼저
- 지수 과거 차트를 보여 주는 서비스는 모두 **① 지수 회사·거래소와 직접 계약**(네이버-Nasdaq, 다음-코스콤)하거나 **② 재배포 계약이 있는 벤더(ICE·Cboe 등)를 거친다**. 무료 공개 자료를 그대로 싣는 상업 서비스 사례는 찾지 못했다. Macrotrends·Yahoo는 자기 데이터 재배포를 금지한다.
- 작은 서비스가 **지금 비용 0원으로 쓸 수 있는 현실적인 길은 TradingView 임베드 위젯 하나뿐**이다. 데이터는 TradingView 서버가 사용자 브라우저에 바로 보내고, 우리 서버는 받지 않는다. 대신 **금리·사건을 차트 위에 겹칠 수 없고**, 연도별 등락 표·하락 구간 표도 만들 수 없다.
- 겹침·연도표까지 하려면 **표시 권한이 있는 벤더 API(월 $149~$2,500, 지수 이력 깊이 미확인)** 또는 **지수 회사 직접 라이선스**가 필요하다. 둘 다 견적 문의(외부 연락)가 필요하고, 비용은 대표가 결정한다.

## 3. 소규모 서비스가 쓰는 합법 경로
**(a) 임베드 위젯 — TradingView**
- 무료, 기본 TradingView 브랜딩 유지 조건. 위젯은 TradingView 서버의 iframe이라 **우리 서버는 데이터를 받지 않는다** → 재배포 주체는 TradingView(약관 원문 미열람이라 "책임 전부 이전"까지는 확인 못 함).
- **자기 데이터를 붙일 수 없다**(제품 비교 문서: 위젯에 자체 데이터 피드 연결 불가). 금리·사건 겹침은 불가 → 위젯 아래에 우리 금리 차트를 **같은 기간으로 나란히** 두는 방식만 가능.
- 무료 Advanced Charts 라이브러리·Lightweight Charts(Apache 2.0)는 겹침이 되지만 **데이터는 우리가 가져와야** 한다 → 라이선스 문제가 그대로 남는다.
- 확인할 위험: 코스피는 `KRX:KOSPI`·`TVC:KOSPI` 두 기호가 있고, 일부 KRX 지수는 페이지에 값이 없다. 위젯 FAQ는 "위젯에서 표시가 허용되지 않은 기호가 있다"고 적는다 → **코스피·나스닥100이 위젯에서 나오는지 preview로 먼저 확인**. TradingView는 위젯을 넣은 페이지 URL·기호·IP를 기록한다(쿠키는 없음) → 자산 데이터는 나가지 않지만 제3자 추적이라 cto 판단 필요.

**(b) 표시 권한 포함 벤더 API**(모두 원문 미열람)
| 벤더 | 상업 표시 조건 | 가격 | 지수 3종·수십 년 월봉 |
|---|---|---|---|
| Twelve Data | Business 플랜부터 **외부 표시 권한**, 재배포는 Enterprise·별도 계약. 미국 외 데이터 상업 이용은 승인 필요 | Venture 월 $149 또는 $499(페이지마다 다름), Enterprise 월 $1,099 | 코스피(KS11)·NDX 페이지 있음. SPX·이력 시작 연도 확인 못 함 |
| Massive(구 Polygon) | Indices Business = 상업 이용. "지수값은 산출 회사가 라이선스" | 월 $2,500 | 집계 이력 **2023-02부터** → 수십 년 불가 |
| FMP | 표시·재배포는 별도 Data Display and Licensing Agreement(Enterprise) | 문의 | 확인 못 함 |
| EODHD | 웹·앱 표시 = 상업, 영업 문의 | 문의 | 지수 600+이지만 지수는 별도 Marketplace 조건 가능 |

**(c) 지수 회사 직접 라이선스**: KRX Data Marketplace(상품 구매·목적 심사), S&P DJI(웹·앱 표시용 미디어 라이선스, 비공개 요금), Nasdaq GIDS(과거·EOD 외부 이용도 구독 필요, 구 요금 월 $1,000~) — `4.xx-license-options.md` §4와 같음.

## 5. 권고
1. **1단계 = 경로 A.** "지수 필수"를 비용 0원으로 바로 충족한다. 화면은 위쪽 지수 위젯(코스피·S&P 500·나스닥100 전환, 월봉, 기간 버튼) + 아래쪽 우리 금리·사건 차트(같은 x축 기간, y축 % 눈금 표시). 고지 위치는 각 차트 바로 아래: "지수 차트: TradingView 제공, 지연 시세 · 금리: 연준·한국은행 · 투자 권유가 아니며 과거 흐름은 미래를 보장하지 않습니다".
   - 착수 전 확인 3가지: ① 위젯에서 코스피·나스닥100이 실제로 나오는지(preview) ② TradingView 약관의 상업 사이트 사용 조건(원문, 호스트 허용 필요) ③ cto: 제3자 iframe의 IP·페이지 기록이 PRINCIPLES와 충돌하는지.
2. **연도별 등락 표·하락 구간 표·차트 위 겹침이 꼭 필요하면 경로 B 견적**을 병행한다. Twelve Data에 "코스피·S&P 500·나스닥100 월말값 1980~, 앱 외부 표시, 사용자 100명 미만" 조건으로 묻는다. 이력 깊이와 지수 회사 권리가 서면으로 확인되지 않으면 쓰지 않는다. Massive는 이력이 2023년부터라 제외한다.
3. 경로 C는 사용자 100명 전에는 비용 대비 이득이 약하다. 보류한다.

## 6. 대표 결정 필요
1. 1단계를 경로 A로 진행할지(겹침·연도표 없이 위젯과 금리 차트를 나란히 둠).
2. 경로 B 견적 문의(외부 연락)와 월 비용 상한($149~$499 수준을 허용할지).
