## 0. 공통 결정 (3안 모두)
- 머리: 지수 선택 세그먼트(`S&P 500|나스닥100|코스피`, 40px) + 결론 2줄. 지수 이름은 바로 위 선택기에 있어 문장에서 뺐다(숫자 1개 절약): `1985년 이후 20% 넘게 빠진 때는 5번이었어요` / `그중 3번은 금리를 내리던 중, 2번은 올리던 중이었어요`.
- **색 의미**: 막대·낙폭 = 상승 빨강(`profit`)·하락 파랑(`loss`) 그대로. **금리 국면은 빨강·파랑을 쓰지 않고 무채색 3종**(올리는 중 = 진한 회색 면 / 내리는 중 = 빗금 / 멈춰 있음 = 옅은 회색 면) → 모양으로 구분(색맹 안전), 손익색과 충돌 0. 선택·커서 = brand 인디고, 사건 = 속 빈 원(주황 미사용).
- 금리 국면 정의: 사건 표 `그때 금리`는 고점 달→바닥 달 기준금리 순변화(5건 중 내림 3·올림 2). 화살표(→)·연결선 0, 값 변화는 `4.5%에서 0.25%로`로 쓴다.
- 기준선(R8): 문장 `같은 기간 금리를 내리던 때는 12년, 올리던 때는 11년이었어요`(국면 목록 기준 가데이터). A는 머리 아래 작은 줄, B·C는 숫자 줄이 첫 화면 숫자를 늘려 ② 아래로 옮기고 B는 **국면 띠 자체가 기준선(전체 기간)** 역할.
- ② 공통 문구: `같은 시기에 있었다는 기록이고, 무엇이 원인인지는 말하지 않아요` + `'바닥까지'·'전고점까지'는 고점 달부터 센 기간이에요`(회복 기간 기준 모호성 제거 — 데이터 recovery_months는 고점 기준).
- ③ 공통: 방식 세그먼트 `한 번에|매달`, 시작 연월 선택, 끝 `지금까지`, **금액 입력 없음**(`금액은 입력하지 않아요`), 칩 `달러 기준`·`지수 값만(배당 빼고)`, `배당을 다시 넣었다면 결과는 이보다 커요`, R5 1줄. 결과 = 한 번에(원금의 N배·총수익률·해마다 평균) / 매달(넣은 돈의 N배·총수익률·가장 낮았던 달). 총수익률 빨강, 가장 낮았던 달 파랑. 기본 시작 = 10년 전(2016.1).
- 색 이외: 점선·빗금·원 모양 병행, 터치 영역 40px(세그먼트·칩·‹›·행), `prefers-reduced-motion` 대응 fade 200ms, 눌림 scale .96.

## 1. A안 '하나의 타임라인' (`a.html`)
- ① 한 SVG에 같은 연도축 3줄: **해마다 등락 막대(빨강/파랑, 올해 칸 빗금+점선)** · **사건 점(13건)** · **금리 계단(회색 선+옅은 면, 숫자 축 없음)**. 세로 커서 = brand 반투명 띠+선, 선택 연도 외 막대 .42 투명도. 그 아래 그해 카드(연도 · 등락 · `4.25%에서 0.25%로` · 사건명+1줄 사실, `‹ ›` 40×40, 올해는 `내 종목과 비교 ›`).
- 막대 한 칸 약 8px → 직접 탭은 어려움: **전체 차트 스크럽(좌우 드래그, `touch-action: pan-y`) + ‹ › 버튼**이 정식 입력. 기본은 선택 없음(`연도를 누르거나 좌우로 끌어 보세요`).
- ② 데이터 표(기간·낙폭·바닥까지·전고점까지·그때 금리 + 사건 1줄) 5행 전수. ③ 숫자 3칸 + 원금/평가액 막대 쌍.
- 1280: 차트(좌) + 그해 카드(우 360px sticky), 아래 ②(좌)·③(우).
- 강점: 대표 문장 '한눈에 종합'에 가장 직설적. 약점: 막대·점·선을 세로로 맞대 **시각 인과(R10) 인상 위험이 가장 큼**(커서가 세 줄을 관통), 연도 단위라 월 단위 ②(−20% 구간)와 단위가 다름.

## 2. B안 '국면 띠' (`b.html`)
- ① 세 줄을 **구간 중심**으로: 위 지수 흐름(로그 눈금, 숫자 축 없음, 크게 빠진 구간만 굵은 파랑·되찾는 구간 파랑 점선) / 가운데 **낙폭 막대 묶음**(폭 = 고점→바닥 기간, 진한 파랑 = 바닥까지, 옅은 파랑 = 바닥에서 전고점까지, 높이 = 낙폭) / 맨 아래 **금리 국면 띠**(배경 음영 대신 분리, 무채색 3종). 국면 띠 위에 범례.
- 입력: 구간 이름 칩 5개(가로 스크롤, 40px) 또는 낙폭 막대 탭. 선택 시 세 줄을 관통하는 brand 구간 띠 + 카드(낙폭 · 바닥까지 · 전고점까지 · 그때 금리 · **그 구간만 확대한 금리 띠** · 사건). 기본은 선택 없음.
- ② = 5행 전부 지속기간 막대(진/옅은 파랑) + 그때 금리 + 사건. ③ = 숫자 3칸 + **배수 곡선**(시작 대비, 가장 낮았던 달 점).
- 1280: 차트 전폭(막대 폭 넉넉), 선택 카드 가로 배치(시안 단계의 2열 정렬은 거칠다 — R2에서 정리), ②·③ 2열.
- 강점: 관계를 **구간(시작~끝)으로 읽게** 하고 국면 띠가 전체 기간 기준선 역할(R8 시각 충족), 금리 음영과 낙폭이 겹치지 않아 R10 충족. 약점: 구성 요소 최다(3줄+범례+칩+카드)로 정보 과다 위험, 로그 눈금 설명 필요(`로그` 금지어 C139라 표기 안 함), 구현 최고난도.

## 3. C안 '사건 카드 중심' (`c.html`)
- ① 얇은 미니 타임라인: 회색 연도 막대(맥락) + 크게 빠진 5구간 파랑 알약(진 = 바닥까지, 옅음 = 회복까지). 선택 구간 하이라이트.
- ② 카드 스택 5장(시간순, 한 번에 1장 펼침). 접힌 행 = 사건명 + **낙폭 길이 막대(숫자 없음)** + 그때 금리 방향(무채색 표식) + 펼침 화살표(행 전체 56px 버튼). 펼침 = 낙폭 · 바닥까지 · 전고점까지 + 그 구간만 확대한 지수선(고점·바닥·전고점 되찾음 표시) + 같은 창의 금리 계단 + `그때 금리` + 사건 1줄.
- ③ = 이야기 문장형(`2016년 1월부터 한 번에 넣었다면, 지금 지수 기준 원금의 3.4배`).
- 1280: 좌 카드 목록(선택 테두리) + 우 상세 패널(기본 금융위기 펼침).
- 강점: 이야기 순서가 직관적, 첫 화면 숫자 최소, 구현 쉬움. 약점: **세 요소를 한 그림에서 비교하는 '종합' 은 카드를 하나씩 열어야** 생긴다(대표 1순위 요구와 거리), 연도별 등락은 맥락용 회색에 그침.

## 5. 재사용 범위 (`origin/main`)
- 차트: `recharts ^2.15.4`, `components/ui/chart.tsx`(ChartContainer 등), `views/activity/{profit,net-asset,dividend}-chart.tsx`, `detail/stock-page/price-chart.tsx`.
- A: recharts `ComposedChart`로 막대+계단선(`type="stepAfter"`) 가능하나 **3줄 정렬·커서·사건 점은 커스텀 SVG가 안정적**(같은 margin 3개 차트 + `syncId` 또는 단일 SVG).
- B: recharts로 어렵다 → **자체 SVG 1벌**(로그 지수선·막대 묶음·국면 띠·구간 하이라이트).
- C: 카드·행은 DOM, 미니 타임라인·확대선은 소형 SVG(또는 recharts `LineChart` 2개).
- UI: `InlineSelector`(지수·방식 세그먼트), `InfoHint`(정의), `Card`·`getProfitLossColor`. **신규 토큰 0 / 신규 패턴 후보 = 금리 국면 무채색 3종(채움·빗금·옅은 면)** → 채택 시 design-system §1.2에 '국면 표기' 흡수 검토 필요. 실제 앱 폰트는 별도(목업은 대체 폰트, 굵기는 근사).

## 6. 추천
**B안 '국면 띠'를 기본으로 R2 진행**, 다음 두 가지를 보완.
1. 이유: 대표 최우선 '연관관계 한눈에 종합'을 가장 정확히 시각화 — 지수 흐름·크게 빠진 구간(낙폭+회복)·금리 국면이 **한 화면에서 구간 단위로 대응**되고, 국면을 별도 띠로 둬 R10(시각 인과 금지)을 지키며 띠가 R8 기준선(전체 기간 비율)을 시각으로 제공해 첫 화면 숫자도 10 이내. A는 연 단위 연도 막대라 −20% 구간(월 단위)과 단위가 달라 ②와 안 이어지고 R10 위험이 크다. C는 이해는 쉽지만 종합 비교가 없다.
2. 보완(R2): ⓐ B의 선택 카드에 **C의 확대 미니 차트(고점·바닥·되찾음)** 차용 ⓑ 구간 칩 대신 C식 접힘 행 목록을 ② 와 합쳐 ②·① 중복(같은 5건 두 번) 제거 ⓒ 1280 카드 정렬 정리 ⓓ B 위험(정보 과다) 완화 — 범례를 띠 안 라벨로, 로그 눈금 표기 없이 시작·끝 지수 수준 숫자 0 유지.
3. 대표 결정 질문: ① 국면 무채색 3종(빗금 포함) 채택 ② R8 기준선 숫자를 첫 화면에 둘지(A) 띠로 대체할지(B) ③ 지수 흐름 로그선 사용(ia R1은 제외로 정리했던 항목).
