## 0. 규칙 재정의: 숫자 ≤10 = '축 눈금 제외, 데이터 값만'
- 제외: 축 눈금 라벨(지수값·%·연도 눈금), 지수 선택기 라벨(`S&P 500`·`나스닥100`), 고유 명칭 속 숫자(`코로나19`·`2022년 하락`). 같은 숫자 반복은 1개.
- 포함: 머리 문장·기준선 문장·카드 값·행 값·읽기 줄 값. **390 첫 화면(접지 780) 자동 집계: S&P 9, 나스닥100 8, 코스피 9**(`1985·20·5·3·1·41·12·11·10`). 연도 읽기 상태(`yr=2008`)는 10. 접힌 행에는 숫자를 두지 않는다(낙폭 값은 펼침 + 위 낙폭 패널 눈금이 대신함).
- 축 요구 충족: 지수 y = 1-2-5(범위 넓으면 1-3) 실제 값 눈금(`100·200·500·1,000·…`), x = 10년 라벨 + 5년 눈금(1280은 5년 라벨, 390·320 겹침 0 자동 검사), 낙폭 `0%·−20%·−40%·−60%`(나스닥100·코스피는 −40·−80), 금리 `0%·5%·10%`(코스피 `0·2·4·6%`).

## 2. 화면 구성 (위→아래, 390 기준 폭 328px 차트 / 320 256px)
1. 지수 선택(`InlineSelector` 재사용, 40px) `S&P 500 | 나스닥100 | 코스피` — 전환 시 머리·그림·행 전부 해당 지수로 교체, 선택 초기화.
2. **카드 1 = 공유 한 장**(business 보완 1·3 반영): 머리 3줄 → 3패널 차트 → 행 목록. 서비스명 워터마크 없음.
   - 머리: `{시작연도}년 이후 20% 넘게 빠진 때는 N번이었어요`(18/700) · `그중 3번은 미국 금리를 내리던 중, 1번은 올리던 중, 1번은 거의 그대로였어요`(14, 첫 구절 fg 600) · 기준선(11, mf). 코스피 = `한국 금리`, 자료 없는 건은 `1번은 금리 자료 없음`.
   - 차트(자체 SVG 1벌, 같은 시간축 3패널, 패널 사이 연결선·화살표 0 — R10): ⓐ **지수 흐름** 높이 112(1280 190), 로그 눈금 라벨 `로그` 낱말 없음, 캡션 ⓘ = `오르내린 비율이 같으면 같은 높이로 그렸어요`, 낙폭 구간만 굵은 파랑, 끝점 점 + 캡션 `10월 말까지`. ⓑ **고점 대비 낙폭**(언더워터 면) 높이 46(70) — 전체 낙폭은 회색 면, ≥20% 구간의 내림만 파랑 면, 회복은 회색 면이 0으로 돌아오는 모양. 이름 라벨 줄. ⓒ **기준금리**(미국/한국) 계단선 + 국면 면 높이 42(64), 코스피 1999-05 이전은 `자료 없음` 빈 칸. x축 연도 눈금 1줄.
   - 목록: 캡션 줄 `크게 빠진 때  −20%  −40%  −60%`(낙폭 눈금), 행(이름 15/600 · 국면 표식 12 · 낙폭 막대 8px, 쉐브론), 한 번에 1개 펼침. 펼침 = 큰 낙폭 % 24/700 파랑 → `고점 2007.10 · 바닥 2009.03` → 3칸(`고점에서 바닥까지 17개월` · `고점에서 전고점까지 65개월 ⓘ` · `그때 금리 내림 4.5%에서 0.25%로`) → **구간 확대 차트**(지수 y 값 눈금, 고점·바닥·전고점 점, 고점 수평 점선 + 같은 창 금리 계단 % 눈금, x 연·월 눈금, 고점·바닥 달 축 표식) → `같은 시기 사건` 1줄. 진행 중(코스피 2026): `진행 중` 표시, 헤드라인 집계 제외, 펼침 `아직 전고점을 되찾지 못했어요`.
3. 카드 2 = ③ `기간을 골라 계산해 보기`: 방식 세그먼트 · 시작/끝 · 칩(`달러 기준`/코스피 `포인트 기준`, `지수 값만(배당 빼고)`) · 결과 문장 · 배당·R5 각주. 금액 입력 없음.
4. 출처 줄(1280은 카드 1 안, 390은 페이지 끝): 가격 지수(배당 제외)·월말 종가·기준일·`가데이터`.
- **1280**: 카드 1 = 머리 + 전폭 차트(x 라벨 5년), 아래 좌 400px 목록(행 선택 = 우측 상세, 기본 = 가장 깊은 하락) · 우 상세 패널(sticky, 확대 차트 560px). ③ 좌측 560px. 최대폭 1080.

## 3. 토큰·간격 (신규 토큰 0)
카드 `rounded-2xl`·shadow 우선(다크는 그림자 없음), 카드 안 padding 16(하단 12), 섹션 gap 12(카드 사이 — 같은 흐름), 행 56px 히트 전체, 선택기·세그먼트 40px, 누름 `scale(.96)/.99`, 모든 글자 ≥11px(`text-2xs`), tabular-nums, 파랑=손실 전용·선택 brand·빨강=총수익/해마다 평균. **design-system 흡수 후보 1건: 금리 국면 표기**(올림 = 진회색/다크 밝은 회색 면, 내림 = 45° 빗금, 멈춤 = 비움, 6px 미만 = 1px 테두리). 언더워터 낙폭 패널·3패널 공유 시간축 차트는 투자 탭 전용 패턴으로 문서화 제안.

## 4. 상태·모션·접근성
- 상태: 기본(선택 없음) / 행 펼침 / 연도 읽기 / 진행 중 행 / 금리 자료 없음(1994 외환위기 행 `금리 자료 없음` 표식 + 확대 차트 계단 생략) / 정적 데이터라 로딩·오류 없음, 빈 상태 없음 / 긴 이름은 이름 줄바꿈 없이 칩과 같은 줄(320 확인).
- 모션: 행 펼침 grid-rows 전환(항상 마운트, design-system §6 높이 펼침), 선택 면 fade 160ms, 시간 `motion-safe`, 연타·중간 전환은 선택 상태 교체만(재마운트 없이 같은 DOM 값 갱신). 차트 탭/끌기는 `touch-action: pan-y`, 가로 끌기는 연도 스냅.
- 접근성: 행 `<button aria-expanded>`, 차트 `role="img"` + 요약 aria-label, SR용 표(5행 전수: 이름·기간·낙폭·바닥까지·전고점까지·그때 금리)를 접힘이어도 DOM에 둠(business §4 SSR), 국면 = 색이 아니라 면/빗금/비움 모양, 다크 대비 확인, 차트 그림 탭은 보조 입력(정식 입력 = 행). ⓘ 히트 40px(`pointer-coarse` 확장).
- data-testid: `invest-index`·`invest-headline`·`invest-base`·`invest-readout`·`invest-sec1`·`invest-sec2`·`drop-row`·`episode-detail`·`detail-dd`·`invest-sec3`·`calc-result`. `data-screenshot-hide`: 없음(개인 자산 없음), 지수 값은 공유 캡처에 그대로 포함.
