## 방향 재계산 (0.25%p 규칙)
ECOS 12월 값으로 계산: 올라감 12(2000·02·05·06·07·10·11·17·18·21·22·23) / 내려감 14(2001·03·04·08·09·12·13·14·15·16·19·20·24·25) / 거의 그대로 0 → 합 26. **코스피 26 = 12/14/0**. 앱 `buildIndexView('kospi').base` = n26·up12·down14·flat0. 일치. 경계 ±0.25 해(2002·2013·2016·2017·2018·2023)는 모두 쿼터 단위라 부동소수 오차 없이 분류됨.
- ⚠ spec 4-6 본문의 "코스피 26 = 14/12/0"은 (내려감/올라감/거의 그대로) 순서로 읽으면 일치(내려간 14·올라간 12). 앱 표시 순서와 문구가 같은지는 UI 쪽 확인 사항이며 숫자 자체는 일치.
- 하락 6행 중 금리 있는 행: 1999→2000 상승(4.75→5.25, +0.5), 2007→2008 하락(5.0→3.0, −2.0), 2017→2018 상승(1.5→1.75, +0.25), 2021→2022 상승(1.0→3.25, +2.25). 1989~91·1994~97 행은 금리 자료 없음(none). ECOS 값으로 재계산한 방향과 동일 — **방향 변화 0**.
