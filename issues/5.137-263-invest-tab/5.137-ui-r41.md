## 3. 연도별 격자 사양 (`yearly-grid`)
- 카드: `card` 16px 패딩, 제목 `{지수} 연도별 등락률`(16 bold), 보조 `해마다 연말 기준 등락(%) · 가격 지수(배당 제외) · 미국 달러 기준`(코스피 `포인트 기준`, 11px muted).
- 격자는 **카드 좌우 끝까지 펼침**(마진 −16): 첫 열 12px(끝자리 0~9, 11px muted) + 연대 열 `1fr`×N. 머리 행 28px(`1960`…, 11px 600 muted), 셀 높이 40.
- 셀 = `<button role=gridcell>` `±N.N`(소수 1자리, `+`·`−`(U+2212), 11px 600 `fg`, tabular-nums), 배경 = 손익 토큰 알파(양 `profit`·음 `loss`, 라이트 225,29,72 / 37,99,235, 다크 251,113,133 / 96,165,250), **알파 = 0.10 + 0.50×min(|등락|/40, 1)**, |등락|<0.05는 `--sec` 회색 `0.0`. 셀 사이 `inset -1px -1px` card색 1px. 데이터 없는 칸(첫 해 전·미래)은 빈 칸, `aria-hidden`.
- 대비(실측 `minContrast`): 라이트 7.83, 다크 4.91(390)·4.71(1280) — 글자 `fg` 대 알파 합성 배경, 모두 ≥4.5. 색만이 아니라 **부호 글자**로도 방향이 구분된다(색각 대응). 알파 상한 0.60 넘지 말 것.
- 범례: 7칸 색 막대 + `−40% 이하 ~ +40% 이상, 진할수록 많이 움직인 해`, 보조 `━ 아래 기간 등락률에서 고른 기간`.
- **기간 연동**: 아래 카드에서 고른 기간(시작 다음 해~끝 해)의 셀에 하단 3px brand 밑줄(`in`). 기본 10년이면 2016~2025 밑줄. 지수 그림(카드1)에는 표시를 더하지 않는다(첫 화면 보호).
- 선택·읽기 줄: 셀 탭/끌기 → 셀 `inset 2px fg` 윤곽 + 격자 아래 읽기 줄 `2008년 말 903 · −38.5% · 금리 내려감 · 경기침체`(R3 읽기 줄 문구 재사용, `aria-live=polite`, 320은 줄바꿈 허용). 기본 안내 `해를 누르거나 끌면 그해 말 값이 나와요`.
- 모션: 셀 press scale .96, 윤곽 `box-shadow` 120ms(`transition: all` 금지), 격자는 재마운트하지 않고 클래스만 바꾼다(구현), `motion-safe`.
- 접근성: `role=grid`+`aria-label`(열은 연대·행은 끝자리), 셀 `aria-label="2008년 −38.5%"`(+`, 선택됨`), 화살표 키 이동(구현), 포인터 `touch-action: pan-y`(가로 끌기=스크럽, 세로=스크롤).
- 상태: 로딩 없음(정적) · 빈 칸 처리 · 지수 전환 시 선택 해제·열 수 변경(S&P 7/나스닥 5/코스피 5, 셀 폭 69px) · 긴 문구 없음.

## 4. 기간 등락률 카드 사양 (③ 통합, `invest-sec3`)
### 4-1. 구성(위→아래)
제목 `{지수} 기간 등락률` + 부제 `그해 말에 넣었다면` → 기간 알약 4개(`5년 10년 20년 전체`, 40px, 일치 시 brand soft) → 시작·끝 선택 2칸(40px, 라벨 `시작`/`끝`, 값 `1999년 말`; 끝은 시작+1 이상, 시작이 끝 이상이면 끝 자동 보정) → **결과 2줄 블록** → 어림 1줄 + ⓘ → 범례 3개 → 읽기 줄 → **그림** → chip `달러 기준` `지수 값만(배당 빼고)` → 각주.
- 기본 기간 `{LAST−10}`→`{LAST}`(2015→2025) 유지. `전체`는 지수 첫 해부터지만 알약 문구가 `전체`일 뿐 시작 연도를 칭찬·권유하지 않는다. 알약 `5·10·20년`은 숫자지만 첫 화면 밖이라 예산 영향 없음.
### 4-2. 정의(확정)
- 총액 = 1. 한 번에: 시작 연말에 1 전부, 평가액 = 지수 ÷ 시작 지수. **매달 사기: 시작 연말 다음 달부터 끝 연말까지 매달 같은 금액(총액/12n)으로 12n번, 그해 12번 모두 `(직전 연말 값 + 그해 연말 값) ÷ 2` 가격**. 연말마다 평가액 = (그때까지 산 수량) × 그해 연말 값. 끝점 = 한 번에 `끝 연말 ÷ 시작 연말`, 매달 `총액 대비 평가액`. 반올림 전 값으로 계산해 표시 때 한 번만 반올림(배수 2자리·총 변화 0자리·연평균 2자리).
- **연평균**: 한 번에 = 배수^(1/n)−1. 매달 = **넣은 시점을 반영한 해마다 평균**(매달 현금흐름의 내부수익률, 월 말 납입·월 복리 연환산). 문구에 `넣은 시점을 반영해`를 붙여 두 값이 다른 정의임을 알린다. 적립 쪽 `총 변화`는 `넣은 돈 대비`(= 평가액/총액 −1)이며 표시 `+19%`.
- **평균 vs 직선 보간(대안) 비교**(`compare.js`, 총액 1 기준 끝 배수 / 연평균):

- 차이는 장기(10년 이상)에서 ≤0.01배, 하락·반등이 겹치는 2~3년 짧은 기간에서만 최대 0.03배(+1.7%p). **평균 방식 권고**: 문장으로 정의를 한 줄에 설명할 수 있고(보간은 `월 값을 직선으로 이었다`는 가짜 월값 설명이 필요), 가짜 월 모양을 만들지 않는다. 보간은 월 값처럼 보이는 정밀 착시를 줄 위험이 있어 기각. 부호 반전 가능 구간(2007→2009 S&P 연평균 +2.36 vs +4.06)이 있어 짧은 기간일수록 `어림` 문구가 중요하다.
- **같은 시각 무게**: 두 선 모두 2px·같은 점 크기(원 vs 마름모, 점 안 card색), 색은 회색(`--ink2`)과 brand 인디고(`--brand`) — 휘도가 비슷한 두 중간 톤(라이트 4.6/ 다크 3.4:1 이상 필요, 구현 때 qa 실측). 끝점 라벨 두 개 모두 12px 600 `fg`(같은 서식), 결과 행도 같은 크기·같은 서식(아이콘 원/마름모만 다름). 평가액 `±` 색은 손익 부호색(규약)이며 어느 행도 배경·테두리·배지로 강조하지 않는다. `유리·불리·더 좋다·더 낫다` 자동 검사 0.
- 하락장에서 갈린 모습: 1999→2012 그림에서 한 번에 선은 시작 1배에서 2002년 0.6배대까지 내려갔다 2007년 1배 근처를 거쳐 2008년 0.6배로 다시 꺼지고, 매달 선은 0에서 서서히 올라 2007년 0.75배, 2008년 0.52배에서 꺼졌다 1.19배로 끝난다. 화면은 해석을 달지 않고 두 선·넣은 돈 선을 같은 축에 둔다.
### 4-3. 그림(390: 폭 326, 320: 256)
- 상단 층(높이 132): 세로축 **배수**(`0`, `0.5배`, `1배`…, 오른쪽 눈금 gutter, 간격 {0.5,1,2,5,10,…} 중 4칸 이하, 선형), `1배` 점선(= 넣을 총액 = 한 번에 넣은 돈). 선: 한 번에(회색, 원 마커, 시작 1배) / 매달(인디고, 마름모, 시작 0). **넣은 돈 선**(인디고 45%, 1.25px) 0→1배 직선(매달 같은 금액). 끝점 점 + `한 번에 0.97배` / `매달 1.19배` 라벨(halo, 겹치면 14px 위·아래로 벌림). 마커는 연 폭 ≥14px일 때만.
- 하단 층(높이 92): `연간 등락(%)` 막대(손익색 100%), 막대 라벨 정수 `±N`(11px, 연 폭 ≥20px = 390에서 14년 이하·320에서 10년 이하만; 초과 시 라벨 숨김 — 값은 읽기 줄·격자). x축 연도(간격 1·2·5·10년 자동, 첫 라벨 왼쪽 정렬로 안 잘림).
- 선택: 그림 탭 → 세로선(brand 1.5px) + 읽기 줄 `2008년 말 · 그해 −38.5% · 한 번에 0.61배 · 매달 0.52배`. 기본 안내 `해를 누르면 그해 말 두 방식의 평가액이 나와요`.
- 모션: 기간·알약 변경 시 SVG는 같은 DOM에서 값만 교체(구현은 path `d`/막대 transform 전환 200ms, `motion-safe`, 연타에도 현재 값에서 이어짐), 결과 블록 `pfade` 180ms. 재마운트 금지.
- 극단 기간(`전체`, 65년): 한 번에 117.8배·매달 32.3배 → 선형 눈금(0·50배·100배)에서 막대 라벨 숨김 상태. 읽을 수 있음(`390-period-full-light`)이나 초기 구간이 바닥에 붙는 한계가 있어 구현 때 세로 눈금 로그 전환은 이번 범위 밖(필요 시 후속).
### 4-4. 결과 2줄(문구 최종)
- 한 번에: `{시작}년 말에 총액을 한 번에 넣었다면, {끝}년 말 {지수} 지수 기준 넣은 돈의` `N.NN배` `±N%` `해마다 평균 ±N.NN% {오른·내린} 셈이에요`
- 매달: `같은 총액을 {시작}년 말부터 {n}년 동안 매달 나눠 넣었다면({12n}번), {끝}년 말 넣은 돈의` `N.NN배` `±N%` `넣은 시점을 반영해 ±N.NN% {오른·내린} 셈이에요`
- 아이콘 ○(회색) / ◇(인디고)로 그림 마커와 연결. 문장은 과거형·가정형(R1), 권유·평가 0.
### 4-5. 어림 1줄 + ⓘ
- 1줄(정본): `월 지수 값 대신 연말 값의 평균으로 매달 산 것으로 어림했어요` + ⓘ 버튼(40px 히트, `aria-expanded`/`aria-controls`).
- ⓘ 펼침(정의): `그해 12번을 모두 ‘직전 연말 값과 그해 연말 값의 평균’ 가격으로 샀다고 봤어요. 실제 월별 값이 아니라서 한 해 안에서 오르내린 모양은 반영되지 않아요. 총액과 기간은 한 번에 넣기와 같아요.`
- 각주(기존 정본 유지): `총액과 기간은 같고 넣는 방식만 달라요. 두 방식의 평가액은 같은 높이 눈금에 그렸어요.` / `배당을 다시 넣었다면 결과는 이보다 커요.` / R5 1줄(`과거 연말 지수 값으로 계산한 결과예요. 배당·세금·수수료는 빼고, 반올림하지 않은 값으로 계산해 마지막에 한 번만 반올림해요. 앞으로도 같다는 뜻은 아니에요.`).
- spec 영향: 4-13(해마다 방식·`가장 낮았던 해 말`)·6-1 ③ 줄·AC5/AC6/AC29(`해마다` 결과 값) 개정 필요. 검산 값: S&P 2015→2025 한 번에 `3.35배 · +235% · 해마다 평균 +12.85%` 유지, 매달 `2.01배 · +101% · 넣은 시점 반영 +13.60%`, 1999→2012 `0.97배 · −3% · −0.23%` / `1.19배 · +19% · +2.66%`.

## 10. developer 구현 요점
1. **격자**: 정적 연말 등락을 `d.ret`에서 만든다(R3 계산 재사용, 신규 데이터 0). 셀 배경은 인라인 rgba — 신규 CSS 변수 0, 알파 공식 4-3 그대로, 글자는 `fg`(알파 합성 대비 ≥4.5 qa 확인). `ggrid`는 `grid-template-columns: 12px repeat(N,minmax(0,1fr))`, 카드 `-mx-4`로 가장자리까지.
2. **상태 공유**: `period={sy,ey}` 1개를 격자(밑줄)·기간 카드가 공유, 저장 안 함(탭 이탈 시 초기화), 지수 전환 시 기본 기간으로 복귀. 새 저장 키 0.
3. **계산**: `tools/r41/r41.js`의 `series()`(한 번에 평가액·매달 평가액·넣은 돈)·`irrM()`을 그대로 `src/lib`에 옮겨 vitest 검산(S&P 2015→2025·1999→2012 위 표 값, 평균 방식 1개만 구현 — 보간 코드 금지). 연평균은 반올림 전 값으로.
4. **그림**: SVG, 한 컴포넌트에서 데이터만 바꿔 transition(재마운트 금지). 두 선 `stroke-width 2`, 같은 점 반경, 색 `--ink2`/`--brand`, 라벨 서식 동일. 끝점 라벨 겹침 보정·눈금 간격 규칙(28px)·x 라벨 간격 규칙은 목업 코드 참고. 막대 라벨 숨김 임계 = 연 폭 20px.
5. **기존 ③ 삭제**: `한 번에 | 해마다` 토글, `가장 낮았던 해 말` 줄 제거. spec 4-13·AC5·AC6·AC29 개정, GA `invest_calc`는 기간·알약·선택 변경 시 진입당 1회로 유지.
6. **카피**: 5절 그대로. `수익`·`로그` 포함 금지, CEO 판정 대기 항목(0절)은 판정 전 `등락률`로 구현.
7. **qa 시점 확인**: 두 선의 시각 무게(휘도·굵기) 육안·실측, 320 셀 폭, 1999→2012·2015→2025 값, 금지어, 기간 연타 시 그림이 이어지는지, ⓘ 펼침·포커스.
