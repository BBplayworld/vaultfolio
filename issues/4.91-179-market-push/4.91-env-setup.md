# PWA 시장 알림 — Vercel 환경 변수 등록 안내 (대표용, 11/14)

값 자체는 이 문서·저장소·채팅에 쓰지 않는다. 대표 PC에서 만들어 Vercel에만 붙여 넣는다.

| 변수 이름 | 만드는 법 | Production | Preview |
|---|---|---|---|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | `npx web-push generate-vapid-keys` 의 Public Key | ○ (벌 A) | ○ (벌 B, 다른 값) |
| `VAPID_PRIVATE_KEY` | 같은 명령의 Private Key (공개키와 같은 벌) | ○ (벌 A) | ○ (벌 B) |
| `VAPID_SUBJECT` | `mailto:운영연락이메일` 또는 `https://www.secretasset.xyz` | ○ | ○ (같아도 됨) |
| `PUSH_STORE_KEY` | `openssl rand -base64 32` (base64 32바이트, 길이 다르면 동작 안 함) | ○ (값 1) | ○ (값 2, 다른 값) |
| `CRON_SECRET` | `openssl rand -hex 32` | ○ | ✕ (Production만) |

- 이미 있는 `KV_REST_API_URL`·`KV_REST_API_TOKEN`(Redis)은 그대로 사용. 새로 넣지 않음.
- Preview·Production은 같은 Redis를 쓰므로 키를 반드시 다르게(저장 키 공간도 환경별로 분리돼 있음).
- `NEXT_PUBLIC_…`은 빌드 때 들어가므로 등록 후 재배포 필요(Preview는 issue-4.91 최신 배포 Redeploy).
- `PUSH_STORE_KEY`를 나중에 바꾸면 기존 구독은 복호화 불가로 정리됨(재구독 필요). 함부로 바꾸지 않기.
- Vercel Cron은 `CRON_SECRET`이 있으면 Authorization 헤더를 자동으로 붙임.
