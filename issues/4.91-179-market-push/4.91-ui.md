## 1. 컴포넌트 트리

### 1-1 설정 '알림' 섹션 (수정: `settings-page.tsx`, 신규 파일 `notify-section.tsx` 권장)
위치: `settings-section-display` 다음, `settings-section-data` 앞. `<section data-testid="settings-section-notify">` + `MENU_SECTION_LABEL` "알림" + `flex flex-col gap-2`(기존 보안·데이터 섹션과 동일).

- 행 3 `테스트 알림 보내기` — preview 환경 + ON일 때만. `MENU_ROW`, 아이콘 `Send`, 설명 `미리보기 환경에서만 보여요`. 대표 데모용(운영 미노출).
- 대화상자 3종 + 삭제 확인 문구 1구: 아래 1-2~1-4, 2-4.
- 신규 컴포넌트 `NotifyPreview`(예시 알림 카드) 1개만 — 켜기 안내 전용, 공용화 안 함.

### 1-2 켜기 안내 `Dialog` (`DialogContent className="sm:max-w-md touch-pan-y"`, 앱 잠금 Dialog와 같은 껍데기)
위→아래: ① `DialogTitle` `flex items-center gap-2` + `Bell size-5 text-primary` + "시장 알림 켜기" ② 캡션 `예시 알림`(11px muted, px-1) + 잠금화면 well(`rounded-xl bg-background p-2 gap-1.5`, 안쪽 카드 `rounded-lg bg-card`(동심: 12→8… 구현은 `rounded-xl`→`rounded-lg`), 카드 = 앱 아이콘 36px `rounded-[9px]`(`/icons/icon-192x192.png`, alt="") + 위 줄 `시크릿에셋`·`지금`(11px muted) + 제목 14px semibold + 본문 14px muted) 2건: `11/12 국내 종가 / 코스피 +0.8%`, `11/12 미국 종가 / S&P 500 -0.3%` ③ 핵심 신뢰 문구 `text-sm font-medium`(foreground, muted 아님 — 가장 중요) ④ 보조 2줄 `text-sm text-muted-foreground leading-relaxed text-pretty break-keep` ⑤ `DialogFooter flex-col gap-2`: `Button variant="brand"` [알림 켜기] → `Button variant="secondary"` [취소](기존 순서·크기).
- 예시 카드는 **OS 알림이 색을 못 쓰므로 손익색 금지**(전부 foreground/muted). 예시 날짜는 고정 문자열 아님 — 마지막 거래일이 아니라 "예시"이므로 오늘 M/D 사용(코드: 오늘 날짜 포맷), 값은 고정 예시 +0.8%/-0.3%.

### 1-4 대상·조건 `Dialog`
위→아래: 제목(`SlidersHorizontal`) "알림 받을 대상·조건" → **상태 줄**(고정 높이 20px 한 슬롯): 평소 `N개 선택`(`tabular-nums` muted), 0개면 같은 슬롯에 `대상을 1개 이상 골라 주세요`(주황) → **목록 영역**(`max-h-[320px] overflow-y-auto overscroll-contain`, 좌우 `-mx-2 px-1` 로 히트영역 확보) → `알림 조건` 라벨 → `InlineSelector fullWidth`(role=radiogroup 내장, min-h-10, 화살표 키) → 선택 조건 설명 1줄(`min-h-11` 2줄분 예약) → 도착·적용 범위 문구 → [저장] brand · [취소] secondary.
- **목록 5묶음·15행**(서버 카탈로그 순서): `국내 지수`(코스피·코스닥) / `해외 지수`(S&P 500·나스닥 종합) / `관심 지수·환율`(나스닥100·필라델피아 반도체·원/달러) / `관심 ETF`(TIGER 반도체TOP10·TIGER 배당커버드콜액티브) / `시가총액 상위`(국내 3·미국 3, 행 우측 시장 태그). 시총 국내/미국은 한 묶음 + 시장 태그로 5묶음 유지. ETF·시총 종목명은 **mock 표기 — tech-review 확정 상수로 교체**.
- 묶음 라벨 `text-sm font-semibold text-muted-foreground`(= `MENU_SECTION_LABEL` 위계, 높이 32). 행 = `<label>` 전체가 탭 영역 `flex items-center gap-3 min-h-10`, 기본 `Checkbox`(자동 brand). 행 우측 시장 태그 `국내`/`미국` 11px muted(국내 지수·해외 지수 묶음은 라벨이 시장을 말하므로 태그 생략; 도착 시각이 시장별이라 혼합 묶음에만 필요).
- **조건 라벨 최종**: `매 거래일` / `±2% 이상만`(합의안 `종가 ±2% 이상인 날만`은 320에서 `truncate` 셀(약 100px)에 잘림 → 짧은 칸 라벨 + 선택 설명줄에 풀문구). 설명줄: 전자 `거래일마다 장 마감 후 종가 등락을 알려드려요.` / 후자 `종가가 ±2% 이상 움직인 대상만 알려드려요. 그런 대상이 없는 날은 알림이 없어요.`
- 하단 문구(고정 1단락): `국내 장은 오후 4~5시, 미국 장은 다음 날 아침 9~10시에 도착해요. 이 설정은 이 기기에서만 적용돼요.`
- **높이 규칙(320×568급 소형 포함)**: `DialogContent`에 `max-h-[calc(100dvh-2rem)] overflow-y-auto`. 뷰포트 높이 ≥700이면 목록만 내부 스크롤(`max-h-[320px]`), 그 미만이면 `@media (max-height:700px)`로 목록 `max-h-none`(중첩 스크롤 금지, 다이얼로그 전체가 한 번 스크롤) + 푸터 `sticky bottom-0 bg-popover pt-2`로 [저장]이 항상 보이게. (목업 `mock-targets-320-dark.png`는 640 높이에서 이 규칙 없이 푸터가 잘림 — 규칙 필요 근거.)
- **스크롤 단서**: 375×812 기준 목록 높이 320에서 마지막 보이는 행이 **반쯤 잘리게** 우연이 아니라 설계(그라데이션 페이드는 §3.2 장식 금지로 불채택). 목업에서 `필라델피아 반도체` 행이 반쯤 보임.

## 4. 인터랙션·모션
- 행 1 탭: OFF→Dialog(권한 요청은 [알림 켜기] 핸들러 첫 await — 제스처 유지). ON→즉시 해제. 연타: 처리 중 `aria-busy`+무시(중복 구독·중복 토스트 금지), 해제 직후 재탭은 다시 Dialog.
- 배지 전환 `motion-safe:animate-in fade-in duration-150`(배지는 key로 교체하되 행·섹션은 **재마운트 금지** — 섹션 컴포넌트를 상태로 조건부 마운트하지 말고 행만 조건 렌더, 행 2·3 진입은 `grid-rows` 펼침 §6(재마운트 없음) 패턴 권장, 최소한 `fade-in`).
- 행 2·3 등장/퇴장: 항상 마운트 + `grid-rows-[0fr]↔[1fr]` `motion-safe:duration-300` + `inert`(켜자마자 아래 섹션이 부드럽게 밀림; reduced-motion 즉시).
- Dialog 열림/닫힘: 기존 `zoom-in-95 fade-in`(변경 없음). 거부 화면 교체는 위 fade.
- 체크 토글: 기본 Checkbox 전환(무전환 지시 없음), 라디오 썸 슬라이드는 `InlineSelector fullWidth` 기본(200ms, `motion-safe`). 설명줄은 교체 시 높이 예약(점프 0).
- 버튼 누름 0.96 scale은 `Button` 기본.

## 5. 접근성
- 행 1 `button aria-pressed={on}`, 아이콘 `aria-hidden`, 배지 텍스트 ON/OFF가 이름 일부. 행 2 `aria-haspopup="dialog"`. 행 3 일반 버튼.
- 체크 행은 `<label>`+`Checkbox`(id 연결), 묶음은 `role="group" aria-labelledby=묶음 라벨`, 0개 경고 `role="status"`(sr 안내), 저장 비활성 `disabled`.
- 조건 `InlineSelector` `ariaLabel="알림 조건"`(화살표·Home·End 기본 지원).
- 히트영역: 설정 행 ≥56px, 체크 행·라디오 칸 40px(체크박스 자체는 16px — **행 전체가 탭 영역**), Dialog 닫기 X는 기존 `after:-inset-2.5`.
- 다크 대비: 설명줄 `text-muted-foreground`(기존), 주황 `dark:text-orange-400`, 예시 카드 muted 글자 well(`#0B0D12` 위 카드 `#191C22`) 4.5:1 이상 — 육안 목업 확인, 수치 측정은 ui-review.
- 포커스 링 전역 기본(재정의 금지). Dialog `onOpenAutoFocus` 기본(preventDefault) 유지.

- 켜기 Dialog: 제목 `시장 알림 켜기` / 핵심 `알림에는 시장 등락률만 담겨요. 자산 정보는 서버로 보내지 않아요.`(합의 그대로) / 도착 `국내 장은 오후 4~5시, 미국 장은 다음 날 아침 9~10시에 도착해요.` / 기본값 `처음엔 코스피, S&P 500만 받아요. 나중에 바꿀 수 있어요.` / [알림 켜기]·[취소].
- 토스트: `시장 알림을 켰어요` `시장 알림을 껐어요` `알림 대상을 저장했어요` `테스트 알림을 보냈어요` `잠시 후 다시 시도해 주세요`.
- **OS 알림 형식**: 아이콘 `icon`=`/icons/icon-192x192.png`(기존), `badge`=**흰색 단색 S 글리프 투명 PNG 96×96**(Android 상태줄은 알파만 씀 — 신규 에셋 1개, 로고 §14 S 글리프에서 추출). 제목 `M/D 국내 종가` / `M/D 미국 종가`(M/D = 그 시장 종가일). 본문 `이름 ±x.x%`를 ` · `로 연결, 부호·소수 1자리는 `formatCompareRate`와 동일(`+0.8%`·`-0.3%`·`0.0%`, 하이픈 `-`). 예: 국내 `코스피 +0.8% · 코스닥 -0.4% · 원/달러 +0.2%` / 미국 `S&P 500 -0.3% · 나스닥 종합 -0.6%` / 많을 때 `코스피 +0.8% · 코스닥 -0.4% · 원/달러 +0.2% · 삼성전자 +1.1% 외 2개`. 항목 수 4개 초과 **또는 누적 글자수 약 56자 초과** 시 앞에서부터 담고 나머지 `외 N개`(최소 1개, 긴 ETF명 4개가 잠금화면 2줄을 넘어 잘리는 것 방지 — 글자수 상한은 구현 시 실기기 보정). 폴백 `오늘 시장 종가가 업데이트됐어요`. `tag`=`market-kr`/`market-us`(교체), `data.url`=`/?from=push`.
- 삭제 확인: `시장 알림도 꺼집니다.`(ON일 때만).
- `data-screenshot-hide`: 설정 화면은 인증카드 대상 아님 → 해당 없음(알림 섹션 포함 안 함).

## 8. 품질 체크리스트 (qa 판정용)
1. 설정 섹션 순서가 보안·화면·표시·**알림**·데이터·버전이고, 알림 행이 `MENU_ROW`와 같은 반경·패딩·배지 규격(앱 잠금 행과 픽셀 비교 동일)이다.
2. 375·320 × 라이트·다크에서 행 설명줄이 어절 중간에서 끊기지 않는다(`break-keep` computed, C25), 행 높이 2줄 이내.
3. 행 2에 행 1과 같은 요약 문구가 없다(C1). ON 설명 `코스피, S&P 500 · 매 거래일`.
4. 켜기 Dialog 문구가 합의 문구와 한 글자 단위로 같고(핵심 신뢰 문구·도착 시각), 도착 시각이 `오후 4~5시`·`다음 날 아침 9~10시` 범위 표기이다. 정각 표기 0.
5. 예시 카드에 손익색·금액·`내`·`보유`·평가어가 없다. [알림 켜기]는 `Button variant="brand"`(#5b6fbf), 체크박스는 기본 Checkbox 체크 시 brand.
6. 대상 Dialog 목록 15행·5묶음, 기본 체크는 코스피·S&P 500 정확히 2개, 375에서 목록 내부 스크롤이 되고 마지막 보이는 행이 반쯤 잘려 스크롤 단서가 된다. 헤더·조건·[저장]은 스크롤되지 않고 보인다(≥700 높이).
7. 320×568에서 다이얼로그 전체가 스크롤되고 [저장]이 sticky로 항상 보인다. 중첩 스크롤 없음.
8. 0개 선택: [저장] disabled, 같은 슬롯에 경고 문구, 슬롯 높이 변화로 아래 레이아웃 점프 0.
9. 모든 탭 요소 히트영역 ≥40×40(체크 행 `elementFromPoint` 측정), 키보드로 Tab·Space·화살표 조작 가능, 포커스 링 보임.
10. 행 2·3 등장은 섹션 재마운트 없이 부드럽게(`prefers-reduced-motion`에서는 즉시), 연타해도 중복 토스트·중복 구독 0.
11. 권한 거부 화면 문구·행 설명(주황)·OFF 유지. 행 탭이 같은 안내를 다시 연다.
12. iOS 미설치 UA에서 행이 `홈 화면에 추가한 앱…`+쉐브론이고 탭 시 기존 PwaInstallFlow 첫 화면(C33: 문구가 약속한 행동과 열린 화면 제목이 일치). Push 미지원이면 섹션 제목까지 없다.
13. 확인 중 상태에서 스켈레톤→확정 시 아래 섹션 점프 0(높이 예약), ON→OFF 깜빡임 없음.
14. '모든 데이터 삭제' 확인 문구는 ON일 때만 `시장 알림도 꺼집니다.` 포함, OFF일 때 기존 문구와 동일. 실제로 서버 구독 삭제·기기 구독 해제가 됨.
15. OS 알림 제목·본문이 형식(날짜 M/D·`국내/미국 종가`·`±x.x%`·`외 N개`)과 일치, 알림 날짜·값이 홈 `MarketLine`과 같다(C80/C84), 같은 시장 이전 알림은 교체.

## 9. 알려진 한계·참고
- 목업은 DOM 주입 정적 이미지: 체크·스크롤 동작·모션·OS 알림 실제 모양(iOS/Android 렌더 다름)은 목업으로 확인 불가 → ui-review에서 preview로 확인, OS 알림은 실기기 미검증 한계 명시.
