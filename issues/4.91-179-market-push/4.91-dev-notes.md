| `cond` | `daily`/`pm2` | 동일 | 발송 조건 |
| `createdAt`·`updatedAt` | YYYY-MM-DD(일 단위) | 동일 | 정리·진단 |
| `push:{env}:topic:{ID}` | 집합(HMAC id만) | 90일 | 역색인 |
| `push:{env}:sent:{kr|us}:{날짜}` | "1" 플래그 | 3일 | 회차 중복 방지 |
| `push:{env}:all` | 집합(HMAC id만) | 90일(저장 시 연장) | 전체 구독 수 상한(5,000) 판정 |
| `push:{env}:testlock:{id}` | 잠금 플래그 | 60초 | 테스트 알림 쿨다운(preview 전용) |

저장하지 않음: IP·UA·쿠키·동기화 금고 ID·지역·언어·시각(초)·보유 정보. 로그에 endpoint·키 출력 없음(`sendPush` 실패 로그는 상태 코드만). PUSH_STORE_KEY가 없거나 32바이트가 아니면 `isPushConfigured()` false → API 503. 키 교체 시 기존 블롭은 복호화 실패로 null(미발송, 평문 노출 없음, 재구독 필요).
삭제 경로: 해지(DELETE는 endpoint 원문→HMAC)·모든 데이터 삭제·발송 시 404/410·TTL 90일.
