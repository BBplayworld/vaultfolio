## 변경 요약
- 설정 '알림' 섹션(`header-menu/notify-section.tsx`): 켜기 안내 → 권한 → 구독 → 대상 15개·조건 Dialog(320 높이 규칙: `[@media(max-height:700px)]` 목록 max-h-none + 푸터 sticky), preview 전용 테스트 행. 체험 모드·Push 미지원은 섹션 숨김.
- **설치한 앱(standalone)에서만 켜기**(대표 지시): `matchMedia('(display-mode: standalone)') || navigator.standalone`. 브라우저 탭(안드로이드·PC 포함)·인앱은 `홈 화면에 추가한 앱에서 쓸 수 있어요` + 기존 `PwaInstallFlow`. subscribe 본문에 `standalone:true` 필수, 서버는 없으면 400(위조 방어는 아님 — 클라이언트 게이트가 주 방어).
- 서버: `/api/push/subscribe`, `/api/push/test`(preview·로컬 전용), `/api/push/cron/{kr,us}`(`runPushCron`), `vercel.json` crons(국내 `0 7 * * 1-5`, 미국 `0 0 * * 2-6`).
- `sw.js` push·notificationclick(CACHE v5), `PushHost`(from=push GA·구독 보정·TTL 갱신), '모든 데이터 삭제' 연동(서버 삭제 → 기기 해제 → 로컬 키 삭제), 새 소식 `20261112-04`, GA category 4종.
- web-push는 v4.0.0(ESM, `import * as webpush`) + `@types/web-push`. 서버 전용(`send.ts` `server-only`), 클라이언트 청크에 암호화·web-push 코드 0(`aes128gcm|http_ece|generateVAPIDKeys` grep 0건). `.next/static/chunks` 4392→4416KB(+24KB, 전부 알림 UI·클라이언트 코드). `npm audit --omit=dev`에 web-push 계열 신규 취약점 없음(기존 zod 1건).

## 서버 저장 항목 표
| 필드 | 형태 | 보존 | 목적 |
|---|---|---|---|
| `push:{prod|preview|dev}:sub:{id}` 키 | id = HMAC-SHA256(PUSH_STORE_KEY, endpoint) hex | 90일(앱 열 때 `reconcilePush`가 갱신) | 구독 조회(주소 추측·대조 방지) |
| `blob` | endpoint·p256dh·auth를 AES-256-GCM(iv12+tag16+암호문, base64) | 동일 | 푸시 발송 |
| `topics` | 카탈로그 ID 배열(평문, 고정 15개 중) | 동일 | 발송 대상 |
| `cond` | `daily`/`pm2` | 동일 | 발송 조건 |
| `createdAt`·`updatedAt` | YYYY-MM-DD(일 단위) | 동일 | 정리·진단 |
| `push:{env}:topic:{ID}` | 집합(HMAC id만) | 90일 | 역색인 |
| `push:{env}:sent:{kr|us}:{날짜}` | "1" 플래그 | 3일 | 회차 중복 방지 |
저장하지 않음: IP·UA·쿠키·동기화 금고 ID·지역·언어·시각(초)·보유 정보. 로그에 endpoint·키 출력 없음(`sendPush` 실패 로그는 상태 코드만). PUSH_STORE_KEY가 없거나 32바이트가 아니면 `isPushConfigured()` false → API 503. 키 교체 시 기존 블롭은 복호화 실패로 null(미발송, 평문 노출 없음, 재구독 필요).
삭제 경로: 해지(DELETE는 endpoint 원문→HMAC)·모든 데이터 삭제·발송 시 404/410·TTL 90일.

## P0 실호출 확인 결과
**확인 불가** — 이 세션은 KIS 키가 없고 openapi.koreainvestment.com 접근도 막힘(HTTP 000). 따라서 아래는 **미검증**, 카탈로그 15개를 그대로 두고 조회 실패·stale 항목은 알림에서 자동 생략되도록 구현(코드 상수 제거로 줄이는 방법은 그대로 유효):
- 지수 코드: 코스닥 `1001`, 나스닥 종합 `COMP`, 나스닥100 `NDX`, 필라델피아 반도체 `SOX`(코스피 `0001`·S&P `SPX`는 운영 중).
- ETF 등락률: 국내 `inquire-price` `prdy_ctrt`(`StockPriceResult.changeRate`로 추가). 없으면 해당 항목 생략.
- 해외 종목(NVDA·MSFT·AAPL): 신규 `fetchOverseasChangeRate`(price-detail `last`/`base`로 계산).
- 원/달러: 현재값 `fetchExchangeRateFromKis` vs 기존 환율 이력 `getExchangeHistory()`의 이전 일자 USD. 이력이 없으면 생략(이력은 앱 사용자가 환율을 받을 때 쌓임).
- 시총 상위 6개(삼성전자·SK하이닉스·LG에너지솔루션 / 엔비디아·마이크로소프트·애플)는 외부 조회가 막혀 **추정 초기값**. 분기 1회 수동 확인·상수 PR 필요, 확인 기준일·출처 미기록.
- 확인 방법: 대표 환경 변수 등록 후 운영 첫 Cron 로그(`skipped:"no-quotes"` 또는 `sent` 건수)·preview에서 KIS 키가 있으면 cron 로직 단위 실행. 불가 항목이 나오면 `catalog.ts`에서 해당 행만 삭제.
- Hobby Cron 한도·시각 정밀도 공식 문서 대조는 미수행(대표 확인 항목으로 PR에 기재).

## preview에서 확인할 순서
1. (환경 변수 등록·재배포 후) 휴대폰에서 preview 주소를 홈 화면에 추가 → 앱 실행.
2. 더보기 → 설정 → 알림 → `시장 알림` 탭 → 켜기 안내 확인 → [알림 켜기] → 권한 허용 → ON·요약 `코스피, S&P 500 · 매 거래일`.
3. `알림 받을 대상·조건` → 체크·조건 → 저장 토스트. `테스트 알림 보내기` → 알림 수신 → 누름(열린 창 포커스/없으면 홈).
4. `시장 알림` 탭으로 끄기. 모든 데이터 삭제 확인 문구에 `시장 알림도 꺼집니다.`(ON일 때만) → 삭제 후 테스트 발송이 404.
5. 브라우저 탭에서는 `홈 화면에 추가한 앱에서 쓸 수 있어요`+쉐브론, 체험 모드는 섹션 없음.
현재 preview(키 미설정, 375 다크) 실확인: 알림 섹션이 보안·화면·표시 다음 데이터 앞에 있고 `시장 알림 / 준비 중이에요`로 깨짐 없이 표시(체험 모드 섹션 0건). 이 수정(준비 중이면 설치 흐름 비연결)은 두 번째 커밋 반영, 재배포 후 재확인은 하지 않음.

## 알려진 한계
- 알림을 눌러 **이미 열린 창을 focus하는 경우** `from=push`가 붙지 않아 GA `알림·누름`이 집계되지 않음(새 창으로 열릴 때만).
- OS 알림 모양·`badge`(현재 앱 아이콘 재사용, 흰색 단색 글리프 에셋 미추가)·글자수 상한 56자는 실기기 미검증.
- 일부 항목 조회 실패 시 해당 항목만 빠진 알림이 나가고, 전부 실패면 미발송·재시도 없음(중복 금지 우선).
- 환율 항목은 환율 이력이 있어야 동작. 테스트 라우트는 키가 있는 preview에서만 의미 있음.
- 푸시 서버 호출·Cron은 로컬/CI에서 실발송 검증 불가(web-push는 mock).
