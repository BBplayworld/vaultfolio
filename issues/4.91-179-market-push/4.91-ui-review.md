### 수정 요청
1. **`src/app/(main)/_components/header-menu/notify-section.tsx` — 소형 높이 규칙이 CSS로 생성되지 않음 (체크리스트 7번 FAIL)**
   - 원인: `const SHORT = "[@media(max-height:700px)]"` 를 `` `${SHORT}:max-h-none` `` 처럼 **런타임 문자열 결합**해 쓰는데 Tailwind는 완전한 리터럴만 스캔한다. 실측: 번들 CSS에 `max-height: 700px` 미디어 규칙 0건, 푸터 클래스 문자열만 존재하고 computed는 `position: static`·배경 투명.
   - 증상(320×568): 목록이 `overflow-y:auto; max-height:320px`로 남아 **중첩 스크롤**, 다이얼로그 scrollHeight 752 > 536, [저장] 위치 top 664~700 > 뷰포트 568 → **[저장]이 처음에 안 보이고 sticky 아님**(375×812·1280은 영향 없음, 저장 버튼 보임).
   - 기대값: `SHORT` 결합을 제거하고 클래스를 **리터럴로 직접 작성**(`[@media(max-height:700px)]:max-h-none [@media(max-height:700px)]:overflow-visible`, 푸터 `[@media(max-height:700px)]:sticky … :bottom-0 :-mx-6 :-mb-6 :bg-popover :px-6 :pb-6 :pt-2`; 라이트 푸터 배경은 Dialog 면과 동일해야 함 — 현재 코드의 `bg-background`는 라이트에서 Dialog(`#f0f1f4` 계열)와 달라질 수 있으니 popover 계열로 통일 확인). 수정 후 320×568에서: 목록 computed `overflow-y` visible/`max-height` none, 푸터 computed `position: sticky`, [저장] bottom ≤ 568, 중첩 스크롤 0 재측정 필요. (`dev-rules`/`design-system` 흡수 시 "Tailwind 클래스는 리터럴로" 1줄 권장 — 기존 KB의 PostCSS `@max-[Npx]` 경고와 같은 계열.)

### 수정 요청
