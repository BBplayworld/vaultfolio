## 1. #373 투자 유형 PNG (`share-card.tsx`, 신규 `use-capture-line-fit.ts`, `share-menu.tsx`)
- 35자 이하 묶음은 main 마크업 그대로다(`height:31px` div).
- 35자 초과 묶음: `useCaptureLineFit`가 `document.fonts.ready` 뒤 `useLayoutEffect`에서 잰다. 블록 폭은 설명 블록에 잠시 `width:100%`를 줘 max-w(82%) 상한으로 재고, 줄 폭은 숨김 nowrap span(강조어는 같은 strong 클래스)으로 잰다. 잰 뒤 즉시 되돌린다. `w ≤ blockW − 17px`이면 nowrap 한 줄 + 31px, 아니면 `splitLongDescriptionLine` 2줄(줄마다 31px + nowrap). 자를 자리가 없으면 기존 `minHeight`.
- 폴백: 판정 전 첫 프레임·측정 실패(0·NaN·예외)·ref 없음은 모두 2줄(넘침 0 쪽).
- 캡처 경합 방지: 설명 블록 `data-desc-fit="pending|done"`. `captureImage`(저장·사전 캡처·느린 공유 공통)가 `waitDescriptionFit`(16ms 간격, 상한 3초)로 기다린 뒤 `toPng`. 상한을 넘기면 폴백(2줄) 그대로 캡처한다. 긴 묶음이 없으면 바로 `done`.
- 판정 키 = 글자 크기(krPx)·강조어·묶음이다. 기기 자폭 보정(`useKoreanAdvanceScale`)이 바뀌면 다시 잰다.
- 변경 0: targetChars 35·`max-w-[82%]`·문구·화면 미리보기(`responsive`) 분기.
- 테스트: `capture-line-fit-5182.test.tsx`(경계 `blockW−17` 포함/0.01px 초과/511.83 넘침, 실패 폴백, 측정 뒤 width·span 복원, 강조어 굵은 폭, 렌더 분기 3종, 미리보기 불변, captureImage 대기 순서 소스 고정), `investor-type-split-5181.test.ts`(f248ee13 그대로).
