# 4.42 #70 후속 — 다크 모드 톤 정돈 UI 사양 (ui-designer)

대표 지시: "다크 모드 사용자를 위한 추가적 톤 정돈, 토스처럼 공식적인 인상". 다크 불변 약속은 이 작업 한정 해제. **유지**: 브랜드 `#5b6fbf`, 의미색(이익 빨강/손실 파랑/순자산 주황/destructive), 화면 구조·정보 배치. **금지**: 라이트 변경, 신규 라이브러리, 신규 토큰(기존 토큰 값 교체만). 기준 코드 6834394. 대비는 WCAG 상대휘도로 직접 계산(oklch -> sRGB, 알파는 하위 표면 위 합성).

## 0. 현황 진단 (현재 다크 = 순수 무채색 5단)
- bg .145 `#0A0A0A` / card .205 `#171717` / muted·secondary·accent .269 `#262626` / popover .301(+chroma 0.00003) `#2E2E2E` — 전부 C=0 중성 회색. 토스의 푸른 기운 없음, "그냥 검정".
- 대비: card/bg 1.105, muted/card 1.185, popover/card 1.318.
- **구조 문제 2개**: (a) Dialog·AlertDialog·Sheet·Drawer·FAB 시트가 `bg-background`(=캔버스와 같은 톤)라 다크에서 떠 있는 면이 아니라 구멍처럼 보여 `dark:border`로 윤곽을 억지로 만든다. (b) muted=accent가 같은 값(.269)이라 hover(accent)가 muted 위에서 안 보인다.
- 현재 다크 `--input` 흰 15%는 card 위 3.54:1, bg 위 3.82:1 로 **이미 3:1 충족**. 단 Input/Select는 `dark:border-0`이라 경계가 없고 채움(muted/30, card 위 1.056:1)만 있다(기존 갭, §2).

## 4. muted / secondary / accent 상태 일관성
- 규칙: **muted = 정지 상태 채움, accent = hover·포커스, 눌림(active) = muted 한 단계 위 = accent**. 같은 값 금지(현행 결함): muted 0.31 -> accent 0.33(1.077:1 차이는 hover 반응만 알리는 용도; 큰 면적 전환이 아니라 행 hover라 충분).
- 카드 위 행 hover: card .225 -> accent .33 = 1.40:1(전 1.19:1+). 너무 튀면 `hover:bg-accent` 대신 `dark:hover:bg-accent/60`(card 위 약 1.2) — **ROW(설정·더보기)는 후자 권장**(공식적 절제), 일반 리스트는 그대로.
- 메뉴 항목(`dropdown/context/menubar/select/command` 의 `focus:bg-accent`·`data-[selected]`): popover 위 accent 1.214:1 로 전보다 선명(전 popover .301 vs accent .269 = **역전, 오히려 어두워짐**). 코드 변경 없음, 값만으로 해소.
- `dark:hover:bg-input/30·/50`(outline 버튼), `dark:hover:bg-accent/50`(ghost): 알파 합성이라 자동 정렬, 클래스 불변.
- primary/ring: `--ring` indigo-500 불변. `--primary`(.704 0.040 256.788, 이미 푸른 회색)는 불변 — 새 팔레트와 색조가 맞는다.

`font-bold tabular-nums` 유지. foreground 17.5/15.5:1 이라 굵기 외 별도 강조 불필요. 순자산 주황(`important`)·손익 빨강/파랑은 불변이며 card 위 대비 위 §3 수치. **금액 텍스트에 `text-white` 하드코딩 금지**(순백 재도입 방지, grep `text-white` 중 다크 금액 사용처 없음 확인은 §7). 보조 수치(전일 대비 등)는 `text-muted-foreground` 7.4:1.

**영향 범위(소비처 수, grep)**: `bg-card` 48 · `bg-muted(/NN 포함)` 244 · `bg-accent` 57 · `bg-popover` 15 · `bg-background` 47 · `text-muted-foreground` 627 · `border-border` 46 + `dark:border-border/NN` 24 · `dark:*` 사용 파일 81. 토큰 교체라 소비처 코드 수정은 불필요하며, 위 목록 외 클래스 편집 없음.
**위험**:
1. 라이트 불변 — `:root` 블록·`@theme`·`--shadow-*` 미수정, 변경은 `.dark` 토큰 값과 `dark:` 접두 클래스뿐. 검증: 라이트 12화면 전/후 픽셀 diff 0(또는 computed backgroundColor 전수 일치).
2. muted 상승(.269->.31)으로 `bg-muted/10~30` 얕은 채움이 전반적으로 약간 진해짐(card 위 /30: 1.056 -> 1.09). 의도한 방향. 과하면(예: 인풋 안 박스 겹침) 해당 화면만 `/NN` 하향.
3. 입력 경계 복구(§2)는 4.42에서 승인된 "무테두리" 외관을 다크에서만 되돌린다 -> ui-review에서 대표 취향 확인 항목으로 보고, 대안(채움 상향) 병기.
4. 색조 과다 위험: C 0.010~0.016을 넘기지 말 것. 브랜드 인디고와 충돌해 보이면 hue 265 -> 250(더 청록 쪽)으로만 조정 허용.
5. PNG 인증카드·차트 팔레트는 건드리지 않음(공유 이미지 일관성).
