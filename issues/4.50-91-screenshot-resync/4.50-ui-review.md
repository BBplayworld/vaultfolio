R1. 320px 유지 묶음 제목이 `증권사·` / `미지정·비상장` 사이에서 중점 뒤 줄바꿈. 해당 제목의 `다른 {증권사|거래소}·미지정·비상장` 구간을 `whitespace-nowrap` span으로 감싸거나 `미지정·비상장`만 nowrap(holdings-resync-dialog.tsx 유지 묶음 CollapsibleTrigger).

R3. 코인 흐름에 주식 문구 잔존: 업로드 안내 `보이는 종목 화면과 똑같이… 매입 환율이…`, 썸네일 `종목 N개`. 코인은 `코인 화면`·`코인 N개`로 치환하고 `매입 환율` 문구는 코인에서 생략(T.item 활용).
R4. (선택) 후보 Select에서 줄을 고른 직후에도 `맞추기에 포함`이 해제 상태라 푸터가 `바뀌는 내용이 없어요`로 남아 반응이 없어 보임. 줄 선택 시 포함 자동 체크 또는 선택 후 힌트 권장. 또 다크 모드 헤더 hairline이 border/40(= 흰색 약 4%)라 거의 안 보임: 다크는 `dark:border-white/10` 수준으로.

### 수정 요청 (문구·줄바꿈·품질)
2. 접힌 유지 묶음 제목 문구 오류: `스크린샷에 없는 증권사·증권사 미지정 종목 N개`. ui.md 기준 `스크린샷에 없는 다른 {증권사|거래소}·미지정·비상장 N건`(예: `스크린샷에 없는 다른 증권사·미지정·비상장 종목 N개`)로 교체(코인은 거래소).
3. C25 어절 끊김:
   a. 푸터 `확인 필요 N개는 맞추지 않고 그대로 둬요` `<p>`에 `text-pretty break-keep` 없음 → 320에서 `둬 / 요`로 끊김. 같은 p(바뀌는 내용이 없어요 포함)에 추가.
   b. 고지 2줄 `매수·매도`·`손익·세금`이 `·`에서 줄바꿈(375: `주식 매수· / 매도로 잡혀요`). `주식 매수·매도로`, `매수·매도는`, `손익·세금`을 `whitespace-nowrap` span으로 감싼다(코인은 `코인 매수·매도`).
4. 업로드 썸네일 캡션 `완료 · 종목 4개`가 3열(375)에서 `종목 / 4개`로 두 줄. ui.md대로 `종목 N개`(Check 아이콘만 성공 표시)로 줄인다. `일부만 인식됐어요. 나눠서 찍어 주세요`(4줄)는 주문구와 보조 문구를 줄 분리(`일부만 인식됐어요` + muted `나눠서 찍어 주세요`).
5. 거래정지·상장폐지 삭제 후보 행에 ui.md/spec 문구 없음: 해당 행 아래 muted `거래정지·상장폐지 종목은 기본으로 그대로 둬요`(`resync-inactive-note-{id}`). 현재는 체크 해제만 되어 이유가 안 보인다.
6. 삭제 해제 이유 문구 누락: 증권사 미확정 장이 남았을 때 `증권사를 못 정한 장이 있어서 삭제는 모두 꺼 뒀어요`, 실패·한도 장이 있을 때 업로드 단계 `인식 못 한 장이 있어서 삭제는 모두 꺼 둘게요. 다시 시도가 성공하면 다시 계산해요`(ui.md [확정], 체크리스트 19·20). 현재 `화면이 다 안 담겼을 수 있어요`만 삭제 묶음 안에 표시되고 실패 장 안내는 어느 단계에도 없다.
7. 토스트 `되돌리기` 액션 버튼 높이 24px(실측 64×24). ui.md 기준 min-h-10(40px): sonner `actionButtonStyle={{minHeight:40}}` 또는 toast `classNames.actionButton`으로 40px 이상.

10. 사진 N 카드(증권사 Select)와 썸네일 연결 약함: 썸네일에 번호가 없어 `사진 5`가 어느 칸인지 모른다. 썸네일 좌상단 또는 캡션에 `1` 등 번호 배지(텍스트 text-sm, 이미지 위 bg-black/60) 추가.
