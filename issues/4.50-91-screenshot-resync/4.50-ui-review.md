## 판정: UI 수정 요청 (UI 승인 보류)

### P0 (기능 차단)
1. `holdings-resync-dialog.tsx` NeedsRow 체크박스(`맞추기에 포함`)
   `className="after:absolute after:-inset-3"`에 `relative`가 없다. ::after가 DialogContent 기준으로 367×755px로 펼쳐져 대화상자 전체를 덮는다.
   실측: 확인 필요 행이 있으면 `맞추기`(footer) 클릭이 체크박스 토글로 가버려 적용 불가(elementFromPoint = checkbox). 제목·푸터 전부 가로챔.
   기대: `className="relative after:absolute after:-inset-3"`(CheckRow와 동일).

### 수정 요청 (문구·줄바꿈·품질)
2. 접힌 유지 묶음 제목 문구 오류: `스크린샷에 없는 증권사·증권사 미지정 종목 N개`. ui.md 기준 `스크린샷에 없는 다른 {증권사|거래소}·미지정·비상장 N건`(예: `스크린샷에 없는 다른 증권사·미지정·비상장 종목 N개`)로 교체(코인은 거래소).
3. C25 어절 끊김:
   a. 푸터 `확인 필요 N개는 맞추지 않고 그대로 둬요` `<p>`에 `text-pretty break-keep` 없음 → 320에서 `둬 / 요`로 끊김. 같은 p(바뀌는 내용이 없어요 포함)에 추가.
   b. 고지 2줄 `매수·매도`·`손익·세금`이 `·`에서 줄바꿈(375: `주식 매수· / 매도로 잡혀요`). `주식 매수·매도로`, `매수·매도는`, `손익·세금`을 `whitespace-nowrap` span으로 감싼다(코인은 `코인 매수·매도`).
4. 업로드 썸네일 캡션 `완료 · 종목 4개`가 3열(375)에서 `종목 / 4개`로 두 줄. ui.md대로 `종목 N개`(Check 아이콘만 성공 표시)로 줄인다. `일부만 인식됐어요. 나눠서 찍어 주세요`(4줄)는 주문구와 보조 문구를 줄 분리(`일부만 인식됐어요` + muted `나눠서 찍어 주세요`).
5. 거래정지·상장폐지 삭제 후보 행에 ui.md/spec 문구 없음: 해당 행 아래 muted `거래정지·상장폐지 종목은 기본으로 그대로 둬요`(`resync-inactive-note-{id}`). 현재는 체크 해제만 되어 이유가 안 보인다.
6. 삭제 해제 이유 문구 누락: 증권사 미확정 장이 남았을 때 `증권사를 못 정한 장이 있어서 삭제는 모두 꺼 뒀어요`, 실패·한도 장이 있을 때 업로드 단계 `인식 못 한 장이 있어서 삭제는 모두 꺼 둘게요. 다시 시도가 성공하면 다시 계산해요`(ui.md [확정], 체크리스트 19·20). 현재 `화면이 다 안 담겼을 수 있어요`만 삭제 묶음 안에 표시되고 실패 장 안내는 어느 단계에도 없다.
7. 토스트 `되돌리기` 액션 버튼 높이 24px(실측 64×24). ui.md 기준 min-h-10(40px): sonner `actionButtonStyle={{minHeight:40}}` 또는 toast `classNames.actionButton`으로 40px 이상.
8. 카카오(증권사 미지정 연결) 행에 같은 뜻이 두 번 표시: `증권사 미지정 → 삼성증권` + `증권사 미지정 줄과 연결`. 연결 줄은 `brokerFill`이 있으면 생략.
9. 본문 스크롤 시 헤더 구분 없음: 푸터엔 hairline이 있고 헤더 아래는 콘텐츠가 제목 바로 밑에서 잘려 거칠다. 스크롤 상태일 때만 `border-b border-border/40`(또는 본문 상단 `mask-image` 12px 그라디언트) 적용.
10. 사진 N 카드(증권사 Select)와 썸네일 연결 약함: 썸네일에 번호가 없어 `사진 5`가 어느 칸인지 모른다. 썸네일 좌상단 또는 캡션에 `1` 등 번호 배지(텍스트 text-sm, 이미지 위 bg-black/60) 추가.
11. 묶음 카드 하단 여백 과다(p-4 + li py-2.5 = 26px, 위는 헤더 기준 16px): 마지막 li에 `last:pb-0` 또는 ul `-mb-2.5`.
12. 결과 요약(`추가 2 · 변경 1`)의 숫자가 미리보기와 달리 semibold가 아님: `summaryParts` 재사용으로 통일.

### 확정 판단
- 수량 미인식 사유 `수량을 읽지 못했어요`: 승인(존댓말·사실 서술·투자 조언 아님). 단 이 문구는 사유 줄이므로 수량 입력 placeholder `수량 입력`과 함께 한 행에서 어색하지 않음. 확정.
- 남은 횟수 `1장에 인식 1회 · 오늘 N회 남음`(spec 채택), 결산 고지 마침표 없음(spec): 승인.
- sticky 묶음 헤더 생략(v1): 승인. 푸터 버튼 h-9(36px)는 앱 기본 Button 규격과 같아 이번 범위에서는 허용(대표 눈높이 상 40px 권장, 후속 후보).

### 통과 확인
- 375/320/1280 가로 스크롤 없음(대화상자 scrollWidth=clientWidth, P0 오버레이 제외). 헤더·푸터 고정, 본문만 스크롤. `border-dashed`·amber 없음. 6장 선택 시 5장+토스트, 상태 5종 텍스트+아이콘, 재시도는 실패 1장만 호출(calls: a3 재호출 1회), 성공 장 재호출 0.
- 증권사 Select는 장당 1개, 종목 행에는 없음. 요약 단색 텍스트·0건 생략, 삭제 체크 brand, 유지 묶음 접힘, 고지 2줄, 환율 일괄 입력, 평단 실값 `90.5 → 95.2`.
- 단계 전환 시 제목 포커스(H2) 확인, 결과 화면 `되돌리기`·`닫기`·`이 창을 닫기 전에는` 문구, 닫은 직후 토스트 `되돌리기`.
- 다크 대비는 육안 양호(brand 체크 아이콘 대비는 약하나 AA 아이콘 기준 허용).
