## 0. 현재 화면 문제 (design-system 위반 조항)
- 업로드: `border-2 border-dashed border-primary/30`, `bg-primary/5` 드롭존, amber 경고 목록 5줄. §0-3 보더리스·§1.2 색 절제 위반, 안내가 길어 시선 1순위(올리기)가 묻힘.
- 중복 처리: 라디오형 카드 2개(`border border-primary`)로 모드 선택. 이번에 통째로 제거.
- 미리보기: 종목 카드마다 `border`+체크박스+티커 Input+4칸 그리드+Select 2개. 행 하나가 3~4줄이라 20종목이면 스크롤이 길고 "무엇이 바뀌나"가 안 보임. `text-[10px]` 배지(§2 text-xs 이하 지양) 위반.
- `DialogContent`에 `border-primary/40`·`ring-0` 덮어쓰기. 푸터가 스크롤 안에 들어 있어 긴 목록에서 적용 버튼이 밀려남.

  - 헤더 `px-5 pt-5 pb-3 text-left`(§5 설명형) · 제목 `스크린샷으로 보유 현황 맞추기` (`text-base font-bold text-balance break-keep`)
  - **본문만 스크롤** `min-h-0 flex-1 overflow-y-auto scrollbar-themed px-5 pb-4 touch-pan-y`
  - **푸터 고정** `px-5 pb-5 pt-3 border-t border-border/40`(헤어라인 허용 §3.3) · `DialogFooter` 기본(모바일 세로 `[brand, secondary]`, sm 우측 가로)
- 닫기 X는 `showCloseButton` 유지(히트영역 after:-inset-2.5 내장 → 40px). 인식 중 닫기·ESC 차단은 현행 유지.

- 단계 표시는 점 대신 헤더 우측 **텍스트 `1/3 올리기`**가 아니라 제목 아래 한 줄 `text-sm text-muted-foreground`(`올리기`→`확인`→`완료`) 생략 가능, v1은 **생략**(단계가 3개뿐, 제목이 단계마다 바뀜: 4절 문구).

## 2. 화면 (1) 업로드
트리(위→아래): 보안 고지 → 업로드 영역 → 썸네일 그리드(선택 후) → 남은 횟수 한 줄 → (한도 소진 시 안내) → 푸터.
- 보안 고지: `SCREENSHOT_UPLOAD_NOTICE` 원문만. `rounded-lg bg-muted/40 px-3 py-2.5 text-sm text-muted-foreground text-pretty break-keep`, 앞 `ShieldCheck size-4` 단색(muted). 신규 문구 0(C26).
- 업로드 영역: **점선·primary 테두리 제거.** `rounded-xl bg-muted/40 min-h-28 flex flex-col items-center justify-center gap-2 p-6`, 아이콘 `ImagePlus size-6 text-muted-foreground`, 주 문구 `text-sm font-medium` `증권사 보유 종목 화면을 골라 주세요`, 보조 `text-sm text-muted-foreground` `최대 5장 · JPG, PNG, WEBP, HEIC · 장당 10MB`. 요소는 `<button>`(전체 클릭, `min-h-28`), hover `hover:bg-muted/60`(transition-[background-color]), `active:scale-[0.98]`, 드래그 오버 `bg-muted/70`. 파일 입력 `multiple accept="image/*"`, 6장 이상 고르면 앞 5장만 쓰고 토스트 `5장까지 올릴 수 있어요`.
- 안내 보조 1줄만(기존 amber 5줄 삭제): `보이는 종목 화면과 똑같이 맞춰요. 평단가와 매입 환율이 화면에 없으면 기존 값을 그대로 둬요.`
- **썸네일 그리드**: `grid grid-cols-3 gap-2 sm:grid-cols-5`(320에서도 3열 약 92px). 칸 = `relative aspect-[3/4] overflow-hidden rounded-lg bg-muted` + 이미지 `object-cover outline outline-1 -outline-offset-1 outline-black/10 dark:outline-white/10`(§6) + 하단 상태 띠. 칸 위 우상단 `빼기` 아이콘 버튼(`size-6` 보이는 크기 + `after:-inset-2` → 히트 40px, aria-label `사진 1 빼기`). 추가 칸(5장 미만) = 점선 없는 `bg-muted/40` `+` 칸.
- **장별 상태**(하단 띠 `text-xs`는 쓰지 않고 썸네일 아래 캡션 `text-sm` 한 줄, 아이콘+텍스트 모두 사용해 색에만 의존 금지):
  | 상태 | 표시 | 색 |
  |---|---|---|
  | 대기 | `대기 중` | muted |
  | 인식 중 | `Loader2 animate-spin motion-safe` + `인식 중` | muted |
  | 성공 | `Check` + `종목 N개` | foreground, 아이콘만 `text-brand` |
  | 일부만 인식됨 | `AlertCircle`(importantHex 주황 아이콘) + `일부만 인식됐어요` + 보조 `나눠서 찍어 주세요` | 주황(§1.2 범용 강조) |
  | 실패 | `AlertCircle` 주황 + `인식하지 못했어요` + `다시 시도` secondary sm 버튼(`min-h-10`) | 주황 |
  `일부만 인식됨`은 실패와 같은 취급(challenge ③): 재시도 대신 `빼기`만 안내. **재시도는 실패한 그 한 장만** 호출, 성공 장 재호출 없음. 재시도 버튼은 남은 횟수 0이면 disabled. [확정] 실패·일부만 인식·한도 미인식 장이 1장이라도 있으면 장 목록 아래 muted 1줄 `인식 못 한 장이 있어서 삭제는 모두 꺼 둘게요. 다시 시도가 성공하면 다시 계산해요`(`빼기`를 눌러도 이 줄과 해제 상태는 그대로, 재시도 성공 시에만 줄이 사라지고 삭제 기본값 재계산).
- **증권사 미확정 장**: 성공 장 캡션 아래 `Select`(h-10, 기본 `증권사 선택`)를 그 장 카드에서 1회. 자동 추정되면 `증권사: ○○증권`을 muted로 보이고 변경 가능(트리거 `text-sm`). 선택 전에도 진행은 허용한다. [확정] 증권사를 못 정한 장의 종목은 미리보기에서 **전부 `확인 필요`**이고, 그런 장이 하나라도 남아 있으면 **모든 삭제 후보의 기본 체크가 해제**된다. 장 카드 아래 안내 1줄 `증권사를 고르지 않으면 이 장의 종목은 맞추지 않고, 지우는 항목도 모두 그대로 둬요`. 목록 = 기존 `securitiesFirms` 그룹 Select 재사용(코인은 거래소 목록).
- **남은 횟수**: 업로드 영역 아래 우측 한 줄 `text-sm tabular-nums text-muted-foreground`: `오늘 AI 인식 N회 남음`. 장 선택 후 `N장 인식에 N회 써요`(실패해도 차감 반영: `실패해도 횟수는 줄어요`는 재시도 버튼 근처 muted 1줄). 남은 횟수가 선택 장수보다 적으면 그 수까지만 인식하고 `남은 횟수가 부족해서 앞 N장만 인식해요`(주황 아이콘). 0회면 `bg-muted/40` 박스 `오늘 인식 한도를 다 썼어요. 내일 다시 시도해 주세요.`(destructive 박스 폐기).
- 푸터: brand `인식하기`(장 ≥1, 대기 장 있을 때) → 전부 성공이면 자동 이동 대신 brand `변경 내용 보기`. 인식 중에는 brand 비활성+스피너. secondary `취소`.
- 상태 안내 영역 `aria-live="polite"`: `3장 중 2장 인식했어요` 갱신. 실패 발생 시 `role="alert"` 하지 않고 polite 동일 영역에 문구.

## 3. 화면 (2) 변경 미리보기 (핵심)
제목 `바뀌는 내용을 확인해 주세요`(포커스 이동, `tabIndex=-1`).
트리: 요약 → [확인 필요 안내] → 묶음 N개 → 접힌 `스크린샷에 없는 …` → 해외 환율 1줄 → 고지 2줄 → 푸터.
- **요약 한 줄(칩 없음)**: `text-sm text-foreground tabular-nums`, `추가 2 · 변경 6 · 삭제 1 · 그대로 9 · 확인 필요 1`. 0건 항목은 생략. 색 없음(숫자만 `font-semibold`). 320에서 줄바꿈 허용 `text-pretty break-keep`, 항목 사이 `·`는 `⁠` 묶음 없이 항목별 `whitespace-nowrap` span(C25). 변경 0이면 `바뀌는 내용이 없어요`.
- **묶음 헤더**(증권사×계좌유형×시장): `○○증권 · 일반 · 해외` `text-sm font-bold`, 우측 `N건` muted tabular. 헤더는 `sticky top-0 bg-popover`(다크)/`bg-background` + 본문 스크롤 안 stickiness. 묶음 바깥 `rounded-xl bg-card p-4 space-y-1 dark:shadow-sm`(§5.1 외피 레시피, 면 구분은 톤차; 다크 dialog popover 위 card보다 `bg-muted/40`로 한 단계 아래). 증권사 미확정 장 묶음은 `증권사 미정`.
- **항목 행**(SpecRow 변형, `min-h-10 py-2.5`, 행 사이 `divide-y divide-border/40`): 좌 = 종목명 `text-sm font-medium truncate` + 상태 라벨 `shrink-0`(`추가`=brand 텍스트, `변경`=foreground, `삭제`=destructive 텍스트, `확인 필요`=importantHex 텍스트; 라벨은 텍스트+의미 모두, 칩 배경 없음). 아래 줄 `text-sm text-muted-foreground tabular-nums`:
  - 수량 변경 `수량 10 → 12`, 평단은 화면 실값일 때만 `평단 a → b`로 표시, 역산값은 덮지 않음(S4). [확정] 신규는 `12주`, 삭제는 `10주`(취소선 없음). **평가금액·손익·비중·총액은 어떤 행·요약에도 쓰지 않는다**(수량 전후만, 금액 숫자 0). 전후 화살표 `→`는 `⁠` 묶음 + `whitespace-nowrap`.
  - 수량 증가는 손익색 쓰지 않음(손익 아님). 전후 숫자만, 색은 muted→foreground(후 값 `text-foreground font-semibold`).
  - [확정] **역산 평단 안내**: 화면에 평단이 없어 역산된 값이 기존 값과 **1% 넘게** 다를 때만 해당 행 아래에 muted `평단은 화면에 없어 기존 값 유지`. 1% 이내면 문구 없음(`그대로` 항목은 접힌 안 행에만 표시).
  - 연결 사실(S3): 같은 줄 muted `증권사 미지정 줄과 연결`, `종목명으로 연결`. 수량이 줄어 `확인 필요`로 둔 건 사유 `수량이 줄었어요`.
  - **삭제 체크박스**: 삭제 후보 행 좌측 기본 `Checkbox`(brand 자동) `checked=삭제`, 히트 `after:-inset-3`(행 전체 `<label>`로 감싸 40px+). 체크 해제=유지, 행 라벨이 `삭제`→`유지`로 바뀜. S2 해제 상태 묶음은 체크 off + 묶음 상단 muted 1줄 `화면이 다 안 담겼을 수 있어요`. [확정] 이유 1줄 문구는 원인별로 구분: 실패·한도 장 있음 → 위 문구, 증권사 미확정 장 남음 → `증권사를 못 정한 장이 있어서 삭제는 모두 꺼 뒀어요`(둘 다면 위 문구 1줄만), 절반 이상 → 그 조합 묶음만 같은 1줄. **거래정지·상장폐지 항목은 그 행만** 체크 off + 행 아래 muted `거래정지·상장폐지 종목은 기본으로 그대로 둬요`(같은 묶음의 다른 행은 영향 없음). 사용자가 직접 체크하면 삭제 가능.
  - **확인 필요 칸 최소화**: 티커 없음(비상장 등)·티커 미인식만 입력. 행 아래 `Input h-10`(기존 `티커 입력` 유지)과 사유 1줄. 증권사·계좌유형·평단·환율 입력은 이 행에 두지 않음(장 단위 Select가 대신). 수량 충돌(K1)은 `확인 필요` 한 칸: 큰 값 선택된 상태 + muted `화면마다 달라요: 12 / 10`, 탭하면 입력으로 바뀌어 수정 가능(선택 UI 없음). [확정] **확인 필요 행은 기본으로 적용에서 빠진다.** 모든 확인 필요 행 오른쪽 아래(또는 입력 아래)에 `Checkbox`+라벨 `맞추기에 포함`(기본 해제, 행 전체 `<label>` 40px). 해제 상태 행 라벨은 `확인 필요`+muted `맞추지 않고 그대로 둬요`, 체크하면 `확인 필요`→`포함`(추가·변경 라벨처럼 foreground)으로 바뀌고 요약의 확인 필요 수와 N이 즉시 갱신된다. 입력이 필요한 행(티커 등)은 값을 입력하기 전엔 체크 disabled가 아니라 허용하되 빈 입력이면 체크 시 입력창에 포커스 이동+`티커를 입력해 주세요`. 증권사 미정 장의 종목 행도 같은 규칙.
  - 푸터 바로 위(적용 버튼 위) muted 1줄: 포함 안 된 확인 필요가 N≥1개일 때 `확인 필요 N개는 맞추지 않고 그대로 둬요`(`aria-live=polite`, N=0이면 줄 없음). **적용 버튼은 이 때문에 막지 않는다.**
  - `그대로` 항목은 `Collapsible` 접힘 `그대로 9건`(§6 grid-rows 방식, 재마운트 없음), 기본 닫힘.
- **접힌 유지 묶음**: 버튼행 `min-h-10` `스크린샷에 없는 증권사·미지정·비상장 N건` + chevron(`aria-expanded`, 회전 `motion-safe:transition-[rotate]`), 부제 muted `기본으로 그대로 둬요`. 펼치면 행마다 `Checkbox`(기본 off=유지, 체크=삭제). 비상장은 체크 가능하되 라벨 `비상장은 직접 입력한 값이라 기본으로 둬요`. 펼침 시 포커스는 헤더 유지.
- **해외 매입 환율 일괄 1줄**(신규 해외 종목 있을 때만): `bg-muted/40 rounded-lg px-3 py-2.5` 좌 `신규 해외 종목 매입 환율` 우 `Input h-10 w-24 text-right tabular-nums` 기본 오늘 환율, 보조 muted `기본값은 오늘 환율이에요. 기존 종목은 그대로예요.`
- **고지(K4) 2줄**: `text-sm text-muted-foreground text-pretty break-keep`, 앞 `Info size-4 text-sky-600/70 dark:text-sky-400/70`(§1.2 정보 아이콘) 1개씩.

## 4. 화면 (3) 결과 + 되돌리기, 토스트
- 제목 `보유 현황을 맞췄어요`. 본문 `rounded-xl bg-muted/40 p-4`: 큰 숫자 없이 요약 한 줄 재사용(`추가 2 · 변경 6 · 삭제 1`) + muted `이 창을 닫기 전에는 되돌릴 수 있어요`(**`앱 닫기 전까지` 금지, S7**).

[확정] 삭제 항목을 복원한 경우(1건 이상) 같은 영역에 muted 한 줄 추가 `삭제했던 종목 N개는 목록 맨 끝에 다시 넣었어요`(원래 순서는 복원하지 않음). 삭제가 없었으면 줄 없음. 문구는 `aria-live` 결과 영역에 함께 갱신.
- 닫으면 토스트(sonner, `duration 8000`, 동일 id): `보유 현황을 맞췄어요` + action `되돌리기`(`min-h-10`). 닫은 직후 한정이라 토스트 소멸 후 노출 입구 없음 → 문구에 기간 명시 안 함, 소멸 후 복구는 백업뿐(브리프 위험 절).

## 9. 품질 체크리스트 (qa 판정용)
1. 대화상자에 `덮어쓰기`·`초기화 후 등록`·`공통 적용`·`개별 선택` 텍스트가 없다(DOM 검색 0).
2. 375·320·1280 × 라이트·다크 12장에서 가로 스크롤 없음, 본문만 스크롤되고 헤더·푸터는 항상 보인다(푸터 버튼 viewport 내 bounding box).
3. 업로드 영역·썸네일·묶음에 `border-dashed`·`border-primary`·amber 색이 없다(computed style).
4. 6장 선택 시 5장만 채워지고 토스트가 나온다. 장별 상태 5종이 텍스트로 구분된다(색 제거 스크린샷에서도 구분 가능).
5. 실패 장의 `다시 시도`는 그 장 1건만 호출한다(네트워크 로그), 성공 장 재호출 0.
6. 증권사 미확정 장에 증권사 Select가 장당 1개, 종목 행에는 증권사 Select가 없다.
7. 미리보기 요약은 칩/배경 없는 단색 텍스트이며 0건 항목은 생략된다. 변경 0이면 `맞추기` disabled이고 클릭해도 저장·GA 없음.
8. 변경 행은 바뀌는 칸만 `전 → 후`로 표시하고, 삭제 후보 체크박스는 brand 색이다. 유지 묶음은 기본 접힘+기본 비체크.
9. 고지는 정확히 2줄(해외주식 삭제 후보가 있을 때만 양도세 1줄 추가). 보안 문구는 `SCREENSHOT_UPLOAD_NOTICE` 원문과 일치, `앱 닫기 전까지`·`덮어쓰기` 문구 grep 0(C26).
10. 한글 문구 전수가 320·375에서 어절 중간 줄바꿈 없음(`word-break: keep-all` computed, C25).
11. 모든 인터랙티브(빼기·체크 행·펼침·재시도·토스트 action) 히트영역 ≥ 40×40px(boundingBox).
12. 키보드만으로 업로드→인식→미리보기 체크→적용→되돌리기→닫기까지 완료 가능, 단계 전환 시 제목에 포커스.
13. 인식 진행·건수·되돌림 결과가 `aria-live=polite` 영역에 갱신된다.
14. `prefers-reduced-motion: reduce`에서 fade·spin·펼침 전환이 꺼진다. 펼침 연타 시 끊김 없이 역전.
15. 맞추기·되돌리기 버튼은 클릭 직후 disabled(더블클릭해도 저장 1회).
16. 숫자는 `tabular-nums`, 미리보기 건수·수량이 상세·홈 값과 일치(C1).
17. 되돌리기 후 토스트 `되돌렸어요`, 결과 화면에서 `이 창을 닫기 전에는` 문구, 토스트 소멸 후 되돌리기 입구 없음(문구와 일치).
18. [확정] 확인 필요 행마다 `맞추기에 포함` 체크가 있고 기본 해제다. 체크 안 한 채 `맞추기`를 눌러도 그 행 값은 저장 전과 같다. 버튼 위에 `확인 필요 N개는 맞추지 않고 그대로 둬요`가 보이고, 그 때문에 버튼이 disabled가 되지 않는다(체크 시 N 감소).
19. [확정] 증권사 미확정 장이 남아 있으면 그 장 종목이 모두 `확인 필요`이고 모든 삭제 체크박스가 해제 상태이며 이유 1줄이 보인다. 증권사를 고르면 재계산된다.
20. [확정] 실패·일부만 인식·한도 미인식 장이 있으면 모든 삭제 체크가 해제이고 장 목록 아래 안내가 보인다. `빼기` 후에도 해제·안내 유지, `다시 시도` 성공 시에만 안내가 사라지고 삭제 기본값이 재계산된다.
21. [확정] 거래정지·상장폐지 삭제 후보는 그 행만 해제되고 같은 묶음의 다른 후보는 영향 없다. `평단은 화면에 없어 기존 값 유지`는 역산 평단이 기존과 1% 넘게 다른 행에만 있고(1% 이내 0건) 평단 저장값은 불변이다.
22. [확정] 미리보기·결과 DOM에 평가금액·손익·비중·총액 숫자(원·% 단위 금액)가 0건이고 수량 전후만 있다. `삭제 종목의 거래는 … 거래 화면에는 보이지 않는다` 취지의 문구도 화면에 0건이다.
23. [확정] 고지 2번의 `주식 매수·매도`/`코인 매수·매도`가 `asset-report.ts` 라벨과 글자 일치한다. 삭제 항목을 되돌린 결과 화면에 `목록 맨 끝에 다시 넣었어요` 한 줄이 있고 실제로 stocks 배열 끝에 위치한다.
