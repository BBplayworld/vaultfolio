### 2. '내 선택의 승률' — 정의와 경계
**화면에는 '승률'이라는 말을 쓰지 않는다.** 내기·우열로 읽힌다. 내부 이름은 '내 선택 돌아보기', 화면 용어는 6차 용어표(`평단 대비`·`정한 날 대비`·`점검일 대비`·`그대로 두기`)를 그대로 쓴다(C133).

**재료(지금 있는 것)**
- 결정 기록 `reviews`: 종목·시각·그때 묶음·선택·그때 가격·그때 수익률(`stock-labels.ts:53-66`), 티커당 12건(`:114`). 정한 날 가격 `base.price`(`:27`).
- 매매 기록: 종류·수량·단가·날짜(`transaction.ts:4-21`). 최근 3개월 건수 집계는 이미 있다(`grow-rows.ts:185-197`).
- **없는 것 2가지**: ① 조건에 닿아서 한 점검인지 표시가 없다(5차 설계의 `hit`은 구현에 없음, `stock-labels.ts:134`) → 선택 필드 1개 추가가 필요하다. ② 결정 뒤 특정 시점(예: 3개월 뒤)의 과거 가격은 저장하지 않는다 → 결과는 **'다음 결정 때 가격'**(연속 기록 2건)과 **'지금 가격'** 두 기준만 쓴다. 새 서버 요청 0.

**보여 줄 것(결론 1문장 + 정렬된 목록. LEARNINGS 11/18: 사실 조각 나열 금지)**
| 층 | 내용 | 예시(사실형) |
|---|---|---|
| ① 결정별 결과 | 정함·그대로 두기·옮기기마다 그때 가격 → 다음 결정(없으면 지금) 가격 | `7월 16일 그대로 두기 · 그 뒤 +9.8%` |
| ② 분포(건수) | 같은 종류 결정 N번 중 그 뒤 오른 것 M번. 평균 %가 아니라 건수 막대 | `그대로 둔 8번 중 6번은 그 뒤 올랐어요` |
| ③ 조건 | 내가 정한 조건에 닿은 N번을 `그대로 둠`/`옮김`으로 나눈 건수와 각각의 그 뒤 변화 | `조건에 닿은 5번 중 3번 그대로 뒀어요` |
| ④ 매매 기록 | 이 앱에 기록한 매수 N건 중 지금 매수가보다 높은 건수. 장기 보유로 정한 종목의 매매 건수 | `기록한 매수 12건 중 9건이 지금 매수가보다 높아요` |
| ⑤ 내 패턴 1문장 | 값과 무관하게 늘 같은 축(앱이 유리한 축을 고르지 않음) | `점검 차례가 오면 대부분 그대로 뒀어요(10번 중 8번)` |
- 출시 직후 모든 사용자는 결정 기록이 0건이다(오늘 머지). 그래서 **④ 매매 기록이 첫날부터 값이 나오는 유일한 층**이고, 첫 사용자 상태의 중심이다. ①~③은 기록이 쌓이며 채워진다.
- 표본 규칙: 결정 3건 미만이거나 결정 뒤 30일 미만이면 `측정 중`(5.125 점수와 같은 낱말).

- **묶음(장기 보유/점검 대상/정하지 않음)은 그대로, 보기를 자산 종류로 나눈다.** 카드 위에 종류 줄 `주식 6 | 코인 2 | 부동산·실물 2`를 둔다. **가진 종류가 2개 이상일 때만 보인다** → 주식만 가진 사람의 화면은 `내 선택` 1행 말고 5.125와 같다.
- 한 목록에 섞지 않는 이유 3가지: ① 큰 숫자 정본이 상세 › 주식 '전체' 헤더와 원 단위로 같아야 한다(`grow-board.ts:296-300`). ② 기준 4칸은 X-Ray 분류라 주식 전용이고 '묶음 합 = 카드 합계'가 깨진다. ③ 부동산 %는 시세가 아니라 내가 넣은 값이라 같은 눈금 막대에 놓으면 기준이 섞인다.
- **기준 칸 막대에는 주식만 넣는다.** 코인·부동산·실물 보기에는 기준 칸이 없다. 코인 `보유 기간` 1축은 행 2줄의 `N개월`과 오래 가진 순 정렬이 이미 말한다(묶음 1개 축 숨김 규칙과 같은 결).
- 보기별 구성
  | 보기 | 종합 카드 | 행 1줄 / 2줄 |
  |---|---|---|
  | 주식 | 5.125 그대로 + `내 선택` | 그대로 |
  | 코인 | 큰 숫자(정본 = 상세 › 코인 헤더) + 장기 보유·점검 대상·`내 선택`. 배당 행 없음 | 이름·막대·`평단 대비 %` / `8개월 · 4점 · 정한 날 대비 +6.2%` |
  | 부동산·실물 | **없음.** 보통 1~3건이라 합계가 행과 같은 값이고, 대출·보증금을 빼지 않은 합계는 오독된다 | 이름·`매입가 대비 %`(막대·점수 없음) / `7년 2개월 · 내가 넣은 현재가 기준` |
- 첫 화면 피로: 종류 줄 1줄(숫자 문장 아님)과 카드 1행이 늘어 목록이 약 76px 내려간다. '장기 보유 2행 + 점검 대상 1행이 스크롤 없이 보인다'(5.125 완료 기준)는 ui-designer가 실측으로 확인한다. 넘치면 종류 줄을 카드 라벨 줄에 합친다.
- **세그먼트**: 지금은 주식 행이 없으면 칸 자체가 없고 성적표만 나온다(`asset-report-view.tsx:329-332`). 코인·부동산·실물 중 하나라도 있으면 열리게 바꾼다. 칸 이름 `종목 점검`은 부동산을 담지 못해 **`보유 자산 점검`으로 바꾸는 안**을 낸다(둘째 줄은 종류가 섞이면 `점검 차례 3개`, 주식·코인만이면 `3종목`). 6차 확정어와 PRINCIPLES 5장 문구가 바뀌므로 대리 검토에서 판정하고 승인 요청에 먼저 밝힌다.
- 다른 종류에 점검 차례가 있을 때: 화면에 들어오면 차례가 있는 종류 중 고정 순서(주식 → 코인 → 부동산·실물) 첫째를 연다. 종류 줄에는 `코인 2 · 차례 1`처럼 낱말로 적는다(점·색만 쓰지 않는다, C139). 320 폭은 ui-designer가 잰다(C130).

### 4. 결론 문장 — 판단은 건수로, 권유 없음
- 형식(늘 같은 축, 몫 %·평균 % 쓰지 않음): **`내 선택  {N}번 중 {M}번은 그때보다 오름`**. N = 정함·그대로 두기·옮기기 중 30일이 지난 기록 수, '그때보다' = 그때 가격 대비 다음 점검 때(없으면 지금) 가격. 건수는 본문색 굵게, 손익색·큰 쪽 강조 없음.
- 축을 고르는 규칙은 값의 좋고 나쁨이 아니라 **기록 수**뿐이다: 기록 3번 이상 → 위 문장 / 미만이고 매수 기록 3건 이상 → `매수 12건 중 9건은 지금이 매수가보다 높음` / 둘 다 미만 → 아래 표.
| 대입(C138) | 표시 |
|---|---|
| 정상 11번 중 8번 | `11번 중 8번은 그때보다 오름` |
| 손실 11번 중 2번 | `11번 중 2번은 그때보다 오름`(문장을 뒤집지 않는다. 파랑·경고 없음) |
| 전부 / 0번 | `11번 모두 그때보다 오름` / `11번 중 그때보다 오른 것 없음`(5.125 `평단보다 낮은 종목 없음`과 같은 꼴) |
| 종목 부호 혼합 | 같은 문장. 건수 꼴이라 손익 부호가 섞여도 뜻이 뒤집히지 않는다 |
| 표본 부족(1~2번 또는 모두 30일 미만) | `측정 중 · 기록 2번`(5.125 낱말, ⓘ에 `30일이 지난 기록 3번부터 보여요`) |
| 0건(정한 것은 있음) | `아직 기록 없음`(muted) |
| 처음(정한 것 0 · 매매 0) | 행을 그리지 않는다. 기존 안내 1줄만 둔다(안내 2줄 금지) |
- 패널: 고정 순서 5행, 모두 같은 형식(선택 종류 · N번 · 오름/내림 2분할 막대 · 건수). `정함` → `그대로 두기` → `옮기기` → `조건에 닿아 점검` → `매수 기록`. 대표 약속 5종(C131)과 1:1이다. 0건 행은 숨기고 맨 아래 1줄 `기록이 쌓이면 여기에 보여요`. 1~2건 행은 막대 대신 `측정 중`.
- 사업 절 금지어를 그대로 따른다. 부동산·실물 기록은 가격이 시세가 아니라서 이 건수에 넣지 않는다(점검 한 장에 날짜·선택만).

### 6. 사업 절 쟁점 4건 · 이견
1. 위치: 2절. **동의**(별도 영역 없음).
2. 부동산·실물에 점수·±% 조건 없음: **동의.** 축소로 읽히지 않게 행을 주식과 같은 2줄로 채우고, 대조표에 '시세가 아니라서 표현으로 대신함'을 적어 승인 요청 본문에 먼저 밝힌다.
3. 매도 뒤 가격 미표시: **동의**(유지).
4. 키·`조건에 닿음`: 방식은 tech-review. 기획 요건 2개: 5.125 기기에서 주식 외 항목이 안 보일 뿐 지워지지 않는다 / `조건에 닿음`은 차례 이유가 보이는 상태에서 선택하면 자동으로 남는다(입력 추가 0).
- `이견 1`: 코인 기준 칸 `보유 기간` → 두지 않는다(3절).
- `이견 2`: 사업 ①~⑤ 5층을 다 그리면 4차 돌아보기가 되살아난다. ⑤ '내 패턴 1문장'은 `그대로 두기 N번` 행과 같은 사실이라 빼고, ③은 그대로/옮김 2×2 대신 패널 1행으로 줄인다.
- `이견 3`: 주 지표 `·돌아봄`을 '값과 함께 그려질 때'로 재면 화면 진입과 같은 수가 된다. **패널을 열 때 로드당 1회**로 바꾼다.
- `정정`: 부동산 `매입가 대비 %`는 내가 넣은 현재가 기준이고 실거래 추정가는 옆에 따로 적는 참고값이다(`real-estate-tab.tsx:103-110,288-289`). 행 표기는 `내가 넣은 현재가 기준` 하나로 하고, 추정가를 %의 기준처럼 적지 않는다.

### 7. 범위
