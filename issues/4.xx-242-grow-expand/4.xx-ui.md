## 0. 결론 5줄
1. 칸 이름은 **B `내 자산 점검` 확정**(대리 검토). 3안 모두 320에서 1줄이다(글자 영역 126px에 A 90.6 · B 76.6 · C 59.3). 허브 설명은 `성적표와 내 자산 점검을 한곳에서`(320 1줄, 3절).
2. 종류 줄은 **1줄 알약 3칸 + 낱말 꼬리 `점검 차례`(수 없음, 선택하지 않은 칸만)**. 2줄 칸은 390 첫 화면에서 SK하이닉스 행이 849px로 5px 넘친다(`g7-kind-alt-2line-390`). 1줄안은 841px로 들어가고 320까지 1줄이다.
3. `내 선택` 패널은 **칸 막대**(칸 1개 = 기록 1번, 채운 칸 = 오름)로 그린다. 비율 막대는 1번짜리 행이 꽉 찬 막대로 보여 '뜻 모를 막대'가 된다.
4. 매수 문장 `…지금이 매수가보다 높음`은 390에서 2줄이라 출시 첫날 상태에서 AC-21을 깬다 → **`매수 12건 중 9건은 매수가보다 오름`**(1줄, 주 문장과 같은 꼴)으로 줄였다.
5. 부동산 한 장은 **값 구획을 선택 버튼 위로** 올렸다(값을 보고·고치고 → 선택). 새 데모 시드안(12절)으로 무조작 데모가 기본 문장 `6번 중 5번은…`·주석 줄·안내 줄을 보여 준다. 데모로 볼 수 없는 것은 `실거래 추정` 줄과 실물 행 2가지다.

### 2-4. `내 선택` 패널
- 자리: `grow-summary` 바로 아래, 기준 4칸 위. 면 `rounded-lg bg-foreground/6 px-3 pt-1 pb-1.5`.
- 머리 `선택한 날 가격보다 오른 횟수`: `text-xs font-semibold text-muted-foreground` + InfoHint, `min-h-8`. 글자 156.1px — 390(영역 310)·320(영역 240) 모두 1줄.
- **패널은 값이 있을 때만 있다**(`count`·`buy`). `wait`에서는 결론 줄에 화살표·버튼이 없고 패널 DOM도 그리지 않는다.
- 행(버튼): `grid grid-cols-[7rem_minmax(0,1fr)_4.5rem] gap-x-2 min-h-10 -mx-2 px-2 rounded-md`, 320은 `[7rem_minmax(0,1fr)_4rem] gap-x-1.5`. 눌린 행 `bg-foreground/9`(`aria-pressed`).
  - 왼쪽: 이름 `text-sm font-semibold` + 횟수 `text-xs text-muted-foreground`. 가장 긴 `그대로 두기 12번`이 112px 열 안에 들어간다(`g7-06b-panel-320` — 열을 100px로 두면 막대에 닿는다). 세 자리 횟수는 development에서 재서 넘치면 횟수를 이름 아래로 내린다.
  - 가운데 **칸 막대**: 높이 8, 칸 radius 2, 간격 2. 빈 칸 `bg-foreground/14`, 채운 칸 `bg-foreground/60`. 한 줄에 들어가는 칸 수 = max(8, 패널 위 묶음의 최대 번 수) → 번 수가 적은 행은 막대가 짧다. 매수 행은 자기 눈금(max(8, 건수)).
  - 칸 폭이 4px 아래로 내려가면(대략 390에서 19번 이상, 320에서 9번 이상) 같은 자리에 이어진 막대로 바꾼다: 길이 = 번 수 몫, 채움 = 오름 몫(`g7-06b-panel-320`).
  - 오른쪽: `오름 **3번**` / `모두 오름` / `오름 없음`(`text-sm`, 오른쪽 정렬). 굵은 것은 숫자뿐, `모두 오름`·`오름 없음`은 같은 보통 굵기. **1번뿐인 행은 `모두 오름` 대신 `오름 1번`**(12절 ⑨).
- 묶음 구분 3가지(조건 12)
  1. `정함` 행: 단독.
  2. `그대로 두기`·`바꾸기` 행: 왼쪽 2px 세로선(`bg-foreground/22`, 행 왼쪽 −7px)으로 묶는다.
  3. 주석 줄(막대 없음, 세로선 안): `위 두 가지 중 내 조건에 닿아 점검 **3번** · 오름 **2번**` — `text-xs text-muted-foreground`, 숫자만 본문색 `font-semibold`, 히트 40. nowrap 조각 2개(`…점검 3번` | `오름 2번`) + `flex-wrap`: 390 1줄, 320은 가운뎃점 자리에서만 2줄(`g7-06b`). 오름 0이면 `· 오름 없음`. 0번이면 줄 자체가 없다.
  3-1. **안내 줄**(위 묶음 맨 아래, 세로선 밖, 헤어라인 위): `30일이 안 된 기록 1번은 아직 넣지 않았어요` — `text-xs text-muted-foreground break-keep`, 위 2 아래 6. K = 0이면 없다. 390·320 모두 1줄.
  3-2. **매수 문장 상태(`buy`)의 위 묶음 자리**: 행 대신 1줄 `30일이 지난 선택이 3번 되면 보여요`(`text-sm text-muted-foreground`, 높이 36) + 헤어라인 + 매수 행(`g7-05b`, 패널 높이 135).
  4. 헤어라인(`h-px bg-border`, 위 6 아래 2) 아래 매수 행: 왼쪽 2줄(`이 앱에 기록한` `text-xs` / `매수` + `12건`), 높이 48, 오른쪽 `오름 **9건**`.
- 패널 높이(390 실측): 새 데모(3행 + 주석 줄 + 안내 줄 + 매수) = **271px**, 320 예시(주석 줄 2줄) = 287px, 매수 문장 상태 = 135px.

## 5. 인터랙션·모션·접근성
- **종류 줄**: `role="tablist"` + `role="tab"` `aria-selected`, 좌우 화살표 키 이동. 전환은 내용 교체만(슬라이드 없음), 새 보기 컨테이너 `motion-safe:animate-in fade-in duration-200`. 연타해도 마지막 선택만 남는다. 보기 전환 때 열린 한 장·패널·거름은 닫힌다.
- **`내 선택` 패널**: 항상 마운트. 바깥 `grid motion-safe:transition-[grid-template-rows,opacity] duration-200 ease-out`, 닫힘 `grid-rows-[0fr] opacity-0` + `inert`, 안쪽 `min-h-0 overflow-hidden`(점검 한 장과 같은 구조 — 재마운트 없음, 중간에 다시 눌러도 그 자리에서 되돌아감). 화살표 `motion-safe:transition-transform duration-200`.
- **한 번에 하나**: `내 선택` 패널을 열면 기준 패널이 닫히고, 기준 칸을 누르면 `내 선택` 패널이 닫힌다. 두 전환은 같은 200ms로 겹쳐 진행(높이 튐 없음).
- **패널 행 거름**: 행을 누르면 `aria-pressed`, 기준 4칸 아래에 사실 줄. 같은 행을 다시 누르거나 패널을 닫으면 풀린다(거름은 패널이 열려 있는 동안만 — 닫힌 채 걸러진 목록이 남지 않는다).
- **`시세 고치기`**: 기존 수정 창을 연다(`trigger-edit-real-estate`·`trigger-edit-physical`). 닫히면 포커스가 버튼으로 돌아오고 한 장은 열린 채다.
- 버튼 누름 `active:scale-[0.96]`, 전환 목록에 `scale`(DS §6). `transition: all` 없음.
- aria-label: 결론 줄 버튼 `내 선택, 6번 중 5번은 그때보다 오름, 펼치기`(`wait`는 버튼이 아니라 글자라 aria-label 없음). 패널 행 `정함 3번, 오름 2번, 누르면 아래 종목을 이 기록이 있는 종목으로 걸러요`. 칸 막대는 `aria-hidden`. aria-label에도 두 행을 견주는 말(`더`·`덜`·차이)을 쓰지 않는다.
- 히트영역 40 이상: 종류 칸(32 + 위아래 4), 결론 줄(20 + 위아래 10), 패널 행 40, 주석 줄(28 + 위아래 6), `시세 고치기` 40.
- 다크 대비: 꼬리 indigo-200(행 `점검 차례`와 같은 값), 빈 칸 14%·채운 칸 60%는 카드 위에서 서로 구별된다. 라이트는 development 캡처에서 확인한다(채운 칸 `bg-foreground/60`, 빈 칸 `bg-foreground/14` 그대로 쓰되 대비 미달이면 빈 칸을 `/18`).
