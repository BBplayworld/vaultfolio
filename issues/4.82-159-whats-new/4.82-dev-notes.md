## 알려진 한계 / spec·HEAD와 다른 점
- GA: `entryCategory` 이벤트의 `source:"whats_new"`는 이벤트 파라미터뿐이라 페이지 및 화면 CSV에서 홈 팁 경로와 구분되지 않음(tech-review 6장, 새 이벤트 만들지 않음).
- 홈 팁 배지는 오케스트레이터 판정대로 `소식`(ui 제안 `업데이트` 미채택).
- 팁 클릭 시 `SESSION_DISMISS_KEY`를 함께 세워 같은 세션에 다른 팁이 튀어나오지 않게 함(spec 명시 없음, ui.md 4.1 "다른 팁이 튀어나오지 않음"을 따름).
- 시드 id 날짜 = 오늘(KST) 2026-11-11 기준 `20261111-NN`. PR 생성일이 다르면 id 일괄 교체 필요(테스트의 `20261111-*` 참조도 함께).
- 시드 1·4·6번 qa 사실 확인(spec 7장)은 미수행 — 확인 안 되면 목록에서 제외하고 테스트 기대값(8→N, `home-tip.test.ts`·`whats-new.test.ts`의 8/5/`20261111-07`)을 갱신.
- 목록 시드는 게시 30일 지나면 안 본 항목에서 빠지므로 `home-tip.test.ts`는 `today`를 고정 주입(시계 의존 없음), `config` 테스트의 "미래 날짜 없음"만 실시간 KST 사용.
- 시트 `onOpenAutoFocus`는 SheetContent 자체 포커스, 닫힘 포커스는 홈 팁 경로만 `main`으로 이동(ui.md 반영). Playwright preview 확인·ui-designer 검수는 미수행(preview URL 배포 후 진행 필요).
