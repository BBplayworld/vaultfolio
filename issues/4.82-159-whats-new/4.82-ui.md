작성 2026-11-11 · 입력: 4.82-spec/challenge/business, design-system §1~§7·§11, components.md(HomeTipBox·FAB Sheet), 코드 origin/main cca5dbb
원칙: **새 패턴 0.** 홈 팁 셸·FAB 시트(`Sheet` + 모바일 bottom / PC right)·더보기 도움말 선택기 행·기존 배지 색을 그대로 쓴다. 신규 토큰·신규 컴포넌트 스타일 없음(design-system 흡수 불필요, 카탈로그에는 `WhatsNewSheet` 1개만 등록).

## 1. 홈 팁 (HomeTipBox `kind="whats_new"`)
- 컴포넌트: **수정(재사용)** — `contentOf`에 분기 1개, `Icon: Sparkles`(import 기존), `notice` 분기·`NOTICE_SHOWN_SESSION_KEY`·`isNew` NEW 배지 삭제.
- 트리(위→아래, 셸 그대로): `div[role=button] rounded-xl bg-card shadow-xs p-4` › [Sparkles size-4 orange] · [배지 `업데이트` / 제목 `새 소식 N개` (`text-sm sm:text-[15px] font-semibold`)] · 설명(`text-sm text-muted-foreground mt-1`, 첫 안 본 항목 title) · X(히트 40px).
- 수치: 셸과 동일(375px 카드폭 = 뷰포트−24, 내부 패딩 16, gap-2). 1280px도 동일(콘텐츠 컨테이너 폭에 종속, 변경 없음).
- 문구: 제목 `새 소식 N개`(N=1이면 `새 소식 1개`). 설명 = 항목 title(≤32자, 320px에서 최대 2줄, `break-keep text-pretty`). 설명에 `외 N개`·`›` 덧붙이지 않음(제목에 개수가 있음).
- 상태: 기본(위) / 로딩 = 판정 전 미렌더(레이아웃 점프는 기존 팁과 같은 진입 애니메이션 `fade-in slide-in-from-bottom-2 300ms motion-safe`로 흡수) / 빈·첫 사용·체험 = 미렌더 / 오류 없음.
- 클릭 후: 팁은 즉시 언마운트(exit 애니메이션 없음 — 시트 오버레이가 덮음). 같은 세션 다른 팁이 튀어나오지 않음(기존 세션 숨김 유지).
- testId: 기존 `home-tip`(`data-kind="whats_new"`)·`home-tip-title`·`home-tip-close`.

## 2. 새 소식 시트 (`WhatsNewSheet`, 신규 1개, `views/home` 또는 `layout/onboarding`)
구성 = 기존 `Sheet`/`SheetHeader`/`SheetTitle`/`SheetDescription` + `Button variant="brand"`.
```
SheetContent (모바일 bottom: rounded-t-2xl max-h-[80dvh] flex-col / PC right: w-3/4 sm:max-w-sm 전체 높이)
├ 그랩 핸들(모바일 전용, FAB 시트와 동일 코드 패턴: h-10 영역 + w-10 h-1.5 bg-muted-foreground/30, 드래그 dy>80 닫기)
├ SheetHeader  px-4 (모바일 mt-3)
│  ├ SheetTitle `새 소식`  (기본 시트 제목 스타일)
│  └ SheetDescription `지금 버전 v{APP_VERSION}` text-sm muted tabular-nums  data-testid=whats-new-version
├ 목록 영역  flex-1 min-h-0 overflow-y-auto px-4 touch-pan-y  (헤더·푸터 고정, 목록만 스크롤)
│  └ <ul> divide-y divide-border dark:divide-border/40   ← 카드 없이 헤어라인 목록(항목마다 박스 금지: 8~20개라 박스는 피로)
│     └ <li data-testid=whats-new-item> py-3
│        ├ 1줄: [새 chip] 제목  (제목 text-sm font-semibold text-foreground text-pretty break-keep; chip은 제목 앞 인라인)
│        ├ 2줄(body 있을 때): text-sm text-muted-foreground leading-relaxed mt-1 break-keep text-pretty
│        └ 3줄 mt-1.5 flex items-center justify-between: 날짜 `M/D`(text-[11px] muted tabular-nums) · [바로 가기 ›]
└ 푸터 px-4 pt-3 pb-[max(1rem,env(safe-area-inset-bottom))]: Button variant="brand" w-full `닫기`
```
- **`새` chip** (`whats-new-item-new`): `inline-flex mr-1.5 rounded bg-orange-500/10 px-1.5 py-0.5 text-[11px] font-bold text-orange-700 dark:text-orange-400 align-middle`. 홈 팁 배지와 같은 주황 계열(새 색 아님). 라이트는 700으로 한 단계 진하게(600은 흰 배경 대비 4.5:1 미달) — 홈 팁 배지는 이번 범위 밖이라 그대로.
- **`바로 가기 ›`** (`whats-new-go`): `<button>` `relative text-sm font-semibold text-primary` + `after:absolute after:-inset-y-2.5 after:-inset-x-2`(히트 40px), `active:scale-[0.96] transition-[color,scale]`, focus-visible ring. 문구 `바로 가기` + `ChevronRight size-4`(lucide 기존). aria-label `{항목 제목} 바로 가기`. 날짜는 항상 같은 줄 왼쪽, 버튼은 오른쪽 → 버튼 유무로 행 높이 차이는 날짜 줄이 흡수(항목 높이 동일 구조).
- **빈 상태** (`whats-new-empty`): 목록 영역 중앙 `py-12 text-center text-sm text-muted-foreground` `최근 60일 동안 새 소식이 없어요`. 푸터 닫기는 유지.
- **'새' 유지**: 열기 직전 안 본 id 집합을 시트 `useState` 스냅샷으로 들고, 읽음 기록(키 쓰기)은 열린 동안 표시에 영향 없음. 시트는 항상 마운트·`open`만 토글(재마운트 없이 닫힘 애니메이션 보장, 닫힐 때 스냅샷은 `onOpenChange(false)` 후 애니메이션 끝에 정리).
- **레이아웃 수치**: 320px — 좌우 16, 제목 최대 2줄, 날짜·버튼 줄 한 줄(`M/D` + `바로 가기 ›` ≈ 120px). 375px 동일. 1280px — right 시트 폭 `sm:max-w-sm`(384px), 오버레이 `bg-black/80` 기본. 항목 20개·body 긴 문구(48자) 시 목록만 스크롤, 헤더·푸터 안 밀림.
- **긴 문구**: 제목·body 모두 `break-keep wrap-break-word`. 한 줄 제목이 길어도 chip이 줄바꿈으로 고아가 되지 않게 chip+제목을 같은 `<p>` 인라인 흐름에 둔다.
- 다크: 시트 `dark:bg-popover`(기본), 구분선 `divide-border/40`, 본문 muted는 토큰 그대로. 라이트: 시트 `bg-background`(캔버스 톤)에 목록 박스 없음 → 구분은 라이트 `divide-border`(알파 단독 금지 규칙 준수).
- a11y: Radix Dialog 포커스 트랩·Esc. 제목 `SheetTitle`·설명 `SheetDescription` 연결. 열릴 때 포커스는 기본 `preventDefault`(FAB 시트와 같음) 대신 **`SheetContent` 자체**에 두어 스크린리더가 제목부터 읽게 한다. 닫힘 포커스: 홈 팁 경로는 복귀 대상이 사라지므로 `main`, 더보기 경로는 더보기 트리거(기본 복귀) — 바로 가기로 닫힐 때는 `onCloseAutoFocus` preventDefault(이동한 화면 포커스 뺏지 않기).

## 3. 더보기
- 지원 섹션 행: `앱 가이드 · 공지사항` → **`앱 가이드 · 새 소식`**(MENU_ROW 그대로, Info 아이콘·ChevronRight 그대로).
- 도움말 선택기 Dialog: 제목 `앱 가이드 · 새 소식`, 설명 `앱 사용법 가이드와 최근 새 소식을 확인해요.`(기존 `~합니다` 톤이 같은 창 안에 섞이지 않게 해요체로 통일하지 않고 **기존 하십시오체 유지 → `앱 사용법 가이드와 최근 새 소식을 확인합니다.`** 로 한다. 같은 창 안 톤 일관).
- 두 번째 카드: BellRing 아이콘·카드 스타일 그대로, 제목 **`새 소식 보기`**(`data-testid="more-whats-new"`), 설명 `최근 업데이트와 새 기능을 확인합니다.`. 클릭 → 선택기 닫기 → `dispatchOpenWhatsNew("more")`. 두 Dialog가 겹치지 않게 선택기를 닫은 다음 시트를 연다(기존 공지 흐름과 동일 순서).
- 삭제: `showNotice` Dialog 전체(BellRing 헤더 포함), `NOTICE_TITLE`·`NoticeContent` import.
- 미열람 점·숫자 배지 없음(금지).

## 4. 모션 · 인터랙션
- 시트: 기존 `Sheet` 기본(`animate-in/out`, 열림 500ms·닫힘 300ms ease-in-out) — 추가 모션 없음. 항목 stagger 없음(목록 정보 훑기가 목적, 8~20개 순차 등장은 지연만 만듦). 스와이프 닫기는 FAB 시트 패턴(드래그 중 `transition:none`, 놓으면 복원/닫힘, 중간 방향 전환 허용).
- 홈 팁: 기존 진입 애니메이션만. `motion-safe` 전부, reduced-motion이면 즉시.
- 바로 가기·닫기: press scale 0.96(`transition-[color,scale]`, `transition: all` 금지).
- 연타: 팁 연속 클릭은 첫 클릭에서 언마운트돼 시트 1개만(이벤트 `open` 멱등). 바로 가기 연타는 첫 클릭 시 `onOpenChange(false)` + 이동 1회(핸들러 진입 즉시 `closingRef`로 이중 이동 방지).
- 재마운트 모션 소실 방지: 시트는 호스트에 상시 마운트(조건부 렌더 금지) → 닫힘 exit 보장.

## 7. 품질 체크리스트 (qa 판정용; 캡처 전 쿠키 `theme_mode=light|dark`로 강제하고 html class·배경 RGB 기록 — C81)
1. 320·375·1280 × 라이트·다크 홈 팁이 기존 팁(결산)과 같은 높이 규칙·패딩·아이콘 크기이며 가로 스크롤 0. 배지·펄스·빨간 점 없음.
2. 홈 팁 제목 `새 소식 8개`, 설명 `합친 평단을 가격 흐름 위에서 봐요`가 320px에서 2줄 이내로 잘림 없이 보인다.
3. 팁 클릭 시 `whats-new-sheet`가 열리고 팁은 사라지며 시트 뒤 홈에 팁이 다시 뜨지 않는다.
4. 시트 머리에 `새 소식`과 `v{APP_VERSION}`(설정 > 정보와 동일 값)이 보이고, 목록만 스크롤되며 헤더·`닫기`는 고정이다(항목 20개 가정 포함).
5. `whats-new-item` 8개가 시드 순서이고 `whats-new-item-new`는 정확히 5개, 읽음 기록 후에도 시트가 열려 있는 동안 유지된다.
6. D-08 행에 `whats-new-go` 없음, 나머지 7행에는 있고 날짜(`M/D`)가 모든 행에서 같은 x 위치(왼쪽)에 있다.
7. `바로 가기`·`닫기`·X 히트영역 ≥40×40px(요소 박스 실측), 키보드 Tab·Enter·Esc 동작, 포커스 링 보임.
8. 모바일 그랩 핸들 스와이프(>80px)로 닫히고, PC는 오른쪽 시트로 열린다(1280에서 하단 전폭 시트 아님).
9. 다크·라이트 모두 `새` chip 대비 ≥4.5:1, 구분선 가시(라이트 헤어라인 소실 없음), 목록 항목에 개별 박스·테두리 없음.
10. 더보기 > `앱 가이드 · 새 소식` > `새 소식 보기`로 시트가 열리고 선택기 Dialog와 겹치지 않는다. 옛 `공지사항` 문구·BellRing 공지 Dialog 잔존 0.
11. 바로 가기(D-03 등) 클릭 시 시트가 닫히고 해당 화면이 열린다. 연타해도 이동 1회.
12. 빈 상태 `whats-new-empty` 문구·중앙 정렬 확인, 닫기 가능.
13. `prefers-reduced-motion`에서 시트·팁 진입이 즉시 전환(motion-safe 외 애니메이션 클래스 없음).
14. 금지 문구(금액·투자 판단·보장 어휘) 화면 노출 0, 존댓말 일관.

## 8. 검토 요청
- planner-designer: 홈 팁 배지 `업데이트`(spec 4번 `새 소식` 대체) 승인 또는 반려.
- developer: 시트 호스트 분리(§0), `dispatchOpenWhatsNew(source)`는 기존 `asset-dispatch` 패턴에 추가. 반응형 분기는 FAB 시트의 `useIsMobile` 재사용.
