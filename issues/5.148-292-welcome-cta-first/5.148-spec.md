# 5.147 #292 웰컴 첫 화면에 등록 버튼 올리기 — spec (planner-designer, 2026-11-25)

근거: CEO 판정 `_discovery/2026-11-25-d12-welcome/ceo.md`(통과·risk:low·5.147 동승), 진단 `planner.md` 같은 폴더. 코드는 main ef2675e 기준 `src/app/(main)/_components/layout/onboarding/welcome-guide.tsx:153-283`, `(main)/page.tsx:110-127`.

## 1. 문제
폰(320×568·375×667) 첫 화면이 히어로 → 신뢰 줄 → 예시 순자산 5.5억·도넛으로 끝난다. `스크린샷으로 자산 등록`은 문서 736px(375)·786px(320)에 있어 스크롤해야 보이고, 첫 화면에서 누를 수 있는 것은 `자세히 보기`와 `직접 둘러보기` 칩뿐이다. 수치 발동 기준과 무관한 **화면 결함**이다(PRINCIPLES 5장).

## 2. 목표 행동
처음 온 사용자가 스크롤 없이 등록 버튼을 보고 누른다(`웰컴·스크린샷 등록`·`웰컴·직접 입력`·`웰컴·가져오기`).

## 3. 범위
- 포함: (a) 주식 미리보기 블록(`welcome-preview-stock`) 삭제 (b) 등록 칸(`welcome-cta-slot`)을 신뢰 줄 바로 아래로 (c) 안내 문장을 예시 순자산 바로 밑으로(문구 그대로) (d) 삭제로 안 쓰이게 된 import·상수 정리.
- 하지 않을 것: 버튼·칩·문구·아이콘 변경, 새 버튼·새 이벤트, GA title, `RootFirstPaint`(SSR 첫 조각), 체험 진입 조건, 설치 박스, 히어로 문구, 안 B(둘러보기 먼저)·안 C(웰컴 빼기), 예시 순자산 카드와 도넛 가운데 '5.5억' 중복(후보로만).

## 4. 사용자 흐름
1. 0건 기기로 `/` 진입 → 히어로·신뢰 줄 아래에 바로 `첫 번째 자산을 추가해보세요` + 두 버튼이 보인다.
2. `스크린샷으로 자산 등록` → 마법사 / `직접 입력 · 가져오기` → 팝오버(5행+가져오기 2행).
3. 버튼 아래에서 `포트폴리오 미리보기 [예시 데이터]`와 `직접 둘러보기` 칩을 본다 → 칩을 누르면 `/?trial=1`.
4. 체험에서 돌아오면 등록 칸에 포커스, 자산군 제목(#249 trialPick).
5. 인앱이면 ③이 `외부 브라우저에서 시작하기`, iOS는 누르면 가이드가 그 아래로 펼쳐진다.

## 6. 엣지 케이스
- 첫 사용자·빈 데이터: 이 화면의 기본 대상. 일부 갱신·오래된 데이터: 예시 데이터는 정적 JSON이라 해당 없음.
- 보안 상세 펼침: 등록 칸이 그만큼 밀린다(사용자 행동 결과, 허용).
- 팝오버: 위로 올라온 버튼에서 열려도 `collisionPadding`·`max-h` 안에서 7행 전부 닿는다. 4.86 p2 '320 가져오기 행 가림'의 전후를 qa가 기록.

2. 누를 수 있는 요소 수·문구, GA title(`웰컴`·`웰컴·인앱`·`웰컴·<버튼>`·`체험 모드`·`체험 모드·인앱`·`웰컴·체험·*`), `RootFirstPaint` HTML, 저장 키·서버 전송 diff 0. 새 버튼 0.
