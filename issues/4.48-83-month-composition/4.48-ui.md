# 4.48 UI 사양 — 월 탭 "자산 구성 변화" 블록 (#83)

작성: ui-designer, 2026-11-07. 기준: 4.48-direction·4.48-spec, 4.44-ui-v3-composition(막대·행 규격 재사용, 리본 제외), design-system §1~§7·§11. 코드 수정 없음. 근거 코드: `settlement-view.tsx`(원인 블록→AI 행 순서), `change-hero.tsx`(`CauseBlock`, `BODY_ENTER`), `report-section.tsx`(`SECTION`, `SectionHeader`), `dashboard.tsx`(도넛 색), `theme.ts`(`MAIN_PALETTE`, `pickOnColor`).
검증 한계: 이번 실행은 CLAUDE.md "라이브 프리뷰 제외" 규칙에 따라 로컬 dev 캡처를 하지 않고 코드로 톤·간격을 확인했다. 실화면 대조는 ui-review(preview 375·320·1280 × 라이트·다크)에서 한다.

## 1. 톤 근거 (현행 월 탭 결산 화면, 코드 기준)
- 순서: Hero → `CauseBlock`(`SECTION` + `BODY_ENTER`, 헤더 아이콘 ListChecks "변화 원인", 행은 `SpecRow`) → AI 행(`AI_ROW_SURFACE`, min-h-14) → PrepBlock. 최상위 `space-y-` 섹션 간격은 design-system의 섹션 gap-5, 카드 내부는 `space-y-3`.
- 새 카드는 `CauseBlock`의 쌍둥이다: 같은 `SECTION` 면(`rounded-xl bg-card p-4 space-y-3 dark:shadow-sm`), 같은 `SectionHeader`, 같은 `BODY_ENTER`. 테두리 없음, 신규 토큰 없음, 강조는 굵기와 색점뿐.

## 3. 레이아웃 수치
- 카드 내부 폭 W: 375px=319, 320px=264, 1280px=카드 폭(최대 컨테이너 따름). 카드 `p-4`, 내부 `space-y-3`(12). 블록 위 `CauseBlock`과의 간격은 부모 gap 그대로(섹션 gap-5).
- 막대: 폭 100%, 높이 `h-8`(32) / `sm:h-10`(40) (리본이 없어 4.44의 h-10/12보다 한 단계 낮춤). `rounded-lg overflow-hidden`, 세그먼트 `flex`, 폭=실제 비중 % 선형, 최소 폭·보정 없음. 세그먼트 사이 `border-l-2 border-card`(첫 칸 제외). 순서는 `COMPOSITION_KEYS` 고정(부동산·[실물]·주식·암호화폐·현금성), 두 막대 같은 순서.
- 간격: 시작 라벨↔막대 `gap-1.5`, 두 막대 사이 `gap-1.5`(6), 막대↔끝 라벨 `gap-1.5`. 막대 블록↔행 목록은 `space-y-3`+`pt-1`.
- 막대 안 %: 비중 **10% 이상**만 정수 %를 `text-xs font-semibold tabular-nums`, 글자색 `pickOnColor(색)`. 10% 미만은 글자 없음(10%=319px에서 32px, "10%" 약 24px로 들어감. 320px에서는 26px로 들어가지만 여유 2px라 `px-0 overflow-hidden whitespace-nowrap`, 잘림은 허용하지 않으므로 여유 없는 10~11%도 통과하는지 ui-review에서 확인).
- 1~2% 처리: 폭을 왜곡하지 않는다. 막대에는 색 한 줄만 남고(3.2~6px), 식별은 (a) 행에 색점+이름+수치가 항상 있고 (b) 세그먼트 `title` 없음(터치 무의미), (c) 반올림이 0이면 수치를 "<1%"로 쓴다. 인접 색과 `border-card` 2px 구분선이 폭을 잡아먹어 1%가 안 보일 수 있으므로, 세그먼트 폭이 구분선보다 작아도 색이 보이도록 구분선은 `box-shadow: -2px 0 0 var(--card)`(폭 소비 없음) 대신 `border-l-2`를 쓰되 `box-sizing: border-box`에서 폭이 2px 미만이면 색이 사라진다는 점을 확인한다. 1%(≈3px)는 1px 색이 남는다. 사양: **구분선은 `shadow-[-2px_0_0_0_var(--card)]`로 구현**해 색 폭을 지킨다(새 토큰 아님, 기존 `--card`).
- 행 `composition-row-{key}`: `grid grid-cols-[auto_1fr_auto_auto] items-center gap-x-2 py-1.5 text-sm` — 색점 `size-2 rounded-full` · 이름 `text-muted-foreground break-keep` · `62% → 58%` `tabular-nums text-foreground whitespace-nowrap` · 증감 `composition-delta-{key}` `min-w-14 text-right font-semibold tabular-nums whitespace-nowrap text-foreground`. "변화 없음"은 `font-normal text-muted-foreground`.
- 1280: 행 목록은 `sm:grid sm:grid-cols-2 sm:gap-x-8`(4.44와 동일), 행 수가 홀수면 마지막 칸은 비워 둔다.
- 높이 감각(375): 헤더 28 + 문장 20~40 + 막대블록 약 110 + 행 4×32 ≈ 330px. AI 행이 그만큼 아래로 밀린다(direction 5절 인지됨).

## 4. 자산군 색 토큰 (신규 토큰 없음, 기존 `MAIN_PALETTE` 인덱스를 고정 매핑)
코드에 구성 색 정의가 남아 있지 않다(`assignCompositionColors`는 삭제됨). 홈 도넛은 `assignColors`로 **그 시점의 최대 항목=`MAIN_PALETTE[0]`, 나머지=`[3]`부터 순번**을 주므로 자산군 색이 데이터에 따라 바뀐다. 두 시점·여러 달을 비교하는 이 블록은 같은 자산군이 항상 같은 색이어야 하므로 고정 매핑을 쓰고, 홈과 가장 자주 일치하도록 최대 비중이 되기 쉬운 부동산에 `[0]`을 준다.

| 자산군 | 토큰 | 색 | 막대 글자(`pickOnColor`) | 홈 도넛 대응 |
|---|---|---|---|---|
| 부동산 | `MAIN_PALETTE[0]` | 인디고 #5b6fbf | 흰색 | 홈 도넛 "부동산"이 최대일 때 같은 색(대부분의 사용자) |
| 실물(#58 동승 시) | `MAIN_PALETTE[8]` | 황토 #7a6236 | 흰색 | 홈에 별도 조각 없음 |
| 주식 | `MAIN_PALETTE[4]` | 초록 #3a9e6e | 흰색 | 홈 금융 막대에서 두 번째 순번과 같은 색(최대가 아닐 때) |
| 암호화폐 | `MAIN_PALETTE[3]` | 황금 #d6b72e | 검정 | 홈 금융 막대에서 첫 순번과 같은 색 |
| 현금성 | `MAIN_PALETTE[5]` | 청록 #2a9db5 | 흰색 | 홈 금융 막대에서 세 번째 순번과 같은 색 |
- 홈과 완전 일치는 보장하지 않는다(홈은 데이터 의존). 일치 보장 대신 "블록 안에서 항상 같은 색"을 선택했고, 이유를 design-system에 한 줄로 흡수한다(7절). 손익색(빨강 `[1]`·파랑)과 `[2]` 주황(순자산 important)은 피했다.
- 초록은 손익색이 아닌 한국 관행(빨강=수익, 파랑=손실)과 충돌하지 않는다. 흰 글자 대비는 초록·청록이 약 3.3~3.6:1로 AA 대형/굵은 글자(12px bold) 기준에 간신히 못 미치므로, 막대 안 % 대신 행에 같은 수치가 항상 있어 정보 손실이 없다(보조 표기).
- 다크: 세그먼트는 라이트와 같은 색, `border-card`(검정에 가까운 면)가 구분을 유지. 다크에서 과하게 밝지 않도록 막대에 `opacity` 변경 없음(채도 이미 낮은 팔레트).

## 6. 줄바꿈 (C25)과 증감 행 형식
- 행 형식 고정: `● 부동산  62% → 58%  −4%p`. 부호는 `+` 와 U+2212 `−`. 반올림 정수 차(`round(끝)−round(시작)`)가 0이면 "변화 없음"(실제 차 1%p 미만이어도 반올림 차 0이면 동일). 손익색 클래스 금지.
- 320(W=264): 점8+gap8+이름(최대 4자 ≈56)+`62% → 58%`(≈78)+gap16+델타(≈44~58) ≈ 214~228px로 한 줄. "암호화폐 100% → 100%"는 단일 자산군이라 숨김이라 최악은 "암호화폐 <1% → 12% +12%p" 약 236px로 한 줄. 넘치면 이름 칸이 줄어드는 순서(`1fr`)이며 수치는 깨지지 않는다.
- 사실 문장은 320에서 2줄(약 17자/줄), `break-keep`이라 "현금성"·"+4%p"가 중간에서 끊기지 않는다. 배지는 320에서 헤더 `flex-wrap`으로 통째 다음 줄로 내려간다(어절 중간 분리 없음).
- 라벨 "9/30"·"지금"은 `whitespace-nowrap`.

## 7. 모션 (전부 `motion-safe`)
- 카드: `BODY_ENTER`(CauseBlock과 동일, fade + slide-in-from-bottom-1, 300ms). `key={month}`로 `CauseBlock`과 함께 재마운트되어 월 화살표마다 같은 연출이 나온다(재마운트로 모션이 사라지는 구조 아님, 오히려 재생이 의도).
- 막대 A `origin-left motion-safe:animate-in fade-in slide-in-from-left-2 duration-300 fill-mode-backwards`, 막대 B 지연 60ms, 행은 `i*25ms` stagger(최대 5개), `animationFillMode: backwards`. 비인터랙티브라 연타·중간 전환 개념 없음; 연타 시 `key` 교체로 이전 인스턴스는 즉시 사라진다(subtle exit 생략, CauseBlock 동일).
- 이번 달 값이 갱신될 때 세그먼트 `motion-safe:transition-[width] duration-300`(세그먼트 key=자산군, 월 내에서는 재마운트 없음).
- `motion-reduce`: 즉시 표시. `transition: all` 금지, `will-change` 없음.

## 8. 접근성
- 막대 블록 `aria-hidden="true"`. 텍스트 대체는 sr-only 구간 문장 + 사실 문장 + `<ul>`의 `<li aria-label>`: "부동산 62%에서 58%, 4%포인트 감소" / "62%에서 62%, 변화 없음" / "주식 0%에서 8%, 8%포인트 증가".
- 포커스 가능 요소는 `InfoHint` 1개뿐(기존 40px 히트영역·키보드 규격). 색만으로 구분하지 않음(행에 이름 병기).
- 대비: 텍스트는 `text-foreground`/`text-muted-foreground` 토큰이라 라이트·다크 자동. 막대 내부 글자 `pickOnColor`, 보조 정보는 행에 중복.

## 9. 문구 최종안 (존댓말, 평가어·권유·금액 없음)
제목 "자산 구성 변화" / 배지 "부채 제외 총자산 기준" / 힌트(위 2절) / 문장 "이 구간 동안 주식 +4%p, 현금성 −3%p", "이 구간 동안 구성이 거의 같아요" / 행 "62% → 58%", "변화 없음", "<1%". 모두 `COMPOSITION_FORBIDDEN_WORDS` 테스트 대상에 포함.

## 10. testId / data-screenshot-hide
`composition-block`, `composition-title`, `composition-badge`, `composition-sentence`, `composition-compare`, `composition-bar-start|end`, `composition-seg-{start|end}-{key}`(`data-ratio` 실제 비중), `composition-label-start|end`, `composition-rows`, `composition-row-{key}`, `composition-delta-{key}`, `composition-sr-range`. `data-screenshot-hide`: 힌트 아이콘만(비중만 있고 금액 없음, 블록 자체는 노출 가능).

## 11. 품질 체크리스트 (qa 판정용, 375·320·1280 × 라이트·다크)
1. 8월 이후 결산 달에서 월 탭 진입 시 클릭 없이 `composition-block`이 `cause-block` 바로 아래, AI 행 바로 위에 있다.
2. 블록 안에 버튼(InfoHint 제외)·`aria-pressed`·리본·범례·금액 문자열이 0개다.
3. 두 막대 폭이 모두 카드 내부 폭 100%이고 세그먼트 폭 비율 = `data-ratio`(오차 1% 이내), 최소 폭·보정이 없다.
4. 시작·끝 라벨이 Hero `settlementRangeLabel` 시작점·끝점과 같은 글자다(이번 달 끝은 "지금").
5. 10% 이상 세그먼트에만 막대 안 %가 있고 글자 잘림·넘침이 없다.
6. 1~2% 자산군도 막대에서 색이 식별되고 행에 이름·수치·증감이 있다.
7. 행 증감 = 반올림 비중 차이고 0이면 "변화 없음"이다. 증감 텍스트에 빨강/파랑 손익 클래스가 없고 부호는 `+`/U+2212다.
8. 자산군 색이 4절 표와 같고 두 막대·모든 달에서 같은 자산군은 같은 색이다.
9. 카드 면·헤더·`BODY_ENTER`가 `cause-block`과 동일하다(테두리 없음, `dark:shadow-sm`).
10. 320·375에서 가로 스크롤과 어절 중간 줄바꿈이 없고 행이 한 줄이다. 1280에서 행이 2열이다.
11. 배지 "부채 제외 총자산 기준"이 320에서 통째로 줄바꿈되고 InfoHint 히트영역이 40px 이상이다.
12. 다크에서 세그먼트 구분이 보이고 막대 글자 대비가 유지된다.
13. 월 화살표 이동 시 블록이 새 구간 값으로 다시 계산되며 진입 모션이 재생되고, `motion-reduce`에서는 즉시 표시된다.
