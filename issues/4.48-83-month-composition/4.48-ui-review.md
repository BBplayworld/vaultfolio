## 판정: UI 수정 요청 (필수 1, 권장 2)

### 필수
1. **[버그·회귀] 월 이동 시 변화 원인 카드가 누적 복제됨.** `settlement-view.tsx` 146·148행에서 `<CauseBlock key={month}>`와 `<CompositionBlock key={month}>`가 같은 부모의 형제인데 key가 동일 → React "two children with the same key" 경고, 월 화살표를 누를 때마다 `cause-block`이 1→2→3→…→7개로 쌓임(콘솔·DOM 확인, composition은 1개 유지). main은 key가 하나라 없던 문제.
   - 수정: 148행을 `key={`composition-${month}`}`로(또는 CauseBlock을 `cause-${month}`로). 수정 후 월 이동 7회 뒤에도 `cause-block` 1개, key 경고 0이어야 함.
2. **[잘림] 320에서 정확히 10% 세그먼트의 막대 안 글자가 양옆 잘림.** `composition-block.tsx` Bar의 `ratio >= 10` → `ratio >= 11`(320 기준 11% = 29px ≥ 글자 27.6px). 10.0%: 폭 26.4 < 27.6 `scrollWidth>clientWidth`. 10.1%(26.7)도 글자가 가장자리에 닿음. 375는 31.9px로 통과.

### 권장(비차단)
3. InfoHint 실제 히트영역이 14×14px(공용 `info-hint.tsx`가 확장 영역이 없음, 변화 원인 카드 등 기존 힌트도 동일). 사양 11-11의 "40px"과 불일치하나 이번 범위 밖 공용 컴포넌트 → 별도 과제 후보로 기록.
