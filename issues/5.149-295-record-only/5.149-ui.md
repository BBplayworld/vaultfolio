## 1. '기록만' 배지 (4종 통일)
- 컴포넌트: 기존 `Badge variant="outline"` 현금형 그대로. 클래스 `text-2xs px-1 py-0 leading-tight text-muted-foreground` (현재 cash/loan/crypto 3곳과 글자만 다름). 문구 `미반영` → `기록만`. 조건 `!t.reflected`만(반영 거래에는 아무 배지 없음).
- 다크 대비(5.148 B 감사 규칙 일치): 글자 muted-fg(.74) on card(.225) ≈ 7:1(토큰 계산, 기준 4.5 통과) → **다크 전용 보정 0**. 테두리는 Badge 기본 `border`(기능성 허용, §보더리스 예외). 라이트도 동일 클래스.
- 크기: text-2xs 11px(모바일)/12(태블릿·PC), 11px 미만 없음. 배지는 장식이라 히트영역 해당 없음(탭 불가).
- 위치(4종 동일): **제목 줄(유형 라벨 오른쪽, `flex items-center gap-1.5 flex-wrap`)**. 현금·대출·코인은 현행 자리 유지. 주식은 금액 아래(`text-right` 열)의 초록 `반영` 칩을 삭제하고, 종목·수량 열 첫 줄(매수/매도 라벨 오른쪽)으로 `기록만`을 옮긴다. 금액 열은 금액 1줄만 남아 항상 같은 높이 → 반영 행/비반영 행 금액 y 위치 동일, 행 높이는 좌측 열(2~3줄)이 결정하므로 **반영 칩 제거로 행 높이 변화 0**(기대값: 반영 거래 행 높이 전/후 diff 0px).
- 초록 `bg-emerald-500/15` 칩 코드 제거(새 색 0). 구버전(reflected 없음/false)은 `기록만`이 붙는다.
- 겹침: 320에서 제목 줄이 `flex-wrap`이라 배지가 다음 줄로 내려가며 금액을 밀지 않는다(금액 열 `shrink-0`).
- testId: `tx-record-only-badge`(4종 공통, 행당 1개).

## 2. 체크 도움말 6곳 (문구는 ceo.md 확정문)
- 클래스: 체크 아래 `text-xs text-muted-foreground text-pretty break-keep`(기존 muted 도움말 줄 위계 유지, 굵기 없음).
- 현금·대출: `이미 잔액에 들어간 거래면 해제하세요. 기록만 남고 잔액은 그대로예요` / 주식·코인·스크린샷 2곳: `이미 보유 수량에 들어간 거래면 해제하세요. 기록만 남고 보유 수량은 그대로예요`.
- 줄바꿈: `break-keep`로 어절 단위, `text-pretty`로 마지막 줄 외톨이 방지. 기대: 390 **2줄 이하**, 320 **3줄 이하이면서 지금 문장보다 늘지 않음**(CEO 판정, ceo.md 6절). 문장 ②가 390에서 3줄이면 spec의 ②′로 바꾸고 측정값을 ui-review에 남긴다. 390에서 3줄이거나 320에서 4줄이거나 지금보다 늘면 qa FAIL. 가로 스크롤 0.
- `YEAR_SETTLE_COPY.help`·`yearIncomeHint` 문단: 같은 `text-pretty break-keep`(InfoHint 요약 본문). 숫자·`꺼낸 돈` 같은 이름은 `whitespace-nowrap` 조각으로 묶어 이름 중간 줄바꿈 금지.
- testId: `record-only-help`.

## 3. 삭제 확인 창 (기록만 거래)
- 재사용: cash-tx-view.tsx:177 `반영 거래 삭제 확인`의 오버레이 레이아웃 그대로(`fixed inset-0 z-[10050] bg-black/50 p-4`, 패널 `max-w-sm rounded-2xl bg-background dark:bg-popover p-5 space-y-4`, 바깥 클릭 닫기). 주식은 기존 deleteTarget 분기 재사용. 잔액 미리보기 줄·`deleteFloored` 줄 **없이** 본문 1줄.
- 제목 `기록 삭제`(`text-base font-bold`), 본문 `text-sm text-muted-foreground text-pretty break-keep`:
  - 현금·대출: `이 기록만 지워요. 잔액은 그대로예요`
  - 주식·코인: `이 기록만 지워요. 보유 수량은 그대로예요`
- 버튼: 우측 정렬 `flex gap-2 justify-end` — `취소`(`variant="secondary"`) · `삭제`(`variant="destructive"`, 삭제=의미색 예외). 기본 Button 높이 40px 이상 확인(기존 창과 동일 `size` 기본값 사용, 축소 variant 금지). 확인 버튼이 오른쪽·마지막, 포커스 초기 위치는 `취소`(안전 쪽), Esc 닫기.
- 반영 거래 삭제 창과 구분: 제목 `반영된 기록 삭제`(잔액 되돌림) vs `기록 삭제`. 한 창에 두 문구 동시 노출 금지.
- 모션: 기존 창과 같음(추가 모션 0). `confirm(` 4개 view 0.
- testId: `tx-delete-confirm`(패널), `tx-delete-confirm-cancel`, `tx-delete-confirm-ok`.

## 4. 연 결산 '꺼낸 돈'
- 이름은 `income < 0`일 때만 `꺼낸 돈`, 0·양수는 `넣은 돈`(copy 상수에서 분기, 행 마크업 불변). 행 = 기존 `YearGroupRow`(`flex min-h-10 items-center justify-between gap-3`).
- 금액: `signed()` 그대로 `−300만`(U+2212), 색은 기존 `getProfitLossColor(amount)`(음수=파랑, 다크 값은 5.148 B1과 동일 토큰). `tabular-nums` 유지, 우측 정렬. 이름 열에 `min-w-0`, 이름은 `whitespace-nowrap` → 320에서 `꺼낸 돈 ⓘ`와 `−300만`이 한 줄, 금액이 길면(`−1억 2,300만`) 이름 쪽 InfoHint 아이콘이 줄바꿈 대신 `shrink-0` 유지.
- 도움말(`incomeHint`)·`help` 문장의 `넣은 돈` 호칭도 현재 보이는 이름과 일치, `data-screenshot-hide` 유지. 결론 문장 `넣은 돈 N%`는 양수일 때만(변경 0).
- 연타·전환: 연 이동 시 이름만 바뀌고 행 재마운트 없음 → `ROW_ENTER` stagger 재생은 첫 마운트 때만(키는 testId 고정 `year-settle-group-in`, 이름 변경으로 key 바꾸지 않음).
- 접근성: 행에 별도 aria 추가 없음(텍스트가 이름·값). InfoHint 히트 40px는 기존.
- testId: 기존 `year-settle-group-in`(+`data-value`) 유지, 이름 텍스트 확인용 `year-settle-group-in-name` 신규(이름 span).
