## 2. ② 비중 범례 압축 · 행 비중
### 2-1. 범례·바 규칙(`StockCategorySection`, 인증카드 분기 불변)
- 새 prop은 `legendMax?: number`다. **screenshotMode가 아닐 때만** 쓴다. StockTab이 `legendMax={4}`를 넘긴다. 인증카드는 기존 `maxItems=7` 경로를 그대로 쓴다(SHOT 토큰·theme-shot 스냅숏 diff 0).
- 해당 탭의 종목 수를 N(barItems 수)이라 하면 N ≤ 4일 때는 지금과 같고(전부), N ≥ 5일 때는 상위 3 + `그 외 {N−3}종목 {합 %}`이다. **이미 있는 `barShown`/`barRest`/`restPct`/`ETC_COLOR` 경로를 재사용**한다(새 계산·색 0). 정렬은 barItems 순서(평가금 순, #288 R1)라서 범례 상위 3 = 목록 위 3행이다.
- **비중 바도 같은 4구간**으로 그린다(색 3개 + 회색 `그 외`). 바의 모든 색에 범례 칸 하나가 대응해야 하기 때문이다. 4구간이면 `displayShareWidths`의 최소 폭 보장(≤5)이 적용되어 작은 종목도 보인다.
- `그 외` 칸은 색점 `ETC_COLOR #9ca3af`, 글자 `text-muted-foreground`, % `font-bold text-muted-foreground`다(기존 마크업 그대로). 칸 높이·글자는 다른 칸과 같다(모바일 `text-sm`, 768~1279는 기존 15 규칙).
- **누름 없음.** 범례는 지금처럼 정적 div다. `전체 보기`나 펼치기를 두지 않는다. 바로 아래 목록에 모든 종목이 같은 순서로 있고, 각 행에 비중 %가 생기므로(2-2) 숨는 정보가 0이다. 접기·저장 키는 쓰지 않는다(11-18 피로, C151).
- 카테고리 탭을 바꾸면 N과 `그 외`를 그 탭 기준으로 다시 계산한다. 1종목이면 1칸이다.
- 바 조각의 기존 `transition-all`(§6 위반)은 이번 범위 밖이다. 건드리지 않는다.

### 2-2. 모바일 행 비중 % 위치(`StockRowHeader`, `!screenshotMode`만)
- 지금은 `·` span과 % span이 따로 있고 둘 다 `max-sm:hidden`이다. 이것을 **조각 하나로 합치고 모든 폭에서 보인다.**
  ```
  meta: `${cardInfoMeta} flex-wrap ${DOT_WRAP_ROW}`(!screenshotMode면 늘)
  수량: `${qtyCls} text-foreground tabular-nums whitespace-nowrap ${DOT_WRAP_FIRST}`
  비중: <span data-testid="stock-row-share" className="whitespace-nowrap text-sm font-semibold text-primary tabular-nums"><DotLead />{pct}%</span>
  결정: 기존 stock-row-decision 그대로(뒤에 옴)
  ```
- 순서는 `수량 · 비중 · 점검 차례`로 PC와 같다(§5 '접힘행 왼쪽 = 이름·비중%'). 조각은 nowrap이고 조각 사이에서만 줄이 바뀐다(C152). 줄 머리·끝에 `·`가 남지 않는다(dot-wrap).
- 인증카드(screenshotMode)에서는 지금처럼 %가 없다. 결정 표시 규칙(390 미만에서는 차례만)도 그대로다.
- PC(≥640)의 같은 줄 간격은 `·` span(gap 4 + 4)에서 DotLead로 바뀌며 약 ±2px 달라질 수 있다. ui-review는 1280에서 확인한다. 오늘 등락 칩이 DOT_WRAP_ROW clip(위아래 −2px) 안에서 잘리지 않는지도 1280에서 본다. 기존에도 결정이 있는 행에서는 같은 조합이었다.

### 2-3. 행 높이 변화(C160 — 의도된 증가 구간)
데모 6종목, 다크, 행 높이 기준. 라이트는 오른쪽 열 폭 차이로 경계가 ±1 단계 다르다.

| 360~374 | **두 자리 이상 수량 행 +24**(왼쪽 메타 폭 84~92px < 수량+비중 93px). 의도된 증가 | 차례 행 +24 |
