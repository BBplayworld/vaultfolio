### 수정 요청
**R1. `stock-tab.tsx` StockCategorySection 범례 `stock-legend-rest` 이름 span**
- 현상: 320에서 `그 외 3종목`이 `그 외 3…`으로 잘려 종목 수가 보이지 않는다. 라이트·다크 같다(`crop-320-light.png`). 실측 칸 폭은 128px이고 필요한 폭은 134px이다(점 10 + gap 4 + 이름 73 + gap 4 + % 43). 340 이상에서는 잘리지 않는다.
- 원인: `그 외` 칸이 생긴 것은 5.171이 처음이다(main 일반 화면에는 `그 외`가 없었다). 고정 문구인데 상위 칸 이름과 같은 `truncate`를 쓴다.
- 기대값:
  - ① `그 외` 이름 span에서 `truncate`를 빼고 `whitespace-nowrap shrink-0`으로 바꾼다. 상위 3칸 이름은 그대로 `truncate`를 쓴다.
  - ② 일반 화면 범례 격자에 `max-[359px]:gap-x-2`를 더한다. 인증카드 `ASSET_THEME_SHOT.legendGrid`는 건드리지 않는다.
  - 결과: 320에서 칸 폭이 132가 되고 넘치는 폭은 2px 이하다. 이 2px는 격자 `px-2` 안에 들어가므로 비중 바 오른쪽 끝을 넘지 않는다. 가로 넘침은 0이다.
  - 판정 기준: 320·360·375 × 라이트·다크에서 `stock-legend-rest`의 textContent에 `그 외 3종목`이 보인다(scrollWidth ≤ clientWidth). rest 칸 오른쪽 끝 ≤ 비중 바 오른쪽 끝. 인증카드 스냅숏 diff 0.
