- 버튼 상자 91.7×20(390·320, 14px) / 104.3×20(1280, 16px). 줄 전체 폭 211.7 / 240.
- **히트 40px 비대칭**: 위 6(문장 글자 아래 여백 3px만 겹침) · 아래 14 · 좌우 8 → 107.7×40. 히트 아래끝 = 도넛 조각 위끝 −2px(390: 290 vs 292, 320: 314 vs 316) → **도넛과 겹침 0**. 대칭 10/10은 도넛 머리 6px을 덮어 탈락. 두 버튼 히트 사이 간격 4px(겹침 0).
- C130 nowrap 조각: 버튼 2개 `whitespace-nowrap`(자연) 최장 91.7 ×2 + 점 20 = 211.7 ≤ 320 글자 영역 296. 문장은 줄바꿈 허용(`break-keep text-balance`)이나 320에서도 1줄.
- 1280: 분포 카드 폭 580 가운데. 폭과 무관하게 **항상 2줄**(1줄 배치 D안은 폭마다 꼴이 바뀌고 문장·동작 위계가 흐려져 탈락, `c250-03`).

## 4. 인터랙션 · 모션
- `현금 추가하기` → `open-add-asset-sheet {category:"cash"}` → FAB 시트 **`현금성 자산 추가`** 방법 선택(스크린샷 가져오기 / 직접 입력) — 허브 0건 카드와 같은 화면(`04-cash-sheet-start-390` ↔ `04-hub-cash-sheet-390`). 대출은 `대출 추가`(`04-loan-sheet-start-390`).
- 잔액 맞추기 시작 화면(`현금성 자산 업데이트` · `계좌별 잔액 고치기`, `04-cash-sheet-has-cash-390`)은 현금 1건↑에서만 열린다 → 블록은 현금 0건에서만 보이므로 **이 블록에서 닿지 않음**(비교용 캡처).
- 진입 모션 없음: 블록은 필터와 같은 시점(데이터 로드 직후)에 대시보드 컨테이너의 기존 `animate-in`과 함께 나타난다. 블록↔필터 교체는 시트가 덮은 동안 일어나므로 전환 애니메이션을 두지 않는다(재마운트로 사라질 모션 없음). Hero 카드·도넛은 같은 노드 유지.
- 연타: 같은 이벤트 2회 → 시트 1개(기존 `openSheet` 멱등) — qa 확인. 누름 피드백 `scale 0.96`·reduced-motion은 즉시.
- 도넛 조각·범례 누름 → 상세·주식(코인). 그 외 도넛 모양·라벨 변경 0.

## 5. 접근성
- 두 버튼 `<button type="button">`, 이름 = 보이는 글자(aria-label 불필요). 탭 순서: Hero 카드 버튼들 → `현금 추가하기` → `대출 추가하기` → 7일 카드. 포커스 링 전역 `outline-ring/50`(+`rounded-sm`).
- 가운뎃점 `aria-hidden`. 문장은 `<p>` — 스크린리더가 문장 → 버튼 순으로 읽는다.
- 대비: 다크 indigo-300 / 배경 #0B0D12 ≈ 9:1, 라이트 brand #5b6fbf / #F0F2F4 ≈ 4.6:1(허브와 같은 토큰), 문장 muted는 기존 설명 문장과 같음(`02-light`).
