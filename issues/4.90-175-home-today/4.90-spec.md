# 4.xx #175 홈 '오늘' — spec (planner-designer)

기준 코드: origin/main 1fb7482 + origin/issue-4.89 f33e6a1(`home_cause_open` 계측, '홈 변동 원인 열기'). 4.89 머지 후 main에서 분기한다. 정본: direction 합의 절(+오케스트레이터 정정), tech-review, ui.md. 이 문서가 셋과 다르면 이 문서가 우선한다(바뀐 점은 각 절에 **[결정]**으로 표시).

## 1. 문제
홈 활성 27명 대부분이 홈만 보고 나간다(성과 7, 시장과 비교 0). 홈에서 '오늘'을 알려 주는 것은 금액 한 줄뿐이다. 원인은 14px 쉐브론 뒤에 접혀 있고, 7일 막대는 눌러도 이동하지 않는다.

## 2. 목표 행동
① Hero 아래 지수 종가 줄을 읽고, 누르면 시장과 비교 '하루'로 간다. ② 가장 큰 원인 1개를 탭 없이 읽고, 누르면 목록이 펼쳐진다. ③ '전체' 탭의 7일 카드를 누르면 성과 › 자산 변화 › 전체·주로 간다.

## 3. 범위
- 포함: A 지수 종가 1줄, B 가장 큰 원인 1줄(쉐브론 대체), C 7일 카드 버튼화(+5% 표시·pulse·글로우·주황 막대 제거), 기능 팁 '시장과 비교' 억제, 시장과 비교 '하루' init(메모리), GA 값 2개.
- 뺀 것: 가장 움직인 내 종목, 장 마감 요약 화면, '오늘'·'실시간' 표기, 스트릭·접속 일수, 홈 팁 위치·우선순위, Hero 금액·원인 계산, 7일 막대 값, 자산 변화·시장과 비교 화면 레이아웃, 기존 시장 타일(`MarketTileValue`)의 휴장 표기(9절 후속).
- 저장 키·스키마·마이그레이션·동기화·공유 토큰·자산 값 서버 전송: **0**.

## 4. 사용자 흐름
1. 홈 진입 → Hero(순자산·전일 대비) 바로 아래 B 줄 `주식 시세 하락 −1,096만원 외 2개 ⌄`.
2. B 줄 탭 → 줄이 사라지고 그 자리에 기존 원인 목록이 열린다(같은 값 두 번 노출 0). 포커스는 패널로 간다. 목록 맨 아래 `접기 ⌃` → 닫히고 포커스는 B 줄로 돌아온다.
3. Hero 아래(8px) A 줄 `11/11 종가 코스피 +0.8% · S&P 500 −0.3% ›` 탭 → 시장과 비교, 목록 기간 '하루' 선택 상태로 도착(표 '하루' 행 지수 열 = A 값).
4. 뒤로 → 홈(기존 뒤로 동작). 도착 화면에서 기간을 바꾸는 것은 저장되지 않는다(새로 들어오면 다시 '1주', 홈에서 오면 '하루').
5. '전체' 탭 7일 카드(스냅샷 ≥2) 탭 → 성과 › 자산 변화, 범위 전체·기간 주로 도착.

## 5. 문구 확정표
**A 지수 종가 줄** (날짜 = 각 지수 구간의 실제 끝 날짜 `endDate`, `monthDay` 재사용 `M/D`; 부호 `formatCompareRate`; 손익색·평가어·'오늘'·'실시간' 금지)
| 상태 | 문구 |
|---|---|
| 두 시장 날짜 같음 | `11/11 종가 코스피 +0.8% · S&P 500 −0.3%` (날짜·`종가` 앞에 1번) |
| 날짜 다름 | `11/12 종가 코스피 +0.8% · 11/11 종가 S&P 500 −0.3%` — 폭이 모자라면 둘째 시장을 숨김: `11/12 종가 코스피 +0.8%` |
| 한 시장(보유 또는 조회 성공이 1개) | `11/11 종가 S&P 500 −0.3%` |
| 그 시장 휴장 | 값 대신 `휴장`: `11/26 종가 코스피 +0.4% · S&P 500 휴장`. 같은 날짜 묶음의 모든 시장이 휴장이면 `종가` 생략: `11/26 S&P 500 휴장` |
| 로딩(분류 전 포함) | 값 자리 스켈레톤(20px 예약), 문구 없음 |
| 두 지수 모두 조회 실패 | `지수와 나란히 보기` (기존 문구, 입구 유지) |
| 폭 < 첫 시장 전체 표기 기준(320 등) | 둘째 시장 숨김 `11/11 종가 코스피 +0.8%` |

- **[결정 ①] 날짜 다름의 모바일 표기에서 `종가`를 생략하지 않는다.** ui.md안(`11/12 코스피 +0.8% · 11/11 S&P 500 −0.3%`) 기각. 근거(C80): A 줄 바로 위 순자산 라벨에 `실시간` 배지(`showRealtimeBadge`)가 붙어 있다. 그 아래 날짜만 있는 `11/12 코스피 +0.8%`는 16시 이후 당일에 '지금 값'으로 읽힌다. 날짜만으로는 종가라는 사실이 전달되지 않는다. 같은 줄이 아침엔 `종가`, 저녁엔 무표기가 되면 둘이 다른 값처럼 보인다. 대신 폭이 모자라면 둘째 시장을 숨긴다(320 규칙과 같은 장치). 숨긴 시장은 도착 화면에 있다. 날짜 다름은 비기본 설정(`kstAccessDay`)의 16:00~익일 07:00(DST 06:00)에만 생긴다. 기본(`sameBusinessDay`)은 두 시장 기준일이 같아 늘 첫 행이다(7절).
- **[결정 ④] 320 둘째 시장 숨김 수용.** 4.88 `restBelowSm` 선례와 같다. 컨테이너 쿼리(`@container`)로 처리하고 JS 측정은 금지한다. 임계값은 표기 형태별로 '전체 문구+쉐브론'의 실측 폭이며 ui-review가 375·360·320에서 다시 잰다. 줄은 `whitespace-nowrap overflow-hidden`이고 2줄은 금지한다. 숨긴 상태에서도 문구는 '보유 시장 전부'를 말하지 않으므로 C91에 걸리지 않는다.
- **[결정] 휴장 표기 추가.** 휴장일에는 지수 구간이 0.0%가 된다(`refHoliday`면 명목일·직전 종가). 도착 화면은 같은 칸에 `휴장`을 띄운다(`computePeriodCell` 휴장 판정). 홈이 `0.0%`를 보이면 A11·C65에 걸린다. 머지 다음 날인 **11/27(금) 오전이 미국 추수감사절(11/26) 휴장 다음 날**이라 바로 발생한다. 판정식 `period==="daily" && (!isBusinessDay(m,endDate) || startDate===endDate)`을 순수 함수 `isDailyIndexHoliday`로 꺼내 `computePeriodCell`과 A가 함께 쓴다(값 계산 불변).
- 접근성: 버튼 `aria-label="시장과 비교 하루 보기, {숨긴 시장 포함 전체 문구}"`. 화면에 보이는 문구를 포함한다.

**B 원인 줄** — **[결정 ②] 문구 = 기존 `c.label` + `c.text` 그대로**(목록 행과 같은 문자열, `dateLabel`은 줄에서 생략). `주로`·`대부분` 등 비중 단정어 금지: 최대 원인이 절반 미만일 수 있다.
| 경우 | 표시 |
|---|---|
| `causes.length ≥ 2` | `[예측] 주식 시세 하락 −1,096만원 외 2개 ⌄` (`외 N개`, N = `causes.length−1`, 360 미만 숨김) |
| `causes.length = 1` | `현금 입금 +500만원 ⌄` |
| `causes.length = 0` 이고 `hasCause` | B 줄 없음, **현행 쉐브론 유지**(패널 = 예측 칩·rangeLabel·기록) |
| `negligible` | B 줄·쉐브론 없음, 현행 `{label} 변동 없음` |
| `screenshotMode` | B 줄·접기 없음, 현행대로 전부 펼침 |
- 대상: `|amount|` 최대. 동률이면 `sortCausesByDate` 순서에서 앞에 있는 항목. 순수 함수 `pickTopCause`.
- 예측 칩은 `change.estimated`일 때 줄 앞에 붙는다. 펼치면 패널 칩으로 대체돼 두 번 보이지 않는다.

**[결정 ③] 접기·포커스**
- 패널 맨 아래 `접기 ⌃` 줄(높이 40px, `text-sm text-muted-foreground`)은 **B 줄이 있을 때만** 둔다. 쉐브론 경우(원인 0개)에는 쉐브론이 그대로 닫는 수단이다.
- 펼침 직후 포커스는 **패널 컨테이너**(`role="region" aria-label="변동 원인" tabIndex=-1`, `preventScroll`)로 간다. ui.md안(`접기`로 이동)은 바꾼다. 맨 아래로 보내면 스크린리더가 목록을 건너뛰기 때문이다. Tab 순서는 패널 → 기록 목록 안 버튼 → `접기`이다.
- 접힘 직후 포커스는 B 줄 버튼으로 간다. 단 포커스가 패널 안에 있었을 때만 옮긴다.
- B 줄 `aria-expanded`·`aria-controls="home-cause-panel"`, `aria-label="변동 원인 펼치기, {라벨} {금액}{ 외 N개}"`. 접기 `aria-label="변동 원인 접기"`.
- 줄과 패널은 항상 마운트하고 grid-rows 200ms로 전환한다(ui.md 3절).

**C 7일 카드**
- 스냅샷 ≥2이면 카드 전체가 버튼이고 머리 줄 끝에 `›`가 붙는다. `aria-label="순자산 추이, 자산 변화 주 보기"`.
- **[결정] 제목의 사실성(C84).** 현재 제목 `최근 {N}일`의 N은 일 수가 아니라 기록 개수다. 띄엄띄엄 접속하면 기록 7개가 20일에 걸쳐도 `최근 7일`로 나온다. 도착 화면 Hero `최근 7일`은 달력 7일이다. 같은 이름이 서로 다른 양을 말하게 되므로 이렇게 바꾼다.
  - N개 기록이 연속된 날짜(`첫~끝 = N−1일`)면 현행 `순자산 추이 (최근 N일)` 그대로.
  - 연속이 아니면 `순자산 추이 (최근 기록 N일)`.
  - 매일 접속자의 diff는 0이다. 순수 함수는 `weekTrendTitle(snapshots)`이다.
- 0개 스냅샷은 현행 안내 문구를 유지한다. 1개 스냅샷은 현행 `하루 더 쌓이면…`을 유지한다. 둘 다 버튼이 아니다.

## 6. 노출 조건 진리표 (A 노출 = 팁 억제의 단일 함수 `marketLineState` → `"on" | "pending" | "off"`)
| screenshotMode | headerChange | hasTickerStock | markets | A | 팁 '시장과 비교' |
|---|---|---|---|---|---|
| true | * | * | * | off | 해당 없음(홈 아님) |
| false | null(첫 저장 당일) | * | * | off | 후보 유지 |
| false | ≠null | false | (조회 안 함) | off | 후보 유지(4.87 보유 필터가 이미 제외) |
| false | ≠null | true | null(분류 전) | pending: 스켈레톤 줄, 탭 가능 | **억제** |
| false | ≠null | true | [] | off(줄 제거) | 후보 유지 |
| false | ≠null | true | ≥1 | on(값·휴장·실패 문구) | **억제** |
- **[결정] pending도 억제한다(tech-review 수용).** direction 합의 5의 "분류 전 억제 안 함"을 대체한다. 깜빡임 처리는 tech-review에 위임돼 있었다. 팁이 떴다 사라지는 일과 `홈 팁·view` 이중 발화를 막는다. 분류 결과가 `[]`이면 억제를 풀어 입구 0을 막는다(드문 경우 팁이 늦게 나타나는 것 허용).
- 지수 요청 게이트: `headerChange !== null && hasTickerStock`. 종목 마스터(`useKospiPeerCodes`)도 같은 게이트를 적용한다.
- B·C 신규 표시도 `headerChange !== null`(B는 원래 change에 종속, C는 스냅샷 ≥2 = 오늘 이전 기록 존재). 첫 저장 당일 홈 diff는 0이다.

## 9. 엣지 케이스
- 첫 사용자·첫 저장 당일: A·B·C 신규 표시 0. 웰컴·첫 저장 흐름 diff 0.
- 일부 갱신: 한 지수만 조회되면 그 시장만 보이고 실패 시장은 표기하지 않는다(도착 화면이 `시장 값을 불러오지 못했어요`). 둘 다 실패하면 `지수와 나란히 보기`.
- 오래된 데이터: 라벨은 데이터의 `endDate`를 따르므로 홈을 16:00·07:00을 넘겨 열어 두어도 날짜가 값과 어긋나지 않는다. 토큰이 바뀌면 재조회(react-query 키 공유).
- 원인: 최대 원인이 목록 첫 행이 아닐 수 있다(시세 우선 정렬). `기록 안 된 변화`가 최대여도 그대로 표기한다. 라벨이 길면 말줄임 처리하고, 금액·쉐브론은 자르지 않는다.
- 후속(이번 범위 밖, 주간 후보): 자산 변화·상세 시장 타일 '하루'가 휴장일에 `0.0%`를 보인다(도착은 `휴장`). 시세 지연으로 시작=끝이면 도착 화면이 `휴장`으로 표기하는 기존 규칙. 320에서 7일 막대 값 라벨 2줄(ui.md).
