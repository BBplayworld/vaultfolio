## 4. 항목별 설계

**A 시장 종가 1줄**
- 노출 = `shouldShowMarketLine`: `!screenshotMode && hasHeaderChange && hasTickerStock && (markets === null → pending | markets.length ≥ 1)`. A 컴포넌트와 팁 억제가 이 함수 하나를 부른다.
- 라벨: `values[i].endDate`(= API refDate = `getDailyClosingRefDates` 결과, 휴장이면 실제 종가일)를 `monthDay`로. 두 시장 날짜가 같으면 앞에 1번(`11/11 종가 코스피 +0.3% · S&P 500 −0.2%`), 다르면 시장별(`코스피 11/12 종가 … · S&P 500 11/11 종가 …`). 360px 1줄 넘으면 ui 판단(단일 라벨 폴백은 이미 날짜 같을 때의 형태).
- 로딩: 스켈레톤 줄(자리 유지, 높이 점프 0). 로딩 후 `values.length===0`이면 `지수와 나란히 보기`(MarketTileValue 문구 재사용). 줄은 버튼(히트 40px), 클릭 시 `track("feature_use",{category:"home_market"})` → `navigate({type:"activity",tab:"change-market",init:{period:"day"}})`.
- 기능 팁과 달리 A는 항상 `daily`이므로 `linkOnly`·ytd 경로 불필요.

**B 가장 큰 원인 1줄**
- `top = causes.reduce((a,c)=> |c.amount| > |a.amount| ? c : a)`(동률은 앞 항목 유지 = 기존 정렬 순). 순수 함수 `pickTopCause(causes)`를 `lib/report/asset-report.ts` 옆(또는 dashboard 상단)에 두고 단위 테스트. 표기 `{label} {text}` + `외 N개`(N = causes.length−1, 0이면 생략; ui가 빼도 됨).
- 경우표: ① negligible → 줄 없음(기존) ② `causes.length>0` → B 줄이 쉐브론 대체, 펼치면 B 줄 숨기고 목록 ③ `causes.length===0 && hasCause` → 현행 쉐브론 유지 ④ screenshotMode → 전부 펼침(현행).
- 4.89 `홈·원인 펼침` 계측: 같은 `setCauseOpen` 토글 핸들러에 붙어 있을 것이므로 그 핸들러를 그대로 B 줄·③ 쉐브론이 공유(`onToggleCause` 1개). 이벤트·파라미터 변경 0.
