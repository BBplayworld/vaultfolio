# 4.44 UI 사양 v2 (#75 / PR #76) — 대표 반려 반영 재설계

작성: ui-designer. 근거: design-system §3(반경·고도)·§6(모션)·§7, 성과 SECTION(`rounded-xl bg-card p-4 space-y-3 dark:shadow-sm`), 4.42 다크 톤(bg #0B0D12 / card #191C22 / popover #24282F / muted #2D3038).
이전 사양(3단계 면: background < card < popover, 항목별 면)은 **폐기**. 원인: 항목마다 면을 달리 줘 "검은 well"과 모서리 불일치가 생김(지적 1~3).

## 0. 핵심 원칙 (다크, 상세 전 영역 공통)
1. **리스트 영역 전체 = card 면 1장.** 항목(행)·펼침부·액션줄·메타줄은 **배경 없음(투명)**. 항목 구분은 헤어라인(`divide-border/40`)과 간격만.
2. 면은 2단계만: 페이지 `background` < 박스 `card`. 박스 안에서 한 단 더 올릴 때(증권사별 타일)만 `popover`. **`background`(검정)를 박스 안쪽에 쓰지 않는다.**
3. 모서리: 박스 `rounded-xl`(16)+`overflow-hidden` → 마지막 항목을 펼쳐도 하단 좌우가 박스 곡률로 잘린다(지적 1). 안쪽 타일은 동심 `rounded-lg`(12), 박스 가장자리와 12px 띄움.
4. 상단 요약 박스(`detail-summary-header`, 각 탭 요약, X-Ray, 거래 요약)도 **같은 면(`dark:bg-card dark:rounded-xl dark:shadow-sm`)** 으로 통일 → "상단 BOX = 리스트 BOX"(지적 3). 현재 `bg-primary/10`(라이트 토큰 `primary.bgLight`)은 다크에서 `dark:bg-card`로 교체(`screenshotMode`는 기존 `boxCls` 유지).
5. **라이트 모드: 상세 영역은 무변경.** 모든 상세 변경은 `dark:` 접두 또는 신규 `dark:` 전용 토큰. (자산 구성 변화 차트만 라이트·다크 공통 적용 — §3)

## 2. (a) 상세 5탭 BOX 구조 (주식·가상자산·부동산·현금·대출)
```
[요약 박스 card]  ← 총 평가금액 등 (rounded-xl)
(gap-5 / 20px)
[카테고리 칩 탭]  ← 맨 배경 위, 면 없음
[listBox card rounded-xl]
 ├ 항목1 헤더 (px-4 py-3) ─ 이름·금액·손익, chevron
 │   └ 인셋 비중 바 (mx-4, 2px, rounded-full)
 ├ ───── 헤어라인(border/40, 전폭) ─────
 ├ 항목2 [펼침]
 │   헤더 / 비중 바
 │   펼침부 (면 없음, 행 사이 헤어라인 border/30)
 │     · 종목명·티커 줄 (px-4 py-2.5)
 │     · 상세 그리드 (px-4 py-2.5)
 │     · 거래입력/거래내역 버튼줄 (px-4 py-2, 버튼 h-8→히트 40: py-1 보정)
 │     · 액션 아이콘줄 (justify-end px-4 py-2)
 │     · 증권사별 항목 (분할 종목만)
 │         라벨 "증권사별 항목" (text-sm muted px-1)
 │         [타일 popover rounded-lg] × N, 간격 8px, 좌우 12px 띄움
 │            타일 헤더 (px-3 py-2.5) → 펼치면 타일 안 펼침부(면 없음, 헤어라인)
 │     · 메타줄(보유·매수일, pb-3)
 ├ ───── 헤어라인 ─────
 └ "그 외 N종목"(주식 탭, 마지막 행, chevron 자리 spacer 유지)
```
- 항목 배경 클래스(`bg-muted/..`, `bg-popover`, `bg-background`)를 항목·펼침부·액션·메타 어디에도 쓰지 않는다(`dark:`). 
- 카테고리 탭이 있는 탭(부동산·현금·대출)은 **카테고리별 listBox 1개**, 제목은 박스 밖 `text-sm font-semibold px-1 mb-2`.
- 개별 행 타일로 흩어진 곳 통합: 대출 탭 "완납된 대출"(`rounded-lg bg-muted/20 dark:bg-card` 행 N개) → `listBox` 1개 + 행 `px-4 py-3` 헤어라인. 타일 간 `space-y-2` 제거(다크).
- 모서리 규칙: 박스 16 / 증권사 타일 12 / 비중 바·뱃지 full. 펼친 마지막 항목 하단은 박스 overflow-hidden이 책임(항목 자체 radius·bg 없음).
- 펼침 모션: 기존 Collapsible 유지, chevron 180° 200ms, `motion-safe` 외 즉시. 열림/닫힘 시 박스 높이만 변하고 면 색 전환 없음.
- 상태: 빈(항목 0)=박스 없이 기존 안내문; 항목 1개=박스 내 단일 행(헤어라인 없음); 긴 이름=truncate, 금액줄 `tabular-nums`; 상장폐지/비활성 배지는 기존 위치.

## 4. (c) 성과 > 자산 구성 변화 차트 재설계 (`composition-card.tsx`, `composition.ts`)
라이트·다크 **공통 적용**(대표 지적 5는 모드 무관). 카드 외피 `SECTION`·헤더·문장(`composition-sentence`)은 유지.

**레이아웃** (카드 내부 폭 W = 375px에서 319, 1280px에서 카드 폭 그대로)
- 차트 영역 높이 H: `h-44`(176) / `sm:h-52`(208). 기존 h-20(80) 대비 2.2배. 카드 하단 빈 공간을 막대·리본이 채움.
- 칸 영역(zone) = W/n(그리드 `repeat(n,1fr)`), 막대 폭 `barW = clamp(zone×0.55, 14, 72)`px. 3칸@375: 막대 58·리본 폭 약 48 / 5칸: 35 / 13칸: 14(리본 폭 약 10). 막대는 zone 중앙. 
- 폭 측정: `ResizeObserver`로 W 측정(SSR 폴백 319), 기하는 px 계산.
- 막대: 자산군 세그먼트 `flex-col-reverse`(부동산 아래, 현행 순서 유지), 세그먼트 사이 2px, 세그먼트 `rounded-[4px]`. 빈 칸(`cell.empty`)은 점선 막대 높이 100%·opacity 40%, 리본 없음.
- **연결 리본**: 막대 뒤 단일 `<svg>`(absolute inset-0, aria-hidden). 인접한 두 값 있는 칸 사이, 자산군별로 왼 막대 세그먼트 우측변→오른 막대 세그먼트 좌측변을 잇는 cubic bezier 면(제어점 x = 두 막대 사이 중점). 색=자산군 색, opacity 0.16(선택 칸에 닿은 리본 0.30). 자산군이 한쪽에 없으면 폭 0 쪽으로 수렴(삼각) 처리. `transition-opacity 150ms`.
- 기준선: 차트 하단 헤어라인 `border-border/60`. 눈금선·Y축 없음(보정 스케일에서 눈금은 오해 소지).

**표시용 보정 스케일 규칙** (실제 비중 아님, 높이 전용)
1. 모드 결정(차트 전체 1회): 값 있는 칸 중 `0 < 비중 < 10%` 자산군이 하나라도 있으면 `corrected`, 없으면 `linear`(선형, 캡션 없음). 한 차트 안에서 칸마다 스케일을 바꾸지 않는다.
2. corrected 계산: `w_k = √r_k` → `d_k = w_k / Σw × 100` → 기존 `compositionDisplayRatios(d, 7)`로 최소 7% 바닥 적용(H=176에서 12px 이상). 신규 함수 `compositionDisplayScale(ratios, mode)`로 노출, `COMPOSITION_MIN_DISPLAY_PCT=7` 재사용.
   - 예) 95/3/1/1 → 표시 약 72/13/7.4/7.4. 3%→1% 변화가 13%→7%로 보임.
3. 숫자·문구·aria는 **항상 실제 비중**(기존 `describeCompositionCell`/`compositionCellAria` 불변). 막대 세그먼트 `data-ratio`(실제)·`data-display`(표시) 부착.
4. 막대 안 % 표기: 세그먼트 표시 높이 ≥18px이고 `barW ≥ 40`(대략 n≤5)이면 실제 % 정수를 `text-xs font-semibold tabular-nums`, 색 `pickOnColor(색)`. 그 외(6칸 이상)는 **선택 칸의 세그먼트만** 표기. 작은 세그먼트는 숨김(범례·선택 줄이 정본).
5. **보정 고지 캡션**(corrected일 때만, 차트 아래): "막대 높이는 변화를 보기 쉽게 보정했어요. 실제 비중은 숫자로 확인해 주세요" — `text-xs text-muted-foreground text-pretty break-keep`.

**3칸·13칸 동작**
- 2~4칸: 막대 폭 최대 72, % 항상 표기, 리본 넓게(변화 흐름이 주인공). 5~8칸: 막대 28~40, 선택 칸만 % 표기. 9~13칸: 막대 14~20, 리본 얇게, 월 라벨 격칸(현 `compositionLabelVisibility` 재사용), 11px.
- 13칸에서도 가로 스크롤 없음(오버플로 금지).

**선택 상태·입력**
- 기본 선택=마지막 칸(이번 달). 선택 칸: 막대 opacity 100, 나머지 55; 선택 칸 뒤에 후광 `rounded-xl bg-muted/40 dark:bg-muted/30`(zone 폭 전체, H 전체); 월 라벨 `font-semibold text-foreground`.
- 입력: 칸=`<button>`(zone 전체가 히트영역: 높이 H+라벨, 폭 W/n). 탭·hover·focus로 선택(현행), **드래그/스크럽**(pointer move로 가장 가까운 칸 선택, `touch-action: pan-y`), ←/→ 키로 이동(roving). `focus-visible` ring 2px.
- **히트영역 40px**: 칸 폭 W/n이 40 미만(375에서 9칸 이상)이면 스크럽 면 전체(폭 W×높이 H+라벨)를 하나의 조작 표면으로 간주해 예외 허용(§7 근거: 인접 목표가 아닌 단일 슬라이더형 조작). 8칸 이하는 칸 폭 ≥ 40 보장.
- 선택 줄(`composition-selected`, aria-live)·범례는 현행 위치/문구 유지. 범례 점 `size-2`→유지.

**모션**: 마운트 시 막대 `motion-safe:animate-in fade-in slide-in-from-bottom-2 duration-300`, 칸당 `animation-delay: idx×25ms`(최대 325ms). 선택 변경은 opacity 150ms만(재마운트 없음: `key=month` 유지, 막대 높이 `transition-[height] duration-300`로 데이터 갱신 시에도 끊김 없음). `motion-reduce`는 즉시. 연타·드래그 중 방향 전환에도 상태가 `selected` 1개라 인터럽트 안전.

**상태**: hidden=null(현행), single=문구만(현행), bars 2칸=안내 "기록이 쌓이면 최대 13개월까지 보여요" 유지, 모든 칸 동일 비중=리본 평행 띠(정상). 자산군 1개만(100%)=세그먼트 1개·% "100%". 

## 5. (d) 라이트·인증카드 무변경 보장
1. 상세 변경은 전부 `dark:` 접두 또는 신규 `dark:` 전용 값. 비-`dark:` 클래스 변경이 diff에 있으면 라이트 영향 → 불허(차트 제외). 확인: `git diff main -- src | grep '^[-+]' | grep -v 'dark:'`로 비-dark 변경 줄 목록 점검.
2. `ASSET_THEME_SHOT`·`ASSET_THEME_SHOT_BIG`·`cardWrapper`·`cardInfo*`·`cardAmount*` **문자열 diff 0**. 공유 컴포넌트(`StockCard`/`StockRowHeader`/`StockCategoryList`)에서 새 다크 클래스(listBox, 비중 바 인셋, 요약 박스)는 `!screenshotMode`일 때만 부여(조건 분기, 현재 `listBox` 방식과 동일).
3. 검증(qa/Playwright): 같은 시드 데이터로 `main` vs 브랜치 (a) 인증카드 프리뷰 375·1280 × 라이트·다크, (b) 저장 PNG(`shotBig`) 캡처, (c) 상세 5탭 라이트 375·1280 — **픽셀 diff 0**. 차트(자산 구성 변화)는 인증카드에 쓰이지 않음(성과 연 탭 전용).
4. `theme.ts` 단위 스냅샷: SHOT 두 상수 JSON 동일성 테스트 1개.

## 7. 품질 체크리스트 (qa: 스크린샷·Playwright 판정, 다크 375·1280 기준)
1. 상세 5탭 각각 리스트 영역이 card 면 1장이며 항목 사이에 항목별 배경 차이가 없다(헤어라인만).
2. 마지막 항목을 펼친 상태에서 박스 하단 좌우 모서리가 박스 곡률(16px)로 둥글다(`overflow` 잘림 없음).
3. 주식 탭 증권사별 항목 영역에 `background`(검정) 면이 없고, 타일은 popover 1단 상승이며 타일 모서리 12px·좌우 12px 띄움.
4. 펼침부·액션줄·메타줄 배경이 투명(card와 동일 색)이며 마지막 줄 하단 패딩 ≥12px로 글자가 곡률에 닿지 않는다.
5. 상단 요약 박스와 리스트 박스의 배경색·radius·그림자가 동일하다.
6. 거래내역 화면: 종목 헤더·매수/매도 통계·거래 리스트 모두 card 면, 필터행은 면 없음, 거래 리스트는 1장 박스.
7. 가상자산·현금·대출 거래 화면과 X-Ray가 6과 같은 규칙, 거래입력 다이얼로그 이중 면 없음.
8. 대출 탭 완납 대출·현금 요약이 박스 규칙을 따른다(행별 타일 흩어짐 없음).
9. 라이트 모드 상세 5탭·거래 화면 스크린샷이 main과 픽셀 동일.
10. 인증카드 프리뷰·저장 PNG(라이트·다크)가 main과 픽셀 동일.
11. 자산 구성 변화 차트가 카드 폭 전체를 쓰고 높이 ≥176px(375), 3칸·13칸 모두 가로 스크롤 없음.
12. 95/3/1/1 데모 데이터에서 3% 세그먼트 표시 높이 > 1% 세그먼트 표시 높이이고 1% 세그먼트 ≥ 12px, 선택 줄·aria는 실제 %를 표기.
13. corrected일 때만 `composition-scale-caption`이 보이고, 모든 자산군 ≥10%이면 캡션 없음.
14. 인접 칸 사이 연결 리본이 보이고 빈 칸 쪽에는 리본이 없다. 선택 칸 리본이 더 진하다.
15. 8칸 이하에서 칸 버튼 폭 ≥40px, 9칸 이상은 드래그로 칸 선택 가능, ←/→ 키로 이동.
16. `prefers-reduced-motion`에서 마운트 애니메이션 없음, 선택 전환 시 막대가 재마운트로 깜빡이지 않음.
17. 라이트에서 차트 리본/후광 대비가 흰 카드 위에서 식별 가능.
