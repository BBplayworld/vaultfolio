## 2. 레이아웃 (카드 내부 폭 W: 375px=319, 1280px=카드 폭)
- 막대: 폭 100%, 높이 `h-10`(40) / `sm:h-12`(48), 외곽 `rounded-lg overflow-hidden`. 세그먼트는 `flex` 가로 배치, 폭 = 실제 비중 % **선형, 보정·최소 폭 없음**. 세그먼트 사이 `border-l-2 border-card`(첫 칸 제외)로 구분. 순서는 `COMPOSITION_KEYS`(부동산·주식·암호화폐·현금성) 왼쪽→오른쪽, 두 막대 동일 순서(리본 정합).
- 막대 사이 간격 = 리본 높이 `h-7`(28) / `sm:h-8`(32). 라벨↔막대 `gap-1.5`, 블록↔행 `gap-4`(카드 gap-3 + 블록 내부).
- 막대 안 % 표기 규칙: 비중 **10% 이상**이면 정수 %를 `text-xs font-semibold tabular-nums`, 색 `pickOnColor(색)` (319px 기준 10%≈32px로 "10%"가 들어감). 10% 미만은 막대 안 텍스트 없음.
- 작은 자산군(1~2%) 처리: 최소 폭을 주지 않는다(폭 왜곡 금지). 대신 (a) 행에 항상 색점+이름+수치가 있고 (b) 리본이 그 자산군 면을 얇게 이어줘 위치를 보여준다. 0.5% 미만이어도 행에는 "<1%"가 아니라 반올림 정수("0%" 방지: 반올림 0이면 `<1%`)로 표기.
- 리본: **유지(경량)**. 판단 근거: 대표 요구 "클릭 없이 변화가 바로 보이고 영역을 채우며 명확" — 두 막대만 있으면 자산군 경계 이동을 눈으로 대응시켜야 하지만, 같은 색 리본이 있으면 늘어난 자산군은 아래로 넓어지고 줄어든 자산군은 좁아지는 모양이 즉시 읽힌다. 가로 100% 선형이라 과거 보정 스케일의 착시 위험이 없다. 구현은 `<svg viewBox="0 0 100 H" preserveAspectRatio="none" class="w-full h-7 sm:h-8">` — 좌표가 % 기반이라 **ResizeObserver 불필요**(px 측정 제거). 자산군별 path: 위 변 [기준 lo→hi] 아래 변 [지금 lo→hi]을 cubic(제어점 y=중간)으로 연결, `fill=색`, opacity 라이트 0.16 / 다크 0.24(기존 값 재사용). 한쪽이 0%면 점으로 수렴. 두 막대가 동일 비중이면 평행 띠(정상).
- 행(`composition-row-{key}`): `grid grid-cols-[auto_1fr_auto_auto] items-center gap-x-2 py-1.5 text-sm` — 색점 `size-2 rounded-full`(범례 점 규격) · 이름(`text-muted-foreground`, 줄바꿈 허용 break-keep) · `62% → 58%`(`tabular-nums text-foreground`) · 증감(`composition-delta-{key}`, `font-semibold tabular-nums text-foreground w-14 text-right`). 목록 `sm:grid sm:grid-cols-2 sm:gap-x-8`(1280에서 좌우 2열로 채움, 375는 1열).
- 증감 문구: 정수 반올림 비중의 차 `round(지금)-round(기준)` — 행의 숫자와 산수가 항상 일치. 0이면 "변화 없음"(`text-muted-foreground font-normal`), 아니면 "+4%p" / "−4%p"(U+2212). **손익색(빨강·파랑) 금지**, 화살표 아이콘 없음. 행 전체 예: `● 부동산  62% → 58%  −4%p`.
- 사실 문장도 같은 반올림 차 기준 상위 2개("7월 기록 대비 주식 +4%p, 현금성 −3%p"), 전부 0이면 "기준 시점과 구성이 거의 같아요".

## 4. 모션 (전부 `motion-safe`, 상호작용 없음)
- 카드 `BODY_ENTER` 유지. 막대 A `animate-in fade-in slide-in-from-left-2 duration-300 fill-mode-backwards`, 막대 B 지연 60ms, 리본 fade 지연 120ms, 행은 25ms 간격 stagger(최대 4개).
- 실시간 값 갱신 시 세그먼트 `transition-[width] duration-300 motion-reduce:transition-none`. 세그먼트는 `key=자산군`(월 아님) 고정이라 **재마운트 없이** 폭만 보간 → 진입 모션이 갱신으로 반복되지 않음. 연타·방향 전환 개념 없음(비인터랙티브).

## 5. 접근성
- 막대 블록 전체 `aria-hidden="true"`. 텍스트 대체는 문장 + `<ul>`: 각 `<li aria-label="부동산 62%에서 58%, 4%포인트 감소">` ("변화 없음"은 "62%에서 62%, 변화 없음"). 기준 시점은 제목·문장이 읽어줌.
- 비인터랙티브라 히트영역·키보드 이슈 없음(포커스 가능 요소 0). 색만으로 구분하지 않음(행에 이름 병기).
- 대비: 막대 내부 글자 `pickOnColor`, 행 텍스트 `text-foreground`/`text-muted-foreground` 토큰이라 라이트·다크 자동. 세그먼트 구분선 `border-card`가 다크에서 면 분리 유지.

## 8. 품질 체크리스트 (qa 판정용, 375·1280 × 라이트·다크)
1. 연 탭 맨 아래 카드가 클릭·탭 없이 막대 2줄과 자산군 행을 모두 보여준다(버튼·aria-pressed 0개).
2. 막대 두 줄 모두 카드 내부 폭 100%를 채운다(`composition-bar-base`·`-now` 폭 = 컨테이너 폭).
3. 세그먼트 폭 비율 = `data-ratio` 비율(오차 1% 이내), 최소 폭·보정 없음.
4. 10% 이상 세그먼트에만 막대 안 %가 있고 글자가 잘리거나 넘치지 않는다.
5. 1~2% 자산군도 행에 이름·수치·증감이 있고 리본에서 색이 식별된다.
6. 행 증감 = 반올림 비중의 차와 일치("62% → 58%"→"−4%p"), 차 0이면 "변화 없음".
7. 증감 텍스트에 빨강/파랑 손익 클래스가 없고 부호는 +/−(U+2212)만 쓴다.
8. 기준 라벨·제목이 데이터 상태와 맞다: 작년 말 / 올해 첫 기록(캡션 포함) / 없음(안내만, 막대 없음).
9. 데이터 1건·기준 없음에서 `composition-empty`만 보이고 막대·행·문장이 없다.
10. 375px에서 가로 스크롤 없음, 행 4개 모두 1열로 한 줄 또는 이름만 줄바꿈; 1280px에서 행 2열로 영역을 채운다.
11. 리본이 막대 사이 간격 안에서 같은 색으로 이어지고 다크에서 과하게 밝지 않다(opacity 0.24 이하).
12. 다크에서 세그먼트 구분선(`border-card`)이 보이고 막대 글자 대비가 유지된다.
13. 진입 모션 1회만 재생되고 실시간 값 갱신 때 재생되지 않는다(`motion-reduce`에서 즉시 표시).
14. 문구에 금지어·금액·평가어가 없다(`COMPOSITION_FORBIDDEN_WORDS` 테스트 통과), 투자 조언 없음.
15. 각 `<li>`에 aria-label이 있고 막대 블록은 aria-hidden이다.
16. 기존 월별 13칸 막대·`composition-selected`·보정 캡션·범례가 DOM에 없다.
17. 새 블록 비교 기준(작년 말→지금)이 연 탭 Hero("작년 말 대비")와 일치한다(CHECKLIST 신규 항목).
