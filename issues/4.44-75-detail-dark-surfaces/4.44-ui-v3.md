|---|---|---|

| b 바 제거·헤어라인만 | 가장 깔끔하나 종목색·비중 시각 정보 소실, 다른 탭과 정체성 상실 (b-*) | 기각 |
| c 선 제거·간격 | 행이 개별 카드로 쪼개져 "리스트 전체 1 BOX"(v2 확정) 위배 (c-*) | 기각 |

### 클래스 변경 (모두 `dark:`, 라이트 픽셀 무변경)
1. `src/config/theme.ts` `listBox`: `dark:divide-y dark:divide-border/40` 삭제.
   -> `"dark:rounded-xl dark:bg-card dark:shadow-sm dark:overflow-hidden dark:space-y-0"`
2. 각 카드 루트 Collapsible(`mb-2 dark:mb-0` 가진 5곳: stock-tab:811, crypto-tab:114, cash-tab:47, loan-tab:55, real-estate-tab:50)에 추가:
   `dark:not-last:data-[state=open]:border-b dark:border-border/40`
   (마지막 항목은 박스 하단과 겹쳐 선 2중이 되므로 `not-last`.) 공통 토큰화 권장: theme.ts `cardOpenDivider`로 등록 후 5곳 재사용.
- 제외: 증권사 하위 타일, 거래내역 박스(`stock-trades-view` trades-list-box, 헤어라인만 있고 바 없음), asset-change/loan-tx 등 거래 목록은 바가 없으므로 기존 divide-y 유지.
- 5개 탭 동일 규칙 적용 (바 패턴이 동일하므로 예외 없음). 라이트: 클래스 전부 `dark:` 접두라 무변경 유지 가능.

## 2. 모바일 보유 비중 제거 — 권고: 비중 % 텍스트만 제거, 비중바는 유지
- 근거: % 는 범례와 중복이라 제거 비용이 없다. 바는 1번 결론에서 구분선 역할을 맡으므로 제거 불가(제거 시 구분선 복원 필요 = 선 늘어남, 대표 취지에 반함). "둘 다 제거"는 기각.
- 변경 (`stock-tab.tsx` StockRowHeader L317~322, `!screenshotMode` 블록 안이므로 인증카드는 렌더 자체가 없어 영향 0):
  `<span className="text-sm text-muted-foreground">·</span>` -> `className="text-sm text-muted-foreground dark:max-sm:hidden"`
  `<span className="text-sm font-semibold text-primary">` -> `className="text-sm font-semibold text-primary dark:max-sm:hidden"`
  (TodayChangeChip은 유지.)
- 범위: 다크 모바일(<640px)만 숨김 = 라이트·PC 무변경. 대표가 라이트 모바일도 원하면 `dark:` 접두만 제거(`max-sm:hidden`)하면 되며 이 경우 라이트 변경이므로 대표 판단 필요.
- 375px 헤더 (a+m-375-dark.png): [아이콘 40] [이름(최대 2줄) / `65주` (+오늘 등락 칩)] [금액 / 손익(손익%)] [chevron]. 하단에 색 바 2px. 높이는 비동일(체험 데이터에서 줄바꿈 없음)이나, 장중 칩 노출 시 `65주 · 31.3% 오늘 ▲1.2%`가 2줄로 넘치던 것이 1줄로 수렴한다.
- PC(sm 이상): 유지 (범례·바와 함께 정보 밀도 여유).
- 영향 확인: `StockRowItem`(welcome-guide 온보딩)도 같은 헤더라 다크 모바일에서 % 숨김, 허용 범위(동일 규칙). 인증카드는 `screenshotMode`에서 이미 % 미렌더 + SHOT 토큰 고정이라 불변.
