### 수정 요청
- A (필수) composition-card.tsx, 13칸@375: 선택 칸(이번 달) 막대 폭 14px인데 % 라벨("95%","2%")이 막대보다 넓어 카드 우측에서 잘림("5%", "2%"로 보임). 기대값: barW<SEG_LABEL_MIN_BAR이면 막대 안 % 생략(선택 줄 문장이 정본), 또는 선택 칸 라벨을 막대 위 툴팁형으로 zone 안에 clamp.
- B (필수) src/config/theme.ts cardHeader `dark:px-4` 부작용: 가상자산 탭 비트코인 헤더가 375에서 "0.05 / 개 · 100.0%"로 줄바꿈(수량 단위 분리). 기대값: 수량 span `whitespace-nowrap`(crypto-tab.tsx 헤더 수량 줄) 또는 비중 `· 100.0%`를 줄바꿈 우선으로 분리. 주식 탭은 정상.
- C (권장) 리본 가시성: 변화가 작은 실제 데이터(체험 3칸)에서 리본이 거의 안 보이고(opacity 0.16, 다크 특히), 비선택 막대 opacity 55%가 다크에서 탁함(1280 "93%" 라벨 대비 낮음). 기대값: 리본 0.16→0.24(다크)/선택 인접 0.38, 비선택 막대 0.55→0.7, 비선택 % 라벨은 foreground 유지. 변화 큰 케이스(wild)는 리본 흐름이 명확해 방향성은 OK.
- D (권장) 1280·3칸: 막대 72px가 1000px 위에 흩어져 휑함. 기대값: n≤4일 때 차트 max-w(예 560~640px) 중앙 정렬 또는 BAR_MAX를 n별로 확대(3칸 120px).
- E (권장) 암호화폐·부동산 요약 박스 하단 여백이 현금 대비 약 28px 큼(요약 박스 내부 빈 줄). 토스 눈높이에서 비대칭 -> 마지막 줄 mb 제거.
