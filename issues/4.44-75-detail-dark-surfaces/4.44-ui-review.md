## 판정: UI 승인 (조건부, 권장 수정 1건)

### 통과
- 3단계 면: 다크에서 배경(background) < 카드 헤더(card) < 확장부·액션행(popover)이 5탭 모두 명도차로 구분됨. 행 사이 divide 유지, 확장부 상단선 제거 후에도 카드->확장부 경계 식별 OK.
- 증권사별 서브카드(popover)가 well(background) 위에 놓여 3단계 유지, 라이트는 회색 well 그대로.
- cardHeader dark:px-4: 카드 헤더 텍스트 좌측이 확장부 텍스트(px-4)와 정렬, 가장자리 여백 확보. 375에서 줄바꿈("0.05개", "TIGER 미국S...") 깨짐 없음.
- 라이트: diff상 dark: 접두 추가뿐이라 클래스 무변경, 스크린샷도 기존과 동일 구조(흰 패널+그림자). 인증카드: StockCard screenshotMode는 cardWrapperShot, "외 N종목"도 분기 -> 다크 면 미적용 확인. 타 탭 카드는 screenshotMode 경로 없음.
- 텍스트 대비: popover(L 0.275) 위 foreground/muted-foreground(0.74) 가독 양호.
- 자산 구성 막대: 375에서 h-20, max-w-9 슬림화 적용, 라벨·범례·문장 겹침 없음, 히트영역 min-h-10 유지.

### 수정 요청 (권장, 비차단)
- composition-card.tsx 막대 행 `flex justify-between gap-1` + `max-w-9`: 1280에서 5칸이면 막대 5개(36px)가 1150px에 흩어져 빈 간격이 과도함(체험 데이터 3칸 스크린샷에서 확인: 9월/10월/이번 달이 좌·중·우 끝). 375에서도 5칸은 간격 약 28px로 듬성함. 기대값: 칸 수가 적을 때 막대를 뭉치도록 `justify-between` 대신 `justify-center gap-2 sm:gap-3`(13칸에서는 flex-1로 자연 축소) 또는 행에 `max-w` 제한. 13칸은 현행 유지 가능(375에서 약 20px/칸).
- 데이터상 5칸·13칸 실측은 체험 데이터가 3칸뿐이라 미실측. 계산상 5칸=196px(375 콘텐츠 311px), 13칸 폭 약 20px로 오버플로 없음.
