## UI 수정 요청
1. **필수 — 튜토리얼 말풍선 아이콘이 보이지 않음** (`src/app/(main)/_components/tutorial/tutorial-overlay.tsx` 177~180행): 원 배경과 아이콘 색이 둘 다 `MAIN_PALETTE[0]`이라 아이콘이 완전히 사라지고 파란 원만 보인다(`ur-tutorial-375-dark/light`). 기대값: 아이콘 `color: #fff`(또는 `text-white`)로 변경. 다크·라이트 모두 대비 4.5:1 이상. (선정 문서 P-B④ 대상, 실측 결함 확정)
2. **권고(같은 파일, 같이 고치면 좋음)** — 말풍선 X 버튼 14×14·`aria-label` 없음, `다음` 버튼 높이 32px: design-system §7 40px 위반. 기대값: X는 `aria-label="튜토리얼 닫기"` + `after:-inset-3`(보이는 크기 유지, 히트영역 40), `다음`은 `min-h-10`. 이번 릴리스에서 이 파일을 이미 수정했으므로 같이 처리 권장. 시간 부족하면 1번만 필수.
3. **참고(이전부터 있던 결함, 이번 범위 밖)** — 320px 배당 표에서 `분기` 배지가 종목명 칸을 넘어 `배당월` 칩과 겹침(`ur-dividend-320-dark`, 이전 캡처에도 동일). 이후 후보로 기록, 이번 승인과 무관.
