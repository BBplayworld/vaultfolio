# 5.114 #215 텍스트 크기 체계 — UI 사양 (ui-designer, 2026-11-14)

근거 조사: `5.114-audit.md`. 이 문서의 수치는 운영 화면에 CSS·클래스 치환을 주입한 프로토타입(21화면 × 7폭, `tools/capture.mjs after`)으로 확인한 값이다.
프로토타입 스크린샷: `screenshots/proto-after-<화면>-<폭>-dark.png`(8화면 × 360·390·768·1024·1280).

## 1. 결정 한 줄
**크기 이름(`text-xs`~`text-4xl`)은 그대로 두고, 그 값이 환경에 따라 달라지게 한다.** 모바일 값은 지금과 같고, 태블릿은 +1px, PC는 +2px. 화면마다 따로 붙인 `sm:`·`lg:` 크기 쌍과 임의 px는 없앤다.

| 환경 | 폭 | 본문 | 근거 |
|---|---|---|---|
| 모바일 | ~767 | 14px | 지금 값 유지. 줄밀림 0건(360·390·430 실측) |
| 태블릿 | 768~1279 | 15px | 1열 레이아웃 + 2열이 시작되는 1024(아이패드 가로) 포함 |
| PC | 1280~ | 16px | 콘텐츠 폭 1,184px 이상. 14px 대비 줄 수 변화 3건(전부 대응 가능) |

PC 경계를 1024가 아니라 **1280**으로 잡은 이유: 1024에 PC 값(16px)을 넣어 보니 홈 추이 막대 라벨 9개가 2줄, 도넛 범례 3개가 말줄임, 허브 행 값이 말줄임됐다. 1024는 2열이 막 시작돼 칸이 가장 좁은 폭이다.

- 입력(`Input`/`Textarea`)은 `text-base md:text-sm` 유지 — 모바일 16px(iOS 확대 방지), 태블릿 15, PC 16.

## 4. 브레이크포인트와 경계 (C99)
- 타입 경계는 **`md`(48rem = 768)와 `xl`(80rem = 1280) 두 개뿐.** `sm:`·`lg:` 크기 클래스는 쓰지 않는다.
- 토큰 값은 `globals.css`의 `@media (min-width: 48rem)` / `(min-width: 80rem)`으로만 바꾼다. Tailwind `md:`·`xl:` 변형과 같은 식(`min-width`)이고 `max-*` 짝이 없으므로 767.5 같은 빈 구간이 생기지 않는다.
- 구조 예외로 남는 `max-[399px]:`(시장 비교 표 `market-compare-view.tsx:325,331`)와 `max-sm:`(배당 월 배지 `monthly-dividend-stocks.tsx:265`)는 기존 쌍 그대로 둔다. 이번에 새 `max-*` 경계는 만들지 않는다.
- 검수 경계 쌍: 767↔768, 1279↔1280 (C104 "변경이 만든 경계 양쪽 1쌍").

## 5. 적용 방식
### 5.1 토큰 (1개 파일, `src/app/globals.css`)
Tailwind v4는 `.text-sm{font-size:var(--text-sm)}`로 컴파일된다(운영 CSS 확인). 변수 값만 환경별로 바꾸면 `text-*` 1,200여 곳이 클래스 수정 없이 따라온다.

```css
@theme {
  --text-2xs: 0.6875rem;
  --text-2xs--line-height: calc(1 / 0.6875);
}
@layer base {
  @media (min-width: 48rem) {
    :root { --text-2xs: .75rem; --text-xs: .8125rem; --text-sm: .9375rem; --text-base: 1.0625rem; --text-lg: 1.1875rem;
            --text-xl: 1.375rem; --text-2xl: 1.6875rem; --text-3xl: 2.0625rem; --text-4xl: 2.5rem; }
  }
  @media (min-width: 80rem) {
    :root { --text-2xs: .75rem; --text-xs: .875rem; --text-sm: 1rem; --text-base: 1.125rem; --text-lg: 1.25rem;
            --text-xl: 1.5rem; --text-2xl: 1.875rem; --text-3xl: 2.25rem; --text-4xl: 2.75rem; }
  }
  /* 뷰포트와 무관하게 모바일 값으로 고정 — 인증카드 프리뷰·캡처(R32) */
  .type-fixed { --text-2xs: .6875rem; --text-xs: .75rem; --text-sm: .875rem; --text-base: 1rem; --text-lg: 1.125rem;
                --text-xl: 1.25rem; --text-2xl: 1.5rem; --text-3xl: 1.875rem; --text-4xl: 2.25rem; }
}
```
- 이름을 `text-2xs`로 한 이유: `tailwind-merge`가 `2xs`를 크기로 인식한다(티셔츠 사이즈 패턴). `text-caption` 같은 이름은 색 클래스로 오인돼 `text-muted-foreground`와 서로 지운다. developer는 `cn("text-2xs","text-muted-foreground")`·`cn("text-sm","text-2xs")` 단위 테스트 1개로 확인한다.
- `html` 글자 크기(16px)는 건드리지 않는다. 간격·아이콘·히트영역은 그대로다.
- **인증카드**: `share-menu.tsx`의 프리뷰 래퍼와 캡처 전용 인스턴스(`fixed left-[-9999px]`) 두 곳에 `type-fixed`. `theme.ts`의 SHOT·SHOT_BIG 상수와 `header-menu/share/*`는 **수정하지 않는다**(`theme-shot.test.ts` 불변). PC와 모바일에서 저장한 PNG가 같아야 한다(R32).

## 7. 프로토타입이 덮지 못한 범위 (development에서 반드시 확인)
1. **시트·다이얼로그·입력 폼**(336회). 토큰은 전역이라 함께 커진다. PC에서 `sm:max-w-md`(448px) 다이얼로그 안 16px은 줄 길이 25자 안팎으로 모바일(22자)보다 여유가 있다고 계산되지만 실측하지 않았다. 확인 대상: FAB 자산 업데이트 시트, 주식 입력, 스크린샷 가져오기 결과, 보유 재맞춤 3종, 알림 대상, 공유·동기화. 깨지면 그 컨테이너에만 `type-fixed`를 붙이지 말고 폭(`max-w`)을 늘린다.
2. 설명 문장 12 → 14(§5.2의 19곳)는 주입하지 않았다. `tool-menu.tsx` 다이얼로그와 부동산 입력 높이를 390에서 확인.
3. `CardTitle` 페이지 제목 16 → 18/22/24, 다이얼로그 제목 통일도 주입하지 않았다. 배당 화면은 제목 줄에 세그먼트가 같이 있다(`dividend-chart.tsx:244`) — 360 1줄 확인.
4. 실물 탭·거래 내역 3종(체험 데이터 0건), 온보딩·잠금 화면, 라이트 모드.
5. 헤드리스 글꼴은 실기기와 폭이 다르다. iOS Safari·Android Chrome preview로 360·390 재확인.
6. **SVG 차트 글자**(`fontSize` 고정 10~18)는 토큰이 닿지 않는다. 이번에는 값만 정리한다: 가격 눈금 10 → 11(`price-axis-layer.tsx:59,60,67`, 가격 칸 46~76px 안에서 겹침 없을 때만), 축 tick 11·12 → 12로 통일(`net-asset-chart.tsx:308`). 환경별 확대는 하지 않는다(차트 폭 계산과 묶여 있어 별도 과제).

## 9. 상태·모션·접근성
- 로딩·빈·오류·예측 상태는 같은 토큰을 쓰므로 별도 규칙 없음. 스켈레톤 높이(`h-4`·`h-5`)는 글자 높이와 묶여 있지 않다 — 로딩 → 완료 전환에서 줄 높이가 튀지 않는지(특히 PC 16px 본문 줄높이 22.9px vs `h-4` 16px) 허브 행·시장 비교 표에서 확인하고, 튀면 값 칸에 `min-h-[1lh]`.
- 모션 변경 없음. 폭이 바뀌어 토큰 값이 바뀔 때 전환 효과를 넣지 않는다.
- 히트영역은 글자 크기와 무관하게 40px 유지(11px로 커지는 배지는 버튼이 아님). 다크·라이트 대비는 색을 건드리지 않아 그대로.
- 브라우저 글꼴 확대(rem 기반)는 그대로 동작한다.
- 문구 변경 0, `data-screenshot-hide` 변경 0, 새 `data-testid` 0(기존 testid로 검수 가능).
