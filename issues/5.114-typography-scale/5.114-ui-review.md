## 2. 전체 인상
- 모바일(360·390): 값이 운영과 같고 달라진 것은 뒤로 16 < 페이지 제목 18 < Hero 24, 섹션 제목 16 bold, 9·10px 배지 → 11px뿐. 문서 가로 넘침 0, 줄 수 증가는 세금 설명 문장 1블록뿐. 빽빽해진 화면 없음(R1 한 곳 제외).
- 태블릿(768·1024): 본문 15로 한 단계 올라가고 페이지 제목 22가 처음으로 본문과 구분된다. 감소는 뒤로 라벨·페이지 Hero·1차 네비·배당 표·홈 추이 라벨 + 범례(4a)로 dev-notes 목록과 일치.
- PC(1280): 본문 16·섹션 제목 18·페이지 제목 24·Hero 30으로 홈·상세 주식·자산 변화·더보기가 같은 단계로 읽힌다. 감소는 뒤로 라벨뿐(24 → 18, 의도). 잘림·겹침 없음.

## 3. UI 수정 요청
**R1 (필수, 이번 변경이 만든 겹침)** — 성적표 `5축 측정` 행 이름이 별점과 겹친다. `장기 순자산 성장` 글자 끝과 첫 별 사이: 운영 360 17px·390 9px → preview **360 2px·390 −6px**(겹침, `pv-perf-report-390-dark.png`). 행 이름은 카드 제목이 아니라 목록 행 라벨이다.

- 기대값: 360·375·390·430에서 이름 끝 ~ 첫 별 간격이 운영 이상(17·32·9·49px).

**R2 (필수, 운영에도 있는 태블릿 깨짐)** — 배당 표가 640~1023에서 종목명 칸이 0~22px이 돼 종목명이 안 보이고 `매수 2026-03-12`가 한 글자씩 세로로 꺾이며 `예상금액` 머리가 잘린다(`x-dividend-768.png`, 운영 `before-perf-dividend-768-dark.png`도 같음). 이번 변경이 만든 것은 아니지만, 태블릿을 정리했다고 내는 릴리스에서 같은 줄을 고치고도 남겨 둘 수 없다. ui.md가 놓친 항목이다.
- `monthly-dividend-stocks.tsx:201,219` `sm:grid-cols-[1fr_16rem_6rem_7rem_7rem]` → `sm:grid-cols-[minmax(0,1fr)_11.5rem_4.75rem_5.5rem_5.5rem] lg:grid-cols-[1fr_16rem_6rem_7rem_7rem]`, `sm:gap-x-3` → `sm:gap-x-2 lg:gap-x-3`

- C103: 고친 뒤 640·768·1023을 운영과 대조(행 높이·월 배지 줄 수·말줄임).

**R3 (필수, 작은 보정)** — 시장 비교 표 640~1023 값 열 간격 8px → 16px.
- `market-compare-view.tsx:305` `sm:gap-x-2` → `sm:gap-x-4` (`lg:gap-x-1.5`는 그대로)
