## reconcilePrices 경계 (실행 확인)
| 입력 | 결과 | 판정 |
|---|---|---|
| 수익률 0·값 없음 | keep(검증 생략) | 의도 |
| 정상 읽기, 소수익률(AVGO 0.86%, VST -1.93%) | keep | OK |
| VST 바뀐 읽기 (-1.93%) | swap 교정 | OK |
| **AVGO 바뀐 읽기 (0.86%)** | **keep (교정 안 됨)** | 한계: 두 해석 차이가 약 1.7%p라 허용 3%p 안에서 둘 다 맞음 → |수익률| 약 1.5% 이하는 바뀐 읽기를 못 잡음 |
| 수수료 포함 차이 ≤3%p | keep | OK |
| 차이 >3%p이고 swap도 불일치 | estimate(평단 0, 기존 평단 유지) | OK, 안전 방향 |
| 허용폭 안 바뀐 읽기가 틀린 방향으로 가는가 | 아님. 소수익률은 교정 안 함(keep)일 뿐 새로 틀리게 만들지 않음 | 한계 |
| 입력 자체가 불일치한 인위 케이스(현재가 97.5·평단 100·수익률 +3.5) | swap으로 뒤집힘 | 실화면에서 수익률 부호가 반대일 때만, 낮은 위험 |
- 한계 1: 소수익률 종목은 AI가 바꿔 읽으면 교정 불가, 다만 기존 평단과 차이는 1~2% 수준. 완화책 후보(비필수): |수익률|<1.5%면 평단은 기존 값 우선.
- 한계 2: 원화 표시 해외주식은 수익률이 환율 변동을 포함하면 차이가 커져 estimate로 떨어질 수 있음(안전 방향, 평단 미덮어씀). 이번 화면(외화 표시)은 해당 없음.
