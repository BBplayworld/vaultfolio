## 3. 설계 판정
**호출 지점**: origin/main 실측 **16곳**(spec 14 + 거래 스크린샷 2: `crypto-trade-screenshot-import.tsx:183,268`). 직접 입력 8(stock·crypto·cash·loan ×2)·스크린샷 4·balance-resync 1·holdings-resync 1 = 14, 거래 2. 함수 1곳 수정으로 호출부 수정 0 → 단일 신호 방식은 유효.

**A. 결함 1 — holdings-resync는 mark 시점에 창이 안 닫힌다.** `holdings-resync-dialog.tsx:326` 이후 `setStep("result")`로 결과·되돌리기 화면이 계속 열려 있다(닫힘은 `handleClose` `:196-208`). mark 즉시 신호를 내면 결과 화면 위로 시트가 겹쳐 열린다. → 이 호출만 `{notify:false}`, `handleClose`에서 `step==="result"`(적용됨)일 때 신호 별도 발행(`notifyCategoryRefreshed(kind)` export). 나머지 12곳은 mark 직후 `onClose/setOpen(false)/handleClose`를 같은 tick에 부르므로 즉시 신호로 충분(React 18 자동 배칭).
**B. 결함 2 — "취소" 신호가 없다.** spec 4-6 "취소로 닫으면 플래그 해제"는 공통 창 닫힘 이벤트가 없어 직접 구현 불가. 해결(창 수정 0): ① 플래그는 `{category}` 보관 ref, 신호의 category와 **일치할 때만** 소비 ② 이벤트 수신 시 즉시 ref=null(중복 신호 무시) ③ 시트 수동 닫힘(`onOpenChange(false)`)·[완료]·`navigate` 뷰 변경 시 ref=null(상세 탭 편집·성과 이동은 뷰가 바뀜 → AC6 보호) ④ 거래 스크린샷 2곳 notify:false. 잔여 위험: 홈에서 취소 후 같은 자산군을 홈 내 다른 경로로 저장하는 경우뿐(홈에 편집 경로 없음, 가능성 낮음) — qa 시나리오에 포함.
**FAB 상태 설계**: arm은 `handleMethodSelect`(refresh 4종만, 마법사 `directInput="add"` 경로는 FAB를 거치지 않으므로 자동 제외)와 `open-add-asset-sheet`+category 수신 시점이 아니라 **방법 선택 시점**에 한다(수신 시점은 시트가 select-method라 아직 창이 안 열림). arm은 ref라서 `resetState`/`setIsOpen(false)`에 지워지지 않음; 시트가 닫혀 있을 때만 arm되므로 "닫힘 중 신호"는 구조상 불가(Esc·드래그는 ref=null이 먼저). 복귀: `setIsOpen(true); setStep("holdings"); setResumeNotice(category)`. 복귀 알림 state는 시트 닫힘 시 해제. 시트 상단 `{자산군} 맞췄어요`의 "전부 맞춤" 판정은 `heldRefreshCategories`(기존 `asset-refresh-status.ts`) 재사용. 보유 판정은 열림·복귀 시 `getAssetData()` 신선값(저장 직후 context 갱신 지연 방지).
**✓ 판정**: `lastRefreshedAt`은 UTC ISO → `new Date(Date.parse(iso)+9h).toISOString().slice(0,10) === todayStr()`(기존 비공개 `todayStr`와 같은 방식). `isRefreshedToday`로 모듈 내 노출(재사용 등록 대상). 렌더당 4회 JSON 파싱 → 열림/복귀 시 `useMemo`로 1회. 알려진 한계: 되돌리기(undo)는 mark를 되돌리지 않아 ✓가 남음(현행 동작과 동일, 문서화).
**GA**: 새 `GaEvent` 없이 기존 방식 그대로 — `track("feature_use", { category: "resync_continue" })` + `CATEGORY_TITLES.resync_continue = "이어서 맞추기"`(`resync_start`와 동일 패턴, `featureTitleOf`가 page_title만 전송). 발화: 복귀 상태에서 **보유 4종 행을 다시 누른 순간** 1회(`handleHoldingsClick`, 복귀 알림 활성 시). spec §7-9 "신규 이벤트 0"과 direction "신규 title 1개"는 표현이 다를 뿐 모순 아님(이벤트명 0·category 값 1) — spec 문구 정정 요청.
**신호 이벤트 이름**: `asset-category-refreshed`(기존 `trigger-*`/`open-add-asset-sheet` 관행). 발행 함수는 `asset-dispatch.ts`가 아니라 `asset-refresh-status.ts`에 둔다(순환 import 회피; 이 모듈은 이미 모든 호출부가 import).
