# 4.xx #113 첫 화면 빈 화면 없애기 — spec (planner-designer, 2026-11-09)

> 근거: 4.xx-direction.md(사업·경험·합의), 4.xx-challenge.md(K1~K5). risk:medium, COO 자체 승인 범위.

## 1. 문제
- `src/app/(main)/page.tsx`가 `if (!isDataLoaded) return null`이라 루트 `/`의 서버 HTML 본문이 비어 있다.
- 0건 새 방문자는 번들 수신·hydrate·localStorage 읽기가 끝날 때까지 빈 검은 화면을 본다(인앱·느린 회선일수록 길다). 인앱이면 이어서 빈 덮개(`InAppBrowserGate` `cover`)까지 본다.
- JS를 실행하지 않는 수집기는 루트 본문을 읽지 못한다.

## 2. 목표 행동
- 0건 새 방문자: 첫 HTML 도착 즉시 h1 `나만의 비밀 자산 금고`·부제·신뢰 한 줄을 본다. 이후 웰컴 나머지가 아래에 붙고 위 블록은 움직이지 않는다.
- 보유자: 웰컴 조각을 한 프레임도 보지 않고 지금처럼 홈으로 간다.
- 수집기: JS 없이 같은 텍스트를 읽는다.

## 3. 범위
**포함**
1. `!isDataLoaded` 분기에서 `null` 대신 정적 조각을 렌더: 히어로(h1·부제) + 신뢰 한 줄(아이콘·텍스트 3항목). 문구는 WelcomeGuide와 같은 출처에서 가져온다(새 문자열 리터럴 0).
2. `layout.tsx` head의 기존 `data-device` try 블록에 1줄: 키 3개(`secretasset_asset_data`, `secretasset.physical_assets`, 레거시 `secretasset-asset-data`) 중 하나라도 `getItem(k) !== null`이면 `html[data-has-assets]`를 붙인다(K1·K2).
3. CSS 1규칙: `html[data-has-assets]`이면 조각 `display:none`(K3, React 분기 아님).
4. `resolveInAppGate`: 로드 전이라도 `data-has-assets` 없음 + restoreHash 없음 + syncAssetId 없음이면 `cover` 대신 `welcome`(K5) + 단위 테스트.
5. 조각 → WelcomeGuide 전환 시 위치 이동 0·재진입 애니메이션 0·h1 동시 2개 0(K4). 방식은 ui-designer가 ui.md에서 정한다.

**하지 않을 것**: 새 문구·키워드 / `자세히 보기`·보안 펼침·미리보기·CTA·설치 박스·체험 링크의 SSR / 메타·sitemap·JSON-LD / TopBar·하단 내비·푸터 / 새 이벤트·title·맞춤 정의 / 새 `<script>` 태그 / 저장 키 쓰기·값 읽기 / 수집기 전용·숨김 텍스트 / head에 `#share`·`#sync` 해시 판정 추가.

## 4. 사용자 흐름
1. 브라우저가 `/` HTML을 받는다. head 스크립트가 body 파싱 전에 키 존재만 보고 `data-has-assets`를 정한다.
2. 속성 없음(0건 기기·수집기): 조각이 첫 페인트에 보인다. 속성 있음: 조각은 CSS로 숨은 채 페인트된다(현행과 같은 빈 화면).
3. hydrate 후 `isDataLoaded=true`가 되면 조각 자리에 기존 분기(웰컴/마법사/홈)가 렌더된다. 웰컴이면 히어로·신뢰 줄이 같은 위치에 그대로 이어진다.
4. 인앱 0건(복원 해시·동기화 없음): 덮개 없이 2→3. 인앱 보유자·복원 진입: 현행대로 덮개 → 게이트.
5. `welcome_view`는 지금처럼 WelcomeGuide mount 때 1회만 전송된다(조각은 이벤트 0).

## 7. 데이터 계약
- 읽기: head에서 키 3개의 **존재 여부만**(`getItem(k) !== null`). 값을 변수에 담거나 parse·길이 확인·전송하지 않는다.
- 쓰기: 저장 키·스키마·마이그레이션·동기화·공유 토큰·서버 전송 변경 0. DOM 속성 `data-has-assets` 1개만 추가(새로고침마다 재계산, 저장 안 함).
- 롤백: PR revert 1개, 남는 상태 0.
