## 4. preview에서 확인할 화면 경로와 순서
preview는 PreviewGate가 children을 클라이언트에서만 렌더하므로 **원본 HTML 조각 검증 대상 아님**(로컬 운영 빌드/머지 후 운영 curl로). preview에서는:
1. `/?demo=1` 주입 직후: 조각이 잠깐 보였다 홈으로(preview 전용 현상, 결함 아님). 새로고침 후 조각 노출 0.
2. 빈 기기(시크릿 창) `/`: 히어로·신뢰 줄이 먼저 보이고 아래로 미리보기·CTA가 붙는다. 위 두 블록이 움직이지 않는다.
3. 웰컴 → CTA로 마법사 → 닫기 → 웰컴 복귀 시 히어로·신뢰 줄 ENTER가 기존처럼 재생(회귀 아님).
