## 수정 요청 (2건, 둘 다 `welcome-guide.tsx` `WelcomeAssetCta`)
- **R1** asset 셸 하단 여백 +20px: 루트 `space-y-5`의 마지막 자식이 숨은 `<input type=file className="hidden">`이라, 버튼 행에 margin-bottom 20px이 붙는다. 실측 상단/하단 여백은 데스크톱 24/44, 모바일 16/36. **기대값: 상단 = 하단(24/24, 모바일 16/16).** `<input>`을 `space-y-5` div 밖(형제, 프래그먼트)으로 빼면 된다. 그러면 데스크톱 asset 높이가 160이 되어 pending `sm:min-h-[160px]`와 맞는다.
- **R2** asset 설명 `p.text-sm.text-muted-foreground.text-pretty`("부동산, 주식, … 관리하세요.")에 **`break-keep` 추가**. 375에서 "모든 자 / 산을"처럼 단어가 쪼개지는 것을 막는다. 기대값은 어절 단위 줄바꿈.
두 건 모두 1줄 수정이다. 반영 후 ui-designer가 375 skip·1280 슬롯만 재측정한다.
