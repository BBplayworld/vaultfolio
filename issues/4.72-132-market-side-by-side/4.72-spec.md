## 1. 문제
- 증권사·계좌를 2곳 이상 쓰는 주식 투자자는 지금 가진 종목 전체가 시장만큼 움직였는지 한곳에서 볼 수 없다. 주 4.5회 여는 상세·주식에서 다음 갈 곳도 없다.
- 상세·주식의 `오늘` 칩은 장이 끝나고 일정 시각이 지나면 값이 0.0%(미국 종목은 환율 변동분)로 바뀐다(7절). 대표 기대와 다르고, ③ 정렬의 기준값이라 먼저 바로잡아야 한다.

## 2. 목표 행동
1. 상세·주식에서 `내 종목과 비교`를 눌러 하루·1주·1개월 등락을 코스피·S&P 500 옆에서 본다.
2. 같은 화면에서 시장 줄 위·아래에 어떤 종목이 놓였는지 본다.
3. 상세·주식 목록을 `움직인 순`으로 바꿔 가장 최근 거래일에 많이 움직인 종목부터 본다.
4. 장이 끝난 뒤·주말에도 종목 칩에서 '어느 날 종가 기준 등락인지'를 읽는다.

## 4. 사용자 흐름
1. 상세·주식 요약 헤더에 글줄 `최근 1주 코스피 +1.2% · S&P 500 +0.4%  내 종목과 비교 ›`가 보인다. 누른다.
2. `시장과 비교`가 열린다. 정의 한 줄 → 시장별 표(세 기간이 누르지 않아도 보임) → 기준 종가 구간 → 비교하지 않은 종목·제외 안내 → 종목별 목록(기본 1주).
3. 목록의 기간을 `하루|1주|1개월`로 바꾼다. 위 표는 바뀌지 않는다.
4. `뒤로`를 누르면 들어온 화면으로 돌아간다. 상세·주식은 정렬 선택이 그대로, 자산 변화는 범위 = 주식·들어올 때 기간이 그대로다(K3). 주소로 바로 열었으면 자산 변화(주식·주)로 간다.
5. 성과 › 자산 변화 › 주식에서는 Hero 아래 글줄 `코스피 +1.2% · S&P 500 +0.4%  시장과 비교 ›`(선택한 일·주·월 값, 연 탭에는 없음)로 들어온다.
6. 상세·주식 카테고리 줄 오른쪽 정렬을 `움직인 순`으로 바꾼다. 목록만 다시 놓이고 비중 막대는 그대로다.

## 5. 화면·상태·문구
### 5-1. 비교 페이지 구성 (위 → 아래, 시각 사양은 ui.md)
1. 제목 `시장과 비교` + (i). 뒤로 라벨 `뒤로`.
2. 정의 한 줄(항상): `지금 보유한 종목을 그대로 들고 있었다고 보고 계산한 가격 등락이에요`
3. 시장 블록(가진 시장만, 국내 → 미국).
   - 머리: `코스피와 비교한 국내 주식 N종목` / `S&P 500과 비교한 미국 주식 N종목 (달러)` — 줄 이름이 범위를 말한다(K2).
   - 열 `하루 · 1주 · 1개월`, 행 `보유 종목` / `코스피`(`S&P 500`) / `차이`.
   - 등락 `+2.0%`(소수 1자리, 기존 손익 색). 차이 `+0.8%p`(**중립색**, 부호 있음). **차이 = 화면에 보이는 두 값(소수 1자리)의 차**(C65: 보이는 숫자로 검산이 맞는다).
   - 블록 아래 `기준 종가 하루 11/9→11/10 · 1주 11/3→11/10 · 1개월 10/10→11/10`(`formatRefRange` 형식, 항상).
4. 안내 줄(해당할 때만)
   - `비교하지 않은 종목 N` + 이유 한 줄: `해외 자산·채권·금리형 ETF는 코스피와 비교하지 않아요` / `미국 밖 해외 종목은 S&P 500과 비교하지 않아요`
   - `제외 N` + 사유별 개수: `기준가 없음` · `비상장·티커 없음` · `기준일 다름`
5. 종목별 목록: 머리 `종목별` + 기간 선택 `하루|1주|1개월`(기본 **1주**) + `기준 종가 11/3→11/10`.
   - 묶음 `국내` / `미국 (달러)` / `비교하지 않은 종목`. 줄 = 종목명 + 등락률만(금액·수량·비중 0, 티커 기준 병합).
   - 국내·미국 묶음은 등락률 높은 순, 시장 줄(`코스피 +1.2%`)을 그 순서 안에 끼운다. `비교하지 않은 종목` 묶음에는 시장 줄이 없다.
   - 줄을 눌러도 아무 일도 없다.
6. 맨 아래 링크 `금액은 자산 변화 › 주식에서 ›`.
7. (i) 내용(알려진 한계 4건 포함, 6절): 계산 방법(지금 수량 × 시작 종가 비중, 배당은 양쪽 다 제외) · 기간 중에 산 종목은 사기 전 등락도 들어감 · 미국 종목은 달러 가격이라 환율이 빠져 자산 변화의 하루 값과 다름 · 국내는 주식과 국내 주식형 ETF만 코스피와 비교 · 코스닥 종목도 코스피와 비교 · 자산 변화 `국내`에는 해외형 ETF가 들어 있어 값이 다름.

### 5-3. 진입 글줄
- 상세·주식 요약 헤더 안(박스 아님, 인증카드 미표시). 값은 **1주·시장 값만**, 차이는 싣지 않는다. 카테고리 선택과 무관하게 같은 내용.
- 자산 변화 › 주식 Hero 아래. 값은 선택 기간(일·주·월). Hero의 전체/국내/해외 필터와 무관. 연 탭에는 없다.
- 공통: 비교할 종목이 있는 시장의 값만 싣는다. 주식 0개·비교할 종목 0개면 글줄이 없다. 판별·지수 값이 준비되기 전에는 그리지 않고, 값을 못 받으면 링크 문구만 둔다(0% 금지). 페이지의 같은 기간 시장 값과 같은 함수·같은 반올림.

### 5-4. ③ 정렬
- 자리: 카테고리 선택과 같은 줄 오른쪽. **줄 수 +0.** 카테고리는 실제 최대 7칸(`CATEGORY_TABS`: 전체·국내·해외·IRP·ISA·연금·비상장) — challenge의 '최대 6개'를 7로 바로잡는다.
- 옵션 `평가금 순`(기본) / `움직인 순`. `움직인 순` = 각 줄 칩에 보이는 등락률의 **절대값 큰 순**. 칩이 없는 종목은 맨 뒤(그 안에서 평가금 순), 동률은 평가금 순.
- 기준가를 불러오는 동안은 평가금 순 순서를 유지하고 다 받은 뒤 한 번만 다시 놓는다.
- 비중 막대·인증카드 순서는 평가금 순 고정. 선택은 메모리에만(새로고침하면 기본값, 저장 키 0), 카테고리를 바꿔도 유지.
- 승인 문구 `오늘 등락 순`은 `움직인 순`으로 바꿨다. 장이 닫힌 날에는 '오늘'이 사실이 아니기 때문이다(13절 Q3).

### 5-5. 문구 기준
- 쓰는 말: `보유 종목`, `등락`, `코스피`, `S&P 500`, `차이 +0.8%p`, `기준 종가`, `비교`.
- **금지어(비교 페이지·진입 글줄·홈 팁·채널 공통)**: 수익·수익률·실제 수익·성과 / 이겼다·졌다·앞섰다·뒤처졌다·나았다·못했다·선방·초과 수익·알파·우수·부진 / 순위·등급·축하·아쉬워요 / 사세요·파세요·줄이세요·늘리세요·추천·"지수를 사는 편이" / 올해·1년 / 모든 종목·내 주식 전체 / 금액 숫자.
- 차이는 중립색, 시장보다 낮아도 숫자만. 홈 팁: `시장과 비교` · `지금 보유한 종목의 등락을 코스피·S&P 500 옆에서 봐요`.

### 7-3. 비교 페이지 '하루'와의 정합
- '하루'는 **항상 종가 → 종가**이고 장중 값이 없다. 칩의 '장 종료 후'와 같은 종류의 값이다.
- 의도된 차이 2건(둘 다 날짜·`(달러)`로 구분): ① 미국 종목은 칩 = 원화 평가 기준, 페이지 = 달러 가격 ② 페이지·자산 변화는 설정 '기간 수익 종가 기준'(기본 동일 영업일)을 따라 국내가 하루 늦을 수 있다(화 저녁: 칩 `11/10 종가`, 페이지 하루 `11/6→11/9`).
- 국내 종목은 칩의 종가일과 페이지 하루의 끝 종가일이 같으면 두 값이 같다(소수 1자리).
