## 2. 비교 페이지 `#activity/change-market` (위 → 아래, 신규 `views/activity/market-compare-view.tsx`)
바깥 `flex flex-col gap-3 sm:gap-4` + 진입 모션은 `AssetChangeView`와 같다. TopBar 뒤로 라벨 `뒤로`.
1. **제목 줄** `flex h-11 items-center gap-1.5`: `h2`(자산 변화 `h2`와 같은 클래스) `시장과 비교` + `InfoHint`. 바로 아래 정의 한 줄 `p text-sm leading-relaxed text-muted-foreground text-pretty break-keep`(`market-definition`).
2. **비교 카드** `section.SECTION`(`market-compare`) — 카드 1장에 시장 블록을 모은다. `grid grid-cols-1 gap-y-4 sm:grid-cols-2 sm:gap-x-8`, 둘째 블록 `border-t border-border dark:border-border/40 pt-4 sm:border-t-0 sm:border-l sm:pl-8 sm:pt-0`. 한 시장만이면 `sm:max-w-md` 한 칸.
   - 블록(`market-block`, `data-market="kr|us"`) `space-y-3`. 머리 `p flex flex-wrap items-baseline gap-x-1.5 break-keep`: `span text-sm font-semibold text-foreground` `코스피와 비교한 국내 주식` + `span whitespace-nowrap text-sm text-muted-foreground tabular-nums` `3종목` / `2종목 (달러)`.
   - 표: `grid grid-cols-[minmax(3.75rem,1fr)_repeat(3,minmax(0,5rem))] sm:max-w-md sm:grid-cols-[minmax(5rem,1fr)_repeat(3,5.5rem)] items-baseline gap-x-1.5 gap-y-2`, ARIA `role="table"`(행은 `contents` + `role="row"`, 칸 `columnheader/rowheader/cell`, `aria-label` = 머리 문장).
     - 열 머리 `text-right text-sm text-muted-foreground` + 구간 `span block text-[11px] leading-4 tabular-nums` `11/3→11/10`(M/D, 공백 없음. 1개월 이하라 해를 넘겨도 M/D). **375 미만은 `11/3→` / `11/10` 두 줄 고정**(`max-[374px]:block`), 375 이상 한 줄 nowrap.
     - `보유 종목`: 라벨 `text-sm font-semibold text-foreground`, 값 `text-base font-bold tabular-nums` + 손익색. 시장: 라벨 `text-sm text-muted-foreground`, 값 `text-sm font-medium` + 손익색. 구분 `col-span-4 h-px bg-border dark:bg-border/40`. `차이`: 라벨 muted, 값 `text-sm font-semibold text-foreground`(손익색 금지).
   - 안내 줄(`market-notice`, 해당할 때만, 카드 맨 아래) `space-y-1 border-t … pt-3`: `p text-sm text-muted-foreground text-pretty break-keep` 안에 `span whitespace-nowrap font-semibold text-foreground` `비교하지 않은 종목 1` + `·` + 이유 / `제외 2` + 사유별 개수.
3. **종목별 카드** `section.SECTION`(`market-list`): 머리 `flex items-center justify-between gap-3` — `h3 text-sm sm:text-base font-bold` `종목별` + `InlineSelector fullWidth className="w-[168px] shrink-0"`(`하루|1주|1개월`, 기본 1주, `market-list-period-*`).
   - 묶음 `grid grid-cols-1 gap-x-8 gap-y-4 sm:grid-cols-2`. 묶음 머리 `flex items-center justify-between pb-1`: `GROUP_BADGE` `국내` / `미국 (달러)` / `비교하지 않은 종목` + 오른쪽 구간 `text-sm text-muted-foreground tabular-nums` `11/3 → 11/10`(시장마다 종가일이 달라 묶음별 표기).
   - 종목 줄 `li flex items-center justify-between gap-3 py-2.5`(`market-list-row`), 줄 사이 `border-t border-border dark:border-border/40`: 이름 `min-w-0 truncate text-sm font-semibold`, 등락 `shrink-0 text-sm font-medium tabular-nums` + 손익색. hover·press·커서 변화 없음.
   - 시장 줄 `li -mx-2 my-1 flex items-center justify-between gap-3 rounded-md bg-muted/40 px-2 py-2`(`market-list-index`): 이름 `text-sm font-medium text-muted-foreground`, 등락 `text-sm font-semibold` + 손익색. 앞뒤 종목 줄 사이 헤어라인은 그리지 않는다.
   - 카드 맨 아래 링크 행(`market-to-change`) `button -mb-2 flex w-full min-h-10 items-center justify-between border-t … pt-1 text-sm text-muted-foreground`: `금액은 `**`자산 변화 › 주식`**(`font-medium text-foreground`)`에서` + `ChevronRight size-4`.
4. **접기** `button inline-flex min-h-10 items-center gap-1 text-sm text-muted-foreground`(`market-basis-toggle`, `aria-expanded/controls`) `비교 기준 자세히` + `ChevronDown`(펼치면 `rotate-180`). 본문은 항상 마운트 + grid-rows 펼침(design-system §6), `ul list-disc pl-5 space-y-1.5 text-sm leading-relaxed text-muted-foreground break-keep`.

## 4. 상세·주식 (`ui-r1-stock-compare.png`, `ui-r1-sort-7cat.png`)
- **진입 글줄**(공용 `MarketEntryLine`, 자산 변화와 같이 씀) — `StockSummaryHeader` 박스 안 맨 아래, `!screenshotMode`. 래퍼 `mt-3 -mb-2 border-t border-border dark:border-border/40 pt-1.5`, 안에 `button flex w-full min-h-10 flex-col items-start justify-center text-left sm:inline-flex sm:w-auto sm:flex-row sm:items-center sm:gap-3`(`stock-market-entry`).
  - 값 줄 `span text-sm text-muted-foreground`: `최근 1주 코스피 +1.2% · S&P 500 +0.4%` — 시장별 `whitespace-nowrap` 묶음, 값 `tabular-nums font-medium text-foreground`, 구분점 `mx-1.5 text-muted-foreground/60`. `최근 `은 `max-[359px]:hidden`.
  - 링크 줄 `span inline-flex items-center gap-0.5 whitespace-nowrap text-sm font-medium text-foreground` `내 종목과 비교` + `ChevronRight size-4 text-muted-foreground`.
  - 자리 예약: 티커 있는 종목이 1개 이상이면 첫 렌더부터 래퍼 높이를 잡고 내용은 `opacity`만 200ms로 나타난다. 판별 결과 비교할 종목 0이면 grid-rows로 접는다. 값을 못 받으면 링크 줄만.
- **카테고리 줄** `div flex items-center gap-2`(`stock-category-row`): 왼쪽 `div min-w-0 flex-1 overflow-x-auto rounded-md`(스크롤바 숨김) 안에 기존 `InlineSelector`, 오른쪽 정렬.
  - 정렬 = 기존 `Select`(`stock-sort`, `aria-label="정렬"`). `SelectTrigger size="sm"`에 className `relative h-8 min-w-8 shrink-0 gap-0.5 rounded-md px-1.5 text-[13px] sm:text-sm lg:text-base text-muted-foreground bg-transparent dark:bg-transparent dark:hover:bg-transparent dark:border-0 [&>svg:last-child]:size-3.5 after:absolute after:-inset-y-1 after:inset-x-0`(히트 40px, 화살표는 기본 `text-primary`). 입력 칸이 아닌 글자 버튼이라 면·테두리를 두지 않는다(카테고리 트랙과 한 덩어리로 보이지 않게). `등락률 순` 선택 시 `font-semibold text-foreground`. 내용 `align="end"`, 항목 `min-h-10`(`stock-sort-value`/`stock-sort-change`).
  - **좁을 때**: 360 미만 또는 카테고리 6칸 이상이면 트리거는 `ArrowDownWideNarrow size-4` 아이콘만(32×32, 라벨 `sr-only`, 화살표 `[&>svg:last-child]:hidden`). 6칸 이상이면 `InlineSelector className="[&>button]:px-1.5"`.
  - 카테고리를 바꾸면 선택 칸을 `scrollIntoView({ inline: "nearest", block: "nearest" })`.
- 목록 다시 놓기는 모션 없이 즉시, 비중 막대 불변.

## 6. 문구·표기 규칙
- 등락·차이 포맷 함수 1개: 소수 1자리, `+`/`-`(기존 `formatRate`와 같은 하이픈), 차이는 `%p`. 페이지·글줄 2곳이 같은 함수를 쓴다. 차이 = 보이는 두 값의 차.
- `S&P 500`은 상수 `S&P 500`. 모든 한글 문장 `break-keep`.
- (i) 요약 `지금 수량을 기간 내내 들고 있었다고 보고 계산해요.` / 본문 2문단 `종목마다 시작 종가 기준 평가액 비중으로 합쳤어요.` · `배당은 보유 종목과 시장 모두 넣지 않았어요.`
- 접기 5줄: `기간 중에 산 종목은 사기 전 등락도 들어가요.` / `미국 종목은 달러 가격 기준이에요. 환율이 빠져서 자산 변화의 하루 값과 달라요.` / `국내는 주식과 국내 주식형 ETF만 코스피와 비교해요.` / `코스닥 종목도 코스피와 비교해요.` / `자산 변화의 국내에는 해외형 ETF가 들어 있어 값이 달라요.`
- 나머지 문구는 spec 5절 그대로. 금지어·금액 0.

## 7. 모션·접근성
- 기간 선택(`fullWidth`)은 목록 본문 밖에 한 번만 렌더한다(본문만 `key=기간`으로 `motion-safe:animate-in fade-in duration-200`). 썸이 미끄러지고 연타·방향 전환에도 같은 노드다.
- 접기·글줄 접힘은 grid-rows 전환(항상 마운트, `inert`), reduced-motion 즉시. `transition-all` 금지.
- 종목 줄은 `li`(버튼 아님). 글줄·링크·정렬·접기는 `button`/`Select`, 히트 40px 이상, `focus-visible:ring-2 ring-ring/50`.
- 다크·라이트 모두 토큰만 사용. 시장 줄 면 `bg-muted/40`은 design-system §3.3이 정한 흰 카드 위 최소값(`bg-muted/30`)보다 진하다(대비 수치는 ui-review에서 실측).

## 9. 품질 체크리스트 (qa 판정용)
1. 375×667 `?demo=1` 첫 화면에 두 블록의 9칸씩이 스크롤 없이 보인다(A2·C32·C66).
2. `차이` 칸 color = `--foreground`, 등락 칸은 손익색, 0.0은 muted. 차이 = 같은 열 두 값의 차(C65).
3. 열 머리 구간이 375 이상 한 줄, 375 미만 두 줄이고 열끼리 겹치지 않는다(320·360·375).
4. 목록에서 시장 줄 등락의 오른쪽 끝 x = 종목 줄 등락의 오른쪽 끝 x. 시장 줄 배경 ≠ 종목 줄 배경.
5. 기간을 바꿔도 기간 선택 노드가 같고 썸 transform이 보간된다. 위 표 텍스트 불변(C3·A7).
6. 상세·주식 헤더 높이 증가가 320·360·375에서 51px, 글줄 2줄(두 자리 등락 주입 포함). 글줄이 늦게 떠도 X-Ray 스트립 y 불변.
7. 카테고리 줄 높이 main과 같음. 7칸 주입 시 320·375 문서 가로 넘침 0, 375·360에서 7칸 전부 보임(C2·A20).
8. 정렬 옵션 2개, 트리거·항목 히트 40px 이상, 키보드로 열고 고를 수 있다.
9. 자산 변화에서 월↔연 전환 시 기간 선택 y 불변. 글줄은 연 탭에 없다.
