## ② 공통 원칙 — 신기능 표식 `새` chip

| 항목 | 규칙 |
|---|---|
| 모양 | 새 소식 시트의 `새` chip 그대로(`whats-new-item-new`: `rounded bg-orange-500/10 px-1.5 py-0.5 text-[11px] font-bold text-orange-700 dark:text-orange-400`). **신규 색·토큰 0.** 대비 실측 라이트 4.69 / 다크 6.32 |
| 자리 | 진입 버튼·칩 **라벨 바로 뒤 인라인**(`ml-1.5`, 버튼 안). 겹치는 코너 배지·점·숫자·펄스·흔들림 금지. 모션 없음(정적) |
| 출처 | `WHATS_NEW` 항목과 1:1 연결(같은 게시일·같은 '새' 어휘). 항목에 `spot` 1개를 붙이는 식(설정 파일만, 저장 키 0) |
| 켜짐 | 게시일(KST, id의 YYYYMMDD)부터. 자산 있음·체험 아님·잠금 아님·인증카드 캡처 아님(`data-screenshot-hide`) |
| **꺼짐(먼저 오는 것)** | ① 그 기능 도착 화면을 **게시일 이후 1회 방문**(기존 `feature-usage` visits의 `lastVisitedAt ≥ 게시일` — 새 저장 키 없음) ② 게시일 + 30일(`WHATS_NEW_UNSEEN_DAYS` 재사용). 닫기 버튼 없음 |
| 새 소식과의 관계 | 시트를 읽어도 꺼지지 않는다 — '읽음'과 '써 봄'은 다르고, 팁을 X로 닫은 사용자도 제자리에서 만나야 하므로. 시트 `바로 가기`로 들어가면 방문이므로 함께 꺼진다 |
| 노출 상한 | **한 화면 최대 1개**(아래 우선순위로 결정, 결정적·테스트 가능). **홈·하단 네비·상단 헤더·더보기에는 0개**(첫 화면 최소, 4.82 '점·배지 금지' 유지) |

| 접근성 | 시각 `새`는 `aria-hidden`, 버튼 안 `sr-only` ", 새 기능" |

## ③ 기능별 개선안 (★ = 권고)

### 1. 종목 한 장 — 펼침 안 텍스트 링크 → 버튼
- **★A. 펼침 첫 줄 아래 brand 틴트 버튼** (`mock-m1-stock-card-{320,375,1280}-{light,dark}`)
  - 이름·`총 N주` 줄 바로 아래, 칸 그리드 위. `[LineChart size-4] 가격 흐름·평단 보기 [새] ›`
  - `flex min-h-10 w-full sm:w-auto items-center gap-2 rounded-lg bg-brand/10 dark:bg-brand/15 px-3 text-sm font-semibold text-indigo-600 dark:text-indigo-300`, chevron `ml-auto`, press `scale-[0.96]` + `transition-[scale,background-color]`. 바깥 `px-3 dark:px-4 pb-2.5`(카드 12 → 버튼 lg 10 동심)
  - 1280은 `sm:w-auto` — 이름 아래 왼쪽에 붙어 시선 흐름 안(현재 오른쪽 끝 1,000px 이탈 해소). 분할·비분할 같은 자리, `data-testid="stock-page-entry"` 유지
  - 높이: 기존 링크 2줄째(≈28px) 제거 + 버튼 줄 50px = **+22px**(4.81 상한 28px 이내)
  - 대비 실측 라이트 5.08 / 다크 8.44
- **★A+. 기존 사용자 첫 카드 1회 자동 펼침**(기존 `defaultOpen` 재사용): `새` chip이 켜진 동안, **앱을 연 뒤 상세·주식 첫 진입 1회만** 첫 카드를 펼친다(모듈 메모리 플래그, 저장 0 — `marketCompareEnteredInApp`와 같은 방식). 방문하면 끝. 펼치지 않으면 `새`가 아무에게도 보이지 않는 문제를 막는다. → cto 판정 요청(Q-C1)

### 3·4. 최근 7일 결산 · 월별 기록
- **★A. 허브 칩 줄**(2-A와 같은 줄)

  - 칩 줄은 카드 전체 클릭 영역 **밖 형제**로 둔다(중첩 인터랙티브 금지 — KpiCard는 상단 영역만 클릭)
  - 이동: `최근 7일` = APP_FEATURES `week-causes` target 그대로 / `월별 기록` = 월 탭 + 월별 기록 카드로 스크롤(`init.focus`, history 상태만, `motion-safe:smooth`) / `시장과 비교` = `change-market`(비교할 종목 0이면 칩 숨김). 월별 기록 카드가 안 그려지는 조건(기록 달 <2)이면 `월별 기록` 칩 숨김
