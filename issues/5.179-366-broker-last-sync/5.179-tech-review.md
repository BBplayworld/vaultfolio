## 2. 데이터 계약 구현안 (`asset-refresh-status.ts`에 추가)
- 타입: `BrokerSyncCategory = Exclude<Stock["category"], "unlisted">`, `BrokerSyncEntry { broker; category; date; count }`. `AssetRefreshMeta.brokers?: { stock?: unknown }`.
- `parseBrokerSynced(meta: unknown, today): BrokerSyncEntry[]`: 순수 함수이고 전체를 try/catch로 감싼다(throw 0). spec 5장의 버림 규칙을 그대로 따른다.
  - 날짜는 `^\d{4}-\d{2}-\d{2}$` 형식에 더해 `Date.UTC` 왕복으로 같은 날인지 확인하고, `today`보다 늦으면 버린다.
  - count는 `Number.isInteger(n) && n >= 0`일 때만 받는다.
  - 중복은 `sameBroker && category`로 판정하고 늦은 날짜를 남긴다.
  - 저장 모양이 배열이므로 `__proto__`가 들어와도 일반 문자열 값일 뿐이다. 객체 키 읽기는 `Object.hasOwn`만 쓴다.
- `markBrokersSynced(scopes)`: 동작 순서는 아래와 같다.
  - ① 적용 전 원본 `stock`을 읽는다. 키가 없으면 `undefined`다.
  - ② upsert하고, 60항목을 넘으면 오래된 날짜부터 버린다.
  - ③ `brokers`가 plain object이면 다른 키를 보존한다.
  - ④ `writeMeta({ brokers })`로 쓴다.
  - ⑤ 다시 읽어 모든 범위가 들어갔는지 검증한다.
  - ⑥ 결과로 `{ prev, applied } | null`을 돌려준다. null이면 쓰기 실패다.
  - ⑦ `BROKER_SYNCED_EVENT`를 보낸다.
- `restoreBrokersSynced(prev, applied)`: 현재 `stock`을 정규화 JSON으로 비교한다. `applied`와 같을 때만 `prev`로 되돌리고, prev가 없으면 `stock` 키를 삭제한다. 끝나면 이벤트를 보낸다. `restoreCategoryRefreshed`와 같은 방식이다.
- 종목 수 스냅(새 파일 `src/lib/asset/broker-synced.ts`, 순수 함수):
  - `writableScopes(d, sel, afterStocks)`: spec 4장의 1~4를 계산한다. 남는 삭제 후보는 "`afterStocks`에 같은 id가 같은 broker·category로 남아 있음"으로 판정한다. 이렇게 하면 이관·이어받기가 자동으로 빠진다.
  - `scopeCount(stocks, broker, cat)`: `sameBroker`이고, delisted가 아니며, qty가 0보다 큰 **항목 수**를 센다. `BrokerTotalRow.count`(티커 중복 제거)와 정의가 다르므로 섞지 않는다.
  - 표시 쪽: `computeBrokerTotals`의 행에 선택 필드 `scopeCounts?: Partial<Record<BrokerSyncCategory, number>>`를 더한다. 값은 그룹의 live 항목을 category별로 센 것이고, 미지정 행은 넣지 않는다. 코인 `exchange-totals.ts`의 `satisfies`는 필드가 선택이라 영향이 없다.
  - `syncedLabel(row, entries, todayKst)`: 필요한 범위가 모두 `sameBroker(e.broker, row.name)`로 매칭되고 count도 같을 때만 가장 이른 날을 돌려준다. 형식은 `M/D`이고 해가 다르면 `YYYY.M.D`다. 아니면 null.
  - 쓰기와 표시는 묶는 규칙이 미세하게 다를 수 있다(쓰기는 scope.broker 기준, 표시는 그룹 raw 기준). 어긋나면 수가 맞지 않아 날짜를 숨기므로 거짓 날짜는 나오지 않는다.
- 손상 처리: 파서가 `[]`를 돌려주면 날짜 조각이 0이 된다. `categories` 경로는 C1 정규화 덕분에 영향이 없다. 다음 쓰기에서 유효한 항목만 남겨 덮는다.
