## 1. 후보 그룹 (외화 거래일 때만 달라짐)
Select 안 순서: `연결 안 함` → (같은 통화 현금) → `원화 현금` → `대출`. 기본 선택은 항상 `연결 안 함`(기억·자동 선택 없음).
| 거래 통화 | 그룹 라벨 (SelectLabel, text-xs muted) |
|---|---|
| KRW(국내·코인) | `현금 계좌` / `대출` (현행 그대로) |
| USD | `달러 현금` / `원화 현금` / `대출` |
| JPY | `엔화 현금` / `원화 현금` / `대출` |
- 같은 통화 현금을 먼저 둔다(환산이 없는 쪽이 기본형). 원화 현금과 같은 통화 현금이 둘 다 있을 때만 두 그룹이 보이고, 비면 그 그룹만 숨김. 외화 거래에서 원화 현금 하나만 있어도 라벨은 `원화 현금`(어떤 환산인지 목록에서 읽히게).
- 항목 텍스트는 계좌명만(잔액 미표기, truncate). 매도의 잔액 0 대출 제외는 기존 규칙.
- 행 숨김 조건 불변: 즉시 반영 해제, 현금·대출 후보 0개.

## 2. 미리보기 환산 표기
- 주 줄은 **선택 계좌 통화**로 표기(4.56 형식 유지: 계좌명 + 전 → 후, 금액 각각 nowrap, 후 값 semibold).
  - `생활비 통장 3,000,000원 → 2,860,000원` (USD 100 × 1,400원 매수, 원화 계좌)
  - 같은 통화 계좌 선택 시 기존대로 `달러 통장 $1,000 → $900`.
- 보조 줄(text-xs muted, 기존 `preview.sub` 자리) 문구만 변경, 줄 추가 0:
  - 원화 계좌 외화 매수: `$100 × 1,400원만큼 현금이 줄어요` / 매도 `… 현금이 늘어요`
  - 대출: `$100 × 1,400원만큼 대출이 늘어요`(매수) / `… 대출이 줄어요`(매도)
  - JPY: `¥10,000 × 100엔당 920원만큼 현금이 줄어요`
  - 수수료 있으면 끝에 ` (수수료 포함)`. 같은 통화·국내 계좌의 보조 문구는 현행(`거래 금액만큼 …`) 유지.
- `$100 × 1,400원`(식 부분)은 `whitespace-nowrap` 한 덩어리, 나머지는 `break-keep text-pretty`. 320에서 `$1,234.56 × 1,385원만큼 현금이 줄어요 (수수료 포함)`은 2줄 허용(어절 중간 줄바꿈 0, C25), 박스 높이 증가는 이 한 줄(12px×1.5)뿐.
- 오류 박스의 금액·계좌 통화 표기도 선택 계좌 통화. 모션·마운트 유지·`aria-live` 현행 그대로.
- 체결 환율 칸: 원화 계좌 선택 시 비어 있으면 현재 환율을 채움(수정 가능), 연결 안 함으로 되돌려도 유지(challenge B). 라벨·배치 변경 0.
- 환율 없음 차단 오류(신규 문구, `cash-link-error` 재사용·같은 위치·클래스·`role="alert"`): `환율을 확인할 수 없어요. 체결 환율을 입력하거나 연결 안 함으로 저장해 주세요.`

## 3. 안내 1줄 (연결 후보는 있는데 거래일이 이번 달이 아닐 때만)
- 문구: `지난달 거래는 계좌 잔액을 바꾸지 않아요` (20자, 320 1줄 ≈240px). 투자 조언·금액·`연동`·`자동` 없음.
- 위치: 즉시 반영 박스 바로 아래(연결 계좌 행이 있을 자리). 박스 없이 `<p data-testid="account-link-note" className="px-1 text-xs text-muted-foreground break-keep text-pretty">` 한 줄. 아이콘·강조·투명도 `/NN` 없음(muted 토큰 그대로).
- 조건: 즉시 반영 ✓ + 후보 ≥ 1 + 거래일이 이번 달(KST) 아님. 즉시 반영 끔(토글이 이유를 보여 줌)·후보 0개는 줄 없음. 공용이라 국내·코인에도 표시. 거래일을 이번 달로 바꾸면 줄 → 행으로 즉시 교체(모션 없음, 높이 변화 ≤ 박스 1개).
- 컷 기준: 320에서 2줄이 되면 문구를 줄이거나 뺀다(현 문구는 1줄).

## 6. 품질 체크리스트 (qa, 320·375·1280 × 라이트·다크)
1. USD 종목 + 원화 현금만 보유: 연결 계좌 행 노출, Select에 `원화 현금`·`대출` 그룹(달러 현금 그룹 없음). USD 현금도 있으면 `달러 현금` → `원화 현금` → `대출` 순서.
2. JPY는 `엔화 현금` 라벨, KRW 종목·코인은 `현금 계좌`·`대출` 그대로(diff 0).
3. 미리보기 주 줄이 선택 계좌 통화(원화 계좌에 `$` 없음), 값 = 수량×단가±수수료 × 체결 환율(원 반올림)과 일치. 같은 통화 계좌는 `$` 유지.
4. 보조 줄이 `$100 × 1,400원만큼 현금이|대출이 줄어요|늘어요` 형식, 수수료 있으면 `(수수료 포함)`, 새 줄 추가 0(미리보기 영역 줄 수 현행과 같음).
5. 320에서 보조 줄 어절 중간 줄바꿈 0, 식 부분 한 덩어리, 가로 넘침 0 (C25).
6. 원화 계좌 선택 시 체결 환율 칸이 비어 있으면 채워지고, 연결 안 함으로 되돌려도 유지, 칸을 비우고 저장해도 거래에 환율이 저장됨.
7. 환율 없음 시 `cash-link-error` 문구 정확·`role="alert"`·저장 차단, 부족·초과 오류의 금액이 선택 계좌 통화.
8. 안내 줄 `account-link-note`: 후보 있음 + 거래일 지난달 → 표시(국내·코인 포함), 이번 달 → 행 표시·줄 없음, 즉시 반영 끔·후보 0개 → 줄 없음, 320 1줄, text-xs muted.
9. 거래일을 이번 달↔지난달로 연타 전환해도 값이 어긋나지 않고 선택 계좌는 `연결 안 함`으로 복귀(이번 달로 돌아와도 기억 없음).
10. 신규 문자열에 `연동`·`계좌 연결`·`자동`·`동기화`·`환전`·금액 예시 0(문자열 단언), 신규 색·토큰·`transition: all` 0, 결산·홈 UI diff 0.
11. 키보드: Tab → Select 방향키·Enter, 포커스 링 가시. 히트영역 박스 ≥ 40px.
