# 4.xx 월별 기록 — spec (#127)

작성: planner-designer 2026-11-09 · 근거 origin/main dc4133d · 선행 문서 `4.xx-direction.md`(사업·경험·합의), `4.xx-challenge.md`(S1~S9)
신규 기능 → **최종 반영은 대표 승인**(위임 머지·COO 자체 승인 아님). risk:low(읽기 전용).

## 1. 문제
엑셀에 매달 자산군별 금액을 한 줄씩 적어 온 사용자는 결산을 본 뒤에도 '여러 달 흐름'을 보려고 시트를 연다. 앱의 결산은 화살표로 한 달씩만 보여 주고, 자산군별 금액은 저장돼 있지만(`MonthlyAssetSnapshot.breakdown`) 화면에 그리는 곳이 없다.

## 2. 목표 행동
- 결산 화면에서 `월별 기록` 행을 눌러 지난 여러 달의 자산군별 금액을 한 장에서 보고 닫는다.
- 다음 결산 때 다시 연다. 시트 안에서는 아무것도 누르지 않는다.

## 3. 범위
- 포함
  - 진입 행 1개: 성과 › 자산 변화 › 전체 › 월 탭, `CompositionBlock` 아래·`SettlementAiButton` 위. `SettlementAiButton`과 같은 외피(`AI_ROW_SURFACE`), 새 색 0, `data-screenshot-hide`.
  - 시트 1개 `월별 기록`: 캡션 + 표(읽기 전용). 시각 사양은 ui-designer `4.xx-ui.md`.
  - `SCREEN_TITLES` 1키 `"activity:change:monthly-log": "성과·자산 변화·월별 기록"`.
- 줄일 수 있는 것(이미 줄임): 전월 대비 열, 아카이브, 연 탭 노출, 차트.
- 하지 않을 것: 증감·%·비중 열 / 행 탭으로 결산 이동 / 선택 달 강조·월 화살표 연동 / 정렬·접기·필터 / 차트 / 메모 / `dailyArchive` 읽기(2027-07 재검토) / 복사·내보내기·공유 이미지·파일(C54) / 평가·요약·최고/최저 강조 / 목표선 / 과거 달 입력 / 홈 팁·알림 / 연도 줄 / 주식 범위 노출 / '월말' 단어(C56).

## 4. 사용자 흐름
1. 홈 결산 팁·허브 결산 카드·성과 메뉴로 자산 변화 › 전체 › 월 탭에 들어온다.
2. Hero → 변화 원인 → 자산 구성 변화 아래에 `월별 기록` 행이 보인다(노출 조건 6절). 보조 줄 `8월~11월 · 4개월 기록`.
3. 행을 누르면 시트가 열린다. 이때 GA page_view 1회.
4. 시트: 제목 `월별 기록` → 캡션 `그 달 마지막으로 앱을 연 날, 그때까지 맞춘 값이에요` → (조건부 캡션) → 표. 표는 이번 달(`진행 중`)이 맨 위인 최신순.
5. 읽고 닫는다(X·바깥 탭·Esc, 기존 시트/다이얼로그 닫기와 같게). 결산 화면은 열기 전의 선택 달·스크롤 위치 그대로다.
6. 월 화살표로 다른 달로 가도 행 문구와 시트 내용은 바뀌지 않는다.

## 5. 표 사양 (정보 구조)
- 열 순서: `월`(아래 작은 글씨 기록일) · 부동산 · 실물 · 주식 · 암호화폐 · 현금성 · 대출 · 임차보증금 · `순자산`. 자산 라벨은 `COMPOSITION_LABELS` 재사용, 부채 2종은 앱 기존 명칭.
- 자산군 열은 '검증 통과 줄 중 한 번이라도 0이 아닌 것'만 보인다(S1).
- 대출·임차보증금 칸은 `−` 부호(예 `−1.2억원`). 손익 빨강/파랑 금지.
- 월 라벨: `settlementName(month, today, false)` 규칙(올해 아니면 `25년 12월`). 기록일: 이번 달 `오늘`, 지난 달 `formatSettlementPoint(date)`(`11/28`), `date` 없는 레거시 `formatSettlementPoint(null, month)`(`2026-07 기록`, S2).
- 금액: 모바일 `formatShortCurrency`, 1280px `formatCurrency`(원 단위, S6). 0은 `0원`. `—`는 '순자산만 있는 줄'의 자산군 칸에만.
- 기록 없는 달(첫 기록 달 ~ 이번 달 사이 빈 달): `기록 없음` 한 줄. 보간 0. 첫 기록 달보다 앞은 줄을 만들지 않는다.
- 375px: 자산군 4개까지 가로 스크롤 없음(필수). 자산군 5개 이상 또는 320px에서 넘치면 `월`·`순자산` 칸 고정 + 사이 자산군 칸만 가로 스크롤. 열 머리줄은 세로 스크롤 시 고정.
- 접근성: 실제 표 의미(열·행 머리)로 읽혀야 한다(예 "11월, 주식 1,234만원").

## 6. 노출 조건
- 전체 범위 월 탭 · 결산 정상 상태(`computed.ok`) · 선택 달이 `first_month` 아님 · 자산 1건 이상 · 기록된 달 수 = |저장된 달 ∪ {이번 달}| ≥ 2.
- 하나라도 아니면 행을 렌더하지 않는다(대체 문구·약속 문구 없음, C20).

## 7. 엣지 케이스
| 경우 | 동작 |
|---|---|
| 빈 데이터(스냅샷 0 또는 자산 0) | 결산 빈 상태 그대로, 행 없음 |
| 첫 사용자(이번 달만) | 행 없음. 다음 달 첫 접속일부터 행이 생김 |
| 2개월(지난 달 1 + 진행 중) | 2줄 표 |
| 13줄(보존 최대) | 13줄 + 조건부 캡션 `최근 13개월까지 보여요`. 다음 달 가장 오래된 줄이 빠짐(롤링, 알려진 한계) |
| 9월처럼 빠진 달 | `기록 없음` 줄, 기록된 달 수에서 제외 |
| breakdown 없는 레거시 달(2026-07-23 이전) | 자산군 `—`, 순자산만 + `—인 달은 순자산만 기록돼 있어요` |
| `tenantDeposit` 필드 없는 달 + 임차보증금 보유 | 합 불일치 → 위와 같음 |
| `physical` 필드 없음 | 0으로 읽음. 실물이 없던 달이면 합 일치 → 정상 줄 |
| 구버전 기기가 쓴 달(실물 보유인데 `physical` 없음) | 합 불일치 → 순자산만 |
| 11월 실물 신규 등록 | 실물 열 생김, 이전 달 칸은 `0원`(— 아님) |
| USD 현금·해외주식 | 저장된 원화값 그대로(그달 환율), 이번 달은 오늘 환율. 새 환산 0 |
| 오래된 데이터(결산 창에만 접속) | 11월 줄 기록일 `11/3`처럼 그대로 표시. 꾸미지 않음(C56) |
| 일부 갱신(그날 일부 자산만 캡처) | 그 자산은 이전 값. 캡션 1문장으로만 알림(줄별 표시 정보 없음, 알려진 한계) |
| 시트 열린 채 동기화·복원(`snapshotVersion` 변경) | 다시 읽어 갱신. 줄이 1개 이하로 줄어도 닫지 않고 남은 줄 표시, 0줄이면 `기록된 달이 없어요` |
| 연 경계(1월) | 지난해 달은 `25년 12월`, 13개월 안이면 계속 보임 |
| 순자산 음수 | `−` 부호 그대로 |
| 표시 반올림 | 짧은 금액은 내림 표기라 열을 눈으로 더하면 순자산과 몇 만원 다를 수 있음(알려진 한계, 1280px은 원 단위) |
| 체험 모드·preview | 데모 4개월(@M-3 레거시·breakdown 없음 포함)로 행·`—` 줄·레거시 기록일 확인 가능. 체험 모드 GA 미전송(`trackScreen` 기존 동작) |

## 8. 데이터 계약 (읽기 전용)
- 입력(전부 기존): `readMonthlySnapshots()`(SettlementView의 `monthly`, `snapshotVersion` 의존), `summary.netAsset`, `buildLiveAttributionCurr(...).breakdown`(SettlementView의 `live`), `snapshotDate`·`formatSettlementPoint`·`settlementName`·`shiftMonth`.
- 줄 값
  - 이번 달: 자산군 = live breakdown, 순자산 = `summary.netAsset`(결산 Hero 끝값과 같은 값). 저장된 이번 달 스냅샷이 있어도 live를 쓴다.
  - 지난 달: 자산군 = `snapshot.breakdown`, 순자산 = `snapshot.netAsset`(= `settlementDelta`의 `w.end.netAsset`).
- 합 검증(S3): `|realEstate + (physical ?? 0) + stocks + crypto + cash − loans − (tenantDeposit ?? 0) − netAsset| > 1` 또는 breakdown 없음 → 그 줄은 순자산만.
- 새 코드는 줄 조립 순수 함수 1개(제안 `src/lib/report/monthly-log.ts`, state-and-utils 등록)와 컴포넌트뿐. 새 금액 계산·환산·보간 0.
- 쓰기 0: localStorage·저장 키·스키마·마이그레이션·동기화·공유 토큰·서버 전송 변경 0. 렌더·effect에서 저장 함수 호출 0(C16).

## 9. 지표 계측
- 시트가 열릴 때 `trackScreen("activity:change:monthly-log")` 1회(키 정규식 통과, 27자). 월 탭 진입·행 노출만으로는 보내지 않는다.
- `trackScreen` 기존 중복 거름 때문에 같은 세션에서 다른 화면 없이 연달아 다시 열면 1회로 센다(의도: 방문당 열람). 닫을 때 화면 키 복원은 하지 않는다(구성 블록과 같은 방식, 새 GA 함수 0).
- 파라미터에 금액·달 수 등 값 0. 신규 맞춤 정의 0.
- 판독: 머지~1/10 활성 사용자(대표 기기 제외) ≥3 유지 / 2 → 1/31 재판독 / 0~1 제거 후보(type:simplify). 보조 조회수/사용자 목표 1.5, 1/31에 1.2 미만이면 유지하되 v2 열지 않음. '성과·자산 변화' 사용자 수는 #125와 겹쳐 판정에 쓰지 않음. 판독 경계 = 머지 시각(#125 머지 시각 별도 기록).
