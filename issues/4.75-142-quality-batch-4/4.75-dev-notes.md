## 변경 요약
1. **직접 추가 매수일** (`forms/asset-update/input/stock-input.tsx`)
   - 수익률 역산 자동 과거 추정 useEffect·`isEstimatedDate`·`purchaseDateTouchedRef` 제거. 신규 기본값 = `resyncNewPurchaseDate(todayKst())`(4.74 유틸 재사용, 올해 1/1 KST). 안내 문구 "기본값은 올해 1월 1일입니다. 실제 매수일을 알면 수정하세요."(신규만). 수정 경로는 editData의 저장된 매수일 유지.
   - `estimatePurchaseDateFromReturn`(`lib/number-utils.ts`)은 호출처가 stock-input 하나뿐이라 기능 제거에 따른 정리로 삭제. 이 함수의 전용 테스트는 원래 없었고 삭제·우회한 테스트 0.
   - **결산 예측 투입일(C74)**: 판단 = 만든다. 직접 등록 종목(1/1 기본)은 이번 달 등 1/1이 속하지 않는 구간에서 투입 0으로 읽혀 시세 효과로 오귀속된다(4.74 D1과 같은 문제). 최소 수정으로 `resyncInflowDate` 정규식을 `stock_<ms>`(직접 등록 id `stock_${Date.now()}`)까지 확장, 기본값 1/1 그대로면 만든 날 투입. 매수일을 고친 항목·1/1 당일 등록·기존 `stock_<ms>` 데이터 중 매수일≠만든 해 1/1인 것은 영향 없음. 단 과거에 만든 직접 등록 종목 중 매수일을 우연히 만든 해 1/1로 둔 것은 만든 날로 읽힘(결산 예측 구간 투입 추정만, 상세 매수일·배당 불변). 소비처: 배당(`payoutDate < purchaseDate`)·보유 기간·연환산은 purchaseDate 그대로(1/1 기본 의도, main 대비 이전 추정값보다 보수적), 결산 투입만 `resyncInflowDate`.
2. **체험·데모 칩** (`lib/finance/today-chip.ts`): `getStockChipQuote`에서 장중(live)·마감직후(afterCloseGap, 둘 다 현재가 사용)는 `isTrialMode()` 또는 `stock.id` 접두 `demo_st_`이면 null. 장 종료 후 종가 쌍·chipPair 경로 유지.
3. **자산 변화 › 주식 목록** (`views/activity/profit-chart.tsx`): 행 `grid-cols-1 min-[400px]:grid-cols-[1fr_auto]`(+`gap-y-1`, `min-[400px]:items-center`), 우측 `text-left min-[400px]:text-right min-[400px]:shrink-0`, 금액 줄 `min-[400px]:justify-end`, 티커 `truncate`.
