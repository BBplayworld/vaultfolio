## 1. 종목 직접 추가 매수일 자동 과거 채움
- **원인**: 상장일이 아니라 "수익률 역산 추정"이다. `stock-input.tsx` 83~103행 useEffect가 신규 등록 중 매수일을 안 만졌고 현재가>평단가이면 `estimatePurchaseDateFromReturn`(`src/lib/number-utils.ts` 113행, 연 8% 가정, 최대 30년 전)으로 `purchaseDate`를 채우고 "수익률(약 연 8% 가정) 기준 추정" 안내(611행)를 띄운다. 검색 선택이 현재가를 채우고 평단가가 이미 있거나 입력되면 발동. 2009-01-13 ≈ 17.8년 = 현재가/평단가 약 3.9배.
- **시점**: fb7af6e `[#4.18] 자산 성적표 (#29)`(2026-07-23)부터. 이후 변경 없음.
- **재현**: 신규 > 주식 > 검색으로 종목 선택(현재가 자동) > 평단가를 현재가의 1/4 정도로 입력 > 매수일이 약 17~18년 전으로 바뀜(안내 문구 표시됨. 평단가 0이면 오늘 유지).
- **영향(저장 시)**: ① 배당 예상: `dividend-yield.ts:49`, `dividend-chart.tsx:116`, `monthly-dividend-stocks.tsx:97-107`이 `payoutDate < purchaseDate`만 제외 → 과거로 당겨질수록 지난 배당이 "받은 것"으로 포함(과대). ② 결산: `estimatePeriodInflows`(asset-report 매수일 기반 추정)가 매수일이 속한 구간에 매입액 유입으로 잡음 → 실제 투입 시점과 어긋나 시세 효과 분해(price 잔차)가 왜곡, 현재 구간에는 투입 0. ③ 연환산: `annualizeReturnRate`가 보유 17년으로 나눔 → 결과가 항상 약 8%로 수렴(순환값, 정보 없음). 저장 스키마 변화 없음, 데이터는 사용자가 상세에서 수정 가능.
- **한계**: 손실·동가는 오늘 유지. 사용자가 실제 매수일을 모르는 신규 입력에서만 문제. 추정 안내는 있으나 저장 시 별도 확인 없음.
- **기대 동작 제안**: 자동 추정 제거(useEffect와 `isEstimatedDate` 삭제), 기본값은 "올해 1/1"(4.74 새 종목 매수일 1/1 규칙과 동일, 대표 결정 11-10 정합) + 안내 "실제 매수일을 알면 수정하세요". 대안 오늘은 배당·결산 영향이 가장 작지만 수익률 모순(오늘 매수인데 이익)이 남고, 빈 값은 필수 필드(`*`)라 부적합. `estimatePurchaseDateFromReturn`은 다른 호출처가 없으면 함께 제거(테스트 정리).
- **규모**: 소(stock-input 약 −25/+3행, 기존 estimate 테스트 정리). **위험 low~medium** (저장 스키마·서버 전송 변경 0, 신규 입력 기본값만 변경). 기존 저장 데이터 소급 없음.

## 2. 체험(?trial=1)·데모 '오늘' 칩 비현실 값
- **원인**: `today-chip.ts` `getStockChipQuote`가 장중(live)·마감직후 국내 대체 경로에서 분자를 `stock.currentPrice`로 쓴다(147, 154, 160행). 체험·데모는 `isBackgroundWorkBlocked()`(체험 포함)로 시세 갱신이 꺼져 `demo-data.json`의 고정 currentPrice(삼성 70000, 하이닉스 190000, AAPL 225, NVDA 130 등)가 그대로이고, 분모(`ref.refPrice`)는 `/api/finance/profit` 실제 전일 종가라 어긋남(−15~−83%). 장 종료 후 경로(167행)는 두 종가만 써서 정상 → **장중·마감직후에만 발생**. 4.72(962830d)에서 칩 도입, 4.73 등락률 순·헤더 가중에 전파.
- **재현**: 평일 장중 `/?trial=1` > 상세 > 주식, 헤더·종목 '오늘' 칩과 등락률 순.
- **영향**: 신규 방문자 첫 인상 화면. 시장과 비교(`market-compare-view`)는 종가 쌍만 사용해 영향 없음.
- **최소 수정안**: 데모에선 live 분자가 의미 없으므로 `getStockChipQuote` live·gap 분기에서 데모면 null(칩 숨김) 반환. 판정은 `isTrialMode()`(의존 0 모듈) + preview 데모 주입 종목(`stock.id` 접두 `demo_st_`)을 함께 처리. 호출 지점 `computeTodayChip` 하나만 막으면 stock-tab 3곳이 모두 해결. 대안(데모 현재가를 실종가로 갱신)은 네트워크 0 원칙·데모 고정 값과 충돌해 비권장. 테스트: today-chip 단위 테스트에 데모 케이스 1개.
- **규모**: 소(코드 약 +6행, 테스트 +1). **위험 low**.

## 3. 성과 > 자산 변화 > 주식 종목별 목록 320px 눌림
