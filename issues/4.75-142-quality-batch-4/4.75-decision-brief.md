# 4.75 decision-brief (#142 품질 묶음 4, PR #143, 기준 커밋 e160b0e)

## 권고: 반영 — COO 자체 승인(risk:medium, 위임 머지). 단 머지 전 G1(UI 승인 증분 기록) 필요
가짜로 만든 과거 매수일이 배당·결산·연환산을 왜곡하던 결함을 대표 11-10 결정(새 종목 매수일 = 올해 1월 1일)과 같은 규칙으로 바로잡고, 체험 첫 화면의 비현실 등락과 좁은 폭 겹침을 없앤다. 저장 형식·서버 전송 변경 0.

### 판정 ① 매수일 자동 추정 제거 = 버그 수정(COO 자체 승인 가능), 대표 승인 불필요
- 근거: 추정값은 사용자가 입력하지 않은 날짜(연 8% 가정 역산, 예 2009-01-13)를 저장해 ① 지난 해 배당까지 받은 것으로 계산 ② 결산 예측에서 투입 시점 오귀속 ③ 연환산이 항상 약 8%로 수렴(가정값을 되돌려 보여 줌). 화면 수치를 틀리게 만드는 동작이라 결함 수정으로 본다.
- 정합: 대표 11-10 #139 결정 '새 종목 매수일 = 올해 1월 1일(올해 배당 포함 목적)'과 같은 값. 팀은 4.50 challenge K2에서 이미 이 추정을 결산 소급(C8) 이유로 맞추기 경로에 쓰지 않기로 했다. LEARNINGS·DECISIONS에 이 추정을 유지하라는 대표 결정·반려 이력 없음. 기존 저장 데이터 소급 0, 큰 UI 방향 변경 아님(입력 기본값 + 안내 1줄) → 위임 ⑦ 충족.
- 대표 확인 대상(대표 지적·반려 영역 재시도)에 해당하지 않음. 다만 4.18에 대표가 직접 만든 동작을 없애는 것이므로 사후 보고 문장에 "4.18부터 있던 수익률 역산 추정 제거"를 명시한다(이견 시 PR revert 1회로 원복).
- 대표 답 대기 중인 '첫 스크린샷 등록 매수일(현재 오늘)'은 이번 diff 밖. 답이 '1월 1일'이면 세 경로가 같아지고, '오늘'이면 직접 추가도 같은 답을 따라 후속 처리.

## 핵심 반영 내용
- `#142` 직접 추가 매수일 자동 과거 추정 제거(올해 1월 1일 기본 + 안내), 체험·데모 장중 '오늘' 칩 숨김, 자산 변화 › 주식 목록 좁은 폭 겹침·헤더 금액 줄바꿈 수정

## 무엇이 바뀌나
- 주식을 직접 추가하면 매수일이 몇 년 전 날짜로 저절로 바뀌지 않고 올해 1월 1일로 시작하며, 바로 아래에 고치라는 안내가 보인다.
- 체험 화면에서 장중에 '오늘 −35%' 같은 엉뚱한 값이 사라진다(장 마감 뒤 'M/D 종가'는 그대로).
- 휴대폰 좁은 폭에서 자산 변화 › 주식 목록의 종목명·금액이 겹치지 않는다.
