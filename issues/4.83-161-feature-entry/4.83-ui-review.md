## 결함 (developer 수정 요청)
- D1 (중, 라이트 320·375) `activity/hub-change-rows.tsx` `ROW` 클래스의 `rounded-md` + 부모 `divide-y` 경계선이 겹쳐, 최근 7일·월별 기록 행 아래 구분선 양끝이 둥글게 휘고 그림자처럼 보임(mock은 직선). 기대: `ROW`에서 `rounded-md` 제거(hover 면 radius는 `rounded-none` 또는 경계선을 행이 아닌 래퍼/`border-t` 의사요소로) → 구분선 직선, hover/press 면은 유지. 캡처: `ui-review-hub-375-light.png`.
- D2 (소, 320) 허브 `시장과 비교` 행 값이 `1주` / `코스피 -7.8%` 2줄로 접혀 행 56px(다른 행 44). 기대: 320에서도 한 줄(`1주 코스피 -7.8%`, mock 동일) — `MarketIndexValues restBelowSm`의 줄바꿈이 `1주`만 떼어 놓지 않게(값 전체 `whitespace-nowrap` 또는 이름 열 `shrink` 허용). 어절 단위 끊김이라 C25 위반은 아니나 위계상 어색.
- D3 (소, 320) 펼침 이름 줄 `1년 주가 등락` / `+101.0%`가 두 줄로 갈라져 이름 줄 100px(mock 한 줄, 375는 80으로 같음). 기대: 320에서 `1년 주가 등락 +x%`가 한 줄(스파크 폭 72 유지, 필요하면 `주가 등락`+값을 `whitespace-nowrap`하고 스파크 폭을 64로) — 펼침 높이 증가 +20px 제거. 값이 짧은 종목이면 한 줄이므로 데이터 의존 문제임을 감안해 우선순위 낮음.
- 참고(수정 불필요): 음수 부호가 `-`(하이픈)이고 mock은 `−`. 앱 전체 표기가 `-`이므로 구현이 맞다.
