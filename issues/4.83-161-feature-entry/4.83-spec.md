# 4.83 신기능 진입 경로 개선 — spec (planner-designer)

작성 2026-11-11 · #161 · 근거: 대표 승인(11-11) "v2 권고안 그대로 + 펼침 '총 N주' 제거", `4.83-ui-proposal-v2.md`(T-A·R-A·H-A), `4.83-ui-proposal.md`(v1 ② `새` 규칙·④ 하지 않을 것), 코드 origin/main 95abcdb.
시각 사양(크기·토큰·모션)은 v2 문서가 정본. 이 문서는 흐름·문구·정보 구조·수용 기준만 정한다.

## 1. 문제
최근 기능(종목 한 장·시장과 비교·최근 7일·월별 기록)은 이미 아는 사람만 찾아 들어간다. 상세·주식 요약 아래에는 모양이 다른 입구 3개(요약 안 글줄, X-Ray 상자, 세금 문장 상자)가 따로 쌓여 있다. `종목 보기`는 펼친 뒤 오른쪽 끝에 붙은 작은 링크라 각주처럼 읽힌다. 성과 허브에는 최근 7일·월별 기록·시장과 비교로 가는 입구가 없다.

## 2. 목표 행동 (관찰 가능)
- 상세·주식 사용자가 요약 바로 아래 타일을 눌러 시장과 비교·X-Ray·세금으로 이동한다(1탭).
- 종목을 펼친 사용자가 이름 줄을 눌러 종목 한 장으로 이동한다.
- 성과 허브 사용자가 `자산 변화` 카드 안 행을 눌러 최근 7일·월별 기록·시장과 비교로 바로 이동한다(1탭, 월별 기록은 스크롤 없이 보임).

## 3. 범위
**포함**: ① 상세·주식 도구 타일(T-A) ② 펼침 이름 줄 = 종목 한 장 입구 + 1년 미니 흐름(R-A, 폴백 R-C) ③ 성과 허브 `자산 변화` 카드 안 행 3개(H-A) ④ `새` 표시(v1 ② 규칙, 아래 6절로 범위 축소) ⑤ 새 소식 바로 가기 대상 정정(04·05·07) ⑥ 주 탭·월별 기록 방문 기록 ⑦ (cto 확정 대기) 첫 카드 1회 자동 펼침(A+)
**제거(줄이는 것)** — 3절 아래 표
**하지 않을 것**: v1 ④ 전부(홈·하단 네비·헤더·더보기의 점/숫자/`새`, 자동 팝업·코치마크, 펄스, 한 화면 `새` 2개 이상, 결산 팁 순서 변경, 더보기 이동(C57), 새 색·토큰, 30일 넘는 `새`, 체험·인증카드 캡처에 `새`) + 아래 9절

## 4. 사용자 흐름
**A. 상세·주식 상단**
1. 요약 박스(총 주식 평가금액) 바로 아래, 카테고리 줄 위에 타일 묶음(`role="group" aria-label="내 주식 도구"`, 보이는 제목 없음).
2. 타일 순서: 시장과 비교 → X-Ray 분석 → 해외주식 세금. 2개면 한 줄, 3개면 세금이 아래 전폭, 1개면 전폭, lg는 한 줄 3칸.
3. 시장 타일 → `change-market`(지금 글줄과 같은 이동·뒤로 라벨). X-Ray 타일 → `stocks-xray`, **미리보기 값의 축(axis)으로 열림**. 세금 타일 → 세금 관리 › 시뮬레이터(`setInitialTab("simulator")`).
4. 뒤로 → 상세·주식.

**B. 종목 한 장 입구**
1. 종목 행을 펼치면 첫 줄 = 이름·티커·분류 배지(그대로) / 둘째 줄 `1년 주가 등락 +90.6%` / 오른쪽 스파크라인 + `›`. 줄 전체가 버튼.
2. 누르면 지금 `종목 보기`와 같은 `openStockPage`(누른 행의 groupStockIds·원/달러 토글, origin `stocks`).
3. 1년 데이터는 펼칠 때만 요청(react-query 키 `["price-history", ticker, "1y"]` = 종목 한 장과 공유 → 열면 즉시 표시).

**C. 성과 허브 `자산 변화` 카드**
1. 카드 머리(제목·금액, 누르면 월 결산 — 지금 그대로) 아래 헤어라인 목록 3행. 행은 머리 클릭 영역 밖 형제(중첩 인터랙티브 0).
2. `최근 7일` → `{activity, change, init:{scope:"all", period:"week"}}` + `feature_use {category:"change_week_all"}` 1건(4.79 팁 진입과 같은 규칙).
3. `월별 기록` → `{activity, change, init:{scope:"all", period:"month", source:"menu", focus:"monthly-log"}}` → 월 탭 렌더 후 `monthly-log-title`이 뷰포트 안에 오도록 스크롤(reduced-motion 즉시). `focus`는 1회 소비, 해시·저장 없음.
4. `시장과 비교` → `change-market`.

**D. 새 소식 바로 가기 정정**

**E. 방문 기록(기존 `feature-usage` visits 안 버킷 추가, 저장 키·모양 불변)**
- `change-week`: 자산 변화가 범위 전체·기간 주로 **보일 때** 진입당 1회(init·탭 전환 모두). 지금은 어디서도 기록되지 않아 홈 팁 `주간 변화 원인`이 계속 0회로 추천됨 → 고쳐지는 의도된 차이.
- `monthly-log`: 월별 기록 카드가 50% 이상 처음 보일 때 화면 진입당 1회.

## 6. `새` 표시 — v1 ② 적용 범위 확정
| 항목 | 규칙 |
|---|---|
| 자리(spot) 5곳만 | ⓐ 상세·주식 **첫 카드** 이름 줄 둘째 줄 끝(01, visitKey `detail:stocks-item`) ⓑ 상세·주식 시장 타일 이름 뒤(02, `activity:change-market`) ⓒ 허브 행 `최근 7일`(03, `change-week`) ⓓ 허브 행 `월별 기록`(04, `monthly-log`) ⓔ 허브 행 `시장과 비교`(02, `activity:change-market`) |

## 9. 뺀 것(대표 확인용 명시)
- 진입원 GA(`source`) **추가 안 함**: `ga.ts`는 `page_title`만 보내고 `source` 등 매개변수는 GA로 나가지 않는다(코드 확인). 구분하려면 새 page_title이 필요한데 활성 6명 규모에서 판독 불가 → 도착 화면 page_view로만 본다. 경로별 기여는 측정하지 않는다(수용 한계).
- 자산 변화 `주` 칸 `새` 배지, 홈 원인 펼침 `최근 7일 원인 보기`, E1 글줄 brand 색(v1 ★B), 묶음 목록 카드(T-B), 펼침 미니 차트(R-B).
- 새 소식 신규 항목: **해당 없음**(C82 줄: 기능 추가 없음 — 기존 01~04 바로 가기가 새 입구로 도착. 항목을 늘리면 홈 팁 개수가 다시 올라 `새` 표시와 혼동, C84).

## 10. 완료 기준 (qa가 그대로 검사)
1. 상세·주식 요약 박스와 카테고리 줄 사이 입구는 `stock-tools` 1묶음뿐이고, `stock-market-entry-wrap`·X-Ray 상자(`X-RAY 인사이트` 텍스트)·세금 문장 상자 텍스트가 DOM에 0개다.
