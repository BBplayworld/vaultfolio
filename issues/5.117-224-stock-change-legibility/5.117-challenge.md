## 방향 요약 (대표 지시라서 direction 단계는 생략, 이 절이 대신함)
- 누구의 어떤 문제: 성과 › 자산 변화 › 주식에서 종목별 손익을 보는 사용자. 행마다 종목 코드 줄이 이름 바로 아래에서 시선을 끌고, 손익(500)이 이름(600)보다 약하다. 기준 종가 비교 영역의 부가 정보 4개가 12px다. 2번째 그룹부터 둥근 래퍼 위에 금색 선이 곡선으로 휘고, 첫 그룹에는 선이 없다. 그룹 경계는 금색 선·여백·머리 띠 3겹이다.
- 목표: 한눈에 "어느 종목이 얼마 벌고 잃었나"가 읽히게 한다(계산·데이터 변경 0).
- 왜 지금: 대표가 직접 지적했다. 이 화면은 GA 실사용 상위 화면(성과-자산 변화)에 속하고, 결산 창 중 재방문 동선이다.
- 성공 판정: qa 체크리스트 기준 화면 안 12px 글자 0, 코드 줄 0, 골드 선 0, 숫자 스냅샷 main과 동일. 익명 기기 지표는 없다(표시 개선이라 측정 대상 아님. 머지 후 '성과 자산 변화·주식' 체류를 참고만 함).

## ① ui 제안 항목별 판정
| 항목 | 판정 | 이유 |
|---|---|---|
| 종목 코드 줄 삭제(이름 없으면 `name \|\| ticker` 폴백 유지) | 채택 | 대표 직접 요청 |
| 로딩 스켈레톤 2번째 줄 삭제 | 채택 | 코드 줄을 지우면 스켈레톤에 흔적만 남음 |
| `(KST)` 머리 글자 삭제(칸 유지) | 채택 | 12px 요소이고, KST는 `마감 기준` 문구에 이미 있음 |
| `$1=₩…`·`마감 기준`·`휴장제외` text-xs → text-sm | 채택 | 대표 요청의 핵심("글자가 작아 안 읽힘") |
| `휴장제외` `amber-700 dark:amber-400`(80% 불투명도 제거) | 채택 | 키운 글자의 대비 확보(의미색 유지) |
| 합계 값 `font-semibold text-foreground`(크기는 유지) | 채택 | 같은 영역에서 핵심 값을 강조함. 360에서 9자리 금액이 넘칠 위험이 있어 크기는 올리지 않음 |
| 열 머리 font-medium | 채택 | 굵기만 바꾸므로 위험 0 |
| 트리거 `min-h-10`·`text-foreground font-medium` | 채택 | 히트 영역 40px 규칙 위반을 고침. 같은 영역이 읽히게 함 |
| 골드 선은 이 화면에서만 제거, 그룹 간격 `space-y-5` | 채택 | 대표 요청. `dividerAccent` 토큰과 `asset-report-view` 3곳은 diff 0 |
| 행 사이 선 중립 헤어라인(`divide-border dark:divide-border/40`) | 채택 | "구분 라인 정리"의 짝. 이미 쓰던 정본 클래스 |
| 손익 줄 500 → 600 | 채택 | 인지성 목표에 바로 닿음. 값 변경 0 |
| 그룹 라벨 muted → foreground | 채택 | 그룹 머리가 행 이름보다 약해서 생기는 역전을 해소함. 한 단어 수준 변경 |
| 행 hover 배경 제거 | 채택 | 눌리지 않는 행이 눌릴 것처럼 보이는 문제를 없앰(삭제 변경) |
| 선택기 위 `국내·해외 날짜 맞춤` 이름 줄 | **축소 채택** | v5.116 이름과 화면을 잇는 장점은 인정함. 다만 사양의 `w-full`은 1280에서 선택기가 1,100px로 늘어나 과함 → **400 미만에서만 `w-full`, 400 이상은 현행 208px·오른쪽 정렬, 이름은 같은 줄 왼쪽**. 360에서 문제가 생기면 컷 1순위 |
| 1280 `md:max-w-2xl` 좌정렬 | **제외** | 대표 요청 밖의 레이아웃 방향 변경임. Hero·시장과 비교 카드는 전체 폭인데 이 카드 안만 672px이 되어 오른쪽이 비어 보임("휑" 위험). 위임 조건 ⑦(큰 UI 방향 변경 아님)도 흐려짐. 필요하면 별도 후보로 둠 |
| 국내·해외 같은 날짜 한 줄 합치기 | 제외(ui도 범위 밖) | 표시 로직 변경 |
