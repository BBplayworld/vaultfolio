## spec
**문제**: 필터를 고르면 같은 총액이 세 번 보이고, 이동 줄을 누르면 누른 것과 다른 탭에 도착한다.
**목표 행동**: 누른 종류의 상세 탭에 한 번에 도착한다. 총액은 두 곳(가운데·범례)에서만 본다.

**사용자 흐름**
1. 홈 → 필터 `금융자산`(또는 도넛·범례 조각) → 탭 칸에 구성 막대와 이동 수단만 보인다.
2. `암호화폐`(줄 또는 조각)를 누른다 → 상세 `crypto` 탭. `현금성` → `cash`, `주식` → `stocks`.
3. 필터 `부채` → 이동 줄을 누른다 → 대출만/둘 다: `loans`, 임차보증금만: `real-estate`.
4. 필터 `부동산` → 이동 줄 → `real-estate`(현행).

**도착 탭 규칙**
| 탭 상태 | 누른 것 | 도착 |
|---|---|---|
| 금융(어떤 조합이든) | 주식 / 암호화폐 / 현금성 | `stocks` / `crypto` / `cash` |
| 금융, 한 종류만 | 이동 줄 | 그 종류의 탭 |
| 부채, 대출만 | 이동 줄 | `loans` |
| 부채, 임차보증금만 | 이동 줄 | `real-estate` |
| 부채, 둘 다 | 이동 줄 | `loans`(현행). ui가 금융과 같은 종류별 방식을 쓰면 임차보증금 → `real-estate` |
| 부동산 | 이동 줄 | `real-estate`(현행) |

**제약**: 탭 칸(col-2) 높이는 모든 상태·폭에서 main 이하(박스 삭제분 안에서만 이동 수단을 늘린다 = 줄 수 순증 ≤ 0). 누를 수 있는 요소는 40×40px 이상.

**엣지 케이스**
- 탭이 1개뿐(필터 없음)·자산 0(`등록된 자산이 없습니다`): 현행 유지.
- 금액 0원·개수 1개 이상인 종류(현금 0원 등): 구성 막대에는 없다. 이동 줄 개수 표기는 개수 기준이므로 표시되며, 줄 방식이면 그 탭으로 간다. 조각 방식이면 막대에 없는 종류는 이동 수단이 없으므로 줄에 남긴다.
- 상장폐지만 있는 주식(`stockCount` 0): `주식 0개`를 쓰지 않는다.
- 첫 저장 당일·주말·원인 없는 날: 탭 칸은 `NetAssetSummaryBox`와 무관하므로 동일 동작.
