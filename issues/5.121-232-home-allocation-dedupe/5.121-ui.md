## 1. 현황 (실측)
- 금융·부동산·부채 탭 패널 = `총액 박스`(모바일 74 / 768~1279 79.2 / 1280 84.3px) → `구성`(제목+막대+범례) → `이동 줄`(40 / 41.4 / 42.8px), 간격 `space-y-5`(20).
- 총액 박스는 도넛 가운데(`3,596만원`)·범례(`3,596만원 (6.1%)`)와 같은 값의 원 단위 표기다. 9자리(`535,840,000원`)·12자리(`123,456,789,012원`)·13자리까지 모바일에서도 1줄 74px로 실측 → 박스가 줄바꿈으로 커지는 경우는 없다.
- 이동 줄은 문구가 `주식 N개 · 암호화폐 M개 · 현금성 K개 보유 중 >` 한 덩어리 버튼이고 항상 `stocks`로 간다. 코인만·현금만이어도 `주식 0개`가 먼저 찍히는 결함도 같은 줄에 있다(주식 수를 무조건 렌더).
- 부채 줄 `대출 N건 · 임차보증금 M건 >`은 항상 `loans`로 간다. 임차보증금은 `real-estate` 탭에만 있다.
- 모바일 패널 시작 y=840(390·844 뷰포트 기준 첫 화면 밖). 1024+ 2열은 카드 높이를 왼쪽 열(도넛+범례)이 정해 패널이 줄어도 카드 높이는 그대로다(C115).

## 2. 결정: ②의 방식 = "같은 줄 안 종류별 버튼"
검토한 안과 판정:
- 구성 막대 조각을 버튼으로: 현금 2% 같은 조각은 폭이 40px 미만, 막대 높이 20px → 히트영역 미달. 기각.
- 범례 행을 버튼으로(`SectionBar` 수정): 공용 컴포넌트 3곳 영향, 행 높이 20→40 증가, `6개` 개수 정보 소실. 기각.
- **채택: 이동 줄 1개를 종류별 버튼 N개로 분할.** 줄 수·높이 불변, 개수 정보 유지, 기존 쉐브론 언어 재사용.

사양(`DrillDownRow` 형제로 신규 `DrillDownLinks`, 같은 파일 로컬 — 재사용 지도에 대응 컴포넌트 없음, design-system 흡수 불필요: 기존 `DrillDownRow` 토큰만 사용):
- **종류 1개**: 현행 `DrillDownRow`와 픽셀 동일(`주식 6개 보유 중 >`), 도착만 그 종류 탭(코인만→`crypto`, 현금만→`cash`). 0개 종류는 렌더하지 않는다(`주식 0개` 제거).
- **종류 2개 이상**: `flex flex-wrap`, 버튼마다 `inline-flex items-center gap-0.5 py-2.5 pr-2 last:pr-0 text-sm text-muted-foreground`, 개수만 `font-bold text-foreground tabular-nums`, 뒤에 `ChevronRight size-4`. 문구 `주식 6개 ›  암호화폐 1개 ›  현금성 3개 ›`(`·`·`보유 중` 제거 — 쉐브론이 구분자). 버튼 높이 = 현행 줄과 같은 `py-2.5`+1줄(40/41.4/42.8), 폭 최소 ~74px, 형제 히트영역 겹침 0.
- 상태: hover `text-foreground`, `transition-[color,scale]`, `active:scale-[0.96]`, `focus-visible:ring-2 ring-ring/50 rounded-md`. 새 모션·색·토큰 0.
- 폭 실측(주입): 360에서 3종 모두 99개여도 312/336px 1줄. 그보다 길면 `flex-wrap`으로 2줄(예외, 허용).
- 접근성: `<button>`, `aria-label="주식 6개 상세 보기"`(종류별), 키보드 Tab 순서 = 시각 순서.
- 부채: 대출만 → `대출 N건 >` loans(현행) / 임차보증금만 → `임차보증금 M건 >` **real-estate**(cto ③) / 둘 다 → `대출 N건 ›  임차보증금 M건 ›` 각각 loans·real-estate. **둘 다 분할은 cto v1 문구 밖(확장 1건)** — 같은 규칙(누른 것=도착 화면)이고 줄 수 0·diff 소량이라 포함 권고. cto가 v1 한정이면 둘 다는 `loans` 유지 + 이유 열에 "임차보증금을 눌러도 loans" 잔여 불일치로 기록.
- 총액 박스 3개 삭제. 3개 `TabsContent`의 `lg:pt-0 pt-2`를 **`pt-4`**로(모바일: 도넛 범례 바로 아래에 박스 없이 제목이 붙어 구분이 약해짐 → +8px; 1024+: 구성 제목을 왼쪽 카드의 `순자산` 라벨(py-4 안쪽)과 같은 선에 정렬, 높이 0 영향). `전체` 탭(7일 카드)은 현행 `lg:pt-0 pt-2` 유지.
- 정보 손실 인정: 금융·부동산·부채 총액의 **원 단위 전액**은 이 탭에서 사라진다(도넛 가운데·범례는 만원·억 축약). 순자산 전액은 Hero에 그대로. cto 판정 범위 내로 수용.

- 모바일 첫 화면(844)에서 달라지는 것은 y≥840의 패널 첫 4px뿐 → 8px 기준 이내. 높이가 줄어드는 건 필터를 고른 아래쪽(팁·푸터가 86px 위로)이다.
