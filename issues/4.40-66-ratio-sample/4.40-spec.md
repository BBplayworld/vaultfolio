시각 값(버튼 variant·간격)의 최종 확정은 ui-designer ui.md. 이 문서는 흐름·상태·데이터·문구·수용 기준을 정한다.

## 1. 문제
`/ratio`는 캡처를 올려야만 결과를 볼 수 있다. 처음 온 방문자는 "무엇이 나오는지" 모른 채 계좌 화면을 보내야 해서 망설이고, 홍보 글에서 보여줄 결과 예시도 없다.

## 2. 목표 행동
업로드 전에 예시 결과를 보고 → "내 캡처로 해보기" → 자기 캡처를 올린다.

## 3. 범위
- 포함: "예시로 먼저 보기" 버튼, 고정 예시 6종목, "예시 데이터예요" 표시, "내 캡처로 해보기" 버튼, GA `method: sample`.
- 제외: 샘플 캡처 이미지, 딥링크(`?sample=`), 예시 저장·공유, 실제 종목명·티커, 결산·홈·웰컴·체험·`(main)` 변경, 서버·저장 키·스키마 변경.

## 4. 예시 데이터 (신규 `src/lib/ratio-preview/ratio-sample.ts`)
- `RATIO_SAMPLE_STOCKS: ParsedStock[]`(6건, `ticker` 없음·`brokerHint` 없음), `RATIO_SAMPLE_RATES = { USD: FALLBACK_USD, JPY: FALLBACK_JPY }`(고정, 환율 조회 안 함).
- 구성(표시 순서 = 비중 내림차순). 금액은 화면에 나오지 않는다.

| 순 | 종목명(가상) | section | 수량 × 현재가 | 표시 비중 |
|---|---|---|---|---|
| 1 | 가나전자 | 국내 | 40 × 70,000 KRW | 28.0% |
| 2 | 사아테크 | 해외(USD) | 10 × 159.42 USD | 22.0% |
| 3 | 다라바이오 | 국내 | 20 × 80,000 KRW | 16.0% |
| 4 | 마바금융 | 국내 | 35 × 40,000 KRW | 14.0% |
| 5 | 자차클라우드 | 해외(USD) | 5 × 173.91 USD | 12.0% |
| 6 | 카타에너지 | 해외(USD) | 4 × 144.93 USD | 8.0% |
- 결과: 총 6종목, 국내 58.0% 3종목 / 해외 42.0% 3종목, "그 외" 행 없음, 가격 0 종목 없음(USD 1380 기준 `buildRatioList` 계산값으로 검증함).
- 투자 권유로 읽히지 않게: "가나다" 음절 가상명, 티커 없음, 테마 유행어(AI·반도체·2차전지 등) 없음, 1위 비중 30% 미만으로 "이렇게 담으라"는 모범 배분으로 보이지 않게 고르지 않은 숫자. 평가 문구 0.
- 예시 결과는 `buildRatioList(RATIO_SAMPLE_STOCKS, RATIO_SAMPLE_RATES)` 그대로(전용 계산 없음).

## 5. 사용자 흐름
1. 첫 진입(idle): h1·설명 → 업로드 영역(dropzone) → 고지 박스(현행, dropzone 바로 아래 유지) → **"예시로 먼저 보기" 버튼**(고지 아래, 보조 버튼. 업로드가 주 행동이므로 brand 아님). 버튼은 dropzone과 같은 펼침 영역 안에 있어 결과가 열리면 함께 접힌다.
2. "예시로 먼저 보기" 탭 → 로딩 없이 즉시 예시 결과. dropzone 영역 접힘 + 결과 펼침(현행 전환과 동일). GA 1건.
3. 예시 결과 구성(위→아래): **예시 표시**("예시 데이터예요. 가상 종목으로 계산한 비중이에요.") → 요약 카드 → 종목별 비중 카드 → 액션: brand **"내 캡처로 해보기"** 1개 + 캡션 "내 캡처를 올리면 이 화면처럼 보여드려요."
   - 숨김: "내 기기에 저장하고 계속 관리", 인앱 안내 박스·"브라우저에서 열어 저장하기"·iOS 폴백 안내, "다른 사진으로 다시 보기", 캡션 "금액은 저장 후 확인 창에서 볼 수 있어요.", 환율·가격 0 노트.
4. "내 캡처로 해보기" 탭 → idle로 복귀(결과 접힘, dropzone·고지·예시 버튼 펼침), 포커스는 dropzone, 페이지 상단으로 스크롤. **파일 선택창을 바로 열지 않는다**(전송 고지를 다시 보이게 하기 위함, 탭 1회 추가는 감수).
5. 이후 업로드는 현행 흐름 그대로(loading → result/error). 실제 결과에는 예시 표시가 없고 액션은 현행.
- 예시 → 실제 전환은 4번 경로 하나뿐. 실제 결과 화면에는 예시 버튼이 보이지 않는다(dropzone 영역이 접혀 있으므로).

## 6. 상태 전이
| 현재 | 동작 | 다음 | 비고 |
|---|---|---|---|
| idle | 예시 탭 | sample | GA sample 1건 |
| error(empty·fail) | 예시 탭 | sample | 콜아웃 사라짐. 복귀 시 idle(오류 복원 안 함) |
| error(limit·device) | 예시 탭 | sample | 예시 버튼은 비활성 아님(서버 비용 0). 복귀 시 같은 오류 콜아웃·dropzone 비활성 복원 |
| loading | 예시 탭 | — | 예시 버튼 `disabled` |
| sample | 내 캡처로 해보기 | idle(또는 위 복원 오류) | GA 없음 |
| sample | 새로고침·재방문 | idle | 메모리 상태만, 저장 키·URL 변화 없음 |
| sample | 뒤로가기 | 이전 페이지 | 히스토리 항목 추가 안 함 |
| result(실제) | — | — | 예시 버튼 미노출, 현행 그대로 |
- 구현 메모: 상태는 현행 `status`에 `"sample"`을 추가하거나 `isSample` 플래그를 두되, 결과 펼침 조건은 `result`·`sample` 모두 참. 예시 진입 시 `raw=null`, `result=예시 계산값`, `fxEstimated=false`. 오류 복원용으로 직전 `errorKind`가 limit·device면 보관(device는 복귀 시 `geminiUsage.canUse()` 재확인으로 대체 가능).

## 12. 엣지 케이스
- 빈 데이터: 예시는 고정 6건이라 빈 결과 불가(vitest로 고정).
- 일부 갱신·오래된 데이터: 해당 없음(고정 데이터, 환율 조회 안 함 → 시세가 바뀌어도 예시 비중 불변).
- 첫 사용자: 기본 진입 경로. 아무것도 조작하지 않은 첫 화면에서 예시 버튼이 보인다(SSR html에도 포함).
- 인앱 브라우저: 예시 결과는 동일, 인앱 저장 분기는 예시에서 숨김. 복귀 후 업로드·인앱 분기는 현행.
- 한도 초과 기기: 예시 가능, 복귀 시 비활성·콜아웃 복원.
- 320: 6개 종목명 모두 4~6자라 truncate 없음, 티커 없음.

## 13. 완료 기준 (qa 그대로 검사)
1. 첫 진입 화면(무조작)에 "예시로 먼저 보기"가 고지 박스 아래에 보이고, 탭하면 로딩 표시 없이 결과가 열린다.
2. 예시 결과에 "예시 데이터예요. 가상 종목으로 계산한 비중이에요."가 결과 맨 위에 보인다.
3. 예시 결과: 총 6종목, 국내 58.0%·3종목 / 해외 42.0%·3종목, 행 28.0·22.0·16.0·14.0·12.0·8.0(합 100.0), "그 외" 행 없음. 원·$ 금액 문자열 0, 티커 0.
4. 예시 결과에 `ratio-save-btn`·`ratio-inapp-btn`·`ratio-inapp-guide`·`ratio-retry-btn`·`ratio-zero-price-note`·`ratio-fx-note` DOM 없음(일반·인앱 UA 모두).
5. 예시 진입~복귀 동안 네트워크 탭에 `/api/*` 요청 0건, `localStorage`·`sessionStorage` 변화 0, `peekHandoff()` null.
6. "내 캡처로 해보기" 탭 → dropzone·고지·예시 버튼이 다시 보이고 dropzone에 포커스, 파일 선택창은 열리지 않는다. 이어서 업로드하면 현행 결과(저장 버튼 포함, 예시 표시 없음)가 나온다.
7. limit·device 오류 상태에서 예시 → 복귀 시 같은 콜아웃과 dropzone 비활성이 복원된다. empty·fail은 idle로 복귀.
8. 새로고침하면 idle, URL 변화 없음.
9. GA: 예시 탭 1회 = `feature_use{category:ratio_preview, method:sample}` 1건, 예시 중 `submit`·`click`·`open` 0건. `PARAM_VALUES.method`에 `sample`, 라벨 "예시 보기".
10. vitest: `buildRatioList(RATIO_SAMPLE_STOCKS, RATIO_SAMPLE_RATES)`가 3번 값과 정확히 일치, 종목명이 `kr-etf-master.json`·`us-etf-master.json` 이름과 겹치지 않고 `ticker` 빈 값.
11. 회귀: 일반 업로드 성공·오류 4종(empty/fail/limit/device)·인앱 분기·저장 인계가 main과 같다(4.39 ui.md §10 체크 7·8·11·12 재실행). 노드 동일성(C3): 예시↔복귀↔업로드 반복 중 `ratio-file-input`·`ratio-dropzone`·`ratio-result` 노드 교체 없음.
12. 320·375·1280 × 라이트·다크에서 새 문구 4개 어절 중간 줄바꿈 0(C25), 가로 스크롤 0, 버튼 히트영역 ≥40px, reduced-motion에서 즉시 최종값.
