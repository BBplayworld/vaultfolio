## 4. 인터랙션·모션
- idle→sample: 로딩 없이 현행 Unfold 전환(upload 접힘 + result 펼침 동시 300ms, `motion-safe`, 인터럽터블). 결과 행 stagger·막대 `scale-x` 현행 그대로. reduced-motion은 즉시 최종값.
- 예시 진입 후 포커스: 예시 표시 `tabIndex=-1`로 `focus({preventScroll:true})` + `scrollIntoView({block:"start"})`(smooth는 `motion-safe`). 표시가 결과의 첫 요소이므로 헤더 아래에 위치. `focus-visible`은 프로그램 포커스에 링이 안 뜨도록 `outline-none`(현행 요약 제목 포커스와 동일 처리).
- 복귀(CTA): 결과 접힘 + upload 펼침, dropzone `focus({preventScroll:true})` 후 `window.scrollTo({top:0})`(smooth는 `motion-safe`). 파일창 자동 열림 없음.
- 연타: 이미 sample이면 예시 탭 무시(GA 중복 방지). 전환 중 CTA 연타는 현재 상태에서 역전, 상태 값 하나라 안전.
- 누름 피드백: Button 내장 0.96. `transition: all` 금지.
- 노드 동일성: `ratio-file-input`·`ratio-dropzone`·`ratio-result` 교체 없음. 예시 버튼·표시·CTA는 조건부 렌더가 아니라 **Unfold 안에 항상 마운트 + 상태 `hidden`/`inert`**가 이상적이나, 결과 안 표시·CTA는 `data-mode`에 따라 교체돼도 무방(노드 동일성 대상 아님).

## 5. 접근성
- 히트영역: 예시 버튼·CTA 44px. 키보드 Tab 순서: dropzone → 예시 버튼, sample에서는 CTA.
- 예시 표시 `role="note"`(선택), 아이콘 `aria-hidden`. 결과 래퍼 `data-mode`.
- 다크: 토큰만(`bg-muted/50`, sky 아이콘 `dark:` 쌍). 라이트에서 추가 투명도 중첩 금지.
- 상태 낭독: 현행 `aria-live="polite"` 영역에 sample 진입 시 표시 문구가 읽히도록 함.

## 6. 문구 (spec 9절 상수 그대로, 직접 기재 금지)
`RATIO_SAMPLE.button` 예시로 먼저 보기 / `.label` 예시 데이터예요. 가상 종목으로 계산한 비중이에요. / `.cta` 내 캡처로 해보기 / `.caption` 내 캡처를 올리면 이 화면처럼 보여드려요.
- 투자 조언·보안 단정 0(C26). `data-screenshot-hide` 해당 없음.
- 줄바꿈 예측: 라벨 320(내부폭 ≈264-아이콘 22≈242px)에서 2줄, 어절 단위 줄바꿈(break-keep): "예시 데이터예요. 가상 종목으로 / 계산한 비중이에요." 형태 허용. 375·1280도 1~2줄.

## 7. testid
`ratio-sample-btn` · `ratio-sample-label` · `ratio-sample-cta` · 결과 래퍼 `ratio-result[data-mode="sample|real"]` (spec 10절과 동일).

## 8. 품질 체크리스트 (qa·ui-review 판정용)
1. 첫 무조작 화면 375·라이트/다크: 예시 버튼이 고지 박스 아래에 보이고 secondary(은은한 배경, 테두리 0), 폭 = dropzone 폭, 높이 ≥44px.
2. 업로드 brand와 예시 secondary의 위계가 구분됨(brand는 dropzone 칩/업로드만, 예시 버튼은 brand 색 아님).
3. 예시 결과 맨 위 라벨: 고지 박스와 같은 면·글자 톤, 주황 계열 클래스 0, 아이콘만 sky. 요약 카드보다 위.
4. 예시 결과에 `ratio-save-btn`·`ratio-inapp-*`·`ratio-retry-btn`·`ratio-zero-price-note`·`ratio-fx-note` 없음, 맨 아래 brand CTA 1개 + 캡션.
5. 새 문구 4개가 320·375·1280 × 라이트·다크 12조합에서 어절 중간 줄바꿈 0(computed `word-break: keep-all`, C25), 가로 스크롤 0, 폭 ≤480px 중앙 컬럼.
6. loading 중 예시 버튼 `disabled`, 탭해도 상태 변화·GA 0. limit·device 오류에서는 활성, 복귀 후 콜아웃·dropzone 비활성 복원.
7. 예시 진입 직후 라벨이 viewport 안에서 헤더 아래에 보이고 포커스가 라벨에 있음. CTA 후 dropzone 포커스, scrollY≈0, 파일창 안 열림.
8. 전환 모션: idle↔sample에서 Unfold 높이 보간 중간값 존재, 행 stagger 40ms, reduced-motion 즉시 최종값, 로딩 단계 없음(스피너·Skeleton 0회 노출).
9. 노드 동일성: 예시↔복귀↔업로드 반복 중 `ratio-file-input`·`ratio-dropzone`·`ratio-result` 노드 교체 0(C3).
10. 예시 결과 값: 6행 28.0/22.0/16.0/14.0/12.0/8.0, 국내 58.0%·3 / 해외 42.0%·3, 금액·티커 문자열 0, 색 = 현행 팔레트(1위 `MAIN_PALETTE[0]`), 카드 보더리스(C2).
11. 신규 색·간격·컴포넌트 패턴 0: className diff에 새 토큰·원시 hex 0, 버튼 variant는 secondary/brand만.
12. C27: 라벨의 "가상 종목"이 화면에 드러나고, 웰컴/체험의 예시와 같은 숫자 표기가 충돌하지 않음(이 화면엔 금액·순자산 없음).
