### 1-2. 이름 규칙 (6탭 공용)
- 규칙: **어절 단위(`break-keep`) · 최대 2줄(`line-clamp-2`) · 초과 말줄임 · 칸보다 긴 낱말은 `[overflow-wrap:anywhere]`로 넘침 방지(남김)**.

### 1-3. 전체 이름 노출
- 시각 말줄임은 화면에만 적용, DOM에는 전체 텍스트가 있어 스크린리더는 전체를 읽는다 → `aria-label` 추가 불필요.

### 1-4. 거래 행 '기록만' 배지 (stock-trades-view.tsx:327-331)
- 모든 폭에서 배지는 **둘째 줄**. 한 모양만 쓴다(11-16 '같은 기능 두 모양' 방지).
- 증권사 줄이 있을 때(brokerScope=all): 둘째 줄 = `[기록만 배지] 증권사명`(배지 앞, gap-1.5, 한 줄, 증권사명 truncate). 줄 수 증가 0 → 반영 행과 높이 동일.
- 증권사 줄이 없을 때: 둘째 줄을 새로 만들되 배지 높이를 증권사 줄과 같게(`h-4 leading-4 py-0`, 줄 높이 16px). 기록만 행은 반영 행보다 +16px — **같은 둘째 줄 유형끼리 높이 0px 차이**가 기준(spec AC는 '증권사 줄 있는 행 = 기록만 행'으로 읽는다). 1줄 행과 같게 만들 수는 없음(320에서 배지를 첫 줄에 넣을 폭이 없다: 중간 칸 ≈ 87px < 수량·단가 문장 90px).
- 첫 줄(수량·단가) 문장의 `· 68,000원`은 `whitespace-nowrap`(§2 미달 B 참조).
- 부호: 매도 금액 `-` → **U+2212 `−`**(`{tx.type === "buy" ? "+" : "−"}`), 현금·코인·대출은 이미 U+2212. 삭제 버튼: 현금·코인·대출에 `aria-label="거래 삭제"`, `title="삭제"` 유지. 배지 문구·삭제 확인·잔액 계산 0 변경.
- 거래 4종 둘째 줄 패턴은 현금·코인·대출 행도 동일(대출 행은 이름 줄에 배지 inline — 이름 줄 폭이 충분해 그대로 둔다, 2차 정리 후보).

시안: 01~12 캡처가 현행. A·B 시안 2장(320·390)은 구현 후 preview에서 확인(코드 수정 금지 단계라 미작성).
