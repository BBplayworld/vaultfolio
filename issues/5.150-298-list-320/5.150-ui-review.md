## 항목별 판정
- 이름 2줄 말줄임 시각 품질: `TIGER 미국S&P500`은 어절 경계에서 줄바꿈, 다크 320은 `TIGER / 미국S&P5…`로 2줄째만 말줄임. 한 글자 끊김 없음, 행 높이 균형 양호.
- 범례 칩: `TIGER ...`·`KODEX ...`·`SK하이닉...` 1줄 말줄임 유지, 2열 정렬·퍼센트 위치 정상(두 테마).
- 배지 둘째 줄: 데모에 '기록만' 행이 없어 증권사 줄 행에 배지(h-4 leading-4 동일 구조)를 DOM 주입해 측정 — 주입 전후 행 높이 동일(320 라이트·다크 76→76, ±0px). 한계: 실제 `data-testid=tx-record-only-badge` 렌더는 qa가 기록만 시드로 확인.
- 대출 요약 3칸(320 다크)은 칸 간격이 빡빡(≈8px)하나 겹침·분리 없음.

## 지적(비차단)
1. 사양 불일치: 320 다크 `KODEX 200`이 2줄(`KODEX`/`200`, 이름 칸 79px). ui.md §1-1의 "한 줄" 실측과 다름(라이트는 1줄). 어절 끊김일 뿐 글자 끊김 아님 → 수용. 후속에서 우측 열 폭 미세 조정 후보.
2. 거래 행(320 라이트) `10주` / `· 62,000원`: 단가 nowrap으로 `·`가 둘째 줄 머리에 남고, 같은 목록에서 1줄 행(56px)과 2줄 행(76px)이 섞임. `원` 분리보다 낫고 겹침 없어 수용. 후속: `max-[359px]`에서 `·` 숨기고 단가 block.
3. **5.150 이전부터 있던 결함(이번 변경 무관, 이월 권고)**: 320 다크 코인 목록 우측 열 잘림(`7,000,00`, `(+16.…`). 우측 열 `flex-shrink-0` 163px > 가용폭이며, 이름 클래스를 제거해도 동일(rightEdge 338 > rowRight 292) → 5.150 원인 아님. 라이트는 308=308로 간신히 맞음. 다크 코인 메타 줄 `dark:whitespace-nowrap`와 우측 열 합이 256 초과. 주식(45%)처럼 코인 등도 `max-[359px]` 폭 처리 필요. ui.md §2 감사의 DOM 잘림 검사가 overflow-hidden 내부 잘림을 놓친 점 정정.
4. X-Ray 분류 실패 토스트는 로컬 프록시 차단 환경 요인, 제품 결함 아님.
