# #219 첫 결산에 돌아오게 — UI 사양 (design-review, ui-designer)

근거: spec.md AC-1~17·문구 확정안, design-system v5.114(타이포 정본·§6·§7), v5.114 코드(`home-tip-box.tsx`, `install-nudge.tsx`, `notify-section.tsx`, 허브 2종, `monthly-dividend-stocks.tsx`, `invalid-access/page.tsx`, `config/whats-new.ts`). 운영 캡처는 하지 않았고 코드 대조로 확정했다(신규 시각 요소 0이라 기존 팁과 동일 렌더).
원칙: 신규 토큰·컴포넌트 0. 전부 기존 패턴 재사용이라 design-system 흡수 항목도 없다.

## 1. 알림 팁 (홈)
- 컴포넌트: `HomeTipBox` 카드 그대로 재사용(수정). `contentOf`에 `notify` 분기만 추가.
- 트리: 카드(rounded-xl bg-card shadow-xs p-4) > 아이콘 `Bell`(lucide, size-4, `ASSET_THEME.important`) · 배지 `알림`(기존 orange 칩, text-xs bold) · 제목 `결산이 열리는 날 알려 드릴까요?`(text-sm semibold) · 설명 `받을 알림은 설정에서 직접 골라요.`(text-sm muted) · X.
- 배지·아이콘·간격은 다른 팁과 픽셀 동일. 알림만 다른 색·강조·CTA 버튼을 두지 않는다(카드 전체 클릭 = 유일한 동작).
- 닫기 히트영역: 현재 `-m-3 p-3` + 아이콘 16px = 40×40. 유지(변경 금지). aria-label "닫기", data-testid `home-tip-close`.
- 줄 수 기대: 390 기준 제목 1~2줄(제목 22자, 배지와 같은 줄에서 flex-wrap으로 넘어가면 2줄 허용), 설명 1줄. `break-keep text-pretty` 유지, 어절 중간 끊김 0.
- 모션: 기존 `motion-safe:animate-in fade-in slide-in-from-bottom-2 300ms` 그대로. 팁 종류가 바뀌어도 같은 노드(role=button)라 재마운트 없이 내용만 교체되므로 진입 모션이 다시 돌지 않는 것은 기존 동작과 같다(변경 없음).
- testId: `home-tip` + `data-kind="notify"`(AC-3). 팁 종류 키 `notify-offer`는 spec 대로.

## 2. 설치 안내 카드 문장 교체
- 문장: `아이콘으로 바로 열고, 월 결산·세금 일정 알림도 받을 수 있어요.` (text-xs muted, `break-keep text-pretty`, 카드 w-[min(18rem,100vw-2rem)]).
- 폭 계산: 카드 안쪽 폭 18rem-2rem(p-4)-아이콘 1.25rem-gap 0.75rem ≈ 200px(12px 글자, 약 17자/줄). 신문장 29자 → 2줄, 구문장 21자 → 2줄. 즉 줄 수 2줄 유지, 카드 높이 불변이 기대값이다.
- 확인 기준(qa): 320·360·390에서 설명 `<p>` 줄 수 ≤2, 카드 높이가 v5.114와 동일(±0px), 버튼 2개가 카드 안, "월 결산·"이 어절 중간에서 끊기지 않음. 320에서 3줄이 되면 문장 변경이 아니라 `수정 요청`으로 되돌린다(높이가 늘면 하단 버튼이 탭바와 겹칠 위험이 있어 허용 불가).
- 확인 부족 시 대안 문안(planner 재승인 필요): `아이콘으로 바로 열고, 결산·세금 알림도 받아요.`(23자, 확실히 2줄 이내). 1차 확정안으로 먼저 측정한다.
- 제목·버튼(h-10 두 개)·z-40 위치·그림자 무변경. 기존 testid 없음 → `data-testid="install-nudge-desc"`를 설명 `<p>`에 추가(qa 측정용).

## 3. 설정 알림 구역 도착 강조
- 구역 UI는 변경 0. 스크롤만: 렌더 후 `settings-section-notify`에 1회 `scrollIntoView({block:"start"})`, reduced-motion이면 `behavior:"auto"`, 아니면 smooth. 상단 고정 헤더가 있으므로 구역 `scroll-mt-16`(= 헤더 높이 이상)을 추가해 제목 "알림" 라벨이 가려지지 않게 한다.
- 강조: 별도 하이라이트 링·깜빡임을 두지 않는다(켜기 전 권한 창이 없는 상태에서 시선만 도착하면 충분, 기존 설정 화면 톤 유지). 구역 라벨 `알림`이 뷰포트 상단 안쪽에 보이면 합격.
- 도착 후 첫 행 `settings-row-notify`가 뷰포트 하단에 걸리지 않아야 한다(구역 높이 ≤ 뷰포트 - 헤더). 390x844에서 확인.
- 이동 후 뒤로 가기·재진입 시 재스크롤 0(focus 상태를 1회 소비 후 비움). 일반 진입(더보기>설정)은 스크롤 위치 변화 0.

## 4. 허브 머리 설명 줄 삭제
- 상세·성과 허브 `<p>` 제거. 헤더 행 `flex items-start justify-between gap-3`는 그대로. 제목(text-lg md:text-xl) 높이 28~32px, 공유 버튼 40px라 제목 줄이 버튼보다 낮아진다 → `items-start`를 `items-center`로 바꿔 제목과 버튼 세로 중앙을 맞춘다(AC-16 정렬 유지). 카드 목록까지 간격은 부모 `gap-3 sm:gap-4`가 그대로 담당하므로 추가 마진 0.
- 기대: 헤더 행 높이 = 버튼 높이(40px), 제목 수직 중앙. 다른 허브(홈 등)와 헤더 기준선 일관성은 qa가 상세·성과 2화면 비교로 확인.
- 영향 테스트 `detail-hub-*` 문구 단정이 있으면 developer가 수정.

## 5. 배당 표 O1 (`monthly-dividend-stocks.tsx`)
- 휴대폰 배치 전환점 `sm:` → `md:`, 짝(`sm:hidden` 줄 → `md:hidden`, `hidden sm:inline` 티커 → `hidden md:inline`, `hidden sm:inline-flex` 배지 → `hidden md:inline-flex`)을 한 세트로 바꾼다. 하나만 바꾸면 티커·배지가 이중 또는 0회 노출되므로 4곳 모두 같은 전환점(그리드 헤더 201행, 행 219행 포함)이어야 한다.
- 폭별 기대: 320~767 = 390과 같은 5열(minmax 1fr + 3.25/3.5/3.5/3.5rem), 이름 아래 보조 줄(티커·주기 배지). 768~1023 = 기존 sm 값(11.5rem 월 칩 열), 1024+ = 기존 lg 값. 종목명 2자 말줄임 없음(640~767에서 확인), 보조 줄은 `md:hidden`이라 768+에서 0개.
- `gap-x-1 sm:gap-x-2`, `px-2 sm:px-3`도 같은 전환점으로 맞춘다(열 폭과 간격이 어긋나지 않게). 월 배지 칩 재배치는 하지 않는다.

## 6. 1회용 링크 안내 1줄 (`/invalid-access`)
- 위치: 기존 `<p>` 본문 바로 아래, 같은 `space-y-2` 블록 안. 클래스 `text-muted-foreground text-xs md:text-sm max-w-md mx-auto break-keep text-pretty`(본문보다 한 단계 작게, 보조 정보 톤). 버튼 위 `pt-4` 간격 유지.
- 톤: 존댓말, 사과·원인 단정 없이 가능성만(`…있어요`). 문구는 spec 확정안 그대로: `이미 한 번 연 1회용 링크이거나 시간이 지났을 수 있어요. 보낸 쪽에서 다시 전달받아 주세요.`
- 줄 수: 390에서 2~3줄, 320에서 3~4줄 허용(max-w-md 안쪽, 가운데 정렬). 버튼이 화면 밖으로 밀리지 않음(h-dvh 중앙 배치라 스크롤 0 확인).
- 기존 본문에 이미 "만료"가 있어 의미가 겹친다. 본문 수정은 spec 금지(본문·버튼 불변)라 겹침을 감수하고, planner 판단 요청: 본문 삭제·통합이 가능한지. 1차는 spec대로 추가만.
- testId: `data-testid="invalid-access-onetime"`.

## 7. 새 소식 문안 (가계 비교) 화면 대조 확정
- 대조: 새 소식 시트 항목 = 제목(2~32자, 한 줄~두 줄)+본문(≤48자), `바로 가기 ›`. 성적표 블록 정본 문형 `가구 100곳 중 약 N곳이 이 구간…`.
- 확정안(추가 최대 2건, 최신순 날짜는 developer 게시일 기준):
  1. `{id: 20261114-01(게시일), featureId: "report"}` 제목 `성적표에서 가계 통계와 나란히 봐요`(17자) / 본문 `가구 100곳 중 약 몇 곳이 같은 구간인지 문장으로 봐요`(29자). 순위·평가어·금액 0.
  2. 체감 변화 2번째는 planner가 v5.102~5.114 중 고름. ui.md는 형식만 확정: 제목 ≤32자 이득 한 줄, 해요체, U+2060 결합자 규칙 준수.
- 성적표 기능 팁(`app-features.ts` report) description은 `성과 탭의 성적표에서 가계 통계와 나란히 놓고 가구 100곳 중 내 구간을 확인하세요.`(2줄 이내 40자대 → 홈 팁 설명 2줄 기대). `내 구간 확인`이 순위 단정으로 읽히는지 planner 재승인 필요.
- 위 문안 모두 planner 재승인 대상(spec은 ui.md에서 확정으로 위임했으므로 승인 = 이 절 승인).

## 8. 상태·접근성·반응형
- 상태: 알림 팁은 로딩 중 0(데이터 로드 완료 후만), 빈·자산 0 0, 체험·데모·잠금 0, 오류 없음(렌더 실패 상태 없음). 라이트·다크는 기존 팁 토큰만 써서 대비 동일(배지 orange-600/orange-400, 아이콘 important).
- 폭: 320 / 360 / 390 / 640 / 768 / 1024 / 1280 / 1440. 팁은 부모 폭을 따라 가변, 1280에서 홈 컬럼 안 카드 폭 변경 0. 긴 문구 대비 `break-keep wrap-break-word`.
- 접근성: 팁 role=button·Enter·Space 유지, X는 stopPropagation. `Bell`은 장식(aria-hidden 불필요, 텍스트가 같이 있음). 스크롤 도착 후 포커스 이동은 하지 않는다(OS 권한 창이 없어 방해 요소 불필요).
- `data-screenshot-hide`: 알림 팁은 홈 팁 컨테이너의 기존 규칙을 따른다(스크린샷 공유 시 팁 비노출). 신규 지정 0.

## 9. 품질 체크리스트 (qa 판정용)
1. 알림 팁 DOM이 기존 팁과 같은 클래스 구조이고 배지 `알림`·제목·설명이 spec 문구와 일치(`data-kind="notify"`).
2. 팁 닫기 버튼 실측 ≥40×40px, 키보드 Enter·Space로 팁 활성화.
3. 390·1280 라이트·다크 4컷에서 알림 팁이 최신화·결산 팁과 높이·여백·그림자 동일(눈에 띄는 색 차이 0).
4. 설치 안내 설명 줄 수 ≤2, 카드 높이가 v5.114와 같음(320·360·390), 버튼이 카드 안.
5. 팁 누름 후 `settings-section-notify`의 상단이 헤더 아래에 보이고 라벨 `알림`이 가려지지 않으며 URL에 해시·파라미터 0.
6. 팁 노출~이동 동안 `Notification.requestPermission` 호출 0.
7. 일반 경로 설정 진입은 스크롤 위치 불변, 뒤로 후 재진입에 재스크롤 0.
8. 상세·성과 허브에 `<p>` 설명 0, 제목-공유 버튼 세로 중앙 정렬, 카드 첫 줄까지 간격 12/16px.
9. 배당 표 640·700·767에서 390과 같은 배치(보조 줄 노출, 인라인 티커 0), 768·1024에서 기존 배치, 티커·배지 중복 노출 0.
10. 같은 폭대에서 종목명이 2자 말줄임되지 않는다(`truncate` 폭 확보).
11. `/invalid-access`에 `invalid-access-onetime` 1줄이 본문 아래에 있고 금지어(암호화·서버·저장·관리자) 0, 버튼이 스크롤 없이 보임(320·390·1280).
12. 새 소식 시트 추가 ≤2건, `report` 항목 바로 가기가 성적표로 이동, 금액·순위·평가어 0.
13. 모든 신규 요소가 다크에서 대비 4.5:1 이상(기존 토큰 재사용으로 충족, 스팟 확인).
14. 신규 색·간격·그림자·모션 토큰 diff 0(design-system 변경 0).
