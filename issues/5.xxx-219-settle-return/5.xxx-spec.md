# #219 첫 결산에 돌아오게 — 상세 기획 (planning ③, planner-designer)

기준: direction.md 합의 절, challenge.md 통과(C1~C6), origin/main 72bc9ec(v5.114) 코드. 범위는 ①②③과 p2 4건이며 더 넓히지 않는다.

## 1. 문제
- 11월 신규 사용자는 결산·세금 알림을 켤 길을 모른다. 알림은 설치 앱에서만 켤 수 있는데, 설치 안내는 그 사실을 말하지 않는다. 켜는 곳도 더보기 > 설정 > 알림 하나뿐이다.
- 설치하지 않은 Safari 사용자는 7일 동안 쓰지 않으면 기록이 지워질 수 있다(`persist` 호출 0건).

## 2. 목표 행동
설치 안내를 보고 설치한다 → 설치 앱 홈의 '알림' 팁을 눌러 설정 > 알림에서 직접 켠다 → 11/27 결산 알림을 눌러 돌아온다. 설치하지 않은 사람도 결산 때 기록이 남아 있다.

## 3. 사용자 흐름
1. 모바일 탭에서 첫 저장을 하면 기존 설치 안내 카드가 같은 조건으로 뜬다. 설명 문장만 바뀐다.
2. [추가하기]를 누르면 기존 `PwaInstallFlow`가 그대로 열린다.
3. 설치 앱을 처음 열고 복원이 끝나면 홈 팁 판정이 돈다. 상위 팁 7종이 모두 없으면 '알림' 팁이 뜬다.
4. 팁을 누르면 설정 화면으로 이동하고, 알림 구역이 보이도록 스크롤된다. 그 기기에서 팁은 다시 뜨지 않는다.
5. 알림 구역은 지금 그대로다(OFF 행 → 종류 직접 선택 → [켜기] → 이때 처음 OS 권한 창).
6. 자산이 있는 상태로 앱(탭 포함)을 열면 화면 변화 없이 `persist()`를 요청한다.

## 4. 화면·문구 확정안 (ui.md는 시각만 정한다. 문구를 바꾸려면 planner 재승인)
| 위치 | 현재 | 확정 |
|---|---|---|
| 설치 안내 설명(`install-nudge.tsx`) | 다음부터 아이콘 한 번으로 바로 열 수 있어요. | 아이콘으로 바로 열고, 월 결산·세금 일정 알림도 받을 수 있어요. (교체, 줄 추가 0) |
| 홈 팁 배지 / 제목 / 설명 | 없음 | 알림 / 결산이 열리는 날 알려 드릴까요? / 받을 알림은 설정에서 직접 골라요. |
| `/invalid-access` 본문 아래 1줄 | 없음 | 1회용 링크는 한 번 열리면 다시 열 수 없어요. 보낸 쪽에서 새로 전달받아 주세요. (만료는 기존 본문이 맡고 이 줄은 소진만 맡는다. 본문은 데이터 문구라 고치지 않는다) |
| 허브 머리 설명 | 상세 '자산 카테고리별 보유 현황을…', 성과 '자산 변화·배당·성적표를…' | 둘 다 삭제. 대체 문구 0 |

- 설치 안내 대안(ui 흐름 검토 1): 320에서 설명이 3줄이면 모든 폭에서 `아이콘으로 바로 열고, 결산·세금 알림도 받아요.` 하나로 바꾼다.
- iOS 16.4 미만 판별(C5-3): tech-review가 UA로 5줄 이내 분기가 가능하다고 판정하면, 그 기기에서는 설치 안내 설명을 현재 문장으로 유지한다. 판정이 불가하면 확정 문장을 쓰고 감수한다.
- 1회용 링크 줄(C4)에는 암호화·저장 위치·서버·관리자 열람을 언급하지 않는다. 기존 본문과 버튼, 이동 동작은 바꾸지 않는다.

## 5. 노출·1회 규칙
- **알림 팁 노출 조건**(모두 참): 설치 앱(standalone) · `detectPushEnv()==="ready"` · `Notification.permission==="default"` · `readPushPrefs().on`이 거짓 · 자산 있음 · 데이터 로드 완료 · 체험·데모·앱 잠금 아님 · `isTipDismissed("notify-offer")` 거짓 · 세션 숨김 아님.
- **우선순위**: `pickHomeTip`에서 자산 최신화 아래, 기능 팁 위에 둔다. 판정은 호출부가 해서 `notifyOk`로 넘긴다(relink와 같은 방식).
- **1회**: 누름과 X 중 어느 쪽이든 1번 하면 `dismissTip("notify-offer")`로 그 기기에서 영구 종료한다. X는 기존처럼 그 세션의 팁 박스도 숨긴다. 반응이 없으면 다음 방문에 다시 뜬다. 횟수 상한·날짜 기록은 없고, 새 저장 키도 0이다(featureUsage 재사용).
- **알림 팁을 누르면 이동(C2)**: `navigate({ type: "settings", focus: "notify" })`로 이동한다. 렌더 후 알림 구역(`settings-section-notify`)으로 1회 `scrollIntoView`한다(settlement-view 패턴, reduced-motion이면 즉시). focus는 상태로만 전달하고 URL 해시·저장에 남기지 않는다. 새 라우트는 0이다.

## 6. persist 트리거 (C1)
- 데이터 로드 완료 상위 1곳에서 판정한다(`HomeTipBox`에는 넣지 않는다). 조건 `isDataLoaded && hasAssets`이면 그 페이지 로드에서 1회만 실행한다(메모리 플래그, 저장 키 0).
- 다음 경우는 호출하지 않는다: 체험·데모, `navigator.storage?.persist` 미지원, 프롬프트를 띄우는 브라우저(최소안 UA `Firefox/`, tech-review 확정).
- 실행 순서: `persisted()`가 참이면 아무것도 하지 않는다(GA 0). 거짓이면 `persist()`를 호출해 결과로 GA 1건을 보낸다. 예외가 나면 삼키고 재시도·GA·화면 변화가 모두 0이다.
- 같은 세션 안에서 자산 0에서 첫 저장을 하면 이 조건으로 잡힌다. 별도 트리거는 없다.

## 8. 동승 p2 (각각 독립, 컷 순서는 p2 → ① → ②, ③은 컷하지 않음)
- **O1 배당 표**: `monthly-dividend-stocks.tsx`에서 휴대폰 배치 전환점 `sm:`을 `md:`로 바꾼다(그리드 2행·티커·배지). 짝을 이루는 휴대폰 보조 줄(`sm:hidden`)도 같은 전환점으로 맞춘다. 월 배지 칩 재배치는 하지 않는다.
- **새 소식 2건(ui.md 흐름 검토 확정)**: ① `성적표에서 가계 통계와 나란히 봐요` / `부동산까지 등록하면 내 순자산이 속한 구간도 보여요` ② `성적표가 결론부터 보여 줘요` / `투입 대비 성과를 결론 상자로 먼저, 계산 근거는 펼쳐서 봐요`. 둘 다 `featureId: "report"`다.
- **성적표 기능 팁 description**: `성과 탭의 자산 성적표에서 내 자산을 가계 통계와 나란히 확인하세요.`로 고친다. '내 구간'은 부동산을 등록하지 않으면 숨겨지므로 약속하지 않는다(C33). 금액·평가어·순위 0이며 금지어 테스트를 통과해야 한다.
- **1회용 링크 1줄**과 **허브 설명 삭제**: 4장 표와 같다.

## 10. 엣지 케이스
- **이미 결정한 기기**(권한 granted·denied, 로컬 알림 on, 켰다 끔): 팁 0.
- **iOS 16.4 미만·unsupported**: 팁 0, 알림 구역 없음(기존).
- **결산 창 11/27~12/10**: 결산 팁이 위에 있어서 알림 팁은 12/11 이후 뜬다. 새 소식 팁도 위에 있어서 그쪽이 먼저 뜰 수 있다.
- **복원 전·자산 0**: 웰컴이 보이므로 팁 0, persist 0.
- **잠금 상태**: 해제 후 자산이 확인될 때 판정한다.
- **다기기**: 팁 닫음·persist·구독은 모두 기기별이다(featureUsage는 동기화 대상이 아님).
- **Android 탭**: 설치 안내 문구가 실제 동작(설치 후 켬)과 맞는다.
- **persist 거부·예외**: 화면 변화 0, 백업 팁이 안전망으로 남는다.

## 11. 하지 않는 것
