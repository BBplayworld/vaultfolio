# 홈 전일대비 영역 정돈 (대표 11-14)

근거: origin/main(b2608a0) `home/dashboard.tsx`(Hero 변동·원인 1줄), `activity/market-entry-line.tsx`(MarketLine), `home-tip-box.tsx`. 스크린샷은 못 찍음(코드 근거만, 실측 후속 필요). 기능 삭제 없음, 정보 위계 정리가 목표.

## 1. 현재 노출 요소 (주식 보유·원인 있는 평일, 360px)
| # | 요소 | 언제 | 중복 |
|---|---|---|---|
| 1 | 순자산 금액(주황, 2xl) | 항상 | - |
| 2 | ▲금액 | 변동 ≥1만원 | - |
| 3 | (+x.x%) | 동일 | 금액과 같은 방향 수치 |
| 4 | 라벨 `전일 대비` / `지난 접속(M/D) 이후` | 동일 | 날짜가 #9·#11과 겹침 |
| 5 | 원인 1줄: [예측] 라벨 금액 `외 N개` ˅ | 원인 있음 | 요약 안의 요약 |
| 6 | 지수 줄 `M/D 종가 코스피 +x% · S&P -x%` > | 주식 보유·판정 on | 날짜 #4와 겹침, 원인1줄(시세)과 의미 겹침 |
| 7 | 총자산/총부채(우측) | 항상 | - |
| 8 | 닉네임·실시간 배지 | 조건부 | - |
| 9 | 펼침 시: 예측 칩·구간 `M/D → M/D`·원인 목록·상쇄 캡션·기록 목록 | 탭 | 구간·날짜 반복 |
| 10 | 그 아래 HomeTipBox 1개 | 조건부 | 별도 카드 |

Hero 한 덩어리에서 보이는 정보 단위 = 금액·%·라벨·예측·원인(라벨+금액+외N개)·지수 날짜·지수 2개 ≈ 11개, 텍스트 줄 3~4줄(변동 줄이 360에서 %·라벨로 줄바꿈 → 2줄 + 원인 1줄 + 지수 1줄).

## 2. 진단
1. 위계 4단이 같은 크기: 변동(base bold) → 원인(sm) → 지수(sm muted). 시각 위계는 사실상 2단뿐인데 의미 단계는 4개.
2. 날짜 중복: 접속 간격이 길면 `지난 접속(11/10) 이후` + 원인 구간 + 지수 `11/13 종가`가 서로 다른 날짜를 연달아 보여 줌 → "xx/xx 이후" 메시지가 반복되는 느낌.
3. 변동 줄 자체가 금액·%·라벨·(예측)으로 360에서 줄바꿈 → 숫자 한 덩어리로 읽히지 않음.
4. 원인 1줄과 지수 줄이 둘 다 "왜 움직였나"를 시장 쪽에서 답함(내용 겹침). 둘 다 사용자는 탭 입구가 아닌 정보 줄로 읽음.
5. 지수 줄은 입구(>)인데 정보처럼 보이고, 원인 줄은 입구(˅)인데 문장처럼 보여 입구가 2개로 분산.

## 3. 개선안

### A안(권고): 한 줄 요약 + 단일 펼침 입구
- 기본 노출: 변동 줄(금액·%·짧은 라벨) 1줄 + 원인·지수를 합친 **보조 1줄** 1개만. 라벨은 `전일 대비`면 그대로, 접속 간격이 길면 `M/D 이후`(`지난 접속` 삭제).
- 보조 1줄: `삼성전자 -3.2만 외 2개 · 코스피 +0.8%` 식(원인 top 1 + 지수 첫 시장 1개), 끝에 ˅ 하나. 눌러 펼치면 현재 패널 안에 원인 목록 + **지수 종가 요약(M/D 종가 코스피·S&P, 시장과 비교 이동 링크)** 을 같은 섹션에서 보여 줌. 예측 칩은 라벨 옆으로 이동(펼친 패널엔 중복 제거).
- 지수 날짜는 변동 라벨과 같으면 생략, 다르면 펼침 안에서만 표기.
- 정보 수: 기본 11 → 6(순자산·금액·%·짧은 라벨·원인 top1·지수 1), 줄 수 3~4 → 2~3, 입구 2 → 1.
- 구현 범위: dashboard.tsx Hero(원인 줄·MarketLine 위치 이동), MarketLine를 패널 내부 variant로. 기존 테스트 id(home-cause-line, home-market-today) 유지, 접힘 모션(grid-rows 전환, inert)·`motion-safe`·히트 40px 현행 재사용. 신규 토큰 0.
```
360 기본
순자산  
12억 3,456만원
▲1,234만 (+1.0%) 전일 대비
삼성전자 +820만 외 2개 · 코스피 +0.8%  ˅
펼침:
 ▸ 원인 목록(라벨·금액) / 상쇄 캡션
 ▸ 11/13 종가 코스피 +0.8% · S&P -0.3%  >
```

### B안: 지수 요약 칩화 + 중복 제거만(소폭)
- 원인 1줄은 유지, 지수 줄을 Hero 밖 우측 정렬 소형 칩 `코스피 +0.8%`(1개, 날짜는 같으면 생략, 다르면 `11/13`만)으로 축소, 둘째 시장은 칩 탭 후 시장과 비교에서. `지난 접속(M/D) 이후` → `M/D 이후`.
- 정보 수 11 → 8, 줄 수는 지수 줄이 칩이라 변동 줄에 합류 불가한 360에선 그대로 3줄. 입구는 2개 유지.
```
360
12억 3,456만원
▲1,234만 (+1.0%) 11/10 이후
삼성전자 +820만 외 2개 ˅      [코스피 +0.8%]
```
