## 1. 제안 (순위순)

### 1위. 표 붙여넣기·CSV 가져오기 (엑셀·시트 사용자 입구) — 규모 M, 위험 medium
- **단절**: B. 경쟁자가 엑셀인데 엑셀 데이터를 받지 못한다.
- **사용자 흐름**: 웰컴 "직접 입력 · 가져오기" 팝오버 + 상세 주식 탭 가져오기 → "표 붙여넣기 / CSV" 선택 → 시트에서 복사한 `종목명(또는 코드) · 수량 · 평단` 붙여넣기(또는 파일) → 열 자동 인식(헤더 한글/영문) → 종목 매칭 결과 확인 화면(미매칭은 직접 선택) → 저장. 2단계로 현금·코인·대출(이름·금액) 확장.
- **재사용**: 확인·충돌 단계 UI는 `StockScreenshotImport`의 `preview/conflict` 단계(`ImportStock[]` 입력)를 파서 결과 주입만으로 재사용(파싱 함수 분리 필요), 종목 매칭은 `kr/us-stock-master.json`·`name-match.ts`·`/api/ticker-search`(종목코드만 서버), 저장은 `saveData`·`trackAssetSave`·`first_asset_saved`. 신규는 순수 파서 1개와 붙여넣기 다이얼로그 1개.
- **지표(GA)**: 기존 `onboarding_action`(method) · `asset_save`(method)에 값 `paste` 추가(PARAM_VALUES 1줄, 맞춤 정의 method 이미 등록). 성공 지표: 28일 first_asset_saved ÷ welcome_view 기기, 보조로 `method=paste` 비중. 실패 지표: 매칭 실패율(`data_action result=fail`).
- **서버 전송**: 0. 파싱·매칭은 로컬, 서버는 기존처럼 종목코드 시세 조회만(원칙 부합). 스크린샷 AI 한도·서버 분석을 거치지 않는 점이 보안 메시지에도 이득.
- **위험**: 열 인식·종목 오매칭이 자산 수치 오류가 됨 → 확인 화면 필수, 미매칭은 저장 제외. 스키마 무변경.
- **결산 창 충돌**: 없음(입력 경로 추가, 결산 화면·홈 팁 무접촉). 단 웰컴 팝오버 항목이 늘어 #48 퍼널에 영향 → 머지일·코호트 기록으로 판독 보정(대표 2026-10-31 지시).

### 2위. 검색 유입용 SSR 소개·구조화 데이터 (같은 URL) — 규모 M, 위험 low

- **사용자 흐름(관찰 가능)**: 사용자 화면은 그대로. 크롤러·링크 미리보기가 "엑셀 대신 쓰는 로그인 없는 자산 정리, 자산은 내 기기에만" 소개·핵심 기능 3개·FAQ 5개 본문과 `WebApplication`/`FAQPage` JSON-LD를 받는다. 로드 후 앱이 이를 대체.
- **재사용**: `layout.tsx` metadata·OG(v4.35 반영분), 앱 가이드 `app-guide.tsx`의 기능 설명 원문, 보안 카드 원문. 서버 컴포넌트 셸 한 겹(`page.tsx`가 client라 소개 섹션은 layout 쪽 서버 렌더).
- **지표**: GA 유입 소스별 first_visit(검색/Direct 구분), 28일 신규 기기 수. 표본이 작아 4주 누적 비교.
- **제약 준수**: 새 URL 금지 → sitemap 확장·가이드 페이지는 **제외**. 문구에 금액·투자 조언 없음, 실제 기능만(서버 역할은 보안 메시지 기준 따름).
- **결산 창 충돌**: 없음. 첫 화면 UI 무변경이라 #48 판독 오염 최소(분모 코호트만 변동, 변경일 기록).
- **안건(대표 판단)**: 가이드·FAQ 별도 URL(sitemap 확장)은 "새 진입점 금지"와 충돌 → 필요하면 재논의.

### 3위. 첫 자산 직후 "내 투자 유형" 보상 순간 — 규모 S~M, 위험 low
- **단절**: D. 첫 자산을 넣은 사용자에게 돌아올 이유·공유할 재미가 없다. #33 닫힘(재제안 허용, 새 이슈).
- **사용자 흐름**: 주식 포함 첫 자산 저장 → 저장 완료 화면(토스트 대신 1회성 하단 시트) "내 투자 유형이 나왔어요" → 유형명·한 줄 설명 → [인증카드로 보기] / [나중에]. 이후 홈은 현행. 새 URL·테스트 질문 없음(보유 종목 기반이므로 "테스트가 첫 페이지" 결정과 충돌 없이 이미 있는 동선 활용).
- **재사용**: `resolveInvestorType`, `useXrayClassifications`, `ShareScreenshotDialog` variant `type`, `dispatchOpenShareCard`, `first_asset_saved` 훅 지점(`trackAssetSave` prevAssetCount===0).
- **지표**: `share`(content_type=type) 오픈율, 신규 `feature_use category=...`는 기존 값 재사용 불가 시 PARAM_VALUES 추가. 2일차 재방문 기기 비율(session_start).
- **위험**: 분류 캐시가 비면 결과 지연 → 스켈레톤 후 지연 시 시트 생략(실패 시 아무것도 안 띄움). 투자 조언 아님을 문구에 유지("유형", 추천 없음).
- **결산 창 충돌**: 홈 팁 박스 비접촉(시트는 별도 레이어). 첫 달 사용자는 결산 대상 아님. 충돌 없음.

1. **조건 알림(Push) 재도입** (L, risk high): 단절 D·E의 근본 해결책이나 iOS는 설치 사용자 한정, 서버 구독·시세 조건 판정·크론 필요, 2026-08 신선도·목표 알림은 "효용 낮음" 롤백 전례. 2026-08 승인한 "사용자가 직접 켠 평가금액 변동 알림"만 대상이며 월 활성 33명 규모에 투자 대비 불확실. 이번 우선순위에서 제외, 방향만 확인 요청.
