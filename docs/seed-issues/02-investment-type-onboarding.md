## 한 줄 요약
자산이 없는 신규 사용자의 첫 페이지 주 버튼을 "스크린샷 한 장으로 내 투자 유형 보기"로 바꿔, 테스트가 곧 온보딩이 되게 한다.

## 배경
자산 기록·성과 공유는 사회적 부담 때문에 공유되지 않는다. 투자 유형은 금액·수익률 없이 "웃기고 신기해서" 공유할 수 있는 콘텐츠다.
동시에 처음 온 사용자가 첫 스크린샷을 올릴 강한 이유가 된다.

## 이미 결정된 것
- 기존 사용자의 첫 화면(홈 대시보드)은 바꾸지 않는다
- 자산 0건 사용자의 첫 페이지만 변경 (현재 동선: 첫 페이지 → 자산 입력)
  - 주 버튼: 스크린샷 한 장으로 내 투자 유형 보기
  - 보조 버튼: 직접 입력하기 (기존)
- 흐름: 증권사 스크린샷 업로드 → 인식 결과 확인·수정 → 투자 유형 카드 → "이대로 저장하고 내 자산 보기" → 홈
- 유형 분류는 기존 X-Ray 분야 비중 데이터 기반 규칙 매핑 (AI 판단 불필요)
- 유형 카드에는 금액·수익률·등급 없음. 유형명 + 한 줄 설명 + "S" 아이콘
- "스크린샷은 서버로 가지 않아요, 폰에서만 분석해요"를 테스트 화면에 명시 (실제 처리 방식과 일치하는지 developer가 확인)
- 별도 /type 링크는 지금 만들지 않는다
- 기존 사용자는 인증카드 메뉴에서 유형 카드를 지금처럼 생성

## 열린 질문
- 유형 목록과 분류 기준 (6~8종, 자조적 유머 허용, 비하 금지)
- 스크린샷 인식 실패 시 테스트 흐름에서의 대체 경로
- 기존 온보딩 마법사 스펙과 겹치는 부분 정리
